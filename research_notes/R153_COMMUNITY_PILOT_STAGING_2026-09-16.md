## Chosen sharing, private work, and the console

Proposed layout under a NEW node-local root per learner: `life/`, `workspace/`,
`private_inbox/`, `tool_spool/`, `receipts/`. A host-side broker owns the shared
catalog and versioned artifact store. Learners cannot mount each other's roots.
Cross-node transfers use trusted repository wrappers; no transport credentials
are exposed in child sandboxes. The shared store is not the research repository.

The child explicitly chooses operations: list/read its notes, write a new note
version, publish an artifact version, list/read public artifacts, send a message
to named peer IDs, inspect/defer inbox items, or request an experiment. Publishing
copies bytes to an immutable content-addressed object with publisher and version;
later edits create new versions. Reading/listing is not publication. A peer may
inspect, ignore or defer; no automatic context injection of every thought, no
automatic complete-workspace mirroring, no automatic execution of received code.
An inbox availability notice may contain counts/IDs only; the child requests
message content. All-child broadcast requires an explicit recipient choice.

Mint author identity from the authenticated life/process binding, never a model-
supplied `speaker` field. Persist publication, routing, inspection and any cited
use as distinct events. A durable outbox/inbox cursor plus request IDs suppresses
duplicate effects on restart; interrupted ambiguous execution is recorded as
UNKNOWN and is not silently rerun. Received content is untrusted data, not a
system/parent instruction and not authority to access files or allocate GPUs.

Rohin's console selects C1..C5 or the separate R127 life; viewing a history does
not send it anywhere. `Rohin`, peer ID and executor source remain distinguishable.
Parent delivery is recorded at actual rendered-turn exposure, not just enqueue.
No automated parent cadence by default in this lightly guided pilot; one named
console lead at a time and explicit handoffs. While any tool/human/peer response
is pending, generation continues. Inject results only at a safe turn boundary.

## Visibility, observations, and claim limits

Each learner sees its own history and explicitly inspected TRAIN publications,
attributed selected messages, actual tool results and targeted human input. No
other private context/adapter/optimizer or cross-life execution authority is
visible. Parents/console see TRAIN activity, not sealed benchmarks, readout
answers/scores or derived rankings. Stores and workspaces are constructed from
explicit allowed inputs, not a broad repo mount with blacklist-only filtering.
Readouts have neither community connectivity nor retrieval/file support.

Track all five learners, failed and ignored interactions included:
- Propagation: attributed contribution -> chosen inspection -> changed artifact
  or attempted work -> independently observable consequence. Text similarity alone
  establishes possible influence, not useful learning or causal peer benefit.
- Independent continuation: self-initiated follow-up after help, logging further
  parent/peer/tool exposure and elapsed activity rather than rewarding long text.
- Retention: reuse after sleep/intervening work; separate context/file retrieval
  from fresh-process, empty-context, file/parent/peer-free checkpoint behavior.
- Diversity: distinct projects, selective rejection and self-directed changes;
  useful convergence on verified results is not degradation. Record repetitive
  agreement, copied errors and rewrites without new evidence as failure signals.

Keep fixed inherited readouts, initial checkpoints and per-sleep snapshots; no
new benchmark pass thresholds or degradation cutoffs introduced here. The R127
one-to-one thread is observational, not a peer-ablation control. A later five-
isolated-learner comparison must match starts, task opportunities, human guidance,
aggregate inference/training/tool compute and realized exposure accounting.
No community advantage, human-parent superiority or improved intelligence claim
from this pilot alone. Any changed scientific claim gets its own deliberation.
