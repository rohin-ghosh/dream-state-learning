**Learning From a Life: Connected Parametric Memory for Acting Agents**

## Full result-conditional abstract (241 words before result insertion)

Language agents can preserve deployment experience in text, but it remains
unclear whether one agent can turn its own action outcomes into selective
parametric knowledge that improves later action. We study a frozen language
model with a per-life low-rank adapter and three operations: THINK interleaves
reasoning, tool use, and public outcomes; DREAM distills active state and
proposes connections among grounded experiences; SLEEP compiles admitted
events and child-authored connections into a cumulatively replayed adapter.
We first qualify the writer on conditional native actions, requiring
acquisition without global action spill or interface damage. We then introduce
a two-cycle causal relay in which a child acts and observes, organizes old
experiences before their later use is revealed, selects an informative
experiment from recalled content, writes its outcome in a second sleep, and
faces a delayed task requiring one old connection and the new fact. Source-
binding derangements, DREAM-deranged rows, adapter removal, wrong-life mounts, link
cuts, semantic twins, and an exact-text ceiling localize every step. Finally,
independently raised children receive either adaptive target-blind parenting
or no teacher, after which the teacher and all childhood text are deleted.
RUN/FROZEN deployment forks test whether continued SLEEP causes improvement;
a concurrent evolving-text-memory branch supplies a strong nonparametric
baseline. [Insert sealed writer, relay, lifetime, retention, and baseline
results with root-level uncertainty.] These experiments test whether useful
experience can be compiled, connected, expanded, and reused across a finite
life, while separating initial competence, personal learning, teaching, and
temporary textual assistance.

## Current-evidence fallback abstract (228 words)

Language agents can preserve deployment experience in text, but turning one
agent's own action outcomes into stable parametric changes creates a coupled
acquisition--locality problem: a write may memorize useful content, install a
global habit, or damage the action interface. We develop a provenance-bound
Think--Dream--Sleep testbed around a frozen language model and a per-life
low-rank adapter. THINK interleaves reasoning, actions, and public outcomes;
DREAM distills active state; SLEEP renders grounded experience, replays older
material, and transactionally accepts or rejects a new adapter. Across three
adapter-training seeds in a 4x4 Sudoku diagnostic, correct solution material
outperformed equal-target-marginal corrupted material by `+2`, `+2`, and `+5`
exact first-action solves, establishing repeatable directional material
transfer at this resolution. The result is not yet selective or child-
authored. On a conditional memory assay, lowering the learning rate preserved
broad action spill; masking prompt-side loss reduced spill from `.416` to
`.202` but also reduced the acquisition contrast from `1.921` to `.015`.
Parenting prerequisites also remain unresolved: fitting historical lesson-
conditioned continuations harmed both lesson and sham children, while a
teacher-present process card tied its sham at `1/16` solves and changed only
output form. We use these failures to specify a two-cycle causal benchmark
that separately tests authentic action--outcome binding, child-authored
connection, goal-conditioned traversal, new-outcome incorporation, delayed
old-plus-new use, and a clean parented-versus-no-teacher lifetime study.
Connected experiential learning and increasing-lifetime improvement remain
prospective rather than claimed.
