Core Thesis

The thesis is not fundamentally "we invented a new sleep mechanism" or "we invented a new form of LoRA memory."

The thesis is that we can teach a model a behavior that causes its own interaction with the world to continuously generate useful post-training data for itself.

Pretraining gives the model latent capabilities and knowledge about reasoning, planning, reflection, memory, emotions, goal pursuit, verification, and so on. Post-training demonstrates that weights can be changed to alter model behavior and encode new information.

The missing loop is:

external world → model experience → model cognition/reflection → trainable experience → post-training → changed model → better future cognition/reflection → better future learning

The model does not learn only because it receives new information. It learns because it has been trained to process new information in a way that makes that experience useful for subsequent weight updates.

That is the continual-learning flywheel.

The key distinction from naive self-distillation is that the information being consolidated does not originate only from the model itself. New information enters through people, agents, environments, tools, outcomes, rewards, failures, and observations. The model transforms those external signals through its own cognition into representations that can be consolidated.

So the flow is:

external signal → perception → internal thought/reflection → structured experience → consolidation/post-training → model change

The model's outputs can be distilled because its outputs contain transformations of genuinely new external information.

Parenting

Parenting is the bootstrap procedure that creates the first functioning learning flywheel.

The parent is not primarily teaching the model facts. The parent is teaching the model how to experience things in a way from which it can learn.

The model needs to learn things like:

how to perceive important events; how much attention different events deserve; how to think about an event from multiple perspectives; how to connect new observations to prior experience; how to reflect on success and failure; how to construct goals; how to move between long-term goals, plans, subplans, and immediate execution; how to verify its actions; how to critique its own reasoning; how to critique the strategies it uses for reasoning; how to decide when further thinking is useful versus wasteful; how to react to reinforcement; how to remember things selectively; how to transform experience into future behavioral change.

A weak version of this could be hardcoded: "think about every event sixteen times," "always produce five reflections," etc.

But that is not the desired endpoint. Those rules are scaffolding.

The desired endpoint is a learned policy for cognition: the model learns what deserves thought, what deserves memory, what deserves reflection, and how much computation each deserves.

Memory therefore has both a mechanistic and an intelligent component. The mechanism might make storing an experience possible. Parenting teaches the model which experiences are worth storing and how richly they should be processed before storage.

The Learning Flywheel

At initialization, there is already a tiny flywheel because pretrained/post-trained models can reason, remember within context, plan, reflect, and follow instructions. Then we expand it in stages.

Birth — Create the simplest initial behavioral prior. Tell or post-train the model toward behaviors such as: important things should receive more attention; important ideas should be revisited; observations should be connected to prior knowledge; failures should produce reflection; plans should persist across execution; outcomes should modify future strategy. This does not need to be intelligent yet. It only has to create enough structure for subsequent learning to become possible.

Preschool — Now allow the model to begin learning these behaviors through experience. Use small, controlled parenting gyms where reinforcement makes it possible to test whether it can learn things such as: what should be remembered; how deeply something should be processed; when to verify; how to plan; how to update a plan; how to react to mistakes; how to alter its own cognitive strategy. Preschool is the first stage where the flywheel itself begins improving through the flywheel.

School — Move into richer environments containing genuine external information and consequences. The curriculum remains fundamentally the same: perception, memory, reasoning, planning, execution, verification, reflection, metacognition, goal formation, and learning. But now these skills are exercised while solving actual tasks. The model is therefore no longer merely practicing "how to learn." It is simultaneously learning how to learn and learning things about the environment. At this point external outcomes enter the flywheel: environment → cognition → consolidation → changed model → changed behavior in environment.

Adulthood / Deployment — Once the learning system is sufficiently formed, deploy the model into a novel gym. The childhood parent does not need to remain omniscient. The model should now continue learning from: environmental outcomes; people; agents; task success/failure; observations; its own subsequent reflection on these signals. Plasticity can be reduced or constrained relative to childhood while still permitting learning. The experiment asks whether the flywheel continues turning after the explicit childhood curriculum ends.

Runtime Cognitive Loop — During an episode, the model receives observations, produces thoughts and actions, and receives new observations. Its context therefore represents an evolving cognitive state. A rough loop is: observation → perception → current goal → plan → subplan → execution → new observation → comparison with expectation → reflection/update → continued execution. Longer-horizon state should also remain represented: long-term goal → intermediate goal → local plan → current action. The important point is that planning, execution, perception, and reflection are not separate magical systems. They appear as sequences within the model's evolving context. The learning objective is to make those sequences coherent enough that they become useful material for later consolidation. There may also be a "daydreaming" phase during the episode that compresses or reorganizes accumulated context before final consolidation.

Sleep / Consolidation — Sleep is the mechanism by which experience becomes persistent model change. The current hypothesis has at least two kinds of consolidation. Memory-oriented consolidation: memory is comparatively local; a perception, observation, result, reflection, or small cluster of connected thoughts can become an individual training sequence; the compiler identifies units such as perception → interpretation → significance, or event → reflection → remembered conclusion; these sequences can be relatively short; the goal is retention of information learned through experience. Behavior-oriented consolidation: behavior exists across longer trajectories, e.g. goal → plan → execution → outcome → revision, or failure → diagnosis → strategy update → second attempt, or an entire episode; behavioral consolidation trains on variable-length slices: full episodes, goal segments, planning segments, plan-to-execution transitions, execution-to-reflection transitions, long thought streams, subsequences that express a useful behavioral pattern. This distinction is important: memory comes largely from the content of states; behavior comes largely from transitions between states over time. The exact compiler does not have to be perfect for the first paper. It needs to be good enough for experience to produce measurable persistent behavioral and memory changes.

Mechanism-First Experimental Strategy — Do not solve the whole parenting problem before validating the learning mechanism. First determine what kinds of training examples reliably produce persistent memory changes and persistent behavioral changes. This is essentially a controlled post-training question. Given the correct target sequence, can our adaptation mechanism make the model remember this? Given the correct trajectory, can our adaptation mechanism make the model behave differently later? Once those mechanisms work, parenting becomes the problem of teaching the runtime model to generate those useful target sequences from real interactions. Step 1 — Verify consolidation (idealized memory and behavioral examples; train; test whether the change survives removal of the original context). Step 2 — Verify the birth policy. Step 3 — Preschool. Step 4 — School. Step 5 — Adult continual-learning test.

Experimental Claim — A language-model agent can be post-trained to transform interaction experience into useful self-generated training trajectories, creating a feedback loop in which experience-induced weight updates improve the cognitive behaviors that generate subsequent learning data. Parenting bootstraps this loop. School strengthens it. Deployment tests whether it persists. The central empirical question: Can learning-to-learn behaviors acquired during a developmental curriculum cause subsequent experience-driven post-training to produce greater persistent improvement than the same adaptation mechanism without that curriculum?

The Flywheel in One Line — Teach the model how to turn experience into learning; consolidate the resulting experience; the resulting model becomes better at turning its next experience into learning.
