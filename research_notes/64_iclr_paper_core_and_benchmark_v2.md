# ICLR paper core and benchmark v2

Date: 2026-09-10

Status: source-only manuscript and experiment planning. This document adopts
no protocol, parameters, benchmark bytes, model, run, claim, or release. It
authorizes no implementation or execution. It updates the paper logic without
overwriting `main.tex` before the corresponding architecture gates pass.

## The paper in one paragraph

A strong pretrained model begins with general reasoning but no personal life.
Optional target-blind schooling installs habits for making and revising rules;
one adaptive parent then teaches when to use those habits in unrelated
classrooms. The parent disappears. During deployment the child THINKs through
states and actions, DREAMs to manage active context, and SLEEPs by compiling
only its own grounded state transitions into a transactional personal LoRA.
The paper asks whether this produces connected experiential knowledge that the
child can traverse under different goals, expand by choosing an informative
action, and use to improve over an increasing lifetime after a strong evolving
text-memory agent has plateaued.

## One benchmark family, three distinct experiments

Use the PCFL relational-world generator as shared infrastructure, but never
pool the scientific units or artifacts across the three experiments.

### M -- mechanism relay: can the child use experiential structure?

One fixed, parent-deleted child is cloned into disjoint environment roots.
Within each root, the public chronology is:

```text
act -> observe atoms/relations -> connect them -> receive goal A / goal B
-> traverse different required paths -> identify a missing relation
-> choose a separating experiment -> observe its public outcome
-> SLEEP writes the new grounded transition -> reset
-> solve a delayed goal requiring both old and new knowledge
```

This is the direct test of connection, traversal, and expansion. It needs:

- authentic linked experience versus atoms-only, truthful-null links, and
  deranged links;
- two same-start goals whose correct paths differ;
- necessary bridge cut and binding twin/redirection;
- authentic uncertainty signal versus truthful sham;
- reachout/action disabled at dispatch;
- old-row available/cut crossed with new-row written/not written;
- adapter off, wrong life/root, and new-binding swap; and
- an explicit-text same-semantics ceiling before LoRA.

The independent unit is an environment root conditional on one fixed child.
Goals, paths, branches, calls, and checkpoints inside it are repeated measures.
M supports a mechanism-relay claim, not a population claim about children or a
lifetime-learning claim.

### L -- longitudinal development: does one learning system keep improving?

Independently raised clean child roots are paired into:

- `F`: full THINK/DREAM/SLEEP learner with personal writes; and
- `B`: certified `ACTIVE_TEXT_FIXED` agent with the same ordinary tools,
  public outcomes, update opportunities, and generated-token envelope, but a
  frozen acting model and evolving typed textual memory.

Both receive the same sealed sequence of opportunity sets and the same
exogenous-randomness tape, but each system chooses its own actions and owns
the resulting public outcomes. This makes L a total on-policy system
comparison: the systems may accumulate different information because their
earlier memories changed their later actions. A separate same-source carrier
assay, not L, compares text and LoRA over identical admitted payloads. The
baseline must satisfy its own prospective local plateau rule at the anchor;
at least three later cuts form the late window.

The release order is noncompensatory:

1. both systems have task headroom and the active-text baseline passes its
   faithfulness/read/use certificate;
2. the baseline's projected late-window slope is equivalent to zero;
3. the full learner's late-window slope is positive;
4. the slope advantage is positive;
5. old competence is retained; and
6. terminal full-learner value exceeds the baseline by the registered practical
   margin.

The independent unit is a separately raised paired child lineage. Lifetime
cuts, tasks, and samples are repeated measures. No fixed-child environment
clone counts as another life.

A failed or uncertified active-text implementation blocks only the superiority
and saturation claims. It does not erase an otherwise valid carrier-specific
M result; exact-text M cells are the assay ceiling, while the evolving
candidate-blind active-text agent is the separate systems opponent.

### C -- rate--distortion: is the learned semantic code actually compressed?

Use disjoint PCFL roots and increasing semantic loads. Compare:

- expanded observation text;
- normalized connected text; and
- schema-plus-residual connected text.

Measure exact round-trip fidelity, utility, false memories, and complete bytes
for the ordinary lossless codec and live representation. At current rank-8
size, physical LoRA compression is mathematically closed until the expanded
semantic reference exceeds the measured crossover. Therefore the near-term
claim is text-interface semantic-code compression. A LoRA arm, if run, tests
transport of the same semantics, not physical compression.

The independent unit is a disjoint environment root conditional on one fixed
child. Loads are repeated measures.

## Why PCFL is the headline environment

CompilerGym is useful ecological evidence that personal writes can alter real
agent behavior, and it exposed dialect drift, ritualization, late harm, and
writer-gate failures. It is not by itself a clean test of connected knowledge:
many pass sequences can work without an identifiable relation graph, and the
bootstrap prompt supplied an important strategy.

PCFL can mechanically guarantee that:

- the answer is unavailable from one observation;
- two goals require different paths through the same personal evidence;
- one necessary relation is absent until the child chooses an experiment;
- the delayed task requires both an older relation and the newly learned one;
  and
- every shortcut, binding, visibility, and intervention has an exact public
  receipt.

CompilerGym therefore moves to secondary transfer/failure characterization.
It cannot contaminate clean PCFL births, and PCFL confirmation cannot tune on
CompilerGym-selected mechanisms without declaring CompilerGym as development.

## Developmental causal surface

The parenting claim is separate from the mechanism relay. A clean factorial
must distinguish inherited entry competence from improved later learning:

```text
P0: parented childhood, deployment personal writes disabled
P1: same parented birth, deployment personal writes enabled
U0: matched unparented childhood, deployment writes disabled
U1: same unparented birth, deployment writes enabled
```

Every cell still receives the same certified active-text memory. The primary
parenting estimand is the root-level difference in entry-adjusted learning
between `(P1-P0)` and `(U1-U0)`. A better score at deployment entry is
schooling/parenting competence, not learning-to-learn.

The bootstrap is an inherited schooling factor, not personal experience. Its
scientific contrast is structure-heavy metacognitive schooling versus equally
active non-metacognitive schooling, with bootstrap-free and form-sham anchors
only where affordable. The bootstrap earns “learnability” language only if it
changes later acquisition or the incremental effect of parenting after entry
adjustment.

## Clean lineage in one rule

The canonical developmental child may continue across subjects and parenting
changes while its mechanism is unchanged. Any change to THINK, DREAM, SLEEP,
writer, mask, rank, eligibility, or promotion forks immutable mechanism
siblings. Any final/deployment benchmark visit creates a one-way disposable
descendant. Nothing from that descendant—including selection decisions—returns
to the child, parent, bootstrap, or protocol.

## Writer prerequisite

No M, L, or parenting result can support the paper until E0 passes. The writer
must:

- compile native prompt -> child response pairs and mask loss to the response;
- build every candidate from immutable birth over only the committed cumulative
  corpus;
- stage candidate adapter and candidate corpus together;
- use a predeclared fit-seed schedule and source-local qualification only;
  commit the first candidate passing every hard gate, never the candidate with
  the best deployment/report score, and count every rejected fit as writer
  yield rather than hiding it;
- compare against both raw base and the previous child using disjoint safety
  panels;
- atomically promote or reject both heads;
- quarantine rejected rows and derivatives;
- preserve exact action/outcome and source provenance; and
- emit a source/launch/artifact receipt for every evaluated child.

Current R2/RP/R3/R4 observations use the old bare-text writer and remain
failure/safety characterization only.

## Scaled THINK slot

State-branching is a mechanism sibling, not something silently added to the
longitudinal child. The first test compares:

- one visible sequential depth chain; and
- context-isolated sibling routes from the same state;

both with the same child-authored JOIN, one real next action, and equal
generated route/review/JOIN tokens. A second generous-budget comparison tests
the practical package. Raw branches remain lossless ledger records, not SLEEP
targets; grounded post-outcome state-transition syntheses may write.

If branching does not clear its topology, practical-value, and harm gates
before the final child begins, the paper uses the safe reference THINK and
reports branching as future work. The deadline does not convert an untested
organ into part of the child.

## Main-paper evidence order

Four figures/tables are enough:

1. **Architecture and clean lineage:** schooling -> parenting -> parent
   deletion -> THINK/DREAM/SLEEP, with disposable benchmark descendants.
2. **Mechanism relay:** authentic versus intervention curves for connection,
   two-goal traversal, selected experiment, and delayed old+new use.
3. **Lifetime curve:** full learner versus certified active-text baseline,
   plateau anchor, late window, retention, and terminal difference with
   root-level uncertainty.
4. **Noncompensatory evidence/cost table:** E0, parenting interaction, M, L,
   text compression, failures, tokens, calls, optimizer work, GPU hours,
   storage, and retrieval work.

If the evidence cannot fit, mechanism M and lifetime L stay in the main paper;
compression C moves to the appendix unless it passes strongly enough to alter
the title. CompilerGym is a secondary table/appendix result.

## Claim-controlled abstract

1. Fleet post-training does not include a particular agent's future life.
2. Define the clean schooling/parenting/THINK--DREAM--SLEEP system.
3. State the independent-root causal design and evolving active-text baseline.
4. Insert only the highest passing result among writer, parenting interaction,
   mechanism relay, and late-window lifetime advantage.
5. State the strongest observed failure or scope limit.

Do not say connected, traversable, expandable, compressed, continual
improvement, or baseline saturation unless its exact experiment above passes.
