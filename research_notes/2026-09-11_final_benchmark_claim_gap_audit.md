# Final benchmark claim-gap audit

Date: 2026-09-11

## Verdict

The planned reasoning-gym childhood followed by CompilerGym deployment can
test a useful but bounded question: whether targeted parenting changes what a
child carries, and whether that child benefits more from continued SLEEP over
a finite deployment horizon.

It cannot by itself support the full Dream--LoRA--Think claim. CompilerGym has
no identified experiential relation graph, no witnessed path traversal, no
missing-edge intervention, and no certified evolving-memory baseline. Its
repeated set of programs also cannot establish open-ended lifetime learning.

Current CompilerGym and child-frame scouts should finish. Their honest role is
writer, stability, and bounded-learning evidence. The connected-knowledge
claim requires the prospective PCFL relay after its design is repaired.

## What each final surface can establish

| Claim | Minimum decisive evidence | If absent, say only |
|---|---|---|
| Grounded experiential writing | Conditional-policy carriage, unrelated-write retention, and an unrepaired child action--outcome source test | Periodic self-training altered behaviour |
| Connected experiential knowledge | Authentic co-use links versus matched atoms, truthful-null and deranged links, plus necessary-link cuts | Compiled policies or records |
| Goal-conditioned traversal | Same public start with two goals requiring different memory paths, plus necessary-edge and twin-redirection controls | Task-conditioned use, not traversal |
| Expansion through action | An uncertainty-induced separating action, its public outcome, a causal write/no-write contrast, and a later goal requiring old plus new knowledge | Passive outcome consolidation |
| Compression | A rate--distortion comparison using total acting-state bytes at increasing semantic loads | Compiled or consolidated; never compressed |
| Increasing-lifetime improvement | Novel sequential cohorts, a prospective active-text plateau, at least three later cuts, retained old competence, positive slope advantage, and terminal margin | Improvement over a bounded deployment horizon |
| Better than strong memory | Candidate-blind evolving textual memory with the same admitted evidence, prompts, tools, seeds, and generated-token budget | Better than the tested static brief only |

## Highest-information order

1. Qualify conditional action carriage with V10R1.
2. Test survival through one identity-disjoint later write.
3. Test an unrepaired action--outcome source through the same writer.
4. Run one clean, randomized parenting-carriage experiment.
5. Certify the evolving textual-memory comparator.
6. Run the prospective parenting-by-SLEEP deployment factorial.
7. Use C11 only as the supplied-memory ceiling for the PCFL topology.
8. Run the learned PCFL connectedness, traversal, and expansion relay.
9. Add lifetime and compression studies only after the corresponding lower
   mechanism gates pass.

This ordering is noncompensatory. A positive downstream score cannot repair a
writer that carries only one global habit, a parent effect without removal, a
text baseline that was never made usable, or a benchmark without the claimed
causal structure.

## Recommended paper boundary under the deadline

If the clean parenting and bounded deployment tests land, the paper may claim
a developmental case study: one taught child retained a bounded learning
skill and benefited more from continued consolidation over the measured
horizon. The current compiler evidence can support that story with explicit
limits.

If the PCFL learned relay also lands, add connected experiential knowledge,
goal-conditioned traversal, and prospective expansion as separate causal
results. If it does not fit or does not pass, remove those words from the
headline rather than treating general task improvement as a proxy.

Do not claim physical compression from LoRA rank. Use `compiled` or
`consolidated` until a registered total-byte crossover and preserved-utility
measurement exists.
