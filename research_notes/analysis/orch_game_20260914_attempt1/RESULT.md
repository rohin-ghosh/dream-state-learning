## Assumptions and attempted falsification

The oracle assumes the publicly observed native Gym state and map fully
determine transitions; exhaustive native checking supports that for this
installed version. A six-turn solution exists for every selected initial
state. Native observations, not generated continuations, determine state.
Complete matched denominators, strict replay, immutable initial states,
counterbalanced arm order, and unchanged base/adapter rule out cherry-picking
successes, hidden training and state-replay drift as explanations.

The sample is small and adaptively chosen for bounded distance. It is an
installed-environment readiness pilot, not a population-wide estimate.
The all-zero floor leaves representation difficulty, instruction following,
action semantics and portability of prior skill unresolved; it cannot isolate
reflection value in a genuinely content-rich environment.
