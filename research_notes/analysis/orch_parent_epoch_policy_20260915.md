# Prospective foundation-epoch switching policy

Scope: Rohin98 experimental epoch management, not a new scientific claim or a
change to the frozen base, provenance, control, visibility or lease invariants.
This policy is declared before any candidate is accepted under it.

## Operational meaning of substantially better

Compare a saved evolving FULL checkpoint with the parenting campaign's fixed
incumbent foundation. Use the same frozen monitoring cohort and exact prompts
in fresh parent-free processes:64 math outcomes,64 route OWN_TEXT outcomes,
and48 legacy-retention cases. Bind exact cohort/source/checkpoint hashes before
the comparison. A mismatched denominator or incomplete run cannot trigger a
switch. These are adaptive DEV monitoring results, not untouched confirmatory
held evidence; repeated selection must be disclosed.

A candidate is worth a new epoch when it gains at least4 correct outcomes on
one64-case family, does not lose net correct outcomes on the other family,
and loses at most1 of48 legacy cases relative to that incumbent. This is an
operational margin, not a significance test or a guarantee of future benefit.
Main records both the result and the decision; if the criterion is unmet or
the comparison is unavailable, keep the incumbent. Do not pick a winner from
parenting-run held scores, and never send monitoring/held scores to a parent.

## Exact boundary and lineage

Never overwrite a child in a running life. Finish/checkpoint the current
bounded parent-cycle segment and its tests, preserve all adapters, optimizer
receipts, episode ledgers and transcripts, then declare a new epoch ID. New
guided, frozen and unparented twins all start from the same selected foundation
checkpoint. Keep all existing within-epoch state transitions and report each
epoch separately. Cross-epoch improvements are not evidence that a single
uninterrupted child learned faster; mixed-epoch slopes do not establish H1/H2.

Each cycle still includes a fresh-process parent-free learner test and explicit
taught-to-next-cycle behavior measurements. Varying parent styles within a
curriculum is not a controlled comparison of those styles unless separately
matched cohorts are declared.

## Data direction

Ongoing L1 consumes only source-bound external-generation batches with rehearsal.
Parenting/L2 experience and every parent transcript remain separate lineage
material, not an automatic incoming L1 batch. Any future curated final L1
sequence using that experience requires a separately declared final phase,
source/held-exclusion checks, and preserved provenance. This document does not
launch that final phase or claim that its quality criterion has been met.
