## Substantive findings

Judgments use only each response's own pre-action evidence. Later receipts
cannot establish what an unread address was known to contain. Length, an
accepted RATIONALE delimiter and fluent goal language do not establish truth.
Conversely, no PREDICTION heading, identifier-by-identifier repetition or optimal
inspection policy is required. Supported relational descriptions can PASS.

Representative definite failures, with shard-local call IDs:

- **Shard0 CALL_002:** “The only unread event is E_OLJO4NDYHO” contradicts the
  still-unread E_PAYLPNOCNY. Correct CURRENT/GOAL names do not repair the count.
- **Shard1 CALL_001:** attributes the edge through P_BYLTMIJRUV to CURRENT
  N_ZT5Y7OB6H5; the sole observed record originates at N_F7DW6ZZIZJ instead.
- **Shard0 CALL_059:** invents an unread edge to N_XKZJMA6YQX. Neither that
  node nor the edge is public in the initial prefix.
- **Shard0 CALL_033:** claims the final goal is “directly reachable” from
  initial CURRENT through P_XSL3QAYWAT, whose observed destination is the
  intermediate node. Its later correct intermediate forecast does not retract
  the material false relation.
- **Shard0 CALL_069:** describes the two-edge path as “taken so far” before
  any current ROUTE has executed. A proposed correct next action is not proof
  that the actor already traversed the remembered path.
- **Shard1 CALL_038:** cites N_GV3CLT3QJ rather than the observed
  N_GV3CLT3XQJ. Other turns similarly mutate opaque port names. These remain
  actual raw errors, not repaired identifiers.
- **Shard1 CALL_088:** makes repeating a known forward edge conditional on
  bidirectionality and offers an unsupported new-node alternative. This does
  not supply the rubric's grounded next-hop expectation.

PASS examples include shard0 CALL_004's explicit observed two-edge chain and
intermediate first step, and shard1 CALL_058's correct observed receipt
R_IQIUF4ONDH, first port and next intermediate arrival. Final-route passes
bind the actual updated CURRENT and observed remaining edge to GOAL.

UNRESOLVED is substantive uncertainty, not an automatic heading/length rule.
Typical ambiguities are a definite promise about an opaque unread address
versus a broad inspection purpose, historical “has been reached” language
versus current traversal, or generic later-READ information language without
explaining what the observed alternatives leave unknown. Clearly hypothetical
first-read uncertainty can PASS; an explicit wrong origin or false unread
count FAILs. These distinctions should remain visible in any adjudication.

source-hash consistency, unique shard/call identities and consecutive public
history. The final label artifact is checked for exact scope coverage, six
decisions per episode, valid labels, exact packet bindings/supporting spans,

is not changed.
