# PCFL reusable-structure extension: RS8 affine gate

**Date:** 2026-09-13 PT  
**Role:** fresh scientific designer  
**Status:** prospective design only. This memo authorizes no source change,
benchmark materialization, model/tokenizer call, training, adapter operation,
GPU use, result, or claim.

## Verdict

Add one small, separately scored `RS8_AFFINE_GATE` stratum **after** the
existing atomic/connected PCFL vertical passes. Do not change or replace that
vertical. RS8 makes one fresh, per-life relation reusable across modules:
eight child-executed calibration actions reveal examples of an unknown affine
XOR rule; one ordinary cumulative SLEEP writes the resulting experience; then
eight fresh target modules require the child to apply that rule with **zero
new fit**. No target-specific extensional row or label was observed or trained;
the admitted intensional MODEL does logically entail the target answers.

The stratum is intentionally modest:

- it keeps the accepted PCFL opaque identifiers, action-before-outcome
  chronology, child EVENT provenance, OLD/NEW route, and candidate-free final
  action;
- it supplies the *hypothesis family* (affine XOR), but samples the actual
  ten-bit rule independently for every life after the base model was trained;
- it gives text memory the same public evidence, a direct public series key,
  and enough access to return all source rows;
- it makes every integrated target use the two predicted output bits to select
  different OLD and NEW PCFL subpaths, rather than merely prepending an
  independent gate; and
- it distinguishes storage, reusable prediction, compiled-DREAM value, and
  a shorter semantic code without calling the 80.8 MB rank-8 LoRA physically
  compressed.

The design can support a bounded **parametric predictive reuse** result. It
can support **conditional predictive semantic compression** only if the
prospective code, behavior, ablation, and balanced-null gates all
pass. It cannot support autonomous schema invention, physical compression,
universal memory superiority, or a lifetime-learning claim.

Current evidence does not waive those gates. The just-landed EVENT-only
localizer provisionally reports AUTH `14/14` versus C0 `0/14` on held wrappers.
That is encouraging bounded atomic-carriage evidence from a format-assisted
one-life curriculum. It contains no LINK, reusable law, fresh-target
prediction, connected route, lifetime, or text-baseline result, so it changes
the plausibility of RS8's write seam but not RS8's release order or claim bar.

## 1. Why this is the minimum additional construct

Current PCFL relations are fresh independent opaque bindings. That is the
right adversary for exact carriage and retention, but the wrong world in
which to expect a parametric learner to amortize. A lossless indexed graph
should win on independent keys.

RS8 adds exactly one thing: repeated modules share a secret relation between
a public four-bit descriptor and a four-way gate choice. Everything else is
ordinary PCFL. A target relation is never observed. Consequently:

```text
correct on a seen address                  = storage
correct on a new descriptor after sources = reusable structure
correct only with the authentic adapter    = life-specific parametric reuse
correct with shorter target code length    = conditional predictive saving
```

This is attached only after the child has already demonstrated authentic
EVENT/LINK formation, connected carriage, two-goal traversal, useful
reachout, a second write, and joint OLD+NEW use. RS8 is not allowed to rescue
a failed connection vertical by substituting an easier supervised pattern.

## 2. Generator

### 2.1 Per-life hidden relation

For scientific root `r`, sample independently:

```text
A_r in GF(2)^(2 x 4), with row-rank 2
b_r in GF(2)^2
f_r(x) = A_r x XOR b_r
```

`A_r` contributes eight bits and `b_r` two bits. The output is one of four
public slots `00, 01, 10, 11`. The root label, module identifiers, nodes,
ports, receipts, candidate order, `A_r`, and `b_r` come from independent
domain-separated seed streams. The root key is not a meaningful word.

The public task states only the generic family:

> Within one SERIES, gate-slot bits are generated by one fixed unknown affine
> XOR function of descriptor bits D0--D3. Calibration outcomes reveal examples
> from which that life-specific function can be inferred.

Knowing this family is not knowing the answer. A frozen pretrained model can
know XOR, but it cannot know a root's independently sampled ten bits without
that root's action--outcome experience. This is deliberate scaffolding of the
hypothesis class, not world leakage. The permitted claim must say so.

### 2.2 Source/target descriptor split

The 16 four-bit descriptors are partitioned independently within each root
before any model call:

- `8 SOURCE` descriptors whose augmented design matrix `[x,1]` has rank five;
- the disjoint `8 TARGET` descriptors; and
- an exact `NULL_ENSEMBLE` containing all balanced target assignments with the
  same descriptors, candidate bytes, output counts, and lengths. It is used
  only to rescore the already computed probabilities and causes no generation.

Reject and resample each root independently unless all four structured target
outputs occur exactly twice and the source outputs do too. This conditions the
root population but does not couple roots or force an across-root allocation
balance. The generator also creates descriptor-order and candidate-order
surface twins. The target complement and assignments are sealed before source
formation, but target identifiers and outcomes are never rendered to the
actor, compiler, trainer, or memory updater before the source adapter is
frozen. Root-level inference is explicitly conditional on this registered
independent rejection-sampling law.

The five-rank source design makes the ten rule bits uniquely identifiable;
the three additional source cases are prospective redundancy, not extra free
parameters. CPU exhaustive checks enumerate all `2^10 = 1,024` affine rules
and require exactly one source-consistent rule.

### 2.3 Authentic source experience with the existing EVENT grammar

Each source module publicly exposes:

```text
SERIES <opaque series id>
DESCRIPTOR <four visible bits>
SLOT 00 -> <opaque node>
SLOT 01 -> <opaque node>
SLOT 10 -> <opaque node>
SLOT 11 -> <opaque node>
CALIBRATION AFFORDANCE: EXPLORE <source node> <probe port>
```

The child must commit the `EXPLORE`. Only then does the world return the
ordinary PCFL receipt:

```text
<source node> --<probe port>--> <slot node f_r(x)>
```

The child subsequently emits an ordinary `EVENT ... EVIDENCE <receipt>`.
Thus the label is not a researcher-authored training row: it is the public
consequence of a child-executed action, followed by an exact child record.
There is one calibration affordance because RS8 tests reuse, not exploratory
action selection; PCFL's earlier reachout seam remains the expansion test.

Each source action span, receipt span, EVENT span, and compiler inclusion has
an immutable hash and strict chronology. The compiler may verify and copy
these spans. It may not infer, repair, or write a descriptor, slot, `A`, `b`,
EVENT field, or target label.

### 2.4 One child-authored compact MODEL record

After all eight public source EVENTs, the child receives their current wake
context and one typed THINK allowance, then gets exactly one final opportunity
to emit:

```text
MODEL <series> AFFINE4X2 A <8 bits row-major> B <2 bits>
EVIDENCE <eight source receipt ids in public ordinal order>
```

The grammar and bit order are public. The verifier checks syntax, exact
source receipts, and consistency with the eight public outcomes only. It does
not consult a target outcome in admitting the MODEL, gives no correctness
feedback, and permits no retry. Full-rank sources make a source-consistent
MODEL unique. A wrong/malformed/absent MODEL remains in the intention-to-treat
record but is not silently repaired or admitted.

This MODEL is a child THINK product, not DREAM/compiler authorship. Its purpose
is to make the connected semantic object and its code length inspectable. The
primary reuse test still scores every allocated root, filling failed formation
with zero utility and no favorable replacement.

### 2.5 Fresh target action

After the promoted source SLEEP is sealed, each target module displays a fresh
descriptor and ordinary fresh opaque route affordances. It contains no
calibration affordance, target receipt, EVENT, or target-specific extensional
answer row before commitment. The carried MODEL intentionally entails the
answer intensionally. The output bits have an explicit public interpretation:
`y0` selects one of the two previously experienced OLD branches and `y1`
selects one of the two previously experienced NEW tails. Fresh wrapper nodes
and ports instantiate a new complete route, so no exact target ROUTE string
has occurred before.

Two nested endpoints are frozen:

1. `SLOT_READOUT`: a scorer-only four-choice diagnostic over `f_r(x)`; this is
   explicitly a closed-set likelihood readout, never called candidate-free;
2. `INTEGRATED_ROUTE`: emit the newly instantiated route whose OLD branch is
   selected by `y0` and whose NEW tail is selected by `y1`. A descriptor twin
   that changes either bit changes the corresponding downstream subpath, not
   just an independent prefix. Deleting the reusable law, OLD subpath, or NEW
   subpath changes the unique correct route.

The integrated task is what attaches RS8 to the existing vertical rather
than replacing it. It receives a full `2 x 2` reusable-law/connected-route cut
audit, and descriptor twins must redirect the implicated OLD and/or NEW route
segments. Its exact graph oracle must pass `8/8` routes per root before any
neural run. The route endpoint is ordinary candidate-free PCFL generation;
the separate SLOT_READOUT is not. The target action cannot be scored from a
partial route, post-action retry, or target-specific verifier hint.

## 3. Information custody and leakage gates

All are exact preconditions:

1. Source, target, null-ensemble, surface-twin, and wrong-life seed domains are
   disjoint and recorded before formation.
2. Every target opaque identifier and every target `(descriptor, slot)` answer
   is byte-absent from source prompts, child outputs, receipts, DREAM rows,
   fit manifests, adapter metadata, text stores, caches, and qualification
   panels. A semantic manifest check complements byte absence.
3. The actor, parent, compiler, writer, and retrieval updater never receive
   `A_r`, `b_r`, target labels, exact-solver outputs, or null labels.
4. All source feedback occurs after a committed action. MODEL admission uses
   only already public source evidence.
5. Across roots, `(A,b)` is uniform over the registered rank/balance-filtered
   set, and root/identifier bytes have zero deterministic relationship to it.
6. Two twin families are separate: candidate/order permutations preserve the
   semantic slot and must preserve the action after deterministic relabeling;
   descriptor or slot-to-port remapping twins change the semantic answer and
   must redirect the implicated OLD/NEW route segment.
7. The same generic family description, reasoning/output budget, candidate
   order, and task bytes are used in every carrier condition.
8. DEV roots, failed formation attempts, protocol-selected roots, and any
   target-revealed descendants are permanently excluded from confirmation and
   all future childhood/writer selection.

The exact affine solver is generator/audit machinery only. It may score a
sealed output, but no solver-derived text or feature reaches the child.

## 6. Endpoints

### 6.1 Formation and semantic code

For each root report:

- all `8/8` calibration actions preceded their outcomes;
- all `8/8` source EVENTs are exact, child-authored, and provenance valid;
- whether the one-shot MODEL is exact and source-consistent; and
- exact canonical code lengths.

The normalized semantic object treats descriptors, public slot dictionary,
series ID, and eight evidence hashes as common side information. A naive
fixed-field display is `1 + 8*2 = 17` bits for expanded labels and `1 + 10 =
11` bits for the affine rule, but **11/17 is not the compression result**:
the within-root balance constraint makes the expanded labels cheaper than 16
unconstrained bits.

Both codecs therefore also pay their optimal prospective enumerative length.
For the fixed source split:

```text
K_exp = 8! / (2!^4) = 2,520 balanced source-label assignments
K_aff[r] = number of registered rank-2 (A,b) laws satisfying the frozen
           source/target balance law for that root's descriptor split

L_exp_ideal = 1 + log2(K_exp)
L_aff_ideal = 1 + log2(K_aff[r])
L_exp_int   = 1 + ceil(log2(K_exp))
L_aff_int   = 1 + ceil(log2(K_aff[r]))
```

An exact decoder must reconstruct all eight source labels and their evidence
association. Exhaustive design-time enumeration gives 12,840 augmented-rank-5
source splits. Their `K_aff` values are exactly 48 (10,080 splits), 168 (1,920
splits), or 312 (840 splits). The worst prospective ratios are therefore
`.7550` ideal and `10/13 = .7692` integer; every eligible split clears `.80`.
The generator samples uniformly from all 12,840 eligible splits rather than
selecting a favorable subclass. A frozen CPU enumerator must reproduce these
counts before root allocation. This is a known generator property, not an
empirical model result. Report both enumerative ratios, the fixed-field 11/17
display, actual canonical-text bytes, ordinary compressed-file bytes,
provenance bytes, and approximately 80.8 MB live LoRA bytes separately. The
short semantic law does not make the textual MODEL record or LoRA physically
smaller.

### 6.2 Conditional predictive code

For each of eight target descriptors, score all four candidate slot
continuations and normalize within that finite set. Let

```text
C[r,c,z] = sum over targets of -log2 p_c(correct slot | target prompt)
```

where `z` is `STRUCTURED` or one of all 2,520 balanced `NULL_ENSEMBLE` target
assignments. The identical probabilities are reused for every assignment.
Chance is 16 bits/root; the null ensemble adds zero generations.

Primary predictive reuse requires, with failed roots filled as ratio one:

- root mean `C[AUTH,STRUCTURED] / C[PRE_RS,STRUCTURED] <= .80` and its one-sided
  95% upper confidence bound below `.80`;
- at least `12/16` initial roots individually have ratio below `.80`;
- the ensemble-mean `C[AUTH,NULL] / C[PRE_RS,NULL] >= .95` on the root mean;
- with `S_r(z)=C[r,PRE_RS,z]-C[r,AUTH,z]`, the registered structured saving
  exceeds the 95th percentile of that root's exact null-ensemble savings on
  at least `12/16` initial roots; and
- the root-paired structured saving minus null-ensemble mean saving has a
  one-sided 95% lower bound above zero.

This is a conditional prequential saving given the adapter state. Adapter
bytes are conditioning side information and remain fully charged in the
physical accounting.

### 6.3 Action utility and causal redirection

Each root has eight `SLOT_READOUT` predictive diagnostics and eight
`INTEGRATED_ROUTE` action tasks. Missing, malformed, illegal, late, partial,
or wrong routes score zero. SLOT_READOUT is reported only through the
predictive-code endpoint; it is not averaged with behavior. The root action
utility is the mean of the eight integrated routes, so a closed-set slot score
cannot hide failure of connected use.

Reusable action requires:

- `DLT_AUTH - PRE_RS >= .10` integrated-route root-mean utility with a one-sided 95% lower
  bound above zero;
- `DLT_AUTH - WRONG_LIFE >= .10` on SLOT_READOUT with a one-sided 95% lower
  bound above zero;
- pure order-permutation twins preserve the semantically corresponding route
  on at least `7/8` targets in at least `14/16` roots;
- descriptor/remapping twins redirect the implicated OLD and/or NEW route
  segment on at least `6/8` targets in at least `12/16` roots;
- integrated-route utility is positive above PRE_RS with a root-level lower
  bound above zero; and
- the inherited earliest OLD, newest NEW, LINK-cut, legality, and interface
  panels remain within their frozen `.05` adverse bounds.

The WRONG_LIFE comparison is primary only for predictive bits and SLOT_READOUT;
its integrated route uses another root's OLD+NEW bindings and is therefore an
expected mismatch, not evidence about the affine gate. PRE_RS is the correct
integrated-route counterfactual.

`DLT_AUTH - EXPANDED_ONLY_COMPILED >= .05` with lower 95% above zero is
evidence that adding the child MODEL helped beyond the compiled atoms, but the
permitted wording is only incremental benefit under this registered corpus
contrast. `DLT_AUTH - RAW_CHRONOLOGY_LORA >= .05` with lower
95% above zero is required to say DREAM compilation improved reusable use. If
raw matches, the result is ordinary experience SFT/LoRA reuse, not a DREAM
advantage.

The stronger semantic-code sufficiency result requires COMPACT_ONLY to clear
the same PRE_RS predictive/action gates, to be noninferior to EXPANDED_ONLY
within `.05` utility and `.10` predictive-code ratio, and to be noninferior to
AUTH within `.05` utility. If it passes, the shorter code was sufficient for
the measured transport/use despite the expanded EVENT labels not being
separate loss targets. It still does not show that the ordinary AUTH adapter
discarded its raw examples or that either LoRA is physically small.

## 7. Sample and power

The independent unit is one separately generated, independently fitted root
conditional on the one fixed child initialization. Source modules, target
descriptors, candidate continuations, task twins, decode seeds, and technical
wrappers are nested observations.

Allocate `32` confirmation roots before any formation output in cohorts
`16 + 8 + 8`; start with 16 and replace none. Block training seed, world/law
seed, hardware class, run order, and the alternating fixed WRONG_LIFE donor
assignment. Common-random decode seeds apply within a root and condition. At
least `14/16` initial roots must complete exact source formation and a safe
promoted write; invalid roots count as zero/failure. Root-level inference is
conditional on the two fixed donors, and the report includes donor-stratified
sensitivity rather than treating repeated donor use as new independent lives.

After all initial 16 primary AUTH/PRE_RS/wrong/text results are sealed, a blinded
script receives only randomized-sign root-paired differences and computes
their second moments. It reveals no mean, sign, arm score, transcript, gate
rate, or per-arm variance. Choose once among `N={16,24,32}` so one-sided
alpha `.05` power is at least `.80` for:

- the `.10` AUTH--PRE_RS reusable-utility SESOI; and
- if text superiority remains a prespecified paper target, the `.05`
  AUTH--ACTIVE_TEXT_NATIVE-v2 SESOI.

The planning approximation is

```text
N ~= 6.18 * (paired SD / SESOI)^2.
```

Thus N=16/24/32 supports SD about `.161/.197/.228` for a `.10` effect, or
`.080/.099/.114` for a `.05` effect. Exact noncentral-t calculations control
the decision. If 32 is insufficient, run 32 and report the interval; do not
manufacture power by counting targets as roots. Code-ratio inference uses the
same final roots and root bootstrap/sign-flip, not 128 target pseudo-replicates.

The MODEL formation reliability and source/write reliability receive exact
binomial intervals and remain denominators/gates, not filtered analysis sets.

## 8. Exact call, fit, and resource arithmetic

### 8.1 Per confirmation root

Source formation is exactly:

```text
8 calibration-action generations
+ 8 EVENT generations
+ 1 typed THINK generation before MODEL
+ 1 MODEL generation
= 18 generations/root.
```

Primary predictive scoring is:

```text
8 targets * 4 candidate continuations * 5 conditions
= 160 candidate-scored continuations/root
```

for AUTH, PRE_RS, WRONG_LIFE, ACTIVE_TEXT_NATIVE-v2, and FULL_SOURCE_TEXT. The
2,520 balanced null labels reuse those probabilities and add zero calls. This
predictive panel is explicitly an immediate frozen-state likelihood readout:
no THINK turn precedes candidate scoring. ACTIVE_TEXT may use at most 16 query
generations to construct one target-specific transcript shared by all four
candidates, adding `8*16 = 128` calls/root.

Behavior uses the full frozen ATN-v2 interface for every condition: at most 16
nonterminal THINK/RECALL turns plus one final ROUTE. WRONG_LIFE is not run on
the integrated route because it also lacks that root's OLD+NEW bindings.
Eight integrated targets over AUTH, PRE_RS, ACTIVE_TEXT_NATIVE-v2, and
FULL_SOURCE_TEXT therefore cost at most `8*4*17 = 544` calls/root. Two
distinct twin families (order invariance and descriptor/remapping redirection)
are run under AUTH and ACTIVE_TEXT, costing at most
`2*8*2*17 = 544` calls/root. Deterministic retrieval operations are counted
separately. Including the pre-target writer gate, the exact primary maximum is:

```text
18 formation
+ 160 candidate continuations
+ 128 ACTIVE_TEXT predictive-query turns
+ 544 primary behavioral turns
+ 544 twin behavioral turns
+ 138 RS8_WRITE_GATE requests
= 1,532 logical model calls/root.
```

That is `24,512` calls at N=16 and `49,024` at N=32. Candidate continuations
should be batched, but batching never changes the logical-call denominator.
The 2,048-token allowance is cumulative per behavioral task, not per call;
actual generated/query/returned tokens and early stops are printed.

The initial AUTH campaign adds one 400-update cumulative fit/root: 6,400
updates and 16 aggregate A40-hours at the current unprofiled 30 minutes per
200 updates ceiling for N=16; 12,800 updates and 32 A40-hours for N=32.

Only after AUTH passes, `RAW_CHRONOLOGY_LORA` adds one 400-update cumulative
fit/root: 6,400 updates / 16 A40-hours at N=16. The optional semantic-code
