# Smallest honest compression-claim route: prospective PCFL schema coding

Date: 2026-09-12 UTC

Role: fresh independent scientific review

Status: design memo only. This changes no benchmark, claim, child, writer,
carrier, source, or execution authority; authors no builder code; and launches
no job.

## Verdict

Do **not** put physical LoRA compression on the current ICLR critical path.
The measured current rank-8 adapter-plus-config subtotal is `80,793,355`
bytes, while one M-core or PCFL-R3 memory is tiny and an exact witnessed graph
is smaller still. A positive physical result against verbose event prose would
be uninteresting if a minimally packed graph beats both. Against the complete
strong graph package, current-scale physical crossover is not close.

The smallest potentially meaningful positive result is instead one separate,
zero-fit **prospective semantic-code** sidecar. A parent-deleted,
H1-qualified child sees a few ordinary PCFL cohort mappings and commits one
schema from a frozen small language before later cohort outcomes exist. A
public-syntax residual encoder then makes the final code lossless. Measure its
complete two-part bytes against a near-minimal packed witnessed graph, the
same graph under an ordinary codec, and a hindsight schema oracle. Preserve
all graph traversal power. If the prospective child code is at least 20%
shorter at two fixed loads, decodes exactly, matches the hindsight code, and
fails to compress a counterfactual independent stream, the paper may claim a
bounded semantic compression result.

This is not H1, not part of H1, and not a prerequisite for an H1 paper. It
belongs after H1 and after a PCFL-R3 connection/traversal result, normally in
the appendix. Promote it to the main paper only if it passes and compression
remains in the title or abstract. If schedule pressure exists, omit the word
`compressed`; do not delay H1.

## 1. Why neither existing small relay can carry the rate claim

M-core v8 and PCFL-R3 are finite causal microscopes. Their strength is that
old/new cuts, twins, derangements, goal swaps, and exact witnessed graphs can
identify connection, traversal, and one expansion cycle. Their weakness for
rate is equally clear: a root contains only a handful of relations. Repeating
their prose, witnesses, or RPC frames would increase bytes without increasing
semantic information.

Therefore:

- M-core/PCFL-R3 may supply the already-qualified meaning of a relation and a
  route, but their event bytes are not a positive compression denominator;
- the exact witnessed graph must remain a full-strength native planner and a
  primary coding comparator, not be restricted to one-row retrieval; and
- the compression sidecar needs genuinely increasing relation assignments
  under a prospective reusable law. It must not add LoRA fits to PCFL-R3's
  already expensive intervention bank.

## 2. The minimum semantic object

Use PCFL-Stream's existing per-cohort semantic backbone: one cohort is exactly
the three permutation assignments for its `6` preparation, `4` site, and `3`
route relations. Encode that triple by its enumerative rank

```text
y in {0, ..., 6! * 4! * 3! - 1} = {0, ..., 103679}.
```

This needs `17` packed bits per cohort and deterministically expands to the
thirteen witnessed relation assignments. It is already much stronger than
JSON or a table of thirteen strings.

For each root, sample without replacement and preseal `K_max = 16384` public
cohort descriptors `x_i` from `{0, ..., 103679}`, in a random order. The
semantic opportunity roster is fixed before any model call:

```text
Omega_r = {(i, x_i, status_i, y_i): i = 0, ..., K_max-1}.
```

`status_i` is one of `PARSED`, `ABSENT`, `MALFORMED`, `LATE`, or
`PUBLIC_SUPPORT_MISSING`. No failed or missing opportunity disappears from a
denominator. The actor-facing semantic denotation `D_rel` is exactly
`Omega_r` plus the deterministic thirteen-relation expansion of every parsed
`y_i`. Raw wording, repeated witnesses, optimizer exposure, RPC padding, and
the scientific audit archive are outside `D_rel` and are reported separately.
The allowed claim is compression of this relational denotation, never of the
whole life or autobiography.

### Structured/independent counterfactual pair

Before root generation, freeze a supplied schema language with exactly two
modes:

```text
NO_SCHEMA
AFFINE_MOD_103680(a, b): y = (a*x + b) mod 103680,
                         with gcd(a, 103680) = 1.
```

Each root contains a list of eight candidate `(a,b)` pairs; the correct pair
is uniformly placed. The roster is constructed so every two candidate maps
agree on at most `.01` of that root's complete descriptor set. The complete
candidate list and its decoder are charged. The first eight public cohort
outcomes are selected so that the correct candidate is uniquely identified.
The child sees those eight ordinary public descriptor/mapping observations
and gets one schema-commit call. It returns either `NO_SCHEMA` or one candidate
index. There is no retry, repair, or post-outcome replacement.

The two paired continuations are byte-identical through that commitment:

- `STRUCTURED`: every later `y_i` follows the committed root's hidden affine
  law; and
- `INDEPENDENT`: the same `x_i`, public surfaces, statuses, lengths, marginals,
  and first eight outcomes, followed by a presealed uniform permutation of
  the structured continuation's remaining `y_i` multiset.

The same committed child bytes are mounted on both continuations. Thus a short
code in `STRUCTURED` and a long residual in `INDEPENDENT` cannot be explained
by prompt choice, schema eloquence, or an outcome-dependent second call.
After the commitment, a frozen nonadaptive survey schedule emits every later
mapping as an ordinary public action/outcome event in both continuations.
Only those actually emitted public outcomes enter `D_rel`; hidden generator
truth never fills a missing slot. This sidecar claims coding under fixed
exposure, not active experiment selection.

This deliberately supplied two-mode language supports only a narrow claim:
the child prospectively selected an instance within a supplied compressible
family. It does not support schema-family discovery or universal abstraction.

## 3. Exact carriers and denominators

Freeze one canonical prefix-free package law before DEV. Generic serialization
used byte-identically by all carriers is excluded; task-shared PCFL permutation
unranking, carrier-specific decoders, mode inventories, indices, and every
root-specific byte are included. Primary lengths are deployable two-part
package bytes, not token counts or abstract bits:

```text
L_2p(c) = B_task_shared
          + B_carrier_static(c)
          + B_life(c).
```

`B_life` includes descriptor keys, statuses, payload, schema selection,
residual bitmap and values, catalog/order, index, checksums, and any prompt or
lookup state needed after cold start. Report conditional payload bits too, but
they cannot replace `L_2p`.

The mandatory carriers are:

1. `PACKED_WITNESSED_GRAPH`: the `x_i` keys and exact `17`-bit `y_i` values,
   packed statuses, and a native exact lookup/traversal engine. This is the
   primary denominator.
2. `DELTA_VARINT_GRAPH`: the same denotation under a frozen ordinary
   delta/varint table encoding, with decoder/index bytes charged.
3. `CODEC(PACKED_WITNESSED_GRAPH)` and `CODEC(DELTA_VARINT_GRAPH)`: one frozen
   ordinary lossless codec, fixed level, no learned dictionary, charged cold
   decoder and scratch. The shorter of the two forms the ordinary-codec
   opponent.
4. `CHILD_SCHEMA_RESIDUAL`: the sealed child choice plus one status/exception
   bitmap and exact replacement `y_i` values for every disagreement. It must
   decode all of `D_rel` exactly.
5. `HINDSIGHT_SCHEMA_ORACLE`: the shortest exact `NO_SCHEMA` or affine-plus-
   residual package selected after seeing the full root. It is a coding
   ceiling, not an actor and not a permissible source of child bytes.
6. `RAW_EPISODIC` and `ACTIVE_STRUCTURED_TEXT`: complete public events and the
   ordinary normalized connected store, respectively, for descriptive
   storage/work reporting. Neither verbose carrier is allowed to substitute
   for the packed graph denominator.

The graph keeps native adjacency and route planning. The schema carrier gets
its native arithmetic decoder. Compare causal information and exact denotation,
then report their different work; do not force either through an artificial
one-row reader.

Primary rates at load `K` are:

```text
R_plain(r,K) = L_2p(CHILD_SCHEMA_RESIDUAL[r,K])
               / min(L_2p(PACKED_WITNESSED_GRAPH[r,K]),
                     L_2p(DELTA_VARINT_GRAPH[r,K]))

R_codec(r,K) = L_2p(CODEC(CHILD_SCHEMA_RESIDUAL[r,K]))
               / min(L_2p(CODEC(PACKED_WITNESSED_GRAPH[r,K])),
                     L_2p(CODEC(DELTA_VARINT_GRAPH[r,K])))

R_oracle(r,K) = L_2p(CHILD_SCHEMA_RESIDUAL[r,K])
                / L_2p(HINDSIGHT_SCHEMA_ORACLE[r,K]).
```

The minimum operation is legitimate only because every alternative and its
one-byte mode selector are fixed before roots. All candidate-specific decoder
bytes remain charged even when a root chooses `NO_SCHEMA`.

## 4. Loads, fidelity, and route distortion

Use the four fixed nested loads

```text
K = {256, 1024, 4096, 16384} cohorts.
```

The first two are diagnostics. `4096` and `16384` are the only claim loads.
Every added cohort supplies a new descriptor/mapping assignment; repeated
wording or evidence never counts as load.

Two independent decoders must reproduce the same canonical `D_rel` bytes from
every carrier. Any mismatch, ambiguity, collision, missing package, or cold-
start failure makes that root fail. For each successfully decoded carrier,
exhaustively check:

- all thirteen one-relation answers in every cohort;
- the frozen two-, four-, and eight-edge route compositions for every cohort;
- `NOT_FOUND` on every presealed absent/malformed slot; and
- identical route destination and legality under the packed graph and schema
  carrier.

This is zero semantic distortion on a finite object, so a noisy LLM actor is
not needed to manufacture a utility measure. The upstream PCFL-R3 result is
what establishes that these relation/route semantics matter behaviorally. A
later native actor readout may be reported separately but is not part of this
minimum compression claim.

Also score the schema alone, before residual correction, on all post-commit
cohorts. This prospective prediction score prevents an exact residual encoder
from disguising a useless schema.

## 5. Controls and exact release rule

Use `8` DEV pair-roots, then `16` untouched CONF pair-roots conditional on one
fixed H1-qualified child. Roots, not cohorts, calls, loads, twins, or route
queries, are independent units. DEV may freeze only rendering and the package
implementation; it may not change the language, loads, thresholds, codec,
carrier roster, or confirmation roots. Continue to CONF only if at least
`6/8` DEV roots emit a valid unique schema choice and meet every structured
root gate below.

A CONF root is a success only if all of these hold:

1. every carrier round-trips exactly and every exhaustive route answer agrees;
2. schema-only post-commit mapping accuracy is at least `.99` in `STRUCTURED`;
3. `R_plain < .80` and `R_codec < .80` at both `K=4096` and `K=16384`;
4. the incremental child-code bytes from `4096` to `16384` are less than `.80`
   of the matched packed-graph increment, separately plain and codec;
5. `R_oracle <= 1.05` at `K=16384`;
6. the same schema on `INDEPENDENT` has schema-only accuracy at most `.01` and
   both `R_plain >= .95` and `R_codec >= .95` at `K=16384`;
7. a cyclic wrong-root schema and a fixed-point-free candidate-index shuffle
   each have schema-only accuracy at most `.01` and no rate below `.80`; and
8. all missing/model/parse/runtime failures remain present through the
   deterministic `NO_SCHEMA` full-table fallback. There are no replacement
   roots.

Release requires at least `12/16` successful CONF roots. Under the explicit
iid-root model this rejects `H0: p <= .5` by the exact one-sided binomial tail
`2517/65536 = .0384063720703125`; also report the one-sided 95% Clopper--Pearson
lower bound. In addition, the one-sided root-bootstrap 95% upper bounds for
mean `R_plain` and mean `R_codec`, with failed roots set to `1`, must each be
below `.80` at both claim loads. Freeze the bootstrap seed and resampling law
before confirmation.

The independent twin, wrong-root, and shuffle requirements are part of the
intersection. A favorable mean cannot compensate for leakage, false schema
use, round-trip failure, or a graph/codec loss.

## 6. Budget and stop gates

### CPU zero-model gate

Before a child call, exhaustively validate tiny worlds, both decoders, all
carrier packages, the structured/independent twin cut, and the four-load byte
recurrences. The supplied hindsight oracle must itself achieve both `.80`
rate thresholds at the two claim loads; otherwise the benchmark/package is
not capable of supporting the registered claim and no model call is made.

Hard planning ceiling: `8 CPU-core-hours`, `8 GiB` peak RAM, `2 GiB` temporary
disk, zero tokenizer/model calls, and zero GPU time. This stage may earn only
a supplied-schema compressibility receipt.

### Child-authorship assay

There is exactly one schema call per pair-root: `8` DEV plus `16` CONF, `24`
total. Per call ceilings are `2048` input tokens and `128` output tokens, with
no retry. Therefore the complete maximum is:

```text
49,152 input tokens
 3,072 output tokens
52,224 total model tokens
```

There are zero optimizer steps, zero LoRA fits, and zero actor-evaluation
calls. The hard accelerator ceiling is `1.0 aggregate A40-hour`, including
model load, failed calls, and cleanup; expected useful inference should be far
below that. CPU reduction remains under another `8 CPU-core-hours`, `8 GiB`
RAM, and `2 GiB` temporary disk. If the exact prelaunch token manifest or a
native timing sentinel exceeds these ceilings, stop and rebind rather than
drop a control.

This budget is intentionally too small to compete with H1. It must never take
a GPU needed by the writer qualification, plasticity measurement, or H1
bridge.

## 7. Physical crossover receipt and why it stays negative

Always print, but do not test as a positive cell:

```text
B_LoRA_actor >= 80,793,355 bytes
R_LoRA_vs_graph = B_LoRA_actor / L_2p(PACKED_WITNESSED_GRAPH)
R_LoRA_vs_schema = B_LoRA_actor / L_2p(CHILD_SCHEMA_RESIDUAL).
```

Even the weak threshold `R_LoRA_vs_graph < .50` requires a graph denominator
strictly above `161,586,710` bytes before any additional LoRA catalog,
verbalizer, prompt, or resume state is charged. At 34 payload bits per cohort
for descriptor plus mapping, that is roughly `38 million` cohorts before
headers and indices, or about half a billion PCFL relations. This planning
conversion is not evidence; the exact serializer must produce any future
crossover receipt.

More importantly, the schema carrier in this assay is far smaller than both.
Making verbose text cross 80.8 MB while a packed graph or schema remains tiny
would not establish a meaningful physical advantage. Reopen physical LoRA
compression only for a complete mounted actor package, and separately a
cold-resumable updater package, at three useful post-crossover loads against
the strongest packed graph/schema carrier. That is a later architecture/scale
project, not this paper's September experiment.

## 8. Exact claim ceiling

If the full confirmation passes, the strongest allowed sentence is:

> Conditional on one fixed parent-deleted child and a supplied affine PCFL
> schema language, the child prospectively selected a schema whose exact
> schema-plus-residual representation of later witnessed cohort relations was
> at least 20% smaller than packed, delta/varint, and ordinary-codec witnessed-
> graph packages at zero relational and route-query distortion; matched
> independent, wrong-root, and schema-shuffle streams did not compress.

Say `prospective semantic coding` or `semantic compression within the supplied
schema language`. Do not say that:

- the LoRA compressed experience;
- H1 caused the code choice;
- the child discovered the schema family;
- the whole life, audit archive, or organism was compressed;
- the representation is universal, asymptotically sublinear, or more compute-
  efficient; or
- text/graph memory was beaten behaviorally.

If only the hindsight oracle passes, report that the registered distribution
is compressible but the child did not select the code. If the child beats
expanded or normalized prose but not the packed graph and codec gates, report
only ordinary normalization. If the physical ratios are unfavorable, print
them next to the semantic result.

## 9. ICLR disposition

The ICLR order should remain:

```text
level-zero plasticity
-> conditional/opposite-action writer qualification
-> child-authored parent-deleted H1 bridge
-> H2 / strong active-text result if pursued
-> PCFL-R3 connected relay if retained
-> this semantic-code sidecar only if “compressed” remains in the paper.
```

No component of this memo should block or modify the first three steps. A
focused H1 paper needs no compression experiment. A connected-relay paper may
say `compiled`, `connected`, `traversable`, and `expanded` if its own gates
pass. Only this separate rate result licenses `compressed`, and only with the
claim ceiling above.
