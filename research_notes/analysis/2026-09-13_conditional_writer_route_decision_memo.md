# Conditional writer-route decision after Q0

**Date:** 2026-09-13 UTC  
**Role:** independent, result-blind route synthesis and adversarial comparison  
**Scope:** analysis only. I did not inspect the live or terminal Q0 attempt-2
root, its logs, its markers, or coordination entries that could reveal its
outcome. I changed no builder source, test, model, tokenizer, adapter, job, GPU
state, threshold, benchmark, or claim.

## Decision in one table

| valid Q0 terminal | exact next scientific experiment | routes closed immediately |
|---|---|---|
| full exact + held + locality pass | run the one-root parent-free endogenous **action relay** exactly as specified in `2026-09-13_shortest_parent_free_one_sleep_endogenous_action_relay.md`; run the two unchanged Q0 repetitions in parallel, not first | no direct jump to M or L; no action-relay confirmation program |
| early XOR canary failure | finish only Q0's already registered DERANGED one-step and unary diagnostic, then run one excluded **addressed endogenous event-row gate** (`E0`) from `2026-09-13_post_q0_failure_endogenous_event_row_gate.md` | Q0 confirmations, the Q0-surface action relay, and every direct-action rank/LR/heat/objective sweep |
| canaries pass, exact acquisition fails | finish only the already registered V/unary diagnostic allowed by the Q0 lifecycle, then run the same one-root `E0` | same as early failure; neither checkpoint selection nor more dose is allowed |
| exact passes, held extraction fails | run one bounded **diverse-view, fixed-dose Q0 DEV repair** defined below; if it fails held extraction, stop the action surface and run `E0` | action relay before the held repair passes; paraphrase ladders; extra dose |
| exact and held pass, locality/interface fails | run `E0` with the adapter confined to the goal-blind memory process and a clean actor; preserve the Q0 spill as a terminal result | action relay, direct-action deployment, KL/mask/rank sweeps meant to hide spill |

`E0` and rung `S` in the post-relay benchmark ladder are the same scientific
primitive and should become one implementation, not two successive semantic
writer gates. Use the more complete `E0` controls (balanced authentic/outcome-
swap rows, unused-address `MISS`, exact-text closure, unmounted shadow, separate
clean actor), then carry that EVENT representation into the route-world `M`
rung. This removes a duplicate two-fit gate.

## Why this ordering follows the evidence

The repository has established four useful constraints:

1. The legacy CompilerGym writer can install a narrow action routine. Five
   selected high-routine lives retain roughly `+.043` report and `+.027`
   disjoint value over pooled OFF, but the modal objects are life-specific
   variants of a supplied four-pass prefix. That is a strong positive control
   for action-prior transport, not conditional memory, discovery, connection,
   or a lifetime flywheel.
2. The matched formation scout did not establish parenting or formation. AUTH
   produced six multi-action proposals, all safely projected, but completed
   only `6/8` quizzes versus OFF's `8/8`; five record errors all mislabeled a
   missing prediction as `matched`. Therefore a compiler may admit only exact
   child-authored supported bytes. It must never fill the child's lesson.
3. Earlier recognition and supplied-text ceilings show that the base can use
   structured information when it is made visible. They do not qualify a
   candidate-free LoRA reader. A candidate bank, candidate logprob scoring, or
   one supplied answer row beside each query would recreate textual retrieval
   under a parametric label.
4. OFF generation is not exact merely because per-request seeds match. Fresh
   first replicas matched `60/60` across nodes, but later replicas matched only
   `24/60`; backend history and a live clock remain nuisance variables. Any
   SHADOW/OFF byte-identity gate must use fresh, history-matched processes and
   deterministic model-visible state. Otherwise a mismatch is assay-invalid,
   not evidence of leakage.

These facts make Q0 useful but narrow. It asks whether supplied complementary
native actions can coexist without becoming the same global habit. A full pass
licenses the cheapest own-experience test on that exact carrier. A failure does
not license endless optimization, but it also does not falsify semantic memory:
moving the adapter behind a goal-blind EVENT interface changes the module and
the claim rather than weakening the failed direct-policy gate.

## Adversarial comparison of the three routes

### A. Parent-free endogenous action relay

**Best use:** only after a complete Q0 pass.

Its advantage is continuity. The child acts, observes public success/failure,
writes the two future-action branches itself, and the already qualified Q0
carrier writes those exact branches. AUTH versus mode-SWAP gives causal
redirection; OFF versus unmounted SHADOW cuts temporary memory. It costs two
fits, 256 updates, at most 984 short generations, and at most 1.25 A40-hours.

Its fatal ceiling is also clear: it can pass as a flat policy table. The public
two-action law makes converting failure into the alternative future action
trivial, the source forces both modes, and the later read directly emits the
action. A pass establishes one learned action relay under Rohin's vocabulary;
it does not show that an event or relationship is represented, queried,
connected, traversed, or expanded.

Therefore run it once as a kill test, then stop. Do not replicate it into a
paper program. The two Q0 repetitions already test carrier robustness; the
next paper-relevant uncertainty is semantic memory.

### B. Addressed endogenous event-row gate (`E0`)

**Best use:** the fallback after any direct-action acquisition/locality
failure, and the semantic successor after an action-relay pass.

This route is much closer to the paper's required module boundary:

```text
child action -> public outcome -> child EVENT row -> SLEEP ->
goal-blind candidate-free memory return -> separate clean actor -> later action
```

It prevents the most important policy shortcut by never mounting the memory
adapter in the actor. Outcome rebinding must redirect both the raw remembered
field and the clean actor's later action. Unused and wrong-root addresses must
return `MISS`. Exact text must solve before either fit, so a failure cannot be
blamed on an unsolvable actor/task interface.

It nevertheless remains an addressed lookup-table gate. The child is required
to precommit both legal actions, the episode handles are externally allocated,
and researcher-supplied `MISS` anchors are half of the fit corpus. That is
acceptable only because the claim is atomic episodic carriage and use. It is
not autonomous exploration, spontaneous abstraction, connection, or
compression.

The strongest version is the existing 16-row balanced `E0`, not a second,
weaker eight-row `S` implementation. Render its payload in a route-compatible
local EVENT form so that the same carrier can later support child-authored LINK
rows. Do not change its two-fit, 256-update, 1.5-A40-hour ceiling or add a
recipe ladder.

### C. Post-relay `S/Z/M/L` ladder

**Best use:** the experiment order and paper claim firewall after the atomic
semantic gate, not a single build to start now.

The ladder contains the first design that actually reaches the full objective:

- `M` makes a child-authored LINK behaviorally necessary under two goals,
  directs an information-seeking experiment, performs a second SLEEP, and
  requires delayed OLD+NEW use without forgetting the old route;
- `L` introduces novelty-growing information cohorts and compares periodic
  DLT against no-write, final-batch, and a strong evolving linked-text system;
  and
- the zero-fit rate--distortion sidecar is the only currently honest route to
  a semantic compression statement.

Three corrections are required before treating it as executable:

1. Merge its `S` with `E0`; do not pay for or interpret two atomic semantic
   writer gates.
2. Split `Z` into two closures. The same-row exact-text ceiling in `E0` must
   pass before the `E0` fits. The four-root route-world shortcut, link-value,
   and strong-text closure must pass before the first `M` fit. Neither closure
   may be postponed until after observing a favorable LoRA result.
3. `L` needs independently raised paired child lineages as its scientific
   units if the paper claims developmental reliability. Cloning one fixed
   child into many environment roots supports only one-child robustness.
   Checkpoints, tasks, and goals within a life remain repeated measures.

The advertised 52 pre-lifetime fits are a maximum, not a queue to launch.
After `E0/S`, spend zero fits on `Z`, then ten fits on exactly two M development
roots. Only two complete, unchanged M roots release the 40-fit eight-root
confirmation. Only confirmed M releases L. This is the correct failure-
inclusive use of GPU time.

## Exact branch specifications

### 1. Q0 fully passes

1. Freeze the exact Q0 pairwise writer bytes, model/tokenizer hashes,
   optimizer schedule, views, thresholds, and receipts.
2. Launch the two prospectively allocated Q0 repetitions for narrow writer
   reliability.
3. Without waiting for those repetitions, run one fresh, permanently excluded
   parent-free action relay exactly as route A specifies: 24 child source/
   record calls, 8/8 supported-record formation or no fit, AUTH and mode-SWAP
   only, 128 updates each, OFF and no-extra-fit SHADOW, sterile held readout.
4. If the action relay passes, archive it as the bounded own-experience action
   edge and immediately run the unified `E0/S` semantic gate. Do not run more
   action-relay roots.
5. If the action relay has a formation shortage, repair only the child record
   interface on a new excluded root; it is not writer evidence. If formation
   succeeds but acquisition, held extraction, or locality fails, preserve the
   exact subtype and move to `E0`; do not tune the action carrier.

The confirmation roots do not gate completion of the already excluded relay.
If they later produce mixed Q0 subtypes, the relay remains useful diagnostic
evidence but cannot qualify a robust action writer or seed a lineage; proceed
only through the separately qualified `E0` branch.

This branch gains the first learned edge for approximately 1.25 A40-hours
while the narrow Q0 repetitions run concurrently. It does not let the
supplied-policy table enter M or L.

### 2. Q0 stops at an early XOR canary

1. Complete only the already frozen diagnostic lifecycle: the registered
   opposite-map first step and, if released, the one unary opaque-tool cell.
   Neither can rescue Q0.
2. End the direct `(tool, mode) -> ACT` family. No new seed, quartet, rank,
   dropout, learning rate, loss, paraphrase, or dose is allowed.
3. Run `E0` on one fresh excluded root. Require its zero-fit exact-text/clean-
   actor closure before model fitting. Then attempt only EVENT-AUTH and
   OUTCOME-SWAP from clean state, with ordinary response-masked full-row loss,
   candidate-free reads, unused/wrong-root `MISS`, and an unmounted shadow.

The early Q0 miss rejects one local tangent on a direct conditional policy.
`E0` is justified because it factors the task into unary addressed factual
memory and goal-conditioned use by a separate actor. It must be described as
a new representation, never as Q0 recovery.

### 3. Q0 canaries pass but exact acquisition fails

1. Preserve `LOCAL_XOR_DIRECTIONS_NOT_PRESERVED` plus its registered
   `MAP_ASYMMETRY` or `BOTH_XOR_EXACT_NULL` qualifier.
2. Run only the predeclared V/unary suffix allowed by the initialization
   audit and three-fit cap. Do not select an intermediate checkpoint.
3. Run the same one-root `E0` above. If unary Q0 passed, `E0` tests the natural
   hypothesis that the joint XOR policy was the problem. If unary also failed,
   `E0` still earns one bounded attempt because its full semantic row, ordinary
   masked loss, and isolated memory process are a different carrier; no second
   E0 recipe follows a miss.

### 4. Q0 exact acquisition passes but held extraction fails

This is the only branch that earns one direct-action repair because the map is
already stored and the registered adjudication explicitly localizes the gap to
views.

On the same permanently excluded DEV root, preseal a single `Q0-H_VIEW`
compiler before loading a model:

- keep the Q0 keys, modes, targets, natural common prefix, rank 8, alpha 16,
  dropout `.05`, AdamW `3e-5`, initialization, pairwise objective, 128 updates,
  512 row presentations, first-quartet canary, and every exact/held/locality
  threshold unchanged;
- replace only `8 views x 4 repeats` with `32 prospectively generated,
  semantics-preserving views x 1 presentation` per key-mode; include each of
  the original eight training forms once and 24 renderer-generated siblings;
- keep every original held object and held renderer byte out of training, and
  prove input-prefix, object, and full-prompt hash disjointness; and
- train exactly AUTH and DERANGED, then evaluate the unchanged original exact,
  held, copy, and locality panels.

This is two fits and one compiler hypothesis, not a paraphrase sweep. A full
pass freezes the diverse-view compiler and releases route A on a fresh relay
root. A second held failure closes the action surface and sends the project to
`E0`. Exact regression or locality failure also closes it. Because the repair
is post-result DEV tuning, any writer reliability statement requires fresh
roots after the compiler freezes.

### 5. Q0 exact and held pass but locality/interface fails

Do not mount that adapter in a learning child and do not run the action relay:
it would knowingly promote an unsafe write. Preserve
`CONDITIONAL_BINDING_WITH_SPILL_OR_INTERFACE_FAILURE`.

Run `E0` next. Its adapter is visible only to a fresh, goal-blind memory
process; the clean actor receives raw EVENT/MISS text and never mounts the
adapter. Negative unused and wrong-root addresses, false-row use, native copy,
neutral-surface behavior, and shadow/OFF reset remain hard gates. This is the
smallest routing repair that also advances from policy installation to
episodic semantics. If `E0` still spills, emits false memories, or changes the
clean interface, stop M/L rather than adding KL, preservation mix, rank, or
mask sweeps.

## Shortcut firewall for `E0`, `M`, and `L`

The following remain non-negotiable:

- Q0 may select writer hyperparameters after a pass, but no Q0 key, target,
  prompt, output, adapter tensor, hidden map, or error enters the action-relay
  or `E0` root.
- Every authentic semantic target byte is emitted by the child after its
  cited action and public outcome. The compiler parses, verifies, copies, and
  may apply fixed lexical views; it never derives an action, endpoint, link,
  route, or answer.
- Only the actor sees the later goal. The memory process receives a local
  request and emits one complete raw row or `MISS`, with no candidates,
  candidate scores, hidden membership bit, action menu, target state, or
  expected trace.
- One row is local. It never contains a complete route. M must require
  multiple reads and a child-authored LINK whose removal costs at least `.40`
  in the zero-fit world and whose authentic fit beats atoms-matched and
  link-permuted states by at least `.20`.
- Synthetic swaps are controls only. They never enter a child lineage, parent,
  DREAM policy, or later authentic corpus.
- `ACTIVE_LINKED_TEXT` receives the same admitted EVENT and LINK semantics as
  DLT, a candidate-blind typed index, charged actor-authored reads, and a
  prospectively frozen bandwidth. Withholding child organization from text
  would manufacture a substrate win.
- Native on-policy and same-history carrier comparisons are reported
  separately. Different acquired histories can establish a total-system
  advantage; only the same-history direction can support LoRA-carrier
  superiority.
- Backend-history matching, deterministic clocks, fresh caches/processes, and
  complete raw outputs are required for SHADOW/OFF identity. A stochastic
  mismatch cannot be relabeled as a model leak.

## What to drop now

1. Drop further CompilerGym writer/parenting optimization from the critical
   path. Preserve it as ecological routine and failure characterization.
2. Drop Q0-surface action relay and Q0 confirmations after any valid Q0
   scientific failure.
3. Drop a second standalone semantic `S`; merge it into `E0`.
4. Drop all action-relay confirmations after one excluded pass. The next
   uncertainty is connected semantic use.
5. Drop rank, LR, heat, dropout, mask, KL, checkpoint, and paraphrase ladders
   after a registered writer terminal. The one held-only diverse-view repair
   above is the sole exception.
6. Drop candidate-bearing recognition, answer-row prompts, compiler-derived
   policy targets, and hidden graph access from every claim-bearing route.
7. Drop physical LoRA compression from the near-term claim. A rank-8 adapter
   is about `80.79 MB`; use the zero-fit semantic rate--distortion sidecar only
   after connected utility passes.
8. Drop scaled parenting and branched THINK from the headline critical path
   until the endogenous semantic carrier passes. They can change formation and
   policy quality, but they cannot repair an unqualified writer.
9. Do not launch all 52 pre-lifetime fits. Release 2 semantic fits, then 0-fit
   closure, then 10 M-development fits, then confirmations only on complete
   DEV success.

## Paper-facing stopping point

Q0 and the action relay belong in the writer/provenance gate or appendix. The
minimum main-paper evidence remains:

1. unified `E0/S`: own action--outcome experience becomes candidate-free local
   EVENT memory;
2. `M`: child-authored connection, goal-dependent traversal, an informative
   action, a second write, and delayed OLD+NEW use under binding cuts;
3. `L`: positive novelty-growing lifetime improvement with retention, root-
   level uncertainty, and independently raised paired lineages; and
4. a fair `ACTIVE_LINKED_TEXT` comparison allowed to win, plus the semantic
   compression sidecar only if its complete code length and utility gates pass.

A negative Q0 does not kill that paper path; it kills direct parametric policy
installation under the frozen Q0 recipe. A negative `E0` is more consequential:
it says the current project has not yet shown even atomic own-experience-to-
candidate-free parametric memory, so connected, lifetime, parenting, and
superiority experiments should stop rather than bury that missing edge.
