# E0 value red-team: keep the atomic carrier decision, remove the toy-gate tax

**Date:** 2026-09-13 UTC  
**Role:** fresh adversarial watcher-side review  
**Scope:** documents only. I did not inspect any new E0 outcome, edit builder
source, inspect or mutate a runtime root, run a model/tokenizer, train an
adapter, or touch a GPU.

## Decision

**Simplify E0 before running it. Do not run it as written, do not skip it, and
do not merge its fitted states into the connected two-SLEEP experiment.**

Keep one excluded-root, two-fit **own-experience addressed event carrier
gate**, but make it answer only the decision that the paper actually needs
before spending on connection:

```text
child action bytes + public outcome receipt
  -> fixed provenance-preserving EVENT rendering
  -> response-masked LoRA write
  -> candidate-free EVENT/MISS generation after reset
  -> clean actor uses the generated rows for a later goal
```

The two fits remain authentic outcomes and a within-scene outcome swap. Run
both to their full frozen dose unless there is an integrity failure. The exact
event, held-renderer, semantic-redirection, absence, and clean-actor results
are the scientific gates. Record first-update gradient geometry as a
diagnostic, but **do not let a conjunction requiring every item margin to move
correctly after one minibatch terminate E0**.

On a pass, freeze this carrier and immediately run the zero-fit four-root
route-world/strong-text closure, followed by the two-root connected two-SLEEP
development experiment. Do not replicate E0 and do not introduce another
standalone semantic-row rung. On a full-dose storage, extraction, redirection,
or false-memory failure, stop LoRA M/L spending; do not tune rank, learning
rate, dose, views, or thresholds on E0.

This is the best information/GPU-hour route. It preserves cause localization
after Q0's clean rejection without spending another day proving that a tiny
addressed lookup table is the paper.

## Why not the four alternatives?

### Run E0 exactly as written: reject

The written protocol contains one valuable two-fit causal test surrounded by
three kinds of tax:

1. **An unjustified efficacy stop at update one.** Ordinary shared-parameter
   causal-LM training does not require every example's action and outcome
   margin to improve after the first balanced minibatch. Q0 has now shown that
   this conjunction can cleanly terminate a recipe while answering only a
   local tangent-geometry question. Repeating it on a new representation can
   consume the entire E0 decision before testing whether the completed write
   stores or exposes anything.
2. **Formation mixed into transport.** Requiring the child to serialize
   `16/16` exact rows makes punctuation and schema following a prerequisite for
   learning, even though SLEEP is expressly allowed to render, paraphrase, and
   replay immutable experience. CompilerGym already showed that articulation
   is weak. E0 should test the writer, not rediscover that fact.
3. **Redundant isolation panels.** Wrong-root addresses duplicate unseen
   absence at this one-root stage; native action copy and neutral-policy panels
   are irrelevant when the adapter is mounted only in a goal-blind memory
   process; actor use of false rows is undefined and unnecessary. These are
   valid concerns later in M, but weak uses of the immediate deadline.

The result would be technically impressive custody for a gate whose most
likely terminal says little about the paper.

### Skip E0 and jump to M: reject

Q0 rejected even the registered unary direct-action first step, while legacy
CompilerGym evidence supports only a broad repeated routine. No current result
shows that this writer can generate a candidate-free local semantic memory
from own experience. A five-fit-per-root M null would conflate atomic storage,
held extraction, link writing, actor query choice, traversal, second-write
coexistence, and task design.

The simplified E0 costs two fits versus ten fits for the first two M
development roots. Even if E0 has only a one-in-five chance of catching an
atomic failure that would invalidate M, its expected avoided fit count is
already comparable to its cost. Given the existing writer failures, that
failure probability is far above one in five.

### Merge E0 into M: reject for fitted states, accept for implementation

Use the same `EVENT` grammar, reader, reducer helpers, and carrier bytes in M;
do not build two semantic-memory systems. But do not make a LINK-containing M
fit the first atomic writer test. A failure would not reveal whether EVENT
rows were absent, overwritten by LINK material, or present but unused.

Thus implementation should be shared and E0 should flow directly into M, but
the two E0 fits remain a separate excluded development decision. They do not
count as paper replication units.

### Keep simplifying until E0 is only a reconstruction-loss check: reject

Training loss and exact training-form completion are already known to be weak
evidence. The minimum useful gate still needs a disjoint request renderer,
within-scene outcome rebinding, unseen `MISS`, sterile reload, and clean-actor
use. Those jointly distinguish carried event semantics from syntax training,
base prior, and a generic output habit.

## The minimum E0-r protocol

Call the revised gate `E0-r` in development records so that its result is not
silently attributed to the earlier specification.

### Source and compiler boundary

- Keep 8 opaque scenes, 16 preallocated live handles, two balanced legal
  actions, and two balanced public outcomes.
- Before outcomes, the child emits two strict action precommits per scene. The
  world executes those exact bytes in the committed order. Require 8/8 valid
  precommits or declare `E0R_SOURCE_INTERFACE_FAIL` before any fit.
- After each public receipt, a fixed renderer copies only the already public
  handle, scene, executed action, and outcome into:

  ```text
  EVENT <handle> AT <scene> DID <action> GOT <outcome>
  ```

- The renderer emits one canonical row and may not infer, repair, replace,
  summarize, or add a semantic field. Exact receipt joins and raw-byte
  provenance are mandatory. The four views below vary only the `READ` request,
  never the target row.
- A child-authored post-outcome reflection may be logged as a non-gating
  diagnostic, but it is not a training prerequisite and is not admitted to
  this carrier corpus.

This remains own-experience evidence: the actions came from the child before
the result, and the outcomes came from the public world. It does **not** prove
that the child spontaneously authored good memory rows. That formation claim
belongs in the connected DREAM experiment, where child-authored LINKs are
behaviorally necessary.

### Arms and dose

Train only:

- `E_AUTH`: the authentic rendered event rows; and
- `E_OUTCOME_SWAP`: within each scene, swap only the two public outcome
  tokens.

Keep zero-fit `E_OFF`, exact text, and a fresh-process unmounted shadow. Use
rank 8, alpha 16, LoRA dropout `.05`, AdamW `3e-5`, and ordinary
response-masked causal-LM loss. Require equal-length one-token action and
outcome alternatives under the pinned tokenizer.

Use 16 live and 16 trained-negative addresses, four fixed training request
views, and **32 presentations per address** (`4 views x 8 replays`). This is
prospectively chosen once, not swept: historical uniform atomic-fact storage
needed about 24 touches, while candidate-free generation is no easier than
recognition. With four natural rows per update, this is 256 updates and 1,024
natural-row forwards per fitted arm, 512 updates and 2,048 forwards total.

AUTH and SWAP must match in inputs, lengths, target marginals, row order,
initial trainable tensors, optimizer state, and RNG; only the outcome target
IDs differ. Always complete both fits unless an integrity condition fails.

At update one, preserve tensors, gradients, projected field margins, and
observed changes. Gate only on numerical and lifecycle integrity: exact update
replay, finite values, correct masks/counts, and no state drift. Report how
many semantic directions moved correctly, but do not use that count for
release.

### Zero-fit closure

Before fitting, lossless exact text over the same 16 rows must return 16/16
rows and a fresh clean actor must solve at least 15/16 later questions. The
same frozen actor outputs must score as the registered opposite action pattern
under the within-scene swapped map. ID, order, length, renderer, and
target-marginal shortcuts must stay at 8/16 or below.

Failure is `E0R_ASSAY_INVALID`; repair the zero-fit assay without examining a
fit. It is not writer evidence.

### Full-dose scientific gates

After fresh reloads and caches:

1. **Storage and extraction:** each fitted state returns at least `29/32`
   exact complete rows across two seen request renderers, and at least `14/16`
   across one disjoint held renderer. Validity must be at least `31/32` and
   `15/16`, respectively. Each action and outcome class needs at least `7/8`
   held correctness.
2. **Causal content:** on at least `14/16` held addresses, AUTH and SWAP are
   both correct under their own maps and their outcome fields are opposite.
   AUTH must exceed OFF held semantic correctness by at least `.20`.
3. **Absence:** train 16 allocated negative handles to `MISS`; separately test
   16 never-trained negative handles. Require exact `MISS >=15/16` in each
   group under both fitted states. Score them separately; do not pool a trained
   interface behavior with unseen false-memory control.
4. **Behavioral use:** the clean actor receives only the desired outcome, two
   public handles, and two raw memory generations. Under each adapter it must
   solve at least `14/16` own-map questions, at least `7/8` per action class;
   at least `13/16` actions must flip between AUTH and SWAP. AUTH must exceed
   the OFF actor on authentic balanced accuracy by at least `.20`.
5. **Sterility:** adapters are mounted only in goal-blind memory workers. The
   actor is a newly loaded clean base after raw returns are sealed. OFF and
   unmounted-shadow request projections and deterministic fresh-process
   outputs must match; otherwise the assay is invalid, not a memory failure.

These are intentionally integer engineering gates on one excluded root, not
confidence intervals or sixteen independent scientific samples. A pass is one
carrier release, not a paper result.

## Disposition of all twelve handoff ambiguities

1. **`29/32`:** define 32 as `16 handles x 2 seen request renderers`; retain
   the prospective `29/32` threshold. Renderer identities are frozen before
   source capture.
2. **Held query:** exactly `16 handles x 1` prospectively bound renderer whose
   complete prompt bytes and template are absent from training. It tests
   renderer transfer, not unseen-event generalization.
3. **Negative addresses:** maintain two disjoint sets: 16 trained-negative
   handles and 16 evaluation-only handles. Report and gate each at `15/16`;
   never call the trained set held.
4. **Wrong root:** delete it from E0-r. A payload-free second namespace adds no
   fact beyond unseen-address `MISS`; wrong-life/root is mandatory in M/L,
   where real independent roots exist.
5. **Four training views:** freeze four request templates that differ only in
   connective wording around the same handle. The deployment API is the
   canonical first template; the separate held template is a fifth form.
6. **Canary arithmetic:** require single-token action and outcome alternatives
   and freeze their exact target positions. Preserve FP64 field-margin
   arithmetic as diagnostic. Only exact optimizer/update replay, finiteness,
   masks, and counts are gate-bearing at update one.
7. **Loss normalization:** require all targets to have equal token length and
   use ordinary token-mean response loss. With equal lengths this is also an
   equal row mean; assert the equivalence in preparation.
8. **Actor prompts/seeds:** greedy decoding (`temperature=0`), strict one-line
   `ACT <action>` grammar, and a prospectively fixed max-token limit. Generate
   once per sealed raw-return condition; cross-map contrasts rescore those
   fixed outputs rather than regenerate them.
9. **False row used by actor:** delete the clause. Negative-address generation
   is a memory-only false-row gate. The actor panel contains only live scenes.
10. **OFF denominators:** OFF receives the same 16 held memory requests; its
    raw outputs are passed unchanged to the same 16 actor questions. A
    malformed row or `MISS` is wrong, and a malformed/no/multiple action is
    wrong. Report semantic and actor denominators separately.
11. **Copy/interface and neutral surface:** delete both panels. Complete-row
    validity and exact `MISS` are the memory interface tests. Policy locality
    is irrelevant because the memory adapter is never mounted in the actor;
    M/L later test organism-level safety.
12. **Budget:** bind a 120-minute controller deadline with this cumulative
    stage allocation: source capture 10 min; exact-text/shortcut closure 25;
    OFF read 35; AUTH fit 60; SWAP fit 85; both fitted reads 100; actor/shadow
    110; seal, teardown, and verified GPU release 120. The hard maximum is
    therefore **2.0 A40-hours**, including cleanup. Preserve actual tokens,
    forwards, updates, loads, generations, and stage wall times.

The exact natural-language request templates, action/outcome token strings,
opaque identifiers, seeds, and max-token integers remain builder preparation
work; the constraints above determine their meaning without selecting them
after an outcome.

## Information per GPU-hour

The relevant currency is a downstream decision, not the number of logged
metrics.

| route | max fitted work before next decision | expected diagnostic value |
|---|---:|---|
| E0 as written | up to 2 fits / 1.5 A40-h, but likely update-one stop | often only another local gradient-geometry result |
| **E0-r** | 2 complete fits / **2.0 A40-h** | separates full-dose storage, held extraction, causal content, false memory, and clean-actor use |
| merge into two M DEV roots | 10 fits before confirmation / roughly 7.5+ A40-h before profiling | paper-near if positive, highly confounded if atomic carriage is absent |
| skip to lifetime | at least 20 DEV fits plus long wake inference | nearly uninterpretable if the writer lacks atomic semantic carriage |

E0-r yields one of five named, action-changing outcomes for at most two GPU
hours, or about **0.4 A40-hour per distinguishable writer layer**. More
importantly, a negative saves at least the first ten M fits and all lifetime
fits. The extra half hour relative to written E0 buys adequate 32-touch dose
and a full test of the behavior we care about rather than an update-one stop.

Builder engineering time is the real scarce resource. Reusing E0-r's EVENT
grammar, memory worker, exact-text closure, and reducer directly in M is
mandatory. Do not build a general memory framework or port Q0's 16,000-file
tensor-seal granularity merely because it exists. Preserve hashes, exact work
counts, raw outputs, adapter tensors, and a replayable reduction, but treat
per-item first-step tensor archaeology as optional diagnostics after the
counter regression is covered.

## Exact release and stop

### Release

Only `DEV_E0R_OWN_EXPERIENCE_EVENT_CARRIER_PASS` releases the next stage. On
that label:

1. freeze the EVENT renderer, request renderers, reader process, writer recipe,
   dose, and actor interface;
2. do **not** run an E0 repetition;
3. run the zero-fit four-root route-world shortcut, link-value, and
   `ACTIVE_LINKED_TEXT` closure; and
4. if all four zero-fit roots pass, run exactly two connected two-SLEEP M
   development roots. Both must complete before confirmation roots open.

### Stop

- Source-interface or exact-text failure: stop before fitting. One assay-only
  repair is allowed because it contains no writer result; change no writer
  knob.
- Integrity/replay/teardown failure: preserve as nonreportable and rerun the
  unchanged bytes once after a non-material repair.
- AUTH or SWAP full-dose failure at storage, held extraction, causal
  redirection, trained/unseen absence, or clean-actor use: preserve the named
  layer and **stop M, L, parenting-as-headline, and LoRA-superiority spending**.
  Do not sweep rank, LR, dose, renderers, loss, or threshold.

The paper then becomes an honest writer/failure-characterization result unless
a separately motivated representation change is designed from evidence other
than the E0-r outcome. A miss does not mean LoRA can never hold facts; it means
the current Dream--LoRA--Think route has not qualified the atomic experiential
carrier required by the stronger paper.

## Strongest allowed claim

If E0-r passes:

> On one excluded opaque development root, a fixed compiler rendered a child's
> precommitted actions and public outcomes into local event rows. A fixed LoRA
> write made those rows generatively addressable without candidates after
> reset; changing only the outcome bindings redirected both the recalled rows
> and a separate clean actor's later choices.

This is not spontaneous memory authorship, connected knowledge, traversal,
expansion, compression, retention, generalization across roots, lifetime
improvement, parenting, or superiority over active text. It is the cheapest
qualified carrier prerequisite for experiments that can test those claims.
