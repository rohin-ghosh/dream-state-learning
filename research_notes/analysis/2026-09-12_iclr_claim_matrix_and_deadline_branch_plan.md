# ICLR claim matrix and deadline branch plan

**Date/evidence cut:** 2026-09-12 13:54 PDT, repository through
`6e11be8e` plus the terminal artifacts cited below.  
**Scope:** paper-strategy audit only. This changes no source, benchmark, model,
adapter, parent, GPU job, or scientific release.

## Verdict

Keep the full paper target. The shortest path is not another family of writer
scouts; it is:

```text
Q0 selective writer
  -> one equal-dose OLD+NEW/replay coexistence canary
  -> one causal two-SLEEP mechanism study (M-core)
  -> one five-branch parented lifetime study (L-core, including P-TEXT)
  -> semantic compression only after connected utility
```

Run the cheap no-write parenting-utility gate in parallel, because L-core
needs a useful lesson but Q0 does not. Q0 is an enabling result, not a paper
headline. M-core is where the agent's own action--outcome experience,
child-authored organization, goal-conditioned traversal, prospective
experiment, cumulative second write, and delayed old-plus-new action first
join. L-core is where parenting, continued SLEEP, absolute improvement,
retention, and comparison with evolving text first become estimable.

Heuristic readiness, not a statistical quantity: the architecture and causal
design are about 75% specified; claim-bearing evidence is about 15%; and the
submission artifact is about 30% ready. Overall readiness for the intended
full positive paper is still roughly **25--30%**. The uncertainty is almost
entirely experimental, not conceptual.

This is deadline triage, not a contraction of Rohin's goal. Connected use,
expansion, lifetime improvement, and compression remain in the ordered
program. A clause is omitted from the submitted claim only if its own evidence
does not arrive.

## Highest-information path from Q0

### 1. Qualify or localize Q0 first

Q0 has the best immediate information/GPU-hour: at most three fits and a
`0.75` A40-hour ceiling. It asks the one question every later write assumes:
can this fixed rank-8 recipe install mutually opposite native actions under a
supplied `(opaque tool, mode)` relation while preserving locality and the
interface?

- **Pass:** freeze that writer. Do not tune it on Level-1, M, or L outcomes.
- **Stored exact but not held:** run only the prebound semantic cross-view
  extraction repair.
- **Acquired but spills:** run only the prebound disjoint frozen-OFF anchor.
- **Both defects:** at most the prebound `Q0/X0/QA/XA` screen.
- **No acquisition or invalid carrier:** stop writer-family churn. This is a
  valid prospective barrier result and forces a result/claim branch.

The contaminated Level-1 fits and the lexical-view sentinel cannot qualify
Q0. The varied-view scout is useful only as a secondary extraction diagnostic
after its optimizer-step schedule is repaired; it must not delay Q0.

### 2. Spend one root on coexistence, then move to the organism

After Q0, run one equal-memory-dose cumulative/replay canary. Its job is only
to prevent funding M if old and new content cannot coexist. It is not a
separate powered paper study. A clean pass must preserve both banks and the
native interface noncompensatorily.

In parallel, close M-core's zero-fit materializer, schema/visibility,
side-channel, exact-text, and oracle-air-gap proofs. Use four exact-text roots,
then two LoRA roots as the kill gate. Each LoRA root needs only three trained
conditions: `FULL_AUTH`, `OUTCOME_SHUFFLED`, and `DREAM_NULL`; SLEEP-off,
wrong-root, goal/outcome twins, and content cuts are read-time interventions.
Scale only if both kill roots have the registered direction and every causal
trace seam passes. The next expensive dollar should purchase another
independent root, not another endpoint or rendering.

### 3. Develop the parent in parallel, but do not raise a claim child early

The parent can adapt its teaching in context/notebooks; its weights need not
learn. First qualify one lesson without a write. Then, once Q0 is frozen, test
parent-deleted persistence. Do not contaminate a future childhood ancestor
with deployment tasks, sealed M/L targets, or readout feedback.

Only then raise matched parented and neutral children. L-core should be one
five-branch root block:

```text
P-RUN, P-FROZEN, U-RUN, U-FROZEN, P-TEXT
```

Use an exogenous information/exposure clock, parallel exam forms, one excluded
executor canary, source-disjoint DEV, and fresh confirmation. Root blocks are
the independent units. Confirmation size must come from a sealed mean-blind
variance rule; episodes, cuts, branches, and decodes do not increase `N`.

### 4. Compression remains downstream

Do not spend the abstract-critical path measuring token density or physical
LoRA size. Once M proves connected utility, the fixed semantic-code assay can
ask whether the same exact relational denotation admits a shorter deployable
code. A null there removes only the compression sentence; it does not erase
M or L.

## Submission branches

Use the branch-stable title **“Experience Models: Causal Tests of Per-Life
Parametric Learning in Acting Agents.”** It remains accurate for a positive,
null, or localized-failure outcome. The abstract's stable core should describe
the question, three-operation architecture, prospective causal decomposition,
and controls. Only its result paragraph changes.

### At the September 18 abstract freeze

The official deadline is **September 18, 2026, 23:59 AoE**, which is
**September 19, 04:59 PDT**: about **6 days 15 hours** from this audit. The
abstract must be genuine and informative; it cannot be a placeholder. It may
be edited through the paper deadline, but the revision must remain the same
paper.

| Evidence available by freeze | Honest result language |
|---|---|
| M confirmation and clean L confirmation pass | Full bounded claim: own public experience -> child-organized connected write -> prospective expansion; parenting-by-SLEEP interaction; absolute late improvement/retention; text advantage only if its gates also pass |
| M confirmation passes; L is null or incomplete | Mechanism paper: the finite two-cycle causal relay works; report the parenting/lifetime test as null or not established. Do not say learning-to-learn, increasing lifetime, or text superiority |
| Q0/W1 pass, but M is valid and null | Controlled negative: selective supplied writing is possible, but the causal own-experience/DREAM relay fails at the named seam. The paper remains about the Experience Models hypothesis, not generic LoRA tuning |
| Q0 validly fails after its allowed repair | Writer-barrier result: correct supplied content can affect action, but this writer cannot install local complementary native policies without acquisition/locality/interface failure. No THINK--DREAM--SLEEP efficacy claim |
| No valid Q0 or downstream prospective result exists | The current positive/diagnostic evidence is insufficient for the intended empirical abstract. A method-only promise would be a placeholder. The only honest fallback is a clearly negative, causal writer-failure paper using already sealed denominators—or no submission |

A two-root M kill result is feasibility evidence, not confirmation, and should
not be upgraded to the first row. Likewise, L-DEV selects mechanics and
variance; it does not establish the lifetime effect.

### At the September 25 paper freeze

The official paper deadline is **September 25, 2026, 23:59 AoE**, or
**September 26, 04:59 PDT**: about **13 days 15 hours** from this audit.

- **Positive branch:** M confirmation plus L confirmation gives the intended
  core paper. Add semantic compression only if its separate assay passes.
- **Clean-null branch:** a complete prospective M and/or L study is still a
  paper about the original hypothesis if it localizes the failure with the
  frozen controls. Report nulls and adverse roots intention-to-treat; do not
  substitute exploratory favorable lives.
- **Writer-failure branch:** potentially submission-worthy only if Q0 and its
  allowed repair produce a prospective, replicated causal failure with a
  valid carrier and precise acquisition/extraction/locality diagnosis, tied
  to the end-to-end question. A single invalid or one-root convenience null is
  not enough.
- **Incomplete/invalid branch:** do not turn diagnostics into the full
  Experience Models result. Preserve the benchmark and continue the research
  rather than claim an unexecuted organism.
