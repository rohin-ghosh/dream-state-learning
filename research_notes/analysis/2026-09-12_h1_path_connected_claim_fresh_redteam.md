# Fresh red-team: what L0 -> Q0 -> Level 1 -> W-H1 -> H1 can actually prove

**Date:** 2026-09-12  
**Role:** independent scientific falsifier  
**Status:** design/evidence audit only. No builder source, GPU job, benchmark
material, coordination record, or scientific result was changed by this memo.

## Ruling

The sequence is well ordered for establishing a **bounded experiential write
bridge**, but it is not sufficient for the paper sentence as currently
phrased.

If Q0, Level 1, W-H1, and H1 all pass, the defensible result is:

> A process parent increased the production of supported child-authored
> conditional action records, and a qualified LoRA write of exact action
> continuations traceable to the child's own public action outcomes changed
> later parent-free actions on held instances.

That is real and paper-relevant. It closes action/outcome -> child artifact ->
write -> later action once. It does **not** establish that the resulting
knowledge is connected, traversed under a goal, expanded, recurrently
improving, compressed, or superior to strong memory.

The hidden proxy is simple: H1 mechanically renders each accepted two-mode
artifact into independent `(family, mode) -> action` targets, and its held
readout asks for one such action at a time. A flat table of 32 independent
bindings can pass every AUTH/SWAP action gate. The model never has to use the
fact that two bindings were authored together, join two separately experienced
relations, choose a path because a goal changed, or identify a missing edge.
AUTH/SWAP proves conditional content carriage, not connected structure.

There is also one smaller selection shortcut inside H1. The factual gate
discards unsupported STORE attempts before SLEEP. If parenting merely causes
more valid-looking guesses, rejection sampling can create more admitted correct
rows and better downstream action without improving the child's use of
evidence. The current design reports pre-admission supported precision but does
not make it noncompensatory in the H1 gate. Schema parity alone does not close
this route.

The smallest repair is therefore **not** to redesign Q0, W-H1, or the H1
writer. It is:

1. add one pre-admission precision guard to H1; and
2. append the already-designed PCFL-R3 connection/traversal stage before using
   “connected experiential knowledge” in any claim.

Do not force H1 itself to become a graph benchmark. H1 should remain the clean
ownership/compilation bridge. PCFL-R3 should remain the downstream necessity
test for connection and traversal.

## What each current gate buys, and no more

| gate | if it passes | shortcut it still leaves |
|---|---|---|
| repaired L0 coexistence | one adapter can preserve one global convention while acquiring another under replay | both conventions are global; no input-selective decision |
| adjudicated Q0 `P_AUTH/P_DERANGED` | one rank-8 recipe can acquire complementary opaque tool x mode action maps on one root with locality | supplied SFT, one finite surface, no experience or composition |
| Level-1 PROSPECT + REVISE | supplied conditional procedures can be carried and, if the zero-fit chain passes, composed in dialogue | all answers are computable from the current prompt; no stored world knowledge |
| W-H1 AUTH/SWAP | the exact H1 renderer/writer can carry arbitrary family x mode bindings on held objects/forms without spill | oracle-authored material; independent bindings suffice |
| H1 | a parent-caused child artifact can be compiled from authentic action/outcome evidence and alter a later action after state deletion | verifier selection can reward guess volume; one-key lookup suffices; no connection is behaviorally necessary |
| PCFL-R3 `C/T` | separately experienced relations must be combined and selected differently under different goals | no active expansion or lifetime slope yet |
| PCFL-R3 `Q/X` | old memory directs one informative action and a later reset task needs old plus new knowledge | one bounded cycle, not a learning curve |
| H2 plus strong baselines | continued SLEEP changes learning over increasing lifetimes and can be compared with evolving text/graph memory | physical compression remains a separate rate claim |

The high-dose keyed-memory result strengthens, rather than removes, this
separation. It proves rank 8 can store arbitrary keys after 20 real encounters
per binding, while two of three no-replay continuations destroy the inherited
interface. The repaired L0 coexistence result proves explicit replay can
preserve compatible global conventions. Neither result says that a bundle of
stored keys is a connected representation.

## Minimal H1 amendment: keep rejected guesses visible

Keep the current `Q`, coverage, NULL, schema-parity, AUTH/SWAP, OFF, TEXT,
locality, and root-level gates. Add exactly one noncompensatory guard computed
**before admission** over every syntactically valid informative-family STORE:

```text
STORE_precision[a] = supported complete two-mode STOREs[a]
                     / all syntactically valid informative STORE attempts[a]
```

An empty denominator scores zero. A partially correct, contradicted,
unsupported, or wrongly cited STORE is an incorrect attempt; the grounding
gate may keep it out of training but may not erase it from this denominator.

For H1 promotion require, aggregated over the predeclared clean roots:

- `STORE_precision[P] >= .80`;
- `STORE_precision[P] >= STORE_precision[S] - .05`; and
- the already registered P supported-STORE coverage `>= .70` and coverage
  advantage `>= +.10`.

This does not require equal STORE rates and does not prevent parenting from
teaching discretionary selection. It only prevents “emit many guesses, let the
verifier choose the lucky ones” from satisfying the parenting edge. Report
precision and coverage jointly; neither may rescue the other. This is the
smallest change because all required counts and rejection classes are already
specified in the H1 artifacts.

## Minimal connected-knowledge necessity test

After H1 passes, instantiate only phases A/B of the existing PCFL-R3 proposal
first. Do not begin with the second write or the full lifetime factorial.

### Required experience

In separate source episodes, the child executes and observes two public opaque
transitions that share an endpoint. No source row contains the composed route,
future route goal, or complete action sequence. At DREAM the child may author:

- the two cited atoms; and
- one cited, directionless connection joining them.

The verifier may authenticate endpoints and citations. It may not propose,
repair, rank, or insert the connection.

### Three equal-information writer states

Use the H1-qualified writer with identical atomic facts, target-token counts,
optimizer geometry, replay, and interface material:

1. `LINK_AUTH`: the child-authored authentic connection;
2. `LINK_ATOMS`: the same atoms, no link, plus predeclared neutral
   gradient-bearing material to match dose; and
3. `LINK_DERANGED`: the same atoms with a type/degree/age/token-matched
   fixed-point-free link permutation.

Also read `OFF`, cyclic wrong-root, exact structured text, raw episodic, and a
witnessed graph. Rote one-edge accuracy must remain comparable across all
three LoRA states; otherwise a route difference can be an atom-storage
difference.

### Necessary downstream readout

With sterile contexts and no memory text, score two goals from the same start.
Each requires joining the separately witnessed transitions; the two goals
require different first actions and paths. No training row may contain either
goal or path.

The connection claim requires both:

```text
C = route_success(LINK_AUTH)
    - max(route_success(LINK_ATOMS), route_success(LINK_DERANGED))

T = both goals correct under LINK_AUTH
    AND goal swap redirects first action and complete path
```

For confirmation, preserve PCFL-R3's root as the independent unit and require
mean `C >= +.10`, a one-sided 95% root-level lower bound above zero, the
expected sign in at least `13/16` roots, strict legality `>= .95`, rote
differences within `.05`, and every cut/wrong-root/interface gate. If
`LINK_AUTH ~= LINK_ATOMS > LINK_DERANGED`, the model composed atoms at read
time: claim composition/traversal, but not added value from a child-authored
stored connection. If AUTH does not beat both, no connected-memory claim.

This is the smallest behavioral necessity test because it reuses one SLEEP
state for both composition and goal traversal and adds no second write. Only a
`C/T` pass releases PCFL-R3 phases C/D (`Q/X`) for active gap filling and
old-plus-new delayed reuse.

## Clean-lineage repair

The current H1 and PCFL-R3 memos conflict on ancestry. H1 says all
confirmation children are disposable and must not become deployment
ancestors. PCFL-R3 says to use an “H1-qualified adult checkpoint.” Do not
silently reuse a favorable H1 participant.

After H1 confirmation, freeze the qualified parent/DREAM/SLEEP recipe and
create a **new, result-independent release child or cohort** on identifiers
disjoint from H1 confirmation and PCFL-R3. Seal it before generating PCFL-R3
roots, then make outward disposable benchmark clones. Nothing learned from a
PCFL-R3 score, root, action, corpus, or adapter returns to that release lineage.
For a two-root PCFL sentinel use two predeclared release children, not two
optimizer seeds on one selected child. This preserves the project's
one-way-childhood-to-deployment rule and the root-level sampling unit.

If the project wants only a carrier-mechanism PCFL scout rather than a claim
about a developed adult, it may instead start every state from the same frozen
common birth. It must label that result a mechanism scout and not use parenting
or adult-development language.

## Exact go/no-go sequence, optimized for device time

### 0. L0: closed

The repaired one-root coexistence sentinel passed `32/32` on both own orders,
opposite-order rejection, inherited PREDICT-before-ACT, arithmetic ACT, and
zero spill. Stop L0 permanently. No seed replication and no more tag-order
cells.

### 1. Q0: one root, at most three fits (`<=0.75` A40-hour)

Run the adjudicated no-update objective audit, then mandatory `P_AUTH` and
`P_DERANGED` four-prompt XOR-quartet fits. Use the optional third fit only by
the sealed degeneracy/failure rule. Any canary, exact, held,
complementary-flip, locality, or interface failure is no-go for Level 1. A full
two-map pass advances. Do not interpret Q0 as experiential evidence.

### 2. Couple the first Level-1 and W-H1 sentinels before replication

To avoid six Level-1 fits before discovering that the exact H1 surface is
unwritable:

1. run Level-1 root 0 AUTH/DERANGED and its zero-new-training chain probe;
2. if it passes, construct the fixed root-0 birth and run W-H1 seed 0
   AUTH/SWAP;
3. only if **both** sentinels pass, run Level-1 roots 1--2 and W-H1 seeds 1--2,
   in parallel if capacity is free.

Every original per-root/per-seed gate remains binding. This changes staging,
not the qualification standard. If the zero-fit Level-1 chain fails, use only
the already registered one root chain-teaching pair; do not add a compiler or
parent. If W-H1 seed 0 fails, repair the exact H1 representation/writer before
replicating Level 1.

### 3. H1: excluded root, then 16 confirmation roots

Run the excluded operational root only after Level 1 and all three W-H1 seeds
qualify. Require the new pre-admission STORE-precision guard in addition to
the existing schema, `q`, `g`, `theta`, AUTH/SWAP, locality, interface,
state-deletion, and intention-to-treat rules. An operational pass releases the
16 clean roots; no efficacy tuning follows the excluded root.

If H1 passes, claim only bounded child-authored experiential compilation into
later action. If it fails, use its registered localization and do not enter a
graph world.

### 4. Connected C/T: zero-fit ceiling, then six-fit LoRA sentinel

1. CPU/oracle and exact structured-text/witnessed-graph phases A/B on four DEV
   roots; require at least `3/4` roots to expose rote, both routes, goal
   redirection, and all cuts.
2. On two predeclared release-child DEV roots, fit `LINK_AUTH`, `LINK_ATOMS`,
   and `LINK_DERANGED`: six fits total. Require correct sign for `C`, both-goal
   traversal/redirection, rote parity, legality, locality, and interface in
   both roots.
3. A failure stops connected-language and localizes world/reader versus writer
   versus link value. A pass releases completion of the eight DEV roots and
   then 16 sealed confirmation roots under the existing PCFL-R3 fixed-sequence
   test.

Only the sealed `C/T` pass licenses “connected experiential knowledge that is
traversed under goals.” H1 alone does not.

### 5. Expansion, lifetime, and baseline claims remain downstream

Only after the two-root `C/T` sentinel succeeds, add the PCFL-R3 `Q/X` second
write on DEV: old structure must direct the target-relevant experiment and the
delayed route must require OLD + NEW, with opposite-twin redirection. Then run
the sealed fixed sequence `C -> T -> Q -> X`.

Only after `Q/X` passes should the parented/unparented x running/frozen H2
lifetime be paid for. That factorial, not H1 or PCFL-R3 alone, tests improvement
across increasing lifetimes. `ACTIVE_STRUCTURED_TEXT`, witnessed graph, raw
episodic, and final-batch controls must run as registered before any superiority
claim. Use “compiled” or “consolidated,” not physical “compressed,” until a
separate rate--distortion crossover exists; the current rank-8 adapter is about
80.8 MB and the tiny worlds cannot support a positive physical-compression
claim.

## Final claim firewall

The complete causal ladder is:

```text
Q0/W-H1: supplied conditional writer works
H1: authentic child experience can be selectively compiled into later action
C/T: separately experienced relations become behaviorally necessary connected
     knowledge and are traversed differently under different goals
Q/X: carried structure directs a new experiment and old+new knowledge is reused
H2: continuing SLEEP changes learning across an adult lifetime
baselines: the complete system is compared with evolving text/graph memory
```

No lower rung inherits the name of a higher one. In particular, bundling two
independent mappings in one DREAM schema is not connected-memory evidence, and
a verifier-filtered corpus is not evidence of improved DREAM judgment unless
the child's pre-admission precision also passes.
