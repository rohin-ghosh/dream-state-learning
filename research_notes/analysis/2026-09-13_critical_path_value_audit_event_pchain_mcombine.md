# Critical-path value audit: EVENT-retention-v2, P-CHAIN-2, and M-COMBINE-4

**Date:** 2026-09-13 PT  
**Role:** fresh high-level scientific value audit  
**Scope:** documentation only; no source, model, tokenizer, fit, GPU, remote,
benchmark, adapter, or parenting work was performed.  
**Current runtime premise supplied by Main:** EVENT-retention-v2 A200 seeds 0
and 1 have passed acquisition; seed 2 and all retention descendants are not
yet terminal.

## Verdict

The current sequence is **useful component qualification, but it becomes
diagnostic overfitting if treated as a long serial claim ladder**. None of its
three present tests contains the paper's essential conjunction:

```text
own action -> public outcome -> own admitted memory -> same-adapter write
-> fresh episode -> self-chosen recall -> >=2 memories jointly choose action
-> new outcome -> second write -> OLD+NEW action
```

Use the three tests as bounded, one-shot seam localizers:

1. **GO:** finish EVENT-retention-v2, including the already bound descendants
   once the warm-path implementation is independently green.
2. **GO, primary and in parallel:** run M-COMBINE-4 Stage 2A once its source
   audit passes. It is the needed controller-birth test.
3. **PARALLEL, appendix diagnostic:** run P-CHAIN-2 once at D1/D2 under its
   exact stops. It must not serially gate an explicit READ architecture.
4. **SKIP:** the tiny Stage-1 model run and any further storage-only, syntax,
   rank, heat, or prompt scouts. CPU oracle/parser checks remain useful.
5. **FREEZE NOW:** specify and seal the integrated two-SLEEP junction before
   seeing P-CHAIN/M-COMBINE outcomes. That is the defense against designing a
   final task around whichever diagnostic happened to pass.

If the integrated junction passes, move immediately to one powered lifetime
campaign. If it fails, its exact failing seam is more valuable than another
round of isolated microbenchmarks.

## Why the components do not add up automatically

| Test | What a pass establishes | What remains absent |
|---|---|---|
| EVENT-retention-v2 | The numerical writer can acquire, preserve, and/or coexist with two exposed four-EVENT banks under scheduled replay. | The records are not a fresh own-life action-to-outcome chain; no cue or action uses them; no relation is composed. |
| P-CHAIN-2 | A supervised rank-8 adapter can expose two separately trained opaque NEXT facts and return an assigned two-hop endpoint, with same-ID redirection. | No own experience, autonomous READ, world action, second write, or lifetime. The visible endpoint candidates and canonical query differ from the intended agent loop. |
| M-COMBINE-4 | A target-disjoint supervised adapter can coordinate SEEK, PROSPECT, CHECK, and CONTINUE/STOP over an exact text service. | The memory is externally supplied, not parametric or autobiographical. |

Passing all three would make the integrated conjunction plausible, not prove
it. A same adapter can still fail because memory fitting erases the controller,
the controller never calls the learned address, the reader cannot extract
under free-running history, or atomically correct memories never change the
held action. Those are precisely the project's unresolved seams.

## Exact priority and stop rules

### P0 — EVENT-retention-v2: finish, then stop this line

**GO.** Seed 0/1 acquisition makes completing seed 2 and the prebound
descendants high-value. It tells us which replay schedule can be used in the
integrated writer. Preserve the intended comparison among new-only,
fixed-work, replay, and clean cumulative writes.

Stops:

- An A200 acquisition miss stops descendants for that learner seed; no
  same-version LR/rank/dose rescue.
- Run every prebound descendant for every qualifying seed regardless of an
  intermediate B200 score; otherwise the retention comparison becomes
  outcome-selected.
- If only 2/3 optimizer seeds acquire, report 2/3 robustness. It may support a
  DEV junction on passing lineages, but it does not qualify the writer as a
  reliable paper mechanism. The final lifetime must remain fail-inclusive.
- After these descendants, stop synthetic singleton storage work. Another
  exposed-bank assay cannot close prospective action utility.

### P1 — freeze the integrated junction material now

**GO in parallel with all current source work.** Freeze the final junction's
generators, controls, scoring, and future confirmation namespaces before the
component results are known. Do not materialize sealed confirmation answers
into any trainer namespace.

This is more important than either additional diagnostic. It prevents the
common failure mode in this repository: discovering a model-specific surface
that passes, then rebuilding the downstream task around that surface.

### P2 — M-COMBINE-4 Stage 2A: primary birth test

**GO after its deterministic source/oracle/null audit.** Run CLOSED and
ATOM-LOCAL at D1. Open D2 only under the already bound under-acquisition or
acquired-but-chain-failure rule. D2 is terminal.

**Skip the tiny Stage-1 base model run.** Its exhaustible three-READ topology
is an interface smoke test, not a scientific prerequisite, and the Stage-2A
intervention, typed-output, canary, and autonomous-chain panels already
separate acquisition from execution. Retain Stage-1's CPU parser/service/oracle
tests only.

Stops:

- If neither arm passes all four single-variable intervention gates at D2,
  stop this SFT controller version.
- If the atoms pass but autonomous chains fail at D2, stop. Do not add another
  micro-skill or prompt scaffold. A later rescue must be a declared objective
  change such as on-policy trajectory optimization or a stronger base.
- If ATOM-LOCAL passes, select it by the simpler-curriculum rule; coherent
  history was unnecessary at this scale.
- If only CLOSED passes while ATOM-LOCAL is not acquired, do not advance from
  the contrast; it is inseparable from learnability.

### P2b — P-CHAIN-2: parallel diagnostic, not a gate

**Run in parallel if a spare GPU exists and the exact writer prerequisite is
qualified.** Its cost is small and its redirection control answers whether
the adapter can perform canonical parametric two-hop completion. Keep its D1
and D2 terminal rules exactly.

**Change its scheduling status:** a P-CHAIN miss must not block the integrated
explicit-READ junction. The intended agent can retrieve one atom per mounted
reader call and connect atoms through THINK/READ/STEP recurrence; it does not
require a single prompt to directly emit the entire hidden two-hop chain.
P-CHAIN is a mechanism appendix and a useful negative localizer, not a
necessary organ.

Stop after the registered D2. Do not add candidates, more junction examples,
rank, heat, or a new prompt. A pass does not substitute for the junction.

### P3 — integrated two-SLEEP junction: the decisive kill gate

Run this immediately when a controller birth and single-atom writer/reader
are available. The smallest valid DEV is two independently generated roots,
both required to pass; optimizer repeats are robustness checks, not roots.

Each root must execute the same causal microcycle:

1. Begin from the exact target-disjoint birth checkpoint.
2. With no later goal visible, the child chooses actions and observes public
   outcomes.
3. Admit only exact child EVENT commitments supported by those action/outcome
   receipts plus at least one child-authored LINK whose two indispensable
   parents are independently witnessed EVENTs. The compiler may verify and
   replay this connection but may not invent it. Continue the **same** adapter
   with birth replay.
4. Start a genuinely fresh episode: empty KV/context and no text/vector/event
   store. The mounted adapter is the only life-specific state.
5. Require a child-issued cue before any memory is returned. Its held action
   must depend jointly on at least two independently acquired bindings.
6. Let that action reveal one precommitted new outcome; write again.
7. Require a delayed action that jointly needs an OLD and NEW binding.

Minimum simultaneous controls:

- exact supplied-text ceiling;
- birth-only/no-write;
- authentic own-life bank;
- foreign-life bank with matched write heat;
- same-ID binding-deranged bank;
- indispensable binding cut and equal-token irrelevant cut;
- goal redirection with the same evidence;
- raw chronological LoRA at matched target-token/update/FLOP dose if DREAM
  compilation is claimed.

The authentic linked bank and all matched text baselines receive the same
admitted EVENT/LINK meanings. An atom-only bank removes LINK while retaining
both parents; it is required whenever the paper says a compiled connection,
rather than inference-time atom composition, caused the action.

The test fails closed if the exact-text ceiling fails, if personal storage
erases the birth controller, if authentic does not beat foreign and
birth-only, if derangement does not redirect behavior, if an indispensable
cut does not hurt, or if the second write does not preserve OLD while adding
NEW. Do not rescue this root. Diagnose the seam and version the architecture.

Parenting may continue as a no-fit immediate-effect study in parallel, but no
durable parenting write belongs on the critical path until this junction
passes.

## Minimum final experiment that closes the scientific objective

After the two-root junction passes, the minimum paper-facing experiment is
one pre-registered novelty-growing lifetime campaign, not another collection
of pilots.

### Independent units and branches

- **16 independent world/learner lineages per primary branch**, subject to a
  prospective power simulation before launch; nested tasks and optimizer
  repeats are not additional `n`.
- Primary branches:
  `DLT_PERIODIC`, `SLEEP_FROZEN`, and a certified
  `ACTIVE_LINKED_TEXT` agent.
- Add `FINAL_BATCH` on the same histories if the paper claims periodic
  recurrence rather than merely experience-dependent learning.
- At fixed DLT histories, include `RAW_CHRONO_LORA` versus
  `DREAM_COMPILED_LORA` at matched target-token/update/FLOP dose if the paper
  claims value from compilation.

### Lifetime and tasks

- Five predeclared cuts are the minimum for increasing-lifetime/AUC evidence.
- Use seven cuts, with the last two fixed before launch, if the headline says
  the strong memory baseline **saturates** or that the learner passes it after
  saturation. Fit a curve with root-level uncertainty; do not infer a plateau
  from two equal points.
- At every cut, score old retention, newest acquisition, unseen OLD+NEW
  recombination, and an informative-probe-to-delayed-action expansion relay.
- Later goals are withheld during experience formation. Every claimed use is
  in a fresh episode and every branch sees only consequences of its own
  actions through a precommitted potential-outcome tape.
- Use both an opaque-binding stratum and a reusable-structure stratum. Exact
  text may rationally win on opaque facts; superiority requires a positive
  reusable-structure effect, no opaque harm worse than `.05`, and a positive
  predeclared aggregate.

### Causal and baseline qualification

- Preserve own/foreign, same-ID derangement, indispensable/irrelevant cuts,
  goal redirection, adapter-off/birth-only, and exact-text ceilings.
- Certify `ACTIVE_LINKED_TEXT` on ideal provenance-valid child rows before
  comparing branch-authored memories. Give it an unlimited persistent store
  and predeclare an access curve over query count and returned tokens. If the
  largest access point still improves materially, call it
  `MAX_TESTED_ACCESS`, not saturated.
- Score intention-to-treat: rejected writes and collapsed children remain
  zeros/failures in their allocated lineage.

This single campaign can establish own-experience acquisition, content-causal
connected use, goal traversal/expansion, retained OLD+NEW growth, lifetime
improvement, and a strong-memory comparison. The diagnostic trio cannot.

### Compression is a separate non-negotiable measurement

At current scale a rank-8 adapter is roughly 80.8 MB in fp32, larger than the
semantic ledgers. Therefore the core campaign can support **context-bandwidth
amortization**—useful behavior with zero retrieved memory tokens—but not
physical compression.

To literally close the full objective's compression clause, add a prospective
rate--distortion sidecar charging:

- raw chronology bytes;
- compiled semantic-row bytes;
- adapter/checkpoint bytes;
- all index/schema/provenance bytes;
- training presentations/compute; and
- memory tokens returned at inference.

At no fewer than three predeclared rates, require matched held action utility,
zero unsupported memories, and a persistent-byte or predictive-code crossover
against an ordinary packed-text codec. If it does not cross, remove
`compressed knowledge` and report only compilation plus context-bandwidth
amortization. Reduced dream prose or fewer inference tokens alone is not a
compression result.

## Prior-art consequence

The broad space is occupied:

- [TMEM](https://arxiv.org/abs/2606.04536) writes rollout-derived supervision
  into fast LoRA and uses it after working history and explicit memory are
  cleared within an episode.
- [PEAM](https://arxiv.org/abs/2605.27762) consolidates embodied experience
  into persistent category LoRA skills and reports long-horizon improvement
  and forgetting mitigation.
- [Online Experiential Learning](https://arxiv.org/abs/2603.16856) iterates
  deployment trajectories, experiential-knowledge extraction, and weight
  consolidation, reporting successive improvement and an advantage for
  extracted knowledge over raw trajectories.
- [AgeMem](https://arxiv.org/abs/2601.01885) trains one policy to manage
  external short- and long-term memory across a staged reset curriculum.
- [Evo-Memory](https://arxiv.org/abs/2511.20857) already benchmarks streaming
  experience reuse and implements many evolving external-memory systems.
- [AgentOdyssey](https://arxiv.org/abs/2606.24893) already evaluates
  exploration, world-knowledge acquisition, episodic memory, skill learning,
  and long-horizon planning in continuous generated games across long-context,
  RAG, SFT, latent, and other agents.

Consequently, neither “experience changes weights,” “memory survives a
reset,” “continual improvement,” nor “one benchmark combines exploration,
memory, and planning” is defensible novelty. The paper-worthy gap is the
controlled conjunction:

> One target-disjoint composition adapter is continued on verified opaque
> events from its own life; in a fresh episode with no external content store,
> it autonomously cues and jointly uses multiple identity-bound memories to
> choose a new action, extends that knowledge after another outcome/write, and
> improves over a powered lifetime under identity-sensitive cuts and a strong
> evolving-memory opponent.
