# Optional source-occurrence attribution repair v1

Builder adoption, September14 2026,02:30UTC. This is a prospective non-material
repair of false-positive attribution, not a change to hidden-data prohibition,
actor inputs, training bytes, targets, controls, thresholds or scientific claims.
No new human ratification is claimed. Formal final-paper C11 stays deferred.

Complete metadata produced numeric array-index aliases inside original opaque
IDs and lowercase structural-key aliases goal/start/service on original fixed
wire keywords. Raw strict failures are preserved in the integration-progress
note. Neither metadata fields nor aliases nor IDs may be removed/reselected.

The legacy scanner/default remains unchanged. Add an explicitly enabled
source-bound attribution path: reconstruct the whole supplied source and arm,
derive original complete identifier occurrences and parsed fixed-keyword
occurrences, and retain their evidence. Only semantic_alias hits may receive
these new receipts. Identifier hits must lie wholly inside one exact original
typed ID. Keyword hits must cover the complete original shared keyword token,
not a substring. Normalize/compact offset mappings must preserve containment.

Bind the entire original projection, not just matched endpoints: a candidate
must start with those unchanged bytes. Appended/copy occurrences have no new
spans; moved/modified source prefixes fail binding. Never derive exemptions
from a mutation or accept caller metadata/spans through the source adapter.
Low-level scanner inputs remain caller-bound evidence, not an authentication
service; full source reconstruction is mandatory in the integration path.

Alias derivation and all hits remain observable. Full-target, operand, future-ID,
registered-route, forbidden-core, core-semantic and resource checks are untouched.
The finite route matcher remains mandatory. The new path is explicit and
receipted; original strict results must not be relabeled as passing.

Descartes cautions that the existing substring acceptance contract would change
if this were made a global exemption, and that caller-selected IDs can conceal
semantic-dependent selection. Boole independently supports only this optional,
fully source-bound path as a non-material attribution repair; a legacy test
over unbound causal fields must still reject. Main adopts the narrow latter
scope under standing Builder authorization, not an independent-review override
of a reserved invariant. Both provenance concerns remain requirements:
reconstruction alone never proves an authorized allocator/master, absence of
selection retries, or scientifically independent ID allocation. Native admission
must bind those separately. A source receipt is not C11 or experiment approval.

Tests must retain legacy behavior and the full ledger, demonstrate exact
source receipts in all three forms, reject copied/moved/modified/boundary-crossing
occurrences, foreign arms/roles/masters and off-trace mutations, preserve all
other rejection categories, and leave every native/scientific gate false.
