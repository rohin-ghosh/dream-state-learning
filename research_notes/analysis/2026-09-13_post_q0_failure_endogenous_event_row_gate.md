# After a clean Q0 XOR-canary rejection: factor the memory address, not the gate

**Date:** 2026-09-13 UTC
**Status:** bounded watcher-side design memo. This is not implementation or
launch authority. I inspected committed design/audit memos only, not a live or
terminal Q0 root. I changed no builder source, test, model, adapter, job, or GPU
state.

## Decision

Assume the clean rerun passes custody and numerical integrity but receives a
registered first-update XOR terminal. The Q0 recipe is then scientifically
rejected exactly as registered. The mandatory DERANGED one-step diagnostic and
any permitted unary suffix may localize the miss, but neither can rescue Q0.
End rank, learning-rate, heat, paraphrase, dose, seed, and objective search on
that supplied `(opaque tool, mode) -> ACT` family.

The highest-information successor is one permanently excluded development
root of an **addressed endogenous event-row gate**, `E0`:

```text
child precommitted action -> public outcome -> child-authored EVENT row
        -> fixed row replay -> LoRA memory process -> candidate-free row
        -> separate clean actor reads two rows and chooses for a later goal
```

Train only `E_AUTH` and `E_OUTCOME_SWAP`, with `E_OFF`, an unmounted shadow,
and lossless exact text requiring no fits. The representation change is the
point: the adapter no longer maps a two-factor condition directly to an action.
It maps one exact episode address to one complete semantic event or `MISS`.
Only a separate, adapter-free actor sees the later goal and converts retrieved
events into an action.

This is preferable to the already designed action relay after a Q0 rejection:
that relay inherits the rejected Q0 action surface. It is preferable to jumping
to connected M or lifetime L because their failure would confound formation,
atomic storage, candidate-free reading, traversal, recurrence, and control
quality. `E0` is the smallest test that can open a new semantic-memory path
without pretending Q0 passed.

## What the Q0 rejection says—and does not say

A valid first-update miss says that the exact registered initialization,
dropout sample, quartet, pairwise objective, and direct-action representation
did not move all four XOR margins in their required directions. It rejects that
recipe as the project gate. It does not prove that LoRA cannot store a unary
episode, generate a factual row, or serve as a memory behind a separate actor.

The old Q0 label remains permanent in every paper and ledger. `E0` cannot
release Q0-dependent Level 1, W-H1, or the Q0-surface action relay. A successful
`E0` instead opens a new architecture branch whose next gate is child-authored
links over event rows.

## Why this is a representation redesign, not threshold weakening

| frozen Q0 object | proposed `E0` object |
|---|---|
| researcher-supplied finite action map | records authored after the child's executed actions and public outcomes |
| joint `(tool, mode)` address and XOR action target | one preallocated episode handle and a complete `EVENT` payload |
| adapter mounted in the acting model | adapter mounted only in a goal-blind memory process |
| output is the task action | output is a local factual row or `MISS` |
| evaluator asks whether the trained policy fires | a separate clean actor must use raw returned rows for a later goal |
| complementary policy map | outcome-rebound semantic control with identical addresses, marginals, and work |

It is legitimate to remove the XOR interaction only because the claimed module
has changed from a conditional policy writer to a content-addressed episodic
memory. An exact-address lookup may pass; that is the intended bounded
primitive. It would be disguised weakening to call that lookup a Q0 pass,
selective policy learning, connection, traversal, or generalization.

The following are expressly forbidden successors: rank 32, a new learning
rate, zero dropout, more Q0 sweeps, a different quartet, semantic tool names,
one mode, unbalanced actions, easier paraphrases, full-vocabulary CE on the
same direct `ACT` target, or a lower Q0 accuracy/locality threshold. So are a
candidate row bank, answer-bearing retrieval, and a compiler that derives the
correct later action. Those are Q0 tuning or task leakage, not a new memory
representation.

## One-root material and authorship boundary

Create one fresh opaque root only after the protocol/checker bytes freeze.
Allocate eight scene IDs, sixteen episode handles, sixteen unused handles, two
equal-token legal actions, and two equal-token public outcomes before assigning
semantics. Each scene has a private balanced two-action outcome permutation;
across the root, actions, outcomes, handle lengths, order, and renderers are
balanced.

For each scene:

1. Before either outcome is visible, the child emits one ordered precommit
   containing two strict `ACT` lines, one for each legal action. The environment
   executes those exact child action bytes in that order and returns the two
   ordinary public outcomes.
2. With both immutable receipts visible, the child gets one opportunity to emit
   two complete rows:

   ```text
   EVENT <handle> AT <scene> DID <action> GOT <outcome>
   ```

3. The admission checker may parse, join handles to executions, and copy exact
   bytes. It may not add, replace, infer, paraphrase, or regenerate a semantic
   field. All `16/16` rows must be correct and supported. Otherwise stop before
   fitting as `E0_FORMATION_FAIL`.

This deliberately guarantees action coverage by asking for a pre-outcome
two-action plan. It proves neither spontaneous exploration nor autonomous
experiment choice. It does preserve the narrower provenance fact needed here:
the action bytes came from the child before the outcome, and the AUTH semantic
payload came from the child afterward.

No hidden permutation, later goal, action answer, score, admission bit, donor
identity, or evaluation item enters model-visible source or training text.
Evidence citations and raw chronology remain in the audit projection; the
model-visible row above is the complete semantic payload.

## Zero-fit closure before a writer opens

The memory API is:

```text
READ EVENT <handle> -> raw model generation -> exactly one EVENT row or MISS
```

The memory process sees only the request, base, and assigned adapter. It never
sees the later goal, action menu, source transcript, candidate row, candidate
ID bank, live-membership bit, scorer, or hidden world. Handles are public
addresses, not answer candidates.

Before any fit, require a lossless exact-text implementation over the same
child rows to produce `16/16` exact rows, at least `15/16` correct actions on
the later two-outcome goal panel, and the registered opposite actions after an
outcome swap. No-memory, ID, order, length, renderer, and target-marginal
shortcuts must remain at chance plus `.05`. If text/clean-actor closure fails,
label `E0_ASSAY_INVALID`; repair the task or reader, not the LoRA.

This text condition is an assay ceiling, not the paper's strong active-memory
baseline. It receives exactly the same event semantics and address roster as
the LoRA path.

## Two fitted arms and one fixed recipe

All states begin from the pinned clean Qwen2.5-7B-Instruct base. Use one
prospectively hash-bound rank-8 row-reconstruction recipe: the existing Q0
module inventory, initialization, optimizer constants, dropout, and numerical
custody, but ordinary masked causal-LM loss over the complete `EVENT ...` or
`MISS` target. There is no recipe ladder, selection, or retry. Reusing the
optimizer constants reduces nuisance variation; changing the output object and
module boundary is the declared intervention. Full-row loss is not evidence
that another objective rescued Q0.

Build 64 positive rows (`16 events x 4` fixed train views) and 64 negative
address rows (`16 unused handles x 4`, target `MISS`). Preseal 32 four-row
optimizer units and replay the exact order four times. Each fit therefore uses
128 updates and 512 natural-row forwards, with 16 positive presentations per
event and equal negative-address exposure.

| state | persistent content | role |
|---|---|---|
| `E_AUTH` | exact admitted child rows | complete experiential path |
| `E_OUTCOME_SWAP` | within each scene, swap only the two outcome tokens | matched semantic redirection |
| `E_OFF` | no fit | no-write floor |
| `E_SHADOW` | AUTH candidate exists but is not mounted | reset/leak cut; no extra fit |
| `E_TEXT` | lossless admitted rows outside weights | zero-fit assay ceiling |

AUTH and SWAP must have identical input bytes, target lengths, action and
outcome token marginals, syntax, row order, updates, initial tensors, optimizer
state, and dropout RNG. The outcome strings are one token with identical
boundary behavior. SWAP is a synthetic causal control and can never enter a
lineage.

The first positive optimizer unit is frozen before child output and contains
two scenes x both actions, hence balanced actions and outcomes. Reuse Q0's
state-neutral FP64/error-bound machinery, but define the new canary on the
teacher-forced action and outcome field margins of these four addressed rows.
The actual full-row update must improve every registered target-versus-other
action margin and target-versus-other outcome margin. Preserve Q0's executable
serial lifecycle: an AUTH pass continues uninterrupted through update 128,
after which SWAP starts; an AUTH miss stops after update 1 but still receives
the registered one-step SWAP diagnostic. A SWAP pass continues uninterrupted.
Any canary miss makes the primary result
`E0_ADDRESSED_ROW_FIRST_UPDATE_MISS`; no alternate address, quartet, seed,
loss, or dose follows.

This is not a softened Q0 canary. It keeps an opposite-direction first-update
test, but the source, address, output, and claim are now episodic and semantic.

## Sterile read and behavioral gates

Every read starts with a fresh cache and no source, record, ledger, or fit
label. The memory adapter is never mounted in the actor. For each scene, the
clean actor receives a later desired outcome, the two public handles, and the
two raw memory returns, then emits one action. It receives no feedback before
the scored action. AUTH, SWAP, OFF, SHADOW, and text use identical actor bytes
except for their raw returned rows.

One excluded root passes only if every integrity and formation condition plus
all of the following hold:

1. **Addressed memory:** for each fitted arm, exact complete-row correctness is
   at least `29/32`, held-query correctness at least `14/16`, and validity at
   least `31/32` and `15/16`. Each action and outcome class has at least `7/8`
   held recall.
2. **Semantic redirection:** SWAP emits its registered swapped outcome on at
   least `14/16` held handles; at least `13/16` handles are correct under both
   adapters and have opposite outcome fields. AUTH exceeds OFF held semantic
   correctness by at least `.20`.
3. **Use by a separate actor:** AUTH solves at least `14/16` authentic
   scene-by-goal actions, with at least `7/8` recall per action. SWAP solves at
   least `14/16` under its synthetic map, at least `13/16` items flip between
   AUTH and SWAP, and the symmetric redirection contrast is at least `.40`:

   ```text
   B = .5 * [(BA(E_AUTH, AUTH)-BA(E_AUTH, SWAP))
           + (BA(E_SWAP, SWAP)-BA(E_SWAP, AUTH))].
   ```

   AUTH must also beat OFF on authentic action BA by at least `.20`.
4. **Absence and scope:** on 16 unused held handles plus 16 wrong-root handles,
   each fitted memory emits exact `MISS` at least `30/32`; no false row is used
   by the actor. The fixed native copy/interface panel remains `8/8`, and the
   registered neutral-surface behavior differs from OFF by at most `.05`.
5. **Reset:** unmounted SHADOW and OFF have byte-identical model-visible
   request projections and raw held/interface outputs under deterministic item
   seeds. Adapter, cache, record, or process leakage is an integrity failure.

Thresholds are fixed engineering gates on one excluded root, not confidence
intervals. Prompt forms and the sixteen action questions are repeated measures,
not independent scientific units. Any missing denominator, retry, selected
checkpoint, wrong mount, nonfinite value, source/target leak, compiler semantic
edit, or teardown failure outranks efficacy and is nonreportable.

Failure labels remain separated: `FORMATION_FAIL`, `ASSAY_INVALID`,
`FIRST_UPDATE_MISS`, `ROW_NOT_STORED`, `STORED_NOT_EXTRACTABLE`,
`OUTCOME_BINDING_NOT_CAUSAL`, `ROW_NOT_BEHAVIORALLY_USABLE`,
`FALSE_MEMORY_OR_INTERFACE_FAILURE`, or the full
`DEV_ENDOGENOUS_ADDRESSED_EVENT_MEMORY_PASS`. Do not average one stage over
another.

## Bounded cost and next release

Maximum source work is eight precommit calls plus eight record calls. Maximum
training is two fits, **256 optimizer updates and 1,024 row forwards**. The
complete OFF/AUTH/SWAP memory panels, clean-actor panel, SHADOW cut, and text
ceiling are under 400 short generation calls. Full-row targets are longer than
Q0 branches, so Q0 timing should not be copied as a runtime claim; reserve at
most **90 wall minutes / 1.5 A40-hours** for this one serial DEV root, with
actual token, forward, backward, load, generation, and cleanup counts sealed.
An early formation or dual-canary stop uses no or negligible fit budget.

A pass freezes the address, row, compiler, reader, actor, and writer bytes. The
next experiment is then a small child-authored `LINK(event_1,event_2)` versus
atoms-matched and link-permuted test using the same row carrier. Only that rung
can claim connection; only a later second SLEEP with an outcome-selected new
row can claim expansion; only novelty-growing repeated cuts can claim lifetime
improvement. The strong `ACTIVE_STRUCTURED_TEXT`, raw RAG, native context,
final-batch LoRA, and witnessed-graph contest belongs with that later integrated
study, not as a way to rescue this writer DEV result.

Log normalized raw-transcript, EVENT-row, schema/index, and adapter bytes now,
but make none gate-bearing. At this scale the roughly 80 MB rank-8 adapter is
not physically compressed. Semantic compression is a later model-free
rate--distortion sidecar after connected utility, with complete codebook,
index, decoder, provenance, fidelity, false-memory, and utility accounting.

## Strongest allowed claim

If every gate passes, the maximum statement is:

> On one permanently excluded opaque development root, a model's executed
> actions and public outcomes were transcribed by that model into complete
> event rows; a fixed compiler wrote those exact semantics into an addressed
> LoRA memory; after sterile reset, a goal-blind memory process generated the
> rows without candidates, and a separate clean actor used them for later
> goal-conditioned actions. Rebinding only the outcome field redirected both
> the generated memories and actions.

This is one bounded own-experience-to-episodic-semantic-memory relay. It is not
Q0 recovery, autonomous exploration or abstraction, root robustness,
cross-situation generalization, connected knowledge, traversal, expansion,
retention, parenting, lifetime improvement, LoRA-over-text superiority, or
compression.

## Adversarial attack on the proposal

1. **It can pass as an exact-address lookup table.** Correct. The new primitive
   is content-addressed episodic memory. The separate actor and outcome-swap
   show semantic use, but only LINK/atoms and goal-swap interventions can show
   connection or traversal.
2. **The child merely transcribes a schema and is forced to cover both
   actions.** Correct. `E0` proves provenance and carriage, not spontaneous
   reflection or information seeking. Removing that scaffolding now would mix
   formation with representation and lower information per fit.
3. **A successful row writer would not explain why Q0 failed.** Correct. It
   would show a viable alternative boundary, not identify dropout, tangent
   geometry, or optimization as Q0's cause. The stop rule deliberately trades
   further Q0 diagnosis for thesis progress.
4. **Full-row CE can again learn syntax while ignoring the binding.** That is
   why syntax, loss, or legal-row mass never pass the gate. Both exact semantic
   fields, held rows, opposite SWAP outputs, and downstream action redirection
   are mandatory. A null kills this fixed row recipe; it does not invite a
   post-result objective ladder.
5. **The address roster is external memory and over-scaffolds retrieval.** It
   is a charged index with no payload and is shared with text/OFF. `E0` tests
   storage/read, not actor-chosen search. Later M must require the actor to
   select local reads under goal swaps and compare against a fully capable
   active-text index.
6. **The synthetic SWAP may be harder or less pretrained than authentic text.**
   Equal one-token outcomes, within-scene swaps, identical marginals, and
   symmetric scoring reduce but do not eliminate semantic-alignment effects.
   One DEV root cannot resolve them; fresh randomized roots are required only
   after the complete protocol freezes.
7. **MISS anchors are researcher-supplied.** Yes. They train the interface, not
   world semantics, and are identical across arms. Report their 50% corpus
   share; do not call the entire corpus self-generated.
8. **The clean actor may simply be better with visible text than weights.** The
   weights are only the transport substrate, so this is intended. Exact text is
   allowed to win. Parametric superiority remains untested.
9. **A tiny row is not compression.** Correct. The adapter dwarfs the payload,
   and shorter prose can be a formatting artifact. Compression language stays
   closed.
10. **One excluded root is not paper evidence.** Correct. It is a kill gate. A
    positive freezes a genuinely new family; a negative prevents expensive
    connected and lifetime work from hiding an atomic-memory failure.
