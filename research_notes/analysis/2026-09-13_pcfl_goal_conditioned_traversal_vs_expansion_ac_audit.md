# PCFL area-chair audit: goal-conditioned traversal versus expansion

**Date:** 2026-09-13 UTC  
**Role:** fresh skeptical area chair  
**Scope:** analysis only; no source, benchmark, fixture, model, tokenizer,
adapter, GPU, or scientific execution  
**Evidence cut:** repository through `d0d685bc`

## Ruling

**Recommend B: register one minimal goal-switched, read-only control now.**

Current PCFL v2.2 is already sufficient for the narrow claim that stored
experiential knowledge is **used to produce a route conditional on a goal**.
Its pure goal intervention is modest, however: the two same-start delayed
goals share four of five route decisions and change only the terminal edge. It is not
sufficient for the stronger claim that the goal controls **which missing
knowledge the agent chooses to acquire**. Both delayed goals require the same
unknown frontier, `H -> S_R`, so an always-choose-`H -> S_R` policy can pass
the present reachout panel without using the goal to value the experiment.

The newly bound real distractor makes the missing intervention unusually
cheap. The OLD graph already contains:

```text
main route:  S_L -> A -> H       S_R -> B -> G_R0/G_R1
dead route:  S_L -> X            Z -> Y
frontiers:   H -> S_R            X -> Z
```

Use a sterile read-only fork of the same post-S1 snapshot and change only the
public target from `G_R0/G_R1` to existing node `Y`. For a right-hand goal,
`H -> S_R` is uniquely useful. For goal `Y`, `X -> Z` is uniquely useful. No
outcome is returned, no memory is authored, no fit occurs, and neither fork
may enter an authentic lineage.

This should be a **claim-optional side gate**, not a new progression gate for
carriage, connectedness, or authentic OLD+NEW expansion. Failure merely
forbids goal-conditioned experiment-selection/value-of-information wording;
it must not stop the existing PCFL vertical.

## What the registered assay already establishes if it passes

### 1. Goal-conditioned traversal: yes, but bounded

S1 has two candidate-free OLD tasks with different starts, targets, and
routes:

```text
S_L -> G_L  : a_O,b,c
S_R -> G_R0 : d,f_0
```

This S1 pair establishes **task-conditioned** traversal, but it is not by
itself a clean goal-only intervention because start and target change
together. The registered trace-divergence requirement is still useful process
evidence, not the cleanest basis for a goal-conditioned claim.

The clean goal intervention occurs later: delayed tasks keep start `S_L`,
memory, affordances, and long route prefix fixed while changing target
`G_R0` versus `G_R1`. The correct terminal memory edge changes from `f_0` to
`f_1`. The service is goal-blind; only the clean actor sees the goal. The
native endpoint separately mounts the same personal adapter in the acting
model. Candidate-free output, OLD/NEW cuts, OFF, wrong-root, cross-mounts, and
collision controls bound prompt, identity, and carrier shortcuts.

Safe wording:

> With start and memory fixed, the goal selected the target-specific terminal
> connection in an otherwise shared stored route.

This is an actor/API-level result. It is not evidence for latent graph
geometry, a broad goal-directed replanning policy, or an autonomous internal
search algorithm. Calling the entire route “different” without noting the
shared prefix would overstate the intervention.

### 2. Task-relevant experiment selection and expansion: yes, narrowly

The existing authentic lineage can show that memory made `H -> S_R` useful,
the child selected that experiment after seeing a future task, experienced
its result, authored NEW EVENT/LINK memory, slept again, and later solved a
task requiring OLD and NEW information. OFF, wrong-root, the critical-memory
cut, sham/permutation controls, and OLD_REPLAY can make this causal.

Safe wording:

> Stored experience supported selection of a task-relevant experiment; its
> public outcome was then authored, consolidated, and reused with older
> experience.

### 3. Goal-conditioned value of information: no

Both registered delayed goals use `H -> S_R`. The newly real `X -> Z`
distractor fixes the previous no-op-control defect, but it does not itself
make probe utility vary with the goal. A fixed “choose the frontier joining
the denser components” or “always choose the H-side probe” policy can pass.
Even if that policy depends on learned memory and is useful for this task, it
does not demonstrate goal-conditioned experiment valuation.

Unsafe wording without the added control:

- “the goal determined which knowledge the agent sought”;
- “the agent learned a general value-of-information policy”;
- “changing the goal changed its expansion decision”; or
- an unqualified conjunction that implies both traversal **and expansion
  selection** were goal-conditioned.

## Minimal goal-switch panel

For each post-S1 AUTH snapshot used by the reachout diagnostic, create paired
sterile prompts with identical memory, probe affordances, probe ordering,
surface render, budgets, and decode seed. Change only the public goal node:

| goal | uniquely useful probe | reason from OLD memory |
|---|---|---|
| `G_R0` or `G_R1` | `H -> S_R` | joins the known left prefix to the known right target suffix |
| `Y` | `X -> Z` | joins known `S_L -> X` to known `Z -> Y` |

Score the committed `PROBE` only. Do not return either result. The diagnostic
fork terminates immediately and is permanently non-lineage-entering.

Minimum prospective checks:

1. **Exclusive utility:** the exact oracle proves that adding only `H -> S_R`
   enables the right-hand goal but not `Y`, while adding only `X -> Z`
   enables `Y` but not either right-hand goal.
2. **Paired public equality:** within each pair, pre-choice bytes differ only
   at the public goal-node substitution; probe IDs, endpoints, order, memory,
   budgets, and seeds are byte-identical.
3. **No role leak:** the same opaque probe ID that is privately called the
   distractor in the authentic branch is the correct action for `Y`; no
   `relevant`, `distractor`, `dead`, or structural mnemonic becomes public.
4. **Goal switch:** AUTH changes probe with the goal on at least `7/8` paired
   renders, while choosing the correct probe at least `7/8` for each goal.
5. **Memory necessity:** OFF, wrong-root, and goal-specific necessary-OLD-row
   cuts do not pass the paired switch criterion. Report fixed-position and
   simple goal-blind topology heuristics.
6. **Custody:** zero results, receipts, EVENT/LINK requests, corpus rows,
   writes, descendants, or authentic-state mutations are created.

Exact thresholds can reuse the existing eight-view reachout arithmetic; the
critical scientific object is the within-snapshot paired action switch, not
another independent root count.

## Cost and deadline judgment

This is high information per GPU-hour:

- **zero new fits and zero new adapters**;
- no new node or port identifier;
- no child-authored target or compiler change;
- no change to either authentic R continuation;
- only a small number of extra inference calls on already required S1
  snapshots; and
- the goal target `Y` and both supporting OLD EVENT atoms already exist.

The implementation cost is not literally zero. The sealed preparer must add a
diagnostic goal/work-row kind, exclusive-utility certificate, paired prompt
hashes, reducer fields, and fail-closed tests. This is a modest extension if
bound before the PCFL contract and renderer are sealed; it becomes expensive
and scientifically post hoc after outcomes are seen.

Therefore register it now, but place it beside—not in front of—the authentic
vertical. If it threatens the CPU/zero-fit critical path, ship the already
valid narrow PCFL claims and mark this side gate unexecuted. Do not redesign
the authentic world or delay S1/S2 fits for it.

## Claim release if both pieces pass

The added side gate and the existing authentic lineage support a careful
two-clause statement:

> The learned experiential memory supported goal-conditioned selection of
> which unknown connection to investigate. In the authentic lineage, the
> selected connection was then experienced, written, and later reused with
> older knowledge.

They still do **not** show that both alternative discoveries were separately
written and reused, a learned general information-gain objective, spontaneous
goal creation, or broad autonomous scientific inquiry. Those remain successor
claims.
