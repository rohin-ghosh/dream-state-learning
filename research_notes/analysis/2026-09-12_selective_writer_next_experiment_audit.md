# Selective-writer next-experiment audit

Date: 2026-09-12 UTC

Status: watcher-side scientific recommendation only. This note changes no
builder source, model, adapter, run, job, node, claim authority, or launch
state and does not authorize execution.

## Verdict

The single highest-information **next** experiment is the already-bounded
fresh semantic-action V10R2 W0, using its canonical query-view recipe (`Q0`):

```text
fresh semantic exact-row carrier and native-action canary
  -> only on a complete pass, four clean-base conditional W0 fits
  -> one terminal all-cell W0 decision
```

Do not run a preservation-only frame fit next, and do not jump directly to the
post-V10R2 2 x 2. The current writer has never received a valid test of
complementary conditional bindings through a reliable semantic action
surface. V10R1's positive control and seal were invalid, while the later
`a0/a1` diagnostics exposed a motor-alphabet asymmetry. The prefix-mask and
learning-rate experiments used one globally reusable frame completion and
therefore do not answer the semantic multi-key question.

This order is also the frozen order in the semantic-action W0 ruling and the
end-to-end synthesis: the post-W0 recipe screen is eligible only if the fresh
semantic carrier passes and the unchanged semantic W0 writer then fails.

## What the new negative evidence identifies

- At `3e-5`, the frame writer acquired strongly (`I_d_frame=3.078`) while
  spill remained `.394`; at `1e-5`, acquisition weakened and spill remained
  `.296`, almost ten times the `.03` ceiling. Learning-rate reduction changes
  magnitude, not selectivity.
- Prefix masking reduced spill from `.416` to `.202`, but erased acquisition:
  `I_d_frame=.015`, interval `[-.133,.174]`, and dose-16 correct probability
  fell from OFF `.260` to ON `.251`. Removing supervision is therefore not a
  selective solution.
- Attempt-2 W0's low streaming loss did not become held conditional binding:
  descriptive fitted cells had only 4--8 of 16 keys above the required NLL
  gain, chance-like complementary behavior, and spill `.266--.622`. Because
  the assay and seal failed, these values localize a risk but cannot be a W0
  negative.

Together these results reject more heat/mask-only tuning. They leave open the
most important uncertainty: whether complete semantic keys under
complementary maps can bind two real actions without a global action habit.

## Comparison of the three choices

| Choice | Question answered | Why it is or is not next |
|---|---|---|
| Semantic cross-view conditional W0 (`X0`) | Can multiple semantic access routes make a full-key relation recoverable on fresh forms? | Best representation repair if canonical-view semantic W0 stores the rows but cannot extract them. Running it first would combine a new action surface and a new rendering, so a pass or failure could not localize which change mattered. |
| Frozen-OFF/KL preservation (`QA` or `XA`) | Can the writer retain an already-valid OFF distribution on out-of-scope prompts while learning owner rows? | Directly targets locality but does not create conditional binding or extractability. The mask result warns that a constraint can lower spill by suppressing acquisition. On the old frame assay, OFF already fails G11, so preserving OFF cannot make that absolute abstention gate pass. |
| Full `Q0/QA/X0/XA` factorial | Do cross-view rendering and an OFF anchor have separable main effects, and can they coexist? | Highest total mechanism information after a valid semantic baseline failure, but premature as the immediate experiment. It spends four recipe cells before establishing that the new semantic carrier and unchanged W0 recipe are valid, and the current factorial prose has unresolved/stale contract details. |

The current factorial must not execute unchanged. It still prints artificial
`a0/a1` targets in its view contract rather than `-mem2reg/-gvn`; its full
request denominator is unresolved; its KL bank reuses the named locality
panel it later evaluates; and `0.8 L_memory + 0.2 L_anchor` weakens the memory
gradient as well as adding preservation. A later clean anchor comparison
should instead use semantic targets, an anchor-training bank disjoint from all
locality evaluation prompts, and an additive frozen coefficient:

```text
L = L_memory + lambda * KL(p_OFF || p_ON)
```

with `lambda`, teacher prefixes, vocabulary support, and every byte frozen
before fits. Otherwise an apparent locality pass can be exact-prompt rehearsal
or another lower-acquisition condition.

## Decisive next W0 cells

The exact-row carrier is a precondition, not a writer observation. On fresh
opaque material, its four root-map cells are:

```text
carrier(root_0, W+)  carrier(root_0, W-)
carrier(root_1, W+)  carrier(root_1, W-)
```

Each cell must independently reach at least 15/16 generated and 15/16 scored
correct actions. Across the fixed 64 items, strict validity must be at least
61/64, with zero truncations and zero multiple-action outputs; both generation
and scoring must redirect on at least 29/32 complementary-row swaps. The 16
semantic-copy canaries, tokenizer/backend receipts, exact seal, and replay must
also pass.
Any failure terminates with zero fits as
`ASSAY_INVALID_SEMANTIC_ACTION_SURFACE`.

Only that automatic conjunction releases exactly these fitted cells:

```text
Q0(root_0, W+)  Q0(root_0, W-)
Q0(root_1, W+)  Q0(root_1, W-)
```

All four must pass the already-frozen per-key NLL, complementary-map,
fresh-held choice/generation, stratum, strict interface, missing,
unsupported, neighbour, wrong-root, and semantic-copy gates. Roots and maps
are repeated cells, not four independent learners; no pooling, majority vote,
best checkpoint, or compensatory mean is allowed. Freeze the currently
ambiguous request denominator before output. Add canonical train-form scoring
as a predeclared diagnostic if feasible, but never let it rescue a failed
held-form W0 gate.

The only positive terminal label is the existing all-cell
`MULTIKEY_BINDING_PASS`. It would establish four supervised instances of
seen-key binary semantic-action carriage under this engineered grammar. It
would not establish unseen-key generalization or writer reliability.

## Predeclared successor, only after the W0 label

The W0 failure subtype should choose the next development treatment rather
than launching every treatment now:

1. If exact-train storage is present but fresh-held extraction fails, run
   semantic `X0` against a fresh matched `Q0` control.
2. If storage/extraction/interface pass but held locality fails, run the
   disjoint-bank OFF-KL anchor against the matching unanchored view recipe.
3. If both extraction and locality remain unresolved, then run the repaired
   full 2 x 2. Its decisive cells are absolute: `Q0`, `X0`, `QA`, and `XA`
   each either passes every storage/extraction/interface/locality gate or it
   does not. Main-effect improvement without an absolute passing cell is only
   a tradeoff. Only `XA` passing when both single-factor cells fail supports
   coexistence of the two repairs.
4. Any recipe selected on that development screen must rerun unchanged on
   fresh source-disjoint semantic W0 roots. Development roots, maps, and
   step-128/256 checkpoints never become independent confirmation.

If multiple later cells pass, use a presealed simplicity order rather than
choosing the largest observed effect: `Q0`, then `X0`, then `QA`, then `XA`,
with the earliest passing checkpoint preferred. This keeps the recipe search
from silently becoming best-of-many fitting.

## Claim boundary

A semantic carrier pass proves direct use of one visible row through two real
actions, not parametric memory. A semantic W0 pass proves only bounded
supervised conditional-policy carriage. A cross-view contrast may support a
development statement about extractability; an OFF-KL contrast may support a
development statement about held distribution preservation; a joint cell may
show that those properties coexist in this recipe. None establishes authentic
child experience, SLEEP, cumulative retention, connected knowledge, parenting,
increasing-lifetime improvement, compression, or the whole organism. W1
remains blocked until a fresh, sealed, replayed semantic W0 pass exists.
