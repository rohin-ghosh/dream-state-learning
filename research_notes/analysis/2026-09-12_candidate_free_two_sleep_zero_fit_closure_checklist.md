# Candidate-free two-SLEEP relay: shortest exact zero-fit closure checklist

Date: 2026-09-12 UTC

Role: independent closure reduction after the M-core/PCFL red-team

Status: specification/checklist only. This memo changes no source, benchmark,
model, tokenizer, adapter, process, job, GPU, resource, claim, release, or
submission and authorizes none of them.

## Verdict

Do not repair M-core v4/v8 by adding more receipts around its 32-row
recognition mount. Candidate-free means **no answer-bearing row candidate or
candidate ID exists in a claim-bearing LoRA read**. The actor emits an opaque
query; a goal-blind adapter process generates `MISS` or one complete local row.

The six future causal fits remain unchanged:

```text
S1  AUTH_OLD | SOURCE_BINDING_TWIN_OLD | ATOMS_ONLY_OLD
S2  AUTH_OLD_NEW_H0 | AUTH_OLD_NEW_H1 | AUTH_OLD_PLUS_PAD
```

Before any of them can open, one fail-closed `ZERO_FIT_CLOSED` receipt must
conjoin Z0--Z6 below. `ACTIVE_TEXT_NATIVE` closure is Z7 and is additionally
required before a paper-facing external-memory comparison. No average or
later model result can repair a failed item.

## Closed artifact set

One package manifest binds every immutable protocol byte: actual schemas,
root generator, independent checker, parser, actor/read/compiler/writer/text
renderers, prompts, tokenizer/runtime pins, output grammar, transition table,
failure table, query catalog, intervention functions, view schedule, analysis,
and dependency lock. The manifest excludes itself and rejects extra, missing,
mutable, or symlinked members.

Each of the two DEV and sixteen CONF roots has independently sampled pre-outcome
entropy and three disjoint projections:

```text
AUDIT: hidden graph, roles, potential outcomes, expected traces, donor maps
PUBLIC: opaque aliases, current state/goal/menu, observations, constant catalog
TRAIN: only authenticated/admitted rows and fixed role-blind rendering metadata
```

Static plans may preseal a slot, selector grammar, and potential-outcome
commitment. They may not contain a future answer row, correct link, selected
NEW payload, or expected action. Runtime result objects and endpoints live in
a separate append-only content-addressed namespace; there is no future-hash
cycle.

## Z0 -- deterministic bytes and chronology

- [ ] Two independent implementations materialize all 18 root packets
  byte-identically from the sealed entropy transcript; a checker importing no
  generator/compiler code reconstructs every member and digest.
- [ ] Every hash input has a typed width/codec; every draw, rejection,
  permutation, retry prohibition, and root index is total. Independent root
  entropy, not domain-separated hashing alone, is the iid premise.
- [ ] Every visible handle is allocated before semantic role and is jointly
  token-shape matched. Rejection occurs before role assignment; accepted roots
  are never regenerated or replaced.
- [ ] One closed transition row exists for every phase/state/legal action,
  including dead states, budgets, compiler events, outcomes, reset, and
  terminal. CPU enumeration finds no missing or ambiguous transition.
- [ ] Model-turn action commitment precedes its cited public observation;
  DREAM proposal precedes support; hypothesis/map/action precede the second
  outcome; admission precedes deck construction; deck construction precedes
  opening a writer; S2 follows S1. Logical and monotonic order both pass.

Any failure is `Z0_BYTES_OR_ORDER_FAIL`; no TEXT/model call or fit is eligible.

## Z1 -- exact information visibility

Bind a deny-by-default byte projection for each role:

```text
ACTOR: current public goal/state/menu, constant query catalog, public transcript
MEMORY: actor-emitted query handle, fixed read prompt, base+assigned adapter
COMPILER: named public events/proposal/support or selected public outcome only
WRITER: exact admitted rows, renderer/mask/schedule; no task or audit state
ENDPOINT: committed public trace plus isolated validation handle, after action
AUDIT/CHECKER: everything; no channel back to a live role
```

- [ ] The memory process receives no goal, target, action menu, candidate row,
  candidate ID, availability map, graph, provenance class, score, endpoint,
  expected trace, carrier label, or hidden role.
- [ ] The actor receives no stored-row roster, live-membership bit, reader
  score/order/index/timing, audit mapping, future row, or unselected branch.
- [ ] Compiler inputs exclude hidden truth, endpoint scores, expected
  admission, candidate rows, donor/provenance labels, future goals, and writer
  state. The compiler cannot call actor, reader, endpoint, or audit services.
- [ ] Writer inputs exclude raw history, goals, hypotheses, outcome prose,
  unselected NEW, terminal task/action, condition label, and evaluator bytes.
- [ ] Kernel/broker fixtures enumerate argv, environment, mounts, inherited
  descriptors, IPC, network, caches, and input frames. One injected violation
  of each class is detected by the same checker used for the negative receipt.
- [ ] Goal twins are byte-identical before the goal field; outcome twins are
  byte-identical through the common action commitment; run-versus-skip leaves
  all later-life public bytes identical.

Any forbidden byte or unobserved channel is `Z1_CAPABILITY_FAIL` globally.

## Z2 -- endogenous source and copy-only compilers

- [ ] Every credited atom is a deterministic lossless rendering of a
  model-turn-cited child action followed by its later public outcome. A missing
  action is never filled, scripted, or re-attributed.
- [ ] DREAM has one proposal slot before support/link-template/future-goal
  reveal. The child emits the complete connection: two event citations,
  ordered local relation, scope, and proposed query handle.
- [ ] LINK validates only public syntax, chronology, citation identity, and
  the later co-use predicate; it copies the child's exact bytes or emits
  `NO_ADMISSION`. It cannot fill, orient, broaden, rank, repair, replace, or
  request another proposal.
- [ ] Before the second action, the child emits exactly two hypotheses, one
  experiment, both predictions, and two complete `outcome -> NEW row` bytes.
  NEW validates the public law and copies only the branch selected by the later
  public outcome. Invalid/nuisance/ambiguous outcomes admit nothing.
- [ ] One presealed bit designates the factual outcome. The opposite outcome
  clone differs first at the public outcome byte and is labeled a repeated
  counterfactual control, never a second independent life.
- [ ] After selection, the unselected row and complete branch map remain audit
  only. Searches over writer, adapter, text-store, reader, actor, logs mounted
  to roles, caches, and final prompt bytes find zero copies.
- [ ] Exhaustive fixtures cover every legal/illegal SOURCE, LINK, PAD, and NEW
  case and every possible outcome selector. Expected ADMIT/NO_ADMISSION and
  exact output bytes match 100%.

Any compiler-authored semantic byte or provenance break is
`Z2_NONENDOGENOUS_FAIL`.

## Z3 -- exact carrier bytes and causal arms

The checker constructs, rather than accepts from the executor, each allowed
semantic difference:

| future carrier | sole semantic difference |
|---|---|
| `AUTH_OLD` | authentic atoms plus exact admitted child connection |
| `SOURCE_BINDING_TWIN_OLD` | same rows/work; presealed donor rebinding reverses the source conditional relation with equal information |
| `ATOMS_ONLY_OLD` | authentic atoms plus grounded irrelevant matched connection-slot material; no useful connection |
| `AUTH_OLD_NEW_H0/H1` | identical complete AUTH old deck plus only selected `NEW_H0` or `NEW_H1` |
| `AUTH_OLD_PLUS_PAD` | identical complete AUTH old deck plus one grounded irrelevant PAD row |

- [ ] SOURCE_TWIN preserves event identities, action/global-outcome/target
  marginals, entropy, row/view counts, token shapes, citations, and work; only
  the registered action--outcome donor binding and forced descendants differ.
- [ ] ATOMS_ONLY and PAD are truthful and gradient-bearing, not empty, masked,
  duplicated old data, or a false relation.
- [ ] All S2 old rows bind byte-identically to the accepted AUTH S1 deck. Only
  the one added slot may differ; no in-place S1 optimizer state is inherited.
- [ ] Within each triplet, initialization, device/image, optimizer, deck slots,
  masks, positions, target/input tokens, batches, updates, RNG/dropout streams,
  view/visit schedule, and work are bit-identical outside the checker-derived
  semantic bitmap.
- [ ] The ledger distinguishes evidence events, unique propositions, views,
  presentations, and source-specific optimizer encounters. Same-batch views
  count as one source-specific update; views never increase evidence or
  novelty counts. Text inserts every unique meaning once.
- [ ] Every train row has exactly one typed origin: authenticated event,
  copy-only compiler admission, registered derived-control donor transform,
  or byte-identical inherited old row. A static answer plan is never an origin.

Any undeclared byte/work difference is `Z3_CARRIER_MISMATCH` before fitting.

## Z4 -- candidate-free read and live causal machine

The sole LoRA read is:

```text
READ(query_handle) -> raw model generation -> exactly MISS or one MemoryRow
```

- [ ] The root-wide opaque query catalog is constant across goal, carrier,
  outcome, OFF, wrong-root, cut, and swap cells and has more plausible handles
  than the read budget. It reveals no live membership or semantic role.
- [ ] The actor alone sees the goal and chooses the query. The memory process
  is goal-blind and directly generates the row; no backend scans, scores,
  selects, retrieves, repairs, or copies an answer row.
- [ ] Parser grammar is closed and accepts exactly one complete row or MISS;
  malformed/extra/truncated generations remain visible adverse outputs. Strict
  ordinary generation is primary. Candidate likelihoods may be audit-only and
  can never enter the actor or choose a row/action.
- [ ] One returned row is state-local and contains no complete plan. Two
  same-start goals require different first query handles, paths, and actions.
- [ ] A broker CUT/SWAP, when invoked, transforms the already-hashed raw return
  after generation with fixed status/length/timing. It tests live mediation,
  not storage. Same-surface adapter-OFF and wrong-root test storage.
- [ ] Exhaustive BFS over ideal returns, MISS, malformed rows, all queries,
  actions, budgets, and broker interventions proves: no direct-plan solution;
  atoms are insufficient under the AUTH read budget; both old goal paths are
  reachable only with the connection; the informative action is unique; and
  delayed D is unreachable after either the old or new cut.
- [ ] Goal swap, connection swap, source-binding twin, factual outcome twin,
  old/new cuts, and old/new payload swaps have exact redirected or destroyed
  traces. No generic failure substitutes for the named intervention.

Any answer-bearing candidate at a live LoRA read is `Z4_EXTERNAL_MEMORY_FAIL`.

## Z5 -- shortcut and noninterference closure

- [ ] Direct-record/full-plan occurrence is zero in source, DREAM, training,
  text, and returned rows.
- [ ] Registered target-only, state-only, goal-label, episode-ID, query-handle,
  catalog-order, position, token-length, citation-count, recency/frequency,
  passive-signature, and proper-visible-subset predictors score at most chance
  plus `.05` in their own label space.
- [ ] Counterfactual mutations of hidden truth, future rows, expected action,
  condition, and scorer state at fixed visible bytes leave every live-role
  input/output before the causal cut byte-identical.
- [ ] Positive injected leaks in every permitted projection cross their
  registered detector floor; a negative scan without this test is invalid.
- [ ] Fixed-size padded success/MISS/malformed/cut/swap frames and logical
  release ticks are identical. Timeout/overrun ends the actor without a
  callback, exception, retry, or public continuation.
- [ ] Fresh reset removes context, KV/cache, raw events, DREAM/branch text,
  files, indexes, stores, process state, clocks, RNG continuation, and prior
  query state. Only base plus the assigned adapter enters LoRA MEMORY.

Any shortcut above its ceiling or failed injection test is `Z5_SHORTCUT_FAIL`.

## Z6 -- zero-fit CPU/gold/exact-text gates

Run four fixed, source-disjoint TEXT roots; no adaptive extension.

- [ ] Hidden legal-history/gold succeeds `>=.90`; no-memory and every shortcut
  projection remain at most chance plus `.05`.
- [ ] `TEXT_SAME_SEMANTICS` uses the identical actor query/action surface and a
  goal-blind exact lookup. It passes both old goals, goal redirection, the
  informative action, both outcome twins, and delayed factual OLD+NEW at
  `>=.90`, with strict legality `>=.95` and false-memory use `=0`.
- [ ] Connected text beats atoms-only by `>=.20` on the registered
  connection-dependent endpoint. If atoms solve it, the benchmark cannot test
  connection value.
- [ ] Each connection/old/new cut changes value from at least `.75` to at most
  `.25`, or by `>=.40` where the sealed endpoint cannot meet those anchors.
  Binding and outcome twins redirect rather than merely fail.
- [ ] All four roots pass every compiler, trace, visibility, reset, cut/swap,
  and endpoint conjunction. A failed/malformed/missing cell is not scored as a
  favorable control failure.

Any failed root yields `Z6_TEXT_ASSAY_FAIL`; do not fit around it.

## Z7 -- strong active-text certificate (paper comparison only)

Before any claim of comparison with strong memory, freeze and certify the
separate `ACTIVE_TEXT_NATIVE` system: empty branch-local start; lossless public
events plus the same admitted child-authored records; target-blind BM25 plus
declared-link PPR; four charged reads; at most 1,024 returned tokens; no
parameter update.

Require source/citation fidelity `=1`, no future/hidden/parent/wrong-root row,
byte-identical restart and insertion-order invariance, donor-store
redirection, necessary-bridge drop `>=.40`, irrelevant-store effect `<=.05`,
strict legality `>=.95`, and complete resource receipts. Its graph reader is
not inserted into a LoRA mechanism cell. Failure blocks only the paper-facing
strong-baseline comparison, but that comparison may not be run later on a
favorable subset of roots.

## One final machine-readable decision

```text
ZERO_FIT_CLOSED = Z0 & Z1 & Z2 & Z3 & Z4 & Z5 & Z6
BASELINE_CLOSED = Z7
M_DEV_ELIGIBLE  = ZERO_FIT_CLOSED
                  & separately passed candidate-free Q0 writer receipt
                  & separately passed identity-disjoint OLD/NEW receipt
```

`ZERO_FIT_CLOSED` is not writer evidence and authorizes no fit. Q0 must qualify
exact row generation, opposite conditional movement, held forms, locality,
reload, and ordinary generation. OLD/NEW must keep both banks `>=.90` and each
within `.05` of its single-bank ceiling. Until all three receipts bind the
same renderer/grammar/runtime, the terminal status is
`CLOSED_ASSAY_WAITING_WRITER`, not GO.

LoRA fits                         0
training GPU time                 0
root materializations/checks     18 roots x 2 implementations
TEXT roots                        exactly 4
ACTIVE_TEXT certificate roots     exactly 4, if Z7 is required

latency, crashes, and partial attempts. “Zero fit” never means zero compute.
No GPU-hour forecast is licensed by this checklist.
