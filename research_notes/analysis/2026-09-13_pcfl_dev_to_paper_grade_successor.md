# PCFL DEV to paper-grade successor: one combined mechanism--lifetime campaign

**Date:** 2026-09-13 UTC  
**Status:** design memo only; no source, benchmark, model, adapter, or GPU change  
**Evidence cut:** repository through `cf5308c0`  

## Verdict

If PCFL vertical DEV v2.1 passes unchanged on both roots, the shortest
paper-grade successor is **not** another sequence of writer, memory, traversal,
and lifetime pilots. Freeze the DEV mechanism and run one hierarchical
`PCFL-STREAM-16` campaign whose first cut confirms the two-SLEEP relay and
whose later cuts extend those same independent lineages.

The minimum paper-facing system comparison is only:

```text
DLT_PERIODIC       authentic child rows -> periodic LoRA SLEEP
SLEEP_FROZEN       same learner and opportunities; compile is shadowed, no write mounts
ACTIVE_LINKED_TEXT frozen actor + evolving raw/event/link text memory
```

At fixed DLT histories, add inference-only `NATIVE_CONTEXT`, `RAW_RAG`,
`ACTIVE_LINKED_TEXT`, `EXACT_WITNESSED_GRAPH`, and `NONE`, plus one terminal
`FINAL_BATCH` fit. Do not run weak RAG variants or a parenting
factorial inside this benchmark.

This can support connected carriage, traversal, knowledge-seeking expansion,
OLD+NEW reuse, finite lifetime improvement, and comparison with a strong
agent-memory system. A seven-cut conditional extension is required for the
word *plateau*. It cannot make the current 80.8 MB rank-8 LoRA physically
compressed. The only feasible compression addition is the already designed
prospective semantic-schema sidecar, reported separately from LoRA bytes.

## 1. Why this is the shortest valid route

The completed evidence does not establish the headline:

- Level-1 authored policies reach `47--48/48`, but the real-record bridge is
  optimizer-sensitive (`14/16, 8/16, 8/16` versus OFF `7/16`) and is not SLEEP.
- Q0 and the two-SLEEP public-record diagnostic learn global output habits or
  remain at `8/16`; they do not carry a keyed experiential map.
- The first contrastive screen primarily learned bare-JSON formatting and its
  polarity shortcut reconstructs the labels.
- Historical CompilerGym lives alter behavior, but the supplied routine,
  generation mismatch, repeated programs, and dialect collapse prevent a
  paper-grade lifetime inference.

PCFL v2.1 is the first design that directly binds child action, public outcome,
child-authored EVENT/LINK, two writes, candidate-free use, goal-directed
reachout, and a delayed OLD+NEW action. Rebuilding those seams on a new task
would add risk without adding a claim. The successor should repeat that exact
microcycle under fresh namespaces and add only the two missing axes: independent
lineages over lifetime and a certified strong memory opponent.

## 2. Benchmark world

### 2.1 One lineage

One scientific unit is one prospectively allocated triple:

```text
(clean child initialization, learner/training seed, world-root seed)
```

The frozen base is always the same Qwen2.5-7B-Instruct checkpoint. Distinct
decode calls, tasks, modules, checkpoints, optimizer repeats, and surface
renders are nested observations, not independent `n`.

A lineage contains a stream of fresh opaque PCFL v2.1 route modules. Every
module preserves the accepted collision cube, strict action and EVENT/LINK
grammars, candidate-free route interface, relevant-versus-distractor reachout,
and OLD/NEW deletion theorem. Identifiers and public receipts are fresh and
token-balanced. No DEV, Level-1, parenting, CompilerGym, or prior diagnostic
identity is reused.

Modules are joined only through registered cross-era tasks. A cross-era task
has a fixed-length command assembled from one early module and one newly added
module; deleting either registered subpath changes the unique correct command.
Thus route length does not grow with lifetime, while the set of possible
memories does. An exact witnessed-graph oracle must solve every task.

### 2.2 Lifetime cuts

Use five core cuts including entry:

```text
t = 0, 1, 2, 3, 4
```

The entry cut is one complete 15-assignment PCFL module: 12 OLD
(`8 EVENT + 4 LINK`) plus 3 NEW (`1 EVENT + 2 LINK`). Each later cohort adds
exactly eight fresh modules' OLD portions plus one preselected module's NEW
portion, for `8*12+3 = 99` new scheduled semantic assignments. Therefore the
core scheduled lifetime coordinates are exactly:

```text
m_sched = {15, 114, 213, 312, 411}.
```

The two optional plateau cohorts extend this to `{510,609}`. Scheduled slots,
including absent or malformed child attempts, define the common clock; also
report actually admitted assignments. Replay, paraphrase, revisits, and
optimizer steps never advance either count. Before inference, a model-free
tokenizer receipt must show that the cut-4 raw public chronology exceeds the
measured usable 16k native context while every individual task/output budget
fits. Failure is assay-invalid; the cohort size is not tuned from model results.

At every cut the fixed balanced exam has eight opportunities for each:

1. earliest-cohort retention;
2. newest-cohort acquisition;
3. unseen old--new recombination; and
4. expansion relay: useful-probe choice followed by a delayed OLD+NEW action.

The fourth component averages its eight probe decisions and eight delayed
actions before entering the aggregate. Invalid, malformed, missing, late, or
illegal actions are zero. The root score is

```text
U = (u_old + u_new + u_cross + u_expand) / 4.
```

Exactly one designated module per later cohort carries the primary expansion
relay. Its outcome is unavailable before the child's committed probe, becomes
a public receipt, is authored as NEW experience, and is tested only after the
next promoted SLEEP. No later goal is visible when the row is authored. The
terminal core cut starts no untestable new primary relay.

### 2.3 SLEEP cadence

The entry cut is the unchanged two-SLEEP PCFL relay (`S1_AUTH`, reachout,
`S2_FULL`). After each nonterminal exam, the child performs the one primary
reachout for the next cut. Each later cohort then adds its eight OLD portions
and performs one cumulative promoted SLEEP before its exam; that write includes
the preceding cut's newly obtained outcome. Consequently every claimed NEW
outcome is tested only after a write, while later cuts cost one fit rather than
two.
Every fit starts from the same clean entry checkpoint and the cumulative
accepted corpus, following the frozen PCFL v2.1 response-only, eight-view,
rank-8 recipe. This is a cumulative replacement write, not a warm optimizer
continuation.

The compiler may verify, copy, group, wrap, replay, and pack exact child spans.
It may not invent or repair a semantic field. The child-authored formation
denominator, rejected rows, canary failures, and rollbacks remain visible.

## 3. Visibility and branch isolation

All three on-policy systems begin from byte-identical, parent-free, empty-
deployment-memory snapshots. They share the sealed opportunity schedule,
potential-outcome tape, generated-token allowance, action allowance, and
addressed RNG law. After the fork they never exchange thoughts, actions,
outcomes, rows, retrieval results, adapters, or later histories.

- `DLT_PERIODIC` mounts each passing cumulative adapter.
- `SLEEP_FROZEN` runs the same child formation and deterministic compile, but
  no candidate adapter is mounted. It need not burn optimizer GPU time merely
  to simulate an invisible computation.
- `ACTIVE_LINKED_TEXT` keeps child weights frozen. Its branch-local store
  contains every raw public event and exactly the same kinds of admitted
  child-authored EVENT/LINK rows available to DLT at the same causal frontier.
  It receives no hidden graph or compiler-inferred edge.

All actors receive up to 2,048 generated tokens and the same environment-action
allowance. These are token-sufficient task budgets, not compression budgets.
Text retrieval alone is resource-calibrated as described below.

## 4. Strong memory baseline

`ACTIVE_LINKED_TEXT` is the primary opponent. Freeze it on four excluded roots:

1. exact-handle plus BM25 retrieval (`k1=1.2`, `b=.75`);
2. top-16 positive typed rows seed 20 fixed float64 PPR iterations with restart
   `.20`;
3. typed score `.5*BM25 + .5*PPR`, complete-row MMR packing `.8`, deterministic
   public-ordinal ties; and
4. queries are written by the ordinary actor and charged. There is no hidden
   LLM query rewriter, answer-aware retry, or target scan.

Calibrate seven nested access points on the excluded roots:

```text
q = {1,2,4,8} at 4096 returned tokens;
B = {1024,2048,4096} at selected q.
```

Choose the smallest setting whose doubling has a one-sided 90% upper bound
below `.05` utility and changes necessary-row recall by less than `.02`; if no
point qualifies, use `(q=8,B=4096)`. Freeze it before confirmation. The
persistent store remains unlimited.

The certificate requires `FULL_CHILD_TEXT`, `ACTIVE_LINKED_TEXT`, and
`EXACT_WITNESSED_GRAPH` to solve at least `15/16` route/expansion/delayed tasks
on at least three of four excluded roots, exact source fidelity `1.00`, binding
twin redirection `>=12/16`, necessary-memory cuts `>=6/16`, legal actions
`>=.95`, and irrelevant/wrong-root change `<=.05`. Failure blocks superiority
language; it may never become evidence that LoRA won.

## 5. Arms and fits

### 5.1 On-policy branches

Only three longitudinal branches run: `DLT_PERIODIC`, `SLEEP_FROZEN`, and
`ACTIVE_LINKED_TEXT`.

### 5.2 Fixed-history table

At entry, the middle cut, and terminal cut, freeze DLT's exact history and
evaluate disposable clones with:

```text
DLT adapter
NATIVE_CONTEXT
RAW_RAG
ACTIVE_LINKED_TEXT
EXACT_WITNESSED_GRAPH
NONE / wrong-root
FINAL_BATCH (terminal only)
```

`FINAL_BATCH` starts from the clean entry child and receives the exact terminal
DLT corpus with the same cumulative supervised target-token presentations as
all periodic writes, but shuffled into one terminal training event. This is a
temporal control, not a claimed LEAFE reproduction.

An eight-lineage, presealed sentinel subset additionally runs `S1_ATOMS` at
entry. Stored-LINK added value may be claimed only if AUTH exceeds ATOMS by
`>=4/16` on the registered endpoint with a positive paired direction. If not,
say the thinker composed connected EVENT atoms; do not call LINK storage
necessary.

### 5.3 Fit arithmetic

For the core five-cut study, each lineage uses:

```text
2 entry AUTH fits (S1 and S2)
4 later periodic cumulative fits
1 terminal FINAL_BATCH fit
= 7 fits/lineage
```

The eight-lineage ATOMS sentinel adds exactly eight fits. Thus:

| independent lineages | core fits | + ATOMS sentinel | total |
|---:|---:|---:|---:|
| 16 | 112 | 8 | **120** |
| 24 | 168 | 8 | **176** |
| 32 | 224 | 8 | **232** |
| 48 | 336 | 8 | **344** |

The strong text, context, RAG, graph, wrong-root, and frozen arms add no fits.

Profile the first entry, first cumulative, and one terminal-equivalent fit
before binding wall time. At the current PCFL conservative ceiling of
30 A40-minutes per fit, the training ceilings are `60/88/116/172` aggregate
A40-hours for `N=16/24/32/48`. Reserve an equal inference envelope, making the
planning totals approximately `120/176/232/344` aggregate A40-hours. If the
terminal-equivalent profile exceeds the envelope, reduce no scientific arm;
stop with a resource label or acquire capacity.

## 6. Units, seeds, and statistics

Start with 16 prospectively sealed lineages, no replacement. Training seeds,
world roots, and lineage IDs are unique; task/decode seeds are common-random
within each paired lineage.

At the middle cut, use only the centered (mean-free) root-paired standard
deviation of the two primary contrasts and the fixed SESOI `.05`. Select the
smallest final `N` in `{16,24,32,48}` giving at least `.80` power under a
one-sided alpha `.05` noncentral-t test; use the larger required N of the two
contrasts. If none reaches power, use 48 and let the interval decide. The rule
is frozen before any arm mean or direction is opened.

Primary estimands are root-paired trapezoidal AUC over `m` and terminal `U`:

```text
Delta_life   = DLT_PERIODIC - SLEEP_FROZEN
Delta_system = DLT_PERIODIC - ACTIVE_LINKED_TEXT.
```

Release lifetime improvement only if the authentic entry mechanism passes,
DLT has positive absolute slope and entry-to-terminal gain, `Delta_life >=.05`
on the registered primary endpoint with one-sided 95% lower bound above zero,
old retention loss has one-sided 95% upper bound below `.05`, and legality/
formation failure does not rise with lifetime.

Test strong-memory superiority second, hierarchically. Require the baseline
certificate, `Delta_system >=.05` with one-sided 95% lower bound above zero,
and a directionally positive fixed-history DLT-minus-linked-text effect. If
fixed-history does not have a positive lower bound, claim a complete-system
advantage only, not a parametric-carrier advantage.

## 7. Plateau extension and stopping rule

Five cuts establish only a finite lifetime. They never establish saturation.
If and only if the core lifetime result is positive, text has a plausible flat
late window, and exact-graph headroom is still `>=.10`, add two presealed
novelty cohorts to the same lineages. This gives seven total cuts and two extra
periodic fits per lineage. No new baseline fit is needed; `FINAL_BATCH` moves
to the new terminal cut.

Call only this exact frozen text configuration a **practical local plateau**
when all hold:

- new unique evidence entered every interval;
- simultaneous two-sided 90% intervals for its late slope and last two gains
  lie inside `[-.05,+.05]` utility per cohort;
- the presealed doubled-access sensitivity also meets that equivalence rule
  and changes terminal utility by at most `.05`;
- retention passes and graph headroom remains `>=.10`; and
- DLT's late slope, anchor-to-terminal gain, and paired slope advantage each
  have positive one-sided 95% lower bounds, with terminal advantage `>=.05`.

The seven-cut fit totals become `152/224/296/440` for N
`16/24/32/48`, including the eight ATOMS fits. At 30 A40-minutes/fit, training
ceilings are `76/112/148/220` A40-hours; the approximate full planning envelopes
are `152/224/296/440` A40-hours.

Stop globally on invalid zero-fit ceilings, leakage/custody failure, or
resource exhaustion. Stop a lineage's promoted path at an unsafe write, but
retain it as failure in intention-to-treat. Do not replace a root, tune a
prompt on confirmation, extend a flat learner, or call a resource-limited text
configuration universally saturated.

## 8. Compression: the only honest near-term addition

The main campaign tests **compiled connected experiential knowledge**, not
physical compression. Rank-8 currently serializes to about 80.8 MB, far larger
than a PCFL life. Adapter rank, zero returned memory tokens, shorter DREAM
text, or a fixed parameter count is not a compression result.

After the core connected-utility gate passes, attach the already specified
prospective schema assay to disposable, quarantined roots paired with the first
16 lineages:

- the child executes eight ordinary mappings and observes their public
  outcomes;
- before any later mapping is visible, it commits either `NO_SCHEMA` or one
  affine schema over the fixed `103680`-state PCFL permutation space;
- structured and independent continuations preserve descriptors, marginals,
  lengths, and the first eight observations;
- deterministic residual coding charges schema choice, keys, statuses,
  exceptions, indexes, provenance, and checksums;
- exact decoders reconstruct the registered semantic object at
  `K={4096,16384}`; and
- the compact code is evaluated through the same frozen text interface; and
- one fresh `SCHEMA_LORA` fit per root writes only the admitted compact code,
  then candidate-free structured/independent, adapter-off, and wrong-root
  probes test whether that same code is accessible through LoRA.

Require zero semantic/false-row distortion, both plain and zstd-coded rate
ratios `<.80` at both loads, noninferior utility within `.05`, failure to
compress the independent continuation (`ratio >=.95`), wrong-root/schema-swap
failure, and prospective schema accuracy `>=.99` structured / `<=.01`
independent.

This permits: **the child selected a shorter useful semantic code from a
supplied schema language, and the admitted schema was behaviorally accessible
through its ordinary sleep carrier.** It does not permit: the LoRA is
physically compressed, the child invented the schema family, or the whole
agent state is smaller than text. If this sidecar fails, remove *compressed*
from the contribution while preserving any valid main-campaign result.

The sidecar adds exactly 16 fits and, under the same 30-minute ceiling, 8
aggregate A40-hours of training plus at most 8 A40-hours of inference. It is
never allowed to write back into or select a main lifetime lineage.

## 9. Fatal path

The actual shortest path is therefore:

```text
PCFL DEV both roots pass
  -> four-root strong-text/world certificate
  -> first 16 combined confirmation/lifetime lineages
  -> blinded N decision
  -> finite lifetime + strong-memory result
  -> only then seven-cut plateau extension and semantic-schema sidecar
```

Do not serialize this behind parenting or more Level-1 proxy tests. Conversely,
do not start it if PCFL DEV cannot form exact child rows, carry them after
reset, choose the relevant probe, and use OLD+NEW in both roots. That failure
would make a long lifetime an expensive repetition of a broken seam.
