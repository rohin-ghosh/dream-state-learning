# Interleaved memory/rehearsal three-seed terminal post-audit (2026-09-12)

## Verdict

This is the first clean positive **small writer/coexistence ingredient** in the
current diagnostic series.  When each optimizer batch mixed distinct authored
memory sources with distinct arithmetic-rehearsal sources, a rank-8 adapter
could acquire and extract all or nearly all 16 key--color facts while retaining
the old arithmetic action on three of three optimizer seeds under the
`FOUR_VIEW` recipe.

It is not a qualified selective writer, endogenous DREAM/SLEEP, parenting,
connected memory, or lifetime learning result.  The facts were authored and
supplied; all children were warm-started; the same 16 facts were tested through
new wordings; and the only old-skill panel was the rehearsed arithmetic task.

## Exact terminal counts

All memory denominators below concern the same 16 facts.  The three lexical
families are held phrasings of those facts, 16 requests per family.  “Old
action” is the fixed 32-item arithmetic panel and requires the correct `ACT`,
not merely valid marker syntax.

| optimizer seed / arm | dev memory | exact memory | held lexical | old action |
|---|---:|---:|---:|---:|
| seed 0 `SINGLE_VIEW` | 16/16 | 16/16 | 48/48 | 32/32 |
| seed 0 `FOUR_VIEW` | 16/16 | 16/16 | 48/48 | 32/32 |
| seed 1 `SINGLE_VIEW` | 16/16 | 15/16 | 47/48 | 32/32 |
| seed 1 `FOUR_VIEW` | 15/16 | 15/16 | 45/48 | 32/32 |
| seed 2 `SINGLE_VIEW` | 4/16 | 5/16 | 12/48 | 0/32 |
| seed 2 `FOUR_VIEW` | 16/16 | 16/16 | 48/48 | 32/32 |

Every captured response was parser-valid and below the 64-token cap.  Seed-2
`SINGLE_VIEW` did not merely lose formatting: it emitted valid `PREDICT` and
`ACT` fields but the arithmetic answers were wrong on 32/32 cases.

The preregistered joint `FOUR_VIEW` thresholds were met on all three seeds.
This supports recipe robustness over these three optimizer/parent seeds.  It
does not make three independent fact banks or task worlds: every seed learned
the same 16 authored facts and used the same readout identities.

## What changed relative to the failed grouped run

The immediately preceding grouped diagnostic used the same 16 memory sources,
16 arithmetic sources, source multiplicity, 10 epochs, 320 updates, rank 8,
and learning rate `3e-4`.  But all four copies/views of one source occupied one
mean-loss batch.  It therefore exposed each fact to only ten source-specific
Adam steps.  Both grouped arms extracted only 4/16 memories, and grouped
`SINGLE_VIEW` destroyed arithmetic (0/32).

The interleaved schedule instead placed two distinct memories and two distinct
arithmetic sources in every batch.  Each source was presented 40 times across
320 updates while every update mixed new memory with old behavior.  Under this
schedule both root-0 arms reached 16/16 memory and 32/32 arithmetic.

The defensible inference is:

> At this 16-fact load, optimizer-batch source composition was a binding
> variable.  Distinct-source interleaving enabled supplied-fact acquisition,
> held-wording extraction, and coexistence with one rehearsed old action.

The evidence does **not** show that four phrasings are always required.
`SINGLE_VIEW` tied or exceeded `FOUR_VIEW` on seed 0 and seed 1, then failed
catastrophically on seed 2.  The three-seed pattern supports a directional
claim that varied views improved robustness (`3/3` joint successes versus
`2/3`), not universal recall superiority or a semantic-view mechanism.

## Important bounds

1. **Supplied, not lived.** The 16 key--color bindings were authored training
   material, not selected or compiled from the child's action--outcome ledger.
2. **Warm-started.** The three parents already scored 4/16, 7/16, and 3/16 on
   the development memory panel.  There was no fresh contemporaneous OFF
   child in the replication pair.
3. **Extraction, not composition.** New lexical cues queried the same atomic
   bindings.  No relation was connected, traversed, or used to infer a novel
   action.
4. **One rehearsed locality surface.** Arithmetic was explicitly mixed into
   every fit.  Preserving it does not prove locality on unseen native actions,
   copy behavior, wrong-root prompts, or the broader output distribution.
5. **Views were not input-token matched.** Target-token and padded-slot budgets
   matched, but `FOUR_VIEW` used slightly more input/context tokens.
6. **Small seed count.** Three optimization seeds are enough to reject the
   prior “this recipe never stores” diagnosis, not to estimate a stable effect
   size for lexical diversity.

## What this unblocks

It justifies the already-running bounded sequential OLD/NEW test as a writer
ingredient test: add two new authored banks over two updates and ask whether
explicit replay preserves old facts while new facts are acquired.  That test
must remain labeled fixed-budget allocation because the replay arm spends
part of its memory dose on old facts while the comparator doubles the new-fact
dose.

It does not release M-core or the lifetime headline.  A paper-bearing writer
still needs selective action change with non-cancelling locality tests, then a
candidate-free endogenous two-sleep relay.  The interleaved result tells us
how to make supervised material coexist; it does not yet show that the agent
can decide what its own experience means and write only the useful consequence.
