# Minimum authentic bridge from the fixed-render carrier ceiling to connected M

**Date:** 2026-09-13 UTC

**Role:** fresh independent paper-design audit

**Scope:** research design only. I changed no builder source, test, benchmark,
model, tokenizer, adapter, lineage, job, or GPU state.

## Verdict

An `E0-r` pass should qualify only the **prepared-material carrier**: a fixed
writer can store, generate, causally redirect, and expose mechanically rendered
event records. Its adapter must never seed the claim-bearing child.

The minimum authentic continuation is not another atomic fitted rung. It is a
fresh six-fit-per-root `M-CAB` microcycle in which the child itself emits typed
`EVENT` and `LINK` commitments, those exact bytes are the only life-specific
training targets, the compiler only verifies/replays/packs, and later behavior
requires the semantic content of both record types. A second SLEEP adds one
unpredictable child-authored event and two child-authored links; a delayed goal
then requires old organization and the new event together.

```text
child ACT -> public outcome -> child EVENT
                              -> child LINK
                              -> SLEEP 1
                              -> goal-conditioned local reads and traversal
                              -> child chooses target-relevant experiment
                              -> unpredictable public outcome
                              -> child COMMIT_EVENT + COMMIT_LINKs
                              -> SLEEP 2
                              -> sterile delayed OLD+NEW action
```

This is the shortest route that restores the provenance removed by `E0-r`
while giving each paper word a separate necessity test:

- `EVENT`: coherent event-map rebinding redirects recalled facts and actions;
- `LINK`: link permutation redirects traversal while EVENT recall stays fixed;
- `goal-conditioned`: a goal swap changes the query path and route;
- `expansion`: a balanced, pre-outcome-unpredictable result adds a new event
  and new links during SLEEP 2;
- `OLD+NEW reuse`: removing either an old returned dependency or the new
  returned dependency destroys the delayed solution;
- `two sleeps`: the second cumulative write is compared with an equal-work
  old-replay write and must retain the first-sleep routes.

Do not require M to beat text memory to release its mechanism claim. Run the
strongest text and witnessed-graph systems beside it and allow them to win.
Parametric-memory superiority and saturation remain lifetime-`L` claims.

## 1. Why `E0-r` cannot be inherited

`E0-r` has endogenous factual payload but exogenous serialization. The child
emits the action, the world emits the outcome, and a fixed researcher renderer
decides that these bytes become:

```text
EVENT <handle> AT <scene> DID <action> GOT <outcome>
```

That is an excellent upper-bound calibration for the writer. It is not the
model preparing its own material, which is the repository's boundary between
`trained` and `learned`. Therefore:

1. rename an E0-r pass as `DEV_E0R_FIXED_RENDERED_EVENT_CARRIER_PASS`;
2. keep the fitted E0-r adapters permanently outside every adult lineage;
3. carry forward only frozen *mechanism bytes*: writer recipe, target masking,
   reader interface, dose, lifecycle checks, and custody;
4. start M from the same clean pre-benchmark child checkpoint, not an E0-r
   adapter; and
5. require exact child-authored semantic targets in every authentic M fit.

The authentic M path may use the same grammar as E0-r. A schema is an
interface, not a thought. The decisive fact is that the child emits every
semantic argument and the compiler never fills one in.

## 2. Exact thinker/compiler boundary

Use ordinary decoding and a strict one-line typed commitment surface aligned
with the qualified E0-r row shape:

```text
EVENT <event_id> AT <source> DID <port> GOT <destination>
LINK <link_id> FROM <event_id_1> THEN <event_id_2>
```

The child sees only its public action receipt and outcome when it commits an
event. It sees only previously accepted public events when it proposes a link.
The later route goals are absent. No candidate link bank, future path, score,
hidden graph, or expected answer is visible.

The compiler may:

- verify chronology and exact receipt support;
- verify that `destination(event_1) == source(event_2)`;
- accept or reject the complete child span under frozen rules;
- copy exact accepted bytes;
- select, order, group, shuffle, replay, and pack those bytes;
- add fixed request-side wrappers and mask non-child targets; and
- attach non-target audit hashes and evidence identities.

It may not repair syntax or semantics, canonicalize a field, render an event
from a receipt, infer a missing endpoint, choose link endpoints, paraphrase a
target, add a prospective action, or use a future goal or score to select a
memory. Rejected proposals remain in the formation denominator. Parent text,
checker prose, synthetic control rows, and fitted E0-r rows never enter an
authentic target.

This deliberately tests **scaffolded self-preparation**, not spontaneous
memory initiation: the harness may ask the child to commit after an event and
may define the grammar. The maximum claim must say so.

### Authorship versus causal necessity

Do not add a “researcher typed the identical correct row” arm to prove
authorship. If the bytes and information are identical, that contrast has no
identified semantic treatment. Authorship is a provenance fact proved by raw
generation bytes, chronology, and target-span hashes.

Causal necessity concerns the *content* of those child-authored rows. Test it
with interventions on event bindings and link bindings, plus read-time cuts.
A wrong-child/wrong-root control is still required for lineage isolation, but
it is not an authorship ablation.

## 3. Minimum opaque route world

Use independently generated pair-roots. Each pair-root has two counterfactual
twins with byte-identical public history until one frontier outcome. Opaque
identifiers, token lengths, ordering, action frequencies, endpoint degrees,
and target marginals are balanced before semantic assignment.

One compact root contains:

- eight old child-executed events: two two-edge routes from a shared start,
  two alternate-start upstream events needed only by the delayed task, and two
  already witnessed downstream tail events;
- four true old event-to-event connections;
- two equal-entropy frontier experiments, only one relevant to the revealed
  goal;
- one new frontier event selected by the public outcome; and
- two new links joining that event to the old upstream and downstream memory.

No complete route appears in an episode or target. Old goals are revealed only
after SLEEP 1. The reachout goal is revealed only after SLEEP 1. The delayed
start, target, complete route, and answer surface are revealed only after
SLEEP 2.

### Model-free information certificate

Before model work, the generator/checker must certify these exact variables:

1. Let `T_pre` be every model-visible byte before the frontier outcome and
   `B in {0,1}` the twin binding. The twins have byte-identical `T_pre`, are
   balanced, and `H(B | T_pre) = 1 bit` over the frozen root population.
2. Both permitted frontier tests have one bit of ordinary outcome entropy:
   `H(Y_relevant | T_pre) = H(Y_irrelevant | T_pre) = 1 bit`.
3. For the current goal variable `G`, the relevant test has one bit of
   target-relevant information and the distractor has zero:
   `I(Y_relevant; Z_G | T_pre,G)=1`,
   `I(Y_irrelevant; Z_G | T_pre,G)=0`, where `Z_G` is the missing route fact.
4. Every true old `LINK e_i THEN e_j` is chosen from at least four
   type/age/token-matched possible `e_j` handles. Identifier, order, frequency,
   and nearest-position policies are at most `1/4`; only event semantics reveal
   the compatible endpoint.
5. The delayed correct action is a deterministic function of an old route
   dependency and `B`. Flipping either registered dependency flips the answer;
   neither the old graph alone nor the new event alone identifies it.

These are generator truths, not empirical scores and not model judgments.
Two independent CPU implementations must reproduce them over all DEV and CONF
roots before a fit.

## 4. Formation gate: part of M, not a new fitted rung

Run one disposable formation-only preparation root before M development. It
costs inference but no fit and may tune only the typed interface. Once it
works, freeze the prompt/parser before the two M DEV roots.

For every scored M root:

- all eight old event commitments must be exact, chronological, and supported;
- all four required old link commitments must be exact and supported;
- child LINK precision over all proposed links must be at least `.80`;
- all rejected or malformed attempts remain in the denominator;
- after the reachout outcome, the new event must be `1/1` exact and both new
  links `2/2` exact; and
- every accepted target byte must hash to a child generation span.

Any missing critical record makes the root incomplete. Label old formation
failure `M_CHILD_OLD_FORMATION_FAIL` and post-outcome failure
`M_CHILD_NEW_FORMATION_FAIL`; neither is writer evidence. Do not substitute a
fixed renderer in a claim-bearing root. If interface tuning is required after
seeing a DEV formation outcome, version it and restart DEV from new roots;
never repair a CONF child output.

## 5. SLEEP 1: three fits, two distinct causal questions

Train three fresh rank/dose-identical states from the same clean child bytes.
The precise writer constants are inherited only after E0-r qualifies them.

```text
S1_AUTH
  exact accepted child EVENT bytes + exact accepted child LINK bytes

S1_EVENT_TWIN
  same row counts and LINK handle graph, but a prospectively fixed coherent
  alternative map fixes the public start/goal roster while rebinding matched
  EVENT port/destination fields and preserving every token marginal, row
  length, degree, and link validity

S1_LINK_PERMUTE
  exact authentic child EVENT bytes; a fixed-point-free, degree/type/age/
  token-matched permutation changes only LINK target handles
```

The two synthetic arms are controls and cannot enter a lineage. They must
match AUTH in target tokens, optimizer units, updates, initial tensors,
optimizer state, dropout RNG, and row order; only the registered semantic
fields differ.

After a fresh reload, the goal-directed actor can make local requests such as
`READ EVENT <handle>` and `READ LINK <event_handle>`. The memory worker sees
only the one local request selected by the actor, never the whole task, raw
history, row candidates, scorer, or hidden graph. A public identifier copied
into an actor-authored request is allowed; giving the memory worker the task
prompt or answer is not. Every memory output is raw candidate-free generation.

### SLEEP-1 engineering gates per root

Use fixed paraphrase/order variants as repeated technical probes, not as
independent samples.

- `EVENT` read: at least `14/16` exact and `15/16` valid under each arm's own
  map; the three arm scores differ by at most `1/16`.
- `LINK` read: each arm returns at least `7/8` exact and valid under its own
  map.
- Across eight unseen-address and eight wrong-root requests, at least `15/16`
  produce an exact `MISS` or registered non-row refusal and `0/16` produce a
  usable false row. If a shared
  birth adapter teaches `MISS`, report that supplied interface contribution
  separately and never mix life-specific `MISS` targets into M.
- On 16 frozen route questions, AUTH solves at least `14/16` and at least
  `7/8` per goal branch.
- AUTH exceeds both EVENT_TWIN-under-authentic-scoring and LINK_PERMUTE by at
  least `4/16` on their registered dependency endpoints.
- EVENT_TWIN follows its coherent alternate map on at least `12/16`; LINK
  permutation follows its registered wrong traversal on at least `12/16`.
  Redirection, rather than malformed collapse, is required.
- Across eight paired goal swaps, the correct complete route changes at least
  `7/8`, and the actor's query trace diverges by its second local read at least
  `7/8`.
- Returning `MISS` for the critical LINK from the already generated AUTH read
  trace drops route success by at least `6/16`. This zero-fit read cut is the
  explicit no-link necessity check.

If AUTH and an atoms/no-link view perform equivalently, the child may be
composing events during THINK. That can earn a composition result, but not
“stored child-authored connection added value.”

## 6. Reachout and SLEEP 2: three more fits

Discard all SLEEP-1 evaluation forks and restore the exact pre-evaluation AUTH
state. Reveal one reachout goal. Give the child one frontier experiment. Across
eight fixed wording/order variants, require at least `7/8` choices of the
target-relevant frontier; count every invalid, irrelevant, or missing action as
zero. Both frontiers have equal global entropy, so this is not generic novelty
seeking. Relevant choices carry one registered bit and distractor choices zero;
the required mean target-relevant information gain is therefore at least
`.875` bits.

Fork the pre-outcome state into the two counterfactual twins. Each returns its
ordinary public outcome; each child branch then commits its own exact new EVENT
and two new LINK rows before the delayed goal is visible.

From the same clean child checkpoint, train:

```text
S2_FULL_t0 = exact authentic OLD union exact child NEW_t0
S2_FULL_t1 = exact authentic OLD union exact child NEW_t1
S2_OLD_REPLAY = exact authentic OLD plus an equal-target-token, presealed
                replay of exact old child rows; no NEW semantics
```

SLEEP 2 is a cumulative clean-base write, not adapter averaging. The two FULL
fits have identical work and differ only in the child-authored public-outcome
branch. OLD_REPLAY controls the extra sleep/update opportunity. Cross-mounting
the two FULL states on the opposite twin is the new-binding intervention and
costs no additional fit.

### SLEEP-2 engineering gates per root

- All critical old EVENT/LINK held reads remain within `1/16` of S1_AUTH;
  all three new rows are exact on at least `5/6` held reads, with every
  required new semantic class represented.
- Old route success after each FULL write is within `1/16` of S1_AUTH.
- On 16 delayed questions per twin, each FULL state solves at least `14/16`,
  with strict action legality at least `15/16`.
- Each FULL state exceeds OLD_REPLAY by at least `4/16`.
- Cross-mounting `FULL_t0` and `FULL_t1` redirects to the donor binding on at
  least `12/16` paired items rather than producing invalid actions.
- From sealed AUTH memory returns, replacing the one registered old-link
  return with `MISS` drops delayed success by at least `6/16`; replacing the
  new-event return with `MISS` also drops it by at least `6/16`. These cuts
  establish that the final action consumed both old organization and new
  experience without two additional `NEW_ONLY` fits.
- Wrong-root memory, OFF, ID/order/frequency policies, and a fixed nonadaptive
  route remain at chance plus `.05`; false-memory use is zero.

The interface cuts prove necessity of the retrieved old and new content, not
that no trace of either exists elsewhere in the weights. State that limit.
If a stronger parameter-level decomposition is later needed, add NEW_ONLY and
wrong-OLD fits after the six-fit experiment; do not pay for them before the
minimum chain works.

## 7. Strong textual and task-native controls

Certify these before M fitting on four excluded zero-fit route roots. If the
strong systems cannot solve or the cuts do not work, repair the assay rather
than training around it.

1. **FULL_CHILD_TEXT.** Put every exact admitted child EVENT and LINK row,
   with citations, into the actor context. At M scale this is the strongest
   lossless text ceiling and avoids a retrieval-quality excuse.
2. **ACTIVE_LINKED_TEXT.** Store the same raw public events and exact admitted
   child rows in a frozen typed index/graph retriever. Queries are actor-
   authored; return complete cited rows. Freeze reads/tokens from an excluded
   `1/2/4/8`-read and `1024/2048/4096`-token ladder at the smallest point where
   doubling changes value by at most `.05`.
3. **RAW_EPISODIC_RAG.** Store complete public action/outcome episodes only;
   use exact typed matching plus BM25 and the same charged actor query budget.
4. **EXACT_WITNESSED_GRAPH.** Add only publicly observed edges and permit a
   native exact graph planner. This is a task-native reference allowed to win.
5. **NONE/OFF, NATIVE_CONTEXT, WRONG_ROOT.** Keep the no-personal-memory floor,
   full raw chronology while it fits, and independent-life control.

FULL_CHILD_TEXT, ACTIVE_LINKED_TEXT, and EXACT_WITNESSED_GRAPH must each solve
at least `15/16` route, reachout, and delayed endpoints on at least three of
four zero-fit roots. Link/old/new bridge cuts must each reduce the designated
endpoint by at least `6/16`; goal and outcome swaps must redirect the action;
source/citation fidelity is `1.0`; hidden/future/wrong-root material is zero;
insertion-order and restart rebuilds are identical; action legality is at
least `.95`.

Give linked text the same child-authored organization as DLT. Withholding LINK
rows would fake a substrate gain by comparing two compilers. Report every
system side by side in M, but make **no DLT-over-text release gate here**. The
eventual lifetime comparison must use ACTIVE_LINKED_TEXT as the primary strong
opponent, plus same-history carrier analysis and a final-batch LoRA temporal
control.

## 8. Root units, staging, and GPU economy

The root, not the prompt, twin, decode seed, or technical fit seed, is the
scientific unit.

1. **E0-r carrier ceiling:** one permanently excluded root, two fits, maximum
   two A40-hours under its existing proposed cap. Pass freezes writer/reader
   mechanism bytes only.
2. **World/text closure:** four excluded roots, zero fits. Two independent CPU
   generator/oracle implementations plus the baseline checks above.
3. **Formation dry run:** one further excluded root, model inference only.
   Freeze the child commitment prompt/parser afterward.
4. **M development:** exactly two new pair-roots, `2 x 6 = 12` fits. Both must
   meet every noncompensatory gate. Profile one actual S1 and one actual S2 fit
   before binding the campaign wall/resource cap.
5. **M confirmation:** freeze all bytes, then eight untouched independent
   pair-roots, `8 x 6 = 48` fits, with no replacement. Require at least `7/8`
   roots to receive `COMPLETE_M_CAB`.

The complete path after E0-r is 60 small fits. At the repository's historical
planning anchor of 7.5--15 A40-minutes/fit this is 7.5--15 aggregate A40-hours
before inference and audits; that anchor is not a commitment. Set the hard cap
from the first profiled M root, then parallelize across roots, never within a
root's temporal SLEEP dependency.

For `7/8` complete roots, the exact one-sided sign tail against
`Pr(COMPLETE_M_CAB) <= .5` is `9/256 = .0352`. Report that and the full
root-level vector; do not treat the 16 prompt variants, two twins, or repeated
reads as independent observations. This confirms one fixed child/mechanism
over fresh worlds, not a population of children.

## 9. Noncompensatory root endpoint and failure interpretation

`COMPLETE_M_CAB=1` only if formation, source custody, S1 event read, S1 link
read, coherent event redirection, link redirection, both goal traversals,
target-relevant reachout, S2 new formation, OLD retention, NEW redirection,
OLD+NEW cuts, sterility, legality, and all information/visibility checks pass.
No mean score may compensate for a failed seam.

Use the first applicable label:

- `M_ASSAY_INVALID`: exact text/graph ceiling, generator entropy, shortcut, or
  cut logic fails; repair without reading a LoRA result.
- `M_CHILD_OLD_FORMATION_FAIL`: the child did not prepare grounded old EVENT
  or LINK material; this is a birth/parenting/articulation gap, not a writer
  null.
- `M_S1_EVENT_NOT_CARRIED`: child EVENT rows do not survive candidate-free
  write/read.
- `M_S1_LINK_NOT_CARRIED`: EVENT rows survive but LINK rows do not.
- `M_EVENT_BINDING_NOT_CAUSAL`: coherent event twin does not redirect.
- `M_LINK_NOT_BEHAVIORALLY_NECESSARY`: links read correctly but AUTH does not
  beat/redirect against LINK_PERMUTE and the no-link cut.
- `M_GOAL_TRAVERSAL_FAIL`: local rows exist, but different goals do not cause
  correct different query paths/routes.
- `M_REACHOUT_FAIL`: stored structure is available but the thinker does not
  choose the target-relevant experiment; this is chiefly a THINK/birth gap.
- `M_CHILD_NEW_FORMATION_FAIL`: the child observes the new bit but does not
  prepare the new event/link material.
- `M_S2_NEW_NOT_CARRIED`: the new child rows are formed but absent after S2.
- `M_S2_OLD_FORGOTTEN`: new rows survive but old routes/rows regress beyond the
  bound.
- `M_OLD_NEW_REUSE_FAIL`: old and new rows are readable, but the delayed action
  does not use both.
- `M_UNSAFE_OR_NONREPORTABLE`: leakage, wrong mount, warm cache, missing
  denominator, selected checkpoint, retry, tensor/count/replay mismatch,
  teardown failure, or root replacement.

An E0-r miss closes only that declared fixed-render writer recipe. Rohin's
latest steer requires a newly motivated prospective recipe rather than a
negative-paper pivot; it does not permit relabeling or tuning a failed root.
Likewise, an M development miss should localize the responsible layer and
motivate a newly versioned repair on fresh DEV roots. It must not lower the
gate, repair a child row, or replace a failed confirmation root.

## 10. Strongest allowed claim

If at least seven of eight untouched confirmation roots pass unchanged:

> In a fixed opaque route-world family, one model's own executed actions and
> public outcomes were converted by that model, under a typed scaffold, into
> grounded event records and connections before later goals were visible.
> Two LoRA consolidation cycles made the records generatively addressable
> without candidates after reset. A clean goal-directed thinker traversed the
> remembered connections, selected the uniquely target-relevant experiment,
> added its unpredictable outcome through a second child-authored write, and
> solved a delayed task requiring both old organization and new experience.
> Coherent event rebinding, link permutation, outcome twins, and old/new cuts
> redirected or removed the corresponding behavior across fresh worlds.

This does not establish spontaneous memory formation, indefinite continual
learning, a population of children, physical compression, parenting benefit,
or superiority over text memory. Those remain the lifetime and developmental
experiments.
