# PCFL full-thesis construct-validity audit

**Date:** 2026-09-13 PT  
**Role:** skeptical ML reviewer  
**Scope:** read-only scientific/design audit; no benchmark source, runtime,
model, tokenizer, training, adapter, parenting, GPU, result, or claim change  
**Evidence cut:** repository through `df6565ff`

## Executive verdict

PCFL is a good **mechanism-localization micro-world**. Its collision cube,
opaque identifiers, action-before-outcome chronology, OLD/NEW cuts, wrong-root
controls, and candidate-free native endpoint are unusually careful. A passing
two-SLEEP vertical could establish a bounded fact that has not yet been shown:
a child can emit grounded records from its own public experience, carry them
through a LoRA reset, use them to choose one useful experiment, add its outcome,
and later act using OLD and NEW information together.

PCFL in its current executable/design state cannot support the full paper
objective. This is not because it lacks more gates. It is because four of the
headline constructs are still represented by narrower substitutes:

1. the current formation path either filters the child's connection choice
   through a hidden preselected bank or exposes the bank and thereby lets the
   harness choose the connection;
2. repeating one small opaque topology tests keyed storage and interface
   learning, not reusable/compressed experiential structure;
3. the planned lifetime comparison does not yet separate personal semantic
   memory from generic training on a repeated memory dialect; and
4. the only implemented `ACTIVE_LINKED_TEXT` is a supplied exact-address
   ceiling, while the strong evolving memory opponent and its saturation curve
   remain specifications.

The right decision is **keep PCFL, narrow what its first vertical is allowed to
prove, and make four small high-information additions before paper-scale
execution**. Do not replace it with a larger world or start the 16--48-lineage
campaign yet.

## 1. Authoritative current state

The distinction between design and evidence is presently decisive.

- `organism_v6/pcfl_vertical_dev.py` implements the CPU world, record/query
  representation, cuts, controls, and scripted fixtures.
- `gpu/astra_pcfl_vertical_dev.py` still labels itself
  `SCRIPTED_TEST_ONLY`, rejects production construction with
  `NATIVE_BINDING_UNIMPLEMENTED`, initializes all learned stages as
  `NOT_IMPLEMENTED`, and fixes `scientific_pass=False`, `native_ready=False`.
- The original zero-fit run is unusable as science because finalization failed;
  its raw outputs nevertheless exposed an undisclosed READ grammar and the
  absence of the promised THINK channel.
- `2026-09-13_pcfl_c0_dev_interface_repair_v2_closure.md` is a credible
  prospective repair, but it is documentation, not an executed ceiling.
- The two PCFL own-write formation attempts ended on the first EVENT boundary.
  There is no complete authentic PCFL bank, fit, or cold readout result.
- `ACTIVE_LINKED_TEXT` in current code is a supplied exact-address service. The
  BM25 + typed-graph PPR + MMR evolving baseline exists only in design notes.
- `PCFL-STREAM-16`, the reusable-structure stratum, the powered lifetime panel,
  and the predictive-reuse/compression sidecar are all prospective.

Accordingly, there is currently **zero paper-grade PCFL evidence** for own-write
carriage, connected use, expansion, lifetime learning, compression, or memory-
baseline superiority. The current outputs are valuable engineering evidence,
not a weak positive result.

## 2. Severity-ranked construct findings

### FATAL 1 — connection authorship is not valid under the current required-bank formation

The full thesis requires the agent to turn its experience into connected
knowledge. Current own-write formation preselects exact EXPLORE actions and
exact LINK pairs. A model-generated link is accepted only when it matches that
hidden bank. This creates a two-sided validity problem:

- if the assignment remains hidden, success is conditional on guessing the
  harness's selected connection/order; the harness filters which child
  connection counts;
- if the assignment is disclosed, formation becomes controlled transcription
  of a connection selected by the harness.

Either form is valid for a narrow writer diagnostic. Neither establishes that
the child selected or formed the useful connection from its experience.

This can be repaired without changing the world. The OLD bank already has
exactly four valid directed adjacent EVENT pairs and the NEW bank exactly two.
Freeze the admissibility rule before generation, allow those pairs in any
child-chosen order without replacement, bind each fresh child-supplied LINK ID
to the valid pair it actually names, and require set completion rather than one
hidden ID-to-pair permutation. Future tasks depend on EVENT semantics, not on a
secret structural `l0..l3` ordering. Controls can be deterministically derived
from the sealed actual bank after admission without repairing any child field.

If this dynamic-order repair is not made, use only:

> controlled child-emitted records from a harness-selected curriculum

and remove autonomous connection-formation language.

### FATAL 2 — the opaque repeated world cannot support the intended strong-memory superiority claim

Fresh opaque PCFL modules are excellent adversarial tests of exact keyed
retention. They contain no cross-module regularity for a parametric learner to
amortize. A lossless text/graph store should be the correct carrier for hundreds
of independent exact bindings. If DLT beats it only after text access is capped,
the result can be explained as a resource/API intervention, not superior
experiential intelligence.

Therefore the paper-scale benchmark needs the already proposed, prospectively
fixed **reusable-structure stratum**. It must contain new identifiers and
withheld target relations whose outcomes follow a learnable relation across
prior modules. Both DLT and text receive the same source experiences; no exact
target row exists for either. `FULL_SOURCE_TEXT` must fit and be run on the
reuse assay so a retrieval miss cannot manufacture parametric reuse.

If that stratum is not implemented before confirmation, PCFL can still support
an honest storage/retention paper, but O8 must be bounded to:

> comparison with one named memory configuration on independent opaque
> bindings

It cannot support a broad claim that LoRA outgrows strong agent memory.

### FATAL 3 — current PCFL does not yet field a strong external-memory baseline

The implemented `ACTIVE_LINKED_TEXT` uses a fixture-built exact request table.
It asks whether the actor can operate a supplied-memory service; it is a ceiling
and interface qualification, not an evolving agent-memory opponent.

The planned unlimited branch-local raw+typed store, BM25 + graph-PPR ranking,
adaptive actor-written queries, citations, and restart/insertion invariance is
a credible **named PCFL baseline**, but it remains unimplemented and
uncertified. No superiority language is available until it:

1. receives all eligible public events and admitted child rows at the same
   frontier as DLT;
2. passes a zero-fit ideal-text certificate on fresh, excluded roots;
3. is evaluated both on-policy and on the exact DLT history at every claimed
   cut; and
4. reports its full access-response curve through `q=16, B=8192`.

If the maximum still improves, call it `MAX_TESTED_ACCESS`, not saturated.
“Saturation” additionally requires the registered longer lifetime and doubled-
access equivalence result. A failure of the baseline certificate invalidates
the comparison; it is never evidence in favor of LoRA.

### FATAL 4 — there is no executable end-to-end object yet

The C0 repair, native formation, writer, S1/S2 endpoints, evolving text
baseline, lifetime campaign, and reuse assay are presently split across code
stubs and design memos. The core runtime explicitly stops before production
native dispatch. A paper claim cannot be assembled by combining successful
CPU fixtures with unrelated LoRA diagnostics.

The next end-to-end object should remain the small two-root DEV vertical. Do
not launch the expensive stream until one unchanged root can cross, in order:

```text
clean-base interface ceiling
-> authentic formation
-> cold local/native carriage
-> connection causal contrast
-> useful pre-outcome probe
-> authentic NEW formation
-> second write, OLD retention, delayed OLD+NEW action
```

### HIGH 1 — lifetime gain can be generic dialect/algorithm post-training rather than personal memory

`DLT_PERIODIC - SLEEP_FROZEN` changes both semantic memory and the amount of
training on repeated EVENT/LINK/query formats. In a stream built from the same
small topology, an adapter may learn “how PCFL answers look” or a generic route
routine without retaining its own root-specific experience.

Two low-cost controls close most of this gap:

- at every fixed-history cut, mount the already trained adapter from a
  presealed cyclic wrong lineage. This adds inference, not fits. If the gain
  survives the wrong-life mount, it is not evidence for personal memory;
- preserve raw chronology now and, after a positive S1/S2 vertical, fit a
  same-child/same-history `RAW_CHRONOLOGICAL` LoRA at S1 and the designated S2
  branch. Use the same rank, heat, updates, response masking, and native
  endpoint. This distinguishes DREAM's addressed compilation from ordinary
  replay of lived interaction.

For a whole-system learning claim, raw replay may remain a DEV ablation. For
any claim that **DREAM compilation** improves learning, it must be confirmed at
the claimed terminal cut or across every claimed AUC cut.

### HIGH 2 — the present “connected” contrast is organization under a budget, not new relational information

Every LINK is deterministically derivable from EVENT endpoints. `AUTH > ATOMS`
plus a LINK cut or permutation can show that explicit stored organization makes
the fixed reader/actor more useful under a fixed work budget. It cannot show
that SLEEP inferred information unavailable in the atoms.

That bounded construct is still valuable. Use the exact phrase:

> compiled LINK organization added utility over the same EVENT atoms under
> the registered access and actor-work budget

Do not equate it with discovery of a latent law. Predictive reuse on fresh
structure-governed modules is the later test for learned relational structure.

### HIGH 3 — current expansion is memory-dependent but not goal-conditioned

Both registered right-side delayed goals require the same `H -> S_R` probe.
An always-probe-H policy can pass. The present experiment can show a useful
memory-dependent experiment followed by a new write; it cannot show that the
goal selected which knowledge to acquire.

The already designed `PCFL-GS1` sidecar is the smallest repair: from one frozen
post-S1 snapshot, change only the public goal between a right-side target and
`Y`; the useful frontier reverses between `H -> S_R` and `X -> Z`. No outcome,
write, or extra fit is required. Make GS1 mandatory only for the phrase
“goal-conditioned expansion.” Without it, say “memory-dependent useful
experiment.”

### HIGH 4 — repeated roots are not topology generalization

Resampling opaque IDs and `(O,R,D)` bits on one skeleton creates independent
world draws for this fixed generator, but it does not test new topology or task
structure. Sixteen roots cannot turn one route template into general planning.
The delayed goals themselves share four of five route choices.

Report roots—not tasks, wrappers, branches, or checkpoints—as units, and bound
the mechanism claim to this topology. The reusable stratum should vary at
least the relation instantiation and held target structure, not merely rename
the same route. If a broader traversal claim is desired, add a small sealed
family of two or three graph motifs before any confirmation output; otherwise
do not claim topology generalization.

### HIGH 5 — interface success is a prerequisite, not evidence of memory

The failed C0 capture was dominated by an undisclosed READ dialect, a one-line
action prompt where the design promised thought, and an order/numbering
shortcut. The repaired typed protocol is sensible, but its success will show
only that a fixed 7B actor can use the benchmark interface when sufficient
memory is supplied.

Require the repaired C0 ceiling before interpreting any learned failure. Keep
strict final actions because the environment needs an executable command, but
also report typed-turn failures, graph-semantic success, served READs, thought
turn count, and cap exhaustion separately. Do not call 1--6 `THINK` turns
self-scheduled metacognition; they are a bounded recurrent inference protocol.

### HIGH 6 — “compressed” is not supported by current carrier accounting

The rank-8 adapter is about `80.8 MB`, larger than the PCFL ledger. Zero
returned-memory tokens and a fixed-rank parameter count are not storage
compression. The supplied-schema sidecar would show use of a compact authored
code, not that ordinary SLEEP discovered compression.

The least expensive honest addition is the planned zero-new-fit predictive-
reuse assay on fresh structured modules. If DLT assigns a shorter conditional
prequential code than DLT-OFF, the saving disappears on matched independent
continuations, and behavior improves, the valid term is **conditional
predictive semantic compression**. Print adapter bytes and packed/zstd ledger
bytes beside it. Otherwise remove *compressed* from the contribution and say
compiled/connected.

### MEDIUM 1 — native improvement needs semantic-content causality at every promoted scale

The DEV `EVENT_TWIN`, `LINK_PERMUTE`, OLD/NEW cuts, and wrong-root conditions
are good local controls. At lifetime scale, carry at least the cyclic wrong-
lineage mount and registered critical cuts forward. A no-write branch alone
does not establish that the correct experience, rather than generic fitting,
caused the change.

### MEDIUM 2 — on-policy and fixed-history effects must remain separate

On-policy DLT versus frozen/text is a valid whole-system effect because earlier
writes change later action and therefore later data. It is not a pure carrier
comparison. Fixed-DLT-history LoRA versus text is the carrier/access estimand.
Terminal batch controls separate fit timing only conditional on their source
history. Preserve the planned action-contingent potential-outcome tape and do
not use one estimand to name another.

### MEDIUM 3 — pseudo-replication remains a live reporting hazard

The own-write roster's 153 generations are repeated views of 17 mappings from
12 rows in one fitted life. The collision cube, two R branches, two goals,
wrappers, tasks, checkpoints, and technical seeds are likewise nested. None is
an independent child lineage. The proposed root-level AUC and blinded N rule
are appropriate; they must survive implementation and paper reduction.

## 4. Smallest high-information execution sequence

This sequence preserves the thesis while minimizing GPU spend.

1. **Finish the repaired zero-fit interface ceiling.** If supplied exact graph,
   supplied full child text, and active exact service do not cross their joint
   gates, stop. No writer result is interpretable downstream.
2. **Repair formation once, scientifically.** Separate child payload from
   harness LF framing and allow valid LINK pairs in any order. Run one
   disposable complete 20-call formation; no repeated same-version retry.
3. **Run the one-life own-write address test only as a storage localizer.** Its
   W8 gate can establish cold trained-mapping reproduction, nothing more.
4. **Run the two-root v2.2 vertical.** Add only (a) raw chronology preservation,
   (b) the two-root raw-LoRA ablation after AUTH succeeds, (c) cyclic wrong-life
   mounts, and (d) GS1 after a qualified S1 state. Stop at the first failed
   causal seam.
5. **Only after both roots pass**, freeze/materialize the reusable stratum and
   implement/certify the strong evolving text system. A baseline that cannot
   pass its own ideal-text certificate blocks superiority claims.
6. **Then run the first 16 paper lineages.** Use the preallocated expansion
   roster and blinded power decision. Do not spend the 16--48-lineage budget on
   an opaque-only or unqualified writer.
7. **Run predictive reuse with zero new fit** on the already trained final
   states. Run plateau and recurrence localizers only after the core lifetime
   effect exists.

## 5. Paper disposition

PCFL can anchor a strong paper if the claim ladder remains noncompensatory:

- **vertical only:** authentic scaffolded experiential relay in a finite route
  world;
- **vertical + connection controls:** compiled connection organization changes
  bounded goal-conditioned use;
- **plus GS1 and second write:** goal selects an experiment whose new outcome
  is written and jointly reused;
- **plus powered lifetime:** periodic personal writes improve later action over
  novelty-growing life;
- **plus certified text and reusable stratum:** superiority over one precisely
  named strong evolving memory system;
- **plus predictive-code gate:** conditional predictive semantic compression,
  with physical non-compression stated.

Failures do not make PCFL worthless. A repaired ceiling plus failed personal
write is a clean writer result; successful storage plus failed traversal is a
read/use result; successful opaque retention plus text superiority is evidence
that parametric memory is the wrong carrier for independent bindings. The
benchmark is valuable precisely if those outcomes remain reportable rather
than being optimized away.
