## Executive ruling

The current proposed order

```text
Q0 full dose -> E0-r -> Level-1 M1 -> authentic M -> lifetime L
```

is scientifically conservative but **not the shortest valid path** to the
paper objective. The first three stages are development diagnostics on three
different surfaces:

- Q0 writes a researcher-supplied conditional native action map;
- E0-r writes researcher-rendered event rows at a deliberately high dose; and
- Level-1 M1 installs a researcher-prepared correction-to-reuse disposition.

None converts the child's own action--outcome history into a child-authored
connection, traverses it under a later goal, expands it with a new action, or
measures improvement over a life. A pass at any of the three does not release
authentic M by logic; a failure at any of the three does not falsify authentic
M unless it uses the exact same target surface, dose, reader, and native actor.

The first claim-bearing experiment should therefore be a **two-root authentic
vertical slice** in one opaque route-world family:

```text
child acts -> public outcome -> child EVENT/LINK commitments
-> SLEEP 1 -> candidate-free local reads + native mounted behavior
-> different goals traverse different connections
-> child selects the uniquely useful experiment
-> public counterfactual outcome -> child EVENT/LINK commitments
-> cumulative SLEEP 2 -> delayed action requiring OLD + NEW
```

Build the zero-fit world, formation, reader, and strong-text ceilings first.
Then run at most **six fits per root, two roots, twelve fits total**. Each seam
has its own terminal label, so this vertical slice localizes failures at least
as well as the serial Q0/E0-r chain while directly touching every novel part of
the paper except increasing lifetime and compression.

Q0 should finish if it is already launched, but no further Q0 family should
delay this slice. Level-1 M1 should continue in parallel as developmental
research, not as a prerequisite. E0-r should be run only if its implementation
is literally the reusable EVENT writer/reader path for M and does not cost a
separate builder day; otherwise its atomic read gate is already embedded in
the first authentic M fit.

If both development roots pass unchanged, do **not** first spend an independent
eight-root M confirmation and only afterward build L. Freeze one hierarchical
confirmation campaign whose early cuts repeat M and whose later cuts extend
the same authentic lineages into novelty-growing lifetime cohorts. That is the
shortest valid route to a paper result.

## 1. What the repository actually establishes

The strongest current evidence is useful but remains below the paper claim:

1. Correct oracle-authored mini-Sudoku material beats equal-marginal corrupted
   material in three optimizer seeds, but absolute exact success is small and
   the material is not child-authored.
2. Varied-view, distinct-source replay can store authored atomic facts and
   preserve a rehearsed routine. In the one sequential allocation diagnostic,
   replay retained `64/64` old decisions and acquired `32/32` new decisions,
   whereas no replay retained `25/64` old while acquiring `32/32` new. This is
   one warm-started, authored-data allocation result, not endogenous SLEEP.
3. Historical CompilerGym writes alter behavior and sometimes sustain a small
   advantage, but commonly install global routines, ritualize, spill, or
   collapse. Those histories do not show connected memory or a clean lifetime
   comparison.
4. The three-seed perception comparison shows an interface effect, not a new
   semantic capability: OFF already contains `11/12` supported records after
   descriptive fence removal; ordinary fitting mainly removes the fence, and
   anchor training worsens source selection.
5. Q0 attempt 2 stopped after one update per arm. The corpus audit found no
   map, label, mask, or schedule defect. The stop was caused by an objective-
   incompatible first-update all-row criterion under a base that already
   preferred one action on `128/128` rows. It did not test full-dose
   learnability.
6. No completed result establishes child-authored semantic formation,
   candidate-free event/link carriage, goal-conditioned traversal,
   information-seeking expansion, a second authentic write, positive lifetime
   slope, strong-memory superiority, or compression.

This evidence supports continuing. It does not support treating a diagnostic
writer pass as a paper milestone.

### Why Q0 is not a logical gate

Q0 trains the first divergent token after a supplied `ACT: -` prefix with a
pairwise loss. Authentic M trains full child-authored `EVENT` and `LINK` spans
with response-masked causal language modeling and reads them through a local
memory interface. These are different representations, losses, doses, and
readout paths. A Q0 pass says only that its direct branch writer can become
conditional. A Q0 miss cannot close a richer event/link write, especially
after the earlier full-response birth already expressed complementary maps.

The Q0 full-dose run is worth finishing because it is already implemented,
CPU-accepted (`282` native tests, no failures/skips), allocated across three
roots, and supplies a clean optimization diagnosis. Its map-dynamics sidecar
costs no new model work. It should end there.

### Why E0-r is not a logical gate

E0-r is a well-controlled fixed-render carrier ceiling, but its exact success
would not demonstrate the thinker/compiler boundary needed by the paper. Its
failure would also be ambiguous for authentic M if the latter uses a different
target distribution or dose. The first `S1_AUTH` fit in the vertical slice can
score EVENT generation before any route/link endpoint. If EVENT rows fail,
the root terminates as `M_S1_EVENT_NOT_CARRIED`; no later control fit or SLEEP 2
is spent. This provides the same kill information on the actual claim-bearing
surface.

E0-r remains useful only when it is implementation reuse: same row grammar,
same response mask, same candidate-free reader, and nearly no incremental
builder time. Its fixed-render adapter and rows must never seed M.

### Why Level-1 M1 is a sibling, not an ancestor

M1 asks whether standard post-training can install a correction-to-reuse
routine. That is valuable for the parenting/developmental study, but an M1
adapter is not required to test whether a fixed competent base can author
grounded events and links under a typed scaffold. Serializing authentic M
behind six M1 fits, corpus-route selection, confirmation, and an active control
risks missing the submission window without strengthening the core causal
chain.

If M1 releases, preserve it as a clean optional starting-child factor. Do not
swap it into a running M lineage or use M outcomes to choose its corpus route.
If M1 fails, continue M with the frozen base/scaffold and report that the
developmental bootstrap remains open.

## 3. The fatal missing benchmark ingredients

The present design library contains most of these ideas, but a paper-grade
campaign needs all of them in one executable object.

### A. Authentic source formation with a visible denominator

Every admitted semantic target must be an exact child generation span produced
after its cited action and public outcome. The compiler may validate, reject,
copy, order, replay, and loss-mask wrappers. It may not fill a destination,
choose link endpoints, repair a relation, or write the prospective action.
Malformed and unsupported attempts remain in the formation denominator.

This is scaffolded self-preparation, not spontaneous memory initiation. The
harness may request an EVENT or LINK in a fixed grammar; the claim must say so.

### B. Two readouts, because only one is not the organism

The route experiment currently emphasizes a clean actor consuming rows from a
goal-blind LoRA memory worker. That is excellent causal isolation, but by
itself it is a parametric memory **service**, structurally close to RAG.

Every claim-bearing root therefore needs both:

1. **mechanistic readout:** candidate-free local EVENT/LINK generation by a
   goal-blind memory worker, consumed raw by a clean actor; and
2. **native-organism readout:** the personal LoRA is mounted in the actual
   THINK/action model, which sees only the ordinary goal and legal tools. It
   must choose valid actions without an answer-bearing candidate bank or a
   clean actor doing all cognition over supplied rows.

If only the first passes, claim a generative parametric-memory relay, not a
Dream--LoRA--Think agent. Native behavior must carry locality/interface/no-harm
gates because this is where historical adapters failed.

### C. Connection value, not merely connected-looking text

Holding the same authentic EVENT rows fixed, an authentic child LINK must beat
and redirect against a matched link permutation. A read-time critical-link cut
must remove the registered route. Exact atoms-only text must also be tested:
if the actor composes the route equally well from atoms, the result is
read-time composition, not added value from a stored connection.

### D. Prospective expansion with real uncertainty

Before the frontier outcome, both possible worlds must be byte-identical and
balanced. The useful experiment and a distractor must have equal raw outcome
entropy, while only the useful experiment has target-relevant information.
The child selects before observing the outcome; both prospective outcome rows
are committed before selection, or the two ordinary counterfactual twins are
preallocated. The later task must be impossible from OLD alone or NEW alone.

### E. Novelty-certified lifetime cuts

Episodes, paraphrases, and optimizer repetitions are not lifetime. Each cut
must add independently bound relations or task structure. Early knowledge must
first pass an acquisition floor and then be re-tested after later writes. A
positive endpoint level is not a lifetime effect; require a positive absolute
late slope and anchor-to-terminal gain.

### F. A strong memory opponent that receives the same organization

`ACTIVE_LINKED_TEXT` must receive the exact same admitted child EVENT and LINK
rows, not merely raw episodes. Its frozen updater/index must be faithful,
candidate-blind, restart deterministic, insertion-order invariant, and able to
redirect under binding twins. Give it an excluded-development `1/2/4/8` read
and `1024/2048/4096` returned-token response curve, then freeze the smallest
setting at which doubling changes value by at most the equivalence margin.

Also retain `FULL_CHILD_TEXT`, `RAW_RAG`, `EXACT_WITNESSED_GRAPH`, and
`NATIVE_CONTEXT` as zero-fit ceilings/references. The exact graph is allowed to
win. `FINAL_BATCH` is the temporal LoRA control, not a substitute for text.

### G. Same-history and on-policy comparisons

The native learner and active-text agent will choose different actions and
therefore acquire different later evidence. Their main comparison is a valid
total-system comparison, but it cannot establish carrier superiority by
itself. At every cut, run an inference-only same-history table over the DLT
ledger: personal LoRA, active linked text, raw RAG, and exact graph receive the
same public facts. Claim LoRA carrier superiority only if this table agrees in
direction with the native on-policy result.

### H. Independent lineages, not prompts or checkpoints

For M, a fixed child across independent worlds supports only a world-root
mechanism claim. For L, the unit must be an independently initialized child
lineage paired with an independent world root. Decode seeds, goals, twins,
questions, and lifetime cuts are repeated measurements. The confirmation
roster must vary learner/training seeds rather than treating one favorable
adapter as the species.

### I. Compression needs an actual rate--distortion denominator

A rank-8 all-layer adapter is roughly `80.8 MB`, much larger than any current
micro-world. Neither rank, training-token count, dream length, nor removal of
repeated prose proves compression. Until a downstream same-denotation
rate--distortion test beats normalized expanded text and its ordinary codec at
fixed exact reconstruction and utility, use *compiled* or *consolidated*, not
*compressed*. This clause cannot be rescued by M or L performance.

## 4. Highest-information next campaign: `PCFL-VERTICAL-DEV-v1`

### 4.1 One root object

Use a fresh opaque route-world generator, never an old Q0, E0-r, D0, M-core,
CompilerGym, or nursery root. Preallocate all DEV roots and counterfactual
twins before any model output. Balance identifiers, token lengths, row order,
action/outcome marginals, endpoint degrees, source frequency, and both frontier
outcomes before semantic assignment.

One root contains:

- eight child-executed OLD transitions;
- two different OLD goals from the same start, each needing a different
  two-link route;
- at least four matched possible targets for every true LINK;
- one missing frontier relation;
- two equal-entropy experiments, only one of which informs that relation;
- two byte-identical pre-outcome potential-world twins; and
- one delayed goal mechanically requiring one OLD link and the selected NEW
  relation.

The child commits exact `EVENT` and `LINK` rows before any later goal that can
reward them. The memory API returns one local row or `MISS`; it never receives
the goal, candidate rows, an action menu, or the hidden graph.

### 4.2 Zero-fit closure before any result-bearing fit

Use four excluded roots and one disposable formation root. Freeze the
generator, public/scorer/compiler/audit visibility schemas, actor API, reader,
prompts, parser, baseline updater, and cuts only if all of these pass:

1. two independent CPU solvers agree on every legal history, outcome twin,
   route, informative action, delayed answer, and dependency cut;
2. pre-outcome twins are byte-identical and retain one bit of hidden binding;
3. exact linked child text, active linked text, and exact witnessed graph each
   solve at least `15/16` route, reachout, and delayed endpoints on at least
   three of four roots;
4. no memory and every ID/order/frequency/length/fixed-policy shortcut remain

5. goal swap changes the first relevant query, complete route, and action;
6. OLD-link and NEW-event cuts each reduce their designated endpoint by at

7. link permutation and outcome swap redirect, rather than merely corrupt,

8. running versus skipping an evaluation leaves every later lineage byte
   identical; and
9. the disposable child can form all eight supported EVENT rows, all four OLD

If exact text or the graph cannot solve, the assay is invalid. If source
formation fails, route the problem to M0/M3 instruction or scaffold work. Do

### 4.3 Six fits per development root

Run exactly two new DEV roots. Both must pass; they are a kill gate, not
publication replication.

SLEEP 1 fits, all from byte-identical clean starting child state:

```text
S1_AUTH          authentic child EVENT + authentic child LINK
S1_EVENT_TWIN    coherent, prebound EVENT rebinding with matched valid LINKs
S1_LINK_PERMUTE  authentic EVENT + fixed-point-free matched wrong LINKs
```

```text

S2_FULL_t1       authentic OLD + child NEW from outcome twin 1
```

The control arms match target tokens, updates, initialization, optimizer state,
dropout RNG, row order, semantic-class counts, and request shapes. Synthetic

Run `S1_AUTH` and its EVENT read first. If event carriage fails, stop the root

**Goal traversal**

### 4.5 Failure labels that determine the next experiment

Use the first applicable terminal label:

- `VS_ASSAY_INVALID`: zero-fit solver, shortcut, ceiling, cut, or visibility
  failure;
- `VS_CHILD_FORMATION_FAIL`: public evidence exists but the child cannot
  produce supported EVENT/LINK spans;
- `VS_EVENT_CARRIER_FAIL`: authentic EVENT targets form but do not survive
  candidate-free write/read;
- `VS_LINK_CARRIER_FAIL`: events survive but links do not;
- `VS_SOURCE_BINDING_FAIL`: the coherent EVENT twin does not redirect;
- `VS_CONNECTION_NOT_NECESSARY`: links read but do not affect traversal;
- `VS_GOAL_TRAVERSAL_FAIL`: correct local memories exist but the thinker does
  not select/join them under changing goals;
- `VS_NATIVE_ORGANISM_FAIL`: the modular read service works but the personal
  LoRA-mounted thinker/action loop does not;
- `VS_REACHOUT_FAIL`: stored structure exists but does not cause the useful
  information-seeking action;
- `VS_NEW_FORMATION_FAIL`: the new outcome occurs but the child does not
  prepare supported NEW rows;
- `VS_NEW_CARRIER_FAIL`: NEW rows form but do not survive SLEEP 2;
- `VS_RETENTION_FAIL`: NEW is acquired but OLD falls outside the bound;
- `VS_OLD_NEW_USE_FAIL`: OLD and NEW are readable but the delayed action does
  not consume both;
- `VS_UNSAFE_OR_NONREPORTABLE`: leakage, lineage, identity, mount, numerical,
  missing-denominator, selected-checkpoint, retry, teardown, or receipt fault.

Each label names one concrete successor. It is more informative than a Q0 or
E0-r pass followed by a generic M failure.

## 5. Confirmation and lifetime without paying for M twice

If and only if both DEV roots pass unchanged, freeze all source, mechanism,
baseline, endpoint, threshold, and failure bytes. Preallocate at least `16`
independent confirmation lineages, each pairing a fresh world root with a
prospectively assigned learner/training seed. Use a fixed-sequence hierarchy:

1. the first two novelty cohorts reproduce the complete M conjunction;
2. only if the predeclared mechanism threshold passes do cohorts three and four
   become claim-bearing lifetime evidence; and
3. compression remains a later disjoint sidecar.

Run every confirmation root through the authentic periodic lineage even if an
early seam fails; a failed write keeps the prior child and remains an adverse
intention-to-treat outcome. Do not replace roots. Synthetic control descendants
are terminal and never return to the lineage.

For each root, the main lifetime systems are:

```text
DLT_PERIODIC       native THINK/DREAM; cumulative SLEEP after every cohort
SLEEP_FROZEN       same opportunities and shadow writes; never mount them
ACTIVE_LINKED_TEXT frozen acting checkpoint; evolving lossless store with the
                   same eligibility and organization policy over that
                   branch's own admitted child EVENT/LINK rows
FINAL_BATCH        one terminal clean-start LoRA fit over the DLT branch's
                   final accepted corpus with matched target-token exposure
```

`FULL_CHILD_TEXT`, `RAW_RAG`, `NATIVE_CONTEXT`, and
`EXACT_WITNESSED_GRAPH` are zero-fit/common-history references, not four more
longitudinal training arms.

In the native on-policy comparison, every branch owns its actions, public
outcomes, and later records; no row crosses between branches. “Same admitted
organization” means the same updater and eligibility contract, not giving the
text branch the DLT branch's better history. Only the explicitly labeled
same-history carrier table replays one sealed DLT ledger into every carrier.

At five cuts (entry plus four genuinely new cohorts), report:

- new-cohort prospective action accuracy;
- old-cohort retention after its acquisition floor;
- goal-conditioned traversal and information-seeking action;
- candidate-free EVENT/LINK fidelity and false-memory use;
- native action validity/interface preservation;
- accepted formation yield versus all opportunities;
- generated/returned/supervised tokens, reads, fits, updates, storage, latency,
  and GPU time.

### Mechanism release

Require at least `14/16` confirmation roots to satisfy the complete M
conjunction. The binary root is the unit; prompt variants are repeated
measurements. Report the full vector and exact interval. If this fails, do not
claim general connected/traversable/expandable memory even if mean task score
is high.

### Lifetime release

Use root-level paired inference and a predeclared smallest effect of interest
of `.05`. At minimum require:

1. DLT_PERIODIC has positive absolute post-anchor slope;
2. its anchor-to-terminal gain is positive;
3. its entry-adjusted AUC and terminal value exceed SLEEP_FROZEN by at least
   `.05`, with a 95% root-level lower bound above zero;
4. early acquired competence and any inherited birth skill remain within
   `-.05`;
5. action/interface failure does not increase with lifetime; and
6. all scheduled novel evidence cohorts were actually available independent
   of accepted-write count.

If `16` roots are insufficient for the registered precision, add only fixed
predeclared batches using a blinded, mean-free nuisance-variance rule under a
hard resource cap. Never convert checkpoints or questions into learner N.

### Strong-memory release

Claim superiority only if:

1. ACTIVE_LINKED_TEXT passes its independent faithfulness, restart,
   insertion-order, redirection, source, and action-use certificate;
2. DLT_PERIODIC beats it by at least `.05` on the registered late AUC or
   terminal endpoint, with a 95% root-level lower bound above zero;
3. old competence is retained and oracle headroom is at least `.10`;
4. the inference-only same-history carrier comparison agrees in direction;
   and
5. all resource-response curves are shown.

Do **not** say the baseline *saturated* merely because it is flat at one
budget. Its last two increments and late slope must each have 90% root-level
intervals inside the predeclared equivalence band while new evidence continues,
oracle headroom remains, and doubling both reads and returned tokens remains
equivalent. Otherwise say only that DLT beat one frozen finite configuration,
or that the baseline won.

## 6. The baseline-superiority risk the current ladder understates

The opaque route world is naturally favorable to exact linked text and graph
memory. A typed index can preserve every row losslessly, and a graph planner
may scale better than a small LoRA. That is scientifically healthy but makes
baseline superiority far from guaranteed.

The experiment must therefore expose two distinct interfaces:

- **local-read carrier mode**, where LoRA memory and linked text receive the
  same query/read budget; and
- **native implicit-use mode**, where the personal LoRA is mounted in the
  thinker while text memory receives its frozen best qualified retrieval
  budget.

If LoRA wins only because text was denied the child's LINK organization or was
stopped below its response-curve plateau, the result is invalid. If linked
text or the exact graph wins, report it. The paper can still contribute the
first authentic closed-loop parametric relay if M and lifetime pass; it simply
cannot claim memory superiority.

Conversely, if the route world contains only exact opaque lookups, reviewers
will reasonably ask why a lossy parametric store should win at all. The
lifetime generator should therefore contain a prospectively balanced
**novel-recombination endpoint**: later goals recombine previously witnessed
local relations in paths never shown as complete routes. This tests integrated
use without leaking a target route. It must not become a held-out factual
generalization claim unless the rule family and identifiability ceiling are
separately certified.

## 7. Compression disposition

Compression is not an upstream gate and should not delay the vertical slice.
It is, however, a separate missing requirement if the paper or objective says
*compressed*.

After connected utility passes, use disjoint roots and increasing unique-
relation loads. Compare the complete bytes/tokens for:

1. normalized expanded public EVENT denotations;
2. unique atomic EVENT rows;
3. child EVENT+LINK schema/residual code, including codebook, index, decoder,
   metadata, and provenance; and
4. ordinary lossless compression of each representation.

Require exact semantic round trip, zero false memories, and utility within
`.05` of the uncompressed reference. A semantic-code claim additionally needs
the complete child code to be shorter than the normalized denotation and its
ordinary-codec reference at at least two registered nontrivial loads. A
physical parametric-compression claim needs the complete mounted life-specific
adapter package to cross the same rate boundary; current micro-worlds cannot.

Failure removes *compressed* only. It must never block or retroactively weaken
a valid own-experience/connection/lifetime result.

|---|---|
| Q0 only | a supplied finite conditional branch policy was acquired under the registered pairwise recipe |
| E0-r only | a fixed renderer plus LoRA carried addressed event rows on one excluded development root |
| Level-1 M1 only | researcher-prepared post-training installed one correction-to-reuse routine |

| native endpoint | the personal LoRA-mounted THINK/action organism, not only a memory service, expressed the result |

| strong baseline | the system beat the exact named, certified baseline configuration; add *saturated* only under the plateau certificate |
| compression sidecar | bounded semantic-code compression at registered loads; physical LoRA compression only after full-package crossover |

Never infer internal graph geometry from behavior, general learning-to-learn
from one task family, spontaneous memory formation from a typed request,
population-of-models generality from world roots, or indefinite improvement
from four cohorts. E0-r and Level 1 are **trained**; the authentic self-prepared
closed-loop line is the first candidate for **learned**.
