# Full-objective evidence audit and PCFL critical-path red team

**Date:** 2026-09-13 UTC  
**Role:** independent objective-coverage skeptic  
**Evidence cut:** repository `ee8931b8` plus the current clean worktree at the
end of this audit  
**Scope:** analysis only. I changed no experiment source, model, tokenizer,

## Executive verdict

The repository now contains a credible design for the first experiment that
touches the scientific center of Dream--LoRA--Think: PCFL vertical DEV v2.1.
It is substantially stronger than the completed writer, Level-1, RuleGame,
and CompilerGym studies because it joins in one causal chronology:

```text
child action -> public outcome -> child EVENT/LINK
-> SLEEP 1 -> reset -> local parametric read and native use
-> memory-dependent experiment -> unpredictable public outcome
-> child NEW EVENT/LINK -> SLEEP 2
-> delayed action requiring OLD and NEW
```

No completed experiment has yet run this chain. At the audited commit the
three principal PCFL implementation files and their two PCFL-specific test
files are absent. The protocol is design evidence, not scientific evidence.

The full active objective is therefore **not close to proven**, even though
several important engineering and post-training ingredients are now real. The
current evidence establishes that low-rank fitting can install supplied facts
and supplied decision procedures, that varied-source replay can preserve old
authored facts under one allocation, and that exact training loss can fall
without producing usable conditional memory. It also gives strong negative
evidence against the current direct conditional writer and against assuming
that more learning rate or more repetitions automatically yields scoped
behavior.

PCFL v2.1 is the highest-information next campaign per GPU-hour, but four
interpretive repairs should be made before a claim-bearing run:

1. A full-objective mechanism pass must require a causal connection result;
   `EVENT_COMPOSITION_ONLY` is a valuable fallback result, not a pass for
   “compiled connected knowledge.”
2. The PAD-heavy ATOMS and OLD_REPLAY controls should be replaced, or at least
   triangulated, with target-token-matched replay of real irrelevant/old
   child-authored rows. The current synthetic `padvoid x x ...` targets create
   an avoidable content-and-dialect difference exactly where this project has
   already measured low-rank dialect sensitivity.
3. Enforce source-diverse batching. The positive storage evidence came from
   interleaving distinct sources, not from hoping a random shuffle separates
   eight views of one source.
4. Qualify the exact writer on the already-required disposable authentic root:
   try the registered `3e-5`/200-update recipe first and, only if its semantic
   carriage gate fails, one predeclared `3e-4`/200-update fit. Neither current
   low-heat L2 nor Q0 evidence supports assuming `3e-5` is sufficient.

The best next experiment is consequently a **stage-gated two-root PCFL
vertical v2.2**, identical to v2.1 except for those causal-control repairs. It
spends almost nothing if formation or zero-fit closure fails and at most 16
fits / 3,200 updates / about 18 A40-hours if both calibration fits and every
scientific seam run. Do not
spend the next scientific budget on another authored Level-1 fixture, rank
sweep, or CompilerGym lifetime before this vertical mechanism is known.

The full paper objective additionally needs an independent-lineage lifetime
campaign, an actually implemented and certified evolving linked-text
opponent, a recurrence-specific comparison, and a real rate--distortion result.
Those are designed but completely unproven.

## 1. The full objective, decomposed without lowering it

The requested end state contains nine logically distinct claims. A result on
an earlier row cannot substitute for a later one.

| O3 | compiled connections add value beyond their atoms | same authentic EVENTs, causal LINK treatment, matched no-link control, semantic redirection/cut | **missing** |

| ID | attribution | present requirement |

Parenting is a developmental extension, not a substitute for O1--O10. A
parented child that enters deployment better can establish schooling. It does
not establish experiential learning unless its *later learning increment* is
larger under a clean entry-adjusted comparison.

## 2. What the completed evidence actually proves

“Proven” below always means only the bounded fixture, model, dose, and
independent unit named. It never means a general cognitive capability.

### 2.1 Positive, bounded evidence

1. **Supplied authored facts can be stored and extracted at sufficient dose.**
   The varied-view/distinct-source writer acquired supplied facts on held
   lexical surfaces while preserving a rehearsed arithmetic behavior. This is
   an authored storage ingredient, not own-experience memory or DREAM.

2. **Replay can protect old authored facts under one sequential allocation.**
   In the audited one-seed sequential study, replay retained `64/64` old-bank
   decisions and acquired `32/32` new-bank decisions; no replay retained only
   `25/64` old while acquiring `32/32` new. Arithmetic stayed `32/32` in both.
   Because current-new exposure was 20 presentations/fact with replay and 40
   without, this is one useful allocation result rather than a pure causal
   estimate of replay. Evidence:
   `2026-09-13_sequential_authored_memory_replay_terminal_postaudit.md`.

3. **Researcher-authored narrow decision procedures are fit-able.** Twelve
   Level-1 cells installed contradiction, goal-completion, prediction, and
   update-judgement policies at `48/48` held content/strict in all three
   optimizer seeds on one material seed. The second roster put perception at
   `47/48,48/48,48/48` and the other three skills at `48/48`. These are
   open-book authored-policy execution results, not learned reflection,
   perception, repetition, or parenting.

4. **A literal motor scaffold can open the action--world--record path.** In
   the exploratory RuleGame amendment, OFF and three perception adapters each
   executed `16/16` actions and generated `16/16` record responses. Exact
   production-eligible records were `7/16` OFF versus `14/16,8/16,8/16` for
   the three fitted seeds. All copied the public outcome `16/16`. This proves
   interface availability and one optimizer-sensitive content gain. It does
   not prove a stable learned skill, SLEEP, or downstream use. Evidence:
   `2026-09-13_level1_skill_to_real_record_terminal_reduction.md`.

5. **The transactional two-SLEEP machinery can complete without corrupting
   basic legality.** The L2 public-record diagnostic formed all 8 then 16
   supported records, ran three finite fits, reloaded candidates, and remained
   `16/16` legal. This is infrastructure evidence only; its scientific
   behavior was exactly null.

6. **Naive lifetime LoRA writes can change real agent behavior.** In the
   exploratory CompilerGym v6.1 lives, two surviving learners achieved paired
   AUC gains `+0.0308` and `+0.0447` through episode 896 and terminal gains
   around `+.05`; the third learner destroyed its strict action channel. The
   two survivors transported and fixated on a bootstrap-supplied routine,
   plateauing rather than continuing to learn. This is valuable ecological
   failure/transport evidence, not a clean lifetime or discovery result.

7. **Teacher-withdrawn authored continuation training can weakly move a
   parent-absent choice panel.** The reflection slice improved `7/12` OFF to
   `9/12` in all three optimizer seeds. This is context-distilled SFT on
   authored fixtures, not parenting or child-authored learning.

### 2.2 Claims directly contradicted by completed evidence

1. **The current pairwise writer is not scoped/conditional.** On the two
   complete Q0 roots, 128 updates lowered loss but failed the complementary
   map. Opposite-map adapters moved in almost the same global direction
   (`cosine=.9961/.9973`) and failed every locality family. The writer learned
   a common action bias, not the keyed policy. A third root was an
   infrastructure abort, not a success or failure. Evidence:
   `2026-09-13_q0_fulldose_v2_terminal_independent_raw_reduction.md`.

2. **Loss reduction does not establish extractable memory.** L2 fit loss fell
   from about `.22` to `.05`, yet base, SLEEP1, SLEEP2-PROMOTE, and
   SLEEP2-SHADOW all remained exactly `8/16`, and all 80 reports emitted the
   same action. Both S2 branches produced identical training bytes and final
   tensors. This is fit without observable conditional memory.

3. **Simply increasing learning rate does not repair that interface.** All
   six completed low/high LR L2 cells remained old `4/8`, new `4/8`, legal
   `16/16`. Rank/heat sweeps without a better semantic/read surface are low
   information.

4. **Naive self-training does not monotonically improve a life.** One of
   three CompilerGym learners underwent persistent dialect collapse; the two
   survivors became 95--98% dominated by one supplied routine and plateaued.
   This contradicts any claim that repeated SLEEP alone reliably expands
   exploration or thinking.

5. **The first contrastive authored screen did not meet its gate.** It moved
   held content from plain `17/24` to contrastive `19/24`, while D2 fell
   `8/12 -> 7/12`; its declared threshold required held at least `20`, D2 at
   least `9`, and advantage at least `4`. Fence-stripped OFF was `23/24`, and
   the fixture contained a polarity shortcut. This is a failed exploratory
   screen, not evidence for contrastive DREAM.

6. **Physical compression is false at the current scale.** The rank-8
   all-layer adapter is about `80.8 MB`, far larger than the canonical semantic
   state of any present micro-world. Zero returned memory tokens measure
   context bandwidth, not storage compression.

## 3. PCFL vertical DEV v2.1: what it gets right

PCFL v2.1 should remain the critical path because it closes more fatal
shortcuts per fit than any other current design.

### 3.1 Benchmark and visibility strengths

- The eight-world `(O,R,D)` collision cube makes OLD and NEW jointly
  identifying and gives relevant/distractor outcomes equal entropy before the
  public outcome.
- Later route goals and expected answers are absent during formation and
  training. Training targets are local EVENT/LINK responses, not route
  commands.
- The memory worker is goal blind and candidate free. It sees one child-chosen
  address, never the task, answer, candidate bank, or hidden graph.
- The native mounted endpoint prevents a clean actor plus memory service from
  standing in for the organism.
- OFF, wrong-root, source twin, link permutation, OLD cut, NEW cut, and
  cross-mount controls make generic formatting or action priors insufficient.
- Post-S1 NEW formation is textually sterile: OLD receipts, rows, rosters,
  service returns, and compiler state are forbidden. OLD identifiers in NEW
  links must be recalled through the mounted child.
- Every semantic training byte is intended to hash to a child generation span
  after a public receipt. The compiler verifies and packs but does not fill a
  field.
- The stage DAG fails early. A bad formation interface does not consume 14
  fits, and a carrier failure cannot be averaged with a later route success.

### 3.2 Writer and causal strengths

- Query-level multi-row targets now match the actual `READ EVENTS_AT` and
  `READ LINKS_FROM` API.
- ATOMS no longer receives trained false `MISS` at treatment addresses, and
  OLD_REPLAY no longer receives future-address negative labels.
- Source twins must follow the donor map, and S2 cross-mounts must follow the
  donor branch. These distinguish semantic redirection from generic damage.
- Strict and semantic scores are separate. Fenced or malformed but
  semantically right outputs cannot silently enter the lineage.
- Candidate adapters must preserve a native 40-item interface canary. Rollback
  preserves the organism but does not convert a failed write into success.
- The registered maximum is small for its causal coverage: 14 fits, 2,800
  updates, 7 A40-hours training and 10 A40-hours inference.

These are material strengths. The experiment is not “too complicated”; most
of this complexity is evaluator hygiene around a simple THINK--DREAM--SLEEP
loop.

## 4. PCFL v2.1 red-team findings

### 4.1 `EVENT_COMPOSITION_ONLY` cannot satisfy the full connected-memory claim

The world deliberately makes every LINK derivable from EVENT endpoints. The
zero-fit gate even expects `EVENT_ATOMS_TEXT >=60/64`. V2.1 therefore allows a
root to pass overall when AUTH works but ATOMS ties, assigning the nonfatal
label `EVENT_COMPOSITION_ONLY`.

That is scientifically useful: it would show that local parametric EVENT
memories can be composed under a goal. But it does not show that SLEEP stored a
connection whose presence improved later action. If the paper's central word
is **connected**, the confirmation/full-objective gate must require at least
one of:

```text
AUTH - ATOMS >= registered practical margin on the native endpoint
and a critical LINK cut removes the registered behavior

or

a coherent link-binding intervention redirects traversal while EVENT
read fidelity remains matched.
```

V2.1's endpoint-incompatible `LINK_PERMUTE` is a useful false-pointer
diagnostic. If it is ignored, the current protocol treats that as nonfatal.
That is acceptable for DEV localization but not for the full connected-memory
claim. A claim-bearing confirmation must make semantic LINK redirection or
native link-added value noncompensatory.

### 4.2 The PAD controls create an avoidable treatment-specific dialect

V2.1 equalizes active target tokens with synthetic targets of the form:

```text
padvoid x x x ...
```

ATOMS receives six PAD slots where AUTH receives three; OLD_REPLAY receives
three where FULL receives one. These strings are parser disjoint and the
generic canary can detect broad damage. They are not behaviorally neutral.
The repository's strongest negative findings are exactly that low-rank
training can install a broad dialect/action bias while passing narrow local
checks. Consequently an AUTH-minus-ATOMS route difference could combine:

- presence of authentic LINK information; and
- less exposure to an unnatural repetitive PAD target.

Local EVENT fidelity and a generic route canary reduce this concern but do not
exclude task-specific reasoning interference.

The clean repair is not address-specific `MISS`. It is prospectively balanced
**grounded replay**:

- fill ATOMS' missing semantic dose with evenly distributed repeats of
  authentic old EVENT blocks or child-authored disconnected distractor rows;
- fill OLD_REPLAY's missing NEW dose with evenly distributed repeats of OLD
  blocks;
- keep query shape, total target tokens, updates, and seed coupling exact;
- require the distractor/replay rows to be causally irrelevant under explicit
  cuts; and
- report both a replay-matched no-link arm and the same-dose link permutation.

This makes the no-link and no-new controls strong rather than deliberately
strange. If exact token matching cannot be achieved without synthetic PAD,
retain PAD as a small residual only and require a PAD-only sham adapter to be
noninferior to C0 on the exact native route distribution, not merely on the
generic canary.

### 4.3 Initial acquisition is scaffolded, not autonomous

OLD exploration uses a fixed source schedule and exposes all still-untried
ports at that source. EVENT and LINK commitment timing, grammar, and empty
addresses are supplied. The child chooses an offered port and authors every
semantic field after a real result, so “its own action--outcome experience” is
defensible.

The following stronger descriptions are not defensible:

- autonomous exploration;
- spontaneous memory formation;
- invention of a memory schema; or
- learned decision to dream.

The later reachout is the first autonomous task-relevant action choice. Keep
the claim as **scaffolded self-preparation followed by memory-dependent
expansion**.

### 4.4 Reachout is task relevant but not goal-switched

Both delayed goals need the same `H -> S_R` frontier. The stored map can make
that probe useful, and OFF/cut/wrong-root controls can demonstrate memory
dependence. But changing the goal cannot change which experiment is useful.

V2.1 already narrows its language correctly. Do not later upgrade this to
“goal-conditioned experiment selection.” For that claim, confirmation must
contain two otherwise matched goals whose missing frontiers differ, such that
goal swap changes the selected probe while the pre-outcome prompt remains in a
registered collision class.

### 4.5 Two chronological sleeps do not prove recurrence mattered

Every S2 fit starts from clean C0 and refits the cumulative corpus. This is a
legitimate consolidation policy and gives well-coupled comparisons. It does
not test continuing weight adaptation from S1; it tests:

```text
S1 influences later experience -> cumulative data grow -> clean-base refit
```

That can prove a recurrent *agent--environment data loop*. It cannot by itself
prove that periodic parameter updates outperform a one-shot offline compile of
the same final corpus.

The planned `FINAL_BATCH` control is therefore necessary, not decorative. For
any recurrence claim, require at terminal time:

```text
DLT_PERIODIC on the DLT history
vs
FINAL_BATCH from the same entry child on the exact DLT history,
matched for cumulative supervised target-token presentations,
rank, modules, optimizer family, preservation material, and seeds.
```

If FINAL_BATCH ties periodic, the data were learnable but periodic writing was
not necessary for terminal carriage. The on-policy periodic-versus-frozen
comparison may still establish that intermediate writes improved the history
the agent collected. Report these as two different effects.

### 4.6 DEV roots are not paper evidence

Two roots identify implementation and causal seams; they provide no population
frequency. Counterfactual R branches, goals, wrappers, read calls, and decode
seeds are repeated measures inside a root. A successful v2.1 run licenses a
frozen confirmation campaign, not an abstract sentence about agents in
general.

At confirmation, keep all allocated roots in intention-to-treat tables. The
`14/16` complete-root conjunction can support mechanism reliability only if
the two failed roots remain failures rather than being excluded for formation
shortage.

### 4.7 PCFL is a mechanism assay, not yet a superiority environment

Opaque exact routes are maximally favorable to a lossless typed graph. That is
good for causal mechanism validation: if LoRA cannot compete with exact text
on a tiny graph, the reader is broken. It is not obviously the domain on which
parametric memory should beat a strong explicit graph.

The likely parametric advantage is not lossless storage of opaque edges. It is
amortized access to repeated structure, policies, abstractions, or
generalizations when the external memory's retrieval/context bandwidth binds.
A lifetime extension that merely appends more unrelated opaque routes may let
`ACTIVE_LINKED_TEXT` remain exact indefinitely and leave LoRA with no plausible
advantage. Before L, ensure increasing cohorts add a registered reusable
structure that can be learned from experience but cannot be answered by a
fixed prior. Keep `EXACT_WITNESSED_GRAPH` as an allowed-to-win reference.

This is not permission to weaken the text baseline. It is a warning that a
benchmark can be perfectly causal yet have no headroom for the paper's
superiority hypothesis.

### 4.8 The exact low-heat writer and random batching are not qualified

The newest independent writer audit at `ee8931b8` sharpens the implementation
risk. V2.1 fixes rank 8, `3e-5`, 200 updates, eight wrappers, and one sealed
shuffle. The nearest robust small-map extraction result used `3e-4`, explicit
replay, and source-diverse batching. The nearest objective-matched low-heat
results are negative: L2 remained greedily flat at `3e-5` and `1e-4`, while
Q0 at `3e-5` learned a global action motion rather than keyed bindings.

This does not justify importing `3e-4` blindly. EVENT/LINK responses are
longer and contain shared grammar tokens, so aggregate loss can be dominated
by easy syntax while opaque fields remain unbound. It just means that the
exact v2.1 recipe is an unsupported scalar bet.

The already-required disposable authentic formation root is the right place
for a bounded qualification:

```text
CAL_LOW:  r8, 3e-5, 200 updates
CAL_HIGH: r8, 3e-4, 200 updates, run only if CAL_LOW is valid but misses
          candidate-free semantic carriage
```

Select the first recipe passing candidate-free EVENT/LINK carriage, zero
usable wrong-root/unseen rows, and native interface/noncollapse. The route
endpoint is diagnostic and cannot select the writer, because storage and
cross-interface native use are different capabilities. If both fail, stop;
do not add rank, epochs, or a third heat.

Regardless of heat, batches should be constructed so no batch repeats a
wrapper view of the same query when distinct sources are available, LINK rows
are interleaved with EVENT rows, and every S2 NEW item is interleaved with OLD
replay. A nominal random shuffle is not evidence that the positive
distinct-source condition was reproduced.

## 5. Attack on the likely immediate successor: Level-1 -> PCFL formation

The zero-fit formation-transfer screen is a clean, cheap diagnostic. It uses
OFF and all three immutable perception adapters on two fresh excluded PCFL
roots, prescribes identical actions, and asks for exact EVENT/LINK outputs.
Its maximum is 152 calls and 0.5 A40-hours.

Its permitted interpretation must remain narrow:

- Actions are prescribed, so it does not test action selection.
- The upstream perception policies are researcher-authored, so it does not
  test parenting or learning from life.
- Three optimizer seeds share one material seed and one two-root panel; they
  test fit stability, not curriculum/world generalization.
- There is no fit, SLEEP, context deletion, memory read, downstream action, or
  lifetime.
- A best seed cannot be selected for PCFL. Either all three meet the fixed
  transfer conjunction or the Level-1 transfer candidate fails.
- If OFF reaches ceiling, the panel proves formation availability but has no
  headroom for a Level-1 contribution.

Run it only as a parallel de-risking screen. It should neither block nor seed
the authentic PCFL child. The highest-value outcome is diagnostic: whether a
native-dialect birth policy reduces formation failure before any LoRA write.

## 6. Strong textual-memory fairness audit

The downstream `ACTIVE_LINKED_TEXT` design is directionally fair and much
stronger than legacy `Ledger.recall`:

- its persistent store is uncapped;
- it receives the same causally admitted child EVENT/LINK organization as
  DLT, rather than only raw episodes;
- it may traverse its explicit graph;
- the actor chooses queries and returned rows are complete and cited;
- restart and insertion-order determinism are required;
- read count and returned-token budget are calibrated on excluded roots;
- wrong-root, binding-twin, cut, and irrelevant-store checks are required; and
- both on-policy and same-history tables are planned.

Those choices prevent a fake substrate win obtained by giving LoRA compiled
links while withholding them from text.

Four boundaries remain essential:

1. **It is not implemented.** No current source provides the full evolving
   store, updater, query policy, resource curve, and certification. A prose
   specification is not a strong baseline.
2. **End-to-end and carrier claims differ.** The on-policy systems own
   different later histories. A DLT win there is a total-system advantage.
   Carrier superiority requires the same-history table to agree in direction
   with a positive lower confidence bound.
3. **Compute is intentionally not identical.** DLT accesses weights on every
   forward pass; linked text spends explicit read calls and returned context.
   This is a real system tradeoff. Call it carrier superiority only after the
   text access curve and a simultaneous doubled-access sensitivity show that
   the chosen limit, rather than an arbitrary cap, is not causing the result.
4. **Saturation is configuration specific.** Even seven lifetime cuts can
   establish only that this frozen updater/retriever at this resource setting
   reached a practical plateau. It cannot establish that RAG, graphs, or
   external memory generally saturate.

The custom linked-text system plus RAW_RAG, NATIVE_CONTEXT,
FULL_CHILD_TEXT, and EXACT_WITNESSED_GRAPH is a defensible task-native baseline
suite. Reviewer-facing “strong agent-memory” language should additionally
explain why a general memory framework would not receive more information or
compute on this opaque benchmark; otherwise the exact graph is the safest
upper reference and the custom linked store is the primary deployable
opponent.

## 7. Lifetime and clock red team

The lifetime design correctly treats an independent child/world lineage as
the unit and treats tasks, cuts, twins, and decodes as repeated measurements.
It also correctly separates on-policy total-system comparisons from
same-history carrier comparisons.

One definition needs repair before L. The current memo defines lifetime as the
number of unique public EVENT assignments **plus admitted child LINK
assignments**, while also saying malformed or absent preallocated slots remain
failures. If admission depends on the treatment, this makes the x-axis partly
endogenous: a poor writer appears to have lived a shorter life.

Use the exogenous coordinate:

```text
m_opportunity[r,t] = cumulative number of preallocated unique semantic
                     acquisition opportunities through cut t
```

Every missing/malformed/unsupported slot counts in that opportunity clock and
scores zero for acquisition. Report separately:

```text
m_admitted[r,t] = cumulative exact admitted child EVENT/LINK assignments.
```

Fit lifetime slopes and AUC against `m_opportunity`, never treatment-dependent
`m_admitted`. This preserves the intuitive statement “same amount of life”
even when one system learns less from it.

Five cuts can support a finite slope/AUC test but not saturation. The proposed
seven-cut extension, late equivalence intervals, continued new evidence,
oracle headroom, and doubled-access sensitivity are the minimum credible
plateau design. Curvature/second derivatives are unnecessary and statistically
expensive; a prospectively fitted slope/plateau model is enough.

## 8. Compression audit

The current downstream memo is correct that three different quantities must
not be conflated:

- persistent bytes;
- semantic description bytes; and
- memory tokens returned into active context.

At current scale the LoRA loses the first comparison by orders of magnitude.
Zero returned tokens may establish an active-context bandwidth advantage, not
physical compression.

The proposed affine-schema sidecar can demonstrate that a child selected one
compact code from a supplied language and that a deterministic residual codec
reconstructs it. It does **not** demonstrate that DREAM discovered a schema,
that SLEEP compressed the child's life into the LoRA, or that the deployed
parametric state is smaller. It is a separate guided semantic-coding result.

For the full objective, there are only two honest routes:

1. Use **compiled/connected experiential knowledge** in the main paper and
   keep compression as a separate, explicitly supplied-schema sidecar; or
2. Scale the semantic load beyond the actual full adapter crossover and show
   exact/declared-distortion rate--utility superiority of the complete
   life-specific LoRA package over packed graph plus ordinary codec.

The second is unlikely within the current paper window. Do not use shorter
DREAM prose, paraphrase deduplication, rank, or tokens-per-episode as a proxy.

## 9. Single highest-information next experiment per GPU-hour

### Run: stage-gated two-root `PCFL-VERTICAL-DEV-v2.2`

Use v2.1 unchanged except for:

1. replace most/all differential synthetic PAD with prospectively
   target-token-matched authentic old replay or child-authored disconnected
   distractor blocks; retain any irreducible PAD only with an exact native
   PAD-sham nonharm gate;
2. require the full-objective DEV label to include native or service
   `LINK_ORGANIZATION_ADDED_VALUE` plus a causal LINK cut or semantic
   redirection; keep `EVENT_COMPOSITION_ONLY` as a valuable narrower terminal;
3. enforce source-diverse EVENT/LINK and OLD/NEW batching;
4. use the disposable authentic root for the fixed LOW-then-HIGH writer
   qualification above;
5. bind the future L clock to preallocated opportunity count; and
6. bind `FINAL_BATCH` as the recurrence attribution control released with L.

Then execute the existing stage order as **one experiment**:

```text
CPU collision/shortcut + exact text/graph ceilings       0 fits
disposable formation + writer qualification              1--2 fits
two DEV OLD formations                                    0 fits
S1 four-arm carriage/traversal per surviving root        8 fits max
native/service reachout + both public R continuations    0 fits
S2 full/full/old-replay per surviving root                6 fits max
```

Why this wins information per GPU-hour:

- Formation failure stops before training.
- Exact-text failure repairs the assay rather than spending LoRA fits.
- S1 separates formation, event carriage, source binding, connection value,
  modular traversal, and native use.
- Reachout separates stored world knowledge from a global action bias.
