## Three native stages

1. EXPOSE: four actual offered-edge actions and child EVENT responses per world,
  32native calls total. Keep every malformed response/failure; never reconstruct
   missing child events. Source receipts must replay before downstream use.
2. TEACH: only the two TRAIN collections. Four tasks/world, with both opposite
   goals under each identical display order; six actual child turns/task gives
   48source-grounded targets. Algorithmic parent guidance shows the actual
   CURRENT→intermediate→GOAL source edges and next command. Returned child text
   is never substituted. All parent guidance is absent from student sleep
   prefixes. PROBE cases and baseline scores never enter this parent stage.
3. BASELINE: fresh unchanged37ec process on both PROBE worlds, four tasks each
   under OWN_TEXT and UNAVAILABLE, at most96native actor calls. The stored text
   is the actual captured child source. Report all cases, first choices, legal
   commits and fixed-display goal pairs(0,2),(1,3). Pair success requires BOTH
   goals, distinct source-correct first ports and two committed legal moves per
   case. Include deterministic no-memory first-port reference (paired0/2 per
   world), not merely aggregate goals. Scores never gate or revise teaching.

This48-target first check is smaller than the earlier suggested64–128-row
default; it is deliberately the smallest two-world test with all four goal/order
combinations, not a claim that the full skill curriculum/default is complete.
The prediction is successful actual-source collection and coached execution;
unassisted pair competence is measured, not assumed. Failed sources/lessons
remain evidence and make the affected downstream material not ready. No hidden
retry, synthetic target repair or data-dependent case dropping.
