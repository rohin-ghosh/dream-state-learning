# Closed-loop kickoff and Level-1 scope

**Date:** 2026-09-13 PT  
**Status:** current architectural reading; no new model/GPU authority or claim

## The kickoff behavior

The smallest behavior that turns stored experience into a learning loop is not
mere recall and not merely writing a NOTE. It is this complete transition:

```text
own action -> public outcome -> grounded EVENT/LINK write
  -> later self-issued cue/READ under a goal
  -> recovered content changes the next action
  -> the new outcome becomes new experience
```

SEQ195 now supports only the write/retain part on one exposed bank. The reduced
Stage2A screen asks whether one adapter can operate the four controller
functions needed by the later junction: SEEK, PROSPECT, CHECK, and CONTINUE.
The two-SLEEP junction is the first test of the whole transition above.

The operational kickoff is therefore **a self-issued memory operation whose
content changes a held action**. Without it, retained memories are inert. A
correct action without the self-issued route is insufficient because it cannot
show that accumulated experience entered the decision.

## What “reduced” does and does not mean

The 560-call screen reduces repeated evaluation cells, not child capability.
It trains the same four coupled functions as the full Stage2A curriculum and
keeps the same memory, thought, and action interfaces. It defers extra chains,
the simultaneous CLOSED curriculum, and attribution fits until one BIRTH
checkpoint qualifies. Existing Level-1 skill artifacts remain preserved.

## Repetition

There are two distinct repetition mechanisms:

1. **Writer-level replay:** fixed rehearsal during SLEEP so old supported
   experience is mixed with new experience. SEQ195 qualifies this only on one
   exposed same bank; it is infrastructure for the junction.
2. **Learned selective rehearsal:** the child notices which ideas, failures,
   or procedures need more practice and schedules their re-use. This is a
   candidate Level-2 anti-asymptote behavior, not yet demonstrated.

The first stays on now. The second should be tested only after the authentic
loop turns, because no downstream signal presently identifies whether a
self-selected rehearsal was useful.

## Local proxies and multiple classrooms

During development the child should optimize explicit local goals rather than
know the sealed final evaluation. When multi-classroom scaling becomes timely,
the clean first test is a fixed total lesson budget with 2/4/8/12 disjoint
classrooms, per-classroom held sets, and one mixed replay sleep. Compare against
serial interleaving at the same examples, presentations, updates, and token
budget. This is downstream of the two-SLEEP junction; it must not delay the
current controller gate.

## Anti-asymptote order

After the loop first works, add behaviors only when a measured bottleneck calls
for them: selective repetition, branch exploration, cross-episode comparison,
uncertainty calibration, stopping/depth control, prospective goals, and
meta-review. Test each through later action and retention, not by counting its
words in the thought stream.

This ordering preserves the full vision while preventing Level-1 feature work
from becoming an unbounded prerequisite to observing the first causal loop.
