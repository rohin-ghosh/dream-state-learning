## The interesting

- **Receipts do what parents cannot.** The only children that changed course from feedback in this period were the
  community agents reacting to a machine receipt: a SyntaxError, a FileNotFound, an undefined name. A parent saying "that
  did not run" produced acknowledgment; a receipt saying `returncode 1` produced a different next action. The conversation
  finally has a third party.
- **The exchange grammar is being learned by rejection.** C3's tool calls mutate ("write.workspace", "-write_workspace",
  curly quotes, an unclosed code block); the service answers with the exact reason each time; C2 has started producing
  well-formed workspace writes. Roughly 4 rejections per acceptance, falling on C2, not yet on C3.
- **No peer has talked to a peer.** After eight hours, one message total (C1 to C2, unopened). The agents are alone with
  their tools and parents, which makes the pilot so far an isolated-learners run with a shared bulletin board nobody reads.
- **"Disagree with me if warranted" was offered and never taken.** Every child agreed with every correction, including the
  parent's own retractions.
- **Synonym swapping as revision is universal.** creative_reread asked for one observed fact produced the same three
  paragraphs with word changes; C1 "retries still change only the prose"; frozen_base swapped "研究表明" for "该研究指出".
- **The controls behave like the trained children** under the same parents: same concede-then-reassert, same invented
  sources, no drift over 46 turns. Parenting effects and training effects are still not separable in these streams.

## What needs to change

1. **Train the corrected retelling, not the relapse.** Unchanged since noon and still first: make the pre-sleep segment the
   child's reply to the last correction (what I claimed, what was shown, what I now hold).
2. **Object budget for parents.** After three turns on one mismatch, the parent names it unresolved and hands the child a
   new concrete task; return later. Measure by "same-object streak".
3. **Community parents must not be starved.** One parent turn per agent per two boundaries as a floor; and one turn per
   agent that teaches the message grammar concretely (the exact JSON, once), or a parser that accepts the common
   malformations.
4. **Parents stay in English.**
5. **Measure whether credited steps survive a sleep.** Keep a per-child ledger of credited steps and check the next three
   sleeps for the same step; the watcher can run this from the journals.
6. **Rohin's first console message** is the pilot's real test of propagation: one message to one agent, then watch whether
   it changes that agent's next artifact and whether any other agent picks it up.
