# Fresh ICLR area-chair audit: shortest decisive evidence path

**Date:** 2026-09-13  
**Role:** skeptical ICLR area chair and experimental strategist  
**Evidence cut:** `4a85135031be5165288634e9a9cfbeb472327c65`  
**Scope:** repository/evidence/manuscript audit only; no source, model,
tokenizer, benchmark, adapter, GPU, or scientific execution

## Executive verdict

The project has a coherent scientific thesis and unusually strong failure
instrumentation, but it does not yet have the result that would make that
thesis an ICLR paper. The strongest completed evidence is:

- bounded source-withdrawn carriage of child records;
- a measured acquisition--retention tradeoff;
- immediate answer-free process steering while advice is present; and
- evidence that naive repeated personal writes can alter, ritualize, or damage
  an acting policy.

None of those results establishes connected experiential memory, native
goal-directed traversal, knowledge-seeking expansion, repeated-sleep lifetime
improvement, or superiority to strong textual memory. The current fallback is
honest, but as an area chair I would view it as a careful characterization of
known per-agent fine-tuning failure modes, not yet a strong ICLR contribution.

There is exactly one plausible short path to the full paper: finish the
executable PCFL v2.2 vertical, and—only if it passes—extend the same frozen
mechanism into the already-designed hierarchical PCFL-STREAM campaign. Do not
spend another builder day on generic writer, contrastive, rank, CompilerGym, or
parenting scouts before that path is runnable. Those studies may use otherwise
idle capacity, but they must not consume the critical engineer or select the
PCFL mechanism.

The calendar is severe but not yet impossible. The official ICLR 2027 abstract
deadline is **Sep 18, 2026 23:59 AOE** (Sep 19 04:59 Pacific); the paper
deadline is **Sep 25 23:59 AOE** (Sep 26 04:59 Pacific). The abstract must be
genuine, the main paper is limited to nine pages, and an AI-use statement is
required. A bracketed prospective abstract is not a submission abstract.

## What changed after the latest results

The newest writer-repair experiment does not qualify SLEEP. Own-source replay
retained all `143/143` items that the starting adapters got right, versus
`135/143` under extra memory repetition, but acquired less new memory:
`21/30` exact and `19/30` paraphrase versus `27/30` and `23/30`. Replay passed
only `2/3` roots. This is useful evidence that replay moves the
stability--plasticity frontier, not evidence that it solves it.

The coaching experiment likewise sharpens rather than closes parenting.
Advice improved its targeted fields while present (`48/48` versus `38/48`),
but after advice removal and one write, coached and neutral children tied
exactly (`45/48` each, versus `27/48` before writing). Child records carried;
the lesson-specific advantage did not.

These outcomes make further proxy scaling low information. PCFL's authentic
writer qualification already tests the unresolved conjunction on the exact
paper surface: acquisition, locality, task retention, native legality, and
rollback. It should decide the next scientific branch.

## Ranked next actions by information per GPU-hour and calendar criticality

### 1. Close PCFL v2.2 execution readiness now — zero GPU hours, absolute blocker

The committed tree still has **0/5 readiness blockers closed** and none of the
five named PCFL runtime/test paths. The shortest closure is one machine-readable
v2.2 preparation contract plus a pure CPU validator that binds the exact
renderer/parser, ninth wrapper, root/counterpart/replay/cut maps,
source-diverse five-epoch schedules, conservative LOW-to-HIGH state machine,
and complete request/resource inventory. Runtime should consume that artifact,
not make score-bearing decisions.

The current `main.tex` is not a submission manuscript: it is 2,001 lines of
historical append-only evidence, announces itself as an ongoing working draft,
and predates the terminal replay/coaching evidence. In parallel with runtime
closure, begin a clean nine-page PCFL-centered manuscript rather than patching
that chronology again. Results cells can remain blank internally, but the
argument, methods, figures, related work, limitations, AI-use disclosure, and
reproducibility structure should be written now.

### 2. Predeclare raw chronology and build the strong-text ceiling in parallel — near-zero training

Preserve exact native chronology and masks before any DEV outcome. This costs
no fit and prevents the most likely reviewer-fatal omission: no comparator
currently asks whether DREAM compilation helps beyond training the same LoRA
on the child's chronological assistant continuations.

Build and certify ACTIVE_LINKED_TEXT, FULL_CHILD_TEXT, NATIVE_CONTEXT, RAW_RAG,
and EXACT_WITNESSED_GRAPH on excluded roots while PCFL runtime is completed.
This is predominantly CPU state plus actor inference. If exact text/graph
cannot solve, the benchmark is invalid; do not train around it.

### 3. Run the stage-gated two-root PCFL v2.2 DEV — at most 15--16 fits / about 20 A40-hours

Use the disposable LOW (`3e-5`) qualification first and HIGH (`3e-4`) only
when LOW is valid and safe but misses semantic acquisition. Then open the two
untouched roots. Stop each root at the first failed seam. The correct DEV pass
requires connected added value, native use, relevant reachout, NEW formation,
OLD retention, and delayed OLD+NEW success on both roots; an
`EVENT_COMPOSITION_ONLY` result is useful but not a full pass.

This experiment dominates another generic writer test because it resolves the
actual paper chain and fails cheaply at the exact broken surface.

### 4. If DEV passes, run four quarantined raw-replay DEV fits — about 2 A40-hours plus readout

Run S1 and the prospectively designated S2 continuation for both roots. Match
base child, history, optimizer, rank, update count, and native interface. Do
not test raw replay through the compiler's private READ API.

- compiled wins: carry a bounded DREAM-increment claim forward;
- tie: retain whole experiential-learning claims but remove compiler advantage;
- raw wins: do not scale the addressed compiler;
- neither works: the writer remains the bottleneck.

### 5. Qualify the one-epoch large-corpus writer — four fits / about 22.2 A40-hours

Only after DEV passes. Compare FULL and ONE_EPOCH_SCALE at the fixed 157- and
571-block excluded histories. Require absolute carriage, locality, connected
service, native use, generic canary, PCFL-specific retention, and itemwise
compatibility at both sizes. If the reduced writer fails while FULL passes,
the 16-lineage FULL design costs about 616 A40-hours and is unlikely to be the
best submission-week bet.

### 6. Run one combined N=16 confirmation/lifetime campaign — about 142.4 A40-hours plus inference

This is the minimum high-value paper run, not two separate campaigns. The
entry cut confirms the two-SLEEP mechanism and all 16 roots run ATOMS. The
same lineages then continue through four novelty-growing cuts under
DLT_PERIODIC, SLEEP_FROZEN, and ACTIVE_LINKED_TEXT; same-history text/RAG/graph
readouts piggyback on each DLT cut. Use the exogenous scheduled-opportunity
clock. Freeze the reusable-structure stratum before launch; opaque routes alone
are a valid retention assay but give a lossless linked graph little reason to
saturate or lose.

After all 16 complete, use only the blinded paired-AUC variance rule to decide
whether `N=24/32/48` is necessary. Do not turn tasks, decodes, modules, or
checkpoints into independent samples. At N=16, `14/16` complete entry seams is
only a reliability gate; population claims still rest on root-level intervals.

### 7. Add plateau, compression, and recurrence only conditionally

- If core lifetime and baseline comparisons pass and the text curve is
  plausibly flat with graph headroom, add the two presealed cuts. Qualified
  one-epoch N=16 training rises from about 142.4 to 269 A40-hours total. This
  is the only route to the word *saturated*.
- If connected utility passes, run the zero-new-fit predictive-reuse sidecar
  (designed cap under 4 A40-hours). Disclose the roughly 80.8 MB adapter and do
  not call it physical compression.
- Run matched terminal-batch controls only if claiming that periodic write
  timing itself matters. DLT_PERIODIC versus SLEEP_FROZEN already tests the
  on-policy whole learner; it does not prove recurrence beats one final fit.
  Equal-work terminal batches are expensive and should not precede the main
  lifetime result.

The repaired ALIGNED/SWAPPED/NO_PARENT parenting assay is informative and
cheap (`<=5` A40-hours), but it is off the critical path. Run it only with a
separate owner or otherwise idle capacity; do not let it delay PCFL source,
zero-fit closure, or manuscript work.

## Decisive failure and fallback boundaries

1. **PCFL invalid or formation fails:** repair only that zero-fit/scaffold
   seam on excluded roots. No writer or lifetime fit. The current fallback is
   a careful negative/characterization manuscript, not the full thesis.
2. **Content carries but LINK adds no value:** claim event carriage and
   read-time composition only. Do not call the knowledge compiled/connected.
3. **Service passes but native child fails:** claim a bounded generative
   parametric-memory service, not a Dream--LoRA--Think organism.
4. **The two-root relay passes but confirmation reliability is below `14/16`:**
   report a fragile mechanism; no general lifetime promotion.
5. **Confirmed relay passes but DLT does not beat its own frozen writer:** the
   central finite-lifetime flywheel is falsified under this mechanism. Stop;
   text superiority cannot rescue it.
6. **DLT beats FROZEN but not ACTIVE_LINKED_TEXT:** this can still be a
   defensible paper about authentic parametric lifetime learning. Remove
   memory-superiority and saturation claims.
7. **DLT beats finite text but doubled text access still helps:** report the
   exact configuration comparison only; never say the baseline saturated.
8. **Predictive reuse fails:** remove *compressed* everywhere. No other result
   rescues that adjective.
9. **Raw replay ties or wins:** remove DREAM/compiler incremental claims. A
   positive DLT-versus-FROZEN result may still establish a whole experiential
   learner.

The strongest fallback that remains scientifically coherent is therefore
hierarchical: independently confirmed two-SLEEP relay even if lifetime fails;
finite lifetime learning even if linked text wins; exact-system superiority
even if plateau fails; and conditional semantic reuse only if its separate
assay passes. The existing writer-failure paper should be retained as the
last fallback, but it should not be mistaken for evidence of the full thesis.

## Missing controls that must not disappear

1. Same-history `RAW_CHRONOLOGICAL` LoRA: compiler increment.
2. `S1_ATOMS` plus critical LINK cut/permutation: connection added value.
3. Native mounted thinker: avoids proving only a private memory service.
4. `SLEEP_FROZEN`: whole recurrent learner effect.
5. ACTIVE_LINKED_TEXT with a frozen access curve and doubled-budget check:
   strong memory and any plateau language.
6. Same-DLT-history linked text/RAG/graph: separates carrier from on-policy
   history quality.
7. Exact graph/full-text ceilings and no-memory/shortcut floors: benchmark
   validity.
8. Task-specific retention, not generic canary alone: the generic canary has
   already missed major semantic erasure.
9. Terminal same-history batch if claiming periodic timing/recurrence.
10. Independent-continuation null and adapter removal if claiming predictive
    semantic compression.

## Area-chair bottom line

The paper becomes compelling if it shows one causally complete personal-memory
relay and then demonstrates that the same frozen mechanism improves later
actions over a growing life, with honest failures and a strong linked-text
opponent. The architecture need not solve parenting or physical compression
to be valuable. It does need to stop substituting component post-training
success for authentic closed-loop learning.

The next commit that matters is executable PCFL, not another analysis memo.
The next GPU-hour that matters is the first authentic PCFL carrier fit, not
another generic writer or teaching dose.
