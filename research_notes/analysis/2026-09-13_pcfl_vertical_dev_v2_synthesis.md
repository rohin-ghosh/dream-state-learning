# PCFL vertical DEV v2.1: shortest authentic child-authored THINK/DREAM/SLEEP slice

**Date:** 2026-09-13 UTC  
**Status:** implementation-ready design only; no source authoring or execution  
**Evidence cut:** repository through `f8b30e39`  
**Purpose:** freeze the shortest DEV protocol that can tell us whether a child can
turn its own experience into connected parametric memory and later use OLD and
NEW experience together, without confusing that result with prompting,
researcher-authored post-training, retrieval candidates, or a world shortcut.

**v2.1 repair:** this revision incorporates the independent final-skeptic audit
at commit `405c5db4`. It groups exact child spans into the same multi-row
responses the memory API scores, forbids textual OLD-memory reinjection after
SLEEP 1, makes native memory-dependent reachout explicit, defines both ATOMS
contrasts, retains every control artifact, and corrects the later on-policy
comparison language. The fitted roster remains fourteen.

## 0. Decisive ruling

Build one vertical experiment, not another disconnected ladder:

```text
THINK: child acts -> receives public outcome -> authors EVENT/LINK commitments
  |
DREAM: child commitments are selected and arranged; no semantic field is added
  |
SLEEP: mechanical verification/replay/packing -> conservative LoRA write
  |
THINK: reset child reads and uses the memory, reaches out once, authors NEW
  |
DREAM + SLEEP: OLD and NEW are jointly rewritten
  |
THINK: reset child executes one candidate-free delayed route
```

This is the first authentic learned-memory slice because every claim-bearing
semantic target is a byte span generated by the child after a real public
outcome. The compiler verifies and transports those spans; it does not write
their meaning. A fixed renderer, researcher answer, parent sentence, checker
explanation, or future-goal-derived row is not an authentic target.

The fresh construct attack changes one piece of the earlier proposal. `LINK`
is derivable from complete `EVENT` endpoints in this world. Therefore SLEEP 1
must include `S1_ATOMS` and the strongest possible link conclusion is bounded:

> Exact child-authored EVENT and LINK rows were sufficient life-specific
> targets. Under a fixed local-memory budget, stored LINK organization added
> value over the same EVENT atoms **only if** AUTH beats ATOMS.

If ATOMS ties AUTH, the result is still connected event composition; it is not
stored-link added value. This is a reportable branch, not an excuse to redesign
the world after looking.

The shortest sound fitted design is consequently **seven fits per DEV root**:

```text
SLEEP 1: S1_AUTH, S1_ATOMS, S1_EVENT_TWIN, S1_LINK_PERMUTE
SLEEP 2: S2_FULL_R0, S2_FULL_R1, S2_OLD_REPLAY
```

Use two independently generated DEV roots: **14 fits total**. The complete
eight-world collision cube is generated and audited for every root, but it is
an identifiability certificate, not eight separately trained lives. This
keeps the decisive fitted test small.

Do not serialize this behind Q0, E0-r, Level 1/M1, parenting, or a compression
experiment. Those are parallel evidence. Q0 has already shown why this slice
must score semantic content separately from surface format: the base model
often had the right row behind fences, while ordinary fitting mainly changed
format and source choice. It also showed that a first-update all-row monotonic
gate is objective-incompatible and must not be reused here.

## 1. Claim contract

### 1.1 What a complete two-root DEV pass permits

A complete pass permits only:

> In two development worlds, a scaffolded child converted its own public
> action/outcome receipts into exact typed memories. A low-rank personal write
> carried those memories after reset. The child then selected a relevant
> experiment in a registered memory-dependence contrast, authored a new memory
> without textual OLD-memory reinjection, retained old memory through another
> write, and solved a candidate-free delayed task whose correct command was
> jointly identified by OLD and NEW information.

The modular endpoint may additionally say that a clean thinker traversed a
goal-blind parametric memory service. The native endpoint may say that the
personal adapter, mounted in the actual THINK/action model, succeeded on an
OLD+NEW-identifiable task.

### 1.2 What DEV does not permit

DEV does **not** establish:

- population or paper-grade frequency;
- improvement over a strong linked-text memory;
- autonomous initiation of memory formation;
- parameter-level proof that the native actor used OLD and NEW separately;
- a continual-learning curve, retention over a long lifetime, or saturation;
- parenting benefit, general-domain transfer, or learned pedagogy;
- physical compression by LoRA; or
- whole-organism, sentience, alignment, or superintelligence claims.

The typed commitment prompt is a scaffold. The child supplies the semantic
arguments; it is not being credited with inventing the grammar.

## 2. The architecture stays simple

### THINK

THINK is the child's continuous token/action loop. It may plan, doubt, judge,
act, observe, and revise. Tool actions occur inside the same stream and public
world replies become the next state. A stopping rule ends the current task;
it does not imply that the organism has stopped thinking forever.

For this minimum slice, do not add thought swarms, branch merging, parents, or
parallel classrooms. They are later scaling mechanisms, not prerequisites for
testing whether one authentic state-to-state memory path works.

### DREAM

DREAM has two deliberately small jobs:

1. during wake, keep the active task state within context; and
2. after a task, let the child emit typed semantic commitments from its own
   public experience.

Use ordinary hierarchical context handling: recent turns verbatim, current
goal/state/open questions in a short edited state, and older raw bytes in the
immutable ledger. No learned compactor is required here. No compression claim
is measured upstream of useful memory.

### SLEEP

SLEEP mechanically verifies child rows, applies fixed varied wrappers, replays
accepted rows, packs examples, writes the LoRA, and accepts or rolls back the
candidate adapter using frozen gates. SLEEP may reorder, duplicate, and wrap
meaning; it may not originate or repair meaning.

The child's weights change across SLEEP. The writer recipe does not change
inside a root.

## 3. Exact thinker/compiler boundary

The only semantic formation grammar is:

```text
EVENT <event_id> AT <source> DID <port> GOT <destination> EVIDENCE <receipt_id>
LINK <link_id> FROM <event_id_1> THEN <event_id_2> VIA <shared_node> EVIDENCE <receipt_id_1>,<receipt_id_2>
```

All identifiers are opaque fixed-width ASCII strings selected to have equal
token lengths under the frozen tokenizer. One commitment is one physical
line, single ASCII spaces, one terminal LF, no Markdown fence, prefix, suffix,
or normalization.

During initial OLD formation, the child sees a public receipt when it proposes
`EVENT` and may use prior public events still present in that same causal wake
context when it proposes `LINK`. Later goal prompts, hidden bits, oracle routes,
candidate rows, evaluator scores, and expected answers are absent.

After SLEEP 1 the native lineage is reset and the visibility rule is stricter.
It receives only the ordinary future goal/probe interface, its own newly
generated thought state, the public outcome of its committed probe, the new
executed-event receipt, and the same fixed target-free commitment grammar. The
harness injects **no** OLD receipt, admitted EVENT/LINK row, roster, ledger
excerpt, memory-service return, or compiler state. To author either NEW LINK,
the mounted child must reproduce the needed OLD event identifiers through its
own parametric state. A separate mechanistic read-service fork may expose raw
goal-blind service returns, but that fork is logged, read-only, and can never
become the native lineage. The R0/R1 continuations restore one byte-identical
sealed native pre-outcome state; only the ordinary public outcome changes.

The compiler may:

- check exact syntax, chronology, and receipt identity;
- check that every EVENT field is copied from the cited public receipt;
- check that `destination(event_1) == source(event_2) == shared_node`;
- accept or reject the whole child line;
- exact-copy accepted bytes;
- select, order, group, shuffle, replay, and pack accepted whole lines;
- prepend one of eight fixed loss-masked request wrappers;
- attach non-target evidence IDs, byte offsets, and hashes; and
- run format, source, no-harm, and rollback checks.

The compiler may not:

- repair syntax, choose a missing identifier, or canonicalize a semantic
  value;
- render an EVENT from a receipt or infer a LINK from endpoints;
- paraphrase a target or create an action, belief, plan, or memory;
- select a row using a future task, hidden graph, reward, or answer;
- train on parent/checker prose; or
- silently remove malformed proposals from a denominator.

Exact child span hashes and custody prove authorship. A researcher-authored
identical row is not a useful authorship ablation because it contains the same
information. Semantic derangements are controls and are permanently barred
from authentic lineage.

## 4. Exact opaque route world

### 4.1 One base skeleton

Each root samples fresh opaque node, port, event, link, probe, receipt, and
goal identifiers. The topology below is structural; none of these mnemonic
slot names reaches a model.

For OLD bit `O in {0,1}`, the eight witnessed old EVENT slots are:

| slot | public transition |
|---|---|
| `e0` | `S_L --a_O--> A` |
| `e1` | `A --b--> H` |
| `e2` | `H --c--> G_L` |
| `e3` | `S_R --d--> B` |
| `e4` | `B --f_0--> G_R0` |
| `e5` | `B --f_1--> G_R1` |
| `e6` | `S_L --a_(1-O)--> X` |
| `e7` | `Z --u--> Y` |

The four witnessed old LINK slots are:

```text
l0: e0 THEN e1 VIA A
l1: e1 THEN e2 VIA H
l2: e3 THEN e4 VIA B
l3: e3 THEN e5 VIA B
```

Thus changing `O` swaps the two opaque port labels attached to `e0` and `e6`
without changing any identifier or token marginal. The old route commands are:

```text
OLD_LEFT:  ROUTE S_L G_L  : a_O,b,c
OLD_RIGHT: ROUTE S_R G_R0 : d,f_0
```

After SLEEP 1, the child is shown a future route objective from `S_L` to one
of `G_R0/G_R1` and exactly two symmetric public probe affordances. One probe
tests the missing `H -> S_R` frontier; the other tests an isolated matched
frontier. Their opaque order is balanced. The relevant result bit is `R`; the
distractor result bit is `D`.

The relevant result identifies which opaque port connects the frontier:

```text
e8: H --q_R--> S_R
l4: e1 THEN e8 VIA H
l5: e8 THEN e3 VIA S_R
```

The child must first choose the relevant probe, then execute `q_R`, receive a
normal public receipt, and author exactly this one NEW EVENT and these two NEW
LINKs. A distractor probe supplies one equally uncertain public bit but no
route information.

The two delayed goals have unique successful commands:

```text
G=0: ROUTE S_L G_R0 : a_O,b,q_R,d,f_0
G=1: ROUTE S_L G_R1 : a_O,b,q_R,d,f_1
```

Deleting registered OLD event `e0` or registered NEW event `e8` destroys
every successful delayed route. There is no alternate route.

### 4.2 The eight-world collision cube

Every base skeleton expands before use to:

```text
(O,R,D) in {0,1}^3
```

At fixed `(root,O,G)`, the four `(R,D)` cells have byte-identical visible
history, task prompt, probe schema, probe ordering, and identifiers until a
probe outcome is returned. The exact table is present once each:

```text
(R,D) = 00, 01, 10, 11
```

Therefore both probe outcomes have one bit of entropy, the relevant bit has
one bit of goal information, and the distractor has zero:

```text
H(Y_R)=1, H(Y_D)=1, I(Y_R;Z_G)=1, I(Y_D;Z_G)=0.
```

The OLD-only projection omits all NEW receipts and rows. At fixed
`(root,O,D,G)`, it is byte-identical across `R=0/1` while the correct command
changes. The NEW-only projection omits all OLD receipts and rows. At fixed
`(root,R,D,G)`, it is byte-identical across `O=0/1` while the correct command
changes.

At fixed `(root,G)`, all eight native task prompts are byte-identical and have
exactly four correct commands, each occurring twice because `D` duplicates
the label. The prompt-only deterministic ceiling is therefore exactly `.25`.

### 4.3 Which cube cells are fitted

The cube is an exhaustive construct certificate, not eight trained children.
For the two DEV roots, preseal realized OLD bits as `O=0` and `O=1`
respectively. S1_AUTH uses that realized life. S1_EVENT_TWIN uses the other
coherent OLD world as a synthetic source-binding control. After the one
presealed primary reachout attempt, fork the same authentic pre-outcome child
state into the two possible public relevant outcomes `R=0/1`; the child
authors NEW separately in each continuation. `D` is never injected into an
authentic lineage; its counterfactual cells establish equal entropy and
irrelevance.

Only one presealed R continuation is marked as the canonical branch for any
later lifetime. Both are valid DEV continuations and both are fitted here.

## 8. Frozen local memory service

The service has three candidate-free calls:

```text
READ EVENTS_AT <node_id>
READ EVENT <event_id>
READ LINKS_FROM <event_id>
```

The response is either an exact query-level materialization or the exact token
`MISS`. Before any fit, the compiler constructs and hashes one deterministic
query-to-response table:

- `READ EVENT e` returns the one admitted child EVENT span for `e`;
- `READ EVENTS_AT n` returns the concatenation of **all** admitted child EVENT
  spans sourced at `n`, sorted by event ID;
- `READ LINKS_FROM e` returns the concatenation of **all** admitted child LINK
  spans sourced from `e`, sorted by link ID; and
- an absent address returns `MISS` only where the arm explicitly declares a
  qualified no-row target. Otherwise unseen-address refusal stays an empirical
  gate and is not secretly trained.

The multi-row separator is exactly one LF; the final row keeps its terminal LF.
The parser and hash bind these bytes. Grouping is compiler-safe because it
only concatenates accepted exact child spans and adds no semantic field.
Maximum adjacency is two, so there is no pagination ambiguity.

At S1 this yields 17 scored service requests per full arm: eight `READ EVENT`,
six distinct `READ EVENTS_AT`, and three `READ LINKS_FROM`. ATOMS has only its
14 EVENT-bearing request blocks; LINK addresses are held out rather than
trained false. At S2 each FULL arm yields 19 blocks: nine, six, and four
respectively. OLD_REPLAY retains the 17 OLD request blocks; future NEW
addresses are held out. Controls match total examples, active target tokens,
batches, and updates through parser-disjoint padding, not through invented
semantic responses.

At the mechanistic endpoint:

- a clean frozen C0 actor sees the ordinary task and selects reads;
- a separate C0+LoRA memory worker sees one local request only;
- the worker never sees the task, goal, actor history, candidate rows, score,
  hidden graph, or expected answer;
- raw generated worker bytes, including malformed bytes, enter the actor;
- the actor gets at most 12 reads, 4096 returned memory tokens, and 2048 own
  tokens; and
- request/response bytes and source receipts are logged.

For `S1_ATOMS`, no LINK response is a training target; it may spend the same 12
reads composing from EVENT calls. At evaluation, LINK-address calls are held
out and must yield zero usable false LINK rows, but exact `MISS` is not required.
For `S2_OLD_REPLAY`, old multi-row requests contain only OLD child spans; NEW
addresses are held out and likewise must yield zero usable false rows. This
prevents a control from being poisoned by training it to assert a false absence.

This endpoint isolates parametric carriage and goal-directed traversal. An
opaque public address copied into an actor-authored local request is allowed;
an answer-bearing candidate bank is not.

Score memory output in two columns:

1. **semantic exactness:** every required semantic field is correct; and
2. **strict surface exactness:** the entire returned response block matches
   the registered concatenation of admitted child bytes.

Never convert a fenced but semantically right answer into strict success. This
is the direct lesson from Q0/perception.

## 10. Exact SLEEP recipe

Use the frozen C0 checkpoint (`Qwen2.5-7B-Instruct` in the current harness)
with its exact model and tokenizer hashes bound before materialization. No
birth/parenting adapter is mounted in this DEV.

| knob | frozen value |
|---|---|
| trainable object | one personal LoRA; base frozen |
| target modules | q/k/v/o and gate/up/down projections, every layer |
| rank / alpha / dropout | `r=8`, `alpha=16`, `dropout=.05` |
| dtype | bf16 |
| optimizer | AdamW, betas `(.9,.999)`, eps `1e-8`, wd `.01` |
| LR / clipping | `3e-5`, global grad norm `1.0` |
| batch / accumulation | `4 / 1` |
| max sequence | `512`; zero target truncation permitted |
| formatting | frozen chat template, EOS, no packing |
| loss | response-only; wrappers and metadata masked |
| views | 8 presealed wrappers per query-level response block |
| epochs | 5 |
| initialization | clean C0 tensors and fresh optimizer for every fit |
| ordering | one presealed target-free shuffle, coupled across controls |
| checkpoint selection | final checkpoint only; no best-of-run choice |

The eight wrappers vary neutral request phrasing/order but never the registered
query-level target block. Repetition and varied views are writer mechanics
supported by the existing high-dose authored-memory evidence. This DEV does
not claim they are optimal.

Each arm has exactly 20 query-response slots:

```text
S1_AUTH / EVENT_TWIN / LINK_PERMUTE: 17 semantic blocks + 3 PAD
S1_ATOMS:                            14 semantic blocks + 6 PAD
S2_FULL_R0 / FULL_R1:                19 semantic blocks + 1 PAD
S2_OLD_REPLAY:                       17 semantic blocks + 3 PAD
```

Padding uses disjoint never-called `PAD_S1_<id>` / `PAD_S2_<id>` requests.
Padding targets live in an unparseable control namespace and contain no node,
port, event, link, receipt, route, or outcome identifier. They never answer a
real service call.

After native tokenization, choose one presealed stage-level target-token budget
equal to the longest arm plus a fixed feasible padding reserve. Distribute each
arm's exact deficit only across its padding targets. Require identical total
loss-active target tokens, examples, batches, and updates across arms; require
every padding target to remain parser-disjoint and every sequence to remain
below 512 tokens. If exact equality cannot be materialized with the bound
tokenizer, stop before fitting as `VS_ASSAY_INVALID` rather than altering dose.
Per-token loss weights, fractional examples, duplicated semantic requests, or
trained false `MISS` rows are not fallback equalizers in this version.

Thus the frozen optimizer arithmetic is:

```text
S1 or S2: 20 query-response slots x 8 views = 160 examples/epoch
          160 / batch 4 x 5 epochs = 200 optimizer updates/fit

14 fits x 200 = 2,800 optimizer updates total
```

The manifest reports, for every arm, its 14/17/19 semantic response blocks,
padding blocks, exact target tokens, multi-row response shapes, and 200
executed updates. The token budget is fixed before DEV outputs are opened.

No first-update monotonic acceptance gate is allowed. Candidate acceptance is
based on final-dose absorption, interface, and no-harm gates below.

## 11. Exact fitted arms

### 11.1 SLEEP 1: four fits per root

| arm | semantic query responses + padding responses | role |
|---|---|---|
| `S1_AUTH` | 17 grouped reads over exact 8 EVENT + exact 4 LINK child rows; 3 PAD | only authentic S1 lineage |
| `S1_ATOMS` | 14 identical EVENT-bearing reads; no trained LINK address; 6 PAD | link-added-value control |
| `S1_EVENT_TWIN` | 17 grouped reads over coherent alternate-O 8 EVENT + corresponding 4 LINK rows; 3 PAD | event source-binding control |
| `S1_LINK_PERMUTE` | 17 authentic EVENT/grouped endpoint-incompatible LINK reads; 3 PAD | false-pointer diagnostic |

The stage-level padding responses use a disjoint unparseable control namespace,
carry no node/port/event/link identifiers, and are included only to equalize
loss-active target tokens. They are synthetic and never lineage.

`S1_EVENT_TWIN` is materialized from the presealed alternate O cube cell; it
preserves row counts, token marginals, identifiers, and link-handle graph while
swapping the coherent port binding. It is synthetic because those bytes were
not authored in the realized life.

`S1_LINK_PERMUTE` is explicitly a derangement, not a valid alternate world.
Because authentic LINK is endpoint-derivable, this arm can show that a false
pointer influences behavior; it cannot prove LINK information necessity.

All control adapters and corpora are immutably sealed, quarantined from
authentic lineage, and retained through independent reduction and claim
closure. They may be archived or deleted only under a later separately logged
retention policy. Only the exact pre-evaluation `S1_AUTH` state continues to
reachout/S2.

### 11.2 SLEEP 2: three fits per root

Restore the exact pre-evaluation S1_AUTH snapshot. Fork the pre-outcome child
into its two public relevant outcomes and independently collect exact NEW rows.

| arm | semantic query responses + padding responses | role |
|---|---|---|
| `S2_FULL_R0` | 19 grouped reads over exact 12 OLD + exact 3 child NEW_R0; 1 PAD | OLD+NEW authentic counterfactual continuation |
| `S2_FULL_R1` | 19 grouped reads over exact 12 OLD + exact 3 child NEW_R1; 1 PAD | OLD+NEW authentic counterfactual continuation |
| `S2_OLD_REPLAY` | 17 OLD grouped reads; no trained NEW address; 3 PAD | equal-work no-NEW control |

Every S2 fit starts from clean C0 and trains on the cumulative exact corpus;
it does not stack a new optimizer onto S1 weights. This preserves coupled
comparisons and prevents evaluation forks from contaminating lineage.

## 12. Noncompensatory gates

Fixed wording/order renders are technical repetitions, not independent roots.
Failures score zero; no retry, replacement, or favorable decode selection.

### 12.1 S1 carriage and traversal, per root

- EVENT local reads: semantic exact `>=15/16`, strict exact `>=14/16` under
  each arm's registered map; arm semantic scores differ by at most `1/16`.
- LINK local reads for AUTH, EVENT_TWIN, and LINK_PERMUTE: semantic and strict
  exact `>=7/8` under the registered arm target. ATOMS' held-out LINK-address
  calls must return zero usable LINK rows; exact `MISS` versus another
  registered non-row refusal is reported, not trained or required.
- Eight unseen-address plus eight wrong-root requests: `>=15/16` exact MISS
  or registered non-row refusal and `0/16` usable false rows.
- Candidate-free memory-service OLD route: S1_AUTH `>=14/16`, including
  `>=7/8` for each old goal; score S1_ATOMS under the identical 12-read,
  returned-token, and actor-token budgets.
- Candidate-free native OLD route: S1_AUTH `>=14/16`, strict legal commit
  `>=15/16`; score S1_ATOMS under the identical native prompt and token budget.
- EVENT_TWIN follows its alternate-O command on `>=12/16` and scores at least
  `4/16` below AUTH under authentic scoring.
- Goal-swap pairs change the correct route `8/8`; the memory-service query
  trace diverges by the second goal-sensitive read on `>=7/8`.
- Replacing the critical authentic local memory result with MISS drops
  service route success by `>=6/16`.

LINK added value is endpoint-specific and separately labeled:

```text
Delta_link_service = route(S1_AUTH service) - route(S1_ATOMS service)
Delta_link_native  = route(S1_AUTH native)  - route(S1_ATOMS native)
```

`>=4/16` earns `LINK_ORGANIZATION_ADDED_VALUE` only for that endpoint. Native
added-value wording requires the native delta; service-only success is named
as such. Otherwise label `EVENT_COMPOSITION_ONLY`. That branch is not an
overall root failure if AUTH itself passes.
LINK_PERMUTE redirection `>=12/16` may be reported as false-pointer influence;
failure to redirect is `LINK_DERANGEMENT_IGNORED`, not evidence against EVENT
composition.

### 12.2 Reachout, per root

The one lineage-entering reachout is emitted once, without retry, by the native
mounted `S1_AUTH` child from the sterile post-S1 context in Section 3. Require
the target-relevant probe on that presealed primary render. Only its committed
action receives a public outcome and enters either R continuation.

Use read-only forks of the same untouched S1 snapshot for two diagnostic
panels:

- native S1_AUTH over eight exactly probe-order-balanced surface renders must
  choose the relevant probe on `>=7/8`; and
- the clean actor plus S1_AUTH memory service must score `>=7/8` under the same
  budget. Replacing the critical OLD event group with `MISS`, using OFF, or
  using wrong-root memory must each score `<=4/8`, and AUTH must exceed each by
  at least `3/8`. Every raw service request/return is logged; no diagnostic
  fork enters lineage.

Invalid, missing, distractor, fixed-choice, or post-outcome choices score zero.
The eight views show surface robustness; the primary committed action earns
exactly one registered information bit. These endpoints establish
memory-dependent **task-relevant expansion after a revealed goal**. They do
not establish that experiment choice changes with the goal, because both
current future goals make the same frontier probe useful.

If the native primary action fails, the native panel fails, or the mechanistic
AUTH/cut/OFF/wrong-root contrast fails, label `VS_REACHOUT_FAIL` and stop that
root before S2. Do not reveal the relevant outcome anyway.

### 12.3 S2 carriage, retention, and joint use, per root

- Every critical OLD read remains within `1/16` of S1_AUTH after each FULL
  write.
- The three NEW rows achieve `>=5/6` held semantic-exact reads, with EVENT
  and LINK both represented; strict exact is reported separately.
- OLD route success after each FULL write remains within `1/16` of S1_AUTH.
- Each FULL candidate-free memory-service delayed panel is `>=14/16` exact
  and `>=15/16` legal.
- Each FULL candidate-free native delayed panel is `>=14/16` exact and
  `>=15/16` legal.
- Across balanced R0/R1 tasks, pooled FULL success exceeds OLD_REPLAY by
  `>=8/32`; OLD_REPLAY may not exceed `20/32`.
- Cross-mounting FULL_R0 on R1 and FULL_R1 on R0 redirects to the donor's
  registered command on `>=12/16` each (`>=24/32` pooled).
- A registered OLD local-result cut and NEW local-result cut each reduce
  service success by `>=6/16` per FULL arm.
- OFF and wrong-root service/native controls score `<=2/16` per DEV root and
  produce zero usable false memory rows.

The read cuts establish dependence at the modular interface. For native
mounting, report successful behavior on a generator-certified OLD+NEW task,
not separate parameter-level mediation.

### 12.4 Interface and no-harm gate

Run a frozen 40-item generic action/marker canary on C0 and every authentic
candidate adapter with common-random seeds. Require:

- legal action/marker form `>=38/40`;
- no more than `2/40` loss relative to C0;
- no all-row collapse, early-quit collapse, or private-dialect substitution;
- finite loss and gradients; and
- exact initial/final adapter hashes and rollback receipt.

A failed candidate is rejected and the prior authentic snapshot is restored.
The root is still a writer failure; rollback does not turn it into a pass.

## 14. Exact GPU and fit cap

The maximum is immutable:

- **14 adapter fits total**;
- **2,800 optimizer updates total** after query-level materialization;
- **30 wall-minutes on one A40 per fit**;
- **420 A40-minutes = 7 aggregate A40-hours of training**;
- **10 aggregate A40-hours maximum** for formation, zero-fit ceilings,
  memory-service probes, native probes, and canaries; and
- **17 aggregate A40-hours total** for the complete vertical DEV.

There is no rank sweep, dose sweep, technical-seed sweep, checkpoint search,
replacement root, or retry inside this cap. Profile one S1 and one S2 fit; if
either cannot finish within 30 minutes, stop with `VS_RESOURCE_CAP` rather
than silently raising the budget.

The profiled fits are the first scheduled `S1_AUTH` and, if reached,
`S2_FULL_R0` fits inside the fourteen-fit roster. Profiling does not authorize
an extra fit, replay, or checkpoint selection.

Parallel schedule:

1. CPU construct gate and zero-fit model ceilings run immediately, independent
   of Q0/L1.
2. Generate both DEV OLD lives concurrently.
3. Once a root forms OLD, launch its four S1 fits concurrently.
4. Evaluate only AUTH for progression; evaluate controls in parallel.
5. Run primary reachout and both public R continuations.
6. Launch the three S2 fits concurrently per surviving root.
7. Seal all outputs, then reduce once.

The root, not a surface render, outcome twin, goal, decode, or fit RNG stream,
is the scientific unit. Two DEV roots are mechanism debugging, not a
confidence interval.

## 16. What this releases next

### 16.1 If both DEV roots pass unchanged

Freeze the formation interface, compiler, sleep recipe, local read service,
native scorer, and thresholds. Release a combined confirmation/lifetime run;
do not call DEV itself the paper result.

Minimum mechanism confirmation:

- 16 independent child/world lineages;
- no replacement roots;
- the same authentic formation and candidate-free endpoints; and
- at least `14/16` complete roots for the mechanism claim.

Minimum lifetime comparison:

```text
DLT_PERIODIC       child-authored DREAM/SLEEP throughout
SLEEP_FROZEN       identical starting child, opportunity schedule, random
                   tape, budgets, and shadow-SLEEP transactions; never mounts
                   later writes and therefore owns its divergent THINK history
ACTIVE_LINKED_TEXT exact child rows through the same local service
FINAL_BATCH        same accumulated child corpus, one terminal write
```

Only the separate inference-only carrier table is same-history. On-policy
systems must never exchange actions, outcomes, rows, or later histories.

At presealed cuts, keep the same-history carrier table and native endpoint.
An experiential-learning claim additionally requires DLT_PERIODIC minus
SLEEP_FROZEN `>=.05` with a valid root-level interval, positive prospective
slope/anchor gain, retained OLD competence, and the canary/no-harm gate.

A strong-memory claim additionally requires ACTIVE_LINKED_TEXT to be fully
certified, an on-policy comparison and a same-history comparison pointing in
the same direction, and a `>=.05` effect with a valid interval. DLT is not
required to beat linked text in DEV.

### 16.2 Saturation and parenting

Saturation is a later hypothesis, not a visual plateau. It requires two
additional cohorts extending the horizon to seven total cuts, prospectively
frozen 90% equivalence intervals around both late improvements, and a doubled
memory-access diagnostic.

Only after the mechanism is frozen should clean, gym-naive saved babies enter
parenting. Parenting, deployment-gym learning, and evaluation must fork from
uncontaminated stages. No child that has played the held-out deployment gym
may return to a parenting lineage.

### 16.3 Compression remains downstream

Do not measure dream-token density or call rank-8 LoRA physical compression in
this slice. The current adapter is roughly 80.8 MB and is not smaller than
this tiny evidence set.

After connected lifetime utility exists, run semantic rate-distortion on a
separate candidate-free sidecar at exact budgets `K=4096` and `K=16384`:

- byte-exact round trip and zero false rows;
- plain and codec readers both at their frozen candidate-free utility gate;
- utility difference within `.05`; and
- `R_plain / R_codec < .80` before claiming useful compression.

This preserves Rohin's intended flywheel without making compression an
upstream burden: useful sleep improves memory; better memory may later let
DREAM carry larger learned chunks in the same conscious space.

## 17. Remaining genuine design ambiguities

Only three choices remain implementation-level rather than scientific:

1. **Opaque-token search feasibility.** The generator must find identifiers
   that keep all registered rows and control replacements exactly token-count
   matched through the registered PAD targets under the pinned tokenizer. If
   it cannot, fail closed as `VS_ASSAY_INVALID`; this version has no per-token
   weighting or approximate-match fallback.
2. **Neutral padding surface.** Every nonsemantic PAD target must be pretested
   as unparseable by every EVENT/LINK/read parser and contain no world
   identifier. If padding measurably damages the generic canary, report the
   affected control as assay-invalid rather than interpreting an AUTH/FULL
   advantage.
3. **Native internal mediation.** The minimum native endpoint proves success
   on an information-identified task, not separate OLD/NEW parameter use. If
   that stronger language is required for the first paper, pay for two
   additional NEW_ONLY fits per root in confirmation—not in DEV.

Everything else is decided here: the world, cube, grammar, fit roster, dose,
read interfaces, ceilings, thresholds, custody, fit cap, and release ladder.
