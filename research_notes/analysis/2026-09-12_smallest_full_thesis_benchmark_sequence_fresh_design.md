# Smallest full-thesis benchmark sequence: one causal microcycle, then one lifetime

Date: 2026-09-12 UTC

Role: fresh independent benchmark minimalist

Status: design and claim audit only. This memo does not authorize source
authoring, benchmark generation, model/tokenizer calls, training, GPU use,
parenting, resource acquisition, scientific claims, release, or submission.

## Verdict

The smallest design that still tests the requested causal chain is **not** a
new collection of separate benchmarks. It is one opaque, rendered,
two-SLEEP causal microcycle, first run as a two-root kill gate and then embedded
unchanged at a predeclared checkpoint of one novelty-growing lifetime.

The scientific sequence is:

```text
Q0 + one OLD/NEW coexistence canary
    -> zero-fit world/gold/text proof
    -> two-root, six-fit-per-root causal microcycle
    -> one three-branch longitudinal confirmation
       {DLT_RUN, DLT_FROZEN, ACTIVE_TEXT_NATIVE}
    -> optional semantic rate--distortion sidecar
```

This directly tests:

```text
child-chosen action -> public outcome
-> child-authored grounded atoms/connection
-> SLEEP write
-> different stored paths used for different goals
-> old memory chooses an informative action
-> its outcome selects a precommitted new record
-> second cumulative SLEEP
-> delayed action requiring OLD + NEW
-> improvement over increasing novelty-certified lifetime
-> comparison with a strong evolving external-memory agent
```

The current five-branch `P-RUN/P-FROZEN/N-RUN/N-FROZEN/P-TEXT` study is
necessary for a **parenting-by-SLEEP interaction**, but it is not necessary to
show that Dream--LoRA--Think itself learns from its own life. For the minimum
architecture paper, freeze one clean release-child checkpoint and use the
three branches above. Add the parenting factorial only if parenting remains a
primary causal claim. This halves the headline branch count without weakening
the action--experience--memory--action claim.

M-core v8 should remain a supplied-memory falsification map, not the critical
path. Its six-carrier topology and controls are useful; its 3,388-line package
contract, 32-root package, and child-authenticated preassigned pair cannot by
themselves establish native DREAM intelligence. Reuse the causal geometry,
not the entire governance object.

## 1. One benchmark object

Call the object `M->L` for now; do not create another branded world unless the
implementation actually needs one.

Each independent root has opaque handles and independently randomized
relations. The whole world, both outcome twins, lifetime cohorts, and every
sealed exam are generated before any model call. Public aliases, order, and
surface forms are independently permuted and contain no root, family, role,
depth, split, outcome, or target coordinate.

### Cycle 1: experience, connection, and traversal

1. In separate source episodes, the child chooses and executes actions that
   reveal two public transitions sharing an endpoint. A scripted action may be
   a coverage diagnostic, but cannot support the phrase *its own action--outcome
   experience*.
2. Before any support blueprint, held goal, future action menu, or future
   outcome is visible, the child receives one bounded DREAM proposal slot. It
   may write the two cited atoms and one directionless cited connection. There
   is no generate-until-valid loop; an invalid or unsupported proposal remains
   an adverse zero.
3. A later candidate-independent ordinary public event may support or
   contradict the sealed proposal. The verifier checks citations and public
   endpoint equality only. It cannot propose, repair, choose, broaden, or rank
   a connection.
4. SLEEP compiles eligible child records and rebuilds the cumulative adapter
   from the clean shared release child using the already-qualified writer.
5. In a sterile process, two incompatible goals share the same non-goal start.
   Each requires a different first query, stored path, and terminal action.
   Neither goal nor path occurs in a training row.

This tests grounded connection and goal-conditioned traversal in one adapter.
An atoms-only carrier is mandatory. If authentic connection and atoms-only are
equal while both beat deranged memory, the result is read-time composition and
goal traversal, **not value from a compiled child-authored connection**.

### Cycle 2: prospective expansion and delayed reuse

1. Old memory exposes a target-relevant uncertainty. Before acting, the child
   commits a gap, two hypotheses, one separating action, and both
   `outcome -> candidate new row` branches.
2. The child-chosen action executes. Only the ordinary public outcome selects
   one precommitted branch. Hidden truth, scorer state, and target utility do
   not enter admission.
3. A second clean-base cumulative SLEEP writes exact OLD union the selected
   NEW record. This is cumulative reconstruction, not an in-place online
   update claim.
4. After complete context/KV/store/cache deletion, a delayed goal requires one
   old link and the new record. NEW alone and OLD alone are mechanically
   insufficient.
5. A preconstructed truthful outcome twin redirects the selected row and
   delayed terminal action.

This is one bounded prospective expansion cycle. It is not open-world
discovery or indefinite recurrence.

## 2. The minimum conditions

### Zero-fit conditions

- hidden legal-history oracle;
- no memory;
- exact same-semantics text;
- atoms-only exact text;
- connected exact text;
- exact witnessed graph and its required-edge cuts; and
- target-only, state-only, ID-only, order-only, frequency/recency, and
  passive-signature shortcut predictors.

These must prove the theorem and expose failures before a fit. The exact-text
system is a **carrier ceiling**, not the strong agent-memory baseline.

### Trained microcycle conditions per root

Use exactly the six M-core carrier roles, with simpler public names:

```text
SLEEP 1
  AUTH_OLD              authentic source + authentic child connection
  SOURCE_SHUFFLED_OLD   same marginals/dose, broken action--outcome binding
  CONNECTION_NULL_OLD   authentic atoms, no authentic connection, matched work

SLEEP 2, only if SLEEP 1 passes
  AUTH_OLD_NEW          AUTH OLD + public-outcome-selected NEW
  OUTCOME_TWIN_OLD_NEW  same old state, opposite truthful public outcome/NEW
  AUTH_OLD_PLUS_PAD     AUTH OLD + grounded irrelevant matched PAD
```

`SLEEP_OFF`, adapter-off, wrong-root, read permutation, row cuts, payload
swaps, no-second-write, and exact text are inference-only interventions. They
do not require new fits.

`CONNECTION_NULL_OLD` is atoms plus neutral gradient-bearing material, not an
empty smaller corpus. If a semantically deranged connection is also useful for
localization, use it in DEV only; do not make both null and deranged powered
confirmation arms unless DEV proves the distinction matters.

The three trained SLEEP-1 states distinguish source binding from connection
value. The three SLEEP-2 states distinguish a real outcome-selected new write
from generic extra training and establish redirection. Combining either pair
of questions into one corruption would save fits but destroy attribution.

## 3. Exact staged execution

### Gate A — writer, no benchmark spending

1. Q0 must pass on the exact downstream action/reader surface, including
   opposite conditional movements, held forms, reload, locality, legality,
   and interface preservation. Candidate scoring may diagnose; strict ordinary
   generation remains the primary interface.
2. Run one identity-disjoint OLD/NEW cumulative coexistence canary. Require
   OLD and NEW each `>=.90`, each within `.05` of its single-bank ceiling,
   with zero wrong-root/interface failure.

Q0 is bounded supplied conditional carriage. The coexistence canary is
simultaneous cumulative reconstruction. Neither is experiential evidence.

**Kill:** any Q0 cell failure stops all LoRA M/L spending. An OLD/NEW failure
stops cycle 2 and lifetime recurrence; cycle-1 text diagnostics may continue.

### Gate B — CPU/gold/text closure, zero training fits

Run four fixed DEV roots and extend to eight only if at least `3/4` pass all
core conditions:

- direct-record closure `=0`;
- hidden legal-history/gold graph `>=.90`;
- no-memory and every shortcut projection `<=.35`;
- connected exact text `>=.85` on both goals and delayed OLD+NEW;
- connection/OLD/NEW cuts reduce registered success from at least `.75` to at
  most `.25`, or by at least `.40` if the absolute anchors are infeasible;
- goal swap redirects first query, complete path, and action;
- outcome twin redirects the NEW row and delayed action;
- atoms-only is at least `.15` below connected text on the connection-value
  endpoint; and
- evaluation run-versus-skip leaves future life bytes identical.

If atoms-only solves the route, keep composition/traversal as a possible claim
but delete compiled-connection value. If the graph/text ceiling fails, repair
the world/reader; do not fit around it.

### Gate C — two-root LoRA kill gate

Use two predeclared release-child DEV roots, six fits/root, at most **12 fits**.
Both roots must pass; they are a spending gate, not publication evidence.

Noncompensatory pass:

- every credited source action was emitted by the child and actually executed;
- pre-admission informative-record precision `>=.80`, with empty denominator
  scored zero; rejected guesses remain in the denominator;
- `AUTH_OLD` uses both goals correctly and goal swap redirects query/path/action;
- `AUTH_OLD` beats both `SOURCE_SHUFFLED_OLD` and
  `CONNECTION_NULL_OLD` by `>=.20` on their designated endpoints;
- AUTH improves over its own OFF state, and the AUTH-minus-OFF gain exceeds
  the corrupt-minus-its-OFF gain; harm from corrupt data cannot manufacture
  the result;
- `AUTH_OLD_NEW` solves both truthful outcome branches and beats
  `AUTH_OLD_PLUS_PAD` by `>=.20`;
- old cut, new cut, wrong-root, and payload swap each destroy or redirect the
  exact dependency they target;
- rote one-edge carriage differs by at most `.05` across SLEEP-1 carriers;
- old retention after SLEEP 2 loses at most `.05` from SLEEP 1;
- strict action/read legality `>=.95`, false-memory use `=0`, and no interface,
  locality, visibility, chronology, provenance, or reset failure.

Failure localizes source binding, connection value, writer coexistence, or
expansion. It does not justify another giant lifetime.

### Gate D — one integrated longitudinal study

Reuse the exact same world algebra and actor/read/write surfaces. Do not run a
separate powered M confirmation and then build a different lifetime world.

Fork one clean release child per independent root into:

```text
DLT_RUN             SLEEP promotes at every registered boundary
DLT_FROZEN          identical wake architecture; shadow SLEEP, no promotion
ACTIVE_TEXT_NATIVE  childhood LoRA frozen; evolving lossless raw+typed text
```

Use five predeclared exam cuts: entry plus four novelty-certified information
cohorts. Each interval adds new independent public action outcomes, at least
one relation interacting with an older relation, and one possible
prospective-expansion decision. Paraphrases, compiler views, optimizer
encounters, and repeated programs do not count as new information.

At one predeclared middle cut, create disposable causal clones and run the
six-condition microcycle. The main `DLT_RUN` branch supplies
`AUTH_OLD/AUTH_OLD_NEW`; only the four corrupt/twin/PAD carriers are additional
fits. Thus a five-cut confirmation costs, per root:

```text
4 scheduled cumulative DLT fits + 4 checkpoint control fits = 8 fits/root
```

instead of powering a separate 6-fit/root M cohort and another lifetime. All
other causal attacks reuse snapshots and cost inference only.

The strong baseline is the already specified `ACTIVE_TEXT_NATIVE`: it starts
empty, stores every eligible public event losslessly plus provenance-valid
typed records, uses its deterministic BM25 plus declared-link PPR retriever,
gets four adaptive reads and 1,024 returned tokens per decision, and has no
parameter update. Run its 2,048-token sensitivity if and only if the word
*saturated* remains in the claim. The exact witnessed graph is a cheap
algorithmic reference and must be reported, but it need not become another
learned lifetime branch.

Use two to four excluded DEV roots to measure variance and cost. Before any
confirmation outcome is opened, freeze one root-level sample size with a floor
of 16 and a hard resource cap. If blinded nuisance variance says the cap
cannot resolve the registered effects, report `NOT_ESTABLISHED`; do not treat
checkpoints, goals, model calls, twins, or optimizer seeds as replications.

Test in strict order using root-level paired inference:

1. **mechanism:** the designated microcycle passes its source, connection,
   traversal, outcome-redirection, OLD+NEW, cut, and interface conjunction;
2. **continued SLEEP:** `DLT_RUN - DLT_FROZEN` has a positive entry-adjusted
   AUC lower bound, point estimate at least `.05`, positive absolute post-anchor
   slope, anchor-to-terminal gain at least `.05`, and old/early-cohort
   noninferiority within `-.05`;
3. **strong-baseline comparison:** DLT has positive late-slope advantage and
   terminal advantage of at least `.05` over `ACTIVE_TEXT_NATIVE`, with the
   root-level lower bounds above zero; and
4. **optional saturation:** only if both last active-text increments and its
   late slope have 90% intervals inside `[-.02,+.02]`, new evidence continued,
   oracle headroom is `>=.10`, retention held, and the 2,048-token sensitivity
   is also equivalent. Otherwise report finite curves and omit *saturated*.

This is an intersection claim: no aggregate score may compensate for a failed
source, connection, expansion, retention, or absolute-growth predicate.

## 4. Information-per-GPU-hour order

| stage | training cost | information bought | stop condition |
|---|---:|---|---|
| Q0 | at most three small fits, current cap `<=.75` A40-hour | can this writer learn opposite keyed actions at all? | any conjunctive cell failure |
| OLD/NEW canary | measure from qualified Q0; one root only | can cumulative replay coexist before a second cycle? | either bank/interface fails |
| CPU/gold/text | zero fits | is the theorem exposed and shortcut-free? | any ceiling/leak/necessity failure |
| M kill gate | 12 fits maximum | does the complete own-experience -> connection -> expansion relay work twice? | either root or any noncompensatory gate fails |
| lifetime DEV | 2--4 roots, `8 fits/root` maximum | variance, effect direction, horizon, cost | wrong direction, no headroom, unsafe write |
| confirmation | `8*N_root` fits, `N_root>=16` frozen blind | paper evidence for the whole finite chain | registered hierarchy |
| rate--distortion | CPU/text first; no upstream GPU entitlement | is there a real compression result? | utility/fidelity/byte crossover fails |

Do not quote a GPU-hour total until the exact cumulative fit deck is profiled.
The auditable budget is

```text
12 * measured_M_fit_time
+ N_dev * 8 * measured_lifetime_fit_time
+ N_conf * 8 * measured_lifetime_fit_time
+ fixed inference/retrieval overhead.
```

This is more honest than importing fit times from a smaller Q0 deck.

## 5. Shortcut kill list

The experiment is invalid, regardless of score, if any of these routes
survives:

1. **ID/position code:** public identifiers, suffixes, catalog order, or goal
   names predict relations/actions above `.35` without legal memory.
2. **Compiler as solver:** the compiler proposes, repairs, ranks, broadens, or
   selects a semantic record. It may only render and admit an already sealed
   child proposal against later public evidence.
3. **Verifier rejection sampling:** unsupported guesses disappear from the
   parenting/DREAM denominator or the child gets another proposal after a
   rejection. Count every attempt; one slot means one slot.
4. **Scripted ownership:** the child's released action is ignored and a
   scripted action creates the credited outcome.
5. **Direct-plan row:** one source, DREAM, training, or returned row contains
   the held goal, complete route, decisive pair, or terminal action sequence.
6. **Atoms suffice:** AUTH connection is credited without beating atoms plus
   matched PAD. If atoms work, claim read-time composition only.
7. **Reader as planner:** a same-semantics read ranks candidates, expands a
   neighborhood, follows a path, or returns an answer-shaped bundle. One exact
   local row/read only. Native graph retrieval belongs only to the declared
   strong baseline.
8. **Goal-label mapping:** changing opaque goal bytes redirects action even
   when world semantics stay fixed, or target-only prediction beats its cap.
9. **Outcome-irrelevant expansion:** the same NEW record/action appears under
   both truthful outcome twins, or the branch map is authored after outcome.
10. **NEW-alone solution:** the delayed endpoint remains solvable after the old
    cut, new cut, or exhaustive redundant-path cut.
11. **Corrupt-arm harm:** AUTH does not improve over its own OFF, even though it
    beats a damaged corrupt arm.
12. **Evaluation contamination:** an exam query, action, outcome, retrieval,
    cache, timing signal, or score changes any later-life byte.
13. **Fake lifetime:** later cuts add only repeated programs, paraphrases,
    views, or optimizer exposure rather than new causal information and
    old--new dependencies.
14. **Pseudo-replication:** targets, twins, cuts, samples, fits, or optimizer
    seeds are analyzed as independent learners.
15. **Crippled baseline:** active text is forced through the exact-row carrier
    interface, loses raw events, has hidden capacity eviction, or receives less
    public opportunity/actor budget.
16. **Hidden capacity growth:** rank/adapter bytes change at favorable cuts.
    A fixed-rank pass is the headline; a rank curve is a separate capacity
    analysis.

Run answer-injection tests against every permitted visible projection. A
negative leakage scan is useful only after a positive injected leak is
detected by the same audit.

## 6. Compression and claim bounds

Do not call LoRA itself compressed. The current rank-8 adapter is about
80.8 MB, far larger than these small semantic fixtures.

After connected utility passes, the smallest compression sidecar is
model-free: encode the exact same admitted meanings as (a) expanded canonical
records, (b) ordinary-codec compressed expanded text, and (c) schema plus
residuals. Charge decoder, schema, index, metadata, provenance needed for
round-trip, and residual bytes. Require byte-exact denotation recovery, zero
false memories, and retained connected-task utility at two later loads. Only a
strict byte/fidelity crossover licenses *semantic-code compression*. Failure
removes only compression language.

If all primary stages pass, the maximum bounded statement is:

> In independently randomized finite world-lives, a fixed-rank
> Dream--LoRA--Think agent compiled records traceable to its own public
> action outcomes, carried a child-authored connection beyond its atoms,
> traversed different stored paths under different goals, selected an
> informative action, wrote its outcome cumulatively, and later performed an
> action requiring old plus new knowledge. Continued SLEEP produced positive
> absolute finite-lifetime improvement over a frozen-SLEEP twin while retaining
> earlier competence, and exceeded the predeclared evolving active-text system
> on late slope and terminal value over the measured horizon.

This does not prove a graph geometry inside weights, native open-ended search,
parenting efficacy, universal transfer, indefinite growth, physical
compression, or superiority to all possible memory systems. Add *parented*
only after a matched parenting treatment passes; add *agentic traversal* only
after an ordinary native query/action endpoint passes without a hidden
candidate scan; add *saturated* and *compressed* only under their separate
conjunctions above.
