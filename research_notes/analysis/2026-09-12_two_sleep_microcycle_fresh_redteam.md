# Fresh red-team: smallest paper-worthy two-SLEEP causal microcycle

Date: 2026-09-12 UTC

Role: fresh independent causal/visibility/baseline audit

Status: design memo only. No source, benchmark, model, tokenizer, adapter,
process, job, GPU, resource, claim, release, or submission was changed or
authorized.

## Verdict

Keep the simple architecture and the six-fit-per-root skeleton. Do **not**
execute the current M-core reader unchanged.

The smallest defensible experiment is one lived two-SLEEP root with three
matched S1 carriers, three matched S2 carriers, and a zero-fit strong active
text branch. Two DEV roots are a kill gate; sixteen fresh roots are the fixed
confirmation. Maximum new mechanism cost is therefore **108 LoRA fits**, not
144:

```text
DEV:   2 roots x (3 S1 + 3 S2) = 12 fits maximum
CONF: 16 roots x (3 S1 + 3 S2) = 96 fits maximum
TOTAL:                              108 fits maximum
```

The current documents leave two ways for a spectacular positive to be
scientifically empty:

1. M-core's reader is an external answer store. The mounted 32-candidate bank
   contains complete answer-bearing rows and the LoRA only scores them. Mounts,
   OFF cells, and cuts also change which rows are externally present. A pass
   can therefore be candidate recognition or external membership lookup, not
   a record carried in LoRA.
2. The M-core compiler copies complete LINK and NEW templates. Recovering or
   selecting a preassigned pair can authenticate custody, but it does not make
   the connection child-authored if the experimenter supplies the relation
   payload later.

Repair both before calling the result Dream--LoRA--Think. The rest of the
current causal geometry is useful and can be retained.

## Why a current positive could be meaningless

### 1. Carrier/reader shortcut -- fatal

`RecognitionScorerInput` receives a complete candidate row, and the mount
projection decides which rows are available. The correct actions,
destinations, sequence, and citations can consequently reside in the reader
bank rather than the adapter. `S1_OFF` with fillers is not adapter-OFF under
the same answer-bearing world. Cuts then establish dependence on the external
row service, not storage in weights.

**Repair:** the primary LoRA read is direct ordinary generation:

```text
actor emits READ(query_handle)
-> goal-blind memory process receives only query_handle + checkpoint
-> model emits exactly MISS or one complete local MemoryRow
-> unedited raw bytes reach the actor
```

No candidate MemoryRow, availability map, target, goal, action menu, graph,
score, or expected trace enters that process. Candidate scoring may be a
sealed diagnostic over public action continuations, but may never select or
release a row. Adapter-OFF and wrong-root use the identical query catalog,
prompt, and broker; only adapter bytes differ.

Registered cuts/swaps may transform the already-generated return in the
broker to test live behavioral dependence. They do not count as storage
evidence. Storage evidence is exact raw row generation by AUTH, failure or
redirection under same-surface OFF/wrong-root, and immutable
deck -> adapter -> raw-generation provenance.

### 2. Reader-as-planner / goal cue shortcut -- fatal for traversal

The current reader sees phase, state, public goal, and a direct `route_cue`;
it scans all candidates. Goal-dependent output can therefore be computed by
the reader. The actor need not traverse anything.

**Repair:** only the actor sees the goal. It chooses one opaque query handle
from a constant root-wide catalog containing more handles than its read
budget. The memory response is one state-local row and contains no complete
plan. Both old goals have byte-identical non-goal inputs and the same catalog;
they must change the actor's first query handle, returned local path, and
public action. A goal swap must redirect all three. No row is keyed directly
by the goal label, and target-only, query-handle-only, catalog-order, and
episode-ID projections must remain at chance.

### 3. Compiler-authorship shortcut -- fatal for DREAM

Mechanically rendering an authenticated child action followed by its public
outcome is legitimate. Supplying a complete connection after the child picked
a pair is not child-authored DREAM.

**Repair:** DREAM gets one proposal slot before support, future goals, route
menus, experiment laws, or link templates exist. The child must emit the
complete proposed connection bytes: two event citations, ordered local
relation, scope, and proposed query handle. Later public co-use can support or
contradict it. The compiler may only check syntax, chronology, citations, and
the later public predicate, then copy those exact bytes or reject. It cannot
fill, orient, rank, repair, replace, or retry. Rejected and malformed proposals
remain adverse attempts.

For NEW, the child similarly seals two complete `outcome -> candidate row`
branches before acting. Only the public outcome selects one exact branch.
The unselected row, branch map, and both templates are audit-only after the
clean reset and are inaccessible to the writer, text store, reader, and final
actor.

### 4. Corrupt-arm harm and information-content shortcut

Turning authentic 3:1/1:3 evidence into 2:2/2:2 removes information. AUTH can
beat that arm merely because it contains a usable preference. A wrong link can
also harm behavior, making AUTH-minus-corrupt positive without AUTH improving
over OFF.

**Repair:** use an equal-information `SOURCE_BINDING_TWIN`: presealed donor
rebinding reverses the within-situation conditional relation while preserving
event identities, action counts, global outcome counts, target marginals,
rows, dose, and work. It must redirect the predicted inverse action in the
twin direction, not merely fail. Replace DREAM derangement as the trained
connection baseline with truthful `ATOMS_ONLY_OLD`: all authentic atoms plus
grounded irrelevant material matched for tokens, updates, and work, but no
child connection. Keep a wrong-link payload swap as inference-only mediation.
AUTH must improve over its own identical-surface OFF state.

### 5. View/dose pseudo-evidence

The matched-view memo correctly separates public evidence, supported views,
and optimizer encounters. If repeated renderings are counted as independent
events, or AUTH alone receives structurally richer views, a positive can be
ordinary augmentation rather than DREAM or causal experience.

**Repair:** publish all three ledgers separately. Every S1 contrast gets the
same fixed view-operator roster, supervised-token count, source-specific
optimizer encounters, and schedule. `ATOMS_ONLY_OLD` receives a grounded
irrelevant view in the connection slot, not an empty or masked row. A same-
batch bundle of four views counts as one source-specific optimizer step. The
active text store inserts each unique meaning once; it is never given repeated
copies to imitate LoRA epochs. Views and visits never increase the evidence
denominator or novelty clock.

### 6. Counterfactual twin is not a second lived outcome

Two fitted H0/H1 carriers are useful for redirection but cannot both be the
one factual life. Without a designated factual branch, “the child experienced
an outcome and slept again” is ambiguous.

**Repair:** preseal one factual outcome bit per root. The child commits one
informative action and both candidate rows; the factual world supplies the
ordinary second outcome and the longitudinal claim uses only its S2 adapter.
Clone the process immediately after the common action commitment to create
the opposite truthful outcome twin. Its extra S2 carrier is a counterfactual
redirection control, not another independent life.

### 7. Strong-baseline substitution

`TEXT_SAME_SEMANTICS` is a carrier ceiling deliberately denied planning; it is
not the strong memory opponent. Conversely, `ACTIVE_TEXT_NATIVE` cannot be
added later only on favorable roots or be forced through the LoRA one-row
reader. Either move makes a baseline comparison meaningless.

**Repair:** fork the same pre-S1 lived child/history into a concurrent
`ACTIVE_TEXT_NATIVE` branch on every DEV and CONF root. It starts with an
empty branch-local store, retains every eligible raw public event plus the
same exact admitted child-authored atoms/connections, and gets the frozen
BM25 + declared-link PPR retriever, four charged reads, and at most 1,024
returned tokens per decision. It performs no parameter update. After the
fork, DLT and text each choose their own informative action, receive their own
presealed potential outcome, update only their own memory, and face the same
opportunities and exams. That is an on-policy **whole-system** comparison,
not an information-matched carrier effect.

Keep `TEXT_SAME_SEMANTICS` separately as the zero-fit theorem/carrier ceiling.
Never use its restricted reader to call the active text baseline strong.

### 8. Statistical shortcut

Five sequential positive component tests make interpretation harder and do
not test the external-memory comparison. `12/16` under `p>.5` also establishes
only majority reliability; its one-sided 95% lower bound is about `.516`, not
near-universal success.

**Repair:** use one predeclared confirmatory mechanism indicator per root:

```text
R_root = own-source AND grounded-connection AND two-goal traversal
         AND informative-action AND factual-outcome-selected write
         AND second-SLEEP OLD+NEW use AND every validity/control gate
```

The sole mechanism test is `H0: Pr(R_root=1)<=.5`; with sixteen fixed fresh
roots, require at least `12/16` (`p=2517/65536=.0384063720703125`). Report the
component rates and the `.516` reliability lower bound so the claim cannot be
read as universality. Crashes, malformed actions, rejected writes, skipped S2,
and root-local failures are zeros. A predeclared global-instrument failure
stops the program with no test and never permits replacement roots.

For the text comparison, define before DEV

```text
V_system = mean(old-goal-A, old-goal-B,
                informative-action, factual delayed OLD+NEW endpoint)
Delta_text = V_DLT - V_ACTIVE_TEXT_NATIVE
```

Report all sixteen paired root differences and a two-sided 95% root-level
interval. “Superior” additionally requires lower95 > 0 and mean >= .05;
“noninferior” requires a prospectively named `-.05` lower margin. If neither
passes, report the finite deficit or tie without a relational adjective. This
comparison never substitutes for `R_root`.

## Smallest repaired protocol

### Seal and zero-fit closure

Before any fit, freeze each whole root, both potential outcomes, all public
aliases, a constant query catalog, source/treatment transformations, goals,
action laws, branch maps, exams, controls, active-text implementation, and
failure taxonomy. Root entropy is independently sampled before outcomes; a
single master-seed hash is not called proof of iid roots.

Required zero-fit gates:

- direct-plan closure is zero and every ID/order/target/query projection is at
  most chance plus `.05` in its own label space;
- an injected forbidden leak is detected by the same scanner used to certify
  the negative leakage result;
- legal-history/gold and exact same-semantics text each score `>=.90` on both
  old goals, both outcome twins, and delayed OLD+NEW;
- no-memory scores at most chance plus `.05`;
- old-link, connection, and new-row cuts reduce registered value from at least
  `.75` to at most `.25`, or by at least `.40` if the absolute anchors are
  infeasible;
- the child proposal byte cut precedes support/template/future-goal bytes;
- the writer receives only authenticated event atoms plus the exact admitted
  child proposal/selected NEW row; and
- the active-text certificate has source/citation fidelity `=1`, no forbidden
  row, deterministic rebuild/order invariance, donor-store redirection,
  bridge-cut drop `>=.40`, irrelevant-store effect `<=.05`, and strict legal
  actions `>=.95`.

Q0 must pass on the candidate-free generative row surface, including held
forms, opposite conditional movements, exact reload, locality, and ordinary
generation. One identity-disjoint OLD/NEW cumulative canary must keep both
banks `>=.90`, each within `.05` of its single-bank ceiling. Either failure
stops the microcycle.

### SLEEP 1 -- three matched fits per root

```text
AUTH_OLD             authentic event atoms + exact admitted child connection
SOURCE_TWIN_OLD      equal-information reversed source binding + same connection
ATOMS_ONLY_OLD       authentic atoms + grounded matched work, no connection
```

All rebuild from one clean checkpoint. Initial bytes, optimizer, device/image,
deck slots, masks, target-token count, update count, RNG streams, and work are
identical within the triplet outside a checker-derived semantic bitmap.

After sterile reset, AUTH must solve both incompatible goals, with distinct
first queries, local paths, and actions. `ATOMS_ONLY_OLD` must be at least `.20`
below AUTH on the registered connection-dependent endpoint; otherwise delete
the compiled-connection claim and stop the full-chain program. SOURCE_TWIN
must produce the predeclared semantic redirection, while AUTH must choose the
unique maximum-information action and improve over same-catalog adapter-OFF.
Rote atom carriage must differ by at most `.05` across the three carriers.

### Second outcome and SLEEP 2 -- three matched fits per surviving root

The factual AUTH actor seals two hypotheses, one action, predictions, and both
complete outcome rows before action. The public outcome selects exactly one.
The counterfactual clone differs first at the outcome byte.

```text
AUTH_OLD_NEW_H0       exact old union selected H0 row
AUTH_OLD_NEW_H1       exact old union selected H1 row
AUTH_OLD_PLUS_PAD     exact old union grounded irrelevant equal-work row
```

All reconstruct from the same clean checkpoint; this is cumulative
reconstruction, not in-place learning. After full reset, both truthful twins
must redirect raw generated NEW row and final action. The factual branch must
solve the delayed task. PAD and NO-SLEEP2 must not. Separate post-generation
old/new cuts and payload swaps must each destroy or redirect only their named
dependency. Old-goal value may fall by at most `.05`; false-memory use is zero
and strict read/action legality is `>=.95`.

The concurrent active-text branch must complete the same factual causal chain
from its own action and outcome. Its retrieval/store receipts are reported even
when its actor fails; scientific failures stay in the denominator.

## Exact stop rules and cost

1. **Zero-fit stop:** any theorem, visibility, generative-reader, compiler,
   provenance, Q0, coexistence, or active-text certificate failure -> zero M
   fits.
2. **DEV S1 stop:** run exactly two DEV roots x three S1 fits = **6 fits**.
   Both roots must pass every S1 conjunction. Otherwise stop with no S2.
3. **DEV S2 stop:** only then run two roots x three S2 fits = **6 more**.
   Both complete roots and both active-text factual chains must pass. Otherwise
   stop before confirmation.
4. **Freeze:** no template, threshold, reader, compiler, retriever, endpoint,
   root rule, or analysis change after DEV. A repair creates a new protocol and
   new DEV roots.
5. **CONF:** run all sixteen fresh roots. S1 is **48 fits**. S2 is opened only
   for a root whose predeclared S1 gate passes and is at most **48 more fits**;
   skipped S2 makes `R_root=0`. No replacement, extension, early-success stop,
   or seed rerun.

Thus the exact new-fit cap is **108**. `TEXT_SAME_SEMANTICS` and
`ACTIVE_TEXT_NATIVE` add **zero optimizer fits**, not zero cost. Report their
actor inference, model calls/tokens, CPU indexing/PPR, storage, latency, and
energy separately.

Do not quote GPU-hours until every exact deck class is profiled. The only
valid prospective compute bound is

```text
C_fit_max = 18 * (t_AUTH_S1 + t_SOURCE_TWIN_S1 + t_ATOMS_S1
                  + t_H0_S2 + t_H1_S2 + t_PAD_S2)
```

using a measured conservative bound for each exact deck/device class.
Actual cost is the union of occupied device intervals for every launched
attempt, including completed, crashed, timed-out, aborted, and partial work,
plus separate inference/CPU/noncompute ledgers. Q0 and the coexistence canary
are prerequisites and must be charged in the paper's total resource table,
but are not hidden inside the 108 M fits.

## Maximum claim if it passes

> Across independently generated finite roots, a fixed-rank
> Dream--LoRA--Think child converted its own committed public action outcomes
> into authenticated atoms and a child-authored, later-supported connection.
> With no answer-bearing external row bank, the reset child generated local
> memory rows, chose different queries and paths for different goals, selected
> an informative action, used its public outcome to select one precommitted new
> record, cumulatively reconstructed old plus new content at a second SLEEP,
> and later acted using both. The exact concurrently run active-text system is
> reported as a separate on-policy whole-system comparison over the same
> opportunity schedule.

This does not establish latent graph geometry, open-ended recurrence,
parenting, continual improvement, physical compression, or superiority to
external memory unless the separate paired text criterion passes.
