words, in twelve two-task packets. For records, the immediately preceding
own repair was also read and is the exact additional neutral-prefix content.

Per-task A/B aliases hid branch labels during reading, but this is **not an
independent or fully blind review**: aggregate22/23 correctness was known,
and checker mentions can reveal a branch. Author judgments, exact target
and prefix hashes, whole-target evidence spans and reasons are retained in

for those readings. First person includes I, we and inclusive let's; an
impersonal imperative alone does not count. Specific operations and their
concrete, checkable mathematical consequences can form a reusable lesson;
an independent second solution was not required.

Six GUIDED repairs repeat a real checker-verdict event missing from the
neutral prefix. Their actor transcripts really did contain the rejection:

## Obstacles, assumptions and peer lesson

The first source capsule passed17 CPU tests but lacked runtime-hashed shell
dependencies, so CPU-only preparation failed before any GPU process/call.
That capsule, logs and failure receipt remain preserved. Package2 includes
the dependencies and a dynamic-contract regression:18 tests pass locally
and in the isolated native environment before publication/launch. Final
analysis adds a receipt-tampering regression:19 tests pass. An intermediate
test-placement NameError and its repaired passing run are both retained.
The outer SSH command timed out during detachment; read-only reconciliation
confirmed one running guardian, so no duplicate launch was attempted.
Final CPU token/provenance replay passes all93 rows with zero new model calls.

Limits: small selected public DEV tasks; unknown pretraining contamination;
old naturally wrong terse outputs condition the population; no new task or
held-family sampling; finite greedy decoding rather than repeated sampling.
The question arithmetic is independent of supplied gold/rationales, not a
second independent model or human audit. Strict ambiguity exclusions and
author semantic/prefix judgments are documented assumptions, not perfect
gold validation or a general causal claim about guidance. No feedback
learning, adapter fit, learned loop or parent-child transfer was measured.

**Peer lesson:** compare rejection with the *same rich retry*. Then inspect
whether the child retells removed feedback in its target. A truthful event
in the actor context can still be inadmissible under a neutral student
prefix; a numeric-correct record can contain a false intermediate check.
Neither correctness nor length should silently stand in for those tests.
