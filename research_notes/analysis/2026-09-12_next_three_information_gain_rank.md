## Verdict

Rank the next GPU-bearing scientific work as follows:

1. **Semantic W0: fresh carrier canary, then the four fits only on a pass.**
2. **S-JOIN: authoritative mechanically joined action--outcome events, first
   as a zero-fit source/text assay, then as one TRUE-versus-SHUFFLED LoRA root
   only after W0 passes.**
3. **M-TEXT: CPU M0 plus the four-root exact-text E2/E4 connectedness and
   goal-traversal kill gate, before any LoRA relay deck.**

This is a priority ranking, not a serial wall-clock schedule. The zero-fit
parts of S-JOIN and M-TEXT can be prepared and executed in parallel with W0
without inspecting or changing W0 outputs. The LoRA part of S waits for W0.

The important ordering correction is that **mechanically joined public events
should precede weight-carrying parenting work**. The terminal static-lesson
scout produced 1,903/1,627 measured actions but zero eligible first-person
records; this falsifies that transcription package, not the existence of
action--outcome experience. Requiring a child to narrate an already
authoritative event makes brittle prose syntax an unnecessary upstream cause.
Parenting can later improve planning or add grounded reflection, but it should
not decide whether the organism possesses the action and public outcome that
the environment already recorded.

## 1. Semantic W0

### Why first

This is the cheapest decisive test of the shared parametric carrier. The
`a0/a1` diagnostics localized the latest failure to an asymmetric artificial
motor surface: all 32 `a1` rows copied correctly, while all 32 `a0` rows became
`a a` or `a`. More prompt search is now low-value. A fresh test using familiar,
backend-executable `-mem2reg` and `-gvn` actions distinguishes an invalid motor
assay from a writer that cannot store selective conditional bindings.

The semantic carrier is **necessary as an assay-validity gate**, not evidence
for the paper claim by itself. Candidate scoring alone is insufficient because
the organism must generate an executable action. Conversely, an exact-row
carrier pass contributes no positive observation to the no-row adapter result.

The recent 64-generation diagnostics each cost about `.019` A40-hour. A
128-request generation-plus-score carrier should therefore be on the order of
`.04` A40-hour, subject to measured preparation. The failed-surface W0 attempt
completed four fits plus 1,504 reads in `.472` A40-hour. Those are empirical
comparators, not a guarantee for the new bytes; bind a fresh forecast and keep
the existing hard cap.

### Exact release gate

Before any optimizer step, freeze fresh opaque roots/forms, prompt and token
bytes, candidate masks through LF+EOS, cache kinds, interface rows, resource
receipt, and a zero-fit terminal path. On the 64 balanced exact-row items:

- strict generated BA is at least `15/16` in each of four root-map cells;
- full-candidate-choice BA is at least `15/16` in each cell;
- strict validity is at least `61/64`, with zero truncations and zero
  multiple-`ACT` outputs;
- changing only the complementary map row redirects generation on at least
  `29/32` pairs and candidate argmax on at least `29/32` pairs; and
- model/tokenizer/OFF identity, registry execution, token masks, request
  completeness, seal, and exact replay all pass.

Any failure seals `ASSAY_INVALID_SEMANTIC_ACTION_SURFACE` with zero fits. A
pass automatically releases exactly four fresh clean-base rank-8 fits. Each
root-map cell then must meet the frozen conjunction: all 16 key median target
NLL gains `>=.50`; W+/W- mean-gain asymmetry `<=.25`; generated BA `>=.80`;
each stratum accuracy `>=.75`; at least `12/16` key margins and `6/8` in each
stratum `>=.50`; gain over OFF `>=.20`; own-minus-opposite-map BA `>=.50`;
validity `>=.95` overall and `>=.875` per stratum; zero multiple actions; eight
unrelated native action copies `8/8`; and, separately for missing,
unsupported, neighbour, and wrong-root families, mean two-candidate TV
`<=.05` and absolute legal-action-rate change `<=.05`. The full run must seal
and replay before `MULTIKEY_BINDING_PASS` is accepted.

### Contamination boundary

Carrier rows have a typed, disjoint cache and never enter fit or primary
prompts. W0 roots/adapters are disposable mechanism artifacts and never
become a nursery or final PCFL ancestor. Familiar action names are permitted;
fresh opaque keys plus complementary maps make their prior global preference
insufficient to pass.

## 2. S-JOIN authentic event assay

### Why second

This is the shortest direct test of the paper's first substantive arrow:

```text
child-selected action + public outcome -> later outcome prediction and action
```

It removes the failed first-person-record prerequisite and does not require a
parent. W1 is not a causal prerequisite for this **single-write** assay; W1 is
required before claims about cumulative replay, M-E5 old+new expansion, or a
lifetime. Running one S root before the eight-fit W1 program gives a more
thesis-direct diagnosis per fit. A W1 implementation may proceed in parallel,
but its GPU stage need not block this one-root S kill gate after W0 passes.

The current S design still names `a0/a1`. Do not execute those bytes. Freeze S
on the exact W0-qualified semantic action pair, or on a domain-native pair
that independently passes the same generation-plus-score carrier gate. Using
the already falsified artificial surface would re-confound source learning
with motor spelling.

### Zero-fit source/text gate (eligible before W0 result)

For one fresh opaque root, allow at most 16 opportunities per situation and
require the child itself to execute each of the two actions at least twice in
each of eight situations. Admit exactly the first two valid occurrences per
action and situation: 32 events total. Require exact action parse, public
outcome replay, four events per situation, two per action, both outcomes per
situation, four situations per hidden orientation, complete rejected/extra
attempt publication, and no reward/correctness/final-answer field visible to
the child.

Derive TRUE and within-situation OUTCOME_SHUFFLED only after the source ledger
is sealed. They must share event IDs, actions, marginal targets, ordering,
masks, tokens, steps, seed, node, and recipe; only the donor outcome changes.
Enumeration must put every registered shortcut at BA `.50`, the TRUE joint
oracles at `1.0`, and the SHUFFLED joint oracles at `.50`.

Before fitting, exact GOLD/TEXT lookup must return the exact four cited events
for the queried situation and satisfy:

- forward BA and inverse BA each `>=.90`;
- TRUE-minus-SHUFFLED at least `.20` in both directions;
- strict action legality `>=.95`;
- outcome swap redirects inverse action;
- deleting the necessary action-family rows drops value by at least `.20`;
- wrong-root, new-situation, spill, packing, citation, and interface checks all
  pass.

Failure is `S_SOURCE_INVALID` or `S_ASSAY_INVALID`, with zero LoRA fits. This
stage costs source/actor inference but no optimizer GPU-hours and can expose a
bad world, source policy, renderer, or reader without blaming the writer.

### One-root LoRA kill gate (only after W0)

Fit exactly TRUE and SHUFFLED from the same 32 events, 128 crossed rows and 256
steps per arm. The planning ceiling is `1.5` A40-hours for one root, to be
replaced by measured semantic-W0 throughput. A root qualifies only if all are
true:

- `IBA_TRUE>=.75`, `FBA_TRUE>=.75`;
- TRUE-minus-SHUFFLED is `>=.20` for inverse and forward BA and `>=.50 nat`
  for both candidate margins;
- both desired outcomes cause opposite strict actions on at least `6/8`
  situations;
- at least `3/4` keys in each orientation stratum have positive inverse and
  forward TRUE-minus-SHUFFLED margins;
- GOLD/TEXT, legality `>=.95` overall and `>=.90` per stratum, generic value
  `>=OFF-.05`, locality TV/rate `<=.05`, interface, wrong-root, spill,
  provenance, and replay gates all pass.

Only a qualifying first root releases two further disjoint roots. Advancement
to M requires all three forward and inverse signs positive, at least two roots
meeting the full conjunction, and no validity failure; label this
`S_THREE_ROOT_FEASIBILITY`. Eight unchanged roots, at least `7/8` joint-positive
contrasts, root-equal TRUE BA `>=.75` in both directions, root-median deltas
`>=.20`, and exact paired `p<=.05` are required for the paper-facing source
claim.

### Contamination boundary

No parent, teacher prose, hidden answer, evaluator action, success selection,
or later score enters S. TRUE and SHUFFLED descendants are quarantined and
cannot seed a child. The action pair may be a mechanism choice fixed from W0;
all S situations, outcomes, forms, event IDs, roots, and actor tapes must be
fresh and frozen before S outputs.

## 3. M-TEXT E2/E4 kill gate

### Why third

Before paying for a six-build LoRA relay, test whether the proposed PCFL world,
reader, controls, and exact-text carrier actually expose connected co-use and
goal-dependent traversal. This directly addresses two headline clauses, costs
no training, and creates the same-semantics baseline needed to interpret later
LoRA results. It has higher expected information per GPU-hour than beginning
W1's eight new fits or a parented life immediately.

This is not currently launch-ready: V5 is `REWORK`, the review receipt does not
bind the current proposal hash, and the exact world/deck/resource closure is
unfinished. Repair, re-review, and obtain the required authority over exact
bytes before source or execution. Do not treat implementation fixtures as a
result.

### Exact kill gate

All CPU M0 theorem, visibility, phase, lineage, mutation, reducer, and resource
fixtures must pass exactly before an actor call. In particular, the symbolic
controller and leaked oracle score `1.0`, the registered no-semantic shortcut
ceiling is `<=.25`, both atoms are mechanically necessary, the two byte-shared
starts require different unique paths, and cut/twin/null/derangement mutations
change only their named field.

After one parser/session canary, run sealed exact-text roots `dev_0000` through
`dev_0003`. For a root, accept `R_E2_TEXT=1` only if acquisition and child link
authorship occur, row/citation fidelity is exact, authentic links beat
atoms-pad, truthful-null, separately built derangement, and same-build read
permutation, adapter/text off and wrong-life remove the effect, both atoms are
necessary, and spill is zero. Accept `R_E4_TEXT=1` only if E2 passed and both
goals succeed, changing only goal bytes redirects the first relevant query,
full path, and final action, goal-only/no-memory value is `<=.25`, bridge cut
removes value, the truthful twin redirects path/action, and every registered
control passes.

Extend to `dev_0004..0007` only if at least `2/4` initial roots have both
`R_E2_TEXT=1` and `R_E4_TEXT=1`; never replace a failed root. If fewer than two
pass, stop LoRA M and repair the benchmark/reader. A text pass validates the
bounded theorem and baseline carrier, not parametric memory, latent graph
geometry, autonomous planning, expansion, or superiority.

### Contamination boundary

Use only `DEV_CHILD` and development roots. Freeze all eight root identities,
order, controls, and extension rule before the first actor result. No M-TEXT
outcome may select or alter a future confirmation child. The active-text
lifetime opponent is a separate system: its updater/retriever/manifest can be
built and certified on CPU in parallel, but must be sealed before any
confirmatory learner curve is opened.
