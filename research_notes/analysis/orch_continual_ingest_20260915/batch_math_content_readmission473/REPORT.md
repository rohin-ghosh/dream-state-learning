capture and existing content/gold decision produces 1,313 content-eligible

correct exact FINAL, complete untruncated native output and exact source/review

and bytes are embedded unchanged; the separate eligibility object records the
new policy. No new model call or GPU training is performed by this export.

This does not certify branching, novelty of second renditions, independent
review, or a learning gain. Meaningful branching requires the new sampled
measurement. These are external L1-generation outputs, not parenting/L2
experiences. Append only after native encoding and current held-cohort checks;
never replace/reset the existing learner or silently relabel original FAILs.
