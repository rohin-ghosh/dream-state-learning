# Watcher audit: minimum strong text baselines and downstream compression

Date: 2026-09-12 UTC

Status: docs-only watcher recommendation. This note changes no architecture,
source, run, GPU schedule, gate, or claim. It does not pause Astra under
`AGENTS.md`.

## Verdict

The current direction is sufficient for the full paper **only after preserving
two different text comparisons**:

1. `TEXT_SAME_SEMANTICS` is the fixed-source carrier assay inside the mechanism
   study; and
2. one qualified `ACTIVE_TEXT_NATIVE` / `P-TEXT` branch is the independently
   evolving lifetime opponent.

Neither can substitute for the other. The historical static brief is not a
strong baseline, and a graph-expanding retriever cannot be placed in a LoRA
mechanism cell and then credited to the child. The role separation and finite
reader already close those threats. What remains unclosed is an exact,
executable `P-TEXT` updater/retriever contract and its qualification evidence.

The repaired rate--distortion plan is sufficient for a **prospective semantic
code** claim, not for physical compression into the current rank-8 LoRA. At
roughly 80.8 MB before complete resume state, the adapter is not a plausible
physical compressor at the planned loads. The main paper can remain complete
with M and L as its core and a precisely limited semantic-code result in the
appendix; no compression result should gate writer, source, parenting,
mechanism, or lifetime work.

## Smallest defensible baseline set

Only two text objects need paper-facing scientific endpoints:

| object | minimum role | minimum evidence |
|---|---|---|
| `TEXT_SAME_SEMANTICS` | Carrier localization at a fixed age | Exact same canonical public payload deck; the existing four adaptive one-hop reads, one row and at most 256 returned tokens per read; TEXT versus LoRA with identical query/action opportunities and cuts/swaps. |
| `P-TEXT` (`ACTIVE_TEXT_NATIVE`) | Whole-system lifetime opponent | Same sealed parent-deleted adult checkpoint as `P-RUN`; inherited childhood LoRA active but frozen; empty deployment store; public-pre-frontier updater; target-blind retrieval; no post-fork parameter writes; its own on-policy experience. |

Qualification of `P-TEXT` should use the following small candidate roster on
disjoint DEV/certificate roots, without carrying every candidate into powered
lifetime confirmation:

- `RECENCY`: fixed most-recent eligible public rows;
- `RAW-RAG`: the full append-only public action/outcome store with frozen raw
  BM25 retrieval;
- `STATIC_BRIEF`: cheap diagnostic and continuity with the historical arm; and
- `EVOLVING-RAG`: the same raw frontier plus a frozen public-only typed or
  evolving summary layer, source citations, supersession, and target-blind
  retrieval.

Choose between `RAW-RAG` and `EVOLVING-RAG` prospectively with a proposed
normalized lifetime-AUC SESOI of `.010`. Select evolving only if its
one-sided 95% lower bound over raw exceeds `+.010`; select raw if the paired
effect is equivalent inside `[-.010,+.010]`; otherwise register raw and report
`DEV_INCONCLUSIVE`. Recency and static brief are sanity comparators, not
separate confirmatory lives. GOLD, EMPTY, IRRELEVANT, SWAP, FUTURE-TARGET
mutation, necessary-row/link cuts, and stale-supersession cases are instrument
controls, not additional baselines. `P-FROZEN` remains the causal SLEEP
control, not an external-memory baseline.

This roster is enough to prevent a weak-text strawman while avoiding an
unnecessary BM25/dense/graph/brief factorial. A dense encoder or graph ranker
may be inside the frozen `EVOLVING-RAG` candidate, but its work and graph cuts
belong to that standalone system.

## Fairness and resource budgets

Use opportunity matching, not a false equal-compute claim:

- Pair branches from one byte-identical, sealed, parent-deleted adult per
  independent lineage. Match public opportunity schedules, arm-independent
  randomness addresses, sampling, generation caps, action opportunities,
  failure denominators, and checkpoint cuts.
- Preserve byte-identical system/task/current-state/history partitions. Give
  lifetime text memory one query per continuation and a dedicated maximum
  `B=1,024`-token return partition. If prompt packing cannot preserve those
  partitions at `B`, the configuration fails preflight rather than silently
  evicting state. Any padding used in the non-text arm needs a no-harm
  certificate; otherwise report the prompt surfaces as unmatched.
- Keep the persistent eligible text store complete. Cap actor-visible access,
  not stored history. Use the sealed four-by-256 finite-reader budget for the
  same-semantics mechanism assay.
- Equalize generated actor tokens and dispatch opportunities. Do not pretend
  input tokens, retrieval work, storage, latency, CPU indexing, LoRA fits, or
  energy are matched. Report them separately, including persistent and
  cold-resume bytes.
- Admit invalid public actions and outcomes under the same causal frontier.
  Exclude parent/evaluator/future/hidden-answer material. A failed retrieval or
  access certificate makes the baseline comparison invalid; it is never
  evidence for LoRA superiority.

One native resource point plus a doubled-access sensitivity is sufficient.
There is no need for a Pareto sweep unless the paper makes an efficiency-
optimality claim.

## Minimal saturation test

The safest default wording is superiority over **this exact qualified text
configuration**, not saturation of external memory in general. If the paper
uses “after the evolving-text baseline plateaued,” freeze the following before
confirmation identities exist:

1. Select the anchor on text-only DEV from a finite early-cut set, with at
   least two increments before it and at least three checkpoints after it.
2. Require scheduled source novelty, a passing text certificate, and at least
   `.10` oracle headroom throughout the late window.
3. At the native `B=1,024` budget, require the root-level two-sided 90% interval
   for late slope to lie inside `[-.020,+.020]` normalized utility per cohort;
   registered late interval gains must satisfy the same family-adjusted
   equivalence rule. A negative decline is not a plateau.
4. Run a separately forked `2B=2,048` return-budget sensitivity under the same
   updater and store. It must also be locally flat, and its paired terminal
   advantage over `B` must be equivalent to less than `.020`. If `2B` cannot
   fit the frozen context partition or cannot be powered, omit “saturated.”
5. Independently require positive `P-RUN` late slope, positive anchor-to-
   terminal gain, old-competence noninferiority, positive slope advantage, and
   the frozen terminal practical margin.

The `2B` arm is conditional on wanting the saturation sentence. It is not an
upstream gate for M, the parenting-by-SLEEP interaction, or an absolute
increasing-lifetime result. Without it, a valid paper may still report the
exact-configuration comparison and all absolute L endpoints.

## Smallest defensible compression endpoint

Run compression only after an M connected-utility endpoint qualifies. The
minimum paper-grade endpoint is the repaired same-denotation, two-part coding
test:

- freeze all public opportunity slots before action and encode every parsed,
  absent, malformed, late, and unsupported slot in the same `D_pub`;
- prospectively commit one child-selected schema instance before later
  outcomes, then encode deterministic residuals so decoding is byte-exact;
- charge schema inventory, decoder, codec, index, selection metadata, and all
  life-specific bytes;
- compare against both `PACKED_NORMALIZED(D_pub)` and the identical ordinary
  codec applied to that packed representation; and
- at both preselected later loads `m2` and `m3`, require one-sided upper 95%
  bounds below `.80` for both plain and codec two-part rate.

Release the compression clause only if exact round trip passes, upstream-
qualified connected/cross-era utility is noninferior to packed text
(`upper95[U_packed-U_child] < .05`), false-action excess is below `.01`, and
schema-binding shuffle/equal-marginal controls remove the claimed schema value.
Choose confirmation `N` only from the existing finite set
`{16,24,32,48}` using failure-inclusive DEV power; otherwise return `NO_GO`.

The resulting maximum sentence is narrow but publishable: within a supplied
schema language, the child prospectively selected a two-part exact semantic
code at least 20% shorter than packed same-denotation text while preserving an
already established connected utility. Optional powered LoRA transport can be
added only if the paper specifically needs that clause. It remains transport,
not compression. Physical actor/resume compression stays closed until the
complete persisted and cold-resume packages actually cross the same-denotation
references at useful later loads.
