# Post-relay minimum decisive benchmark ladder

**Date:** 2026-09-13 UTC  
**Role:** fresh independent benchmark and paper-value attack  
**Evidence cut:** repository `b630a2cb398537b716c5d366a990053fe7eabd00`

This is analysis only. It changes no builder source, benchmark bytes, model,
tokenizer, adapter, job, GPU state, threshold, or scientific result.

## Verdict

Do not jump from the supplied-action Q0 or the planned endogenous action relay
straight into the existing full M-core contract. The missing rung is smaller
and more fundamental:

> Can one SLEEP make the child generate a **local fact or connection from its
> own action--outcome history**, with no answer-bearing candidate outside the
> weights?

Q0 can establish supplied conditional native-action carriage. The one-SLEEP
relay can establish child-authored outcome-to-future-action carriage. Both can
pass as a flat policy table. Neither shows that the adapter carries an event,
relation, or connection that a goal-directed thinker can traverse.

The smallest decisive continuation is therefore one fresh opaque route-world
family and four ordered rungs:

```text
S -- endogenous semantic-row gate                 2 fits
Z -- exact-text/world/shortcut/baseline closure   0 fits
M -- two-SLEEP route-and-expand microcycle        5 fits/root
L -- four-cohort lifetime + strong memory         4 periodic + 1 batch fit/root
```

Run `S` only after the current action relay passes. Run two `M` development
roots only after `S` and `Z` pass. A complete two-root `M` pass releases eight
fresh fixed confirmation roots. Only a confirmed `M` releases a lifetime
study. This avoids spending a long life to rediscover that the system stored a
habit rather than knowledge.

The proposed maximum before lifetime is **52 small fits**: two for `S`, ten
for two `M` development roots, and forty for eight confirmation roots. Every
stage stops failure-inclusively. This is substantially smaller than the
108--144-fit M-core routes while retaining separate source, connection,
goal-traversal, new-write, and binding interventions.

## 1. What is still missing after the relay

| completed/planned evidence | strongest allowed inference | missing for the paper objective |
|---|---|---|
| Q0 | supplied opposite input-conditioned actions can coexist safely | own experience; semantic memory |
| one-SLEEP action relay | a child-authored outcome-supported future action can survive reset | factual relation read; connection; composition |
| `S` below | own action--outcome experience can become a candidate-free local memory row | goal-directed multi-row use |
| `M` below | connected rows are traversed, direct an experiment, and support OLD+NEW reuse | improvement over lifetime |
| `L` below | the complete system improves over novelty-growing cuts and is compared with strong memory | physical compression; parenting population effect |

An action relay is necessary, but an action can become automatic without the
system retaining an inspectable world relation. The semantic gate is what
separates *policy installation* from *experiential knowledge*.

## 2. One fresh benchmark object, not another public fixture

Generate a new private opaque root population only after the protocol and
checker freeze. Reuse the causal idea of PCFL, not any old D0/M-core root,
identifier, alias, task row, public expected trace, or CompilerGym strategy.
The generation program may later be released; the scientific root entropy and
root contents remain unexposed until their registered run.

Each root is a small directed route world:

- two routes leave the same start and reach different old goals;
- their edges were witnessed in separate child-chosen action episodes;
- one link between separately witnessed events is useful to each route;
- one frontier edge is initially missing;
- a later goal makes exactly one of two equal-marginal experiments useful;
- the public outcome determines one new local relation; and
- a delayed goal is mechanically impossible without one OLD link and that NEW
  relation.

Handles, order, lengths, action marginals, source frequency, and one-token
shapes are balanced before semantic assignment. Roots contain independently
randomized bindings, not renamed copies. Both possible frontier outcomes are
balanced across the fixed root roster. No target goal, complete route, future
answer, or target-conditioned query occurs in source experience or training.

The child authors two record types before seeing any later goal:

```text
EVENT <event>: <source> + <port> -> <destination>  EVIDENCE <execution>
LINK  <link>:  <event_1> THEN <event_2> VIA <shared_node>
              EVIDENCE <execution_1>,<execution_2>
```

The compiler checks chronology, exact public outcomes, citations, and shared
endpoints, then copies the child's semantic bytes or rejects them. It may add
fixed lexical views and replay. It may not invent an event, endpoint, link,
orientation, query, route, action, or repair. Rejected proposals stay in the
formation denominator.

### Candidate-free memory interface

Only the actor sees the goal. It may emit:

```text
READ OUTGOING <node>
READ LINK <event>
```

A fresh, goal-blind memory process receives only that request plus the assigned
base/adapter and generates exactly one complete local row or `MISS`. No row
candidate, candidate ID, candidate bank, graph, live-membership bit, scorer,
goal, action menu, or expected trace enters the memory process. Raw generation
goes to the actor without repair. One row never contains a whole route.

This is smaller than M-core's general `MemoryRow` machinery while closing the
same fatal reader shortcut. The actor must choose what to ask, join the raw
returns in its THINK context, and act. The adapter carries local memory; the
THINK loop carries traversal.

## 3. Rung S: endogenous semantic-row gate

Use one permanently excluded root, eight child-executed transitions, and eight
child-authored supported EVENT records. SLEEP renders only those records.

From byte-identical clean state train:

- `S_AUTH`: authentic child records;
- `S_DEST_SWAP`: fixed-point-free destination rebinding with identical dose,
  target lengths, views, optimizer work, initialization, and target marginal;
- `S_OFF`: no fit, inference only.

This is two fits. Sterile exact and held reads must use ordinary candidate-free
generation. A pass requires:

- all `8/8` records were authored after the cited child action and public
  outcome, with no compiler semantic repair;
- exact reads at least `29/32`, held-view/new-object reads at least `14/16`,
  with validity at least `31/32` and `15/16` respectively;
- DEST_SWAP produces its registered redirection on at least `14/16` held
  reads, rather than generic failure;
- OFF and wrong-root do not acquire the authentic map;
- save/reload is exact, no false memory is used, and copy/native-action/locality
  value changes by at most `.05`.

Formation shortage is `SEMANTIC_FORMATION_FAIL`, not writer failure. Exact
storage with held-read failure is `STORED_NOT_EXTRACTABLE`. Spill or interface
damage is `UNSAFE_SEMANTIC_WRITE`. Any terminal stops `M`; do not compensate by
raising rank or inserting a candidate bank.

`S` proves one bounded own-experience-to-semantic-memory relay. It does not
prove connection, traversal, or a lifetime.

## 4. Rung Z: zero-fit assay and baseline closure

Before any route fit, use four fixed DEV roots with exact text and the exact
witnessed graph. Require all four to pass:

1. hidden legal-history and exact linked text solve at least `.90` of rote,
   both-goal, experiment-choice, and delayed OLD+NEW endpoints;
2. no memory and every target/state/ID/order/length/frequency shortcut remain
   at chance plus `.05` or below;
3. removing the needed LINK, OLD event, or NEW event reduces its designated
   endpoint by at least `.40`;
4. goal swap redirects the first query, traversed route, and action;
5. outcome/binding swap redirects the NEW row and delayed action, rather than
   merely producing malformed output;
6. linked exact text beats atoms-only exact text by at least `.20` on the
   registered link-dependent endpoint; and
7. running versus skipping an evaluation leaves every later public byte
   identical.

If atoms-only text solves equally well, the world can test read-time
composition but not the value of a compiled connection. Do not fit it under a
connected-DREAM claim. If exact linked text fails, repair the world/reader,
not the LoRA.

At the same stage certify the strong text opponent described below. That
certificate is zero training fits and prevents adding a weak baseline after a
favorable LoRA result.

## 5. Rung M: five-fit two-SLEEP route-and-expand microcycle

Use two fixed DEV roots first. Both must complete every link; no averaging one
good root over one bad root.

### SLEEP 1: source, connection, and traversal

Train three matched states from the same clean checkpoint:

```text
LINK_AUTH      authentic child events + authentic child LINK
ATOMS_MATCHED  same authentic events + grounded irrelevant matched slot
LINK_PERMUTE   same events + fixed-point-free permutation of LINK targets
```

After a complete reset, score rote event reads and two incompatible goals from
the same start. A root passes SLEEP 1 only if:

- pre-admission informative-LINK precision is at least `.80` and rejected
  guesses remain in the denominator;
- rote event accuracy differs by at most `.05` across the three fitted states;
- LINK_AUTH completes both routes and a goal swap redirects its first memory
  query, complete route, and public action;
- LINK_AUTH exceeds both ATOMS_MATCHED and LINK_PERMUTE by at least `.20` on
  the link-dependent endpoint; and
- LINK_PERMUTE produces the registered wrong traversal often enough to show
  semantic redirection, not generic damage.

This makes the connection behaviorally necessary while holding its underlying
events fixed.

### Information-seeking action and SLEEP 2

With LINK_AUTH memory mounted, the child sees a new goal, states the gap and
two hypotheses, commits one separating experiment and both
`outcome -> prospective EVENT` records, then acts once. Only the ordinary
public outcome selects one already-authored branch.

Train two cumulative clean-base states:

```text
OLD_NEW_AUTH   exact authentic OLD union selected NEW
OLD_NEW_SWAP   exact same OLD union plus matched wrong NEW binding
```

The SLEEP-1 LINK_AUTH state is the no-second-write comparator, so no third S2
fit is needed. OLD_NEW_SWAP supplies both equal-work extra training and a
semantic redirection control; a PAD fit adds little information.

A root passes only if authentic OLD memory selects the unique informative
experiment before its outcome; the selected NEW row is child-authored and
chronologically grounded; OLD_NEW_AUTH solves the delayed task; the SLEEP-1
state cannot solve it; OLD_NEW_SWAP generates and acts on the registered
alternative rather than simply collapsing; and old-route value after SLEEP 2
is within `.05` of SLEEP 1. Strict memory/action legality must be at least
`.95`, false-memory use must be zero, and every old/new/link/wrong-root cut
must affect only its registered dependency.

### Smallest confirmation

If both DEV roots pass unchanged, run eight fresh independent roots with five
fits each. Define one binary `COMPLETE_M` per root requiring every source,
formation, link-value, traversal, informative-action, second-write, delayed
reuse, retention, locality, and intervention gate. Missing or failed roots are
zero. Require at least `7/8`; under `H0: Pr(COMPLETE_M)<=.5`, the exact
one-sided tail is `9/256 = .0352`.

This supports a bounded population-over-worlds mechanism claim for one fixed
child. It does not estimate a population of children or establish indefinite
self-improvement.

## 6. Rung L: lifetime and the strong-memory contest

Only after confirmed `M`, embed the same route algebra in four
novelty-certified information cohorts, giving five fixed exam cuts including
entry. Every cohort contributes genuinely new child action--outcome relations,
at least one old/new dependency, and one possible information-seeking action.
Views, paraphrases, repeated tasks, and optimizer exposures do not advance the
lifetime clock.

For each independent life root run three native systems from the same clean
child and the same presealed opportunity/potential-outcome tape:

- `DLT_PERIODIC`: THINK/DREAM plus cumulative SLEEP promotion each cohort;
- `SLEEP_FROZEN`: same wake/DREAM opportunities, no promoted personal write;
- `ACTIVE_LINKED_TEXT`: frozen actor with evolving lossless/linked memory.

Each owns the consequences of its actions. Different later histories are a
causal part of the total-system comparison, not missing data. At each cut,
also build inference-only common-history text/RAG/graph views over the DLT
branch's exact ledger; this separately distinguishes carrier value from an
on-policy history advantage. One terminal `FINAL_BATCH` fit over the DLT
branch's final accepted corpus, with matched total target-token exposure, is
the temporal control.

Thus a four-cohort root needs four periodic fits plus one terminal batch fit.
Run four excluded DEV roots first. Kill the long program if the full learner's
absolute post-entry slope is nonpositive, old competence falls by more than
`.05`, the writer yield is too low to produce all registered cuts, or oracle
headroom is below `.10`. Otherwise set a root-level confirmation size from the
blinded DEV variance, with `16` as the minimum and a predeclared resource cap.

Ordered claims require:

1. DLT has positive entry-adjusted AUC and anchor-to-terminal gain versus
   SLEEP_FROZEN, with a point estimate at least `.05` and a 95% root-level
   lower bound above zero;
2. old/early competence remains within `-.05`;
3. DLT beats ACTIVE_LINKED_TEXT on the registered terminal or post-anchor AUC
   endpoint by at least `.05`, with a 95% paired lower bound above zero; and
4. the same-history carrier table agrees in direction before saying the LoRA
   itself is superior. If only the native on-policy comparison passes, claim
   a system advantage, not a carrier advantage.

Do not use the word *saturated* unless ACTIVE_LINKED_TEXT's last two increments
and late slope each have 90% root-level intervals inside `[-.05,+.05]`, oracle
headroom remains at least `.10`, retention passes, genuinely new evidence
continues, and doubling its frozen retrieval bandwidth is also equivalent.
Otherwise report finite response curves.

## 7. Baselines that cannot be weakened

The paper-facing minimum is:

- `NONE/SLEEP_FROZEN`: no persistent personal memory;
- `NATIVE_CONTEXT`: raw chronology until the measured usable context limit,
  then honest chronological truncation;
- `RAW_RAG`: lossless events, typed exact matching plus BM25, actor-authored
  queries, complete cited episodes;
- `ACTIVE_LINKED_TEXT` (**primary strong comparator**): all raw events plus the
  exact same admitted child EVENT/LINK rows, frozen typed index plus declared-
  link traversal/PPR, native planning, four charged reads and initially 1,024
  returned tokens, frozen from an excluded 1,024/2,048/4,096-token DEV ladder;
- `FINAL_BATCH`: one terminal LoRA write from the same final accepted material
  with matched total optimizer exposure;
- `EXACT_WITNESSED_GRAPH`: public-event-only graph with native planner, a
  task-native reference allowed to win; and
- `GOLD_HISTORY`: headroom only, never ranked as a deployable system.

ACTIVE_LINKED_TEXT must certify source/citation fidelity `=1`, no hidden,
future, wrong-root, or parent row, deterministic rebuild, insertion-order
invariance, binding-twin redirection, bridge-cut drop at least `.40`, irrelevant
store effect at most `.05`, and action legality at least `.95`. It receives
the same child organization as DLT; withholding LINK rows from it would turn a
compiler advantage into a fake substrate advantage.

If linked text or the exact graph wins, report it. The benchmark remains
useful because it localizes whether the advantage is experiential formation,
parametric transport, or memory access.

## 8. Compression is a sidecar, not a gate

The current rank-8 all-layer adapter is about `80.79 MB`; a small route root
cannot support a physical LoRA-compression claim. Do not count rank or training
tokens as compression.

After `M` passes, run a zero-new-fit semantic-code sidecar over the same fresh
roots:

- normalized observation-expanded EVENT text;
- unique atomic EVENT rows; and
- child-authored EVENT+LINK schema/residual code.

Charge the complete codebook/index/decoder and measure exact reconstruction of
the canonical public transition semantics, false memories, action utility, and
bytes/tokens at increasing unique-relation loads. Only call DREAM output a
compressed semantic code if it is shorter than the normalized expanded
denotation while reconstructing it exactly and preserving utility within
`.05`. A trivial reduction from verbose raw chat or repeated paraphrases does
not qualify. LoRA remains a transport surface unless the complete mounted
life-specific bytes cross a separately registered physical rate boundary.

## 9. Information-per-GPU-hour decision tree

| stage | maximum new fits before next decision | failure disposition |
|---|---:|---|
| current Q0/action relay | already running/designed | no semantic or graph spending |
| endogenous semantic `S` | 2 | stop or localize formation/storage/extraction/locality |
| zero-fit `Z` | 0 | repair world/reader/baseline; never fit around a shortcut |
| M development | 10 | either failed root stops confirmation |
| M confirmation | 40 | report fixed complete-chain rate; no root replacement |
| L development | 20 | stop on wrong slope, retention, yield, baseline, or headroom |
| L confirmation | `5 * N_root`, `N_root>=16` | report registered finite curves |
| semantic compression | 0 new fits | omit compression if rate/fidelity fails |

Do not bind wall-clock or A40-hour claims from the much smaller Q0 corpus.
After `S`, profile one actual S1 and one actual cumulative S2 fit, then bind
caps as measured time times the exact maximum fit roster plus fixed cleanup.
Inference and retrieval are separately charged. Logical early stops may save
compute but never redraw a root or change a denominator.

## Final claim firewall

```text
Q0                    supplied selective action writer
action relay          learned future-action preference from own outcome
S                     learned candidate-free experiential relation memory
M / SLEEP 1           child-authored connection used under different goals
M / SLEEP 2           memory-guided experiment and delayed OLD+NEW reuse
L                     improvement across novelty-growing lifetime cuts
baseline comparison   finite or plateau-qualified superiority only
compression sidecar   semantic code only; not physical LoRA compression
```

The shortest scientifically valuable move after the relay is `S`, not a large
lifetime and not more CompilerGym. A valid failure there would say the current
writer can install action tendencies but cannot yet expose lived relations as
usable memory. A pass opens one compact route-and-expand study in which every
later word—connected, traversed, expanded, improving, superior—has its own
behavioral necessity test.
