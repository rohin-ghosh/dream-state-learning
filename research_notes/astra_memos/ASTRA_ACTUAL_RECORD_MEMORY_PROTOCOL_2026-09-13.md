## Cold readbacks and interpretation

After each fit exits and releases its owned processes, load the resulting
checkpoint in a fresh inference process with no formation conversation,
retrieval, cached feedback or record corpus. Both arms receive identical:

1. Exact source-withdrawn training cue for every admitted row (primary
   acquisition/persistence endpoint). This is memory of experienced events,
   NOT unseen-example behavioral generalization.
2. Separate fixed paraphrase cue for those same rows, never trained in this
   primary experiment (prompt-access transfer, not pooled with primary).
3. Original frozen perception48held and12copy/arithmetic canary prompts
   unchanged and absent from this write corpus (narrow retention endpoints).

against original actual execution, not a model-supplied reference: source-
faithful production eligibility, typed fields, exact raw bytes and canonical
format separately. All reference facts are evaluator-only. Report per-arm,
per-seed numerators/denominators and paired wins/losses plus retained/regressed

Correct original-TRIPLE but wrong observed/prior/relation is not successful
memory. An exact-cue gain with no paraphrase gain is an access-limited result.
No gain despite valid finite updates is an informative negative, not proof
that all writing or model capacity fails. Learning retention tradeoffs must be
reported. One additional write does not establish repeated-update G3; no
posthoc success threshold, adaptive row selection or automatic extra dose.
