## Frozen diagnostic question

Does one same-child action-projection opportunity recover an executable next
action after invalid tentative text, without extra wake responses or executing
the invalid proposal? Compare the original completed AUTH birth adapter with
the unchanged adapter-OFF base under the same new interface. This is an adaptive
development diagnostic after SEQ121-123, not confirmation of parenting or learning.
No further birth fit, sleep write, extraction export or adult readout is selected.

Each child mode runs the existing P/A formation topology: two rule families,
pre and apply tasks, four tasks per P/A arm, eight tasks per child mode. The new
namespace `astra-action-projection-v1-20260913` determines fresh development
quiz instances and generation seeds. Both modes use exactly the same schedule,
role sampling settings, public action grammar and frozen parser/world checks.
Each invalid response gets at most one next-response projection opportunity;
a failed projection terminates that task. All responses, including invalid and
projection responses, consume the same five-response task budget. There is no
first-action salvage, hidden retry, extra response or rewritten raw string.

AUTH routes wake/record/restate to its completed original adapter; OFF routes
all roles to the base. Parent is always adapter-OFF in both modes. P and A retain
their existing process-parent and neutral-recap prompts. Actual texts/trajectories
can differ with child behavior; no equality of parent content is assumed.
Tentative proposals are explicitly marked unexecuted in public history. This
marker does not certify the parent's semantic interpretation. Main must inspect
every parent text against its actual source transcript before interpreting P/A.

## Decision boundary

before selecting a separate learning path. If it does not, use raw invalid/
projection pairs to localize the next smallest repair. OFF separates adapter
increment from base/interface failures on these fresh development instances;

G3/P1/G5/H1/H2, or a functioning adult learning loop. Closed Q0 uses only its
