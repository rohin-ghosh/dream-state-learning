## Question and limits

SEQ160 failed its frozen screen, but every NOTE/source failed normalization.
That is not evidence that every raw binding was wrong. Some raw records also
omit required operations or fields. Test a NEW, explicitly specified output
contract to separate accessible content from serialization. Do not rescore or
rescue SEQ160, train its raw outputs, or describe this as parenting amortization.

The ordinary instructions below explicitly teach the requested operations.
Any ALIGNED advantage is therefore incremental responsiveness to the fixed
lesson/current-restatement package under that scaffold, not discovery from
advice alone. Ties can reflect redundancy or a ceiling, not parenting futility.
No persistent-write, transfer, H1/H2 or clean-lineage conclusion is available.

## Frozen cohort and controls

Use the same three ORIGINAL pre-memory perception adapters, seeds0/1/2, frozen
base and CPU world. These are exposed DEV roots. Do not use later descendants.
All roots/arms receive the same new eight tasks in four two-task blocks P-C-C-P.
The four P tasks cover each Boolean prior/outcome pair once. The four C tasks
cross latest-first/latest-last display with true/false latest outcome; their
two public actions differ and outcomes oppose. Generate actual public receipts
in the frozen world, without treating those harness actions as the child's.
The new roster is frozen before any model output; check actual task/receipt
identities and public payloads against supplied prior DEV inventory. Namespace
separation is not a claim of universal clean ancestry. No confirmation data.

ALIGNED receives the old literal P-C-C-P lessons; SWAPPED gets C-P-P-C. Reuse
the frozen SEQ160 lesson strings without task values, answers or hidden rules.
ACTIVE_NEUTRAL receives at every block exactly:
"Continue with the next scheduled tasks using their instructions. Briefly acknowledge this message before proceeding."
All arms have one current contact/restatement opportunity per block. Use the
same restatement request and insertion mechanism as SEQ160, preserving raw
child restatements; application receives the restatement, not the fixed lesson.
Do not select, correct, paraphrase or certify a restatement. No lexical gate.
No accumulated history beyond the current block restatement.

Every task has at most one wake and one post-dispatch record call. Four extra
restatement calls make20calls/arm,60/seed,180total. Invalid action means no
dispatch and no fabricated receipt/record, but keeps its task denominator.
Zero fits, updates, new adapters, adaptive-parent calls or training use.
Equal contact opportunities and ALIGNED/SWAPPED lesson multisets are not equal
realized tokens; ACTIVE_NEUTRAL is not an exactly token-matched control.

## Arm-uniform observable contract

All arms see the same family-specific instruction and typed template. Templates
use type placeholders, never solved task values or evaluator answers.

Wake object: `{"note": OBJECT, "prediction": BOOLEAN, "action": {"kind": "TRY", "values": [INTEGER, INTEGER, INTEGER]}}`.
Fresh prediction must be Boolean. Preserve original strict dispatch bounds;
extra metadata must not open another action path or relax dispatch validation.

P note: `{"predicted": BOOLEAN, "observed": BOOLEAN, "relation": "matched" | "mismatched"}`.
Instruction: "For the public receipt, report its prediction as stated before that action, its returned observation, and whether those values match. These are not your new action's prediction or outcome."

C note: `{"receipt_id": STRING, "try": [INTEGER, INTEGER, INTEGER], "observed": BOOLEAN}`.
Instruction: "Select the executed public receipt with greatest time, not the last receipt displayed. Report that receipt's ID, action and observation together."

Record object: `{"address": STRING, "source": OBJECT, "event": {"receipt_id": STRING, "try": [INTEGER, INTEGER, INTEGER], "predicted": BOOLEAN, "observed": BOOLEAN, "relation": "matched" | "mismatched"}}`.
Explicitly identify source as the task's earlier public P/C note object, not an
origin-prose string; event as ONLY the child's newly executed action/receipt;
address as the supplied task address. Match/mismatch is a child-emitted string,
not a wrapper-computed field. Compare source to original public evidence, not
to a possibly erroneous wake note. Compare event to actual child execution.
Freeze all assembled ordinary prompt bytes and templates in CPU fixtures.

## Separate readouts, not a replacement feasibility gate

Decode one unfenced JSON object; reject duplicate keys, nonfinite values,
multiple objects, ambiguous parsing and coercion. Read required fields only
at their exact declared paths; no recursive search, aliases, prose judgment,
candidate selection, flattening or inferred relation from two listed values.

Report decode status, field presence, types, content correctness, schema
compliance and canonical serialization separately. Correct required fields
with extra metadata may pass CONTENT while failing SCHEMA. Missing fields
remain missing; malformed JSON is unassessable, not a measured wrong value.
Other accessible fields remain assessable when a neighboring field is missing.

Primary diagnostic is correct public NOTE bindings with normal completion,
separately for preservation/comparison and selection/same-receipt binding.
Report each family/4 and all tasks/8. Do not AND this endpoint with lexical
restatement, dispatch or record formatting. Separately report dispatch/8,
source-record bindings/8, each own-event field/8, complete record content/8 and
schema-compliant complete records/8. Show called denominators additionally,
never in place of full denominators. Every failed/uncalled slot remains.

Report all task masks and ALIGNED-minus-SWAPPED/ACTIVE_NEUTRAL contrasts by
learner. Three roots, not72 independent learners. No success cutoffs, promotion,
rescue of old thresholds, selection of favorable roots, retries or added dose.
Raw restatements and all contact/prompt/output costs remain visible diagnostics.
