## Exact semantics

All structural names below remain private and are replaced by the existing
typed opaque inventory before any model-visible rendering.

- Relevant frontier: `H -> S_R`, existing `q0/q1`, selected by R.
- Distractor frontier: `X -> Z`, the same `q0/q1` port inventory, selected by D.
  The latent transition is `X --q_D--> Z`. It enters the existing dead-end
  detour ending at Y, never a route to either delayed goal. It is included
  in full-private-transition route/cut audits, but is not a witnessed EVENT,
  does not receive an EVENT address, and never enters an authentic fit bank.
- R and D are independent balanced binary states, fixed with O before the
  eight-cell expansion. All cells use the same opaque inventory; no redraw.
- The two affordances have identical public field types. Existing RA/RB
  literal templates and opposite listing order remain unchanged; substitute
  X/Z for the distractor endpoints, H/S_R for the relevant endpoints.
- Exact public result for either selected probe (one terminal LF):

```text
PROBE RESULT {probe} TESTED {source} TO {destination} AVAILABLE PORT {port}\n
```

Here `\n` denotes one LF byte, not two printed characters. No role word,
R/D bit, success/usefulness label, route, answer, hidden score or other
frontier's result is returned. Relevant returns q_R; distractor returns q_D.
- Internal probe-observation receipts use existing r9 (relevant) and r10
  (distractor) with `kind=PROBE`, root/stage/turn/hash custody. The public
  result above does not print a receipt ID. Neither is an executed-event
  receipt and neither can support an EVENT/LINK target. They are distinct
  from the later relevant `EXPLORE` receipt r8.
- Exactly one PROBE is consumed, including malformed/unlisted commitments.
  A valid relevant choice returns only its ordinary result and enables the
  one registered `EXPLORE H q_R`, then one EVENT/two LINK opportunities.
  A distractor choice returns its ordinary result, then terminates this
  root's lineage without further model calls, exploration or training.
  There is no additional terminal public message. A malformed/unlisted
  choice terminates with no result bytes. Neither reveals R afterward.
- G_ IDs are reserved private goal metadata only. Every rendered START/GOAL
  and ROUTE endpoint is the corresponding N_ node ID. Root labels are private.
  No new public root-ID namespace or goal-ID substitution is introduced.

## Chronology is not edge numbering

The fixed OLD source order remains `S_L,A,H,S_R,B,Z,S_L,B`. Actual EVENT
addresses are chronological: the sixth event (e5) is at Z, while the eighth
(e7) is the second B observation. Ideal graph edge indices are not an
alternative source of live addresses. Seal expected structural banks before
generation using actual opportunity chronology and explicitly selected
prospective choices. Missing/mismatched authentic child spans fail formation;
never remap handles after outputs or insert oracle rows. The separate
formation-plan implementation exists to make this seam explicit.
