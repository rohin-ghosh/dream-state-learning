Identical task IDs across arms: `rule{lesson}/astra-minimum-20260912/lesson{lesson}/{pre|apply}`. Frozen pinned Qwen2.5-7B-Instruct, no incoming adapter; generation seed 20260912. Each task allows five wake responses: up to three actual TRYs, one quiz reveal, one scored quiz. Generate a child record after each valid **apply** TRY only, not pre TRYs. Early endings leave unused opportunities; no replacement tasks.

**2. Existing seams; small missing adapters.** Reuse `nursery_dialogue.play_task`'s Episode/dialogue shape and `parent_turn`, `RuleGame.evaluate/quiz_triples`, and `batch_loop.run_episodes_batch(..., driver_cls=..., note_after=...)`. **3. Active control and costs.** Both arms receive one parent request and one restatement per lesson. P gives one process correction without answers; A gives neutral acknowledgment without strategy, rule, correction or action recommendation. Same base, parent ceiling 200 tokens, restatement ceiling 120, temperature .5; wake ceiling 400 and record ceiling 100, temperature .7. No exact padding, dummy calls or parent retries. Match opportunities/settings and report actual rendered input tokens, repeated lesson exposure, generated tokens and time by role. This is active-contact/opportunity matching, **not exact realized compute matching**.

**4. Minimal faithful record.** Prospectively freeze one common slot instruction requesting exactly one JSON object: `try` (three submitted integers), `observed` (returned Boolean), `predicted` (actual explicit pre-ACT Boolean or null if absent), `relation` (`matched`, `mismatched`, or `unavailable`). All fields must match the linked actual execution; ambiguous prediction binding, extra prose/fields, malformed output or unsupported facts reject the record. One generation only; never repair, fill or reserialize a corrected target. This tests **format-coached faithful event recording**, not faithful free-prose explanations, useful hypothesis formation or open-ended reflection. It cannot retrospectively pass the old process-note criteria.

**5. Admission and selection.** Select the first **two** eligible apply records per arm in physical source order, from at most six opportunities, requiring distinct execution IDs but not distinct prose. Duplicate text from different actual executions is allowed and disclosed, not called independent knowledge. **No valid-quiz requirement; no apply>=pre gate.** If either arm has fewer than two records, terminate at formation: neither fit nor any subsequent OFF/readout task. No source search, extra tasks, one-sided fit or threshold reduction. Eligibility and first-two selection remain **post-treatment selection**: parenting affects yield, actions and selected content. Report all source opportunities/rejections; the selected-material comparison is not an unconditional parenting effect or mediation estimate.

Parent/control lessons, restatements, slot instructions and full prompts are prohibited everywhere in corpus, **even masked input**; ancestry stays in side receipts. Bypass generic/native sleep rewriting and v21. Fit each arm fresh from the same base: rank 8, lr 1e-4, seed 2, **12 epochs**, native batch 4, two rows ⇒ **12 steps/arm, 24 total**. Fixed tiny-data dose, no tuning; equal steps do not imply equal target-token mass. Preserve immutable artifacts; no ongoing-life promotion or invented formal lineage receipt.
