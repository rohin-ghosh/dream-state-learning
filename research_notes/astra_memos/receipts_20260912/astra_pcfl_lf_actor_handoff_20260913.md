## Stable interface

`gpu.astra_pcfl_lf_actor` exports:

- `POLICY = "pcfl.disposable_old.format_only_terminal_lf.v1"`
- `REGEX = r"[^\r\n]+\n"`
- `sampling_for(request, limits) -> dict`
- `LFNativeActor(native.NativeActor)`

`sampling_for` returns the existing `native.SAMPLING` plus request seed and `max_tokens=limits['output_tokens']`. It adds exactly `structured_outputs={'regex': REGEX}` for request IDs `old/formation/01,03,05,07,09,11,13,15,16,17,18,19` (each with the full prefix). All other IDs, including eight EXPLORE IDs and READ/nonformation IDs, retain the original sampling dictionary. Matching is exact, with no prompt-content sniffing. Requests and limits are not mutated; each returned nested dictionary is fresh. No plan, receipt, expected ID, outcome, target row, or candidate selection enters this function.

`LFNativeActor` overrides `_sampling(request, limits)` to call that function. Its config validation additionally requires `source_files[str(Path(lf_module.__file__).resolve())]`. The inherited source-hash verifier validates that actual file before loading the model/generating; wrong hashes fail, and inherited file-signature checks protect subsequent calls. Both the actually imported native actor and LF actor must therefore be pinned.

## Minimal native seam

This follows Main's supplied installed vLLM API; no installed native implementation was executed here.

## Scope / interpretation

The constraint is only a nonempty single physical line ending with one LF, excluding CR/LF inside the line. It deliberately allows wrong arbitrary contents and does not guarantee EVENT/LINK syntax or source correctness. It provides no semantic values. Generated bytes are returned unchanged; no stripping, LF append, forced semantic text, continuation or retry. A fake backend returning missing LF remains missing LF and fails the original parser; a length termination remains length in the raw receipt, for the formation stop-required validator to reject.

This is externally scaffolded serialization, not learned formatting or an original full-assay pass. Preserve both failed attempts. Use fresh source pins/preparation/manifest/output root, retain the actual backend/regex provenance, and keep source admission and writer-target provenance unchanged. Main owns prospective protocol, integrated acceptance, exact installed-backend checks, launch, shutdown/release and any subsequent fit. CPU tests here do not prove the installed grammar engine emits LF or EOS correctly.
