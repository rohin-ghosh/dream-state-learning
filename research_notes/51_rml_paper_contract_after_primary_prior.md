# 51 — RML paper contract after primary-prior and construct red teams

**Date:** 2026-09-03  
**Status:** current scientific design; not architecture ratification,
implementation authority, GPU authority, preregistration, or a result

## Decision

The paper is **text-primary and LoRA-gated**.

The load-bearing scientific result is whether target-blind prospective
proposals, later public-outcome admission, deterministic compilation, and
recurrent goal-conditioned traversal create external connected experience
memory that improves sealed post-context action over strong native connected
and consolidating memory systems.

The per-life LoRA is a preregistered secondary transport result. It asks only
whether the identical admitted semantics retain enough identity-specific
one-hop access in weights for the same recurrent resolver to recover action
value. It does not discover structure, verify claims, perform multi-hop
reasoning, or establish learned agency.

This resolves two different standards:

- A text-only locked RTCW result can be a credible minimal paper.
- It cannot confirm a paper named Dream--LoRA--Think. If the LoRA gate is
  omitted or fails, the title, abstract, contribution list, and conclusion
  must drop experience-to-weights, parametric world model, and
  Dream--LoRA--Think language.

The current repaired G1 consensus is unchanged. G1 is only a controller
construct gate and its exact hash-bound human ratification remains the next
executable decision.

## Why this is now the correct architecture

Primary papers occupy the broad ingredient claims:

- TMEM: within-rollout QA-to-LoRA memory and outcome-trained extraction;
- Auto-Dreamer: learned provenance-linked multi-source offline consolidation
  evaluated in action environments;
- PEAM: selective embodied skill consolidation into isolated MoE-LoRA;
- A-Mem: linked and evolving atomic external memory for multi-hop use;
- EVAF: selective goal-conditioned LoRA influence after context unload;
- Parametric Memory Law: LoRA rank--length memory laws and a small
  seen/unseen rule task.

Our remaining contribution hypothesis is therefore an identified causal
pathway and its evaluation instrument, not a new ingredient:

```text
public action/outcome life
    -> capped target-blind prospective proposal
    -> later ordinary public-outcome admission
    -> connected semantic snapshot
    -> recurrent goal-conditioned traversal
    -> sealed unseen interventional action
```

Text makes that causal pathway legible. LoRA tests transport only after the
semantics and action value already exist.

## Locked evidence ladder

### G1 — D0 recurrent controller construct gate

Use the existing repaired `chg_20260903_rml_g1_gold_action_fast_v1` proposal:
18 trajectories, exactly 234 registered opportunities, at most 234 model
dispatches, authentic/sham/cut/twin controls, and no DREAM, LoRA, or paper
claim. Failure rejects the exact recurrent action interface before expensive
writer or adapter work.

### G2 — small RTCW text-development gate

Use two independent open DEV pair roots from one open program family. Test
only the text pathway:

1. public experience and gold/program ceilings establish headroom;
2. a fixed capped proposal pool measures pre-outcome proposal precision,
   coverage, contradiction, and cost;
3. raw proposals, blind self-check, and later-public-outcome admission consume
   that identical pool;
4. `E-TEXT` uses recurrent THINK on the admitted snapshot;
5. authentic, binding-shuffled, twin, cut, and sham memories localize content
   dependence;
6. strong native RAG, A-Mem-like linking/evolution, and Auto-Dreamer-like
   region rewriting are verified usable.

No LoRA is trained if the text pathway cannot create action value.

### G3 — disjoint LoRA technical gate

On six disjoint calibration pair roots, freeze one admitted semantic set `M`
per life before targets. Derive all text and adapter data only from `M`.

Required arms and checks:

- identical-corpus `E-TEXT` and recognition-assisted `E-LORA-R`;
- candidate-only clean base and generative `E-LORA-G` sentinel;
- raw-event LoRA;
- outcome-trained direct-QA/TMEM-like LoRA;
- matched selective event-to-LoRA/EVAF-like control with selection and
  actuation calibrated separately;
- wrong-life, whole-twin, and binding-shuffled adapter swaps;
- exact, reverse, paraphrase, partial-cue, `NOT_FOUND`, false-match,
  contamination, retention, time, memory, and training-cost audits;
- clean-base composition after the memory adapter has answered one-hop reads.

Calibration chooses frozen practical fidelity, contamination, retention, and
action-value gates. Six roots authorize or reject the transport pipeline; they
do not supply population inference.

### G4 — locked text-primary confirmation

Run 48 fresh independent pair roots, 16 per program family. Targets, sides,
cuts, writer samples, decoder samples, and adapter seeds are nested; the pair
root is the only `n`.

Use one prespecified post-context boundary, initially the smallest validated
boundary near `2 L_native`. The primary endpoint is equal-root-weight sealed
environment action success on unseen binding-sensitive interventions.
Graph recovery, citations, N/O/J/P/X types, and proposal counts are
diagnostics.

The co-primary intersection-union claim is:

```text
E-TEXT > native linked/evolving A-Mem-like memory
AND
E-TEXT > faithful Auto-Dreamer-like consolidation
```

For each comparison, require a positive one-sided 95% stratified paired-
bootstrap lower bound and a point estimate of at least `+0.10` absolute
root-level action success. No pack may have a negative paired mean. Also
require authentic memory to beat binding-shuffled and twin memory by at least
`+0.10` with positive bounds, and to beat matched no-durable-memory/truncation.

Strong iterative raw RAG, honest full history where feasible, adaptive
truncation, witnessed atoms, matched reflection, generator-aware program
induction, exact graph, and target-independent gold remain interpretation
controls or ceilings. The program inducer is allowed to win.

If the disjoint G3 gate passed, include the frozen LoRA family in the same
confirmation as a secondary claim. Average technical seeds within root before
inference. A positive LoRA result cannot rescue failed text efficacy.

### G5 — later extensions, not required for the minimum paper

Do not attach these to the first confirmation:

- `2x--8x` finite developmental response surface;
- a separately powered equivalence/crossover saturation study;
- randomized authentic/null/shuffle/twin memory before a costly information-
  gathering phase and one reconsolidation cycle;
- learned cross-life THINK/DREAM policy adapters, rank cascades, or base-model
  promotion.

Each requires new roots and its own contract.

## RTCW anti-bespoke requirements

RTCW presently risks being a typed-graph unit test designed around the method.
The following are mandatory before confirmation:

1. `rml_d0` remains regression-only and contributes no paper sample, prompt,
   schema, threshold, endpoint weight, or benchmark-development trace.
2. Development uses only two declared open program families.
3. One of three confirmation packs is separately authored and output-blind.
   Its author receives only a narrow environment API and may not inspect
   system prompts, row schemas, thresholds, or open-pack results.
4. The locked pack changes state factorization, action
   preconditions/effects, and exception mechanism; it must not be expressible
   by renaming predicates and swapping tables in the open generator.
5. Handles, renderer, target order, irrelevant observations, and action
   serialization vary across roots. Across packs, the convenient latent
   representation also changes.
6. Root seeds, private programs, answers, and intervention assignments remain
   hidden until all trajectories are committed.
7. Public lives include randomized probes or explicit interventions sufficient
   to distinguish competing programs. Temporal association alone is not
   called causal learning.
8. Writer calls, tokens, rows, unique hypotheses, and mutually contradictory
   proposals are capped before outcomes. Admission cannot launder exhaustive
   enumeration into induction.
9. Primary efficacy uses each baseline's native interface. A common one-row
   interface is only a mechanism diagnostic.
10. A change after any locked output is viewed creates a new version and a new
    lock; repaired and pre-repair roots are never pooled.

External-environment validation is not required for the narrow RTCW instrument
paper. It becomes mandatory before extending claims to natural, embodied, web,
or generally long-horizon agents.

## Claim discipline

If only G2/G4 text passes, the strongest result is bounded to prospectively
grounded connected external experience memory and RTCW action. Drop LoRA from
the name.

If the frozen G3/G4 LoRA family also passes:

> The identical target-blind admitted semantics retained action value after
> transport into isolated per-life LoRA weights through a recognition-assisted
> one-hop read channel; adapter-identity interventions removed that value.

Still forbidden without separate evidence:

- first dreaming, parametric, connected, or self-evolving agent memory;
- LoRA discovery, verification, multi-hop reasoning, unique agency, or
  superiority to text;
- general causal-world-model learning from temporal records;
- semantic compression without rate--distortion evidence;
- continued improvement, saturation crossover, self-improvement, or an
  open-ended flywheel.
