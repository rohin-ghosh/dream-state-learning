# 54 — One-child PCFL relay v1: causal repair

Date: 2026-09-07

Status: unbound, proposal-only replacement for note 53. It authorizes no
architecture change, implementation, target generation, model/tokenizer call,
adapter operation, benchmark execution, external access, GPU use, or claim.
Execution requires its own source-bound deliberation, exact human ratification,
model-free fixtures, independent implementation review, and separate GPU gate.

## Scope

This is a post-confirmation mechanism assay for one fixed, parent-deleted child.
It does not add a parent, classroom, cohort, peer, teacher ensemble, competing
learner, shared state, or cross-root learning. Independent PCFL pair roots are
new environment trials of byte-identical clones of one fixed terminal child;
they support inference conditional on that child only.

The parenting experiment asks whether process teaching improves later learning.
This assay asks a different question:

> Can that fixed child carry authentic relations learned from its own public
> actions, traverse them differently under different goals, use them to choose
> a discriminating experiment, write the resulting new relation, and later use
> old plus new knowledge on a target hidden until after the write?

No result here rescues a failed parenting result. No successful parenting
result supplies evidence for this relay without this relay passing.

## Changes from note 53

The v0 four-phase narrative is retained, but its causal graph is repaired:

1. all source opportunities, goals, decisive relations, twins, candidates,
   interventions, RNG streams, and budgets are sealed without inspecting model
   output, learned memory, writer admissions, adapter reads, or scores;
2. one end-of-Phase-A child state `M_A` is frozen; Phase B is a write-denied
   diagnostic fork and cannot change the state entering Phase C;
3. authentic links are compared with byte-, type-, degree-, age-, exposure-,
   and candidate-matched link derangements, not deletion alone;
4. two goals over the same public start state must produce different relevant
   paths, and a matched nonadaptive/exhaustive controller must fail;
5. Phase C requires a pre-action proposal, hypotheses, predictions, and selected
   experiment; its target cannot be chosen because the child happened to leave
   one convenient gap;
6. Phase D branches only after one identical Phase-C action and public outcome,
   and purges every alternative carrier of that outcome;
7. semantic write content is separated from optimizer disturbance by no-write,
   resource-matched sham-write, and new-binding-swap branches; and
8. connectedness, traversal, experiment choice, writing, and delayed
   authenticity are tested in a fixed sequence with root-level statistics.

## Immutable pre-output packet

Before any scientific model output, each independent PCFL/twin pair root seals:

- hidden world and counterfactual-twin bytes;
- public source-opportunity tape and legal actions;
- two Phase-B goals over one identical visible start state;
- Phase-C gap, live hypotheses, registered separating experiment, matched sham
  signal, and reachout-off assignment;
- Phase-D target and its mechanically minimal old-plus-new proof;
- authentic link set, fixed-point-free matched link derangement, matched bridge
  substitution, new-binding swap, and sham-write row;
- candidate catalog, ordering, indices, reader bytes, tokenizer, prompts,
  decoding counters, resource ceilings, failure values, and all RNG streams;
- score functions, root aggregation, fixed test sequence, margins, missingness,
  and stopping rules.

Construction may use hidden PCFL truth and the sealed source-opportunity tape.
It may not read realized actions, child declarations, accepted rows, links,
writer status, adapter logits, retrieval behavior, probe scores, or whether a
candidate root looks easy. Failed acquisition remains a scored failure under
intention-to-treat; no target or root is replaced.

For a confirmatory claim, the rule selecting the single terminal child must be
frozen before parenting outcomes are unblinded. Otherwise this relay is labeled
exploratory and conditional on the post-hoc selected checkpoint.

## Permitted carried state

At the end of Phase A, freeze `M_A`:

- prospectively supported one-edge experiential atoms with public provenance;
- target-blind, directionless `USE_LINK` adjacency between already supported
  atoms, admitted before either Phase-B goal is visible; and
- the fixed child parameters and ordinary deployment state allowed by the
  carrier condition.

A `USE_LINK` may encode only co-use adjacency. It may not contain a goal,
held-out handle, action order, terminal action, success label, target identity,
complete path, shortcut payload, or policy continuation. `SHORTCUT`, `DECIDE`,
and answer-bearing records are forbidden in this assay.

Direct-record closure scans every model-visible byte and interface feature,
including identifiers, candidate membership/order/count, token length,
provenance availability, rank, link degree, latency, retry behavior, and
`NOT_FOUND` patterns. No side channel may identify the desired path or action.

## Phase graph

```text
fixed terminal child + parent/nursery deletion receipt
                       |
            presealed PCFL pair root
                       |
Phase A: child-selected actions -> public outcomes -> frozen M_A
                       |
       +---------------+----------------+
       |                                |
Phase-B write-denied diagnostic          restore exact M_A
LINK_AUTH / LINK_DERANGED / ATOMS_ONLY          |
matched bridge substitution / goal swap       Phase C
       |                                AUTH / SHAM / REACHOUT_OFF
discard process; no write                        |
                                      seal declaration, action, outcome
                                                 |
                             clone identical AUTH action/outcome boundary
                                                 |
                     EDGE_WRITE / NO_WRITE / SHAM_WRITE / NEW_BIND_SWAP
                                                 |
                          fresh-process Phase D with only assigned carrier
```

Every intervention is assigned before Phase A and activated only at its named
boundary. An early perturbed branch is never continued and interpreted as the
direct effect of a later mechanism.

## Phase A — own-action atomic acquisition

The child selects legal public information actions. The environment returns
ordinary observations. A target-blind DREAM may propose a one-edge atom only
with exact event citations; deterministic admission checks chronology and
prospective support. Phase A earns own-public-action provenance and atomic
retention only. It does not earn connection, traversal, or expansion claims.

Acquisition eligibility is defined by the presealed source tape, never by what
the child successfully learned. The harness may schedule opportunities but may
not choose the child's decisive experiment or repair an action.

## Phase B — connectedness and goal-conditioned traversal

Phase B forks from `M_A`, is evaluation-only, and cannot write. Two presealed
goals share the same public start state and carrier but require different
authentic paths.

Carrier assignments:

| assignment | contents |
|---|---|
| `LINK_AUTH` | same atoms plus authentic pretarget links |
| `LINK_DERANGED` | same atoms plus fixed-point-free degree/type/token/age-matched link permutation |
| `ATOMS_ONLY` | same atoms without links; explicitly resource-lower diagnostic |
| `BRIDGE_SUB` | same slots/bytes/degrees, but the necessary bridge is replaced by a type-matched twin/false edge |

Credit requires a successful public action and a typed path whose every query
anchor comes from the goal/state, an earlier public outcome, or an explicitly
returned atom. The runtime may copy only the atom selected by the model. It may
not rank semantic relevance, select a next edge, validate a proof, repair a
trace, or insert a path.

Traversal credit additionally requires:

- the two goals change the registered relevant first-query/path distribution;
- a target-blind nonadaptive/exhaustive controller with the same resource
  ceiling remains below its registered ceiling;
- complete cited-cut masking changes the operation; and
- type-matched twin substitution redirects the action to the twin-valid action,
  rather than merely causing `NOT_FOUND`.

`LINK_AUTH - LINK_DERANGED` identifies authentic carried link structure.
`LINK_AUTH - BRIDGE_SUB` identifies necessary path use. `LINK_AUTH -
ATOMS_ONLY` alone supports only a bundled link-plus-resource effect.

After scoring, destroy the Phase-B process and restore exact `M_A` for Phase C.

## Phase C — memory-directed experiment

The Phase-C target is preconstructed from hidden truth and the sealed source
tape; it never depends on realized memory. Before any action, the child must
emit a typed declaration:

```text
GAP(old-memory citations)
HYPOTHESIS(h0)
HYPOTHESIS(h1)
PREDICT(experiment=e, outcome_if_h0=o0, outcome_if_h1=o1)
ACT(e)
```

The child—not a solver or harness—must choose the gap, both live hypotheses,
and legal experiment. An offline exact PCFL posterior scores the sealed output
but has no edge back into life. Success requires both selection of a registered
separating experiment and positive target-relevant information gain, not merely
entropy reduction elsewhere.

Assignments from the identical `M_A` boundary:

- `AUTH_SIGNAL`: authentic old-memory signal;
- `SHAM_SIGNAL`: same records, link degrees, queries, tokens, action menu, and
  budgets, with a predeclared type-matched irrelevant/twin signal replacing the
  decisive old-memory signal; and
- `REACHOUT_OFF`: old memory remains but the information action is unavailable;
  this is a total-path necessity control, not a controlled memory contrast.

The public outcome may support exactly one new relation only because the
pre-action typed declaration prospectively names the claim family and the
chosen action is the predeclared separating test. A claim first invented after
seeing the result cannot enter positive training data.

## Phase D — one new write and delayed use

Clone all D branches after one byte-identical `AUTH_SIGNAL` declaration, action,
and public outcome have sealed. The only allowed semantic difference is the
assigned post-outcome carrier:

| assignment | post-C operation |
|---|---|
| `EDGE_WRITE` | admit exactly the predeclared reusable one-edge relation |
| `NO_WRITE` | run the same call/replay/rebuild schedule but admit no semantic row |
| `SHAM_WRITE` | write a type/token/candidate/exposure/optimizer-matched irrelevant edge |
| `NEW_BIND_SWAP` | write the same envelope with a fixed-point-free twin binding |

The D writer may not train on the Phase-C goal, hypotheses, complete path,
selected final action, Phase-D bytes, or a policy continuation. Training rows,
touches, generated/labeled/attended tokens, steps, optimizer slots, rank,
rehearsal, fits, mounts, storage, and failure handling are frozen and reported.
Padding runs in a process with no semantic, RNG, cache, or audit handles.

Before D, start a fresh process from the same pre-C child state plus only the
assigned carrier. Phase-C goal/action/outcome text, raw ledger, workspace,
queries, candidate state, file descriptors, process cache, and timing/retry
state remain audit-visible but actor- and reader-inaccessible.

The presealed Phase-D goal uses fresh handles and has a mechanically unique
minimal proof requiring one pre-C old relation plus the new relation. Exhaustive
world audit must prove that the old relation alone, new relation alone, C action
alone, C outcome alone, goal/state identifiers, and all legal reacquisition
histories under the action cap remain below the oracle ceiling. Masking either
cut changes value; twin substitution redirects the correct action.

## Carrier assay

Run the complete semantic relay first in explicit text through the same frozen
one-hop READ interface. If this cannot solve the oracle-valid relay, the
benchmark/interface is invalid and no LoRA result is interpreted.

For the parametric carrier, mount LoRA only for the READ operation and use the
same clean frozen resolver for composition and action. Required diagnostics are
candidate-only clean base, unaided generative read, adapter off, wrong life,
twin/binding swap, and `TEXT_SAME_SEMANTICS`. This isolates memory transport
from a learned action policy. Physical carriers need not have equal storage or
compute; report the complete resource vector rather than claiming false parity.

## Root-level estimands

Average paired twin sides, targets, and prespecified technical seeds inside each
independent PCFL pair root before inference. All scores are bounded `[0,1]`.

```text
C_r = connected_value(LINK_AUTH, B)
      - connected_value(LINK_DERANGED, B)

T_r = traversal_value(LINK_AUTH, B)
      - traversal_value(BRIDGE_SUB, B)

Q_r = relevant_experiment_value(AUTH_SIGNAL, C)
      - relevant_experiment_value(SHAM_SIGNAL, C)

W0_r = delayed_value(EDGE_WRITE, D) - delayed_value(NO_WRITE, D)
W1_r = delayed_value(EDGE_WRITE, D) - delayed_value(SHAM_WRITE, D)

Fbind_r = delayed_value(EDGE_WRITE, D)
          - delayed_value(NEW_BIND_SWAP, D)
Freacq_r = delayed_value(EDGE_WRITE, D)
          - delayed_value(REACHOUT_OFF, D)
```

Use the fixed release sequence `C -> T -> Q -> W -> F`. Within `Q`, require
both separating-experiment selection and target-relevant information gain.
Within `W`, require both `W0` and `W1`. Within `F`, require both `Fbind` and
`Freacq`. These are intersection-union gates; no maximum or later endpoint may
rescue an earlier failure.

Before roots exist, freeze `N`, score functions, smallest effect margins,
one-sided or two-sided intervals/tests, familywise handling, missingness,
failure values, and any blinded nuisance-only extension. A provisional design
is `N=32`, root-level 95% Student-t lower endpoints above zero and mean effect
at least `.05` for each released contrast, subject to prospective power attack.
Calls, targets, twin sides, phases, and adapter seeds do not increase `N`.

The complete-chain rate uses all assigned roots as denominator and is
descriptive until a nontrivial `pi_min` and confidence rule are prospectively
powered. Never condition an effect estimate on successful gap detection,
experiment selection, admission, retrieval, or chain completion.

## Pre-execution kill gates

1. **Authority:** exact source hashes, fixed child-selection rule, permitted
   resources, and one-child conditional scope are ratified.
2. **Deletion:** parent, nursery prose/ledger/context, caches, handles, and
   routing state are absent; the child and retained state hash match.
3. **Generator validity:** presealed targets, twins, interventions, unique
   delayed dependence, direct-record closure, posterior scoring, and matched
   derangements pass exhaustive CPU audits.
4. **Controller falsification:** leaked oracle succeeds; no-life, exhaustive,
   goal-only, state-only, identifier-only, passive-signature, action-frequency,
   candidate-only, and hidden-reader controllers remain below ceilings.
5. **Phase isolation:** B is write-denied and discarded; C is restored from
   `M_A`; D branches after an identical outcome; no alternate C carrier reaches
   D; branch timing and rollback are exact.
6. **Resource/corpus equivalence:** authentic/deranged and write/sham envelopes
   satisfy frozen semantic and resource matching; prospective support is
   executable; no answer-bearing or policy row is admitted.
7. **Explicit-text oracle:** the complete relay works through the common
   interface before any parametric interpretation.
8. **Writer/read instrument:** strict typed routing, exact provenance,
   response-only masks, clean-base cumulative rebuild, mount/off, wrong-life,
   twin sensitivity, and transactional rollback pass.
9. **Disjoint development:** only fixed `PCFL-13` DEV roots may tune prompts or
   interfaces; every failure is retained; successful feasibility supplies no
   confirmation evidence.
10. **Statistics:** power, margins, `N`, fixed sequence, missingness, and
    nuisance-only extension are frozen on disjoint information.
11. **Independent review and GPU gate:** a rejection-capable fresh reviewer and
    separate author-side advocate dispose concerns; Rohin ratifies exact bytes
    and separately authorizes model/benchmark/GPU execution.

## Claim ladder

- `C` only: authentic linked records improved connected-path value.
- `C + T`: the fixed child used a goal-conditioned necessary path.
- `C + T + Q`: old experience changed which target-relevant experiment the
  child selected.
- `C + T + Q + W`: the resulting public relation was usefully written.
- `C + T + Q + W + F`: one fixed parent-deleted child completed an
  experience--action--new-experience--later-action relay.

Add “carried through per-life LoRA” only if the carrier diagnostics pass. Add
no compression claim: compression remains the separate rate--distortion assay
in E3. Add no classroom, population, autonomous-theory, general-intelligence,
or unrestricted baseline-superiority claim.
