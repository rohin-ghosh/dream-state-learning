# What to teach, and in what order — curriculum draft v1 (2026-09-10, Fable with Rohin)

Premise (Rohin): the learned agent is learning to compete with a SOTA agentic harness. Its base model is far less capable, so matching harness-level continual learning takes time and scale. We are therefore not inventing parenting; we are integrating what strong harness agents already do into a distributed parenting harness, and then augmenting what is taught. Parents are agentic-architecture intelligences (frozen weights, live judgment, shared ledgers). The learner's job is to absorb, through lived experience and sleep, the behaviours the harness already has.

## What existing harness agents already do (the "existing parenting" we integrate)
Planning and decomposition; explicit hypotheses before action; verification loops (check the result, not the feeling); reflection after failure (Reflexion-style); skill/lesson libraries reused across tasks (Voyager, ExpeL); self-critique and revision; backtracking when a path stalls; budget awareness (when to stop a line and start another); tool-use discipline; calibrated uncertainty statements; asking a targeted question vs acting; persistence on hard problems (exploit-gym style). Each is a trait a gym can instil and a parent can critique.

## Progression (each stage = a gym type + a trait + a measurable exit criterion; parent scaffolds then fades)
| stage | trait | gym shape | parent's role | exit criterion (pre-registered) |
|---|---|---|---|---|
| 0 Birth | the reflecting habit: plan → act → review as states; predictions with a reason and a range | bootstrap adapter from structure-heavy metacognitive flows (target-blind, provenance-verified) | none (pre-child) | unprompted plan/review text in ≥ 80% of episodes in the first 64, no parent present |
| 1 Persistence | keep working a hard problem; re-plan after failure; many attempts; never quit early | programs where the default recipe fails and only per-program search pays; delayed payoff; no end token | rewards continued, changing attempts; never rewards early stopping | turns/episode does not collapse (≥ 0.7 × base); attempts after a non-improving outcome ≥ 2 per episode; no brevity rejections for 4 cycles |
| 2 Prediction & calibration | predictions tied to named features; honest uncertainty; surprise treated as evidence | tasks with varied outcomes where the same action yields different results by context | asks "what feature made you expect that?"; withholds answers | prediction error falls across cycles; predictions vary with features (SD > threshold), not flat |
| 3 Exploration vs exploitation | one deliberate deviation per episode when the default has repeated; recognise when the default fails | mixed task families where the incumbent recipe is wrong on a known fraction | prescribes deviation experiments, not answers | strategy switches when stuck; first-ACT distribution moves between cycles (JS ≥ 0.15) without score loss |
| 4 Contrast & generalisation (anti-lock-in) | notes with scope; compare this case to a named earlier one; different recipes for different families | families of programs needing different actions; disjoint evaluation panel | critiques scope errors; asks for the contrast | per-family action choice (≥ 2 distinct recipes used appropriately); disjoint-panel Δ ≥ 0 across K seeds |
| 5 Metacognition (recurrent CoT) | judge own thinking: enough? efficient? asking vs doing; return to and revise earlier reasoning | long episodes with checkpoints where re-planning is required; review-shaped states | asks the meta-questions; scores review quality with a rubric | efficiency (chunks-to-best) improves over cycles; review quality rubric rises; efficiency and markers move together (markers up but efficiency flat = performing reflection, fail) |
| 6 Goal-setting in white space | choose subgoals; decide when to start and end a state; propose own experiments | open-ended sessions with no assigned task between tasks | evaluates proposed experiments by their later payoff | self-proposed experiments that improve later scores; fewer idle loops |
| 7 Learning to learn | decide what deserves consolidation; rehearse lessons so they become own thought; know when a write helped | the child sees its own probe results and gate decisions | asks what should become plastic and why | write transfer: disjoint-panel Δ rises across cycles; fewer rejected writes; the child's stated consolidation choices predict gate outcomes |

Rules across stages: repetition is the mechanism (parent repeats the same lesson; child rehearses it; fading is stage-wise, not per-episode); parent never gives answers (leak scan, target-blindness); thinker/compiler line holds (lessons enter the corpus only as the child's own thoughts); every stage is judged by an evaluator classroom on gyms the parent never used; advancement requires the exit criterion, otherwise the stage repeats with a changed gym; first and second derivatives vs baselines (adapter-OFF, text-memory agent, regular harness agent) at every stage.

## Where our data already speaks to this
- Stage 1 is the measured failure: late-life collapse to 1–2 turns/program (4/9 ungated lives) and the brevity-gate catches. Persistence is the first trait for a reason.
- Stage 4 is the measured ceiling: recipe lock-in (0.4878 = birth recipe) and no per-program choice; the disjoint panel is its exam.
- Stage 5's fail case is already observed: rehearsal echo rose while efficiency fell (SEQ-003, SEQ-005) — performing reflection rather than using it.
- Stage 0 is what the bootstrap corpora attempt; they are unverified in provenance and unmeasured.

## What scaling changes
More children, more notes and more agent thoughts per child mean the parents need more intelligence, not more corpus: an agent harness with tools over the children's records and a shared parental ledger, so judgment compounds across students without training the parent. Recursion (children becoming parents) is future work.
