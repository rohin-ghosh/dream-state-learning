# Semantic World v0 — frozen implementation contract

Status: implementation contract for branch `semantic-world-v0`.
This document supersedes the open design choices in `SPEC_V2.md` Part IV
for v0 only.  It does not change the G-series memory mechanism.

## 1. Scientific object

The pretrained model is the base image.  A lifetime is a world-specific
container layer.  The memory system should retain compact, verified
residual structure over concepts the base model already understands.

The v0 question is deliberately narrower than learned future-seeking:

> Given a distributed lifetime generated by a small hierarchy of latent
> rules, can an oracle or learned dream representation cross a bounded
> read/write interface and support held-out predictions at increasing
> abstraction depth?

The dream/think policy is not learned in v0.  V0 builds the instrument and
the oracle ceiling required to train that policy later.

## 2. Hidden world

Every seed creates one latent world independent of its textual skin.

- Each animal has a role `r(a) in {0,1,2}`.
- Each ordinary land has a palette `p(l)` (primary or secondary) and a
  rotation `s(l) in {0,1,2}`.
- Its color is `p(l)[(r(a) + s(l)) mod 3]`.
- Primary colors are red/yellow/blue.  Secondary colors are
  orange/green/purple.
- Colors have a paint-pigment representation.  Blending is associative,
  commutative pigment union; red+yellow=orange, yellow+blue=green,
  red+blue=purple, and all three pigments=brown.
- One meta-land uses the blend operator over a hidden three-land subset of
  ordinary lands.  Its parent set is selected so its role-to-color signature is
  uniquely identifiable among same-sized candidate subsets.

The ordinary-land transformations, animal roles, and meta parent set are
randomized per seed.  Surface names never determine them.

Exceptions are intentionally disabled in v0.  They are a later stratum;
adding them before factor transport works would confound induction with
invalidation.

## 3. Evidence construction

Three anchor animals (one per role) are observed across every ordinary
land.  Their observations identify land transformations and connect the
primary and secondary palette systems.

Every evaluation animal is observed in two ordinary lands from only one
palette family.  Consequently:

- another cell in that palette supports a local projection;
- a cell in the other palette requires cross-palette role transfer;
- its meta-land cell requires the meta rule plus several source values.

The meta-land is observed for the three anchors, one per role.  All
non-anchor meta cells are held out.

Evidence is temporally dispersed.  Anchor/calibration evidence and meta
examples occur before a buffer longer than the declared context budget;
sparse evaluation-animal evidence occurs after it.  A full lifetime is
identifiable, while no recent context contains both halves of a D2/D3
proof.  A best-contiguous-window baseline audits this construction rather
than assuming it.

After passive dreaming, an optional **reachout** session permits a small,
declared number of additional visits.  Each visit becomes a provenance-bearing
observation and is counted as new experience.  Exact evaluation cells are
blocked by default, so reachout can close a structural evidence gap but cannot
buy the answer key.  This encodes the G4j→G4k result: second-order merging did
not fire without inter-cluster evidence; one deliberate world experiment made
the missing rule witnessable and restored the merge.

## 4. Goal strata

- **D0 — situated lookup:** the exact animal/land cell was witnessed.
- **D1 — local projection:** the cell is held out; the animal was witnessed
  in the same palette family and a local rectangle supports transfer.
- **D2 — cross-palette composition:** the cell is held out and the animal
  was witnessed only in the opposite palette family.  The solver must
  preserve its role across two surface color systems.
- **D3 — meta-rule composition:** the meta cell is held out.  The solver
  must infer/read the parent-set blend rule, derive the animal's parent
  colors, and combine them.

Every non-D0 goal excludes the exact queried cell from the lifetime.
Depth is stored with a canonical dependency DAG, not inferred from a
coarse tier signature.  The default split contains 12 goals at every depth.
D0-D2 contain exactly two examples of every source color; D3 contains four
examples of every meta outcome.  Majority floors are emitted per depth.

## 5. Skins

All skins are isomorphic renderings of the same latent world and splits.

1. `aligned`: real animals, lands, and conventional color words;
   the meta-land is called Blendyland.
2. `neutral`: nonce entities, zones, and state tokens; no color/animal
   ontology is exposed.
3. `conflicting`: real ontology, but surface color words are a fixed
   derangement of latent pigments and the meta-land name is misleading.

The aligned-vs-neutral comparison measures prior scaffolding.  The
conflicting skin measures prior interference.  Results must never be
pooled across skins without reporting per-skin values.

## 6. Stable integration interface

The implementation exposes:

```python
world = SemanticWorld(WorldConfig(seed=0))
world.sample_lifetime()
world.eval_goals(depth=None)
world.oracle_structure(skin="aligned")
world.render(skin="aligned")
world.start_reachout(skin="aligned")
world.proof_for(goal)
world.verify_claim(claim, evidence_ids, ...)
```

`render()` returns model-facing text only.  Internal IDs and answers stay
in evaluator-owned artifacts.  The reachout interface accepts surface names,
enforces its action budget, and returns rendered observations with fresh IDs.

Every rendered observation begins with its observation and episode IDs.
`atomic_memories_for(goal, skin)` converts a proof into positive, one-hop QA
leaves.  `context_oracle(goal, skin)` appends the same goal to those resolved
or unresolved reads, providing the context ceiling hook used before any LoRA
run.

## 7. Verification entitlement

Claim verification distinguishes:

- `witnessed`: an exact cited observation supports the claim;
- `entailed`: the claim follows from cited lived evidence under the
  public world grammar;
- `counterfactual`: the engine was queried beyond lived evidence.

Counterfactual verification consumes an explicit budget.  An unparsed or
unsupported claim is not accepted.  This prevents rejection sampling
against the hidden engine from masquerading as consolidation.

The only accepted emitted surface forms are:

```text
CELL | animal=<animal> | land=<land> | color=<color>
ANIMAL_EQUIV | left=<animal> | right=<animal>
LAND_RELATION | left=<land> | right=<land> | left_palette=<PRIMARY|SECONDARY> | right_palette=<PRIMARY|SECONDARY> | rotation_delta=<0|1|2>
META_RULE | land=<meta-land> | operator=PIGMENT_UNION | parents=<land>,<land>,<land>
```

Relations are emitted in canonical internal order.  Scratch prose may be
free-form; only full-line grammar matches enter verification.  Duplicate
lines are collapsed and negated/unparsed variants are rejected.

## 8. Baseline ladder

V0 ships five deterministic baselines:

1. exact observed lookup;
2. bounded recent-context factor solver;
3. best contiguous window of the same observation budget;
4. full-lifetime factor solver;
5. oracle-structure solver.

The oracle solver must reach 1.0 on D0-D3.  The full-lifetime solver must
recover all non-exception structure.  Bounded context is expected to
retain D0/D1 ability while failing or abstaining on dispersed D2/D3
evidence.  These are instrument checks, not language-model results.

## 9. Later model experiment

Once this CPU instrument passes:

1. full lifetime in context;
2. oracle atomic proof leaves in context;
3. oracle atomic memories in a read-only lifetime LoRA;
4. verified model dreams in the lifetime LoRA;
5. coverage-driven re-dreaming and second-order inference;
6. priced reachout to close still-unwitnessed structural gaps.

The primary model contrast is D2/D3 improvement beyond D0 lookup,
reported separately for aligned, neutral, and conflicting skins.

The measured nonce-L0 recipe is encoded by `lands/corpus.py`: one-hop
atomic QA, eight duplicates x 25 epochs (~200 touches/fact), with rule lines
receiving 3x exposure.  Training remains in Fable's existing subprocess
pipeline; the lifetime adapter is used for reads only and the clean base
composes.

The complete measured GPU-loop constraints are recorded in
`research_notes/33_semantic_world_gpu_constraints.md` on the live main
branch.  Those constraints are treated as executable interface requirements,
not optional implementation advice.

## 10. Non-negotiable acceptance tests

- Same seed produces byte-stable latent data and goals.
- Different seeds change roles, land transformations, or meta parents.
- All three skins preserve internal answers and proof shapes.
- Public surface artifacts contain no latent IDs, numeric roles, shifts,
  evaluation answers, depth/tags, phase labels, oracle material, or proof
  metadata.
- D1-D3 exact cells never occur in the lifetime.
- D0 exact cells do occur.
- Meta parents are uniquely identifiable from the full evidence.
- Canonical proof shapes separate D0-D3.
- Counterfactual verification consumes and respects its budget.
- Reachout actions are priced, provenance-bearing, and blocked on exact
  evaluation targets by default.
- Exported artifacts contain schema version, configuration, world
  fingerprint, file hashes, split counts, and source commit when known.
