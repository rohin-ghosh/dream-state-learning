# 53 — One-parent post-confirmation PCFL relay v0

Date: 2026-09-07

Status: unbound, proposal-only benchmark design. It authorizes no frozen-source
change, implementation, task generation, model/tokenizer call, adapter work,
external execution, GPU use, or claim. It must receive a separate source-bound
workflow, independent attacks, exact human ratification, model-free fixtures,
and pre-GPU review before execution.

## Purpose

The one-parent CompilerGym experiment can establish whether a target-blind
developmental intervention increases the later benefit of personal writes. It
cannot establish the larger Dream--LoRA--Think mechanism: connected
experiential knowledge, goal-conditioned traversal, memory-directed evidence
acquisition, and a later action that benefits after the new outcome is written.

This relay reuses the existing Persistent Causal Field Lab (`PCFL`) rather than
inventing another gym. It begins only after the parenting result is immutable
and uses within-root clones of the exact same terminal parented child. The
parent never returns. There is no classroom, second child, peer, teacher
ensemble, shared store, or population-learning edge.

## Question

> Can one child use authentic relations learned from its own public actions to
> traverse a necessary path under a fresh goal, choose an information-seeking
> action that reveals a missing relation, consolidate that new outcome, and
> then solve a still-later disjoint goal that requires both old and new
> experience?

The claim concerns functional use and expansion of experiential code. It does
not claim that a literal graph exists inside LoRA weights.

## Reused PCFL substrate

Use the exact causal ontology and typed actions already specified in notes
46--48:

```text
stable preparation -> trait transformations
stable site-family -> acceptance predicates
stable route-family -> traversal requirements

SURVEY | ASSAY | PREPARE | TRAVERSE | INTERVENE | COMMIT
```

Fresh handles and randomized bindings make pretrained semantics non-decisive.
Counterfactual twins preserve visible descriptions and relevant marginals
while changing decisive preparation/site/route bindings. The public engine
returns only ordinary observations, costs, and outcomes—never rules, proofs,
memory labels, or target answers.

Use `PCFL-13` only as the development kill fixture. Confirmation uses
`PCFL-Stream`, where each cohort contributes thirteen genuinely new mappings
and later goals naturally compose old and new cohorts. This prevents repeated
exposure to a 16.7-bit toy backbone from masquerading as development.

## One immutable root and four sealed phases

One independent root samples a PCFL/twin pair, source schedule, goals, action
opportunities, decoding counters, and all within-root intervention assignments
before any scientific output. All branches clone the same child checkpoint,
active-text snapshot, and LoRA bytes at each intervention boundary.

### Phase A — own-action acquisition

The child encounters fresh source situations and chooses legal public actions.
These reveal only atomic preparation, site, and route relations. DREAM may
propose target-independent atoms/edges with exact public-event citations;
SLEEP admits only chronologically supported claims and writes runtime-matched
READ/DECIDE rows.

No source record may contain a held-out handle, complete plan, terminal action,
or more than one declared ontology edge. The held-out goals and their decisive
bindings are sealed before Phase A and unavailable to the child, writer, and
retriever.

### Phase B — fresh-goal traversal

A new A2/A3 goal requires at least two authentic relations acquired in
different source blocks, with one old and one recent relation. The agent has a
bounded public workspace and one-hop query interface. It must expose a typed
dependency path—query, follow/update, optional backtrack, then world action.

Credit requires both successful action and a mechanically valid dependency
DAG whose later query uses a value returned by an earlier read. A lucky action
without the necessary path is task success but not traversal success.

### Phase C — missing-edge experiment

A fresh goal is constructed so the current accepted relations leave exactly
one decisive mapping unresolved. At least two live hypotheses imply different
legal experiments. The target answer remains unavailable.

Before acting, the child must publish:

```text
gap identity -> two live hypotheses -> predicted discriminating outcomes
             -> selected legal information action
```

The action's information gain is computed by the exact finite PCFL posterior
over the public history; the posterior is offline scoring only and has no edge
back into life. The public world then returns the previously unavailable
outcome.

### Phase D — later write and delayed use

After Phase C, one ordinary DREAM/SLEEP opportunity may admit the new outcome.
A still-later goal uses fresh handles and cannot be solved from the Phase C
action or outcome alone. It requires at least one pre-Phase-C relation plus the
newly learned relation. Phase D starts in a fresh process with evaluation
workspaces and caches cleared.

The complete relay is credited only if the child selected the relevant
experiment, obtained a valid new outcome, admitted the correct relation, later
retrieved/used it, and improved the sealed Phase D action.

## Within-root causal branches

All branches receive identical ordinary model-call, generated-token, read,
action, context, and clock budgets. The exact intervention roster is frozen
before roots exist.

| branch | intervention | identifies |
|---|---|---|
| `AUTH_WRITE` | authentic connected memory; Phase-C outcome eligible for later write | complete relay |
| `AUTH_NO_WRITE` | same authentic memory and Phase-C action/outcome; later write disabled | causal value of consolidating the new relation |
| `BRIDGE_CUT` | remove only the necessary old relation while preserving other records/budgets | necessary path contribution |
| `BINDING_DERANGED` | degree/type/token/marginal-matched relation endpoints or action--outcome tuples are deranged | authentic binding rather than generic memory mass |
| `SHAM_GAP` | preserve action opportunity but replace the target-relevant memory signal with a matched irrelevant signal | memory-directed experiment choice |
| `REACHOUT_OFF` | preserve old memory but deny the discriminating experiment | new evidence is necessary |
| `ADAPTER_OFF_FIXED_STORE` | identical explicit snapshot/history, life-LoRA unmounted | parametric-state contribution under fixed visible history |
| `WRONG_LIFE` | matched-capacity adapter from the twin/other root | life-specific binding |
| `TEXT_SAME_SEMANTICS` | identical admitted semantic records via the same one-hop interface, no LoRA | text-versus-LoRA transport, not compiler quality |
| `ATOMS_ONLY` | witnessed atoms without admitted use links/shortcuts | contribution of connected use structure |

The explicit semantic snapshot is the epistemic authority and audit object.
For the parametric-read condition, actor-visible answer-bearing explicit text
must be absent; a target-blind fixed candidate roster and one-hop recognition
call may expose a LoRA-selected local value. Candidate construction and any
audit lookup are charged and cannot be credited as model intelligence.

## Fixed estimands and gated interpretation

For root `r`, define:

```text
T_r = traversal_value(AUTH_WRITE, Phase B)
      - traversal_value(BRIDGE_CUT, Phase B)

Q_r = relevant_information_gain(AUTH_WRITE, Phase C)
      - relevant_information_gain(SHAM_GAP, Phase C)

W_r = delayed_value(AUTH_WRITE, Phase D)
      - delayed_value(AUTH_NO_WRITE, Phase D)

F_r = delayed_value(AUTH_WRITE, Phase D)
      - max(delayed_value(BINDING_DERANGED),
            delayed_value(REACHOUT_OFF))
```

The full flywheel sentence requires positive registered evidence for `T`,
`Q`, `W`, and `F` in that order plus a nonzero complete-mediator rate. A later
rung cannot rescue an earlier failure. Adapter-off/wrong-life and
same-semantics text comparisons are separately gated carrier diagnostics; they
do not replace the authentic relay.

Report the mediator chain by arm/root:

```text
necessary old path present
-> correct gap exposed
-> discriminating experiment selected
-> valid new outcome observed
-> supported record admitted
-> record returned/used later
-> final public value
```

No post-treatment filtering, replacement of failed roots, permissive reparsing,
or probe-derived writer repair is allowed.

## Kill gates before scientific GPU spend

1. CPU generator audits prove identifiability, twin visible-byte equality up
   to the first decisive action, direct-record closure zero, unique delayed
   dependence, exact posterior scoring, and feasible derangements.
2. Oracle atomic memory plus the frozen recurrent interface reaches the fixed
   A2/A3 and relay ceilings; atoms-only/nonadaptive and every cut intervention
   show required headroom.
3. Native writer E0 gates pass: typed routing/proposal preservation, exact
   provenance, response-only loss masks, reproducible clean-base rebuild,
   adapter-off/wrong-life sensitivity, and transactional rollback.
4. A small development root must show nonzero complete relays without target
   leakage and with all control branches executable. Failure revises the
   benchmark before any confirmation root exists.
5. Root count, effect margins, multiplicity, resource envelope, and nuisance-
   only blinded extension rule receive a separate prospective power review.

## Compression is a separate paired assay

Neither LoRA, linked memory, nor the relay itself proves compression. A
rate--distortion extension must compare compact connected records with a
deterministic denotationally equivalent expanded carrier while accounting for
all acting-state bytes: adapter, retained text, grammar/codebook, prompt,
index, and per-query scan state. The immutable raw ledger may remain for audit
but cannot be silently counted as free acting memory.

Compression language is allowed only if useful delayed/traversal value is
retained at a shorter total code or sublinear retained growth across at least
three post-native PCFL-Stream checkpoints. Otherwise the result is connected
transport and use, not compression.

## Relation to the parenting experiment

The parenting factorial estimates whether one developmental intervention
improves later learning. This relay estimates what the resulting single child
can carry, traverse, and expand. It introduces no new parent comparison and is
never pooled into `D`.

If the parenting result passes, terminal `P1` clones make the relay a mechanism
study of the same raised child. If parenting fails, the relay may still run as
a separately framed Dream--LoRA--Think mechanism experiment from a fixed
writer-qualified checkpoint, but it cannot rescue or reinterpret the failed
parenting result.
