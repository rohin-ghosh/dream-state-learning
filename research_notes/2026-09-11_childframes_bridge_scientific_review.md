# Child-frame bridge: pre-launch scientific review

Date: 2026-09-11

Status: read-only review of the uncommitted child-frame branch. No model,
training, adapter, or GPU execution was performed. The branch must not launch
before the multi-key writer gateway establishes selective conditional policy
carriage.

## Verdict

The current bridge cannot identify child-authored perception or reflection.
The compiler supplies the answer:

- `CHILD_PROMPT` includes the verified colour and, in two variants, the exact
  canonical target;
- `render_child_frame` returns the harness-built canonical target and appends
  it when the child omits, garbles, or fails to return one;
- the abstention variant is repaired in the same way.

Consequently, an empty or incompetent child can still produce perfectly
labelled training rows. This is not held-out leakage, but it breaks the
THINK/compiler boundary and destroys causal attribution. A positive result
would show only that base-model prefix prose changes a researcher-labelled
completion implant relative to cell F. It would not show that the child
perceived, extracted, judged, or compiled its own experience.

## Other launch blockers

1. Generation reuse validates only variant, rendering count, and negative
   count. It does not bind the bank/event/colour bytes, model revision,
   prompt/template, temperature, or top-p. Stale child prose can therefore be
   paired with a new harness answer.
2. The generation hash excludes negative rows, raw outputs, prompts, and model
   identity.
3. The report calls the result a perception skill and an equal-exposure
   comparison without requiring matched supervised-token budget, optimizer
   steps, seeds, or bank set. The configured corpus caps also differ between
   defaults and the node example.
4. The runbook's rank-capacity probe is fixed at rank 8 even for a requested
   rank-32 run; its cache is not keyed by configuration or corpus; an
   over-budget corpus fails open.
5. The prompt invites unsupported visible details, while the mock child is
   rewarded for hallucinated dents or roof racks and the current novelty
   diagnostic can count those as quality.

The existing five CPU tests pass because some encode answer appending as the
expected behaviour. They are software regression tests, not scientific
clearance.

## Minimum repair criteria for any later successor

- Empty, wrong, or missing child output must never become a correct target.
- A child-authored arm must not receive the canonical answer in its prompt.
- Any bank, model, prompt, template, or sampling mismatch must invalidate
  cached generations.
- Provenance must cover positive and negative rows, prompts, raw outputs, and
  model identity.
- Comparisons must match training dose, seeds, banks, and evaluation surfaces.
- The capacity probe must use the requested rank; over-budget corpora must
  fail closed.
- Unsupported details must be rejected or explicitly measured.

Even after repair, this bridge would be a narrow self-generated
paraphrase/prefix-style ablation. It would not establish conditional routing,
thought/action carriage, connected memory, or parenting benefit. The ordered
path remains: multi-key writer gateway, one unrelated-write survival test,
then an authentic-parent versus matched-sham parenting experiment.
