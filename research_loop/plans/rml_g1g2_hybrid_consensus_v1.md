# RML G1/G2 hybrid consensus candidate v1

**Status:** exact science-design candidate for later architecture intake and
human ratification. It authorizes no implementation, model/network/GPU call,
locked-data access, external action, or scientific claim.

**Selected interpretation:** B's executed target-blind collector and G1/G2
content factorial; A's staged DEV economy, explicit X boundary, binding
falsifiers, and locked confirmation; 16 rather than eight confirmation pairs.

## 1. Claim and stage boundary

G1 tests whether one frozen model can use bounded local gold semantics through
generic recurrent reads. G2 tests whether authentic executed wake traces plus
target-blind cross-episode proposals and deterministic chronological admission
produce useful explicit text memory under a fixed common experience deck.

Maximum claim after locked confirmation:

> In one rendered fluid/thermal pack at one frozen checkpoint, authentic
> executed wake traces and target-blind cross-episode proposals, followed by
> deterministic evidence admission and text compilation, produced local
> memory that a frozen recurrent resolver used causally for later connected and
> prospective action; the full condition exceeded its compiler, replay,
> trace-shuffle, no-write, and binding controls and was noninferior to every
> declared primary native memory baseline within the registered margin.

Add “revision” only if a separate X sidecar passes. Add “post-native” only if
the cut gate in section 4 passes. Never infer a lifetime curve, continued
improvement, saturation, LoRA/weights, compression, multi-pack generality,
on-policy acquisition, or a flywheel from G1/G2.

No stage releases the next. Required authority nodes are:

```text
green reviewed D0
-> R1 CPU model-facing pack/visibility/preflight
-> R2 fast G1/G2 DEV
-> R3 six-pair descriptive calibration
-> R4 sixteen-pair locked confirmation
```

Each arrow requires a new predecessor-bound human decision.

## 2. Frozen collector and chronology

One collector is run once per world-side, before G2 arm assignment. It uses the
same frozen resolver later used in shared THINK/DREAM conditions.

- A CPU-generated target-blind mission schedule and all held-out target bytes
  are sealed before collection; targets are inaccessible to cognition.
- Each life has at most 64 predeclared wake branch points, stratified 16 per
  causal-era quartile. At a branch the model sees only the local public mission,
  current public state/history, bounded workspace, and current deterministic
  witnessed-atom (`C0`) snapshot.
- The model emits local queries/updates/backtracks and at most one action. A
  released legal action executes and its ordinary outcome enters the public
  life. `DEFER`, `STOP`, malformed, illegal, or budget-exhausted output consumes
  the branch and produces no substituted scripted action.
- Background target-blind public source episodes may run between branch points
  under the frozen CPU schedule. They are ordinary experience but are not
  credited as collector-chosen actions.
- After wake traces and DREAM predictions seal, exactly 32 predeclared,
  candidate-independent confirmation actions execute. A proposal that these
  actions do not test remains provisional; no action is selected to support a
  proposal.
- The resulting public event bytes and authentic wake traces freeze once and
  are replayed identically to every G2 arm. G2 does not vary memory during
  collection and therefore is not G5.

Wake traces are append-only selection signals. They can select eligible public
roots, grouping, retrieval shortcuts, or touches. They cannot support a fact,
increase root count, repair a prediction, or enter an action as evidence.

## 3. Visibility contract

| Process | May see | Must not see | May write |
|---|---|---|---|
| wake collector | current mission/state, past public events, `C0`, own bounded workspace/read | held-out targets, future outcomes, arm/trace assignment, hidden program/proof/twin/scorer | typed operations, public action, sealed traversal record |
| DREAM | assigned target-blind replay bundle, eligible prior supported atoms, assigned selection-only trace | held-out goal/target, future confirmation outcome, hidden truth/program/proof, scorer/admission result, authentic-vs-shuffled label | one scoped proposal and executable prediction/sample |
| admission | committed proposal, cited public roots/parents, later ordinary confirmation outcome, frozen public rules | held-out targets and downstream scores; hidden truth as a decision input | append-only support/contradiction/rejection event |
| compiler | eligible supported semantics/status, retrieval-only trace signals, frozen view rules | targets/evaluation, hidden truth/program, unsupported hypotheses, critic-only approval | deterministic text snapshot and resource manifest |
| common reader | snapshot, generic anchor, already-returned candidate IDs | goal/state, desired value/relation, hidden family, candidates/ranks/topology/timing channel | one atom or `NOT_FOUND` |
| evaluation resolver | current goal/state, bounded workspace, one-atom reads, own public outcomes/budgets | source stores, target manifest, proof/scorer, other cells/lives, evaluation history | typed operations and one public action at a time in disposable clone |
| offline audit/scorer | all sealed public/hidden/proof/assignment records | n/a | audit/score only; no source, corpus, reader, or evaluation write |

All public model-visible handles must have a recorded origin in current goal,
state, public outcome, replay event, or prior local read. Evaluation outcomes
are discarded and pre/post source/status/corpus hashes must be identical.

## 4. Cuts, targets, splits, and model

The exact resolver/DREAM model is `Qwen/Qwen2.5-32B-Instruct` revision
`5ede1c97bbab6ce5cda5812749b4c0bdf79b18dd`. Tokenizer revision is identical.
Prompts, schemas, chat template, decoding bytes, attention mask, and output
reserves remain future hash-bound files; no call is legal before they exist and
are ratified.

`L_native` is maximum input tokens minus exact system prompt, public goal/state,
workspace, operation history, maximum reader return, and output reserve. Events
crossing a cut belong to the later cut.

- DEV uses the first CPU-valid complete causal cut after collection and does
  not require or claim native-context overflow.
- Calibration/confirmation uses `C*`, the first complete causal-unit boundary
  at or above `2*L_native`. Between the last within-native boundary and `C*`,
  unique public roots and locally identifiable relations must at least double,
  with at least one old/new interaction and one prospectively committed
  prediction per era. Repetition, views, touches, and padding do not count.
- If `C*` does not exist within the frozen resource envelope, R3/R4 do not run;
  a non-post-native confirmation requires a newly ratified claim/scope.

Primary strata are J and P. J requires an old/recent state-flow join; P has one
unwitnessed edge determined only by a prospectively supported schema. X is
absent unless separately ratified with gold `>=.85`, no-life/shortcut `<=.35`,
disambiguating-evidence necessity, analogous target sealed before the exception,
and full leakage/isolation checks.

Splits and targets per twin:

| Stage | Pairs | J/P targets | X targets | Inferential use |
|---|---:|---:|---:|---|
| DEV | 4 | 4 each | 4 if authorized | debugging/spending gate only |
| calibration | 6 new | 4 each | 4 if authorized | descriptive freeze/feasibility only |
| confirmation | 16 new | 8 each | 8 if authorized | independent locked inference |

Pair is the replication unit. Twins, targets, branches, calls, samples, and
seeds are nested. No world, target, trace, call, or seed is replaced after its
first scientific dispatch.

## 5. Operation and call budgets

One model call emits exactly one typed operation. J/P item caps are 10 public
actions, 32 resolver operations, six memory queries, one atom/read, 256 visible
tokens/read, and 1,536 total read tokens. Optional X caps are 12 actions, 40
operations, eight queries, and 2,048 read tokens. One action operation executes
one environment action. This repairs the infeasible 12-total-operation proposal,
which could not contain a nine-action plan plus reads/updates.

Collector branch cap is eight resolver operations, four queries, and one public
action; maximum 256 new tokens/operation. Thus for `P` pairs (`L=2P` lives):

```text
collector resolver calls <= L * 64 * 8
collector read calls     <= L * 64 * 4
```

Each DREAM-bearing cell receives at most eight replay bundles/life/checkpoint
and exactly four preallocated samples/bundle, maximum 384 new tokens/sample,
temperature `.7`, top-p `.9`, with frozen independent seeds:

```text
DREAM calls per cell = L * 8 * 4 = 32L
```

For `S` retained strata and `T` targets/stratum/twin:

```text
evaluation items/cell            = L * S * T
J/P resolver calls/cell          <= L * S * T * 32
J/P read calls/cell              <= L * S * T * 6
optional X resolver calls/cell   <= L * T * 40
optional X read calls/cell       <= L * T * 8
```

Malformed/truncated/multi-operation output consumes its slot; no repair,
reprompt, retry, fallback model, or extra budget is legal. Actual calls/tokens,
candidate work, failures, FLOPs, wall time, energy, and storage are reported.
R1 must bind absolute CPU/GPU/wall/storage ceilings and prove the maximum cell
roster fits before R2 can be requested.

## 6. G1 cells and gates

Gold records contain one local relation each, the supported P schema, and the
optional scoped X exception—never a target, plan, complete parent set,
terminal action, or proof path.

DEV cells:

| Cell | Content | Policy | Strata |
|---|---|---|---|
| `G1_NONE_REC` | none | recurrent generic anchors | all |
| `G1_C_OPEN` | connected gold | all anchors committed before reads | all |
| `G1_C_REC` | connected gold | recurrent generic anchors | all |
| `G1_A_REC` | witnessed atoms only | recurrent generic anchors | P; other strata optional |

Calibration/confirmation adds `G1_A_OPEN` and `G1_C_TWIN_REC`, completing the
atoms/connected x open/recurrent factorial plus no-memory/twin controls.
Typed queries are DEV-only labeled ceilings.

G1 go requires, separately for every retained stratum:

- legitimate direct-record closure `=0`;
- `G1_NONE_REC <=.35`;
- `G1_C_REC >=.85`;
- mechanically certified constructive cited-path rate `>=.80`;
- `G1_C_OPEN <=.45`, and `<=.35` overall;
- `G1_A_REC <=.35` on P;
- complete-cut masking and matched twin substitution pass on `>=.80` of
  credited C_REC successes;
- unsupported decisive release on missing-edge/conflict fixtures `=0`;
- no visibility, parser, reset, backend-channel, direct-answer, or evaluation-
  isolation failure.

Any failure blocks G2. A typed-only pass establishes a scaffold, not generic
reconstruction.

## 7. G2 cells

Core confirmation matrix:

| ID | Trace | Offline formation | Durable resolver-created write | Resolver |
|---|---|---|---|---|
| `C0` | none | compiler only | no | deterministic |
| `WA` | authentic | wake-local only | yes | shared |
| `WS` | matched shuffled | wake-local only | yes | shared |
| `RP` | authentic | replay/restatement only | yes | shared |
| `F` | authentic | cross-episode proposal | yes | shared |
| `TS` | matched shuffled | cross-episode proposal | yes | shared |
| `NW` | authentic | cross-episode proposal | no | shared |
| `SP` | authentic | cross-episode proposal | yes | specialized DREAM |
| `SL` | authentic trace on action/outcome-shuffled life | cross-episode | yes | shared |
| `SB` | F corpus with postcompile binding derangement | frozen | yes | shared evaluation |
| `TT` | F text snapshot assigned to counterfactual twin | frozen | yes | shared evaluation |

`SG` (shuffled episode grouping) is a DEV attack and enters confirmation only
if grouping is model-visible or changes F by `>=.05` on DEV. Forged/nonreplayable
statistics must be rejected by CPU schema validation and are not a primary
model cell. `SP` is required only if the claim retains shared-resolver
adequacy; otherwise delete both cell and clause before calibration.

DEV is fail-fast, in frozen order:

```text
C0,F
-> if value screen passes: TS,RP,NW,SB,SL
-> if corresponding margins pass: WA,WS,SP
```

Skipped cells are recorded `NOT_RELEASED_BY_PREDECESSOR`, not zero. Calibration
and confirmation run every cell required by the surviving claim.

Trace shuffle is a frozen within-type bijection preserving operation/query/
read-result/found-miss/path/backtrack/terminal distributions, event-age,
relation/root-count bins, bundle sizes, tokens, calls, and valid recipient-life
handle types while breaking trace-to-lived-root binding. `SL`, `SB`, and `TT`
are distinct falsifiers and cannot substitute for one another.

G2 has no semantic-capacity truncation: the compiler cap equals the exact
maximum eligible supported atom count under the frozen generator. Views add no
support. Capacity/compression belongs to later stages.

## 8. Baselines

DEV always runs no memory, actual native context, hybrid raw episodic RAG,
exact witnessed graph, and explicit generator-aware program induction.
Calibration adds native A-MEM, hierarchical reflection, and procedural skill
memory. Confirmation always runs:

- no memory and connected gold;
- actual native context;
- hybrid raw episodic RAG;
- native A-MEM;
- exact witnessed graph with native planner;
- explicit generator-aware program induction;
- whichever reflection/procedural arm has the higher calibration mean.

Native interfaces are primary; common one-atom versions are diagnostics.
Graph/program outputs never enter model prompts, traces, compiler input, or
reader responses. The paper cannot call a calibration winner “the strongest”
unless every declared primary baseline passes the confirmation comparison.

## 9. G2 gates and inference

Let pair-level equal-stratum scores define:

```text
g_gold  = mean(G1_C_REC - G1_NONE_REC)
g_full  = mean(F - G1_NONE_REC)
d_trace = mean(F - TS)
d_comp  = mean(F - C0)
d_dream = mean(F - RP)
d_write = mean(F - NW)
d_bind  = mean(F - SB)
d_share = mean(F - SP)
```

DEV/calibration spending gates, separately on each retained stratum where
stated:

- zero target/future/hidden/scorer/critic-only/trace-as-evidence/compiler-
  invention/taint/provenance violation;
- accepted-edge precision `=1.0`, false-memory use `=0`, unsupported missing-
  edge release `=0`, text-read fidelity `>=.90`, and causal cut/twin rate
  `>=.80`;
- `g_full/g_gold >=.70`, with `g_gold>0`, in every stratum;
- F no more than `.10` below every primary baseline in every stratum;
- `d_trace >= max(.15,.5*g_full)`;
- `d_comp >=.10`, `d_dream >=.10`, and `d_write >=.10`;
- `d_bind >= max(.15,.5*g_full)`, with F-SL and F-TT positive;
- `d_share >=-.05` if shared adequacy is retained.

DEV/calibration produce no population p-value. After calibration is sealed,
confirmation uses all `2^16` paired sign flips, studentized statistics, and
Romano--Wolf max-T simultaneous one-sided 95% bounds over:

- superiority: `F-TS`, `F-C0`, `F-RP`, `F-NW`, `F-SB`;
- shared noninferiority: `F-SP >-.05`, if retained;
- external noninferiority: `F-B >-.10` for every declared primary native
  baseline B.

Life-shuffle and twin-swap contrasts form a Holm `.05` secondary family.
Stratum-specific F-minus-no-memory contrasts form a separate Holm `.05`
family. Claim eligibility requires all practical margins above, superiority
lower bounds `>0`, noninferiority lower bounds above their margins, and
full-minus-no-memory lower bound `>0` in every retained stratum. Failed science
cells remain zero at the registered action cap.

Before locked outcomes are opened, a blinded calibration/resource analysis
must show 16 pairs can resolve the registered family. Otherwise confirmation
does not dispatch; a larger study needs new authority.

## 10. Claim-deletion and stop rules

- G1 failure: stop; model-facing construct invalid.
- F fails 70% gold recovery or any baseline margin: no publishable text-system
  claim and no transport proposal.
- F does not beat TS: delete authentic wake-trace credit.
- F does not beat both C0 and RP: delete residual DREAM credit; if C0 matches,
  call deterministic compilation the parsimonious system.
- F does not beat NW: delete durable resolver-created-write credit.
- F-SP falls below `-.05`: delete shared-resolver adequacy; a specialized result
  may survive.
- SB, SL, or TT is not harmful in the registered direction: delete authentic
  experiential-binding attribution and investigate leakage/priors.
- Precision below `1.0`, false-memory use above `0`, read fidelity below `.90`,
  causal-use below `.80`, or any visibility/isolation violation: no constructive
  memory claim regardless of action score.
- Only one stratum passes: claim only that stratum; never average failure away.
- Graph/program/native memory wins outside the `.10` margin: report it as the
  stronger system; no system-advantage clause.
- X absent/fails: delete revision. `C*` absent/fails: delete post-native and
  block the currently specified R3/R4. One pack/cut: always delete lifetime,
  saturation, cross-pack, and flywheel language.
