# RML G1/G2 Interpretation A: minimalist causal ladder

**Status:** independent design input only. This artifact is not architecture
authority, does not modify D0 or any controlling plan, and does not authorize
implementation, model calls, GPU work, LoRA training, locked-data access, or a
scientific claim. Material adoption requires the repository deliberation path,
exact human ratification, predecessor-bound implementation, and fresh review.

**Interpretation A:** after a green D0, spend the first model budget on one
model-certified post-native cut of one mechanism pack and use a sequential,
incomplete factorial. G1 first establishes that the frozen resolver can use
gold local memory. G2 then changes only wake-trace assignment, offline DREAM
operation, durable compilation, or resolver specialization while memory stays
explicit text. Do not train a LoRA, sweep lifetime, add packs, or run on-policy
collection until this text mechanism is identified.

This is the smallest design I consider capable of a narrow publication. A
smaller study can be a useful engineering probe, but it cannot separately
credit wake traversal, residual DREAM, durable sleep writes, and causal text
memory use.

## 1. Question, unit, and maximum claim

The design tests only this fixed-deck chain:

```text
ordinary public action/outcome life
-> wake traversal record (selection only)
-> bounded offline replay / cross-episode re-derivation
-> chronological evidence check
-> deterministic evidence-bound text compilation
-> generic recurrent one-atom reads
-> cited working-path reconstruction
-> later J/P/X action
```

The independent unit is a counterfactual world-life pair. Twins, target items,
resolver calls, DREAM samples, read calls, trace steps, claims, and replay roots
are nested measurements, never replicates.

If every applicable gate passes, the maximum claim is:

> At one model-certified post-native checkpoint in a controlled rendered
> fixed-deck pack, authentic wake traversal records and bounded cross-episode
> offline re-derivation produced chronologically supported compiled text memory
> that a frozen recurrent resolver used causally for connected, prospective,
> and revision-sensitive action; the full text system exceeded its matched
> trace, replay, compiler, and binding controls and was noninferior to the
> preselected strongest external-memory comparator within the registered
> margin.

This design cannot support a LoRA/weights, compression, fixed-capacity,
multi-pack, lifetime-curve, crossover, baseline-saturation, learned-resolver,
on-policy evidence-acquisition, flywheel, external-validity, or general-
intelligence claim. One post-native checkpoint permits the phrase
`at one post-native checkpoint`; it does not permit `kept improving beyond
context`.

## 2. Preconditions and frozen scope

No G1 call is legal unless the exact D0 predecessor and its independent review
are green. In particular, retain D0's deterministic replay, target necessity,
twin collision, exact Bayes/no-life ceiling, legal-history headroom, leakage
probes, chronology, snapshot isolation, run/skip equality, and resource ledger.
D0 passing is instrument evidence only.

Before model work, bind:

- one frozen fluid/thermal mechanism pack and one cut nearest to, but not below,
  `2 * L_native`;
- the exact resolver and reader models, revisions, tokenizer, chat template,
  system prompts, workspace serialization, attention mask, output reserve, and
  decoding settings;
- `L_native` computed as model maximum input less the exact prompt, public
  goal/state, workspace, operation-history, memory-read, and output reserves;
- the common source policy, checkpoint schedule, target decks, counterfactual
  twins, candidate catalog, trace matcher, compiler rules, parsers, budgets,
  seeds, and all visibility schemas;
- four DEV pairs, six sealed descriptive calibration pairs, and eight new
  locked confirmation pairs, with no pair or target replacement after a
  scientific dispatch;
- equal target quotas for `J`, `P`, and `X`, with at least four target instances
  per stratum in each twin at calibration and confirmation.

`X` is not retroactively credited to D0. Before G1, create a separately
reviewed CPU-only X sidecar using the same public action grammar and leakage
contract. Each X item must contain an observable exception, a legal
information-gathering/backtrack route, and a sealed later analogous target.
The analogous target must be generated before the exception outcome. Its gold
controller value must be at least `.85`, its no-life/shortcut value at most
`.35`, and removing the disambiguating evidence must make the registered
recovery impossible. If that sidecar is not ratified and green, remove X and
all revision language; do not silently substitute a QA correction task.

The source experience remains common across G2 arms. Evaluation clones are
read-only, working context/KV cache/workspace/process state is cleared before
each item, and evaluation outcomes never re-enter source life, claim status,
corpus, future replay, or model training.

For causal clarity, the D0 target-blind script still determines the common
source actions. Immediately before each scheduled source action is disclosed,
the frozen G1 resolver receives a predeclared target-blind local maintenance
goal, current public state, and the current `C0` witnessed-atom snapshot and
runs one bounded wake branch. Its proposed action is not allowed to change the
scripted deck; the traversal is sealed before the scheduled action and ordinary
outcome occur. Thus `authentic wake trace` below means a real chronological
model traversal attached to the lived stream, not a synthetic co-occurrence
table and not evidence that wake cognition selected the experience. The latter
arrow remains reserved for G5. The trace collector's goals, prompts, budgets,
and invocation locations are frozen before DEV, and no evaluation target or
future source action/outcome is visible.

## 3. G1: model-usable gold reconstruction

### 3.1 Objects and arms

The gold snapshot contains only the minimum sufficient supported local atoms:
witnessed local relations, the prospectively supported P schema, and the
supported exception/revision record needed for X. It contains no target, full
plan, terminal action sequence, proof path, parent set, scorer label, or direct
answer. Every model-visible read is one local atom or `NOT_FOUND`.

Run three model-facing arms with the same frozen THINK resolver and the same
operation/read/action caps:

| Arm | Query policy | Memory |
|---|---|---|
| `G1-N` | generic resolver, no persistent reads | none |
| `G1-open` | all anchor queries committed before the first return; later reads cannot change a query | gold atoms/schema |
| `G1-rec` | later generic anchor-only queries may depend on earlier returned atoms; update/backtrack is explicit | the identical gold atoms/schema |

`G1-typed` (relation/direction supplied in the query) may run on DEV only as a
scaffold ceiling. It is not a substitute for `G1-rec`. The D0 exact witnessed
graph without the prospective schema, supplied schema/program solver, exact
no-life Bayes controller, and hidden legal-history controller remain CPU
ceilings/controls and need not consume model calls.

The primary generic query contains only a model-visible anchor copied from the
goal, current public state, a public outcome, or a prior read. It cannot contain
the desired value, hidden cohort/family, target-specific relation, answer-shaped
candidate set, scorer metadata, or a search over every lifetime atom.

### 3.2 Constructive-use record

One resolver operation is accepted per call:

```text
QUERY_LOCAL(anchor)
UPDATE_PATH(read_slot, orientation)
BACKTRACK(path_slot)
EXECUTE_ACTION(one public action)
DEFER
STOP
```

The runtime, not free-form model text, copies a returned atom into a path slot.
The bounded workspace stores read slots, public outcome slots, typed nodes,
one-edge path entries, discarded edges, repeat state, and remaining budgets.
It contains no answer scratchpad or hidden chain of thought. A valid proof is a
mechanically checked sequence of returned/local public edges that connects the
visible goal/state to the decisive action arguments.

For every credited success, seal the pre-action state and run two no-action
audit forks:

1. mask the complete minimal cut of cited memory slots; and
2. replace that cut with type-matched atoms from its counterfactual twin.

Masking must change the decisive operation away from the credited action. Twin
replacement must produce the registered twin-valid action or action set.
Correct behavior that fails either fork remains behavioral success but receives
no constructive-memory credit.

### 3.3 Exact G1 go/no-go gate

Evaluate the gate on the six sealed calibration pairs after DEV is frozen.
Proceed to G2 only if all conditions hold:

1. legitimate direct-record closure is exactly `0` on every J/P/X item;
2. `G1-N` and the exact no-life controller are each at most `.35` action value
   separately on J, P, and X;
3. `G1-rec` action value is at least `.85` separately on J, P, and X;
4. mechanically certified constructive-proof rate is at least `.80` in each
   stratum;
5. `G1-open` action value is at most `.35` overall and does not exceed `.45` in
   any stratum;
6. the complete-cut mask and twin-substitution test passes on at least `.80` of
   `G1-rec` successes in each stratum;
7. on registered missing-edge fixtures, unsupported release/fabrication count
   is exactly zero and the resolver uses `DEFER` or a legal evidence request;
8. every selected cut remains at or beyond `L_native` after exact prompts,
   tokenizer, workspace, and reserves are frozen; and
9. there is no visibility, parser, reset, snapshot-mutation, target-leakage, or
   backend-channel failure.

Any failure is a no-go for learned text memory. A `G1-typed` pass with a
`G1-rec` failure establishes only a task-specific query scaffold. A high
`G1-open` score means the task does not require recurrent query selection and
invalidates the intended reconstruction construct; do not weaken the threshold.

## 4. G2 experimental variables

G2 holds the source bytes, public evidence, THINK resolver, reader contract,
compiler version, maximum semantic capacity, replay count, DREAM samples,
model call/token caps, and evaluation deck fixed. It changes one mechanism at a
time around a full reference cell. It is a fractional factorial, not a full
Cartesian product.

### 4.1 Wake traversal trace

At each ordinary source wake branch, record two hash-bound objects:

```text
resolver_invocation:
  life/checkpoint/snapshot hashes
  mode = THINK
  public local goal and visible-handle hashes
  reader snapshot and model/reset provenance
  operation, query, token and action budgets

traversal_record:
  ordered QUERY_LOCAL / read-result / UPDATE_PATH / BACKTRACK operations
  cited public/read slots and terminal ACT / DEFER / STOP
  per-operation input/output hashes and remaining budgets
```

The record is append-only and mechanically replayable. Free-form rationale,
hidden truth, scorer output, target manifests, final held-out answers, and
evaluation traces are absent. Only a trace actually emitted before the
associated ordinary source outcome is authentic. Failed, malformed, deferred,
and backtracked paths remain in the log and cannot become positive semantics.

Wake traces are **selection signals, not evidence**. They may select and group
eligible public replay roots, select a supported path for re-examination, or
allocate a bounded retrieval shortcut/touch. They cannot support a factual
claim, increase root count, repair a prediction, or authorize an action.

The matched shuffled trace is generated by a frozen within-type bijection over
trace-to-replay assignments. It preserves, per pair and checkpoint:

- trace count, operation count, query/read-result types, found/miss frequency,
  path-length and backtrack distributions, terminal-status counts;
- replay bundle count/size, event age bin, root-count bin, relation/type bin,
  model calls, decoding seeds, and input/output token caps; and
- legal recipient-life handles through a predeclared type-preserving remap.

It breaks the authentic binding between a wake path and the public roots it
traversed. A frequency table without a replayable source record is a forged
statistic and must be rejected before a model call. A paired other-life trace
assignment is a required attack; it is descriptive unless promoted in advance
to the multiplicity family.

### 4.2 DREAM and the residual being tested

DREAM receives a target-blind bounded checkpoint, eligible public replay
bundles selected under the assigned trace condition, and eligible prior
supported local atoms. It never sees a held-out goal, target manifest, future
outcome, scorer, hidden program, proof, acceptance receipt, or evaluation
result. Each sample may emit one local proposal with cited eligible roots,
supported parents, scope/preconditions, and an executable future prediction.
Proposal count is fixed before outcomes; malformed samples are not replaced.

Four DREAM modes define the residual:

- `none`: no model sleep call;
- `wake transcription`: no DREAM; deterministic compilation may retain legal
  hot-path retrieval cues or licensed local composites selected by authentic
  wake traversal;
- `replay only`: replay/selection and restatement of witnessed atoms are
  allowed, but combining roots from distinct episodes into a new relation is
  forbidden;
- `cross episode`: replay, compare, locally re-derive, propose a falsifiable
  cross-episode relation, and revisit contradictions.

`CHECK` by the same model is only a correlated consistency signal. It may guide
search, stopping, or deferral, but never promotes a factual claim and never
enters positive text memory. Positive support requires deterministic entailment
from eligible public evidence or a distinct later ordinary public outcome that
matches a prediction committed before that outcome existed.

The residual DREAM estimand is the full `cross episode` cell minus both
`replay only` and `compiler only`. It is not the full system minus no memory.

### 4.3 Deterministic sleep compilation

SLEEP is a versioned deterministic CPU transformation. Its sealed inputs are
eligible public roots, supported semantic records, assigned selection-only
traces, DREAM proposals/status events, and frozen public composition rules. Its
output is a `consolidation_plan` containing only:

```text
SEMANTIC_COMMIT
RETRIEVAL_SHORTCUT
REALIZATION
TOUCH
DEFER
GC
```

A `SEMANTIC_COMMIT` requires a witnessed atom or a chronologically supported
proposal with mechanically valid root provenance. A semantic shortcut requires
a licensed typed composition rule, supported premises, scope, preconditions,
counterexample handling, and invalidation dependencies. Co-retrieval can create
only a `RETRIEVAL_SHORTCUT`; it is never a premise or derivation-depth unit.

The compiler canonicalizes and deduplicates, preserves provisional,
contradicted, stale, and superseded records outside positive memory, interleaves
old/new claim types, and emits the same frozen one-atom text views for every
admitted atom. Reverse/paraphrase/cloze/incident views inherit exactly the
parent root set and add no support. No view may contain a plan, complete target
answer, proof path, target identifier, status score, critic approval, or hidden
metadata.

The compiler may reject or defer; it may not invent a claim, call a model,
search hidden truth, inspect evaluation, or use future evidence. Corpus and
source/status hashes are sealed at every checkpoint. The `no durable write`
cell runs all full DREAM/search calls but drops every resolver-created semantic
commit and retrieval shortcut before corpus construction. Its remaining
witnessed-atom corpus must hash-identically to `compiler only`; the identical
evaluation trajectory can therefore be reused under greedy decoding, while
the extra search compute remains in its resource ledger.

### 4.4 Text-memory use

The compiled text snapshot is mounted read-only. The frozen target-blind
candidate catalog is constructed before target generation and contains all
legal true and false one-edge atoms plus `NOT_FOUND`. The reader receives only
snapshot ID, a generic model-visible anchor, and already-returned candidate
IDs. It receives no target, state, hidden family, desired relation/value,
scorer, provenance graph, or answer-shaped candidates.

Each read returns exactly one atom or `NOT_FOUND`, without rank, alternatives,
topology, score, confidence, backend identity, timing, candidate count, or
provenance. Runtime assigns the return to a citable read slot. Multi-hop
composition occurs only through the frozen G1 recurrent resolver and bounded
workspace. An exact episodic root can be fetched only through a returned claim
handle and under the same fixed read budget; it is not a second searchable
memory.

For every credited G2 success, repeat the G1 complete-cut mask and twin-atom
substitution forks before the decisive action. Separately build a postcompile
binding shuffle that preserves claim type/status, root-count bin, source-age
bin, token-length bin, answer marginals, view count, corpus bytes within the
registered tolerance, and reader/candidate budget while deranging object/world
bindings. Also cross-assign the authentic compiled text snapshots between
counterfactual twins. These are text-memory-use falsifiers, not wake-trace
controls.

## 5. G2 cells: smallest nonredundant matrix

Run these mechanism cells. All use the same recurrent G1 THINK resolver at
evaluation.

| Cell | Wake trace | DREAM | Durable resolver-created write | Resolver policy |
|---|---|---|---|---|
| `C0 compiler_only` | none | none | no | deterministic witnessed/accepted atom compiler |
| `W1 wake_only` | authentic | none | legal trace-selected cue/composite only | shared kernel |
| `R1 replay_only` | authentic | replay only | yes | shared kernel |
| `F shared_cross_episode` | authentic | cross episode | yes | shared kernel |
| `TS shared_shuffled_trace` | matched shuffled | cross episode | yes | shared kernel |
| `NW shared_no_durable_write` | authentic | cross episode | no | shared kernel; search artifacts stay scratch |
| `SP specialized_cross_episode` | authentic | cross episode | yes | separately frozen THINK and DREAM policies |

`NW` shares the `C0` corpus/evaluation bytes only if the required hash equality
holds. Otherwise it is an ordinary separate cell and the mismatch is a
protocol failure until explained and re-ratified.

The specialized cell uses the same base model revision, source, reader,
visible fields, total calls, token caps, decoding samples, semantic capacity,
and admission/compiler rules. Only the operation policy/prompt/parser may be
mode-specialized, and it must freeze on DEV before any calibration pair is
opened. This comparison can establish that a shared interface is adequate; it
cannot establish that shared learned weights are better.

Run three one-factor falsifier cells around `F`, without crossing them through
the whole matrix:

- `SL life_shuffle`: action/outcome attachments are deranged before DREAM and
  admission, with visible counts/types/lengths and budgets preserved;
- `SB corpus_binding_shuffle`: the already compiled F corpus receives the
  matched postcompile binding shuffle described above; and
- `TT twin_text_swap`: the authentic F snapshot is assigned to its twin.

These interventions are non-interchangeable: `SL` tests dependence of proposal
and admission on authentic lived outcomes; `TS` tests wake-trace connectedness;
`SB` tests learned corpus bindings holding admitted structure fixed; `TT` tests
life specificity. Omitting any one deletes its corresponding attribution.

### External comparator tournament

On DEV and the six calibration pairs, run honest native context, raw episodic
RAG, hierarchical reflection/summary, native A-MEM linked memory, exact
witnessed graph, generator-aware program induction, and procedural skill
memory, each through its native interface where appropriate. Report the common
one-atom interface variants only as protocol diagnostics.

Before confirmation is unsealed, select one comparator `B*` by the largest
calibration mean over equal-weight J/P/X, breaking ties toward the comparator
with the larger upper uncertainty bound and then the lower resource cost. Run
`B*`, no memory, `G1-rec` gold, and every core/falsifier cell needed by the
retained claim on all eight confirmation pairs. The paper may say
`preselected strongest calibration comparator`, not `every baseline`, unless
all competitors are also run in confirmation. Exact graph/program/legal-
history ceilings remain reported even if another `B*` is selected.

This tournament is the main GPU-saving choice. It is valid only because the
selection data are disjoint from confirmation and no prompt, threshold, target,
or arm changes after `B*` is selected.

## 6. Fixed budgets and execution order

Use one cut, one pack, one frozen model stack, and no LoRA. The default per-item
caps are the smallest G1 configuration that clears its gate; they then freeze
for every G2 text/common-reader cell. No G2 arm receives a target-conditioned
query, more resolver operations, more reads, longer workspace, or extra retry
because its memory is harder to use.

At each sleep checkpoint, give each DREAM-bearing cell the same number of
eligible replay bundles, four preallocated DREAM samples per bundle, decoding
seeds, maximum calls/tokens, and proposal slots. Empty/malformed/rejected slots
remain empty and consume budget. Equalize maximum semantic capacity and write
slots, not factual content. Do not pad a weak corpus with another arm's atoms.

The order is:

1. D0 and X-sidecar CPU/review gates;
2. four-pair DEV for prompt/parser/budget debugging only;
3. frozen six-pair G1 qualification;
4. full G2 matrix and comparator tournament on DEV/calibration;
5. freeze `B*`, all hypotheses, multiplicity, corpus/trace matchers, and code;
6. fresh independent review plus explicit human GPU/claim gate;
7. eight-pair locked G2 confirmation with all outcomes masked until complete.

No result may cause a new pair, target, sample, retry, arm, threshold, or model
to be added. Infrastructure failure before a first scientific dispatch may
resume the identical sealed cell. Partial scientific cells remain failures at
their action cap and are reported.

Every pair/cell reports public actions/tokens, wake and DREAM calls/tokens,
trace operations, replay roots, proposal/support/contradiction counts, corpus
atoms/views/bytes, reader candidate work/latency, THINK calls/tokens, causal-
trace rate, final action value, and total CPU/GPU wall time/FLOPs. Candidate
work that scans all lifetime atoms is explicitly reported as external search.

## 7. Estimands and exact G2 gates

Let `A_s(c,p)` be equal-weight J/P/X action value for cell `c` in stratum `s`
and independent pair `p`. Let `N`, `G`, `F`, `TS`, `R1`, `C0`, `NW`, `SP`,
`SL`, `SB`, `TT`, and `B*` denote the corresponding pair scores. Define:

```text
Gold gain:          g_gold  = mean(G - N)
Full text gain:     g_full  = mean(F - N)
Trace loss:         d_trace = mean(F - TS)
Dream residuals:    d_dc    = mean(F - C0)
                    d_dr    = mean(F - R1)
Durable-write gain: d_write = mean(F - NW)
Shared adequacy:    d_share = mean(F - SP)
External gap:       d_ext   = mean(F - B*)
Life binding:       d_life  = mean(F - SL)
Corpus binding:     d_bind  = mean(F - SB)
Twin binding:       d_twin  = mean(F - TT)
```

Calibration promotion requires every validity condition below and:

1. `g_full / g_gold >= .70`, with `g_gold > 0`, separately on J, P, and X;
2. `A_s(F) >= A_s(B*) - .10` separately on J, P, and X;
3. `d_trace >= max(.15, .5 * g_full)`;
4. `d_dc >= .10` and `d_dr >= .10`;
5. `d_write >= .10`;
6. `d_share >= -.05`;
7. `d_bind >= max(.15, .5 * g_full)`, with `d_life > 0` and `d_twin > 0` in
   the same direction; and
8. accepted-edge precision, accepted-edge coverage, false-memory use,
   constructive-proof rate, and action value are all separately reportable.

The confirmation claim requires the same observed practical margins and
simultaneous one-sided 95% world-pair lower bounds:

- above `0` for `F-TS`, `F-C0`, `F-R1`, `F-NW`, `F-SL`, `F-SB`, and `F-TT`;
- above `-.05` for `F-SP`;
- above `-.10` for `F-B*`; and
- above `0` for the full-minus-no-memory gain in each of J, P, and X.

Use exact paired sign-flip/randomization inference over the eight pair scores
and simultaneous max-T bounds over the registered contrast family. With only
eight pairs, the gate is intentionally hard: if the bound cannot clear the
margin, the narrow positive claim is not made. Targets and model samples are
averaged inside pair. No probe-level confidence interval is legal.

For causal constructive credit, at least `.80` of F successes in each stratum
must pass both complete-cut masking and twin substitution. Fixed-query local
read fidelity against the frozen text snapshot must be at least `.90`. False-
memory use is the fraction of decisive actions whose cited path contains an
unsupported, contradicted, wrong-scope, or absent atom; it must be exactly `0`
for a positive mechanism claim. Missing-edge unsupported release must also be
exactly `0`. Accepted semantic-edge precision against the sealed offline audit
truth must be `1.0`; accepted-edge coverage has no independent floor but must
be reported by relation type and cannot be hidden by aggregate action value.

### Validity gates that dominate performance

Any one of the following is an immediate no-go, regardless of action score:

- any admitted positive claim depends on target/evaluation data, an agenda
  answer, unsupported workspace, critic approval alone, hidden truth, a future
  outcome, a realization, repeated wording, or a scorer;
- any derived positive claim lacks a pre-outcome committed prediction, a
  distinct confirming public root, valid scope/preconditions, or a mechanically
  valid provenance DAG;
- any trace used as factual evidence, any forged/nonreplayable trace accepted,
  or any shuffled-trace matching invariant violated;
- any compiler nondeterminism, hidden model call, target access, mutable sealed
  input, corpus hash mismatch on replay, or evaluation write-back;
- any common-reader return contains more than one atom, a plan/path, rank,
  alternatives, topology, target-conditioned candidate, or backend channel;
- direct-record closure above zero, cross-life canary contamination, cache/
  process carryover, parser repair, unregistered retry, target reuse, or
  evaluation run/skip suffix mismatch; or
- the selected checkpoint is not strictly beyond the mechanically computed
  `L_native` after all exact model-visible reserves are charged.

## 8. Decision table and claim deletions

- `G1-rec` fails: the model-facing construct is invalid; do not run learned G2.
- `F` fails the 70% gold-recovery or external-margin gate: stop before LoRA;
  report a negative text/compiler result.
- `F` does not beat `TS`: delete wake-connected-trace credit.
- `F` does not beat both `C0` and `R1`: delete residual DREAM credit. If `C0`
  matches F, report deterministic compilation as the parsimonious system.
- `F` does not beat `NW`: delete durable resolver-created-write credit.
- `SP` exceeds F outside the `-.05` margin: delete shared-resolver adequacy;
  retain the specialized result if otherwise valid.
- `SB`, `SL`, or `TT` does not reduce value in the registered direction:
  delete authentic experiential-binding attribution; investigate leakage or
  generic priors before any promotion.
- text read fidelity is below `.90`, causal trace credit is below `.80`, or
  false-memory use is nonzero: no constructive text-memory claim.
- only J passes: connected retention/planning only; delete prospective and
  revision clauses. Only P passes: schema-conditioned transfer only. Only X
  passes: bounded recovery only. Do not average a failed stratum away.
- native graph/program or `B*` wins: report it as the stronger system; do not
  promote LoRA merely because the internal mechanism contrasts passed.
- fewer than three post-native checkpoints, one pack, and fixed experience
  remain explicit: no lifetime-growth, saturation, cross-pack, or flywheel
  language under any outcome.

## 9. Why this is minimalist

G1 uses only no memory, nonadaptive gold, and recurrent gold; exact graph,
program, Bayes, and legal-history controls stay on CPU. G2 uses one source
snapshot and text only. The seven core cells are the minimum vertices needed
to distinguish deterministic compilation, wake-only structure, replay,
cross-episode DREAM, trace binding, durable writing, and shared versus
specialized operation policies. The three falsifiers are one-factor attacks,
not another Cartesian sweep. A disjoint comparator tournament avoids carrying
every expensive native baseline into confirmation.

The design spends GPU on the unresolved causal arrows and freezes every
intermediate artifact. If it passes, LoRA transport becomes a justified next
question. If it fails, the failure localizes which organ did not earn that
cost.

## 10. Authority boundary

This interpretation is a review artifact. It recommends a design; it does not
ratify bytes, override the controlling organism, release a prompt/model, or
permit a GPU run. Adoption requires at least one other fresh interpretation,
adversarial cross-critique, adjudication of every disagreement and test,
explicit human ratification of exact scope/bytes, scoped implementation,
pre-GPU CPU evidence, a fresh independent reviewer, an author-side scientific
advocate who cannot override rejection, and a separately bound model/GPU
authorization.
