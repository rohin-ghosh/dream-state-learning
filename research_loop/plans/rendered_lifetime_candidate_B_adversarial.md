# Rendered Lifetime Candidate B: adversarial paper experiment

**Status:** independent methods-review proposal only. This file authorizes no
implementation, model call, training run, GPU use, benchmark result, promotion,
or scientific claim.

## Executive verdict

None of the current games is a valid headline test of developmental
experiential learning.

The existing line contains useful component instruments, but the proposed
headline keeps moving from one finite symbolic table to another. Semantic World
v0.2 measures whether an exhaustive controller can recover a hidden parent set
from observational cells. Action World v0 measures a four-bit parity law and
calls two independent crossings A3. PCFL-13 contains 13 mappings and saturates
at about 16.7 latent bits. PCFL-Stream adds independent copies of the same
mapping table. FeltCraft v2 replaces those tables with independent four-edge
crafting families, exhaustively assays every candidate pair, and calls two
namespace-disjoint eight-action plans an old--new join. FeltCraft symbolic
kernel v7 may now be internally exact, but its own contract correctly limits it
to symbolic conformance: `LOCAL` is not an atoms baseline, `MOTIF` is given the
complete graph, and no learned system is exercised.

These are not small imperfections. They leave the central paper claim
unidentified. A system can score by context induction, exact retrieval, graph
traversal, memorizing a finite permutation, following a handcrafted resolution
protocol, or exploiting generator structure without having become better from
its own action--outcome history. Extending the transcript past a chosen prompt
budget does not repair that defect.

The minimum decisive replacement is one rendered, action-first lifetime world
with three properties absent jointly from the current games:

1. genuinely new causal structure continues to enter at three checkpoints
   strictly beyond the tested model's actual native context;
2. later goals require a connected old-to-new causal dependency and at least
   one target-local fact that was never directly witnessed; and
3. authentic memory is randomized before an information-gathering block, so
   the experiment can measure the complete path
   `memory -> action choice -> evidence -> reconsolidation -> later action`.

Call this replacement **Rendered Maintenance Lifetimes (RML)**. The name is
unimportant. The causal geometry is the contribution.

The paper should be killed or sharply narrowed if RML does not beat an honest
native graph/program-induction agent. Graph dominance is a scientifically good
negative result; it is not permission to weaken the graph interface.

## 1. Claim to identify

The primary claim should be behavioral and conditional:

> In unseen world-lives, a fixed agent using consolidation learned only from
> its own public actions and outcomes continues to acquire, retain, and combine
> useful causal knowledge at three post-native checkpoints; authentic assigned
> memory also improves which evidence it gathers, and that evidence improves a
> later sealed action, relative to matched long-context, episodic-retrieval,
> linked-graph, explicit schema-learning, reflection, skill-library, and direct
> parametric-memory baselines.

This sentence contains five separately gated claims:

- **experience dependence:** authentic life memory matters versus type-,
  length-, and compute-matched shuffled or counterfactual memory;
- **beyond-context development:** action value rises as new causal coverage
  rises at multiple points beyond actual native context;
- **constructive generalization:** success is on fresh states whose decisive
  solution was never stored, not on witnessed transitions or replayable plans;
- **substrate credit:** compiled LoRA has value beyond the same compiler in
  text and beyond direct trajectory-to-QA LoRA;
- **flywheel credit:** memory changes exploration, not merely read-only target
  answering.

Failure of one gate removes only that clause. In particular, fixed-deck gains
without an on-policy effect establish representation/use, not experiential
self-improvement.

## 3. Minimum decisive world: Rendered Maintenance Lifetimes

### 3.1 Setting

Each life is one persistent remote habitat containing equipment, routes,
materials, hazards, sensors, and repair objectives. The public interface is
rendered in ordinary semantic language, but every consequential per-life
binding is sampled after the base model was trained. Meaningful words help the
agent parse the situation; they do not determine the hidden answer.

Use three independently authored mechanism packs rather than three skins of
one table:

1. **fluid/thermal:** valves, pumps, filters, coolant, pressure and corrosion;
2. **power/control:** relays, cells, sensors, grounding, overload and signal
   routing;
3. **material/biological:** coatings, cultures, reagents, temperature, toxicity
   and containment.

All packs expose the same generic operation API but use different transition
code and different causal program grammars. A paper-wide claim requires the
same qualitative result in all three packs. Isomorphic word substitution does
not count as replication.

Legal operations are generic and stateful:

```text
OBSERVE(object_or_site)
MEASURE(object, public_test)
MOVE(route_or_site)
ACQUIRE(object)
CONFIGURE(object, setting_or_attachment)
APPLY(tool_or_material, target)
RUN(object_or_process)
COMMIT(goal)
STOP
```

Every operation costs time or resources and returns only the consequence of
the executed operation. Some failures are recoverable, some consume an object,
and some end the mission. There is no `ASK_RULE`, recipe table, counterfactual
query, target checker, or failure message that names a missing prerequisite.

### 3.2 Causal program per life

A world samples a persistent causal program with four kinds of relation:

- **transformations:** an action changes a functional state under a condition;
- **compatibilities:** a transformed state enables or blocks another process;
- **routing/preconditions:** a resource or signal can traverse only after an
  upstream condition holds;
- **scoped exceptions/drift:** a local context overrides one previously useful
  rule and can be discriminated by an action.

The program is modular but connected. New eras add modules whose inputs or
constraints include outputs of earlier modules. They do not add independent
namespaces. At least one new relation per era changes the applicability of an
old relation, so causal depth and interaction grow along with the number of
facts.

An illustrative late mission is:

```text
early life:  coating K prevents corrosion only after heat curing
middle life: cured housings can carry a calibrated sensor through acid routes
recent life: coolant mode Q makes the target process safe but disables an
             unshielded sensor
late goal:   diagnose Q, cure and coat a fresh housing, shield/calibrate its
             sensor, route it through the acid section, activate Q, and repair
             the process
```

Removing the early coating relation makes the recent plan fail. Removing the
recent Q relation makes the old procedure unsafe. This is a connected
old-to-new dependency, not two completed plans placed side by side.

The program generator has at least two higher-order laws per pack. Which law
applies is randomized per life and is not named publicly. Source eras show
partial instances. A DREAM or schema learner may commit a prospective law only
before the confirming era. Later ordinary actions can support, contradict, or
scope it. A sparse target contains one unwitnessed local edge predictable from
the law. Thus raw episode retrieval and a graph of witnessed edges are
insufficient, while an explicit program-induction baseline remains capable.

### 3.3 Lifetime construction

Let `L_native` be the model's measured maximum usable input after the exact
system prompt, current public state, workspace, and output reserve. Do not
replace it with a convenient 8k or 16k experimental cap.

Evaluate at one pre-native reference and three strictly post-native cuts:

```text
0.5 L_native, 2 L_native, 4 L_native, 8 L_native
```

If 8x is infeasible, choose a shorter-native backbone before preregistration;
do not call an imposed window “native.” Fewer than three post-native points
forbids growth, crossover, saturation, or continued-improvement language.

Each interval must add:

- new independently identifiable local causal relations;
- at least one new interaction with an earlier module;
- at least one prospectively testable schema prediction;
- new action outcomes rather than paraphrase, replay, or filler.

Report raw tokens, unique public root events, identified local relations,
causal-program MDL under multiple frozen code classes, minimum sufficient
statistic bytes, and effective dependency depth. A checkpoint is invalid for
developmental analysis if raw tokens grow while these quantities plateau.

### 3.4 Target deck

At every cut, create fresh handles, layouts, and goals with matched difficulty.
No exact source state--goal pair, complete plan, or terminal action sequence may
recur. Score four strata separately:

- **R (recall diagnostic):** one witnessed effect; never a primary endpoint;
- **N (new acquisition):** use relations learned since the prior cut;
- **O (old retention):** use early relations whose last direct support is
  outside native context;
- **J (connected join):** a six-to-twelve-action plan in which an early
  transformation is a necessary input or constraint for a recent mechanism;
- **P (prospective sparse transfer):** one decisive target-local edge was never
  witnessed and is implied by a pretarget schema;
- **X (revision):** gather one discriminating observation after an exception,
  backtrack, and later improve on a fresh analogous mission.

The primary endpoint is the equal-weight mean of N/O/J/P/X action value. R is
an installation diagnostic. Every target has a hidden shortest-plan and
necessity certificate for offline scoring, but the target generator may use
only structural predicates—not model scores—to accept worlds.

For J, deleting the registered early bridge must make every legal plan fail or
exceed the budget; the recent half alone and early half alone must each be
insufficient. For P, a graph containing every witnessed edge but no prospective
schema must remain below the registered ceiling. For X, the later analogous
mission is generated before the exception outcome and remains sealed.

### 3.5 Counterfactual worlds and leakage geometry

For every latent world, generate a paired counterfactual twin with:

- byte-identical target goal and pre-action public state;
- identical public handle, length, action-count, outcome-count, and difficulty
  marginals;
- a different hidden mechanism and correct plan;
- earlier action--outcome histories that identify the appropriate twin.

Public nuisance RNG is independent of hidden-mechanism RNG. Handles, order,
padding, renderer choices, target IDs, and split IDs cannot be deterministic
functions of one enumerable master seed. Leakage analysis conditions on the
complete selection algorithm and on every jointly visible public byte. Hiding
rejection receipts does not erase selection information.

Before model work, a generator-aware Bayes controller and target-only,
state-only, identifier-only, renderer-only, passive-signature, action-frequency,
and source-action-string predictors must remain below `0.35` normalized
N/O/J/P/X value. An exact legal-history controller must exceed `0.85` on every
stratum. Each target, not merely the cohort mean, must have a legal plan and a
nontrivial no-lifetime posterior.

Hold out complete causal program productions, not just seeds. Development may
use some program compositions; locked evaluation uses new compositions and at
least one held-out law instantiation per mechanism pack. A controller that
knows the full generator DSL is included as an explicit Bayesian/program-search
baseline and ceiling. It is never hidden inside the headline system.

## 4. Two experiments are mandatory

### 4.1 Experiment I: common-experience attribution

All arms receive byte-identical ordered public action--observation--outcome
events from one frozen exploratory policy. The policy is nonexhaustive and
outcome-blind within each scheduled probe bundle; it samples diagnostic and
ordinary task actions without enumerating every legal pair. The exact same
source bytes go to all arms.

At each cut:

1. build the arm's memory from the legal prefix;
2. clear prompt history, KV/prefix cache, workspace, temporary files, reader
   cache, and process state;
3. mount one frozen read-only memory snapshot in a fresh target process;
4. execute a sealed target under a common action and cognition budget;
5. destroy the process and discard all evaluation outcomes;
6. require byte-identical later life state to a run that skipped evaluation.

This experiment identifies representation and use at fixed experience. It is a
required prerequisite, not the experiential-learning headline.

### 4.2 Experiment II: randomized on-policy developmental flywheel

At the first post-native boundary, clone the same canonical public world state
and randomize each clone to authentic, null, binding-shuffled, or twin memory.
Each condition then receives the same action, resolver, query, and wall-clock
caps for an ordinary information-gathering block. Exogenous events and initial
inventories are paired. Agents may choose which objects to inspect, which
interventions to run, which operational objective to attempt, and when to stop.

Ordinary block outcomes enter that clone's life. The system then consolidates
once under a fixed budget. A later fresh target deck, generated before the
collection block and kept sealed, measures action value. Evaluation never
re-enters memory.

Repeat the assignment in independently cloned blocks at 2x, 4x, and 8x native
context. Continue one preregistered authentic and control branch longitudinally
to measure compounding; use the other clones for block-local causal estimates.

Cross collection and representation after each block:

```text
collector trace: authentic-memory policy or control-memory policy
representation: compiled system, raw RAG, native graph, or direct-QA LoRA
```

Every representation is built from the same collected trace within a cell.
This factorial separates better experience acquisition from better
representation/use. Arbitrary experience swapping across incompatible worlds
is forbidden.

The flywheel claim requires all four links, not only a total-score difference:

1. authentic assigned memory changes information-seeking actions;
2. those actions increase preregistered target-relevant information gain or
   causal coverage per action;
3. the resulting supported memory improves in precision/coverage or prospective
   prediction;
4. the later sealed target action improves.

Use randomized-assignment intention-to-treat as the primary causal result.
Mediation is descriptive unless a separate interventional mediation protocol
is preregistered.

## 5. Mandatory baseline and factorial suite

Use the same frozen action/reasoning backbone and public interface for all
learned agents. The minimum locked comparison set is:

1. no persistent lifetime memory;
2. chronological context up to the actual native limit, with honest truncation
   afterward;
3. strongest feasible native-long-context diagnostic, explicitly unmatched if
   it uses a different model;
4. iterative hybrid sparse+dense RAG over raw episodes;
5. hierarchical summary/reflection memory;
6. native A-MEM-style linked memory using its native retrieval interface;
7. an exact witnessed-event graph with bounded native graph traversal;
8. explicit Bayesian/program induction over the published generator family;
9. a procedural skill library/trajectory abstraction baseline;
10. raw-trajectory LoRA;
11. direct trajectory-to-QA LoRA using the same write envelope;
12. DREAM-compiled text with native retrieval;
13. the identical admitted semantic corpus in text and LoRA through the same
    one-atom reader;
14. unaided generative LoRA read, separate from recognition-assisted read;
15. end-of-life batch SFT on the same prefix as an upward resource reference;
16. authentic, within-world binding-shuffled, and twin-swapped versions of the
    learned memory.

Do not cripple graph, A-MEM, or skill-library baselines to a common reader and
then call the comparison fair. Report both a common-channel factorial, which
isolates representation at equal visible return bandwidth, and each baseline's
native interface, which tests the best competing system.

Before testing learned DREAM, run the generic thinker with gold legal memory.
Before testing LoRA transport, freeze one admitted corpus and compare compiled
text versus LoRA under byte-identical queries and return schemas. Cross the
reader with the thinker:

```text
memory quality: null / gold atoms / gold schema / learned text / learned LoRA
controller: nonadaptive / generic recurrent / generator-aware program search
```

This prevents a handcrafted resolver from being credited to memory and a good
memory from being blamed for a broken thinker.

## 6. Information, compute, and capacity matching

“Matched” must be a vector, not a slogan.

For every world, cut, arm, and adapter seed, record:

- public source actions/events/tokens and unique roots;
- target environment-action cap;
- resolver operations, queries, input/output tokens and FLOPs;
- candidate construction, hidden scans, index work and latency;
- writer/dream calls, samples, tokens and proposal budget;
- compiler records and views;
- training examples, tokens, steps, rank, optimizer state, FLOPs and energy;
- active memory, retained memory, audit/provenance, index, adapter and workspace
  bytes;
- wall time, failures, retries, malformed outputs and indeterminate calls.

Common-deck arms have identical public information and action history. Common-
reader arms have identical query, return, token, and operation caps. Learned
write arms receive one preregistered useful-compute envelope; no method receives
extra retries because its outputs are poor. Native baselines retain their
native capabilities, with all extra work measured.

Do not use idle reflection, irrelevant padding, or duplicate views to claim
equal useful compute. Do not force a smaller efficient baseline to allocate
unused bytes. Compare action value on a preregistered resource Pareto surface:
at minimum one low, one matched, and one high capacity point frozen on DEV.
The chosen LoRA rank or active graph budget is fixed across lifetime cuts; a
different favorable rank at every cut is prohibited.

A parametric scaling claim additionally requires sublinear query work in total
lifetime memory and no linear growth in adapter bytes/rank merely to retain old
value. If LoRA capacity must grow linearly with identified structure, the result
is parametric storage, not compression.

## 7. Preventing verifier and generator leakage

The following firewall is non-negotiable:

- THINK and DREAM never see hidden state, proof graphs, shortest paths, target
  manifests, scorer output, candidate correctness, paired-world metadata,
  target outcomes, or acceptance receipts.
- A DREAM proposal commits its atom/schema, scope, public roots, executable
  prediction, and deadline before the relevant ordinary outcome exists.
- A later public action outcome may be mechanically compared with that fixed
  prediction. The comparator cannot propose, normalize, repair, rank, choose a
  candidate, reveal distance, or trigger a replacement sample.
- Proposal count and seeds are fixed before outcomes. Generating candidates
  until one passes is verifier-guided search and invalidates dream credit.
- Evaluation outcomes, target queries, paths, actions, caches, RNG and timing
  are write-denied and excluded from later manifests. Run-versus-skip suffix
  hashes must match.
- Provisional, supported, contradicted, stale and superseded records are
  append-only. Paraphrases, views, repeats and common ancestry do not create
  independent support.
- Every model-visible byte has a field-level taint and an origin. Free-form
  rationales and agendas cannot become evidence.
- Generator source, offline solver, posterior calculator and scorer are not
  imported by model-facing processes. Public schemas contain no family, role,
  depth, seed, split or target-answer fields.
- Locked worlds are generated from a fixed registry before scientific calls.
  No target rejection or replacement uses model/baseline performance.

Add a deliberate leakage self-test that injects the answer separately into
every permitted projection and verifies that the audit detects value 1. A weak
probe implementation is not evidence of no leakage.

## 8. Causal-use credit

Behavioral return is primary; an agent need not narrate its true reason to earn
success. But a constructive-memory claim needs more than a correct action.

Before each decisive action, seal the model input and returned memory slots.
In isolated no-action audit forks:

1. mask the minimal set of cited early/recent/schema memories;
2. replace them with type-, length-, frequency-, and status-matched twin atoms;
3. cut all redundant retrieval paths, not just one convenient edge;
4. replay the deterministic decision call with the same public state and RNG.

Constructive credit requires masking to change the decisive action or reduce
its registered success probability, and twin replacement to move behavior
toward the twin-valid action. This is secondary mechanistic evidence. The
randomized whole-memory assignment in Experiment II supplies the stronger
system-level causal effect.

Binding controls must be distinct:

- **life shuffle:** perturb action--outcome bindings before DREAM, allowing the
  learned corpus to change;
- **corpus shuffle:** derange bindings after compilation while preserving type,
  status, root-count bin, token length, answer marginals, view count and write
  compute;
- **twin swap:** assign an intact authentic memory from the paired world.

Collapsing these into one “shuffle” makes the result uninterpretable.

## 9. Replication, endpoints, and inference

The independent unit is a paired world-life, not an episode, goal, model call,
dream sample, memory record, or adapter seed.

Use:

- DEV: at most four twin pairs per mechanism pack for prompts, thresholds and
  resource points;
- locked calibration: six new twin pairs total, descriptive only;
- confirmation: at least eight new twin pairs per mechanism pack, 24 paired
  world-lives total, increased before unmasking if DEV/calibration variance
  requires it;
- two adapter seeds averaged within a world; they are not replications;
- fixed lifetime orderings balanced across world pairs.

If compute cannot support 24 locked pairs, all mandatory baselines, and three
post-native cuts, call the result a pilot. Do not manufacture sample size from
targets.

For method `m`, world pair `w`, cut `L`, and stratum `s`, let
`V[m,w,L,s]` be normalized executed action value, with malformed, illegal,
deferred, timed-out and scientific-call failures scored zero at the action cap.

Predeclare four ordered primary gates:

1. **validity:** legal-history oracle `>=.85`, every leakage/no-lifetime
   predictor `<=.35`, and all isolation/twin/necessity tests pass;
2. **fixed-deck construction:** full system exceeds the DEV-selected strongest
   native external-memory baseline on N/O/J/P/X post-native AUC by a practical
   margin such as `.10`, with a world-clustered simultaneous lower bound above
   zero;
3. **continued development:** from 2x to 8x native, full-system value improves
   by at least `.10`, no post-native interval falls by more than `.05`, old
   retention does not collapse, and new/J/P value rises with causal coverage;
4. **on-policy flywheel:** authentic memory improves information gain per
   collection action and later sealed action versus null/shuffle/twin assignment,
   with both lower bounds above zero.

Use paired randomization/sign-flip inference over world pairs and a paired
world-cluster bootstrap for uncertainty. Correct named co-primary baseline and
stratum tests with a frozen max-T or Holm procedure. Report every world and
mechanism pack. An aggregate positive with a reversed effect in one pack earns
only a pack-bounded claim.

Predeclare the strongest baseline on DEV or test simultaneously against all
primary baselines. Taking the maximum after seeing locked results is not valid.
Missing scientific cells remain failures; infrastructure failures before any
science dispatch may resume only the same sealed cell.

Secondary measures are first-attempt success, normalized return, restricted
mean actions-to-success, information gain/action, causal coverage, prospective
prediction calibration, false-memory use, old/new edge precision and recall,
effective dependency depth, correction half-life, reader fidelity, query/hop
cost, and resource Pareto position.

## 10. Hard falsifiers and claim disposition

The paper's central claim is rejected or narrowed if any applicable condition
holds:

1. target-only, identifier, passive-signature or generator-aware no-life
   prediction exceeds its ceiling;
2. the legal-history/gold-memory generic thinker cannot solve J/P/X;
3. authentic versus twin/shuffled memory does not change decisions;
4. gains vanish under the byte-identical common deck;
5. gains occur only on R or direct local transfer, not J/P/X;
6. value does not rise from 2x to 8x native as unique causal structure grows;
7. old retention falls while new acquisition rises, or vice versa;
8. raw RAG, native graph, program induction, skill memory, or direct-QA LoRA
   matches/wins under its honest native interface;
9. compiled LoRA loses to the identical compiled text corpus beyond the
   registered noninferiority margin;
10. the apparent effect requires recognition menus whose construction scans
    all lifetime atoms or encodes the answer;
11. adapter rank/bytes must grow linearly to preserve the result;
12. a schema is first proposed after seeing target or confirming outcomes;
13. schema value remains when local atoms are sufficient, or appears equally
    in the structure-destroyed control;
14. later evidence quality does not improve under authentic memory assignment;
15. better collection does not yield better later memory and sealed action;
16. recurrent sleep does not beat one matched end-of-prefix batch, if cadence
    is claimed;
17. masking/twin substitution leaves the decisive action unchanged across
    credited constructive traces;
18. one mechanism pack drives the aggregate result;
19. output repair, hidden retries, target-conditioned candidate generation, or
    offline verifier feedback enters a scientific cell;
20. unique structure/causal depth plateaus while only transcript length grows.

Dispositions should be explicit:

- graph wins: report a lifetime benchmark and negative phase diagram; no
  parametric moat;
- compiled text wins but LoRA loses: compilation/external-memory result only;
- common deck passes but on-policy fails: representation/use only, no flywheel;
- J passes but P fails: connected recall/composition, no abstraction;
- P passes only with the explicit program solver: benchmark is valid but DREAM
  has not learned the schema;
- one pack passes: domain-specific result;
- no post-native slope: retention at best, not development.

## 11. Minimum promotion sequence

The smallest scientifically coherent sequence is:

1. CPU-only generator, leakage, exact legal-history, target necessity,
   counterfactual twin, selection-conditioned Bayes and isolation gates across
   all three packs;
2. text-only gold-memory thinker factorial on J/P/X;
3. text-only learned compiler versus raw RAG, native graph and explicit program
   induction on a small DEV common deck;
4. identical-corpus text-versus-LoRA transport at one post-native cut;
5. locked common-deck confirmation at three post-native cuts;
6. randomized on-policy collection and reconsolidation confirmation;
7. only then, optional scheduler/LOOP learning or external-environment transfer.

Failure at a stage stops the next expensive stage. Passing CPU mathematics does
not authorize a model call. Passing fixed-deck transport does not authorize a
flywheel claim. Passing RML does not by itself establish open-ended continual
learning, human-like development, a learned thinker/dreamer, or general
intelligence.

## 12. Bottom line

The minimum decisive replacement is not a larger symbolic crafting table. It
is a randomized longitudinal action experiment in which the life genuinely
changes what the agent can know, authentic memory changes what the agent does,
those actions change what it later knows, and a sealed later goal requires a
connected old-to-new causal model that no episode, transcript window, graph of
witnessed edges, or stored plan directly contains.

Anything less can still be a useful systems diagnostic. It is not the paper's
thesis.
