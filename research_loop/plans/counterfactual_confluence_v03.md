Semantic World v0.2 remains an auditable factor-composition diagnostic, but
its D3 answer has a target-local shortcut. The unordered pair of the two
public target outcomes deterministically identifies the held-out outcome. A

Therefore v0.2 answer accuracy cannot establish a causal
dream -> per-life LoRA -> thinker path. Preserve existing v0.2 results and
parent-set ceilings, but do not use them as the organism headline.

## Arrow under test

```text
temporally dispersed action/outcome experience
  -> recurrent one-edge dream growth
  -> connected per-life memory
  -> identical text/LoRA access
  -> goal-conditioned path traversal and counterfactual reconstruction
  -> held-out decision
```

Dreaming owns local connection and compression. The per-life LoRA owns
persistence/associative access, not structure discovery. The thinker owns the
temporary goal-specific causal hypothesis and final counterfactual. The result
is attributed to the whole trajectory unless an ablation isolates one organ.

## Minimal generator change

Keep the existing six source lands, three latent animal roles, pigment-sum
operator, skins, workshop, and D0--D2 tasks. Replace v0.2 targets with paired
counterfactual targets constructed from collisions.

1. Enumerate all source subsets of sizes 2--6.
2. For a subset `P`, define the exact, unnormalized passive signature
   `S(P)` as the three role-wise pigment-count vectors.
3. Select distinct `P0, P1` with `S(P0) == S(P1)`.
4. Select a discriminator source `s` whose membership differs between `P0`
   and `P1`, and for which blocking `s` produces different normalized outcomes
   for every eligible goal role.
5. Balance a latent bit selecting `P0` or `P1`; split the complete latent
   collision tuple, never its skins, across development and held-out sets.

This construction exists in the current source world. Seed 0 has 11 exact
collision classes and 111 `(P0, P1, s)` discriminator choices. This count must
be regenerated and audited rather than hard-coded.

## Public lifetime

Every target has byte-identical passive target observations across its paired
latent worlds. The distinguishing evidence is a temporally dispersed lived
intervention:

- early: an opaque valve `V` is observed to route the stream from source `s`;
- much later: closing `V` produces categorical `CHANGE` or `STABLE` at target
  `T`;
- separate source episodes establish role-specific source colors;
- separate animal episodes support the goal animal's role equivalence;
- separate target episodes establish passive baseline outcomes;
- workshop episodes map all baseline and counterfactual ratios to public
  labels.

Never place source, valve, intervention effect, target, and goal-animal role in
one episode. Replace the repeated Candyland buffer with other informative
targets, distractors, exceptions, and interventions. No contiguous allowed
context window may contain every proof leaf.

Each atomic observation, valve map, intervention effect, and passive target
role is its own episode, unless a frozen scheduler explicitly allocates more
than one duplicate-guarded WAKE operation to a multi-row episode. The current
one-WAKE-per-multi-row exposure is not acceptable.

## Goal and required reconstruction

The goal is:

```text
If source s's stream is closed, what color/state will non-anchor animal a
have in target T?
```

The paired worlds have identical passive target rows and identical goal text,
but different answers. The public proof path is:

```text
a -> matching role anchor
s -> role-specific pigment contribution
s <- V -> CHANGE/STABLE at T
T -> passive role baseline
remove s contribution iff CHANGE
counterfactual ratio -> workshop label
```

The clean thinker builds this query-specific counterfactual in working state.
It never needs the complete parent set.

## Legal recurrent memories

Each durable node contains one local edge, for example:

```text
V routes s
V effect_on T CHANGE
a same_role anchor
s role_r_color c
T baseline_role_r ratio
s link_state T ACTIVE
```

The last edge may be a depth-2 reactivation over the valve edges. A full
parent list, complete target factorization, or final counterfactual answer is
forbidden. Include an arm that also forbids all direct target-parent membership
edges; success there attributes reconstruction to local factor memories plus
the thinker rather than a serialized solution.

Reactivation must branch over a predeclared uncertainty/salience frontier or
balanced node schedule. Always selecting the newest node is only a calibration
ablation, not the principal recurrent condition.

## Mandatory CPU invariants before a GPU run

Audit at least 1000 paired latent worlds:

1. `collision`: `S(P0) == S(P1)` for all roles while `P0 != P1`.
2. `counterfactual_separation`: blocking `s` changes the paired answer for
   every eligible goal role.
3. `passive_twin_hash`: hiding the causal-effect episode leaves identical
   target rows and identical goal text across twins.
4. `signature_ambiguity`: one visible target row, two rows, and the complete
   passive target signature each map to at least two counterfactual answers.
5. `target_local_ambiguity`: target baseline, target surface, and goal surface
   alone remain answer-ambiguous.
6. `single_episode_ambiguity`: no individual episode plus goal is
   answer-sufficient over the audit population.
7. `temporal_gap`: every proof spans at least three nonadjacent episodes and
   exceeds the declared working-context observation budget.
8. `parent_free_oracle`: a CPU oracle using only public atomic edges scores
   1.0 without accessing a parent-set/list representation.
9. `balance_and_split`: CHANGE/STABLE, answers, roles, collision classes, and
   discriminator lands are balanced; surface names do not predict answers;
   every skin of a latent tuple stays in one split.

Failure of any invariant blocks GPU execution.

## Required baselines and gates

- majority and goal-only;
- passive-target-only and pair/single-signature lookup;
- target+effect with the valve-source bridge removed;
- all evidence except animal-role history;
- last-window and oracle-window;
- raw iterative episodic RAG;
- connected text and shuffled valve/source or valve/target edges;
- identical connected corpus in a per-life LoRA;
- gold atomic-edge iterative thinker.

Whole-loop gain is interpretable only when target-local and single-episode
controls remain at floor, the parent-free gold thinker scores 1.0, connected
text beats shuffled/raw memory at matched reads, and connected LoRA matches the
text arm's atomic read fidelity closely enough for downstream attribution.

This remains a controlled scripted-lifetime calibration. It introduces action/outcome
evidence and counterfactual decision value, but it does not yet demonstrate a
policy choosing information-gathering actions or an improving experience
distribution. It also lacks a thinker -> non-evidentiary agenda -> later dream
-> memory refresh -> rethink transition. Those remain v0.3-R and Action World
requirements.
