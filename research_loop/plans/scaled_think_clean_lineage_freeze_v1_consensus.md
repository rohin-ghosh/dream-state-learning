## Adjudicated architecture

The organism still has only three cognitive operations:

```text
THINK: state -> possible routes -> child-authored synthesis -> action/outcome
DREAM: reconcile the working checkpoint against the lossless ledger
SLEEP: mechanically compile eligible lived transitions -> write/gate LoRA
```

Infrastructure such as the task scheduler, router, parent, principal, ledger,
compiler, evaluator, and rollback controller is not a new cognitive organ.

A local stop closes a route, state, subtask, task, or goal. It never terminates
the life. The next transition is an assigned situation, a resumed goal, or a
bounded quiet-reflection state in which the child may form a viable self-goal.
Only the harness pauses the organismal stream.

Continuity is not a metaphor. One child is identified by its immutable birth,
mechanism version, adapter head, promoted corpus head, lossless ledger, typed
working checkpoint, active goal stack, SLEEP count, and root-local parent
state.

## Branch semantics

A thought branch is a context-isolated stochastic route from one immutable
parent state. It is not another child, classroom, lineage, root, or independent
sample. Branch count is never statistical `n`.

The first implementation candidate is deliberately shallow:

1. snapshot one state;
2. produce bounded alternative routes without shared-world side effects;
3. summarize each route with its status and uncertainty;
4. randomize route order;
5. let the same child perform one JOIN; and
6. commit one next action to the real world.

If a route needs an action, it is a proposal/simulation unless executed in an
explicitly isolated counterfactual world. The learned target is not “always
branch.” It is choosing when to deepen, branch, join, reflect, or act inside a
generous but hard external envelope.

## DREAM and SLEEP boundary

The ledger preserves all route text with goal/state/branch provenance, even
when abandoned or contradicted. Recording does not turn a route into belief.

DREAM is THINK used for context management: recent tail + typed checkpoint +
lossless recall. It may preserve disagreement or author a new synthesis. It
does not delete ledger history or write weights.

SLEEP remains deliberately dumb. THINK/JOIN/DREAM or public world provenance
must already mark scope, polarity, uncertainty, support, and status. SLEEP may
select, exactly deduplicate, organize, replay, paraphrase, write, and gate; it
may not decide which unsupported branch was true.

The common candidate write unit is a grounded state transition:

```text
opening checkpoint -> child thought/synthesis -> committed action
-> public outcome -> child post-outcome review -> next-state consequence
```

JOIN is one subtype. Raw routes, parent text, pre-outcome speculation, and
ungrounded quiet reflection are loss-masked/noneligible by default. A
parent-elicited lesson or self-goal may become eligible later only after uncued,
situation-selective enactment tied to an outcome and child-authored review.

## Clean child and contamination

Every final-gym visit is a one-way disposable descendant. Nothing returns to
the clean child or clean parent: weights, rows, memories, DREAM/SLEEP products,
outcomes, summaries, rankings, selection decisions, or hyperparameter choices
conditioned on sealed performance.

The seed-303 CompilerGym-derived bootstrap artifacts are quarantined as
development-only. They cannot seed a clean CompilerGym child. A clean
bootstrap uses unrelated, family-disjoint, target-blind classroom material
with an exact source manifest.

Changing THINK/DREAM/SLEEP, writer, eligibility, mask, rank, or promotion rules
forks immutable mechanism siblings. Changing subject matter or pedagogy while
mechanics stay fixed continues the same child. Siblings and roots never merge
weights or personal evidence. Parallel classrooms are a separately labeled
data-parallel treatment, not automatically “one natural life.”

## Bootstrap purpose and clean comparison

Bootstrap is inherited schooling, not parenting and not the child's personal
experience. It installs conditional meta-habits that help the child make and
revise its own grounded rules: plan, expose uncertainty, choose what more to
think, act, judge, review, and carry a consequence into the next state.

It must not encode final-task skill, fictive observations, first-person foreign
autobiography, or a literal developmental-age schedule. The primary bootstrap
comparison is structure-heavy metacognitive schooling versus equally active
non-metacognitive schooling; no-bootstrap and form-matched sham are diagnostic
anchors. Bootstrap-only, parent-only, both, and neither separate entry behavior
from parenting acceleration.

More PLAN/REVIEW tokens are not success. Three readouts stay separate:

1. entry policy immediately after bootstrap;
2. later responsiveness/learning rate under parenting and new experience; and
3. later uncued formation or revision of a useful rule on a fresh surface.

## Evidence ladder

1. **Plumbing:** prove isolation, provenance, exactly one trunk action, exact
   token accounting, and no branch/world leakage.
2. **Topology:** compare a visible serial depth chain with isolated sibling
   routes, both ending in the identical JOIN, matched on generated route +
   review + JOIN tokens. Log repeated-prefix input tokens, calls, latency, and
   FLOPs separately.
3. **Practical package:** compare frozen current THINK with the selected
   branch/JOIN package under the same generous total envelope. Measure public
   cumulative value plus throughput, action rate, ritual, calibration, and
   protected harms.
4. **Write-carried development:** on matched mechanism siblings, use
   no-SLEEP disposable NEW_COMMIT/NO_NEW_COMMIT descendants after context reset
   and on fresh surfaces. Gate/safety panels, development endpoints, and final
   transfer sets are disjoint.
5. **One longer runway:** imprecision receives more roots at the same horizon;
   only delayed, binding-sensitive, adapter-dependent, action-facing change
   without harm buys one prebound longer continuation of every safe root. No
   second horizon extension. Passed transfer moves to fresh-root confirmation.

Route diversity, fluent self-reflection, row likelihood, marker compliance,
or writer storage alone never authorize scale or a metacognition claim.

## September 11 freeze ruling

Freeze a safe reference and fork seam, not every developmental idea.

The reference must bind:

- exact base/tokenizer and immutable birth;
- response-masked native compiler/trainer path;
- rank, dose, seed, optimizer, replay, and admission rules;
- separate adapter-head and corpus-head candidate promotion;
- rejection quarantine and atomic rollback to the previous child;
- disjoint writer gates, developmental probes, and final holdouts;
- state/task/goal boundary semantics and carried checkpoint;
- clean-child provenance and one-way evaluation descendants; and
- ordered claim/evidence/stop rules.

Current R2/RP/R3/R4 lives use the legacy bare-text writer. They characterize
failure and parenting/gating behavior but cannot certify the intended
response-masked writer. The recommended reference therefore starts a new clean
writer lineage; it does not silently mutate those lives.

Branch/JOIN, adaptive plasticity, opinion conversations, learned branch count,
and head-node classroom parallelism do not enter the reference merely to meet
the date. The reference exposes a clean mechanism-fork seam. Branch/JOIN may
enter only as a separately ratified sibling after its exact visibility and
SLEEP rules pass the architecture gate.

## Remaining blocker before an expensive child

The single blocking issue is an end-to-end writer transaction that proves the
evaluated child used the response-masked path and that a rejected candidate's
adapter **and corpus** cannot influence later life. Until that exists, the
system can store text and change behavior, but it cannot safely preserve one
continuous child.
