# RML end-to-end scientific traceability audit

**Scope:** science-first audit of the frozen RML design while Candidate B D0 is
implemented. This is a review artifact only. It does not modify or authorize
subject code, Stage B, a model/GPU run, LoRA training, locked science,
on-policy work, or a paper claim.

## Executive verdict

**The currently authorized experiment does not test Rohin's intended loop.** It
tests only whether one CPU world has the required information geometry. A green
Candidate B can establish deterministic instrument conformance, connected J
and grammar-conditioned P headroom, exact references, leakage bounds, and
isolation. It contains no learned wake thinker, learned dream, sleep compiler
comparison, LoRA, recurrent read, model context, or on-policy action.

**The full RML proposal could test most of the intended loop, but not yet as
bound.** It names action/outcome experience, THINK/DREAM/SLEEP, same-corpus
text/LoRA transport, recurrent reconstruction, post-native checkpoints, and an
on-policy randomized stage. Its fixed-deck ladder does not yet bind the key
intervention from authentic wake traversal traces to later sleep selection and
compilation. The latest one-resolver/sleep-compiler document requires that
factorial, but it is an unratified discussion proposal and explicitly does not
supersede the controlling organism plan. It cannot be credited as an
experiment already present in RML.

Without the trace and compiler ablations, a positive RML result is explained by
this simpler system:

```text
scripted truth-table experience
-> explicit graph/program extraction
-> deterministic multi-view compiler
-> recognition-assisted local lookup
-> prompted graph traversal
-> later action
```

That is a legitimate controlled memory system, but it is not evidence that wake
thinking created connected experiential traces, that a distinct sleep process
added structure, or that LoRA compressed and recurrently reconstructed a lived
world. The architecture itself says the explicit semantic graph is
authoritative and LoRA is a derived access view. The paper must use
**goal-conditioned reconstruction**, not invertible “decompression,” unless a
separately defined compression experiment passes.

A narrow fixed-deck systems paper can begin at G4. Rohin's complete
action--experience--memory flywheel requires G5.

The central traceability defect is therefore not lack of prose. It is lack of a
causal variable for the wake trace. A log that is merely stored for future
LOOP-policy training does not show that the current sleep compiler used it or
that its connectedness mattered.

## 2. Minimum G1--G5 pipeline

Each stage requires a new predecessor-bound exact release. The present D0
authority stops before G1.

### D0 prerequisite: CPU instrument only

Candidate B Stage A, four-pair Stage B, and the conditional 64-pair gate remain
the prerequisite. CPU may implement and run the generator, exact transition
system, legal-history/program/schema controllers, Bayes-N, leakage probes,
chronology, canonicalization, certificates, isolation, and resource accounting.

Pass means every registered Candidate B gate passes, including legal-history
value `1`, shortcuts/Bayes means `<= .35`, p90 `<= .45`, P graph `1/4`, P
schema/program `1`, every J cut `0`, exact source counts and BE equality, and
run/skip identity. This does not count as G1 evidence.

### G1 — model-usable gold reconstruction

**Purpose:** prove that a frozen model controller can use sufficient local
semantics without a stored solution.

Minimum arms:

- no lifetime memory and exact no-life Bayes;
- gold local atoms with all queries committed before reads;
- identical gold atoms with generic recurrent anchor-only reads;
- witnessed graph without P schema;
- supplied schema/program search;
- hidden legal-history ceiling.

Add X/revision only in the separately bound model-facing world; it is correctly
excluded from D0. Direct records and individual reader returns must contain one
local relation, never a plan.

Exact go gate:

- legitimate direct-record closure is exactly `0`;
- generic recurrent gold action value is `>= .85` separately on J, P, and X;
- certified constructive-proof rate is `>= .80`;
- nonadaptive gold value is `<= .35`;
- masking the complete cited memory cut changes the decisive operation, and
  matched twin substitution yields the twin-valid operation, on `>= .80` of
  credited successes;
- missing-edge fixtures defer/request evidence rather than fabricate;
- every selected model-native cut is recertified by CPU after exact model,
  tokenizer, chat template, workspace, and output reserves are frozen.

**CPU:** native-cut projection, gold memories, exact program/Bayes controls,
proofs, masks, scoring.  
**GPU/model inference:** the frozen recurrent resolver.  
**Failure:** invalid model-facing construct; do not proceed to learned memory.

### G2 — wake trace, DREAM, and evidence-bound text compilation

**Purpose:** identify whether authentic wake traversal and offline
cross-episode reorganization add useful supported structure before weights are
involved.

The smallest nonredundant text matrix is:

1. `compiler_only`: eligible witnessed/accepted semantics, deterministic
   deduplication and multi-view writes, no resolver-created edge;
2. `wake_only`: authentic wake traversal candidates compiled without DREAM;
3. `replay_only`: sleep selects/replays but proposes no cross-episode relation;
4. `shared_cross_episode`: shared resolver uses authentic wake traces and
   cross-episode re-derivation, then durable compilation;
5. `shared_shuffled_trace`: same trace counts, types, frequencies, budgets, and
   grouping, but paired other-life or within-type shuffled bindings;
6. `shared_no_durable_write`: identical search and scratch candidates, with no
   semantic commit;
7. `specialized_cross_episode`: separate DREAM and THINK resolvers at matched
   calls/tokens.

The primary external-memory baselines in the same fixed deck are honest native
context, hybrid raw episodic RAG, hierarchical reflection, native A-MEM, exact
witnessed graph, explicit generator-aware program induction, and procedural
skill memory. Common-reader versions are secondary protocol controls; native
interfaces are primary competitors.

Exact go gate:

- zero admitted claim depends on a target, agenda answer, unsupported
  workspace, critic approval alone, future evidence, evaluator, or hidden
  truth;
- every positive claim was committed before its distinct confirming public
  outcome and has mechanically valid root provenance;
- the full text condition recovers `>= 70%` of the gold-memory gain over no
  memory and is no more than `.10` below the strongest native external baseline
  on every critical DEV stratum;
- authentic trace versus shuffled trace loses at least
  `max(.15, .5 * G_trace)`, where `G_trace` is the full authentic-trace gain
  over no trace and must be positive;
- durable write versus `shared_no_durable_write` has mean action-value
  advantage `>= .10`;
- to credit a residual DREAM mechanism, `shared_cross_episode` must exceed both
  `compiler_only` and `replay_only` by mean `>= .10`; confirmation later must
  put a simultaneous one-sided lower bound above zero;
- to claim one shared resolver is adequate, it must be noninferior to the
  specialized condition with margin `-.05`. Superiority requires a lower bound
  above zero; noninferiority does not imply sharing is better;
- accepted-edge precision, accepted-edge coverage, false-memory use, and final
  action are reported separately. A final success cannot hide an unsupported
  edge.

If compiler-only matches the full condition, delete the wake-trace and DREAM
content claims. If specialized wins outside `-.05`, delete the one-resolver
claim. The bundled text system may still proceed if it clears the external
baselines.

**CPU:** taint/chronology/provenance engine, deterministic compiler, fixed text
backend, exact graph/program baselines, scoring.  
**GPU/model inference:** wake resolver, DREAM variants, A-MEM/reflection model
calls, recurrent text thinker.  
**Failure:** no LoRA training.

### G3 — same-corpus LoRA transport and recurrent reconstruction

**Purpose:** separate semantic content, parametric transport, reader
assistance, and controller-side composition.

Freeze one admitted semantic atom set before either substrate sees evaluation.
Compare:

- identical compiled text through the common reader;
- recognition-assisted compiled LoRA;
- strict-parser unaided generative LoRA;
- direct trajectory-to-QA LoRA;
- raw-event LoRA;
- clean base, binding-shuffled LoRA, twin/cross-life adapter, and oracle-atom
  LoRA ceiling.

Cross the frozen corpus with nonadaptive, generic recurrent, and gold-read-plan
controllers. Later queries receive an anchor from an earlier public field,
outcome, or read; a target-specific typed query is a labeled scaffold ceiling.

Exact go gate:

- fixed-query local-read fidelity is `>= .90` at every registered cut;
- `E-LoRA - E-text >= -.05` under simultaneous paired bounds;
- generic recurrent exceeds nonadaptive at mean `>= .10`, later queries
  actually use earlier read values, and certified proof rate remains `>= .80`;
- direct-record closure remains zero and the mask/twin causal-use gate remains
  `>= .80`;
- intact LoRA loses at least `max(.15, .5 * G_LoRA)` under the matched binding
  shuffle, with same-direction twin and cross-life losses;
- direct-QA/raw LoRA, clean-base, unaided generation, candidate enumeration,
  adapter rank/bytes, train/query tokens, FLOPs, and latency are fully reported.

This gate permits only: *the admitted corpus retained action value in per-life
weights*. LoRA superiority requires a preregistered superiority contrast. A
compression claim is still forbidden unless G4 keeps adapter bytes/rank fixed
as unique causal content grows and the read path performs no hidden linear scan
over a growing candidate catalog.

**CPU:** corpus freeze/diff, training-manifest checks, provenance, exact reader
fixtures, scoring/statistics.  
**GPU:** LoRA training, 7B reads, 32B resolver calls.  
**Failure:** publish text/graph/compiler or negative transport; remove the
weights clause.

### G4 — three-pack post-native common-deck confirmation

**Purpose:** show fixed-experience acquisition, retention, and constructive use
over genuine lifetime growth rather than a short mapping table.

Minimum design:

- fluid/thermal, power/control, and material/biological packs;
- at least eight new counterfactual world-life pairs per pack (`>=24` total);
- two adapter seeds averaged inside each world, never treated as replication;
- `0.5, 2, 4, 8 * L_native`, with the last three strictly beyond the model's
  exact usable native context;
- fresh N/O/J/P/X targets at every checkpoint and increasing unique roots,
  local relations, old/new interactions, and prospective predictions in every
  interval;
- the G2/G3 system arms plus native context, RAG, reflection, native A-MEM,
  exact graph, explicit program induction, procedural memory, direct-QA LoRA,
  batch SFT, no memory, Bayes-N, and legal-history ceiling.

Exact paper gate:

- every pack has a positive point estimate and no world/target/seed is replaced;
- the full system's post-native AUC exceeds every declared primary native
  baseline by mean `>= .10`, with simultaneous one-sided world-pair lower
  bounds `> 0`;
- at `8x`, each of N/O/J/P/X recovers `>=70%` of its gold-memory gain and its
  corrected contrast to its strongest baseline has lower bound `>0`;
- O at `8x` is noninferior to O at `2x` with margin `-.05`, while N and J/P are
  positive at all three post-native cuts;
- authentic binding/twin/cross-life controls pass the half-gain rule;
- the selected adapter rank and physical adapter bytes are fixed from `2x`
  through `8x`; otherwise delete fixed-substrate compression language;
- failed science cells remain zero-valued and all compute/capacity vectors are
  reported.

Call a baseline saturated only when both later-interval improvement upper
bounds are `<= .02`, oracle headroom is `>= .10`, and unique causal information
continues to grow. Without three strictly post-native cuts, delete context,
growth, crossover, saturation, and lifetime compression language.

**CPU:** generate/recertify worlds and native cuts, exact controls,
compiler/provenance, scoring/statistics.  
**GPU:** every model baseline, learned trace/DREAM/text arm, LoRA train/read,
resolver evaluation.  
**Pass claim:** bounded fixed-deck experiential representation/use over RML
lifetimes. No memory-directed experience-acquisition or flywheel clause.

### G5 — randomized on-policy flywheel

**Purpose:** test the missing causal link from memory to future experience and
back to later memory/action.

At a post-native source snapshot, randomize authentic, null,
binding-shuffled, or counterfactual-twin memory **before** any new observation.
Allow an equal-budget information-gathering block, admit only its ordinary
public outcomes, run exactly one frozen consolidation, and evaluate a
pre-generated sealed later target. Cross each collected public trace through
compiled, RAG, native-graph/program, and direct-QA representations to separate
experience quality from representation/use.

Exact flywheel gate, versus the strongest randomized control:

- pre-outcome information-seeking actions differ at family-wise `alpha=.05`;
- target-relevant information gain/coverage improves by mean `>=.10` with
  simultaneous lower bound `>0`;
- later supported-memory quality improves by mean `>=.10` with lower bound
  `>0`;
- later sealed action value improves by mean `>=.10` with lower bound `>0`;
- final action gain loses at least `max(.15,.5 * G_onpolicy)` under binding or
  twin assignment;
- the collector/representation cross identifies experience quality and
  representation/use separately.

If any link fails, report the passing links and delete the flywheel clause.

**CPU:** environment clones, randomization, state hashes, consolidation
admission, sealed targets, causal estimators.  
**GPU:** on-policy resolver actions, learned memory systems, LoRA training and
reads.  
**Pass claim:** bounded memory-directed evidence acquisition and later action
inside RML. It still does not establish a learned resolver, autonomous
scientific taste, open-ended continual learning, or external validity.

## 3. Benchmark features that favor graph/program solving or lookup

### Candidate B / D0

1. **The source is a reset-panel truth table.** Dense modules enumerate every
   conditioner output twice, every valve family at every mode, and every
   exchanger at every coolant pair. The “actions” render table entries; a
   graph extractor receives unusually clean supervised mappings.
2. **The latent family is finite and explicit.** The schema channel is one of
   24 affine laws and E0's three descriptors determine it exactly. P is
   deliberately grammar-conditioned interpolation. An explicit program
   enumerator is the natural optimal method.
3. **Targets expose lookup anchors.** Four conditioner family handles, one
   exchanger family, and one valve family reduce the consequential choice to
   two SET bindings plus one mode. Most of the nine actions are logistics, not
   dependency depth.
4. **Target construction guarantees `r=u xor 11`.** Every inventory contains
   the useful setters, so the hard problem is identifying their labels. This is
   excellent for leakage control but close to a keyed mapping task.
5. **The semantic skin carries zero mutual information by design.** This blocks
   pretrained shortcuts, but also makes the task closer to nonce binding than
   semantically grounded maintenance learning.
6. **D0 has only 24 modules, 285 witnessed mappings, 996 short events, and no
   model.** Its K0--K3 cuts are structural only. It cannot establish that a
   transcript exceeds any model's context and is mechanically forbidden from
   native/post-native language.

These are acceptable D0 properties because D0 is a microscope. They are not a
paper-world validation result.

### Full RML

1. **The authoritative memory is an explicit semantic graph.** The
   one-resolver proposal explicitly treats LoRA, RAG, and indexes as derived
   access artifacts. If the native graph/program solver wins on value, bytes,
   or compute, the evidence favors explicit structured memory.
2. **SLEEP may be deterministic graph compilation.** Without compiler-only and
   no-dream arms, a writer's apparent “dream” gain can be canonicalization,
   deduplication, or multi-view supervision.
3. **Recognition-assisted LoRA can hide external search.** A target-blind
   candidate catalog can still scan all lifetime atoms. If candidate work is
   `O(lifetime)`, performance is an external-search result, not scalable
   parametric reconstruction.
4. **The prompted resolver supplies composition.** Generic recursive queries,
   candidate recognition, workspace updates, and clean-base reasoning may do
   all multi-hop work. LoRA then stores local labels only. This is acceptable
   transport, not evidence of reasoning in weights.
5. **Prospective laws reward program induction.** If production grammar is
   public and small, an explicit program learner should be strongest. A schema
   discovery/compression claim needs held-out productions or grammar families,
   prospective commitment, and atoms-only controls.
6. **Repeated views can mimic lifetime growth.** More paraphrases/touches of a
   fixed relation increase training exposure without increasing world
   information. Only unique roots/relations and new/old/cross-era targets count.
7. **Fixed decks do not test learning what to do to learn.** They isolate
   representation/use but cannot support action-directed experiential
   acquisition. Only G5 closes that arrow.
8. **Context overflow is currently prospective.** RML's `0.5/2/4/8x` schedule
   is sufficient in design only after the exact model stack defines
   `L_native`, every interval adds unique causal content, and the native-long-
   context arm actually runs. Padding or repeating a solved module does not
   count.
9. **Fixed adapter bytes alone do not prove useful compression.** The semantic
   audit graph, candidate catalog, compiler corpus, training compute, and clean
   base remain external resources. Report the complete resource vector and the
   minimal exact sufficient-statistic bytes.
10. **Three rendered packs remain synthetic.** They can support a controlled
    mechanisms paper. Without a standard-environment result, do not claim
    external or general agent learning.

| residual DREAM | no dream/compiler-only; replay-only; cross-episode re-derivation; breadth/depth bias; shuffled episode grouping |

These are not one giant Cartesian sweep. G1 fixes controller usability; G2
identifies trace/DREAM/compiler in text; G3 freezes content and changes
substrate/reader; G4 changes lifetime and pack; G5 changes experience
distribution. Freezing the intermediate artifact at each handoff is what makes
the ladder identifiable.

## 5. Claim decision

The intended causal sentence becomes traceable only if all five stages pass:

> Under randomized rendered lifetimes, a frozen wake resolver produced
> selection-only connected traces; evidence-bound sleep reorganization added
> chronologically supported reusable structure beyond compiler and explicit
> memory baselines; a fixed-size per-life adapter retained that corpus's value;
> recurrent goal-conditioned reads causally supported later actions; and
> authentic assigned memory improved subsequent evidence, reconsolidation, and
> sealed later action across post-native lifetimes.

Every clause has an independent deletion rule:

- G2 trace/shuffle failure: delete wake-connected-trace credit.
- G2 compiler/no-dream tie: delete residual DREAM credit.
- G2 shared/specialized failure: delete one-resolver credit.
- G3 same-corpus failure: delete the weights clause.
- G3 candidate-scan or G4 fixed-capacity failure: delete compression/scalable-
  reconstruction language.
- G4 graph/program win: report explicit structured memory as the winner; no
  parametric-memory moat.
- Fewer than three post-native cuts: delete lifetime/context/saturation claims.
- G5 failure: delete learning-from-actions and flywheel claims.

As frozen today, only the D0 instrument-conformance clause is authorized and
reachable. The one-resolver/sleep-compiler mechanism is scientifically
promising but remains a future, separately ratified experimental factorial—not
evidence already supplied by RML.
