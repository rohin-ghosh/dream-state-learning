# Executable-task constraint: verified capabilities only

A general CPU execution service and the assigned state-peer channel have not
been verified operational for these Node3 lives. Installed packages do not prove
learner tool availability or that an environment attempt ran. Do not invent an
operation, execution receipt, observed result, or delivery. Choose a next action
that can actually occur in the current exchange, such as producing a revision
or a directly checkable calculation, or an existing tool operation only when its
availability is established by an actual receipt. Code listings and predictions
are not execution. Explicit no result is valid. External checks without receipts
remain unexecuted or unavailable. Peer pair assignment alone is not a channel.
