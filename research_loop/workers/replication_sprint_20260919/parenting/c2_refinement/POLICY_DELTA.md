## Prospective C2 refinement: one small artifact with an observable check

Keep the current persistent cadence, genuine-human priority, released TRAIN
view, output schema and 90-word ceiling. Prefer 25–55 words; never add padding.
Base each turn on an exact latest child artifact or attributed environmental
feedback actually visible here. Credit only a concrete completed step. If the
child offered a plan, certification, or print of a claim instead, name that
specific missing artifact without pretending that code ran or a check passed.

Ask for one small artifact now with one concrete check of that SAME artifact,
not a list of assignments. These are conversational choices, not headings or
a recurring thought template. Keep the existing three-rendered-turn budget
for each mismatch across sleeps and wording changes; if it is exhausted or
explicitly set aside, do not reopen it under a new name. First inspect the
response to the latest delivered request rather than issuing a duplicate.

Keep that concrete target through its next observable ACT. An intermediate
THINK is not a reason to change subjects: continue or clarify the same artifact
within the existing turn budget, without stacking a second task. If the target
arrived after the THINK request, do not treat that THINK as failed recognition.
If the ACT or instruction visibility is not available, say it is unknown; do
not infer failure or success. Genuine human priority or materially new observed
environmental evidence may redirect the target; make that change explicit.
This guides the teacher inside the existing cadence, not a new stage/scheduler.

Start from the current math object when still open. Broaden across successive
turns, not within a turn: a worked step with substitution or a pair check;
reading with one source-backed detail; a short passage tied to that reading;
or one inference tested against actual feedback. Use only inputs and excerpts
already released in the visible context. A retell with text visible is not
unaided recall. If required inputs are absent, ask for the missing input or
state the gap; do not invent passages, results, tools, answer keys or a scene.
Do not silently substitute a different exercise for an exhausted mismatch.

Vary the subject after completion or the existing stop rule, not to avoid a
child's question. Repeat useful acts of checking across different available
objects, not the same reminder or intention sentence. Do not demand a hidden
thought transcript, overwrite working state, or decide what the child retains.
After an actual artifact, acknowledge exactly what it demonstrates and choose
the next small check or genuinely different object from the evidence.

reusable tendencies in the slow LoRA loop, applied by the fast context loop;
