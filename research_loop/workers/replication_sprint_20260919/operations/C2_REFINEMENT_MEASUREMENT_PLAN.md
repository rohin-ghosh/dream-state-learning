# Prospective C2 parent-policy refinement measurement

September 19, 2026, 14:19 UTC. Proposal recorded before candidate deployment.
No deployment or positive outcome is claimed by this document.

## Question and scope

Can shorter, grounded parenting obtain an actual requested artifact and a
concrete check from the current C2, where recent visible corrections did not?
Use one available object per turn; do not bundle several unanswered tasks.
The parent may vary subjects using only already released information. Keep
the original model/provider, help opportunity, budgets, native, learning
recipe, authentic rows, human priority and environment feedback unchanged.
The exact addendum and policy epoch must be bound before publication.

This is an exploratory intervention in one continuing life, not a randomized
replication. The observed historical three-C2-opportunity baseline is not a
concurrent control. Improvement would justify another controlled test, not a
claim that the policy or the adapter caused it.

## Prospective window and measures

Select the first six committed ACT opportunities after verified delivery of
the new policy's first parent turn. Keep every selected opportunity, including
ignored requests, intentions, incorrect artifacts and unavailable observations.
Group parent turns that precede the same ACT instead of counting one ACT twice.
An instruction arriving after that ACT's request belongs to a later opportunity.

For each opportunity record parent publication and INBOX identity, THINK and
ACT request/response hashes, exact instruction visibility, requested artifact,
artifact actually produced, relevant check attempted, check correctness, and
any unprompted reuse on a later relevant action. Record concurrent human turns,
sleep/update boundaries, compaction, language and interruptions separately.
Intention-only is a behavior metric, never a training-row exclusion.

Primary readout: requested artifacts produced / all six selected opportunities,
with missing or unobservable outcomes explicitly unknown and separate assessed
denominators. Secondary readouts: correct checked next actions, stable-target
THINK-to-ACT uptake, and reminder-free reuse. Do not score a THINK as failure
to recognize a correction that arrived afterward. A successful artifact with
the answer still in context is not adapter retention.

Use the existing source-bound collector and manual evidence rubric. If fewer
than six ACTs are available, report the exact partial window, not an estimated
rate for six or a cherry-picked best response. No future collection or review
is claimed completed merely because the parent process is running.

The source life is not stopped at six opportunities. A later policy change
gets a new epoch and separate window; do not silently redefine this comparison.
Tapering and learning-rate changes are outside this intervention.
