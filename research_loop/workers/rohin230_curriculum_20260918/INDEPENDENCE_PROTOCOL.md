# R231 parent-absence and generalization observations

Authority: Rohin message 231, relayed 2026-09-18 09:53 UTC. These are development
probes inside running lives, not a new claim that H1/H2 has been demonstrated.
The formal stage schedule remains the parent's standing brief. A probe never
pauses the learner or changes its learning-rate/row policy.

## One bounded probe, then the parent returns

1. Record the life, stage, current object, last completed sleep, effective
   presentation count/rate, latest actual parent rendering and genuine Rohin
   message frontier. Select a small NEW variant of the current verifiable
   task. Retain original tasks and normal tool/feedback access.
2. Log a parent-absence interval of one running cycle initially. Do not send
   nudges, answers or grading keys during that interval. Genuine human turns
   retain priority; if one arrives, label the interval human-assisted rather
   than silently calling it independent.
3. Observe actual THINK and ACT text. Record a concrete error or uncertainty,
   the child's proposed check, any real tool return, the revised artifact,
   and whether the revision precedes all parent feedback. A promise to check
   is not a check; a changed answer without a reason is not verified correction.
4. Record peers and visible earlier teaching. A math-trio correction with a
   peer explanation can be parent-absent but is not unassisted. Reading recall
   with the text still visible is not adapter-only memory. Explicit 'I do not
   remember', unsupported invented recollection, and no answer are separate.
5. Return with a short source-bound question or credit for a real step; if
   the child loops, restore active support. Keep the original absent interval
   and outcome in the record rather than extending it until success appears.

## Minimum receipt fields

- Life/journal, task/variant, curriculum stage and pre-probe checkpoint reference.
- Absence start/end REQUEST indices and hashes; actual parent/human/peer inputs.
- THINK/ACT/Tool/correction indices and hashes; observation versus grading result.
- Outcome: independent correction / peer-assisted / human-assisted /
  parent-assisted / no correction / no opportunity to correct / indeterminate.
- Recall: grounded / honest uncertainty / invented / unrelated-or-no-answer;
  mark whether source text or an answer-bearing transcript was visible.
- Token/opportunity/sleep/update exposure and intention-only ACT count.
- Return-parent INBOX and first rendered REQUEST; no exclusions or life signals.

Do not invent an error or force disagreement merely to satisfy a stage metric.
Do not let random tie-breaking decide mathematical truth. Do not count a
parent-authored answer as the child's discovery. Parent absence is a teaching
phase, not a learner pause. Stage-four plasticity reductions require a logged
successful transition and a bound runtime change; they are not enabled by
this document. An unrelated life or reset does not stand in for a same-life
retention test.
