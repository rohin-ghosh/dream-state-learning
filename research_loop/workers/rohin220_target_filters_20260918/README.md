# R220 own-target question and speaker policies

Builder scope: bounded provenance/eligibility repair under Rohin220 and the
watcher's fabricated-human-turn report. Frozen base, own-words masking, private
evaluation visibility, existing claim boundaries and confinement are unchanged.

## Implemented and CPU tested; runtime adoption is separate

- `question_target_filter = R220_EXPLICIT_FABLE_QUESTIONS_V1` on a NEW own row
  makes a real, unfenced Fable-addressed question content-bearing even when the
  older lexical heuristic classified it as meta-only or uncertain. Actual
  delivery and actual answers require independent channel receipts.
- `fabricated_speaker_filter = R220_FABRICATED_HUMAN_TURNS_V1` quarantines a
  child-authored row containing a line beginning `Rohin:` (including simple
  Markdown variants). It does not claim every quoted line is semantically false;
  a human speaker label generated by the child is not authenticated human input.
- Both require the existing content/review filter and the same child/TRAIN/loss
  masks. Original text, token IDs and source hashes remain unchanged.
- The speaker quarantine takes precedence over the question exception. CJK,
  glyph, repetition, code-wrapped-prose and receipt backstops remain independent.
- Unannotated historical R213 V1 rows retain their original computed evidence.
  No historical training rows, adapters or frozen live source trees are edited.
- Raw parent/human context is not a target and is not passed through these
  own-target rules. No fabricated human turn is delivered by this implementation.
