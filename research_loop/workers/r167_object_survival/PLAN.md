restatement, a distinct angle, a connection to earlier work, why it matters,

## Good-behaviour replay session

Use an existing parented free/parent-guided distillation life. A parent refers
to an actual TRAIN correction or verified result and asks the child to revisit
and extend that same object in its own words, then make a new prediction or
attempt. The child generates the content; real tools return attributed,
masked observations. The ordinary pre-sleep reply consolidates what it now
holds. Label this cadence segment and its source event IDs. Do not duplicate
parent text, edit previous targets, inject probe answers, or silently increase
training repetitions. Additional experience/generation is a logged exposure
change, not an invisible adjustment of the fixed sleep objective.
