## Implemented transition

`interrupted_sleep.py` is a candidate runtime kernel, not another metadata-only
selector. `prepare_candidate` reuses the untouched V2 contract and binds exact
original plan bytes, recipe, eligibility, durable checkpoint and pending-sleep
identity. `finish_interrupted_sleep` provides the following behavior for a
future original confined driver; **it is not connected to any launcher**:

1. Check the externally pinned candidate and exact original plan; require the
   original 16 NEW-only presentations, all-authentic-child-rows policy, no
   preupdate-recovery spoof and no wall-extension configuration.
2. Require an already exclusively opened original journal. Call its full
   `audit()`, match the exact old head and pending saved state, then restore a
   detached original `ContinualStream`. Require lossless round-trip of all
   rows, history, operations, working state and existing sleep receipts.
3. Require the last durable checkpoint's exact COMMIT, paths, experiment and
   adapter/optimizer/RNG hashes. Delegate restore to the original
   `NativeChild(plan, checkpoint)`: saved adapter, parameter-ordered optimizer,
   optimizer count, Python RNG, CPU RNG and all CUDA RNG states, not a fresh
   optimizer/seed or the unsaved scalar UPDATE counter.
4. Consume a stable exclusive attempt directory keyed only by life/journal/
   pending request. It is not freed by config/source changes or failure. Write
   an append-only restart declaration. The declaration does not clear pending.
5. Call the original `child.sleep` once over **every pending row**, passing all
   historical rows unchanged to the original NEW-only selector. Do not call
   generate, prepare_sleep, tools, inbox responders, readouts or run_loop.
   Compare newly emitted recipe/eligibility with the old exact documents.
6. Label each new recipe/eligibility/UPDATE with its recovery epoch. Require
   all 48 new UPDATE receipts, 16 presentations of each of the three sources,
   no exclusions, exact counters and frozen-base/actual-adapter-change receipt.
   The historical uncheckpointed work is recorded separately, not reused.
7. Save into `checkpoints/sleep_<cycle>_restart_<stable-attempt-key>`, a new
   direct-child namespace compatible with the original `*/COMMIT.json` lookup.
   Never overwrite/adopt the old failed checkpoint or an earlier restart.
   Require a complete, verified new COMMIT before calling the original
   `ContinualStream.commit_sleep` and journal SLEEP_COMPLETE transition.
8. Only that original successful publication advances the frontier and model
   reference. Preserve all failure artifacts. An exception or unknown attempt
   never automatically retries or promotes a saved-but-unpublished checkpoint.
   A sidecar write failure after a durable COMPLETE records the returned
   COMPLETE reference when available; it does not undo it or authorize retry.

The old stream passed through the journal is never mutated by the detached
working copy. New recovery failure may leave a new checkpoint/partial or new
journal intent, which must also be preserved. Claim-directory existence alone
blocks retry even if its STARTED receipt could not be written. Original hard
end is checked before load, each callback, save and completion; the original
outer wall/lease enforcement and NativeChild per-update checks remain required.

## Concrete integration blockers / remaining decisions

1. **Astra7 journal7808 partial:** the unchanged original reader rejects
   `00000000000000007808.intent.json.partial`. This candidate does too via the
   required original audit. No skip/delete/rename/copy-tail workaround exists
   here. A separately explicit preservation/reconciliation reader or epoch
   contract must bind the failed attempt, old head, full retained prefix and
   artifact identity without inventing a7808 payload or silently reusing it.
2. **Original startup integration:** installed native resume rejects pending
   post-update sleep; its existing preupdate route is inapplicable. A new,
   bound entry through the original dispatcher is necessary. This kernel does
   not patch it, install a new module, or create an admitted guard. It returns
   one sleep's completed state/checkpoint, not a continuing live-child driver.
   Exact-once paired R184_LEARN_COMPLETE, next-cycle handoff, and existing
   readout/parent observer handling remain to be integrated. No LEARN receipt
   or parent feedback is fabricated here.
3. **C0 namespace adoption:** the new namespace avoids the existing failed
   `sleep_000146` directory. Before real use, bind it in the new guard and
   prove all receiving wrappers/observers accept the original lookup and new
   epoch without treating overlapping nominal optimizer counters as old work.
   C0's failed adapter/truncated86,966,272-byte optimizer and lack of COMMIT
   remain forensic artifacts, not restore inputs.
4. **Fresh evidence/admission:** actual full records/plan inputs are not staged
   into a runnable candidate envelope here. The local evidence contains
   summaries/pins, not the complete pending-state bodies. Before any use,
   retrieve and bind those exact bodies; fresh-audit full journals/intent
   chains and original extension semantics, verify capacity/preservation,
   stable head and absence of the intended old CPU/native owners, and verify
   source/plan/anchor/base/CPU/allocation/lease pins. The selected10 source
   copies are not the full2292/2295-file receiving closures. Supplying an
   arbitrary Python object or a self-signed envelope is **not admission**.
5. **Original confinement remains mandatory:** use only the admitted original
   `gpu.r233_node2_recovery dispatch --config <new-bound-guard>` route once
   integrated, never this file or NativeChild as a standalone GPU entry.
   Old guards/OUTER_STARTED/DISPATCH_ONCE are consumed. Preserve UID/GID2524,
   strict DevicePolicy, NoNewPrivileges, empty capabilities and life-specific
   BindPaths for the shared virtual root. C0 remains slot4 /
   `GPU-d304a15c-516a-16a0-a926-a560304077cc`; Astra7 slot1 /
   `GPU-e7a322fc-fe84-919f-7534-cdfefb6ce1e4`. Preserve fresh privileged
