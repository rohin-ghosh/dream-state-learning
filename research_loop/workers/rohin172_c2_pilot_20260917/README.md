# C2 fixed pilot v1

The configuration is published before activation. It does not assert that a
checkpoint copy, new parent turn, changed compaction, or GPU continuation has
already run. The original C2 remains preserved. Its already-published Rohin
message is not resent; the prior queued Astra turn is recorded rather than
hidden. First rendered exposure, not inbox publication, starts the window.

Four response opportunities, followed by the next completed sleep, fix the
guided endpoint regardless of whether C2 succeeds. At most one additional
Astra question is allowed. Carry content is the child's actual work and real
evidence, not a supplied solution. The two matched copies then have one
explicit context transition and three parent-free wake/sleep cycles, capped
at4,608 generated tokens and4 hours each. ON and OFF differ in sleep updates,
not guidance, copied working state or decoding budget. No further sleep-time
reflection reminders are added during that withdrawal. A missing carry or
timeout remains a failed/incomplete case rather than a reason to change v1.

The match estimates the contribution of updates during withdrawal. Both copies
share the guided-phase adapter, so it does not isolate initial installation of
the lesson. Context persistence is not a weights-only finding. Existing sealed
clean-context probes remain a separate measurement channel.

Required before any actual copy launch: local regression tests for masking,
no-reminder cadence, exact saved-state custody and RNG separation; verified
checkpoint/workspace source manifest; real device confinement and available
budget within the unchanged machine lease. No inferred private memory,
restated parent text as targets, recreated outcomes, or evaluator scores enter
the child. Do not alter the live fleet's carry/sleep recipe through this file.

`watch_guided.py` is a bounded, read-only observer for this unchanged configuration.
It calls only the pinned node wrapper and TRAIN-journal reader, records actual
rendered exposure and committed responses, and flags the first eligible saved
sleep. It never publishes a parent turn, selects a better episode, launches a
copy, or changes the learner. A question-due flag requires review of existing
publication custody before the single permitted follow-up; it is not permission
to resend Rohin's message. Historical traces and status receipts remain in the
observer's new output directory. A partial trace or mismatched source is rejected.
