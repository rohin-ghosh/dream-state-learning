# PPC5r11 fixture proposal

Proposal-only repair namespace. These bytes confer no ratification,
implementation, fixture-execution, model, GPU, seal, or claim authority.

The PPC5r9 fixture universe and oracle are read only to verify their excluded
byte hashes; they are not part of the PPC5r11 replacement universe.  The
quarantine gate scans the entire replacement namespace recursively and rejects
excluded bytes under any basename or nesting depth, plus excluded hashes in
reachable JSON identities.

The proposal contains 58 content-addressed reducer vectors covering T04--T14.
Every reducer law has a closed facts-only input schema, a closed output-tuple
schema (including schemas for embedded canonical JSON), an executable proposal
reducer, exact source-pointer hashes, and no executor-visible expected result.

T08 derives the changed leaf from paired upstream facts. DREAM binds actual
rendered and reference context bytes plus their hashes, derives equality, and
carries neither an answer-selecting boolean nor an input/output ordinal.
T13 validates the closed technical package and performs a genuine Kahn walk of
the exact source-bound authority graph. T14 resolves the ordered 24 predecessor
fact carriers, validates their canonical bytes and same-run binding, derives
the current 11/6/1 typed closures independently from schema and inventory,
executes two self-contained source-hashed replay implementations with no shared
semantic callback, and consumes six concrete self-hashed final carrier objects.
Final carriers are checked for exact type/role/ordinal/run/origin/status/content;
release exclusion is semantic over typed values such as `RELEASE_BYTES`, not
dictionary-key spelling. The failure/source-binding catalog needed to reproduce
the machine is vendored locally with the exact PPC5r9 lineage hash.

These are proposal and validator bytes only. No fixture universe, executor
receipt, conformance result, ratification, run authority, model call, or GPU
action is created here.
