# Paper-1 v03r end-to-end canary v1a

**Status:** exact proposal for deliberation only. No implementation or model,
GPU, LoRA, analysis, replication, or claim authority is implied.

## Decision

Test the smallest honest instance of the frozen Paper-1 organism:

```text
public action--outcome life (final goal absent)
  -> reliable witnessed atoms
  -> recurrent local connection proposals
  -> fresh blind same-model reflection over claim + cited public memory
  -> append-only epistemic history
  -> non-answer operational probe -> one bounded return focus
  -> fixed OWN-return corpus compiled without truth access
  -> fresh bounded text thinker -> paired counterfactual action
  -> if and only if text passes, the same semantic/view/touch manifest
     -> two per-life MEMORY LoRAs -> recognition reads -> fresh thinker
```

This is a held-out paired existence/failure-localization canary. It does not
test lifetime scaling, RML/Action World, learned LOOP adapters, rank pyramids,
base promotion, population reliability, or the Paper-1 headline.

## Scientific commitments

1. The scored unit is the aligned v03r seed-5 latent-bit pair. Both twins must
   be correct. Development is confined to aligned seeds 0--2.
2. The final goal and answer are absent until every M0, return branch, and
   corpus manifest is sealed. The compiler, reader, trainer, and cognition
   never receive private truth or offline results.
3. The transport corpus is prospectively fixed to `M1_OWN`. M0 and M1_DIST
   are separately evaluated but can never select, repair, or replace it.
4. There is no exact cognitive verifier. Every non-PASS DREAM proposal is
   followed by a stateless fresh call to the same frozen 32B model. That call
   sees only the proposed row, its cited premises, and an entity-matched
   bounded counterevidence view selected without truth access, and emits
   `SUPPORTED`, `CONTRADICTED`, or `UNRESOLVED`. Hidden truth, answer, proof,
   candidate menus, and offline scorer remain absent. False self-approvals
   stay active and count against behavior. Support is labeled either
   `SELF_REVIEW_SAME_EVIDENCE` or `INDEPENDENT_CORROBORATION`; the first is
   never described as verification or independent evidence.
5. DREAM can write only `ROLE_EQUIV`, `CAUSAL_JOIN`, or
   `ROLE_APPLICATION`. The last is a label-free structural shortcut derived
   from a role memory and target-baseline evidence. No dreamed kind can
   contain a color/ratio/state token or encode an animal-at-target value,
   final action token, or complete proof. A depth-2 credit requires the typed
   ROLE_EQUIV parent; extra citations alone do not count.
6. THINK0 is disclosed strong process scaffolding. It receives a public
   source/target probe but no final animal, answer, valve, effect, distractor,
   or final question. Its focus changes retrieval priority only and is never
   citable evidence.
7. THINK1 is fresh and write-denied. Its reader returns one exact row,
   `NOT_FOUND`, or `CONFLICT`; it performs no closure, arithmetic, candidate
   enumeration, or answer checking. The model must resolve role, causal
   effect, passive baseline, source contribution, and public recipe itself.
8. Twin, path-prune, and sham-prune interventions are fresh model-facing
   THINK1 runs, not offline trace edits. Twin substitution uses the other
   twin's same-stage M1_OWN backend and must predict the exact donor-valid
   output token. Path-prune removes the final role parent, its descendants,
   and the final source--target join. Sham-prune removes the same number of
   nonpath rows matched on status, kind when available, and serialized token
   mass. Causal-use credit requires path loss and sham retention.
9. Text and LoRA consume one content-addressed semantic/view/touch manifest.
   Backend delivery bytes may differ; semantic rows, registered questions,
   exact answers, order, and exposure counts may not.
10. Every model operation is a new stateless request with an explicit allowed
    state payload and reset receipt. No conversation, KV state, cache index,
    adapter, reader, or workspace crosses lives, arms, or interventions.

## Stage D0: CPU and development gold

Repair only the model-facing `precheckpoint_export` projection: use the exact
allowlists in `execution_contract.json`; never copy raw payloads. Add mutation
tests for ratios, latent bits, answers, proof/scorer/split fields, pair IDs,
private aliases, filenames, and audit sidecars. Run the existing v03r
population, local-window, edge-removal, and public-feature shortcut tests.

The complete shortcut gate is frozen at 1,000 deterministic paired worlds:

- each of the 31 nonempty public-feature lookup predictors must have
  individual accuracy at most population-majority accuracy + 0.02 and paired
  accuracy at most 0.02; all 31 and both maxima are reported.

On development seeds 0--2, run the exact frozen THINK1 prompt under
`NO_MEMORY`, `RAW_RAG`, `GOLD_TEXT`, and `GOLD_OPEN_LOOP`. No prompt revision
is allowed after the first development model call: this proposal's prompt
bytes are the sole version. D0 passes only if GOLD_TEXT solves all three twin
pairs, every final trace uses the registered role and causal rows, the donor
swap produces the exact donor-valid token for all pairs, and NO_MEMORY fails
at least one pair. RAW_RAG and GOLD_OPEN_LOOP are reported, never gated.

## Stage T: held-out recurrent text organism

For each seed-5 twin independently, convert every projected episode into one
typed witnessed atom. The common episodic layer is disclosed and never
credited as dreaming. Then execute:

- 46 chronological WAKE proposal opportunities;
- 22 precommitted REACTIVATE opportunities balanced across under-linked,
  recent, supported, and unresolved rows;
- 16 target-absent SLEEP proposal opportunities;
- one THINK0 loop, at most 12 operations, ending in one CAUSAL_JOIN focus or
  DEFER;
- fork the sealed M0 into literal `M0` (zero post-THINK0 calls), `M1_OWN`
  (16 calls using the emitted own focus or an explicit NO_FOCUS token), and
  `M1_DIST` (16 calls using the frozen public-only matched distractor focus).

Each proposal opportunity is one DREAM call. PASS ends it. Every valid CREATE
is appended PROVISIONAL and receives exactly one fresh SELF_CHECK call. Its
verdict appends a status event; it never changes row bytes. Invalid calls
consume budget, append an invalid event, and are never repaired or retried.

The matched distractor is chosen before model use from paired-invariant
nonprimary source--same-target route/effect pairs by lexicographically
minimizing the public metric tuple `(abs(route_effect_gap-primary_gap),
abs(local_row_count-primary_count), source_alias)`. Eligibility requires one
unique route/effect pair, both records outside one local working window,
identical premise kinds and neighborhood cardinality, the exact primary
target, and a distinct source. For scored seed 5 this prospective public rule
selects the `land_00 -> cf_target_00` control (positions 2/26, gap 24). The
selected metrics and aliases are audit-private until the DIST calls.

After all three manifests seal, reveal the final goal and run fresh THINK1:

- `T-M0`, `T-OWN`, `T-DIST`;
- `T-TWIN`, using the other twin's M1_OWN text reader;
- `T-PATH`, using own M1_OWN after removing the final-animal `ROLE_EQUIV`, its
  typed descendants, and the final-source/final-target `CAUSAL_JOIN`;
- `T-SHAM`, removing an equal predeclared set of nonpath rows matched on
  status, kind when available, and serialized token mass.

Every arm has at most 12 operations per twin, identical model/decoding bytes,
and a fresh provider/reset receipt. The pipeline text gate is prospectively
`T-OWN`: both twins correct; registered role and causal rows actually cited;
T-TWIN emits each donor's exact correct token; T-PATH loses paired success;
T-SHAM retains both own answers;
all visibility, accounting, and artifact gates pass. M0/DIST comparisons may
credit return focus only if both lose paired success while OWN passes and OWN
contains a newly supported focus-matching row. The canary can pass without
that stronger return-credit condition.

## Stage L: conditional MEMORY-LoRA transport

Stage L is unreachable unless T-OWN passes and fresh independent review plus
author-side advocacy approve the sealed Stage-T artifacts. Train exactly one
rank-64 adapter per twin from the already sealed M1_OWN manifest. Use the
correct Qwen2.5-7B-Instruct revision in `canary_config.json`; no rank, model,
epoch, exposure, prompt, seed, or threshold sweep is allowed.

Before goal reveal or fitting, the manifest seals a 12-row fidelity set per
life: all eligible dreamed rows ordered by semantic hash, truncated to eight,
then witnessed rows ordered by semantic hash until twelve. Each row has four
fixed cue views and an exact registered answer. Recognition candidates are
the values for that queried field present in the sealed life manifest plus
`NOT_FOUND`, capped and ordered as specified in `execution_contract.json`.

Run `L-OWN` and `L-TWIN` with the same THINK1 contract. The 7B adapter is
mounted only while scoring candidates for an atomic read and is unmounted
before the clean 32B thinker continues. Stage L passes only if exact varied-
cue fidelity is at least .90 over the sealed 96 cue cases, L-OWN solves both
twins using transported role/causal rows, and L-TWIN emits the exact donor-
valid token for both recipients. This supports immediate accessibility of one
useful life-specific corpus, not durability, capacity, superiority, or scale.

## Calls and stopping

Exact maxima, all reconciled by phase/kind/token ledgers before dispatch:

- DEV_GOLD: 360 short 32B operation calls (NO_MEMORY, RAW_RAG, GOLD_TEXT,
  GOLD_OPEN_LOOP, and GOLD_TWIN across six development lives).
- HELDOUT_TEXT proposals: 232 32B calls; self-checks: at most 232; THINK0: 24;
  core THINK1: 96; path/sham THINK1: 48. Held-out maximum: 632.
- CONDITIONAL_LORA: exactly two 7B fits; 96 sealed fidelity cue cases; at most
  48 7B-backed online read requests; 48 32B THINK1 operations.
- Whole proposal maximum: 1,040 32B operation calls, two 7B fits, 96 offline
  fidelity cue cases, and 48 online adapter read requests.

Stop at the first invalid stage. Classify precondition/runtime/artifact
failures separately from scientific stage failures. Never rescue a failed
cell by more calls, larger model, new prompt, higher rank, different seed, or
post-result normalization. Every terminal seals artifacts and returns to the
human owner.

## Maximum claims

- Text green: one frozen prompted organism created and used life-bound
  connected semantic memory on one held-out paired decision.
- Text green plus LoRA green: the same useful corpus remained immediately
  accessible through two per-life MEMORY adapters.
- OWN green with M0/DIST red and a new focus row: the disclosed goal-return
  scaffold caused useful extra memory construction on this pair.
- Any red: only the first valid failing stage is named; no unique biological
  organ, population law, or headline conclusion is inferred.
