## Scientific object preserved

The organism still has exactly three cognitive functions:

1. **THINK** — the continuing waking stream of child thought, action, public
   outcome, judgment, and prospective intention.
2. **DREAM** — disposable waking-context management only.
3. **SLEEP** — noncreative compilation of independently eligible, grounded,
   child-authored experience followed by a personal LoRA write.

The sole parenting path remains:

`parent/repetition -> waking child context -> child thought -> child action ->
public outcome -> complete child commit -> independent same-life eligibility ->
later SLEEP`

Parent text, repetition-controller state, and DREAM output are never personal
SLEEP targets, evidence, compiler conditioning, dose, replay, or gradients.
Repetition means the same lesson enacted across varied waking situations, not
identical-string copying.

The experimental question remains whether a one-time, target-blind birth
rendering changes how a child later uses equal parenting and personal SLEEP.
No bootstrap content size, habit list, domain list, LoRA rank, dose, or resource
allocation is fixed by V9. Those are separately powered and ratified first-use
contracts.

Rename `Delta_R` everywhere to **T-versus-D incremental immediate
correct-versus-none advice-use interaction**. Irrelevant and wrong advice remain
mandatory reported controls. The adjective *selective* is forbidden unless a
separately ratified decision rule defines the irrelevant/wrong contrasts,
margins, uncertainty, multiplicity, code root, evidence roots, and a PASS
receipt.

### R2 — executable no-premature-bootstrap checker

phase with one canonical typed checker receipt that rejects unratified fixed

curriculum counts and names, domain counts and names, per-group allocation,

### R3 — canonical object and channel-specific visibility

Create one normative canonical object table. Each object has one semantic
identity; distinct definition, class, request, result, instance, receipt,
terminal, error, cache, and retry objects require explicit facet identities.
Aliases require an equality rule; placeholder category rows are forbidden.

For every principal/source/external observer × canonical object × channel in
`{value,count,order,timing,cache,retry,error}`, choose access independently.
The default is forbidden. Value access cannot imply timing/cache/error access.
Every later sealed invocation sub-DAG must expand its exact concrete objects and
regenerate the matrix before its first effect. Same-verdict hyperproperty tests
must vary quarantined details and verify equality on every forbidden channel.

### R4 — registry and schema exact schemas

producer: the lineage gate calls promotion, while the committed-lineage store

issuance a closed request/result/denial schema body, not just a schema ID.

- external or frozen source issuance;

Every prerequisite must have exactly one producer, strictly lower rank,
