# Visibility, taint, reset, and branch contract

This file expands the cartesian matrix in `change.json`. It is proposal-only.

## Process separation

- `private_certifier` owns factors/tables, both h/q continuations, all 16
  z-orbit members,
  exact closures, target identities, correct paths, alternate-world read
  witnesses, cuts, and truth labels.
- `public_life` owns raw source and A events only.
- `dream1` sees public tree events and announced A requests before A exists.
- `dream2` sees only a Dream-1 candidate-handle catalog; it must READ candidate
  contents and raw A/tree events through typed handles. It also sees announced
  B requests and never comparator fields.
- `sleeper` sees only model-selected notes or AST records plus a registry of
  eligible public event/action IDs and literal surface tokens. It never sees a
  target manifest or semantic truth.
- `reader_thinker` sees target state/goal/menu after corpus freeze and only its
  assigned memory interface.
- `actor` applies emitted actions and returns the public tray, never path truth.
- `offline_scorer` sees all immutable artifacts only after the causal object it
  scores has committed.
- `intervention_builder` is a distinct private terminal process after authentic
  corpus and target hashes freeze. Whole-object opaque cuts use no semantic
  selector; AST record cuts use only preregistered structural selectors. Its
  artifacts flow only to isolated cut actors and the offline scorer.

The public pipeline is a separate process unable to open the private artifact
root. Hidden tokens and descendants are tainted through arguments, objects,
training/input views, prompts, indexes, candidates, filenames, directories,
environment variables, RNG, caches, exceptions, timings, retries, and logs.
Pre-target and post-evaluation corpus/index hashes must match.
Mutating every private target manifest after source sealing must leave sleeper
admission, compiled bytes, lexical/AST indexes, and authentic action inputs
bit-identical.

## Branching and reset

SELF, gate, no-gate, and no-revision fork only after common Dream traces and A
bytes freeze. Every branch/life/target receives a fresh model session, KV cache,
workspace, RNG namespace, reader, index, filesystem namespace, and error state.
The model sees neither arm name nor root/orbit label. Invocation seeds are
presealed by role and root, never recycled across different roles, and cannot
depend on outcomes.

OPAQUE_NOTE_SELF and OPERATOR_AST_SELF use fresh sessions, candidate pools,
Dream-2 decisions, corpora, indexes, readers, and actors. There is no fallback,
mixed candidate/corpus/index, prose-to-AST translation, or cross-lane
selection. AST success cannot dispatch, repair, or reinterpret opaque work.

No result from an open root may enter an untouched-root prompt, parser, corpus,
index, budget, seed, target, or retry. If inspection causes any change, the
untouched run requires a new change ID and new root.

For each OPAQUE_NOTE_SELF continuation fork, Dream-1 runs once against the
shared tree and its full immutable object is cloned. At fixed z, every pre-A
public byte and Dream-1 byte is identical across h; only the raw A after-tray
subtree and mechanically derived hashes may differ at Dream-2. The two Dream-2
processes receive identical templates, eligible-handle shapes, budgets, B
requests, model revision, and paired seed-by-role. They have disjoint KV,
workspace, reader, filesystem, cache, timing, error, and retry state. Neither
sees the counterfactual A branch, h/q, orientation, a match bit, a repaired
candidate, or any expected B/target value.

The matched-independent q fork uses the same public interface. Its acceptance
predicate factors into A-only, B-only, and target-only predicates; B and the
uniform four-bit target ambiguity remain conditionally independent of the
common tree and exposed A branch. The certifier retains an exact conditional-
null receipt. Branch-sensitive output is not evidence of useful revision unless
it equals the independently presealed B/action truth, and systematic success is
a specificity concern, not a factorized mechanism result.

## Comparator mutation test

After common traces and corpora freeze, replace every private/offline truth and
comparison field with arbitrary legal values. SELF Dream-2 bytes, sleeper
corpus, reader index, prompts, and action bytes must remain bit-identical. The
perfect gate changes only when its public A comparison changes and cannot alter
any other branch.

## Evaluation sterility

Target actions, B outcomes, scores, and analysis text are terminal sinks. They
never re-enter episodic state, Dream, sleep, reader, Think, later targets, or a
later checkpoint. A tainted process is destroyed; no in-process cleanup is
accepted as evidence of reset.
