# PPC5r9 — minimal public-pathway prerequisite instrument

Status: proposal only. Nothing in this directory authorizes fixture execution,
model/tokenizer/embedding calls, training, canaries, behavioral work, GPU use,
scientific claims, or release. PPC5r8 consensus

## 1. Scientific boundary

PPC5r9 is not the lifetime flywheel experiment. It is the smallest causal
instrument intended to establish four prerequisites before spending a long
on-policy life:

1. **D1A — supported selection.** Does an evidence-gated READ-LoRA improve
   complete-table candidate selection over adapter-off, a matched wrong-life
   adapter, and a matched binding derangement, while passing false-selection
   and NOT_FOUND safety gates?
2. **D1B — observable pathway dependence.** Does changing each emitted public
   READ response on a sealed decisive path change later public behavior, while
   CUT/TWIN/timing controls hurt and action-preserving SHAMs remain
   noninferior?
3. **D1C — frozen DREAM context value.** Does one shared frozen-model DREAM
   view improve later action over fixed recency and recipient-local permuted
   views?
4. **D1D — DREAM-to-SLEEP total-policy value.** Does assigning the evidence
   root policy to DREAM-selected roots improve selection and action over total
   recency and permuted roots, including every downstream consequence of that
   assignment and without post-treatment adjustment?

The four assays are separate interventions, not a mediation chain. Their only
joint statement is the exact non-mediational intersection literal registered
in `claim_dependency_map.json`. They do not establish learned THINK, learned
DREAM, private cognition, continual improvement, compression, parenting,
population learning, inheritance, or scaling.

## 2. Population and equal-weight unit

The target population is only the accepted-constructible recipient-bundle law
of the exact locked finite generator. One independently generated
recipient-life plus its preassigned common-seed bundle is one equal-weight
sample. Queries, calls, rows, candidates, endpoints, items, and path edges are
repeated measurements and never increase N.

Before entropy, `PRE_ENTROPY_DESIGN_LOCK` freezes:

- generator/source/parameter law and proposal limit;

- lower-unit and D1A safety-key templates;
- D1B path/gate templates;
- margins, null thresholds, safety/missingness ceilings, alpha, and exact
  rational algorithms;
- capacities, schedules, call/read/action/token budgets;
- seed-domain allocation and allowed dispatch plan;
- every typed semantic registry and exact T02–T14 fixture specification.

`ENTROPY_ACQUISITION_RECEIPT` consumes that lock and partitions disjoint
entropy before proposal decoding. Each `LIFE_SAMPLE_RECEIPT` retains every
proposal, predicate result, first failure, rejection, acceptance, recipient,
donor, and common-seed assignment. Exhaustion is construction failure, not an
analyst exclusion or redraw. `SAFETY_KEY_RESOLUTION_MANIFEST` deterministically
resolves ordinal templates to generated identities. Only then may
`POPULATED_RUN_LOCK` bind realized samples, memberships, per-life D1A
controls, safety keys, and unchanged design parameters.

## 3. Frozen cognition and single learned object

THINK, DREAM, and ACT use one byte-identical frozen base model. D1B cognition
may emit only READ, PREDICT, ACT, or STOP under sealed authentic, one-shot, or
open-loop schedules. D1C/D1D use the same sealed READ/PREDICT/ACT budget.
DREAM is one shared no-retry call to that frozen model. D1A invokes no
cognitive model.

SLEEP is the only parametric write. It trains one clean-base READ-scoring LoRA
from direct pre-boundary public ACQUIRE evidence. The adapter is mounted only
inside the common complete-table provider and can change candidate scores
only. THINK, DREAM, ACT, writers, trainers, prompts, and public state never
receive treatment-semantic labels. DREAM prose, cognition, scorer output,
PROBE/future/target-derived bytes, and model confidence cannot create positive
evidence.

## 4. Direct paired interventions

Every arm begins from one byte-identical pretreatment state and common-seed
assignment.

- D1A changes only the opaque mounted adapter or null.
- D1B changes only emitted public response bytes and the sealed schedule.
- D1C changes only the installed reversible context view after one shared
  DREAM result.
- D1D changes only the root policy; evidence dose, training, publication,
  inference, failures, and resources remain natural downstream consequences.

Any unregistered difference is RUN_INVALID. Missing required calls never
retry and contribute failure/missingness. Integrity-clean no-action outcomes
are observed action value zero, not missing.

## 5. D1A controls

Each D1A life has one `D1A_CONTROL_SET_RECEIPT` keyed by run, sample ordinal,
recipient life, and life-sample receipt. It binds exactly three ordered
origins/corpora: AUTHENTIC, WRONG_LIFE, and BINDING_DERANGED. It proves the
registered base/tokenizer/shape/recipe/mount/rank/table/dose/opportunity/token/
update/histogram matches, recipient/donor disjointness, and target-blind
perfect derangement while preserving the frozen multisets.

`D1A_CONTROL_SET_MANIFEST` contains exactly one complete receipt for every D1A
membership ordinal. Its sample/life set must equal both prospective D1A
membership and populated life samples. No global singleton control can satisfy
an N-life estimand.

## 6. D1B emitted-response causality

The privileged router sees assignment, condition, source, matching, scores,
and raw candidate bytes. It allocates a fresh disjoint 32-byte nonce and binds
the canonical privileged route body with a domain-separated SHA-256
commitment. Restricted components receive only a sanitized projection and the
opaque commitment.

The sole causal path into later THINK is:

```text
privileged route
  -> sanitized response projection
  -> INTERVENTION_EMISSION_RECEIPT.emitted_public_bytes
  -> STATE_BODY.public_view.last_read
  -> MODEL_VIEW
  -> MODEL_DISPATCH
```

The controller may consume the emission receipt only; it cannot consume the
projection, route, nonce, preimage, condition, source, scores, or matching
metadata. Provider audits and route-lineage audits are separate complete
manifests with independently derived cardinalities. Tests must show that
changing emitted public bytes can change later THINK, while changing hidden
route metadata with identical emission cannot change restricted ingress,
output, debit, status, or timing class.

## 8. One value per life

For each prospective gate and life, `LIFE_GATE_AGGREGATE` binds the exact
ordered lower-unit universe and complete treatment/control observations. The
frozen within-life reducer emits one treatment value, one control value, one
difference d_i, one strict-margin indicator Z_i, and one missing flag.
Incomplete, invalid, or missing required evidence yields Z_i=0 and
missing=true; it is never dropped. N is derived only from the number of
distinct prospectively assigned sample ordinals with one aggregate each.

Gate inference uses exact Binomial tails and exact one-sided Clopper–Pearson
bounds. D1A safety uses exactly one prospectively keyed Bernoulli trial of
each registered kind per life. Each assay p-value is the maximum of all of its
conjunctive gate p-values. Holm step-down contains exactly the four canonical
D1A–D1D claim IDs; the intersection is not a fifth family member.

## 9. Joint construction-and-release power

No global conditional-power receipt may be multiplied into an unrelated
construction proof. Each finite support/partition row binds typed recipient
and proposal objects, ordered acceptance evidence, exact mass, proposal or
exhaustion status, its per-life D1A controls, and the applicable conditional

The primary r9 proof is pointwise:

```text
L_joint = Σ_s mass(s) * I[construction succeeds at s] * L_release_given_s
```

Failed and uncovered mass contributes zero. Every term is computed under the
same locked N-life construction law; no independence assumption or simulation
is used. A future uniform-bound shortcut is forbidden unless separately typed
and proven over every successful support point.
