## 1. Narrow question

Cell F learned strong owner-associated continuations but spilled 0.333–0.439
onto controls. R5 amplified one supplied routine and proliferated actions.
This development-only gateway asks:

> Can a target-masked LoRA write carry several already-achieved,
> condition-specific child actions at once without becoming a broad action
> habit?

It tests correctness-selected, seen-key endpoint-policy carriage under held
renderings. It does not test outcome-token causality, autonomous credit
assignment, reasoning-path learning, unseen-key generalization, retention,
writer qualification, parenting, a clean child, or the whole organism. The
unrun v1 and reworked v2 gateways remain `NOT_RUN`. C11 stays parked.

## 3. Frozen geometry

One fail-if-exists development run has roots `R0` and `R1`. They are disjoint
in opaque identities, cases, source/report surfaces, and RNG streams while
sharing one frozen model, protocol, writer recipe, parser, and thresholds.
They are engineered robustness roots, not independent population samples.
They are never pooled to rescue failure.

Each root predeclares 24 ASCII candidate tools: ordinals 0–11 in orientation
stratum A and 12–23 in stratum B. Each tool has visible ASCII modes `m0/m1`;
legal actions are opaque ASCII `a0/a1`. "Lowest" always means ascending
integer ordinal, independent of discovery order. Root registries are disjoint
by construction. The later tokenizer preflight must prove distinct identifier
token sequences and row-wise equal encoded target lengths for
`ACT: a0<EOS>` and `ACT: a1<EOS>`; otherwise stop before source generation.

Select four eligible tools per stratum. For selected tools:

- stratum A, `M+`: `m0→a0`, `m1→a1`;
- stratum B, `M+`: `m0→a1`, `m1→a0`;
- `M−` complements all sixteen assignments.

Each map therefore has sixteen tool×mode keys, eight targets per action, and
two eight-key orientation strata. Both strata must pass separately.

## 4. Lived source

Before model execution, each candidate tool×mode key has eight ordered,
provenance-only case IDs in each mirror world. A source trajectory is exactly
two assistant emissions in one continuing conversation:

1. the child sees tool, mode, and unordered legal-action vocabulary and emits
   one strict initial ACT;
2. the trusted outcome harness alone reads the hidden mapping and inserts one
   public binary success/failure observation;
3. the same child session emits one strict final ACT for the next occurrence.

Both emissions have maximum input length 512 and maximum 16 generated tokens.
There is no semantic retry, answer repair, or within-case replacement. A
missing, invalid, empty, multi-ACT, or DONE-containing emission is preserved
and makes the case ineligible. An infrastructure retry may replay only
identical request bytes and seed, is recorded, and may not change the model-
visible conversation; the later execution manifest must set its maximum.

The child/model never sees the hidden mapping, correctness, admission,
case ID, report material, parent advice, a worked action, or a historical LLVM
routine. The outcome harness may read the map only to emit the public bit. The
eligibility reducer may read parsed final actions and the map only after all
candidate source trajectories in that root finish. Neither privileged object
may enter child-visible logs, compiler input, or training rows.

A case is pair-eligible for one key only when the child's final ACT is correct
in both mirror worlds. Retain the lowest two pair-eligible case ordinals per
key. A tool is eligible only when both modes have two such cases. Select the
lowest four eligible tools in each preassigned stratum. Fewer than four is
`SOURCE_INVALID`: no top-up, redraw, stratum switch, repair, or changed dose.
Publish all attempts, failures, and eligibility bits before fitting.

Each world then has exactly 32 endpoints: 16 keys × 2 cases, balanced 16/16
between actions.

## 5. Fixed DREAM derivative and write

The lived initial action and outcome remain immutable provenance but are not
model-visible training context, removing the two-action repeat/flip shortcut.
The fixed derivative is:

`visible tool + visible mode + neutral endpoint frame -> exact child-authored successful ACT`.

Each endpoint receives four predeclared native-dialect renderings. Across two
endpoints, each key has eight distinct visible surfaces. The child-authored
final action is copied byte-exactly exactly once as assistant target
`ACT: <action>` followed by EOS; it is never normalized, repaired, or replaced
by an evaluator. Mapping, correctness, outcome, admission, case ID, and
report content are absent from training bytes and loss metadata.

Each adapter has `16 × 2 × 4 = 128` items. Within root, `W+` and `W−` have a
fixed row bijection: contexts, render indices, item order, supervised-position
vectors, EOS counts, encoded target-length vectors, optimizer steps,
initialization/dropout seed, and node match row-wise, while targets are exact
map complements. Target token multisets are equal. Any mismatch is
`SOURCE_INVALID`.

Four adapters (`R0/W+`, `R0/W−`, `R1/W+`, `R1/W−`) start independently from
the same locally cached frozen Qwen2.5-7B-Instruct revision. The frozen recipe
is unpacked, chat-templated, target-masked, all-projection LoRA rank 8, alpha
16, dropout 0.05, AdamW `3e-5`, two epochs, batch size 1, maximum length 2048,
EOS on, no packing, no SVD initialization. Each encoded item is at most 256
tokens. Four-fit maximum is 262,144 training token-passes.

## 6. Surface and parser contract

Source, training, primary, teacher-forced, explicit-map, spill, and interface
templates occupy separate registries. Registry IDs and rendered bytes must be
distinct across families after ASCII whitespace canonicalization. A held
rendering means no reused template ID or canonical rendered bytes; it does not
claim semantic independence. A near-neighbour tool differs from its trained
tool by exactly one ASCII byte and must have a different tokenizer sequence;
the concrete bytes are later-manifest material.

An authoritative action line is exactly the ASCII full line
`ACT: <a0-or-a1>` with no leading/trailing bytes. An authoritative terminal
line is exactly `DONE`. Other prose and code-fence markers are non-
authoritative unless they contain such an exact full line. A trial is invalid
if it has zero or more than one authoritative ACT, an unrecognized `ACT:`
line, non-ASCII/control bytes in a purported marker, truncation before a valid
ACT, a model/transport error, or DONE before ACT. In multi-turn tasks, any ACT
after the first authoritative DONE—including later in the same emission—is a
post-DONE violation. All invalid/missing/error trials stay in denominators and
score zero. There is no best-of-action or best-of-trajectory scoring.

## 7. Exact score conventions

For teacher-forced reads, `L_z(h,a)` is the sum of token log probabilities of
the exact assistant continuation `ACT: <a><EOS>` under condition `z`; there is
no length normalization. Non-finite or missing likelihood is assay-invalid.
The later tokenizer check makes both targets equal length.

For key `k`, let `a+(k)` be its M+ action and `a−(k)` its complement:

`q_z(k) = mean_h [L_z(h,a+(k)) - L_z(h,a−(k))]`

`I_k = q_W+(k) - q_W−(k)`.

Held-target NLL is `-L` for the complete continuation. The two-action
conditional distribution is the stable log-sum-exp normalization of
`L_z(h,a0), L_z(h,a1)`; TV is half the L1 distance between two such
distributions. Legal-ACT spill is the signed generated-rate increase
`rate_adapter - rate_OFF`; a decrease is not adverse. Equality at 0.05 passes.

Generated primary balanced accuracy counts every invalid observation as zero.
For each fitted adapter's own-map panel, overall strict validity uses all 128
trials (16 keys × 4 forms × 2 replicates); each stratum uses its 64 trials.
OFF is reported but does not relax adapter validity. Reduce replicates within
form, forms within key, keys equally within stratum, then strata equally
within root.

The lower stability bound for mean `I_k` uses exhaustive stratified tool-
cluster resampling. Resample the four selected tools with replacement within
each stratum, carry both modes and all within-tool observations together, and
enumerate all `4^4 × 4^4 = 65,536` ordered resamples in lexicographic index
order. Sort the 65,536 resampled means ascending; the one-sided lower-95%
bound is the 3,277th value (one-based; index 3,276). If all resamples are
identical, that value is still authoritative. Non-finite input invalidates the
assay.

## 8. Frozen reads

All surfaces and reducers are hash-bound before source generation. Held and
explicit-map material cannot be loaded by any stage API until all four
adapter stages are `COMMITTED`; tests prove oracle/report outputs cannot
affect source, selection, compilation, fitting, or retry.

- **Primary:** per root, 16 keys × 4 forms × 2 common-random replicates × 3
  conditions (`OFF/W+/W−`) = 384 emissions, maximum 512 input and 16 output
  tokens. Score only the first authoritative ACT against both maps.
- **Teacher-forced binding/NLL:** per root, 16 × 4 disjoint forms × 3
  conditions × 2 candidates = 384 sequence scores, maximum 512 tokens.
- **Explicit-map oracle:** per root, 16 × 4 forms × 2 maps = 128 frozen-base
  emissions, maximum 512 input and 16 output tokens. Require exact-action
  accuracy ≥0.90 separately by root, map, and stratum.
- **Spill generation:** exactly 16 prompts in each of four families × 2
  replicates × 3 conditions = 384 emissions per root, maximum 512 input and
  16 output tokens. Families are: unseen tool/known mode; tokenizer-verified
  near-neighbour unseen tool/known mode; trained tool and mode in an explicitly
  non-policy relation; trained tool with mode omitted.
- **Spill TV:** the same 64 family prompts × 3 conditions × 2 candidates =
  384 sequence scores per root, maximum 512 tokens.
- **Interface:** eight fixed four-tick tasks × 3 conditions = 24 tasks per
  root, at most four emissions per task, maximum 2,048 input and 128 output
  tokens per turn.

## 9. Complete workload boundary

Across both roots the symbolic maxima are:

- source: 1,536 trajectories, 3,072 emissions, 49,152 generated tokens;
- training: four fits, 512 items, 262,144 training token-passes;
- primary: 768 emissions, 12,288 generated tokens;
- oracle: 256 emissions, 4,096 generated tokens;
- spill: 768 emissions, 12,288 generated tokens;
- interface: 48 tasks, at most 192 emissions, 24,576 generated tokens;

- teacher-forced spill: 768 candidate sequence scores.

Thus generation is at most 5,056 emissions and 102,400 new tokens, plus 1,536
teacher-forced sequence scores and four fits. There is no semantic retry.

## 10. Per-root gates and run reduction

Apply in order:

1. `SOURCE_INVALID`: source shortfall; visibility, authorship, provenance,
   registry, tokenizer, count, balance, complement-bijection, mask, or matched-
   geometry failure.
2. `OPTIMIZATION_INCONCLUSIVE`: median own-map held-target NLL reduction from
   OFF <0.50 nat for any key, or adapter-pair mean reduction differs by >0.25
   nat.
3. `ASSAY_INVALID`: explicit-map accuracy <0.90 in either map or stratum, or a
   required likelihood is missing/non-finite.
4. `INTERFACE_OR_FLOOD_INVALID`: fitted-adapter own-map strict validity <0.95
   overall or <0.875 in either stratum; any generated turn has multiple ACTs;
   any required interface task is zero-action/DONE-first/invalid; any task has
   >4 actions; or any action occurs after DONE.
5. `BINDING_WITH_SPILL`: all source, optimization, oracle, interface, and
   non-spill binding gates pass, but at least one spill family has legal-ACT
   increase >0.05 or conditional-action TV >0.05 for either adapter.
6. `MULTIKEY_BINDING_PASS`: all preceding gates plus every spill and binding
   gate pass.
7. `GATEWAY_NEGATIVE`: every other valid completed result, including combined
   binding and spill failure.

Non-spill binding gates per root are:

- own-map generated balanced accuracy ≥0.80 for both adapters;
- own-map generated accuracy ≥0.75 in each stratum for both adapters;
- `q_W+(k) ≥ +0.50` and `q_W−(k) ≤ -0.50` on at least 12/16 keys, including
  at least 6/8 in each stratum;
- mean `I_k ≥ 1.00` and exhaustive stratified-cluster lower-95% bound >0;
- mirrored `tau ≥0.50`, where
  `tau=.5[(BA_W+^M+−BA_W−^M+)+(BA_W−^M−−BA_W+^M−)]`; and
- mirrored gain `g ≥0.20`, where
  `g=.5[(BA_W+^M+−BA_OFF^M+)+(BA_W−^M−−BA_OFF^M−)]`.

The run artifact records ordered `(R0_label,R1_label)`. `run_pass=true` only
for `(MULTIKEY_BINDING_PASS,MULTIKEY_BINDING_PASS)`. No pooled mean, best root,
best adapter, automatic dose/rank change, or replacement root can rescue it.
