# PCFL-D0-EXACT-V2 cross-audit

Status: **REWORK — not ratifiable and not implementable.**

This audit was performed after the world/controller, schema/reader/compiler,
and authority/statistics contracts were written independently. No D0 code or
GPU science is authorized by these artifacts.

## What is already coherent

- PCFL-13 is explicitly a finite 13-relation mechanism assay, not a lifetime
  scaling result.
- Hidden-world solvability, complete-eligible-atom information, and authentic
  bounded-reader reference controllers are separate estimands.
- The compiler emits exactly four one-edge views per supported atom.
- THINK is bounded to four queries, eighteen total resolver operations, six
  world actions, four memory slots, and four active path edges.
- The capability boundary otherwise excludes models, providers, networks,
  GPUs, training, adapters, and LoRA from D0.
- The locked claim policy includes no-memory usefulness and comparator-reversal
  dispositions.

## Blocking rework

1. **Renderer/tokenizer and cuts are absent.** `token_end` changes pair
   acceptance and the post-working-window qualifier, and S-bind uses frozen
   tokenizer bins, but no ratified artifact pins renderer bytes, tokenizer
   files/hashes/revision, BOS/EOS policy, or complete-event cut vectors. D0 is
   simultaneously forbidden to run the tokenizer.
2. **The actual deck is not frozen.** Seeds and derivation rules exist, but the
   64 CPU pairs, accepted candidate counters/world ranks, target proposals,
   rejection histories, source token cuts, and reachability certificates would
   first be selected by post-ratification code. They must be materialized before
   implementation and later verified, not selected, by D0.
3. **Runtime/resource authority is not self-contained.** The exact Python
   runtime and standard-library/native hashes are not bound, and the <=65 W
   host certificate needed for the energy limit is absent.
4. **DEV authority contradicts the split contract.** The split/controller
   contracts open deterministic D0 DEV, while the authority denies DEV reads
   and writes.
5. **Support admission is underdefined.** The expected 13 eligible atoms are
   required, but no exact relation-specific fit/prediction/contradiction,
   alias, revision, cycle, diamond, or root-dedup algorithm and golden suite
   determines which claims become `SUPPORTED`.
6. **Bayes conditioning is incomplete.** The stated accepted-visible-item
   likelihood handles one target slot, but actual acceptance is conditioned on
   the complete pair deck, prior target tuples, reachability, pair-orbit
   exclusion, and earlier global slots. The exact prior must cover that full
   construction kernel and have a non-toy 103,680-world golden.
7. **The derived-transform anchor is a new architecture choice.** It is not
   copied from a visible slot, contradicting the inherited copy-origin
   firewall. Either expose a target-independent ontology slot or explicitly
   deliberate this operation and its causal credit.
8. **Canonical goldens are not protocol-valid.** Several use handles outside
   the fixed world vocabulary, collisions between instance and family handles,
   and empty/placeholder digests for nonempty artifacts. They must be generated
   from real bytes or marked expected-reject fixtures.
9. **The 1,000-transition performance fixture is unspecified.** Initial state,
   actions, pair, warm-up, timing boundary, and expected digest must be fixed.

## High-priority consistency repairs

- Permit the full legal inventory/applied-preparation state trajectory in the
  schema.
- Resolve candidate-ID exposure in `FOUND` returns.
- Give memory-only and coherent matched-state twin forks different certificate
  branches and real goldens.
- Use the globally frozen RNG derivation for bootstrap resampling.
- Do not duplicate deterministic non-adapter arms into fictitious seed slots.
- Make the resource ledger use exact controller IDs, forbid JSON null, report
  file-descriptor/output-byte maxima, and bind four named compiler-view counts.
- Add estimator goldens for all nondegenerate and boundary cases.
- Define every no-memory/context comparator surface before claiming decisive
  roots are out of view.
- Put the comparator order and one exact resource qualifier directly in the
  claim policy.
- Replace placeholder reachability/collision/intervention goldens with complete
  byte-level certificates.

## Scientific disposition

The proposed D0 remains useful as a checker/reference conformance gate once
repaired, but it is not itself a paper result. The most important paper-facing
progress from this review is the correction that PCFL-13 cannot measure
continued learning: all 13 relations fit in roughly 16.7 bits and can be
supported early. The scientific ladder therefore remains:

1. PCFL-13: fixed-deck mechanism/transport/composition attribution;
2. PCFL-Stream: genuinely growing, nonrepeated lifetime information with new,
   old, and cross-era targets and at least three post-native checkpoints;
3. PCFL-Schema: prospective sparse-sector transfer that tests compression and
   generalization rather than lookup.

No GPU launch should occur from this v2 bundle. The next efficient move is to
repair the finite D0 design with generated, independently checked frozen bytes,
then seek fresh deliberation and exact human ratification. In parallel, paper
design effort should stay focused on PCFL-Stream/Schema, because that is where
the central beyond-saturation experiential-learning hypothesis is actually
identified.
