# PCFL Transition-Path P0/P1 preflight proposal

## Decision

Replace the rejected PCFL-Stream paper-target proposal with a narrow,
hash-bound transition-path preflight. The transition tree is not promoted as
the sole paper benchmark. It is used only to answer whether a clean-base
resolver can causally use target-blind compiled transition witnesses in an
actual four-move episode before the project spends on a new paper-scale world
or parametric transport.

This successor explicitly supersedes the minimal J/P plus Bubblewrap route as a
prerequisite on paper ROI. It reuses their total-generator, target-twin,
typed-headroom, decisive-cut, failure-retention, and nonautomatic-promotion
patterns, but inherits neither authority nor evidence. J/P remains a DEV assay;
Bubblewrap remains its narrow CPU-interface receipt. Neither is run first.

## Scientific role

The tested arrow is deliberately small:

```text
fixed public action--outcome source deck
  -> deterministic target-blind transition atoms
  -> bounded dependent reverse reads
  -> physically executed later action path
```

The world uses ordinary persistent depth-four binary transitions. A cross-era
target is one continuous root-to-leaf path whose four node bindings have two
old and two recent support times. There is no public handoff or splice. The
model must walk backward from the goal through one returned predecessor at a
time, then emit four legal moves that the world executes. Only terminal action
return counts.

This is intentionally a fixed-source/off-policy semantic-use preflight. The
source deck is scripted before outcomes, the compiler is mechanical
`WCANON-T1`, and target execution cannot create later experience or memory. A
flat atom-bag scan and an exact public graph are decisive controls. Therefore a
pass cannot establish learned graph organization, connected-memory necessity,
autonomous dreaming, a self-learning agent, or the complete flywheel.

## Stages

### P0 — deterministic CPU certification

After exact human ratification only, implement the minimal generator,
constructor/oracle, public renderer, canonical compiler, linked and flat-bag
readers, exact graph controller, action executor, evaluator, schemas, and tests
under the future write and resource surface in `resource_manifest.md`.

P0 must establish total construction, exact H/tau involution, target-byte and
goal-pair properties, D1/D4 target-only priors, unique path depth, all six
cross-era age-position patterns, forward and backward reachability, itemwise
typed-controller value one, decisive/sham cuts, descendant-level
visibility/taint/reset behavior, failure denominators, and reproducibility. It
runs locally on CPU with no model, provider, network, tokenizer service, GPU,
training, adapter, or LoRA operation.

Any failed receipt ends `STOP_INVALID`. An all-pass freezes exact bytes but
does not start P1.

### Fresh independent code review

A fresh reviewer who did not author or modify P0 must reproduce it and inspect
the exact code, manifests, write/network/provider boundaries, compiler
blindness, visibility mutants, resets, and resource caps. Only an explicit
`PASS_FOR_P1` on unchanged bytes satisfies this gate. Rejection is final for
this scope; repair requires a new bound review and any authority additionally
required by the repair.

### P1 — one compiled-text action canary

On six disjoint world-life/twin pairs, run only the pinned
`codex/gpt-5.6-luna` resolver against mechanically compiled text. Each pair
uses one of the six possible placements of two recent bindings along a D4
path. The exact 114 target episodes cover authentic linked text, target-only,
crossed twin memory, a lagged snapshot, flat atom-bag scan, old/new/both
decisive cuts, and matching shams. No compiler model and no training are used.

The deterministic request rule is frozen in
`statistics_and_gate_contract.md`. A valid negative ends
`STOP_TEXT_CAUSAL_USE_NOT_ESTABLISHED`; a valid positive may emit only
`REQUEST_FRESH_PAPER_WORLD_DESIGN`. That request is not a claim, promotion,
LoRA request, workflow dispatch, or authority token.

## Why this repairs the previous design

- The paper claim is narrowed instead of using a key-value transition tree as
  a general self-learning or connected-memory benchmark.
- One total source policy and one presealed target manifest exist before
  binding outcomes, support, compilation, or model results.
- Prefix, target, truth, treatment, and outcome information are separate, with
  descendant taint and fresh-life resets through renderer, compiler, index,
  prompt, provider, reader, parser, executor, scorer, audit, errors, timing,
  caches, RNG, and workspace.
- D1/D4 are unique graph-theoretic path lengths. Exact target-only values are
  `1/2` and `1/16`; all lower-depth alternatives are enumerated; the typed
  controller must score one itemwise.
- Cross-era D4 is four edges in one persistent tree, with the six old/recent
  position patterns counterbalanced. No public answer-bearing handoff exists.
- Goal twins change only the goal ID and force different first actions.
- Reverse planning is genuinely dependent; forward execution is checked
  against the same atom hashes. The index is counted as memory, and the bag and
  exact-graph controls prevent graph rhetoric.
- P1 includes every preassigned corpus and failure. Its aggregate text gate
  cannot filter a later confirmation corpus because no confirmation or LoRA
  stage exists in this scope.
- Pair roots, metrics, missingness, NOT_RUN, arms, calls, storage, wall time,
  and terminal decisions are exact. Six pairs remain calibration, never paper
  `n`.
- Independent review admits `APPROVE_NARROW`, `NULL`, `NOT_RUN`, or `REJECT`;
  advocacy is non-overriding and no technical verdict grants authority.

## Exact claim ceiling

At most, P0/P1 may internally record that the registered deterministic
construct conformed and that the pinned resolver did or did not meet the fixed
compiled-text semantic-use canary rule on six calibration pairs. This may guide
a human decision to design a fresh paper world. It may not be released as a
benchmark, paper, performance, learning, lifetime, connected-memory, LoRA,
compression, plateau, SOTA, or self-improvement result.

The current proposal prewrites no positive Paper-1 claim. A future paper-world
change must freshly define its construct, whole-life power, strong baselines,
candidate/index versus substrate factorial, full resource frontier, and claim
sentences. This transition preflight cannot be silently scaled into that study.

## Authority

The material files and initialized intake state create no execution authority.
Exact human ratification must match `scope_proposal.json`. Even then, authority
is limited to P0 and, conditionally after its all-pass and fresh review, P1.
LoRA, any training, full confirmation, claim release, automatic successors,
lease/credential/quota/spend/runtime changes, unrelated edits, and networking
outside the pinned P1 provider transport remain forbidden.
