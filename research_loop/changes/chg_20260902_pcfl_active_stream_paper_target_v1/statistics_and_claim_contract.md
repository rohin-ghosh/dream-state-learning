## 3. Four complete B3 root-level descriptive summaries

The future action-conditioned claim is conjunctive in substance, so B3 reports
all four complete summary families and every component. Under this protocol
none is a population test and success in one cannot license claim language or
hide failure in another.

### P1: randomized chain-complete causal cascade plus compilation advantage

`mediation_contract.md` defines the binary-link product for every assigned
branch/target, six cumulative-link contrasts, six same-event/common-history
reconsolidation contrasts, and three binding scores, then takes their minimum:

```text
P1_w = min(all six cumulative-link contrasts,
           all six reconsolidation/compiler contrasts,
           all three binding scores)
```

Every claimed link is inside the P1 root summary: side-valid informative
probe, positive registered information
gain, newly supported decisive public evidence, readable target-blind branch
delta, executed working path using a branch-event descendant, and terminal
success. Any failed/absent link makes that assigned chain value zero before
AUTH/TWIN/NULL contrasts are formed. The six `r_q,w` components also contain SELF versus
RAW-AO, ACTION-ONLY, WITNESS/MECH, matched-action twin outcome, executable
semantic cut versus sham, and generic SELF versus the root-wise strongest
non-SELF common-history condition. The exact nonadaptive reader is a Stage-A
construct stop; recurrent KV/linked success is allowed and remains in the
strongest comparator.

Link/component root values, recurrent versus nonadaptive behavior, and generic
versus class-informed SELF are reported descriptively. Even favorable P1
values support only a B3 falsification/descriptive account; they establish no
population causal-cascade or offline-compilation advantage and do not identify
a formal natural indirect effect.

### P2: new acquisition

For root `w`, evaluate the same six preassigned new targets with current and
immediately lagged snapshots. For each post-native checkpoint define `a_k,w`
and take the intersection minimum:

```text
a_k,w = Y[SELF,w,M_k,T_NEW,k] - Y[SELF,w,M_(k-1),T_NEW,k]
P2_w = min(a_1.5,w, a_3,w, a_6,w)
```

Since `P2_w` is no larger than any checkpoint component, it is a conservative
descriptive acquisition summary. Report all eight root minima and all three
checkpoint components without a lower bound or population conclusion. Lagged
memory succeeding on genuinely new relations triggers the registered
leakage/shortcut audit.

### P3: old retention

For the exact preassigned earliest eligible 6L OLD targets whose latest
possible supporting opportunities, later-support embargoes, and worst-case
unpadded ages passed A0, let `B_OLD,w` be
their presealed target-only/twin-byte Bayes ceiling and freeze
`tau_w=max(0.50,B_OLD,w+0.20)`. If `tau_w>1`, the construct is invalid rather
than relaxed. Let `A_w` be failure-inclusive value at the presealed first-post-
acquisition snapshot and `L_w` value on those same rows at 6L:

```text
P3_w = min(A_w - tau_w,
           L_w - tau_w,
           L_w - A_w + 0.05)
```

Since `P3_w` cannot exceed any component, it descriptively records
above-floor acquisition, above-floor 6L endpoint value, and the registered
retention-NI margin together. A `0 -> 0` root has
`P3_w=-tau_w<0` and cannot create retention credit. Missing support,
failed acquisition, or failed endpoint rows remain zero-valued in `Y` and no
root is dropped or conditioned away. Report the three components and paired
retention at every eligible post-native checkpoint; none is confirmatory.

```text

  AUC(Y[AS-RAG,w,CROSS]),
  AUC(Y[AS-EXT,w,CROSS]),
  AUC(Y[AS-MECH,w,CROSS])

CROSS_AUC_w = AUC(Y[SELF,w,CROSS]) - BMAX_w
```

Set `P4_w=CROSS_AUC_w`. This root-wise maximum is a conservative descriptive
comparator envelope, not an additional replicate or a claim that a synthetic
