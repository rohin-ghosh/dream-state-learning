# Paper-1 v03r end-to-end canary v1d

**Status:** exact proposal for architecture deliberation only. No file in this
directory authorizes implementation, a model request, held-out exposure, GPU
use, adapter fitting, a scientific claim, or an external action.

## Question

Can one frozen, strongly game-scaffolded resolver turn a target-absent stream
of public actions and outcomes into fallibly self-reviewed connected memory,
use that memory under a later goal, and preserve immediate candidate-
constrained access through isolated per-life LoRAs?

```text
public action/outcome stream
  -> pre-dispatch sealed typed public/probe/withheld-goal projection
  -> witnessed immutable rows
  -> repeated local connection proposals
  -> one blind model SELF_CHECK per new proposal
  -> immutable model-SUPPORTED rows, including false self-approvals
  -> target-absent goal-routing probe
  -> fixed OWN/DIST return branches
  -> final-goal atomic text traversal
  -> prospective path/sham and twin interventions
  -> only after text passes, two fixed-corpus MEMORY LoRAs
  -> candidate recognition -> closed read projection -> clean thinker
```

This is an aligned seed-5 twin-pair engineering-ceiling diagnostic. Public
actions are generated by the environment; the model commits only the final
answer token. It is not the Paper-1 headline experiment. The exact solution
ontology appears in the DREAM prompt and the exact proof-sequence scaffold
appears in THINK1.

## Normative package

All v1d files named by `change.json` are jointly normative. The v1c consensus
is binding repair provenance; every other v1c, v1b, and v1a file is historical
defect/provenance evidence only and has no inherited runtime authority. A
contradiction among v1d normative files is
`INVALID_PRECONDITION/PROTOCOL_CONTRADICTION`; execution may not select a
preferred reading. JSON uses RFC 8785 JCS wherever a hash is specified.

`semantic_consistency_matrix.json` is the exhaustive registry of normative
producers, consumers, object schemas, orderings, validity classes, and ledger
encodings. `opportunity_ledger.schema.json` is the sole opportunity-row and
condition/state/reason vocabulary. Any unregistered producer/consumer path,
unmapped condition, multiple mapping, or cross-contract disagreement is
`INVALID_PRECONDITION/PROTOCOL_CONTRADICTION` before dispatch.

`resolution_brief.md` states the design choices. `canary_config.json` fixes
world/model/compute ceilings. Operation, memory-transport, intervention,
fixture, runtime-training, review, acceptance, prompt, and schema files bind
the executable semantics. Generated prose, confidence, predictions, reasons,
selector receipts, private truth, answers, outcomes, and audit-only fields are
structurally excluded from every later model request, row, selector, reader,
compiler view, candidate registry, and training example.
`public_projection_contract.json` exclusively binds the inherited
`lands/v03r.py`/`lands/v03.py`/`lands/skins.py` public API to these typed
objects; the complete public projection, withheld goal, vocabulary, and DIST
control seal before any held-out provider request.

## CPU and development

Exact human ratification may release CPU implementation only. CPU closure
produces the executable lock, request/token golden vectors, immutable schemas,
full v03r shortcut vector, and the post-ratification P1CB preflight artifacts.
An independent reviewer and separate advocate must both approve the exact
CPU-to-DEV packet.

DEV runs NO_MEMORY, GOLD_TEXT, and GOLD_TWIN on seeds 0--2, both latent bits,
with twelve operation opportunities per trace. All eighteen traces seal before
offline scoring. DEV passes only when GOLD_TEXT and GOLD_TWIN each solve all
three twin pairs with the registered required read handles, donor tokens are
exact, NO_MEMORY loses at least one pair, all 31 population predictors remain
below their frozen thresholds, and all locks/accounting/reviews pass.

## Held-out text organism

For seed 5 and both latent bits, process 46 public episodes into witnessed M
rows only after both raw-to-typed public projections, the target-absent probe,
host-only withheld goal, state vocabularies, and public DIST manifest have
sealed. Run the exact 46-WAKE/22-REACTIVATE/16-SLEEP prefix, target-absent
THINK0, zero-call M0, and matched sixteen-slot OWN/DIST return branches. A
DREAM output is an audit proposal, not memory. Only a schema-valid new
proposal receiving model verdict SUPPORTED creates one immutable DREAMED row.
The system contains no semantic or exact-answer verifier; false self-approved
rows remain in the corpus. SELF_CHECK is same-model blinded self-review and
does not by itself support any truth-verifier or precision-improvement claim.
Every model-identified additional support premise is retained in the accepted
row's canonical citation union, lineage, and depth.

THINK0 DEFER is a nonfatal trace terminal: OWN still runs with fixed NO_FOCUS
and DIST still runs with its presealed public control, but return-feedback
credit becomes impossible. Seal M0/M1, M1_OWN transport manifests, fidelity
rows, and shared candidates. Reveal the already-sealed public goal, then
seal path/sham exclusions and all six arm plans, using a sealed non-dispatch
plan rather than a reader when sham is not identifiable. Execute every prospectively
runnable T arm without scoring or result-conditioned cancellation, seal all
traces, then score offline.

The text gate requires the feedback loop, not merely good final behavior. Both
THINK0 traces must REQUEST_RETURN the exact non-NO_FOCUS probe. T-OWN must
solve the pair while T-M0 and T-DIST each lose paired success. In each life an
OWN-only admitted, offline-correct, focus-matching CAUSAL_JOIN must be returned,
cited in a later THINK/BACKTRACK node causally ancestral to COMMIT, and cited
again by COMMIT. The same nondecorative structural-use rule applies to at least
one offline-correct ROLE_EQUIV and CAUSAL_JOIN root per life and to the
analogous donor roots for exact donor-valid T-TWIN tokens. Paired T-PATH must
lose and paired T-SHAM must retain, with complete validity/accounting/review.
Missing required dreamed candidates is a valid mechanism failure. If SHAM is
infeasible, the other five arms still run, T-SHAM receives exact zero-attempt
non-dispatch rows, and the aggregate is the valid scientific failure
SHAM_NOT_IDENTIFIABLE rather than an invalid precondition.

## Conditional LoRA transport

Only a reviewed text pass can authorize two fits. Each already-sealed M1_OWN
corpus deterministically compiles to four views and trains one rank-64
Qwen2.5-7B adapter from a pristine base. Each must pass 44 of its 48 fixed
recognition cases separately. L-OWN and L-TWIN use the same clean 32B THINK1
contract and closed read projection as text; the presealed candidate roster is
identical and only the mounted life backend changes.

L passes only if both fidelity gates pass, L-OWN solves the pair using both
registered relation classes, L-TWIN produces both exact donor-valid tokens
using the donor relations, and all isolation/accounting/review checks pass.
The permitted conclusion is immediate access for these registered cues and
behavior paths under host-pre-resolved closed candidate recognition, not text
equivalence, retrieval-free or open recall, whole-corpus storage, durability,
capacity, scale, RAG/raw-context comparison, or superiority.

## Stops and scope

Every stage is exactly INVALID_PRECONDITION, INVALID_INFRASTRUCTURE,
VALID_STAGE_FAILURE, or VALID_STAGE_PASS. Only the pre-ratified stage graph can
grant the next stage, and every result reaches HUMAN_TERMINAL. Counts in the
config are dispatch ceilings; early terminal opportunities are sealed as
non-dispatch ledger entries. Nothing retries.

Replication, new seeds or skins, prompts, models, ranks, learned LOOP policy,
rank pyramids, cascades, Action World, RML/PCFL, longer lifetimes, durability,
base promotion, publication, external actions, credentials, lease operations,
or spend are outside v1d.
