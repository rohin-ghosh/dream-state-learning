# Paper-1 v03r end-to-end canary v1b

**Status:** repaired exact proposal for deliberation only. It authorizes no
implementation, model request, GPU use, LoRA fit, analysis, or claim.

## Question

Test the smallest honest instance of the frozen prompted Paper-1 organism:

```text
public action--outcome life, final goal absent
  -> reliable witnessed atoms
  -> repeated local DREAM connections
  -> fresh blind same-model SELF_CHECK over public evidence
  -> append-only typed memory
  -> non-answer source/target THINK0 probe
  -> fixed OWN return branch, selected without outcomes
  -> truth-blind compile to text
  -> fresh goal-conditioned atomic traversal and paired action
  -> only after text passes, the identical semantic/view/touch manifest
  -> two isolated per-life MEMORY LoRAs
  -> recognition reads, clean 32B composition, paired action
```

This is a strongly process-scaffolded one-pair existence/failure-localization
canary. It does not test the Paper-1 headline, learned LOOP policy, rank
pyramid, lifetime scaling, Action World, RML/PCFL, durability, superiority,
base promotion, or a self-training flywheel.

## Normative files and precedence

The contracts in this directory are jointly normative. If prose conflicts,
the stricter visibility, no-retry, stage-stop, or lower-authority reading wins
and the discrepancy is `INVALID_PRECONDITION`; it may not be repaired during
execution.

- `canary_config.json`: fixed worlds, models, call ceilings, and high-level
  training values.
- `operation_contract.json`: final model-request bytes, scratch, identities,
  schedules, selectors, parsing, and seeds.
- `execution_contract.json`: public projection, typed memory, reflection,
  provenance, reader, compiler, and shared candidates.
- `development_fixture_contract.json`: all six DEV lives, all 31 shortcut
  predictors, gold/donor fixtures, parsers, and scorers.
- `runtime_training_contract.json`: pre-DEV executable lock, exact generation,
  LoRA training, recognition scoring, and receipts.
- `stage_review_contract.json`: monotone authority, exact review packets, and
  terminal validity/claim language.
- the four prompts and five schemas: exact model operation grammars.

No generated free text is memory. DREAM prediction/confidence and SELF_CHECK
prediction/confidence/reason are kept only in a capability-separated audit
stream. They cannot affect semantic hashes, reader returns, corpus views,
candidate lists, LoRA examples, selectors, or any later model request.

## T: held-out recurrent text organism

The scored unit is aligned seed 5, latent bits 0 and 1. Each life is isolated.
The final animal/question/answer remain absent until M0, OWN, DIST, all corpus
manifests, the shared candidate registry, and both intervention exclusion
manifests are sealed.

For each life, chronologically project 46 public episodes into 46 witnessed
rows. Run exactly:

- 46 WAKE proposals, one after each witnessed row;
- 22 REACTIVATE proposals, two after each block of four WAKE events;
- 16 target-absent SLEEP proposals;
- one THINK0 loop of at most 12 operations, terminating in one exact
  CAUSAL_JOIN focus or DEFER;
- literal M0 with zero return calls;
- 16 OWN and 16 DIST return proposals from copy-on-write M0 forks.

Each proposal opportunity is one DREAM call and ends in PASS or one typed
CREATE. Every valid CREATE receives exactly one fresh SELF_CHECK call. Invalid
outputs and duplicate proposals consume their registered opportunities without
retry. Model-self-supported false rows remain eligible and count against
behavior; hidden truth and offline results never steer generation, reflection,
selection, compilation, reading, or thinking.

M1_OWN is the fixed transport corpus regardless of every model result. After
all manifests seal, reveal the public final goal and preseal T-PATH/T-SHAM.
Then run fresh write-denied THINK1 arms, at most 12 operations per twin:

- `T-M0`, `T-OWN`, `T-DIST`, and `T-TWIN`;
- `T-PATH` and `T-SHAM` with presealed equal-count exclusion manifests.

The text gate is prospectively T-OWN: both twins correct; registered role and
causal rows actually returned and cited; T-TWIN emits both exact donor-valid
tokens; T-PATH loses paired success; T-SHAM retains paired success; and all
visibility, runtime, accounting, review, and artifact gates pass. This supports
only the exact strongly frontier-scaffolded one-pair statement in
`stage_review_contract.json`.

Goal-return credit is separate and stricter. It additionally requires no
NO_FOCUS case, T-M0 and T-DIST paired loss, one correctly typed OWN-only
model-self-supported focus-matching row, and actual final citation/use. The
canary may pass without this extra credit.

## L: conditional two-adapter transport

Stage L is unreachable unless T passes, Stage-T artifacts seal, and a fresh
independent reviewer plus author-side advocate approve the exact packet.
Train exactly one rank-64 Qwen2.5-7B MEMORY adapter per life from its already
sealed M1_OWN semantic/view/touch manifest. Reload a pristine base in a fresh
process for each fit; never stack or outcome-select adapters.

Before fitting, seal 12 rows and four cues per row for each life. Each adapter
must independently score at least 44/48. Recognition rosters are constructed
from both sealed lives before fitting and are identical in matched own/donor
requests; only adapter identity changes. The adapter is mounted only while
scoring one atomic candidate set and is unmounted before the clean 32B thinker
continues.

Run L-OWN and L-TWIN under the same THINK1 contract. Stage L passes only if
both per-life fidelity thresholds pass, L-OWN solves both twins using the
registered transported path, and L-TWIN emits both exact donor-valid tokens.
The permitted claim is immediate access for the registered cues and behavior
paths, not whole-corpus preservation, durability, capacity, superiority, or
scale.

## Accounting and stops

Maximum dispatched 32B operations:

- DEV_GOLD: 216 = 72 NO_MEMORY + 72 GOLD_TEXT + 72 GOLD_TWIN;
- HELDOUT_TEXT: 232 proposals + at most 232 self-checks + 24 THINK0 +
  96 core THINK1 + 48 path/sham THINK1 = 632;
- CONDITIONAL_LORA: at most 48 THINK1 operations;
- whole conditional canary: 896.

Separate maxima are exactly two 7B fits, 96 sealed fidelity cue cases, and at
most 48 online 7B-backed recognition reads. Early terminals reduce actual use
but never enlarge a ceiling. No request, malformed result, timeout, or failure
may be retried.

Every outcome is exactly one of `INVALID_PRECONDITION`,
`INVALID_INFRASTRUCTURE`, `VALID_STAGE_FAILURE`, or `VALID_STAGE_PASS` and
routes unconditionally to HUMAN_TERMINAL unless the pre-ratified monotone
stage table explicitly grants the next stage. No result authorizes replication,
prompt/model/rank/seed changes, new benchmarks, broader claims, external
actions, credentials, leases, publication, or spend.
