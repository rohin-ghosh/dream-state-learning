# Consensus — lived mirror writer gateway v1

1. Keep current mechanism and parenting scouts running under simple hygiene.
2. Do not finish or enforce the C11 canonical guard before the final
   paper-grade C11 run.
3. Before the expensive six-bank writer qualification, run one small lived
   mirror-world gateway using the exact scope in this directory.
4. The gateway may establish only that success-filtered, child-grounded
   trajectories can transport an endpoint policy through one mechanically
   rendered, target-masked write and later redirect action after context
   removal.
5. It may not establish autonomous learning, outcome-token causality,
   reasoning-path learning, retention, parenting efficacy, generalization,
   writer qualification, or a paper-grade effect.
6. A gateway pass advances to a separately bound six-bank writer and
   cumulative-retention qualification. A gateway failure is localized and
   preserved; no threshold, arm, or result is silently replaced.
