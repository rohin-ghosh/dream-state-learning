# Independent interpretations

## Interpretation A — writer qualification first

The six-bank scripted true/permuted assay is the cleaner writer-isolation
test because its semantic intervention and training geometry can be matched
exactly. A two-world lived assay has only one paired root, conditions on
successful child behavior, and can show endpoint-policy transport without
showing that outcome tokens caused the write. It should therefore be a bridge
after writer qualification, not a replacement for it. Add a result-blind
development fit and a wake-like multi-turn interface canary.

## Interpretation B — lived gateway first

The two-world lived assay asks a narrower but more thesis-relevant question at
roughly 3--6 GPU-hours: can a native write made from a child's grounded
action--outcome trajectory redirect later action after context removal? Run it
as a cheap gateway before paying for the six-bank qualification. Treat
success-conditioned selection explicitly, machine-match nonsemantic training
geometry, use held templates on training-seen identities as the primary read,
and retain the scripted six-bank assay for repeatability, identity-specific
binding, and cumulative-write survival.

## Shared conclusion

The lived assay does not replace writer qualification. Both interpretations
require native child action targets, strict interface and non-harm checks,
candidate-blind textual-memory controls, frozen thresholds, and bounded
claims. They disagree only about which test runs first.
