# FeltCraft symbolic information kernel v3

**Status:** successor proposal after v2 `rework`; no implementation authority.

## Why this successor is smaller

V2's causal idea survived review: RANDOM and MOTIF should differ only in
whether descriptor alignment persists, while physical action--outcome evidence
is held fixed. V2 nevertheless mixed that mathematical kernel with a finite
random renderer, exact controller sandboxes, codecs, developmental rhetoric,
and future benchmark infrastructure. This created seed-fingerprint and
underspecification failures before the scientific kernel had been proven.

V3 authorizes, if later ratified, only an exhaustive symbolic proof. It asks:

> Does this finite causal family actually have the intended information and
> action geometry before we spend time rendering it for language models?

The full paper objective remains Dream--LoRA--Think across growing action
lifetimes. V3 is one fast falsifier, not a substitute for the benchmark,
model, memory, or GPU study.

## Preserved paper architecture

The later reference system remains:

```text
public action/outcome life
 -> fixed recurrent THINK/DREAM resolver
 -> later-outcome-grounded local claims
 -> deterministic SLEEP compilation
 -> identical compiled text / graph / LoRA content
 -> bounded goal-conditioned reconstruction
 -> held-out actions
```

The explicit graph is a primary baseline. LoRA receives transport/access
credit, not discovery or reasoning credit. Paper claims still require
post-native lifetime cuts, new acquisition, old retention, real composition,
strong RAG/A-MEM/graph/Bayesian/TMEM-like baselines, identical-corpus
text-versus-LoRA tests, resource curves, and later on-policy evidence.

## Corrections adopted from v2 review

- The probability space is the full factorized finite alignment product, not
  the empirical distribution of 128 PRNG seeds. V3 has no handles, seed, RNG,
  serializer, or seed fingerprint.
- The CPU stage is an information-kernel proof, not evidence of development,
  learned compression, or model usability.
- Independent family accumulation is called a later memory-load axis, not
  developmental intelligence by itself.
- The former A3 is renamed a conjunctive-retention diagnostic. The new `BRIDGE`
  target consumes an old-family product and a new-family product in a final
  causal craft, so success requires a real old→new dependency.
- `LOCAL` means target-local calibration only. It is not mislabeled as a full
  atoms-only baseline. `SOURCE` receives all legal source observations. A
  future graph/RAG baseline may synthesize a schema at test time and must not be
  artificially prevented from doing so.
- Twin substitution proves dependence on authentic life-specific semantic
  content only. It does not isolate DREAM, SLEEP, reader, or LoRA causality.
- MDL, codecs, renderer bytes, suffix hashes, and model-stage statistics are
  removed from the first scope.

## Promotion after a symbolic pass

A green v3 proof permits only a new proposal for the rendered common-deck
instrument. That successor must bind fresh hidden test generation, exact
target records, controller/model projections, leakage tests, and the real
memory-load/composition axes. It still cannot skip directly to a GPU claim.

## Requested authority

After two fresh exact interpretations, adversarial critique, consensus, and
explicit human ratification, requested scope is only:

- one pure local CPU enumerator over the exact finite domains in
  `symbolic_contract.md`;
- golden count/action/posterior receipts;
- unit/property tests over the same symbolic functions.

Forbidden: stochastic/rendered worlds, source-life execution, model/provider
calls, tokenizers, DREAM/SLEEP/reader implementation, LoRA/weights, GPU/remote
actions, benchmark promotion, or scientific claims.
