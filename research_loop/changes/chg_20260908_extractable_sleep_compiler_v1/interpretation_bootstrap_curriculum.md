# Fresh interpretation C — teachability bootstrap

Date: 2026-09-09

Status: independent read-only interpretation. No implementation or execution.

- The bootstrap can teach the child how to convert advice into its own
  thought, experiment, action, and revision; it must not teach deployment-task
  answers.
- Use a separate initial stage: bootstrap -> parenting -> autonomous
  experiential learning.
- A first corpus can use roughly 240 verified nursery episodes: six general
  habits x four unrelated task types x ten examples.
- Candidate habits: predict; test competing hypotheses; act instead of looping;
  revise after surprise; scope conclusions; reuse a relevant prior correction.
- Parent advice may be visible conditioning but is response-loss-masked. Only
  the child's own committed thought and executed action are targets.
- Repeat each computation across different situations and wording. Do not
  repeat a teacher sentence as the learned object.
- Test bootstrap x parenting as a 2x2 with matched tasks, compute, sleeps, and
  evaluation.
- Estimate parenting acceleration as `(bootstrap+parent - bootstrap-only) -
  (parent-only - neither)` and time to a fixed parent-absent threshold.
- Phrase overlap is only an echo diagnostic. Uptake requires a changed next
  action, verified outcome, unprompted appearance on a new task, and persistence
  after context reset.
- Falsify teachability if gains are echoes, survive shuffled/wrong advice,
  vanish with the parent, equal a generic entry-level boost without an
  interaction, or damage action/interface behavior.
