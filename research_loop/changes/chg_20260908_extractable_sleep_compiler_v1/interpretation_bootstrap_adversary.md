# Fresh interpretation D — bootstrap and repetition adversary

Date: 2026-09-09

Status: independent read-only interpretation. No implementation or execution.

The bootstrap is feasible, but only if it installs a reusable learning
computation rather than benchmark knowledge or slogans. Mechanically it is
ordinary post-training; the scientific question remains whether subsequent
parenting and lived experience compound through THINK/DREAM/SLEEP.

The current idea of forcing the same first NOTE every episode is risky. It may
recreate the ritual collapse: lexical repetition rises while useful cognition
falls. Repetition should mean repeatedly performing `predict -> test -> revise
-> act` across relevant, varied situations.

A minimal target-blind corpus could contain 192 grounded continuations: six
habits x four unrelated microdomains x eight validated examples. Parent advice
is loss-masked; only the child's resulting thought/action is supervised. Ban
CompilerGym terms, passes, programs, rewards, and final-task action vocabulary.

Use a surface-matched neutral bootstrap in the 2x2 so the comparison is not
merely extra tokens or native-dialect practice. Start with two independent
curriculum roots, 32 lessons, sleeps every eight lessons, and parent-absent
exams at 0/8/16/24/32.

Separate entry improvement from parenting acceleration. Treat an interaction
of at least +0.03 on both initial roots as directional, not final proof, while
requiring no interface/generic-task drop below -0.05. Stop for action-format
failure, work-turn collapse below half the previous child, or paired harm below
-0.05. Stop scaling if four sleeps produce no positive interaction and the
repetition signal is mostly irrelevant phrase reuse.

A learned repetition habit must reappear unprompted, in different words, only
when relevant, and must change the next action. A mantra fails even if word
overlap rises.
