# Paper-1 benchmark adjudication: repaired PCFL-Compose

**Date:** 2026-09-02
**Status:** dispositive independent scientific advisory. This file selects a
research direction; it is not architecture consensus, human ratification,
implementation scope, run approval, or scientific evidence.

## Dispositive ruling

Select exactly:

> **PCFL-Compose core plus an entropy- and interface-matched independent-table
> control, with the designated anchor row/column replaced by a presealed sparse
> connected bipartite observation graph.**

Do **not** use PCFL-Stream or parity-door as a second headline world. Do not run
a powered Stream/Compose hybrid. `Neither` remains the mandatory stop outcome
if the Compose construct, generic-compiler, external-memory, or confirmation
gates below fail; it is not the starting design.

The paper question is:

> Can a frozen generic dream/think controller prospectively connect public
> action--outcome evidence into a self-revised per-life factor model, can a
> restricted sleeper transport that same model through text and LoRA, and can
> a bounded goal-conditioned resolver use it for never-executed old/new action
> compounds after the raw life exceeds context?

This choice maximizes ICLR information value, not implementation probability.
Independent PCFL-Stream is cleaner engineering, but its independent transition
bits make an exact graph/program the prescribed optimal algorithm. A Stream
null would mostly show that learned memory is worse at storing random edges.
Compose can instead distinguish generic prospective abstraction, known-class
fitting, target-time external induction, direct weight learning, parametric
transport, and exact program memory. A hybrid would dilute that question across
two generators, two notions of depth, and two baseline stories.

The safe working title is:

> **PCFL-Compose: Causal Evaluation of Prospective Per-Life Action Models
> Beyond Context**

Neither “LoRA” nor “self-learning” belongs in the title unless later evidence
earns a materially narrower wording.

## A. Selected design

### A.1 Factorized world and matched null

The public state is a tray of six fresh, distinct objects. A tool has a visible
two-part name `USE(stem_i, suffix_j)`. In the factorized regime, life-specific
permutations `A_i,B_j in S_6` and an orientation bit `h` define:

```text
h = 0: T[i,j] = B[j] after A[i]
h = 1: T[i,j] = A[i] after B[j]
```

The agent observes only before/after trays from actual tool use. Fresh handles
force extraction of state-independent positional operators. Registered target
tools are never executed in the source life.

The mandatory negative regime uses the same renderer, two-part labels, source
edge schedule, target constructor, token envelope, observed-edge permutation
entropy/marginals, checkpoints, and failure semantics, but samples each
compound `T[i,j]` independently. Never-executed edges are conditionally
independent and unidentifiable there. The identical primary dream prompt must
be used in both regimes.

Mechanically extracting an observed `S_6` permutation from a public before/after
tray is declared supplied preprocessing and is applied to every arm. The
claimed DREAM operation starts at connecting observed compound operators into
a predictive factor law; it does not start at parsing a tray.

### A.2 Adopt the sparse connected observation-graph repair

Replace **designated** anchor rows and columns with one presealed life-wide
sparse connected bipartite observation graph. The minimum construction below
is honestly an unlabeled symmetric double-star: its high-degree `u0/j0` hubs
are visible in the source topology. Thus public two-part morphology and graph
topology are supplied scaffolding; only the anchor designation and completion
formula are withheld. New lifetime blocks attach fresh vertices through
symmetric tree edges to the existing component and never create an
unidentifiable disconnected component.

For a clean D4 module use at least `r=9,c=5`: paired stems
`(u_l,v_l), l=1..4`, support stem `u0`, support suffix `j0`, and decisive
suffixes `j_l`. Execute the symmetric 13-edge tree

```text
(u_l,j0), (v_l,j0) for l=1..4
(u0,j0), (u0,j_l) for l=1..4.
```

Leave every decisive `(u_l,j_l)` and `(v_l,j_l)` absent. Then use this
chronology:

1. Invoke **Dream-1**. The generic resolver may commit at most two candidate
   program objects. Each object contains the model's own gauge/latent-factor
   representation, orientation claim, and predictions for the presealed
   symmetric revision-chord orbit `(u1,j2),(v1,j2)`. Every candidate,
   abstention, and malformed record is charged and retained.
2. Execute those two chords as ordinary public actions and append only their
   raw before/after events. No correctness label is returned to cognition.
3. Invoke one bounded **Dream-2** revision. Reading the raw chord events, the
   resolver itself chooses `RETAIN`, `REVISE`, or `ABSTAIN`, then commits one
   final program and predictions for the disjoint audit-chord orbit
   `(u2,j3),(v2,j3)`.
4. The sleeper performs only syntax, taint, provenance, deduplication, and view
   realization, then freezes that model-chosen snapshot. False but well-formed
   self-approved records stay in the corpus.
5. Execute the two audit chords in a sealed post-freeze continuation. Their
   outcomes are scored offline and never re-enter this memory checkpoint.
   Primary targets remain absent throughout.

The certifier must ensure that the two orientations disagree on every
revision/audit chord, that registered operators do not commute on the
order-sensitive panel, and that the complete graph never enters an
orientation-degenerate commuting subgroup. Conditional on orientation, a
three-edge path `i--j1--i2--j` identifies an absent target edge:

```text
h = 0: T[i,j] = T[i2,j] * inverse(T[i2,j1]) * T[i,j1]
h = 1: T[i,j] = T[i,j1] * inverse(T[i2,j1]) * T[i2,j]
```

These equations belong in the offline certifier and class-informed ceiling,
not the primary prompt. The exact program may choose a gauge. The primary
model must emit its own factor records; the sleeper may serialize but may not
tree-propagate or gauge-fix them. No scorer-chosen gauge, latent factor,
completion, solver trace, or target path may enter a primary prompt, corpus,
candidate set, cache, filename, or failure message.

This is a modest presentation/chronology repair, not removal of the
factorization scaffold. It makes connected evidence and prospective chords
explicit, but does **not** by itself establish autonomous graph discovery,
unsupervised family discovery, or a general connected-memory algorithm. The
matched independent-table regime, not the unlabeled hubs, is the family-
specificity test.

### A.3 Generic compiler versus class-informed ceilings

The primary compiler is a frozen prompted resolver plus a restricted
deterministic sleeper:

- The generic dream prompt may state that public tool names have two parts and
  may offer general operations such as compare, hypothesize, predict, revise,
  compose, and abstain.
- Its output language must be a preregistered general predictive-operator DSL
  usable without a PCFL regime label. It may not state the factor equations,
  `S_6` hypothesis class, two possible orientations, observation-graph paths,
  reserved roles, or target partition.
- Prompt, DSL, parser, proposal cap, retry policy, and stopping rule are
  identical in factorized and independent-table lives and freeze on DEV roots.
- The sleeper may canonicalize, deduplicate, enforce syntax/taint/provenance,
  preserve model revisions and contradictions, and generate equivalent access
  views. It may not determine truth, infer a missing law, propagate factors,
  choose a gauge, enumerate a closure, or repair a proposal. A false but
  well-formed `SELF_RETAINED` record is trained and counted.

Four distinct ceilings remain separate:

1. **Class-informed compiler:** receives the finite PCFL factor family and path
   equations. Success supports known-family fitting only.
2. **Oracle-schema text:** receives the correct public-identifiable schema and
   tests reader/thinker usability.
3. **Exact public program:** derives the sufficient statistic and plans
   exactly. It certifies construct solvability and is expected to dominate
   correctness/bytes; it is never an organism baseline that neural memory must
   beat.
4. **Perfect public-checker memory:** an exact comparator may label and admit
   only predictions matching later public chords. This localizes
   self-verification loss, but it is a verifier-assisted ceiling and cannot
   support the headline organism claim.

### A.4 Public self-verification without oracle leakage

The headline firewall is chronological and process-level:

```text
hidden certifier/scorer                         exact offline comparator
          |                                               ^
          | no model-visible channel                      |
          X                                               |
public prefix -> Dream-1 commit -> raw chord events -> Dream-2 self decision
                                                          |
                                      syntax-only sleeper -> frozen corpus
```

- The certifier alone sees hidden factors, twins, target paths, alternative
  proofs, and exact solver output.
- Dream-2 sees raw public chord outcomes, not a checker verdict, and owns
  `RETAIN/REVISE/ABSTAIN`. The exact comparator runs only after the final
  memory is frozen. Its `CORRECT/INCORRECT` score never enters corpus
  admission, training, retrieval, retries, or any later cognitive state.
- Target goals, target edge identities, reserved-role metadata, certificates,
  and all descendants are tainted through trainer, reader, indexes, candidates,
  caches, RNG, filenames, exceptions, timing, and retry state.
- The schema and all memory treatments are frozen and hashed before evaluation
  targets are rendered.
- False self-retained, self-revised, abstained, malformed,
  compilation-failed, training-failed, timeout, and runtime-failed assignments
  stay in the presealed denominator.
- Evaluation outcomes are sterile: they do not re-enter episodic, semantic,
  compiler, adapter, or cache state, and pre/post life hashes must match.

This tests whether the organism can use public experience to revise itself.
The perfect public-checker arm measures how much an oracle gate would repair
without silently granting that repair to the headline condition.

### A.5 Targets, reads, and action credit

All target menus are visible initially. The model must issue real `USE`
actions and a final `LOCK`; a plan string, predicted permutation, answer label,
or citation earns no credit. D1 and D4 are the only depths.

- Every target edge is absent from source experience and has an independently
  certified three-observed-edge derivation path.
- Every D4 item has a unique successful sequence among its 16 menu sequences,
  no shorter route, and four factor-disjoint decisive stages.
- Every target has a goal twin for which all model-visible non-goal bytes are
  identical, while the goal bytes intentionally differ and require a different
  first action.
- New targets use only factors introduced since the prior checkpoint. Old
  targets use earliest-block factors whose last public evidence lies outside
  `L_native`. Cross-era D4 uses two old-stem/new-suffix stages and two
  new-stem/old-suffix stages; its old, new, and both-factor cuts are presealed.
- D4 uses a sealed uniform stage-twin orbit `H_z, z in {0,1}^4`. Bit `z_l`
  independently swaps `(u_l,v_l)` at stage `l`. For each separately rendered
  member of a goal-twin pair, the complete goal-target packet is byte-invariant
  across all 16 world-orbit members, which have distinct correct sequences.
  The generator prior is uniform over the free orbit, so target-only
  full-trajectory Bayes value is
  exactly `1/16` (`1/2` for first action and D1). A single global two-world
  swap would support only a `1/2` D4 ceiling and is forbidden for that claim.

One compiled-memory reader call returns exactly one model-emitted gauge-fixed
stem factor, suffix factor, orientation record, or `NOT_FOUND`; never a
completed target compound, chain, or plan. Use:

```text
D1 compiled schema:  4 local items; 10 resolver operations; 1 USE + LOCK
D4 compiled schema: 13 local items; 31 resolver operations; 4 USE + LOCK
```

The D4 grammar requires eight candidate stem records, four suffix records, and
one orientation record. A minimum-read certifier must show that substituting
each declared necessary record can change the correct choice.

Raw episodic path induction can legitimately require up to 25 observed-edge
items for eight three-edge candidate paths plus the law. Therefore there is no
single common item cap across unlike native interfaces. Run RAG/A-MEM at both
an equal serialized-token frontier and a construct-sufficient frontier of up
to 25 edge items; run compiled text/LoRA at their 13-item sufficient frontier.
Report actual bytes, tokens, calls, latency, and resolver work. Accuracy at an
insufficient cap is only a resource point, never baseline failure. A one-shot
full-schema planner receives the same 13 items and total model-token budget as
the iterative resolver; if it matches, recurrent THINK is unnecessary here.

### A.6 What architecture arrows this world does and does not measure

The selected design measures one fixed-controller information-flow pass:

```text
public action/outcome
  -> immutable experience
  -> generic prospective Dream-1
  -> later public validation
  -> Dream-2 revision
  -> restricted sleep compilation
  -> text or per-life LoRA realization
  -> bounded goal-conditioned reads/workspace
  -> executed action
```

It can identify:

- experience-to-prospective-connection, if the generic prompt succeeds while
  the independent regime does not;
- public-outcome self-verification and one revision, through raw chord events
  and pre/post commitments, with correctness scored only offline;
- sleep representation value, if prompted compiled text beats atom-only/raw
  treatments or changes the target-time resource frontier;
- LoRA persistence/associative transport, through identical-corpus and
  authentic/twin interventions; and
- goal-conditioned use, through typed reads, explicit working paths, goal
  twins, and executed trajectories.

It does not identify adaptive replay selection, thinker-agenda-to-dream,
wake-trace shortcut formation, recurrent versus batch sleep cadence,
memory-selected exploration, better-action-to-better-evidence mediation,
revision after a world change, a learned scheduler/critic, or a learned LOOP
adapter. Fixed source actions break the full online flywheel. These arrows are
absent, not falsified, and remain out of Paper 1.

## B. Minimal causal graph and estimands

### B.1 Graph

```text
                         [hidden factors / targets / certificates]
                                      scorer only
                                           X
                                           |
fixed public explorer -> episodic events -> observed-edge atoms
                                           |
                   +-----------------------+----------------------+
                   |                       |                      |
             raw RAG/A-MEM          generic Dream-1         exact program
             target-time path        -> raw chord event        labeled ceiling
             induction allowed       -> Dream-2 self-decision       |
                   |                 -> syntax-only sleep           |
                   |                       |                        |
                   |              model-chosen corpus C_k          |
                   |                  /             \              |
                   |             text C_k       LoRA(C_k)          |
                   |                  \             /              |
                   +------------ bounded common reader ------------+
                                           |
                                  iterative wake resolver
                                           |
                                    USE...USE, LOCK
                                           |
                               failure-inclusive action value
```

Direct-QA/raw-history LoRA branches from public events, class-informed and
oracle-schema arms branch around generic Dream, and candidate-only/wrong-adapter
cells intervene between corpus and reader. None may receive scorer data.

### B.2 Unit and notation

The independent unit is a world-life **orbit root** `b`, never an orbit member,
target, goal twin, checkpoint, stage, reader call, model sample, or training
seed. Each root defines and CPU-certifies the complete byte-identical
`{H_b,z : z in {0,1}^4}` orbit. The primary life samples one hidden
`z_b` uniformly. One predeclared counterpart `z_b*=z_b XOR 1111` is materialized
for whole-memory causal swaps. Those two realized variants remain nested in
root `b`; their existence alone is not the basis of the `1/16` Bayes ceiling.
That ceiling follows from the certified uniform 16-state generator prior.

Let
`Y[m,b,k,d,e]` be unconditional normalized executed action value for method
`m`, checkpoint `k`, depth `d in {1,4}`, and era
`e in {new, old, cross}`. The primary value is binary terminal success: the
registered public trajectory followed by `LOCK` scores one, and every wrong,
illegal, malformed, timeout, or missing assignment scores zero. Return,
actions-to-success, and query cost are secondary; they cannot rescue a failed
trajectory.

The fixed checkpoints are:

```text
k in {0.75, 1.5, 3, 6} * L_native
```

`L_native` is tokenizer-exact usable history after subtracting the frozen
system prompt, goal/state, reader/workspace, operation history, and output
reserve. New factor-bearing source edges, not repetitions, views, chords, or
distractors, must create every crossing. Report
`H_k=(r_k+c_k-1)log2(720)+1`, introduced, publicly witnessed,
self-retained, offline-correct, compiled, read, and action-usable factors, and
every information-bearing byte store.

### B.3 Primary estimands

1. **Prospective schema specificity** at the registered `3L_native` sentinel:

   ```text
   Delta_schema = [Y(generic-text,F)-Y(atom-only,F)]
                - [Y(generic-text,I)-Y(atom-only,I)]
   ```

   `F` is factorized and `I` is the matched independent-table regime. The
   generic condition must also predict validation chords before observation;
   target action alone is insufficient.

2. **Compilation versus target-time external induction:** report both
   preregistered contrasts, without choosing a winner post hoc:

   ```text
   Delta_RAG   = Y(generic-text) - Y(raw iterative RAG)
   Delta_AMEM  = Y(generic-text) - Y(native A-MEM/linked memory)
   ```

   Each external method is evaluated at both the equal-token point and its
   preregistered construct-sufficient/native frontier; the contrast above uses
   its strongest legitimate frontier point, not a starved cell. A compilation-
   superiority claim requires both simultaneous lower bounds above zero.
   Noninferiority within `0.05` plus at least 50% lower amortized target-time
   model/read tokens may support an efficiency claim, not an accuracy claim.

3. **Parametric transport:**

   ```text
   Delta_transport = Y(compiled-LoRA) - Y(identical compiled text)
   Delta_direct    = Y(compiled-LoRA) - Y(direct-QA LoRA)
   ```

   LoRA transport requires the simultaneous lower bound for
   `Delta_transport` to exceed `-0.05`, authentic-binding action above its
   controls, and either `Delta_direct>0` or a nondominated fully accounted
   resource point. LoRA is not credited with discovering the schema.

4. **Life-binding causality:**

   ```text
   Delta_counterpart = mean(Y(H_z/M_z), Y(H_z*/M_z*))
                     - mean(Y(H_z/M_z*), Y(H_z*/M_z))

   Delta_law  = Y(sham-cut) - Y(wrong-order memory)
   Delta_bind = Y(sham-cut) - Y(decisive-factor-swap memory)
   ```

   Crossed memory must redirect the first action toward the counterpart-valid
   sequence, not merely change behavior. `Delta_law` and `Delta_bind` must be
   positive on registered noncommuting D4 targets. This two-realized-side
   intervention estimates binding causality; it does not establish the
   population `1/16` ceiling, which is a separate full-orbit construct proof.

5. **Developmental persistence:**

   ```text
   Acquisition_k = Y(M_k,T_new,k) - Y(M_k-1,T_new,k)
   Retention_k   = Y(M_k,T_old) - Y(M_acquisition,T_old)
   CrossEra_k    = Y(M_k,T_cross)
                  - max(Y(old-cut),Y(new-cut),Y(both-cut))
   ```

   A finite post-context growth claim requires, at each of `1.5L`, `3L`, and
   `6L`, a simultaneous 95% lower bound above zero for `Acquisition_k` and
   `CrossEra_k`, and a lower bound above `-0.05` for `Retention_k`. Report
   post-context AUC on the log-lifetime axis and all three components
   separately; no aggregate may offset forgetting or stalled acquisition.

6. **Thinker ownership:** first-action redirection on the exact goal twin,
   useful-query precision, valid cited working-path rate, and
   `Y(iterative)-Y(one-shot-full-schema)` at matched information and model
   work. If the one-shot arm matches, claim goal-conditioned use but not an
   advantage from recurrent THINK.

A named baseline may be called **plateaued** only if its simultaneous 95%
intervals for both `1.5L -> 3L` and `3L -> 6L` change lie wholly inside
`[-0.05,+0.05]`. Losing to another method is not plateau evidence. A
post-context crossover/onset is named only when a paired advantage has a lower
bound above zero and remains above zero at the next two checkpoints.

Confirmation uses root-wise paired estimands and root-blocked bootstrap
intervals, with realized orbit variants treated as nested interventions. An
exact paired randomization test is permitted only when the relevant within-root
assignment was actually randomized or is demonstrably exchangeable. Otherwise
a sign-flip permutation analysis may be reported only as conditional on the
preregistered orbit-symmetry/exchangeability assumptions, not as design-exact.
Holm adjustment applies across the declared D4 new/old/cross secondary
contrasts. The practical margins above are part of the proposed design and
require exact human ratification before use.

9. identical-corpus compiled LoRA; and
10. oracle-schema text;
11. perfect-public-checker-filtered text ceiling.

At the `3L_native` sentinel on all 20 roots, add class-informed text,
orientation-deleted facts, one-shot thinker, candidate-only, matched

No rank grid, second backbone, multiple skins, parity-door, full Stream world,

## D. Baseline dominance and neighboring-artifact disposition

### D.1 Exact program, RAG, and A-MEM

- **Exact program dominance is expected.** It establishes public
  identifiability and the structured ceiling. Neural methods need not beat it.
  If only the program succeeds, the organism hypothesis fails; a one-backbone
  two-week null is not a paper by itself.
- **RAG/A-MEM parity localizes the intelligence.** If either faithfully induces
  the law at target time and matches generic compilation, prospective sleep
  compilation has no accuracy moat. A powered, released study can still be a
  publishable causal benchmark showing that target-time external abstraction
  suffices; it cannot claim DREAM superiority.
- **RAG/A-MEM strict frontier dominance removes the system claim.** Retain the
  benchmark and mechanistic failure map only if the powered multi-arm evidence
  is broad enough; otherwise select neither for Paper 1.
- An arbitrary common-reader cap may not be used to handicap native A-MEM. Its
  native interface, index bytes, calls, and compute must be disclosed.

### D.2 LoRA's role

LoRA is only the per-life persistence/associative-access organ. It does not
discover the law, prove compression, store an invertible graph, or become the
task policy. Same-corpus text/LoRA identifies transport; direct-QA/raw LoRA
tests whether explicit sleep compilation mattered; unaided/candidate-only and
wrong/twin cells locate information in weights versus the reader. If text or
the exact program dominates every resource point, LoRA moves to a diagnostic
table and leaves the title and contribution sentence.

### D.3 FactWorld and ActionShift

The environment mathematics is not a priority claim.

- FactWorld forecloses “first non-abelian/noncommutative action benchmark” and
  “first parametric-versus-context composition benchmark.” Cite it and include
  an explicit protocol table covering its state-only, binding-only,
  state-by-binding, deferred-readout, context, and parametric conditions.
- ActionShift forecloses “first hidden compositional action interface.” Cite it
  and include a bounded target-time no-persistent-memory probe sentinel inside
  PCFL. If short per-target calibration solves PCFL, reframe it as hidden action
  ABI adaptation and abandon the long-lifetime-memory claim.
- Do not spend the core roster on an incomparable robot reimplementation or an
  unpowered cross-benchmark leaderboard. A pinned FactWorld empirical bridge
  may be secondary if its public protocol can be reproduced faithfully; mark
  it `NOT_RUN` otherwise and make no empirical superiority claim.

PCFL's defensible novelty is the full conjunction: hidden per-life operator
semantics learned from public outcomes; generic target-blind prospective
connection; matched text/native-graph/direct-QA/compiled-LoRA treatments;
post-context new/old/cross-era action; and exact twin/law/binding
interventions.

## E. Claim ladder, falsifiers, and publishable result patterns

### E.1 Claim ladder

- **C0 — Construct validity.** The released generator provides increasing
  public factor entropy, never-executed action compounds, an exact uniform
  `2^4` stage-twin orbit, graph/path and depth certificates, and an exact
  public program under the registered interface-specific caps.
- **C1 — Prospective generic connection.** The frozen generic resolver commits
  a factorized predictive program before chord outcomes, self-retains/revises/
  abstains after reading raw public outcomes, stays at chance or abstains on
  independent tables, and its final self-chosen law scores prospectively
  correct offline on disjoint audit chords and target compounds.
- **C2 — Sleep/compiler utility.** Restricted target-blind compilation improves
  D4 action or the fully counted amortized target-time frontier over atom-only,
  raw-history, and named target-time external-memory controls; law/factor cuts
  redirect action.
- **C3 — Goal-conditioned constructive use.** Bounded local reads create valid
  working paths and goal twins redirect actual D1/D4 trajectories. Recurrent
  THINK is claimed only if it adds value over the one-shot information-matched
  control.
- **C4 — Conditional parametric transport.** Identical-corpus per-life LoRA is
  faithful/noninferior to text, beats its reader/wrong-life/direct-write
  controls or occupies a nondominated resource point, and mediates action under
  whole-life twin and factor/law interventions.
- **C5 — Finite post-context capability.** At all three post-native points, the
  named system acquires new factors, retains earliest factors within the
  registered margin, and composes old/new factors above causal cuts while
  unique factor entropy continues to grow.
- **C6 — Named efficiency frontier, optional.** Only full byte/call/FLOP/
  latency/amortization accounting may support a named action--storage--query--
  compute trade-off claim.

Even C6 does not license autonomous/open-ended dream discovery, semantic or
asymptotic compression, generic SOTA superiority, naturalistic validity,
on-policy self-improvement, improved evidence acquisition, human-like
development, unbounded continual learning, a learned scheduler/critic, or a
learned LOOP policy.

### E.2 Hard falsifiers

1. Factorized and independent-table generic arms both gain: leakage,
   hallucination selection, or invalid matching; invalidate the assay.
2. Generic fails while class-informed succeeds: only known-family completion,
   not generic DREAM connection.
3. Oracle-schema text succeeds while generic text fails: dream/compiler is the
   bottleneck; no organism-path result.
4. Only the exact program succeeds: valid construct, failed neural abstraction.
5. Raw RAG/A-MEM matches generic text at matched resource accounting: no
   prospective compilation advantage.
6. Orientation-deleted atoms match full schema: the stored higher-order
   connection was unnecessary.
7. Direct-QA/raw LoRA matches compiled LoRA: sleep compilation adds no
   parametric value.
8. Candidate-only or wrong/twin adapter matches compiled LoRA, or unaided reads
   collapse: information resides in the reader/index, not demonstrably in
   weights.
9. One-shot full-schema planning matches iterative use: no recurrent THINK
   advantage.
10. Goal twins, whole-life twins, wrong-order memory, or decisive-factor swaps
    fail to redirect the certified trajectory relative to shams: authentic
    memory was not causally used.
11. `M_k-1` solves new targets: acquisition is leaked or prior-driven.
12. New acquisition stalls, earliest-factor retention falls below the margin,
    or cross-era action survives old/new cuts: no continuing constructive
    per-life capability over the range.
13. Fewer than three strictly post-native checkpoints, repeated-token growth,
    or linear hidden candidate scans: no scaling/crossover claim.
14. Any hidden truth, target descendant, solver artifact, post-hoc retry, or
    dropped failed assignment enters cognition: no scientific interpretation.
15. Any exact comparator verdict controls headline memory admission, revision,
    training, or retrieval: the public checker, not the organism, performed
    self-verification; relabel that arm as a ceiling.

### E.3 Exact result patterns that remain publishable

| Observed pattern after locked confirmation | Publishable interpretation |
|---|---|
| Generic text passes prospectively, independent control stays null, cuts redirect, and text beats or efficiently matches RAG/A-MEM | Strong benchmark plus prospective fixed-controller experiential-abstraction result. |
| Generic text passes, but LoRA fails same-corpus fidelity or is dominated | Publishable DREAM/sleep-schema and substrate-boundary paper; no parametric-memory claim or LoRA title. |
| Dream-1 proposes a correct candidate, self-revision fails, and only the perfect public-checker ceiling succeeds | A potentially publishable self-verification bottleneck only after a powered multi-system study; no headline organism-path success. |
| Generic text and compiled LoRA pass; LoRA is noninferior and nondominated versus direct-QA/reader controls | Add conditional per-life parametric-transport result; still no LoRA-algorithm novelty. |
| RAG or native A-MEM matches/beats generic text | Publishable causal benchmark/resource study if powered and released: target-time external abstraction suffices; no DREAM moat. |
| Direct-QA LoRA matches compiled LoRA while twins/cuts pass | Publishable evidence for implicit factor learning in weights, but no explicit sleep-compilation advantage. |
| Class-informed succeeds and generic fails | A narrower known-grammar completion benchmark may be publishable only with a strong released multi-system study; not an architecture result. |
| Exact program succeeds and all learned arms fail | Not a two-week or single-backbone paper. Potential negative benchmark paper only after multiple capable systems show a stable, prospective abstraction gap. |
| Mechanism passes pre-context but acquisition/retention/cross-era fails post-context | Publishable finite mechanism/capacity-boundary result if powered; remove growth, crossover, and continued-learning claims. |
| Exact program or A-MEM strictly dominates the full resource frontier | Benchmark/failure-map contribution only; if the released powered study is not independently substantial, choose neither. |
| Independent control gains, twins are distinguishable, or causal cuts do not work | Invalid experiment, not a negative result; repair before any paper claim. |

No DEV pattern is paper evidence. Publishability above assumes 20-root locked,
failure-inclusive confirmation, faithful baselines, complete artifacts, and a
public deterministic generator/certifier/evaluator release. Without that
release, call PCFL-Compose a controlled assay rather than a benchmark.
