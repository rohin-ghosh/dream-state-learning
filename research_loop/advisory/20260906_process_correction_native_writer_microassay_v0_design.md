# Process-correction native-writer micro-assay v0

Date: 2026-09-06

Status: **design advisory only**. This is not an architecture-change artifact,
ratification candidate, implementation authorization, benchmark choice, task
seal, model/tool call, CPU/GPU authorization, experiment, result, or scientific
claim. It changes no existing file or frozen protocol. Any implementation must
start a new `AGENTS.md` deliberation from the exact later human directive.

## Decision

The smallest useful next parenting experiment is not a childhood curriculum or
a long life. It is one prospectively recorded interface correction followed by
one native response-only rank-8 write and a parent-absent held-out test.

The registered question should be:

> Among prospectively selected child roots that produce one useful action in an
> inert prose channel and can repair that same action after one process-only
> correction, does a correction-derived, native-response rank-8 LoRA increase
> parent-absent typed-tool compliance on content- and action-disjoint tasks,
> while preserving the quality of action proposals when routing is guaranteed?

This is a conditional writer/teachability assay. It is not a test of learned
THINK, continual improvement, dreaming, intelligent sleep, broad parenting,
or an Experience Model flywheel.

## Why this is the next causal unit

Fable B2 motivates, but does not answer, this question. At episode 1,024 its
registered strict score was `0.0511`, adapter-off was `0.4859`, and a post-hoc
permissive extraction of the same saved output scored `0.5287`. The exact
writer had amplified Markdown action forms until useful proposals stopped
dispatching. Because generation was unseeded and writer/context policy were
confounded, those numbers are mechanism localization, not a causal benefit.
No Fable/B2 or legacy nursery row enters this assay's source, rehearsal,
calibration, writer, or target data.

The prospective assay therefore separates:

1. **routing:** does ordinary free generation emit one accepted typed call?;
2. **proposal content:** when an exact typed grammar guarantees routing, is the
   selected action still useful?; and
3. **writer attribution:** is any change caused by the authentic correction
   scaffold rather than native-format imitation, a batch recovery writer, or
   mismatched state/action labels?

LEAFE (`arXiv:2603.16843`) is direct precedent, not novelty whitespace. It
already performs reflection, rollback, improved-branch generation, removal of
the explicit experience at test time, SFT into the acting policy, and behavior
rehearsal. This assay must include a LEAFE-style batch recovery control. At
most it can isolate a human process-correction package in one per-life low-rank
state. A later repeated-write lifetime study must compare periodic personal
writes against one final LEAFE-style batch write at matched accepted rows,
supervised tokens, and optimization budget.

## Benchmark contract; selection deliberately deferred

This advisory selects no benchmark, task family, tool name, action vocabulary,
source task, development task, or target task. A later architecture intake must
choose a family satisfying all of the following before exposing any target:

- one closed, offered typed-tool schema and one inert assistant-text channel;
- a bounded action object whose exact normalized arguments can be compared
  across response channels;
- a deterministic, fresh-reset public evaluator returning a predeclared
  normalized action-quality scalar and a separate dispatch-validity bit;
- no hidden reference action visible to the child, parent, writer, or selector;
- enough state/action diversity to support distinct source, rehearsal,
  calibration, and target partitions and a no-fixed-point action derangement;
- content hashes, canonical task identities, and normalized action-tuple hashes
  sufficient to make those partitions auditable;
- a measurable population of “useful proposal, wrong channel” events under a
  frozen base without modifying prompts after observing target behavior; and
- a pure or transactionally reset evaluator so offline diagnostics do not
  contaminate later calls.

Failure to find such a family is a design NO-GO, not permission to weaken the
near-miss, derangement, or held-out definitions. The exact task-selection law,
task count, quality scale, SESOI, and non-erasure margin must be separately
ratified before any task identity or model output is exposed.

## Prospective source root

Use exactly 12 eligible source roots, selected as the first 12 eligible roots
in a prebound order from a maximum of 48 attempted roots. Each root binds one
base-model process, model/tokenizer/tool-template revisions, loaded source
hashes, generation and adapter seeds, and a source-task pair. Every failed
attempt remains in the receipt. Fewer than 12 eligible roots is NO-GO; do not
lower the count, replace roots, or treat tasks within a root as replications.

Eligibility is intentionally conditional and must be stated in every result.
For root `i`:

1. **Initial near-miss.** On source task `S_i`, ordinary free generation sees
   the offered schema but emits no structured call. A frozen offline parser
   finds exactly one normalized, schema-legal action proposal in assistant
   prose. Evaluating that saved proposal once from a fresh reset exceeds a
   prebound useful-action floor. The parent sees only the public response and
   parser result, never this quality score or a reference answer.
2. **Correction.** A fixed process-only parent message is inserted. It contains
   no task identifier, action name, argument, score, reference answer, hidden
   outcome, or target-derived token.
3. **Restatement.** The child returns one closed process-restatement object in
   assistant text and no tool call. It must name the effective channel, state
   that prose is inert, commit to one call, and say that action content comes
   from its own prior proposal. It is rejected if it contains a source task
   identifier, action argument, normalized action tuple, or numeric score.
4. **Rollback and retry.** From the exact original pre-response state, with the
   correction and restatement visible, the child must emit exactly one accepted
   typed call. Its normalized action arguments must equal the action extracted
   from its own initial prose byte-for-byte after the frozen canonicalization.
   Thus the parent changes only routing; it supplies no action content.
5. **Near transfer.** On a second, content-distinct source task `T_i`, the parent
   correction is absent and only the child's restatement is present. The child
   must emit one accepted typed call whose public outcome meets the prebound
   legality/usefulness floor. `T_i` is still training-source material, never a
   held-out endpoint.

Both the corrected retry and near-transfer call must pass the typed provenance
and outcome bindings. A root failing any step is an ineligible attempted root,
not a negative target observation. The permitted estimand is therefore “among
registered, in-context-correctable near-miss roots,” not all agents or tasks.

### Proposed literal parent correction

The later ratification may accept or replace these bytes, but it must bind one
literal version before source generation:

```text
Your previous response did not dispatch an action. Assistant prose, Markdown,
and action-looking text are inert. Keep the action you already chose; do not
change it because of this feedback. On retry, emit exactly one schema-valid
call through the offered structured tool channel and put no action in prose.
First restate only this routing rule without naming the task, an action, an
argument, a score, or an answer.
```

The parent is deterministic in this floor. A model parent, multiple teachers,
personalized advice, or correction about reasoning quality is a successor.

### Exact restatement surface

The restatement request requires one JSON object with exactly these keys and
closed values, serialized in the eventual frozen assistant-text dialect:

```json
{"action_content_source":"my_prior_proposal","assistant_prose_effect":"inert","dispatch_channel":"offered_structured_tool_channel","number_of_calls":1}
```

This is a manipulation check, not evidence of semantic understanding. The
exact generated bytes and IDs are persisted before retry; no missing or
malformed restatement is repaired. The restatement is masked input during
writer training, never an assistant target.

## Native response-only writer and scaffold fading

For each eligible root, the two accepted child calls—the corrected retry and
near-transfer response—produce two exact native assistant-response targets
`y_i0,y_i1`. Each target is the model's real structured response envelope,
bound to the offered schema, parser decision, normalized action, dispatch, and
public outcome. It contains exactly one tool call and no assistant prose.

For each target, form exactly four prompt variants while keeping the ordinary
bootstrap, task state, offered schema, generation boundary, response target,
and terminal EOS fixed:

1. `P3_PARENT`: ordinary state plus the exact parent correction;
2. `P2_CHILD`: ordinary state plus the exact child restatement, with the parent
   absent;
3. `P1_CUE`: ordinary state plus one frozen neutral self-review cue;
4. `P0_STATE`: ordinary state alone.

This is scaffold fading inside one write, not four observations. The same
target appears once at each rung. Do not add a model-generated summary,
principle, dream, or synthetic counterfactual.

Encode every example through the exact native chat/tool template used by the
live child. Freeze the invocation-message bytes, offered-schema bytes,
generation-boundary index, response-envelope bytes, input IDs, response IDs,
label mask, and EOS. Loss is applied only to the complete native assistant
response suffix (including required structured-channel control tokens and the
child-sourced action arguments) plus EOS. System/user/tool-schema, correction,
restatement, cue, old transcript, tool result, score, and rehearsal history are
masked inputs. No bare text, whole-sequence loss, reconstructed prompt, or
casually normalized JSON is permitted.

The exact response-ID vector for a target must be identical across all four
rungs and causal cells. Concatenate the frozen response suffix at the frozen
generation boundary rather than retokenizing across it. Reject zero-label,
missing-EOS, truncated, overlength, nonfinite, or cross-cell row mismatches.

### Rehearsal guard

Every trained cell also receives the same prebound successful-behavior rehearsal
packet, following LEAFE's relevant stability control. It contains only
prospectively generated, source- and target-disjoint successful native responses
from the same child root. Rehearsal rows use the same response-only writer and
are fixed before causal corpus construction. Their row count, target tokens,
update positions, and ordering are identical in every trained cell.

Rehearsal is part of the registered writer package, not proof that correction
caused retention. A later no-rehearsal ablation is required before attributing
non-erasure to rehearsal itself.

## Causal cells at the chosen rank-8 heat

All trained cells start independently from the same frozen base and the same
root-specific rank-8 initialization bytes, and receive identical rehearsal,
response-target multisets, supervised target-token totals, row counts, and
optimizer-update counts. W1--W3 retain the exact W2 target order. W4 alone
changes target-to-state assignment by design; its permutation and per-update
target order are frozen before training and reported rather than described as
order-matched.

| Cell | Correction-derived corpus | Purpose |
|---|---|---|
| `W0_BASE` | none; no adapter | Frozen parent-absent reference. |
| `W1_NATIVE_SHAM` | Four-rung shape and exact targets, but parent/restatement slots contain target-blind sham strings token-length-matched per row; cue/state rungs are identical to W2. | Controls native tool-format SFT, repeated targets, role/position length, rehearsal, and update heat without authentic correction semantics. |
| `W2_PARENT_FADE` | Exact `P3..P0` ladder above. | Registered correction-derived writer. |
| `W3_LEAFE_BATCH` | Original failure history maps to the same accepted improved native response with the explicit parent correction and child restatement removed; dose, response targets, rehearsal, and optimization budget match W2. | LEAFE-style batch recovery-writer precedent/control; not a full LEAFE reproduction or a novel mechanism. |
| `W4_ACTION_DERANGED` | W2 inputs, but the two response targets are swapped within root; no fixed point, target action tuples differ, the aggregate response-token multiset and update-count budget are preserved, and both calls remain schema-legal. | Tests whether syntax-only learning survives while state/action binding is broken. |
| `W2_ADAPTER_OFF` | Exact W2 checkpoint served from a fresh state with the adapter absent. | Localizes target behavior to parametric state; it is not a separate trained life. |

Sham strings are produced only after the tokenizer is frozen, using a
predeclared target-blind neutral-token generator, and must match the replaced
prefix's token count and role position exactly without containing tool-channel,
task, action, correction, or target vocabulary. This makes W2-W1 a semantic
scaffold-package contrast rather than a prefix-length contrast. It still does
not identify a human-psychology mechanism.

W4 exists only if both targets within every root have different normalized
action tuples and are legal under the other state’s common schema. If not, the
entire binding control and every binding interpretation are removed before
target selection; do not substitute a low-support global shuffle.

For W3, each improved response target appears exactly four times behind its
original pre-rollback failure history; the parent correction and child
restatement are absent. Frozen target-blind neutral padding matches the four
W2 prefix-token lengths and role positions. This adopts LEAFE's relevant
history-to-improved-action distillation shape while holding the improved
branch fixed. Because that branch was elicited by the parent rather than by an
independent self-reflection/rollback generator, W3 is only a LEAFE-style batch
writer control. A paper baseline must reproduce LEAFE's actual reflection and
branch-generation procedure rather than relabel W3.

## Rank and heat calibration

The scientific target is rank 8. Before target identities are enumerated, race
W2 on a source-disjoint calibration partition at rank 8 with learning rates
`{1e-6, 3e-5, 1e-4}`. These include LEAFE's published cool prior and Fable's
historically harmful hot value. Batch size, optimizer, schedule, target-token
exposure, update count, adapter initialization law, LoRA alpha/scaling,
dropout, target modules, precision, and rehearsal dose are otherwise identical.

| Calibration cell | Rank | Learning rate | Status |
|---|---:|---:|---|
| `H0_COOL` | 8 | `1e-6` | LEAFE-anchored low-heat candidate. |
| `H1_MID` | 8 | `3e-5` | Intermediate candidate. |
| `H2_HOT` | 8 | `1e-4` | B2-anchored stress candidate. |
| `R16_DIAGNOSTIC` | 16 | selected H0/H1/H2 rate | Runs only after a rank-8 cell passes; never selects or rescues the primary. |

Choose the **lowest** heat that crosses all prebound calibration gates:

1. native response absorption above adapter-off and sham;
2. parent-absent typed-call compliance improvement on calibration-only tasks;
3. typed-forced action quality within the prebound non-erasure margin; and
4. no registered generic/tool-use sentinel beyond its degradation margin.

If no rank-8 heat passes, the assay is NO-GO. Do not promote rank 16 as the
primary, change exposure, or inspect target tasks. If one passes, train one
rank-16 W2 diagnostic at the same selected heat and exposure. Rank 16 is a
capacity diagnostic only; it cannot replace or rescue the registered rank-8
result. All heat/rank choices and gates precede target-panel enumeration.
This sparse calibration cannot establish a rank law, heat optimum,
rank-by-heat interaction, or inverted-U.

Exactly repeated B0-style training canaries must demonstrate the frozen
determinism policy before full cells. If bitwise determinism is infeasible, the
later design must prospectively bind independent training seeds and aggregation
before target exposure; no tolerance or seed averaging may be invented after a
canary failure.

## Parent-absent held-out endpoints

Every target call starts from an identical fresh state with the parent,
correction, restatement, source transcript, source/rehearsal data, notes,
ledger, retrieval, and prior outcomes absent. Cells receive byte-identical task
messages, tool schemas, input IDs, budgets, sampling seeds, and resets; only the
adapter differs.

### E1. Free/native routing — primary compliance endpoint

Use ordinary unconstrained live generation with the offered structured tool
schema and automatic tool choice. Assistant prose is inert. Record the complete
raw response envelope before parsing. `C[w,i]` is the held-out rate at which
cell `w` emits exactly one schema-valid accepted tool call under the registered
call budget. Also report dispatch-validity, exact normalized arguments, and
strict task value with a missing/rejected call assigned the prebound no-action
value.

### E2. Typed-forced proposal — co-primary preservation endpoint

On a separate fresh reset with identical task content, require the registered
grammar/tool choice so exactly one schema-shaped call is produced. This changes
decoding and is an upper bound, not a routing contrast. `Q[w,i]` is the mean
normalized public value of its action arguments. W2 must be non-inferior to W0,
W1, and W2-adapter-off by the prebound practical margin. This is the direct
test that compliance was not purchased by erasing latent action quality.

### E3. Free-text latent proposal — diagnostic only

Apply one frozen permissive parser to the saved E1 response bytes, recognizing
only predeclared action-bearing prose forms. If E1 contains no valid tool call
but exactly one legal prose proposal, evaluate that string once from a fresh
reset. There is no second model call and no reconstructed trajectory. This
diagnostic may localize another B2-like routing failure but never replace E1.

Also report exact action histograms, invalid arguments, call count, assistant
text length, response token count, and a candidate-logprob absorption assay
that compares the native tool suffix against frozen off-channel twins. Direct
lesson recitation is not a primary endpoint.

## Leakage and provenance firewall

Before source generation, freeze and hash:

- the benchmark-agnostic architecture, source eligibility, correction text,
  restatement object, scaffold ladder, sham-token law, rehearsal law,
  derangement law, heat-selection rule, endpoint renderers/parsers, statistics,
  failure meanings, and maximum claim;
- exact model/tokenizer/tool-template/server/parser/evaluator revisions and
  loaded runtime source hashes; and
- finite source, calibration, rehearsal, development-contamination, and target
  selection algorithms.

Before target enumeration, freeze all accepted source/correction/restatement/
retry/transfer/rehearsal bytes, the selected heat, completed deterministic
training receipts, and every final causal-cell adapter hash. Then two no-model
sealers must independently enumerate and bind the target panel. Exclude every
task or content hash appearing in source, calibration, rehearsal, previous
Fable/nursery analysis, or development artifacts; exclude exact normalized
source action tuples and their content-hash aliases. Target IDs, task bytes,
results, action references, and scores are unavailable to the child, parent,
corpus builder, heat selector, trainer, and design roles until the complete run
manifest is ratified.

The parent sees only the child's public initial response, offered schema, and
the frozen parser’s non-dispatch class. It cannot see the permissive action
quality, hidden evaluator state, rehearsal rows, calibration outcomes, target
manifest, or any reference answer. Every visibility edge receives a machine
receipt. No missing prompt is reconstructed: exact invocation messages,
rendered bytes, input IDs, raw response envelope, assistant-text bytes, raw
tool-channel bytes, parsed call, dispatch, state transition, and outcome are
persisted prospectively before downstream use.

## Experimental unit and statistics

The independent unit is the **eligible source root**, including its source task
pair, generation seed, adapter initialization, corpus, and training realization.
There are 12 paired root-level observations. Target tasks, scaffold rungs,
optimizer steps, target tokens, decoding samples, and the two source responses
are repeated measurements, not independent lives.

For every root compute target-panel means before aggregation:

- total correction-package compliance: `C[W2]-C[W0]`;
- correction-scaffold specificity: `C[W2]-C[W1]`;
- LEAFE comparison: `C[W2]-C[W3]` and the corresponding `Q` contrast;
- binding sensitivity: `Q[W2]-Q[W4]`; and
- non-erasure: `Q[W2]-Q[W0]` plus W2-versus-adapter-off.

The later benchmark ratification must bind compliance SESOIs, quality
non-erasure margins, no-action value, target-panel aggregation, seed policy,
and a joint success rule **before target enumeration**. The minimum joint rule
must require both a practically positive W2-W0 free/native compliance effect
and typed-forced W2 non-erasure; a parenting-specific label additionally
requires a positive W2-W1 effect. Report all 12 paired values, mean, median,
range, and an interval resampling roots only. A sign-count rule may be bound
prospectively. No task-, token-, checkpoint-, scaffold-, or seed-level
pseudoreplication; no p-value or post-hoc margin can upgrade this formative
finite-panel result into a population claim.

## Failure interpretations

| Pattern | Permitted interpretation |
|---|---|
| W2 improves E1 and preserves E2 | Narrow correction-derived native-writer pass among in-context-correctable roots. |
| W2 improves E1 but E2 falls beyond margin | The write taught routing at the cost of proposal content; writer fails the joint goal. |
| E2 remains good but E1 does not improve | Useful proposal capacity remains, but the correction did not route into free typed behavior. |
| W1 matches W2 | Native-format response SFT/rehearsal is sufficient here; no correction-scaffold-specific effect. |
| W3 matches or exceeds W2 | Human parenting adds no measured value over LEAFE-style batch recovery in this floor. |
| W4 improves E1 but loses E2 | The adapter learned syntax while broken binding erased action quality. |
| W2-on equals W2-off | No localized parametric behavioral effect, or a serving-path failure; do not claim consolidation. |
| Parent-present retry works but parent-absent W2 does not | Ordinary in-context instruction following without durable transfer. |
| Candidate-logprob absorption changes but E1/E2 do not | Weight recognition without usable behavior. |
| `1e-4` collapses while cooler cells retain behavior | Heat sensitivity consistent with the B2 mechanism; not a general learning-rate law. |
| No rank-8 heat passes | Current data/writer cannot establish rank-8 teachability; redesign before targets. |
| E1 strict fails while E3 remains useful | Prospective B2-like routing failure; E3 cannot rescue the registered endpoint. |

## Maximum possible statement

If and only if the future exact assay passes its joint registered rule, the
maximum statement is:

> In the registered finite task family and among prospectively selected
> in-context-correctable near-miss roots, a response-only native rank-8 write
> derived from one fixed process correction increased parent-absent free
> typed-tool compliance while retaining typed-forced held-out action value
> within the registered margin.

Only a positive W2-W1 contrast permits adding that the authentic scaffold
outperformed a token/role/dose-matched sham. Only the registered W2-W3 result
may compare human correction with LEAFE-style batch recovery. No outcome from
this assay establishes first reflective internalization, general parenting,
reasoning improvement, continual learning, cross-environment accumulation,
learned dreaming/sleep, or an Experience Model flywheel.
