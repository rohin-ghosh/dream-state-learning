# One-parent fresh-attack adjudication v1

Date: 2026-09-07

Status: unbound, proposal-only adjudication. It changes no frozen v2 source,
implementation, benchmark, model/tokenizer state, adapter, external execution,
or GPU authority.

## Binding topology

The paper uses one reset frozen target-blind parent and one child. The parent
teaches process-level thinking through target-blind tasks, thought-to-action
practice, and closed-form corrections. Public task outcomes alone admit or
reject a proposed lesson. Parenting then ends; the parent, parent prose, and
all nursery-only context, state, and ledger material are absent at deployment.

The deployed parented child uses Think--Dream--Sleep with one cumulative
per-life LoRA. The public figure compares that system (`P1`) with a strong
frozen-parameter active-text agent (`R0`) under equal ordinary deployment
affordances. Parenting causality comes only from the isolated
`U0/U1/P0/P1` factorial. Independent roots are repeated realizations of this
fixed policy pair for uncertainty; they never interact. There is no classroom,
cohort, peer exchange, teacher ensemble, shared child state, or population-
learning mechanism.

## Adjudicated decisions

### A. Novelty and paper identity — accept the correction

The broad online-parametric-memory lane is occupied. TMEM already combines
working context, explicit memory, extracted QA supervision, and online LoRA
updates within a rollout. PEAM already internalizes embodied successes and
failure--correction trajectories into selectively triggered LoRA skill
modules. EVAF already evaluates surprise/goal-gated LoRA consolidation after
working-context unload. LEAFE already batch-distills reflective recovery into
acting weights with the reflection absent at evaluation. Learning on the Job
already turns deployment feedback into continually evolving scoped external
rules for frozen actors.

Therefore this submission is a **causal developmental intervention paper**,
not the first online-LoRA, sleep, selective-write, reflection-internalization,
or continual-agent-memory paper. Its narrow novelty is whether target-blind
one-parent process teaching changes the later marginal causal benefit of the
same child's personal writes after complete teacher deletion.

### B. Success condition — accept the joint guard

The phrase "parenting improved the ability to learn" requires the registered
interaction `D`, beneficial parented write effect `W_P`, and literal parented
lifetime improvement `L_terminal` jointly. `D` alone can pass because writes
harm U more than P. `P0-U0` alone is inherited entry competence. `P1-R0` is a
qualified full-package comparison, not parenting causality or an equal-history
carrier comparison.

The fixed claim sequence therefore remains:

```text
D -> W_P -> L_terminal -> C_public -> T_R0
```

and the strong-reference/local-plateau sentence remains conditional on its
separate registered composite.

### C. Pre-confirmation canary — reject a duplicate mini-lifetime

Two of three fresh cross-critiques recommend keeping the existing
writer/parent-absent near-transfer canary and using the exact four-root
deployment pilot as the real later-learning bridge. This is adopted.

The dissenting review correctly objects that same-family near transfer is not
meta-learning. It is not asked to be. The existing full pilot already changes
ontology from two generated non-compiler nursery families (Nonce Codebreaker
and Nonce RuleShift) to CompilerGym, deletes the parent and nursery state,
executes 48 fresh deployment programs, permits three later writes, measures
four cuts, and contains the full `P0/P1/U0/U1/R0` service roster. Adding a
second non-compiler factorial would duplicate the decisive packet, create a
new generator and analysis, and consume the deadline without removing the
need to run the real pilot.

The canary therefore licenses only healthy native writing and parent-absent
homologous near transfer. The four-root pilot, not the canary, decides whether
cross-ontology later learning is plausible enough to fund confirmation.

### D. Pilot advancement — accept a source repair before execution

The current `D`-only spending rule is insufficient. Before pilot roots exist,
the authorized source must require all validity/resource gates plus
directionally positive `D`, `W_P`, and `L_terminal` in at least three of four
roots and positive means for all three. These are pathology/spending guards,
not efficacy tests; the fixed confirmation SESOIs must not be imposed on four
pilot roots.

The pilot must also freeze, print, and preserve by arm/cut the writer pathway:
eligible and accepted scientific rows, process-target type, support route,
rehearsal fills, labeled and attended tokens, optimizer positions, rejection
reasons, fit/mount/quarantine outcomes, and later strict behavior. These are
post-treatment mediators to report, not variables to match or adjust away.

### E. Baselines under the ICLR deadline — narrow the claim, not the science

For the causal parenting paper, the minimum live set is the frozen five-
service roster plus its writer controls and once-only active-text certificate:
`U0/U1/P0/P1/R0`, adapter-off/pre-write/wrong-binding diagnostics, raw/full-
history and static-retrieval certificate checks, and writer mediation. `P1-P0`
is the cleanest live evidence that per-life writes add value above the common
active-text mechanism. `R0` is a singular validated candidate only if every
certificate passes.

Do not rush partial reimplementations of TMEM, PEAM, EVAF, LEAFE, or Spark
before the factorial. Cite them prominently and drop the claims their live
baselines would have been required to support. TMEM-style direct-QA LoRA,
naive/native continual LoRA, matched terminal batch internalization, and a
released active-memory system become mandatory when claiming writer,
schedule, or named-method superiority—not for identifying `D` under one
common writer.

### F. Full Dream--LoRA--Think objective — preserve as a separate evidence arc

The parenting factorial cannot establish connected/compressed experiential
knowledge, goal-conditioned traversal, or action-driven knowledge expansion.
CompilerGym can establish real hill-climbing utility and thought-to-action
learning, but generic compiler policy transfer can explain a gain.

The controlled compositional relay remains required for the full project:

```text
own action -> public atomic relations
fresh counterfactual goal -> necessary multi-edge traversal
missing edge -> memory-dependent information-seeking action
new public outcome -> admitted later write
still-later hidden goal -> action requiring old plus new relation
```

It uses authentic versus binding-deranged, necessary-bridge-cut, write-off,
adapter-off/wrong-life, and same-corpus active-text controls. Compression is a
further rate--distortion experiment with denotationally equivalent expanded
carriers and total acting-state code accounting; fixed LoRA rank is not enough.

The relay should be source-frozen before headline unblinding but must not
delay writer truth or the factorial. After the parenting result is immutable,
it may begin from within-root clones of terminal `P1` state so the parent
remains absent and no second parenting comparison is introduced. Relay results
have their own estimands and cannot rescue a failed parenting interaction.

3. Incorporate the pilot `D + W_P + L_terminal` spending repair before any

6. Run the exact four-root pilot; advance only on the repaired conjunction.
7. Run fixed `N=32` confirmation and lock all claims/artifacts.
8. In parallel at proposal/CPU-fixture level only, freeze the single-agent
   compositional relay and rate--distortion accounting for the full objective.

## Claim ceiling

If only the parenting sequence passes, the eligible result is:

> Under one fixed target-blind parent policy, child checkpoint, writer, and
> deployment distribution, process teaching increased the beneficial effect
> of later personal writes after the parent and nursery state were removed.

It is not evidence of a parent population, broad meta-intelligence, first
online parametric memory, a graph inside LoRA, compression, autonomous theory
formation, or general baseline superiority.

The full Dream--LoRA--Think thesis remains contingent on the separate connected
carrier, rate--distortion, traversal, expansion-relay, and lifetime-plateau
rungs in `research_notes/DREAM_LORA_THINK_FULL_EVIDENCE_STACK_20260907.md`.
