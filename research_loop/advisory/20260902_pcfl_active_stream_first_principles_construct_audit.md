# PCFL-Active-Stream: first-principles construct-validity audit

**Date:** 2026-09-02  
**Status:** independent advisory only; read-only audit of the proposal snapshot.
This memo neither edits nor ratifies the proposal and authorizes no execution.
For compactness, every bare proposal filename cited below is rooted at
`research_loop/changes/chg_20260902_pcfl_active_stream_paper_target_v1/`; other
citations give their full repository path.

## Verdict

**Conditional paper-worthy benchmark; not yet a valid demonstration of the full
Dream--Sleep--Think thesis.** The design's strongest contribution is a rare
causal microscope for one narrow claim: a frozen, prompted model writes
target-blind per-life text from its own public actions and outcomes, that text
changes a later information-gathering action, the resulting outcome is
reconsolidated after the assigned memory is removed, and the acquired delta
changes a still-later action. The on-policy opportunity deck
(`experiment_contract.md:55-82`), destructive unmount
(`visibility_taint_reset_contract.md:98-124`), and same-event raw/witness/SELF
factorial (`mediation_contract.md:129-163`) are unusually strong ingredients.

The ordinary lifetime world, however, is still a collection of independent
finite maps. Each cohort contributes thirteen one-edge mappings
(`research_notes/48_pcfl_stream_and_schema_design_v0.md:28-46`), and a target
exposes enough anchors for a constant number of indexed reads
(`research_notes/48_pcfl_stream_and_schema_design_v0.md:74-88`). Consequently,
most NEW/OLD/CROSS success can be explained by a growing key--value table plus
pretrained clean-base composition. The stable design note itself says that
independent PCFL-Stream cohorts do **not** test higher-order schema discovery
(`research_notes/48_pcfl_stream_and_schema_design_v0.md:154-180`). The proposal
therefore cannot presently distinguish "learned experiential structure" from
finite causal-map caching on its ordinary D4 surface.

This is not fatal if the paper is framed as **causal evaluation of
action-conditioned compiled text memory in a finite synthetic world** and the
integrative mediation assay survives strong cache/controller controls. It is
fatal to a claim of learned dreaming, learned reasoning, compression, generic
self-improvement, or a Dream-LoRA-Think system. The controller remains prompted
and frozen; stable notes explicitly call such controllers teachers/ceilings,
not evidence that the policy was learned
(`research_notes/42_system_thesis_and_experiment_map.md:55-75`). The current
paper surface also contains no per-life LoRA claim, although weights are central
to the original thesis (`research_notes/00_THESIS.md:21-25,51-58`).

For September 25, **Stage A plus eight-root Stage B is a go/no-go pilot, not
claim-grade ICLR evidence**. The proposal correctly says DEV supplies no
population estimate (`statistics_and_claim_contract.md:12-19`) and explicitly
removes confirmation from the deadline path
(`baseline_and_resource_manifest.md:126-132`). A released construct plus
failure-inclusive pilot could be a coherent benchmark/design submission, but a
main-track empirical accept case is weak without later confirmation. Do not
write the abstract as if C1--C3 were established.

## Construct decomposition

The target thesis requires six distinct facts. They must not be collapsed into
terminal success:

| Required fact | Best current identification | Residual ambiguity |
|---|---|---|
| Life-specific evidence matters | pre-action-identical twins; target/null probes; authentic/twin/null fork | twin memories arise from separate on-policy histories, so content coverage and bindings may both differ |
| Outcomes, not action tokens, matter | same-probe outcome-drop and executed twin-outcome lanes (`mediation_contract.md:145-163`) | clean only if all post-action state and compiler inputs except the public outcome are matched |
| Model-owned compilation adds value | RAW-AO/ACTION-ONLY/WITNESS/MECH/SELF plus semantic cut | demonstrates an incremental text record only if the cut rule is prospectively executable and raw/mechanical lanes are not reader-starved |
| Use exceeds mere episode recall | fresh handles/state-goal pairs, D4 minimum proofs, one-record rejection (`experiment_contract.md:109-121`) | ordinary D4 remains four independent keyed facts composed by the frozen controller; fresh handles alone do not defeat map lookup |
| Memory changes future experience | assigned memory changes probe, then is unmounted before reconsolidation and later evaluation (`mediation_contract.md:5-37`) | strongest part of the design; all links must move directionally, not merely final success |
| Learning continues beyond context | unique mappings grow; NEW/OLD/CROSS at three post-native checkpoints (`experiment_contract.md:84-158`) | increasing table size is information growth, but not learned abstraction, fixed-capacity scaling, or increasing reasoning depth |

## Strongest accept case

An area chair can accept the work if all of the following are true:

1. Stage A certifies total presealed allocation, low target-only/no-memory
   headroom, exact twins, unique depth, strict native-context cuts, and isolation.
   These are already substantially specified in the construct gate
   (`stage_gate_and_test_manifest.md:38-73`).
2. A target-blind, prompted SELF compiler commits predictions before outcomes
   and revises them from raw public outcomes without a hidden-truth filter
   (`compiler_memory_contract.md:5-22`).
3. On a **common-history representation sentinel**, SELF beats strong raw RAG,
   typed witness/KV, mechanical causal-map, linked-memory, and rolling-summary
   systems on targets that cannot be solved by one event or independent reads.
4. In isolated on-policy clones, AUTH/TWIN/NULL produces the registered chain:
   probe direction -> information gain -> new public evidence -> readable SELF
   delta -> later executed value, after complete unmount.
5. SELF loses value under outcome and decisive-semantic cuts relative to matched
   shams, and the effects survive neutral skins, opaque labels, fresh roots, and
   a generic controller prompt.
6. Current-versus-lagged snapshots establish genuinely new acquisition; old
   snapshots establish retention; cross-era targets establish use of both old
   and recent bindings. Failures remain zeros.
7. The claim is the narrow finite-range sentence in
   `experiment_contract.md:242-269`, with "learned" referring only to acquired
   per-life content, never to the frozen compiler/controller policy.

That package would be novel less because of absolute score than because it
causally identifies a full action--evidence--memory--action pulse while ruling
out several simpler explanations.

## Strongest reject case

Reject as a thesis paper if the results admit this simpler description:

> A hand-prompted pretrained controller normalizes public transitions into a
> table keyed by persistent family labels; an index retrieves four rows; the
> clean base model assembles them into the uniquely permitted action sequence.

That account is consistent with the world as written: persistent labels and
independent within-cohort permutations (`experiment_contract.md:29-47`), a
deterministic extractor that computes literal trait changes
(`compiler_memory_contract.md:24-39`), and a reader that returns local relations
(`compiler_memory_contract.md:92-108`). It is also close to the original
PCFL-Stream retrieval contract, which explicitly grants constant-degree anchor
queries independent of lifetime (`research_notes/48_pcfl_stream_and_schema_design_v0.md:74-88`).

Four proposal defects make that rejection live:

1. **The benchmark is designed close to its own KV stop.** The proposal says a
   native exact/linked memory that reduces the task to constant-cost KV lookup
   stops the experiential-reasoning claim
   (`baseline_and_resource_manifest.md:202-216`), while simultaneously requiring
   an exact public sufficient-statistic program to score 1.00 and MECH at least
   .90 (`stage_gate_and_test_manifest.md:75-102`). Unless the special
   integrative targets—not only ordinary D4—defeat independent indexed reads,
   the stop is likely to fire by construction.
2. **No nonadaptive-query composition control remains.** Stable PCFL explicitly
   required identical oracle atoms with queries committed before reads versus a
   recurrent reader (`research_notes/46_pcfl_constructive_assay_v1.md:158-188,
   315-343`). The current roster omits this decisive separation of recall from
   adaptive reconstruction.
3. **The primary competitor is not the strongest registered baseline.** P4
   compares SELF only with the DEV-selected AS-EXT
   (`statistics_and_claim_contract.md:168-182`), although RAG and MECH are full
   surface arms (`experiment_contract.md:160-175`). SELF can therefore pass P4
   even if raw episodic RAG or MECH is better. Any "better than memory
   baselines" claim must compare against a prospectively defined strongest
   eligible baseline, or require separate minimum contrasts.
4. **Controller ownership is unresolved until exact bytes exist.** The compiler
   prompt, DSL, reader, retry, and stopping policy are deferred to a later
   proposal (`compiler_memory_contract.md:18-22`). A PCFL-family-aware prompt can
   hand the model the sufficient factorization and join strategy. Twins remove
   pretrained knowledge of the *binding*, but do not remove pretrained or
   hand-authored knowledge of *how to solve the family*.

There are two further intervention ambiguities to repair before interpreting a
positive result. AUTH and TWIN checkpoint memories are produced by distinct
on-policy twin-side histories (`experiment_contract.md:55-82`), so their
difference is not necessarily binding-only; add a same-action counterfactual
twin-memory sentinel or explicitly interpret the contrast as a whole-memory
treatment. And the "presealed decisive SELF records" lesion
(`mediation_contract.md:145-156`) needs an executable selection rule frozen
before SELF output and target results. The contract must clarify that reader
**budgets/shapes**, not semantic return bytes, are held fixed; holding actual
returns fixed would make a semantic-memory lesion causally inert.

## Exact falsifiers and permitted fallback

1. **KV/cache falsifier:** a target-blind typed store of witnessed/publicly
   supported mappings, with a normal index and at most the same reads, solves an
   integrative target by one event, four independent lookups, or nonadaptive
   queries. **Fallback:** finite causal-memory/retrieval benchmark; no
   experiential-reasoning or model-owned-reconsolidation claim.
2. **Common-history compiler falsifier:** on identical action--outcome bytes,
   SELF does not exceed `max(raw RAG, witness KV, MECH, linked memory, rolling
   summary)` by a predeclared practically meaningful margin on integrative
   executed action. **Fallback:** no compilation advantage; report the winning
   memory method.
3. **Semantic-necessity falsifier:** SELF does not beat WITNESS/MECH, or the
   decisive SELF-semantic lesion is no worse than sham. **Fallback:** public
   event/witness memory only.
4. **Outcome-necessity falsifier:** action-only, outcome-drop, or same-probe
   twin-outcome does not move the compiled delta and later action in the
   certified direction. **Fallback:** action-token association, not
   outcome-conditioned learning.
5. **Flywheel falsifier:** AUTH/TWIN/NULL does not directionally change the
   probe, information gain, acquired evidence, delta, and later action after
   unmount. **Fallback:** static memory use, not an action-conditioned flywheel.
6. **Scaffold falsifier:** a generic, world-family-blind compiler fails while a
   PCFL-class-informed prompt succeeds. **Fallback:** prompted symbolic
   controller/benchmark ceiling, not model-owned experiential abstraction.
7. **Prior/skin falsifier:** target-only, descriptor-only, passive-signature, or
   lagged-memory probes solve targets; twin/wrong-life memory does not redirect
   action; or the effect vanishes under descriptor-neutral opaque skins.
   **Fallback:** leakage/prior-driven result; invalid until repaired.
8. **Mere-recall falsifier:** identical known-good atoms work equally with all
   queries precommitted, or a target can be solved without a read-dependent
   query/path DAG. **Fallback:** lookup plus base-model planning, not recurrent
   reconstruction.
9. **Continual-value falsifier:** new acquisition stalls, old value falls below
   its bound, cross-era value does not use both cuts, fewer than three
   information-growing post-native points exist, or lagged memory solves NEW.
   **Fallback:** retention/padding/single-checkpoint memory, not post-context
   continual acquisition.
10. **Higher-order-structure falsifier:** every useful SELF record is equivalent
    to the minimal table of local cohort mappings and cannot predict a
    prospectively held-out relation. **Fallback:** learned per-life causal map;
    do not claim abstraction, compression, schema learning, or world-model
    induction. A real escape requires the prospective schema rung described in
    `research_notes/48_pcfl_stream_and_schema_design_v0.md:154-180`.

## Minimum baseline set

The smallest set that distinguishes the named alternatives is:

1. `NONE` and honest native-context/recent-suffix controls (pretraining and
   context floors).
2. Target-only/current-state/descriptor/passive-signature probes and an exact
   Bayes no-lifetime controller (shortcut/prior headroom).
3. Strong iterative raw episodic RAG with its native indexing and query policy
   (raw retrieval).
4. Typed witnessed-atom KV with a normal target-blind index, crossed with
   **nonadaptive precommitted** versus recurrent reads (mere recall/KV versus
   adaptive reconstruction).
5. The deterministic public-evidence MECH compiler (hand-coded causal map).
6. One faithful native linked/A-MEM-style system and one rolling
   summary/reflection system; do not discard the loser before the common-history
   construct sentinel.
7. SELF under a generic family-blind prompt and a separately labeled
   class-informed/scaffold ceiling, with exact prompt bytes published
   (hand-authored controller leakage).
8. AUTH/TWIN/NULL/wrong-life or binding-shuffled memory, plus same-probe
   outcome-drop/twin-outcome and decisive-semantic/sham cuts
   (life binding, outcome, and model-semantic necessity).
9. Exact public sufficient-statistic program as a construct ceiling, never a
   learned comparator.

All representation baselines need a byte-identical common-history sentinel.
Their ordinary on-policy lives should remain separate for the total flywheel
effect, because different acquired evidence is part of that estimand. Do not
use on-policy arm differences to claim a compiler effect.

## Recommended experiment ordering before September 25

The proposal's gate order is sound, but the current Stage A/B surfaces are not
the **smallest decisive** sequence. Stage A mixes killer construct questions
with A4, full statistics/resource machinery, and exhaustive production
hardening; Stage B attempts four checkpoints and a broad factorial before
showing that the core task escapes KV/scaffold explanations.

1. **A0 -- paper-killer algebra audit (first, CPU only).** On many generated
   roots, run the exact target-only/Bayes controllers, typed witnessed KV,
   nonadaptive four/six-read controller, recurrent controller, MECH, and exact
   program. Verify total preallocation and target uniqueness. If KV or
   nonadaptive reads solve the proposed integrative primary targets, stop and
   either narrow the paper or add a prospective schema target. Do not implement
   the full roster first.
2. **A1 -- causal-boundary certification.** Certify twin bytes and directional
   mappings, deterministic opportunity/outcome replay, native-token cuts,
   unmount, evaluation sterility, RNG separation, taint mutants, and crash
   reset. These are necessary because the mediation result is the paper's best
   asset.
3. **A2 -- freeze the actual cognition.** Before any model call, freeze and
   publish exact generic and class-informed compiler prompts, DSL/parser,
   reader/index behavior, cut-selection algorithm, candidate surface, caps, and
   failure rules. Stage A cannot establish controller leakage resistance while
   these bytes are deferred.
4. **B0 -- known-good reader/planner canary.** With injected correct memory,
   verify exact reads, nonadaptive-versus-recurrent separation, fresh-handle
   executed action, and causal cuts. Stop if the reader/planner cannot expose
   the intended difference.
5. **B1 -- common-history representation killer at 3L (two roots first).** Feed
   identical public histories to raw RAG, witness KV, MECH, linked memory,
   rolling summary, generic SELF, and class-informed SELF. Run regular and
   integrative targets plus outcome/semantic lesions. This localizes
   compilation before on-policy histories diverge.
6. **B2 -- one 3L flywheel pulse (the same two roots).** Run AUTH/TWIN/NULL with
   destructive unmount and score every causal link. Add a matched-action twin
   memory sentinel. If any decisive sign fails or only the class-informed
   compiler works, stop the thesis expansion and write the honest null.
7. **B3 -- only after B1/B2 pass, expand to all eight DEV roots and the
   0.75/1.5/3/6L NEW/OLD/CROSS surface.** Run the minimum full baselines above,
   retain failures, and measure the future confirmation variance/resource
   envelope. A4 is secondary; move it after the D4/flywheel evidence lock if the
   deadline is tight. LoRA and the 24-root confirmation correctly remain
   post-deadline.

This ordering can produce a decisive scientific answer before September 25:
either a narrow, credible causal compiled-memory benchmark with transparent DEV
evidence, or an informative demonstration that PCFL-Active-Stream is a
finite-map retrieval task. It cannot produce a powered continual-learning or
Dream-LoRA-Think confirmation by that date under the proposal's own rules.
