# Scaled THINK experiment: fresh interpretation v1

Date: 2026-09-10

Status: fresh-context interpretation only. No protocol, implementation, model
execution, resource use, or claim is authorized.

## Smallest evidence ladder

1. **Harness audit:** branches share the same child state, cannot act or see
   one another, JOIN sees only declared outputs, and exactly one trunk action
   reaches the world.
2. **Matched-generated-token topology:** serial candidate routes plus JOIN
   versus independent branches plus the identical JOIN. This tests topology,
   not extra thought volume.
3. **Generous practical package:** current THINK versus branch/JOIN THINK under
   the same generous cap, with each child free to allocate thought and action.
4. **H0 developmental packet:** mechanism siblings with disposable
   NEW_COMMIT/NO_NEW_COMMIT probes test delayed, binding-sensitive,
   write-carried change.
5. **One prebound H1 runway:** only if H0 shows proximal causal change without
   harm; continue all safe randomized roots, not selected winners. No H2.

Task/state/goal/route stopping is local. With no assigned situation, the same
child enters bounded quiet reflection and may form a viable self-goal. No
organism-level DONE is learned, but every execution packet remains externally
bounded.

## SLEEP eligibility

- Preserve every branch losslessly with tree and budget provenance.
- Raw speculative, abandoned, contradictory, quiet-reflection, and self-goal
  text is ledger-only by default.
- No branch gets its own weight update; write once from the shared trunk.
- The initial eligible unit is JOIN + committed action + public outcome +
  post-outcome review.
- Unchosen content becomes eligible only after later grounded child
  re-endorsement with explicit scope/status.
- Parent text, answer keys, evaluation descendants, and sealed-gym outcomes do
  not enter the clean corpus.

## Continuity and scale

Branch/JOIN changes THINK, so it creates mechanism siblings from one immutable
clean pre-gym snapshot. Within an unchanged mechanism, the same child continues
across subjects and parenting sessions. Evaluation children are one-way,
no-SLEEP descendants and never return information to the clean lineage.

Writer-only change, fluent reflection, ritual, or harm buys no scale.
Imprecision buys more roots at the same horizon. Delayed binding-sensitive
NEW_COMMIT > NO_NEW_COMMIT with action-facing extraction and no harm buys one
prebound longer runway. Persistent proximal change without transfer at H1
stops; passed transfer moves to fresh-root confirmation.

provenance, contamination boundary, state/task boundary semantics, endpoints,
and claim order. Branch/JOIN remains a separately ratified mechanism sibling
