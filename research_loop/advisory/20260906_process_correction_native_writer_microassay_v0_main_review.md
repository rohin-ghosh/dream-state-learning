## Verdict

**ADVANCE AFTER REWORK.** The proposal is a strong writer-floor assay and is
well aligned with the B2 failure. It prospectively separates free routing from
typed-forced proposal quality, preserves saved-byte diagnostics without
rescuing the registered endpoint, fades the parent scaffold, includes a
native-format sham and an explicit LEAFE-style batch-recovery control, and
defines a narrow conditional estimand.

It is not the paper's parenting experiment. It teaches one interface rule to
an already in-context-correctable subset. Treat it as a time-boxed prerequisite
for the later reasoning-correction nursery, where a parent helps the child map
a belief or surprise into a better experiment/action and the public world
decides whether the lesson enters sleep.

## Required repairs before architecture intake

### R1. Make heat selection treatment-neutral

The current calibration races `W2_PARENT_FADE` at three learning rates and
selects the lowest rate that makes W2 pass. That uses the treatment package to
choose a shared optimization setting before comparing it with W1/W3/W4. Target
sealing prevents held-out overfit, but it does not remove treatment-specific
method-selection bias.

Select heat using a separate, source/calibration/target-disjoint **cell-neutral
native writer canary** containing ordinary successful typed responses and
matched rehearsal only. Prebind generic absorption, native-call compliance,
typed-forced non-erasure, and generic/tool-use preservation gates. Freeze the
lowest passing heat, and only then construct W1--W4 without inspecting their
behavior. If no heat passes the neutral canary, stop. W2-specific calibration
may remain a diagnostic but cannot select the registered heat.

### R2. Clarify the replication object and cost

The statistical section implies one independently initialized adapter per
eligible root per trained cell, but the corpus section can also be read as one
adapter trained on all 12 roots. State this literally. For a causal statement,
the preferred unit is an independently generated **life/corpus/training
realization**, not a source task within one shared adapter. If each of 12 roots
creates four trained adapters plus diagnostics, bind the exact count, accepted
target tokens, update count, expected A40 minutes, and stop rule before calling
the assay a micro-run.

Do not treat repeated target tasks under one adapter, scaffold rungs, or
decoding samples as independent units.

### R3. Separate selection yield from conditional efficacy

Eligibility requires the base child to (a) put one useful action in prose,
(b) repair it after correction, and (c) transfer with its restatement present.
The assay is therefore conditional on three successes. Preserve every one of
the first 48 attempted roots and report the full funnel:

`attempted -> legal prose proposal -> useful proposal -> corrected exact retry
-> restatement-supported near transfer -> eligible`.

The funnel is a first-class result. A large effect among 12 roots is not useful
if the eligible subset is vanishingly rare. No failed root may be silently
replaced in the efficacy denominator or used as negative training data.

### R4. Prove that content/action-disjoint transfer is feasible

Before target sealing, use development-only tasks to show the selected family
has a common typed schema and enough reusable action vocabulary that excluding
exact source action tuples does not make the target mechanically impossible.
Report source/target action-token overlap separately from exact normalized
tuple overlap. The scientific endpoint must not collapse into learning unseen
tool vocabulary.

### R5. Time-box the writer floor and precommit the reasoning successor

This assay can establish only that a process correction can be compiled into
parent-absent executable behavior without erasing proposal quality. It cannot
establish learned reasoning, continual learning, dreaming, or the flywheel.
Register a resource ceiling and stop after one frozen causal run. Regardless
of outcome, the next scientific proposal must target one reasoning disposition
such as surprise-triggered discrimination, scope correction, or
recall-before-rederivation on an interactive near-transfer task.

That successor must compare periodic per-life writes with a matched final
LEAFE-style batch write. Otherwise the project would reproduce reflective
action distillation without testing its remaining novelty: repeated personal
post-deployment learning.

## What must remain unchanged

- The parent supplies no action content, hidden score, or reference answer.
- The world, not the parent, admits a corrected behavior as supported.
- Exact model-native tool envelopes are response-only targets; prose is inert.
- Parent/restatement/outcome/history bytes are masked inputs.
- Free typed compliance and typed-forced proposal preservation are joint gates.
- Permissive parsing is diagnostic only and cannot rescue E1.
- W1 native sham, W3 LEAFE-style batch recovery, W4 action derangement,
  adapter-off, and frozen-base controls remain.
- No Fable/B2, legacy nursery, current conversation, repository result, or
  benchmark-specific row enters the writer corpus.

## Paper relevance

A pass buys trustworthy plumbing for parenting: the child can acquire a
parent-absent action-channel habit from one verified correction. A null says
the present low-rank writer cannot even internalize that minimal habit. Either
outcome changes the next design.

The paper-level claim still requires prospective repeated writes, lifetime
curves, backward retention and forward transfer across environments, strong
textual-memory and batch-experience-distillation baselines, and a reasoning
correction whose benefit survives parent removal. This floor is aligned only
as a bounded prerequisite to that larger test.
