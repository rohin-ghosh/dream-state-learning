# One-cycle flywheel relay: existing-world construct audit

**Status:** advisory only; no implementation, model call, GPU authority, or
scientific result.

## Bottom line

The historical `action-world-v0` branch is a useful legal-action and artifact
fixture, but it does **not** express the proposed causal relay unchanged.  Its
generic cautious policy already solves every A1 information-gathering goal,
either inspection side reveals the only relevant binary uncertainty, and A2/A3
budgets prohibit inspection.  There is therefore no nontrivial choice of *what
to learn next* on which a shared LOOP policy can beat a strong skill prompt.
Restoring it unchanged is appropriate for regression tests, not for the
headline operation-policy transfer experiment.

`lands/v03r.py` is closer on information structure: it already separates a
pre-goal lifetime, an operational probe, a later goal, counterfactual twins,
dispersed public causal edges, and a recurrent thinker interface.  It is still
not the relay unchanged: its probe is a question whose endpoints are supplied,
its decisive intervention has already happened in the fixed lifetime, and its
final endpoint is an answer ratio rather than an executed world action.

The smallest viable construct is therefore a **v03r active-action projection**,
not a new rescue world and not Action World v0 unchanged:

1. Remove exactly one primary `intervention_effect` row from the pre-goal life.
2. Expose a fixed public menu of type-correct interventions over the existing
   route/control/distractor valves and targets.
3. Give the controller one intervention budget.  The useful action is not named
   in the goal; it must follow life memory from source -> routed valve and choose
   the intervention that splits the two remaining causal alternatives.
4. Execute that intervention in the simulator and emit only its ordinary
   `CHANGE`/`STABLE` public outcome.
5. Deterministically compile the route plus new effect as supported one-edge
   atoms, clear working context/KV state, and reveal the later goal.
6. Require a typed legal `COMMIT` action carrying the predicted target state;
   the environment, not a cognitive verifier, applies it and scores the result.

This reuses v03r's latent collision construction, twins, public rendering,
edge-removal audits, recurrence code, and memory/thinker interfaces.  It adds
one actual acquisition action and one final commit action.  It should remain a
small synthetic precursor: semantics are still Candyland-like and the operation
prior may be reproducible by a good skill prompt.  That possibility is the
required control, not a defect to hide.

## Why Action World v0 is not sufficient unchanged

- A1 has one obvious safe policy: `open -> inspect either side -> guard -> enter`.
  `generic_cautious` is already perfect across 100 seeds.
- There is no menu of candidate experiments with different information gain.
  Both side inspections identify the threat side.
- A2/A3 require direct prediction under a three-action-per-threshold budget;
  they test using an already inferred parity law, not acquiring a new relation
  that later enters memory.
- A3 composes two crossings, but no result from the first crossing is needed to
  solve the second.  It is action chaining, not an action -> new evidence ->
  reconsolidation -> improved later action relay.
- The hidden parity family is explicitly encoded in the privileged solver.  A
  positive model result would remain an algorithmic diagnostic, not evidence
  for semantic experiential world-building.

Action World remains valuable as a fast CPU control for legal-action parsing,
budget exhaustion, irreversible failure, artifact separation, and A0--A3
regression behavior.

## Why the v03r active projection is a better minimum

The decisive public path already exists in v03r:

```text
source --route memory--> valve
valve --executed intervention--> CHANGE/STABLE
target passive baseline + source calibration + role relation
  --later recurrent composition--> counterfactual target state
```

Making the effect an executed action turns the fixed diagnostic into the exact
relay without inventing another ontology.  Wrong valve, matched distractor,
counterfactual twin, route masking, wrong-life memory, and binding shuffle are
natural controls.  A final `COMMIT` action makes action success the primary
endpoint while retaining the old ratio answer only inside the evaluator.

The minimum controller comparison is:

```text
P-BASE
P-SKILL       fixed generic retrieve-route / experiment / update / commit procedure
P-TRAJ-SFT    ordinary SFT on the same projected operation rows
P-LOOP        LoRA targeting only typed operation and public argument tokens
```

All conditions use bounded explicit text life memory for the first relay.  The
matched per-life MEMORY-LoRA arm is conditional on the relay passing.

## Additional CPU gates required before model work

1. The useful intervention is unique under the public prior and exact memory;
   no target/current/render/position-only policy identifies it above the frozen
   ceiling.
2. The intervention outcome reduces the live hypothesis set and is necessary
   for the later commit; removing or twin-substituting it changes the valid
   commit.
3. A nonadaptive committed query list remains near floor while a recurrent
   exact-memory controller succeeds.
4. The public goal does not name the required valve, route, effect, target
   answer, twin bit, or proof path.
5. The action outcome is absent from every compiler/training input until after
   the environment executes the selected action.
6. Resetting context and reader cursor after compilation preserves only the
   declared life memory and makes prior-life canaries unreachable.
7. `P-SKILL` is allowed the strongest concise generic procedure.  If it matches
   P-LOOP, the honest result is prompt/skill conditioning and the LOOP-specific
   claim is removed.

## Scope consequence

The current `chg_20260902_one_cycle_flywheel_relay_v1` proposal correctly
chooses the causal relay and defers the rank pyramid, but its world node is
underspecified if read as "restore Action World v0 unchanged."  Fresh systems
and benchmark interpretations should resolve the world to this v03r
active-action projection or propose an equally small existing-code projection
that passes the gates above.  They should reject any resolution that recreates
the standalone PCFL-lite rescue world or calls the unchanged Action World A1
policy a learned evidence-acquisition result.
