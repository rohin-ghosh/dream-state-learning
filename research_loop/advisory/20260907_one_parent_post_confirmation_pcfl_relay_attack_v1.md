# One-parent post-confirmation PCFL relay attack v1

Date: 2026-09-07

Status: independent proposal-only adversarial advisory. It authorizes no
frozen-source change, implementation, task or root generation, model/tokenizer
call, adapter operation, benchmark run, external execution, GPU use, or claim.
It assumes exactly one fixed parent/one fixed child, complete parent deletion,
and relay execution only after the parenting result is immutable. Repeated PCFL
pair roots are environment trials of that same fixed child, not a classroom,
child population, peer system, teacher ensemble, shared store, or population-
learning edge.

## Verdict

**Do not ratify or execute note 53 as written.** The four-phase narrative is a
good decomposition, but its current controls do not jointly identify connected
experiential memory, goal-conditioned traversal, memory-directed information
acquisition, later-write causality, and delayed benefit.

The blocking defects are:

1. Phase C is simultaneously declared presealed and constructed from the
   child's realized accepted relations. Conditioning a target on a
   post-treatment corpus is target selection on a mediator and can make arms
   incomparable.
2. `ATOMS_ONLY`, `BRIDGE_CUT`, and the valid dependency DAG do not identify a
   *carried connected structure*. The proposal never freezes the provenance,
   admission rule, information content, or intervention timing of the use links
   and shortcuts that distinguish authentic memory from atoms.
3. A mechanically valid adaptive trace is not evidence that the *goal*
   selected the trace. A fixed exhaustive anchor scan, target-conditioned
   candidate construction, or runtime-inserted path can pass the current Phase
   B rule.
4. The Phase-C prediction and the post-outcome write are not reconciled with
   the inherited prospective-support contract. A retrospective relation
   inferred from one outcome is either inadmissible, or the test silently
   weakens the compiler.
5. `AUTH_WRITE - AUTH_NO_WRITE` is not a write-content effect while the Phase-C
   outcome can survive in history, ledger, context, workspace, cache, candidate
   state, or policy rows, and while the write arms differ in examples, training
   tokens, steps, or optimizer disturbance.
6. `BINDING_DERANGED` is asked to perturb links, semantic endpoints, and
   action--outcome tuples at unspecified times. Those are different
   interventions. `REACHOUT_OFF` changes Phase-C experience. Their maximum is
   not one interpretable delayed-effect control.
7. The statistical contract has one root-level notation but no independent
   root count, score definitions, smallest effects, missing-cell rule,
   fixed-sequence test, or complete-chain rate threshold. “Positive evidence”
   and a merely nonzero mediator rate are not confirmatory criteria.

The smallest defensible repair is to preserve PCFL and the four named phases,
but freeze one Phase-A state, make Phase B a write-denied diagnostic fork,
preconstruct C/D targets without inspecting learned memory, split interventions
by phase, permit only a single predeclared new atomic relation into the D write,
and add one matched link-derangement and one resource-matched sham-write arm.

## What each phase presently establishes

| phase | what it can establish now | what it does not yet identify |
|---|---|---|
| A — own-action acquisition | Public provenance can show that the fixed child selected an action and received an ordinary outcome before a relation was admitted. | “Own action” is unresolved against note 47's scripted outcome-blind source policy; no rule says whether the engine merely schedules opportunities or chooses the experiment. Atomic admission does not establish connections, and corpus-dependent target eligibility invites post-treatment selection. |
| B — fresh-goal traversal | A successful action plus a valid adaptive dependency DAG can establish online composition of returned atoms. | It does not show that connected structure was carried, that the goal changed the path, or that the model rather than a reader/shortlister/runtime controller selected the path. Deleting an atom also changes degree and `NOT_FOUND` behavior. |
| C — missing-edge experiment | A pre-action gap, two hypotheses, discriminating predictions, a selected public action, and offline exact posterior scoring could establish directed experimentation. | The current target may be selected from the realized accepted store; hypotheses may be supplied by the target schema; raw information gain may be irrelevant to the later target; and `SHAM_GAP` is not a defined matched intervention. |
| D — later write and delayed use | A fresh-process target requiring old plus new knowledge is the right shape for a delayed-use test. | The new outcome has many unblocked carriers; the admissible support event is unclear; the write can include Phase-C goal/action policy rather than one relation; no-write changes training resources; and fresh handles alone do not prove unique old-plus-new dependence. |

Phase A therefore earns **own-public-action provenance**, not successful
learning, unless admission precision and fresh-handle transfer also pass. Phase
B can earn **online constructive use of atoms** without earning **connected
memory carried by the child**. Phase C can earn **memory-directed information
acquisition** only after target generation and the sham intervention are made
causal. Phase D can earn **later-write value** only after all alternative
carriers and update-resource differences are closed.

### Control-by-control disposition

| proposed control | disposition |
|---|---|
| `AUTH_WRITE` | Bundles authentic atoms, possible links/shortcuts, writer content, update compute, and possibly LoRA policy. It is a reference arm, not one treatment. Rename it by phase and branch only at the relevant boundary. |
| `AUTH_NO_WRITE` | Useful only after the same C action/outcome, with all C bytes inaccessible in D and a resource-matched discarded/no-semantic update. Add a matched sham write. |
| `BRIDGE_CUT` | Literal deletion changes degree, context, and `NOT_FOUND`. Use a slot/type/degree/token-matched twin substitution and causal trace masking. It tests necessary content, not connectedness. |
| `BINDING_DERANGED` | Underspecified and overloaded. Split Phase-A link derangement from post-C new-edge binding swap; freeze fixed-point-free permutations and strata. |
| `SHAM_GAP` | The right C contrast in name only. It needs exact downstream timing and matched record/link/query/action affordances. |
| `REACHOUT_OFF` | Establishes structural necessity of obtaining new evidence. Because it changes C experience/legal affordance, keep it out of the controlled write estimand. |
| `ADAPTER_OFF_FIXED_STORE` | Isolates total adapter contribution only if the store is actor-invisible and the same clean resolver is used. If the adapter also drives THINK, it mixes memory with policy. |
| `WRONG_LIFE` | A carrier diagnostic, not a semantic-content control. Under the binding, derive it from an isolated other-PCFL-root/twin life of the same fixed child; it creates no cross-root communication or population claim. |
| `TEXT_SAME_SEMANTICS` | Must run the whole common-interface relay and be primary for carrier interpretation. It cannot be dismissed as a compiler diagnostic. |
| `ATOMS_ONLY` | Removing links changes capacity and resources. Keep it as a lower-resource diagnostic; use matched link derangement for the connectedness estimand. |

## Detailed attacks

### 1. Target and chronology leakage

- The root allegedly seals goals before output, but Phase C is “constructed so
  the current accepted relations leave exactly one decisive mapping
  unresolved.” The accepted set is produced after the child's actions, DREAM
  samples, evidence, admission, and possibly adapter fitting. A generator that
  rejects targets until this realized set has one gap selects on post-treatment
  success. It can also preferentially retain easy stores and leak the identity
  of what is missing through the accepted-set pattern.
- “Acquired” in the Phase-B target rule must mean structurally supported by the
  presealed public source opportunity tape, not successfully learned by this
  child. Otherwise Phase-B eligibility has the same defect. Child failure must
  remain a zero/failed mediator under intention-to-treat.
- Target construction must not use model scores, queries, writer output,
  admission status, adapter reads, or evaluation behavior. The Phase-C gap and
  the D old/new minimal proof must be certified solely from the hidden world,
  presealed source opportunities, and action horizon.
- The Phase-D goal must be sealed before Phase C yet remain byte-inaccessible to
  the actor, writer, retriever, candidate builder, compiler, and all selection
  code until after the assigned write is sealed.
- If the relay protocol, fixed terminal child checkpoint, or root rule is chosen
  after parenting outcomes are inspected, the relay is exploratory and
  conditional on that chosen checkpoint. For confirmatory use, their hashes
  must be frozen before parenting unblinding even though execution begins only
  after the parent is deleted and the parenting result is immutable.

### 2. Stored-answer routes

The one-edge source-record rule is necessary but insufficient.

- A `USE_LINK` can identify the exact two atoms to join even if it is not called
  an ontology edge. A `SHORTCUT` can encode a multi-edge solution while evading
  a literal “one declared edge” parser. An ordered DECIDE row can clone the
  experiment or final action without storing a textual plan.
- Candidate order, candidate presence, candidate count, `NOT_FOUND`, retrieval
  rank, query latency, provenance availability, link degree, claim IDs, token
  lengths, source order, action frequency, and persistent family labels can all
  encode the answer.
- A Phase-C DREAM/SLEEP pass can store the Phase-C goal, hypothesis set,
  selected experiment, public action, or policy continuation rather than the
  intended new reusable relation. Fresh Phase-D entity handles do not eliminate
  this family-level action-cloning route.
- Phase-B outcomes or workspaces can teach the later phases. Unless the intended
  claim explicitly includes this extra experience, restore the exact sealed
  end-of-A actor state before Phase C and keep the B fork write-denied and
  retrieval-inaccessible.

For the primary relay, ban shortcuts and DECIDE/policy rows. Permit only
pretarget Phase-A atoms plus explicitly typed, directionless use-link adjacency,
and in D add exactly one target-blind one-edge READ record. Direct-record closure
must scan every model-visible byte and every hidden interface feature, not just
semantic record text.

### 3. Connectedness is not the current `T`

`T_r = AUTH_WRITE - BRIDGE_CUT` asks whether a necessary old fact helps. It
does not compare connected versus unconnected versions of the same facts.
`ATOMS_ONLY` is named but absent from the estimands, and removing links reduces
record count, training exposure, index size, degree, and retrieval routes.

Freeze a single end-of-A atom set. Define authentic use links before any held-
out goal is exposed. A use link may assert only co-use adjacency between already
supported atoms; it may not contain a goal, handle, action order, terminal
action, success label, or shortcut payload. Compare:

```text
LINK_AUTH       same atoms + authentic admitted use links
LINK_DERANGED   same atoms + fixed-point-free degree/type/token/root-age-
                matched link permutation
ATOMS_ONLY      same atoms, no links; resource-lower diagnostic only
```

Training examples, touches, candidate counts, and interface bytes for
`LINK_AUTH` and `LINK_DERANGED` must match. If only `LINK_AUTH - ATOMS_ONLY`
passes, report a bundled links-plus-resources effect. If no frozen links exist,
rename the result “recurrent composition of experiential atoms”; do not claim a
carried connected representation.

### 4. Goal-conditioned traversal and hidden-controller leakage

A later query that copies a value from an earlier read proves adaptivity, not
goal conditioning. The same trace can be emitted by a fixed exhaustive scan.
The inherited PCFL-Stream interface even permits querying every visible kit
preparation, site, and route within a constant budget unless this negative
controller is explicitly defeated.

Require all of the following before traversal credit:

1. two presealed goals over the same public start state and memory induce
   different registered relevant first-query/path distributions;
2. a target-blind nonadaptive/exhaustive controller with the same queries,
   operations, actions, and public state remains below the registered ceiling;
3. every query anchor comes only from the goal/state, an earlier public outcome,
   or a returned atom, with origin audited;
4. the candidate catalog, order, shortlister, index, and reader seal before
   target generation and receive no goal, scorer, hidden mapping, target
   manifest, or desired relation;
5. the runtime copies only the exact atom the model explicitly selected; it
   never chooses the next edge, validates semantic relevance, fills a path, or
   turns a malformed trace into a valid one;
6. before the decisive action, masking the complete cited minimal cut changes
   the operation and type-matched twin substitution redirects it to the
   registered twin-valid action/set.

Replace literal `BRIDGE_CUT` deletion with a slot-preserving, type/degree/token-
matched twin or false-edge substitution. Otherwise `NOT_FOUND`, shorter
context, and changed node degree reveal the treatment.

The explicit snapshot may validate that a model-selected candidate is present
in the assigned arm, but it may not substitute an answer, rank candidates,
repair a read, or choose the next query. Candidate-only clean-base and unaided
generative-read sentinels are mandatory for any LoRA-read claim.

### 5. Phase-C information acquisition is not yet causal

- The child, not the harness, must publish the gap, both hypotheses, predicted
  outcomes, and selected experiment. A hidden finite solver may score these
  after sealing but may not construct or repair them.
- The posterior must condition on the exact actor-public history and the
  presealed accepted-deck/target-selection rule. It must not condition on hidden
  source actions, writer status, audit provenance, or the fact that a target was
  selected because the learned store had one gap.
- Gate both the probability of choosing the registered discriminating
  experiment and target-relevant information gain. Entropy reduction about an
  unrelated mapping is not success, even if total information gain is high.
- `SHAM_GAP` must be a downstream assignment at the end-of-A boundary: same
  nondecisive atoms, roster shape, record counts, link degrees, return schema,
  token lengths, action opportunity, and budgets, but a fixed predeclared type-
  matched irrelevant or twin signal replaces the decisive old-memory signal.
  It must not change the legal action menu or tell the actor that a sham
  occurred.
- `REACHOUT_OFF` is a structural necessity control. Denying the experiment
  changes Phase-C experience and possibly the visible legal-action set; it
  cannot stand in for the matched sham-memory contrast that identifies
  memory-directed selection.

### 6. Later-write causality and the carrier problem

The D comparison must branch **after one byte-identical Phase-C action and
outcome have sealed**. From that common boundary:

```text
EDGE_WRITE       admit exactly the predeclared new one-edge relation
NO_WRITE         same replay/call/rebuild opportunity; no new semantic row
SHAM_WRITE       type/token/candidate/exposure/optimizer-matched irrelevant or
                 fixed-point-free new-edge row
NEW_BIND_SWAP    same write envelope, but twin/deranged new binding
```

The literal no-write arm remains useful, but `EDGE_WRITE` must beat both
`NO_WRITE` and `SHAM_WRITE` before the effect is attributed to the new semantic
content rather than update compute, rehearsal, or generic adapter disturbance.
`NEW_BIND_SWAP` establishes authenticity of the new binding. It is not the same
intervention as a Phase-A link derangement.

Before D, all arms start a fresh process from the same pre-C base state plus
their assigned post-C carrier. The raw/audit ledger may be retained read-only
for auditors, but must have no actor, reader, shortlister, candidate, prompt,
workspace, cache, file-descriptor, timing, or retry edge. Remove Phase-C goal,
action/outcome text, hypotheses, query history, workspace, and process cache.
The no-write arm must not obtain the outcome through “same history.”

The admissibility rule also needs one exact choice:

- either the child's pre-action Phase-C declaration is the canonical proposal,
  the selected diagnostic action is the predeclared separating test, and its
  public outcome supplies the required later evidence; or
- PCFL declares a directly witnessed diagnostic atom supportable by that exact
  event under a frozen one-shot rule.

A claim first proposed after observing the outcome cannot be treated as
prospectively supported. Do not weaken the note-47 support rule implicitly.
The D writer may serialize only the resulting reusable atom; it may not train
on the Phase-C goal, final action, complete policy path, or D-related bytes.

For the carrier assay, mount LoRA only in the READ operation and use the same
clean frozen resolver for composition. Otherwise adapter-on/off mixes memory
transport with learned decision policy. `TEXT_SAME_SEMANTICS` must execute the
complete relay through the same one-hop read plan and be treated as a primary
system/carrier comparator, not a decorative diagnostic. Native linked active
text with equal public tools/outcomes remains required for any advantage claim.
Different physical carriers cannot honestly have equal compute and storage;
report the full resource vector.

### 7. Delayed benefit and unique dependence

The D generator must mechanically prove, over all legal histories within the
action cap, that:

- the Phase-C action or outcome alone is insufficient;
- the pre-C old relation alone is insufficient;
- the assigned new relation alone is insufficient;
- old plus authentic new relations attain the oracle ceiling;
- neither relation can be reacquired before the irreversible D decision;
- deleting either cited cut lowers value, and twin substitution changes the
  correct action/set rather than merely causing failure; and
- goal/state/handle/action-frequency/passive-signature/candidate-only/no-life
  controllers stay below their registered ceilings.

`F_r = AUTH - max(BINDING_DERANGED, REACHOUT_OFF)` is not a clean causal
estimand. The derangement should occur after the common Phase-C outcome, while
reachout-off removes that outcome altogether. In addition,
`E[AUTH-max(B,R)]` is not the same as requiring both mean pair contrasts to be
positive. Report and gate the two paired contrasts separately with an
intersection-union rule:

```text
binding authenticity:  D(EDGE_WRITE) - D(NEW_BIND_SWAP)
new-evidence necessity: D(EDGE_WRITE) - D(REACHOUT_OFF)
```

The latter is a total pathway contrast, not a controlled write effect. The
write effect is estimated only among common Phase-C outcome clones.

## Minimal repaired phase graph

```text
fixed terminal P1 child hash + verified parent/nursery deletion
    |
presealed PCFL pair-root, source-opportunity, target, intervention,
candidate, RNG, and budget manifests
    |
Phase A: child-selected public actions -> frozen ledger -> frozen M_A
    |                                      (no target-conditioned selection)
    +-- Phase-B write-denied fork: LINK_AUTH / LINK_DERANGED / ATOMS /
    |                          matched bridge substitution / goal swap
    |                          -> discard process, restore M_A
    |
    +-- Phase-C fork from M_A: AUTH signal / matched SHAM / REACHOUT_OFF
                               -> seal declaration, action, public outcome
                                     |
                   clone the same AUTH action/outcome boundary
                                     |
              EDGE_WRITE / NO_WRITE / SHAM_WRITE / NEW_BIND_SWAP
                                     |
           fresh-process Phase D with only assigned carrier visible
```

Phase B is still temporally after A and before C, but its evaluation artifacts
cannot alter C. All control assignments are sampled before Phase A. Each
intervention is activated only at its declared boundary. Do not continue one
early perturbed branch through later phases and then call its D contrast a
direct effect of the later mechanism.

## Repaired estimands and interpretation

For PCFL pair root `r`, average targets, H/twin sides, and technical seeds
inside the root before inference. The independent unit is the randomized PCFL
pair root, conditional on the exact one-child checkpoint. It supports no claim
about a population of children or parents.

Predefine bounded scores and practical margins for:

```text
C_r = connected_path_value(LINK_AUTH, B)
      - connected_path_value(LINK_DERANGED, B)

T_r = traversal_value(LINK_AUTH, B)
      - traversal_value(MATCHED_BRIDGE_SUB, B)

Q_r = relevant_experiment_value(AUTH_SIGNAL, C)
      - relevant_experiment_value(SHAM_SIGNAL, C)

W0_r = delayed_value(EDGE_WRITE, D) - delayed_value(NO_WRITE, D)
W1_r = delayed_value(EDGE_WRITE, D) - delayed_value(SHAM_WRITE, D)

Fbind_r = delayed_value(EDGE_WRITE, D)
          - delayed_value(NEW_BIND_SWAP, D)
Freacq_r = delayed_value(EDGE_WRITE, D)
           - delayed_value(REACHOUT_OFF, D)
```

`Q` must pass on both relevant-experiment selection and relevant information
gain. `W0` and `W1` must both pass. `Fbind` and `Freacq` must both pass. Use a
predeclared fixed sequence `C -> T -> Q -> W -> F`; a later gate cannot rescue
an earlier one. Within composite gates use an intersection-union test, not a
selected maximum.

The complete-chain rate is descriptive unless given a prospective nontrivial
minimum `pi_min > 0`, an all-assigned-root denominator, and a confidence bound.
Call it a **complete observed mediator chain**, not causal mediation. Never
condition an effect estimate on gap detection, successful experimentation,
admission, retrieval, or completion; those are post-treatment variables. No
failed root, action, write, target, side, or technical seed is replaced or
deleted. Scientific failures are zero under the registered scoring rule;
pre-dispatch infrastructure failures resume only the identical sealed cell.

The confirmation contract must fix root count, pair-root construction, targets
per root, technical-seed averaging, score scales, smallest effect margins,
one-sided confidence/randomization procedure, familywise error handling,
missingness, and a blinded nuisance-only extension rule. Calls, phases, targets,
H/twin sides, and adapter seeds do not increase `n`.

## Strict kill-gate sequence

Every gate is conjunctive. Stop on the first failure; later evidence cannot
repair it.

### K0 — authority and conditional scope

- Bind exact source hashes, fixed terminal `P1` child checkpoint, same-child
  clone rule, PCFL version, permitted CPU/model/GPU nodes, and resource ceiling.
- Freeze the protocol and selection rule before parenting unblinding for a
  confirmatory relay. Execute only after the parenting result is immutable.
- State that inference is conditional on this one fixed child. No other child,
  parent, shared memory, or cross-root learning is permitted.

### K1 — deletion and starting-state receipt

- Prove the parent process is dead and inaccessible.
- Prove parent prose, nursery context/ledger, tools, caches, file descriptors,
  handles, canaries, and routing state are absent from every relay-visible and
  candidate-building channel.
- Hash the exact child parameters, retained personal state, active snapshot,
  prompts, tokenizer, and reset state. No favorable child checkpoint/seed is
  selected after outcome inspection.

### K2 — model-free generator, target, and visibility validity

- Preseal all source opportunities, B/C/D goals, decisive bindings, action
  opportunities, interventions, candidates, RNG streams, and budgets without
  reading learned stores or model output.
- Establish visible-byte H/twin equality to each first decisive action,
  structural target uniqueness/minimality, source-target disjointness, direct-
  record closure zero, unique old-plus-new D dependence, and no legal
  reacquisition shortcut.
- Prove exact accepted-deck posterior scoring and target-relevant information
  gain; small full-world enumeration must match every quotient/factorization.
- Prove all fixed-point-free bridge/link/new-edge derangements exist while
  preserving their declared type, degree, token, chronology, candidate, and
  marginal constraints. No stratum is relaxed after model output.

### K3 — leakage and controller falsification

- Leaked oracle reaches the ceiling; hidden-world atomic oracle reaches all B/C/D
  and complete-relay ceilings.
- No-life Bayes, nonadaptive/exhaustive query, goal-only, current-state-only,
  identifier-only, action-frequency, passive-signature, candidate-only clean
  base, and source-action-string probes remain below fixed ceilings.
- Goal swap changes the oracle relevant path; cited-cut masking changes the
  decisive operation; twin substitution redirects to the twin-valid action.
- Reader/shortlister/audit fixtures prove no goal, scorer, hidden mapping,
  target manifest, rank, repair, fallback, timing, or provenance side channel.

### K4 — phase and carrier isolation

- Prove B evaluation is write-denied and cannot alter the restored end-of-A
  state used by C.
- Prove C targets do not depend on realized acquisition/admission and that D is
  absent from all C/write bytes.
- Prove D starts fresh and only the assigned post-C carrier differs; raw ledger,
  C outcome text, workspace, queries, caches, and process state are unreachable.
- Prove branch activation timing, immutable prefix/suffix behavior, transactional
  rollback, crash semantics, evaluation write denial, and cross-root canaries.

### K5 — corpus, admission, and resource equivalence

- Freeze Phase-A atoms and pretarget use links; reject shortcuts, answer-bearing
  links, DECIDE rows, target handles, ordered plans, and terminal actions.
- Make the Phase-C pre-action prediction/support contract executable and prove
  that post-outcome retrospective proposals cannot enter positive data.
- Byte-audit the exact D row: one reusable edge only. Prove matched
  `LINK_DERANGED`, `SHAM_WRITE`, and `NEW_BIND_SWAP` rows and training envelopes.
- Pin calls, tokens, reads, actions, contexts, candidate work, examples,
  touches, steps, optimizer slots, rank, storage, wall time, and failure rules.
  Padding must run in an isolated process with no semantic/RNG/cache handles.
- Report actual resource vectors; do not claim equal compute/storage across
  text, graph, and LoRA carriers.

### K6 — complete CPU oracle and control headroom

- On an uncurated fixed seed suite, oracle `LINK_AUTH` clears connected and
  traversal ceilings; matched link and bridge perturbations remove the
  registered gain.
- Oracle AUTH signal chooses the relevant Phase-C experiment and clears the
  relevant-information-gain ceiling; SHAM and exhaustive controllers do not.
- Common AUTH outcomes plus `EDGE_WRITE` clear D; old-only, outcome-only,
  no-write, sham-write, new-binding swap, and reachout-off preserve the required
  headroom.
- The full explicit-text relay works through the frozen common interface. If
  this fails, the benchmark/interface is invalid and no LoRA call is allowed.

### K7 — native writer/read instrument gate

- Reuse only an already passed, hash-matched E0 writer receipt or separately
  authorize a PCFL-specific DEV instrument canary.
- Require strict typed parsing/routing, exact provenance, response-only masks,
  clean-base rebuild, deterministic mount/off, fixed candidate recognition,
  adapter-off/wrong-root/twin sensitivity, and rollback.
- A format or one-hop-read canary may test executability; it cannot tune the
  generator, targets, estimands, or confirmation thresholds.

### K8 — disjoint development kill fixture

- Run only predeclared PCFL-13 DEV roots. Require at least one complete relay,
  healthy parsing/read fidelity, no leakage, and executable matched controls.
- Keep every DEV failure. Freeze all prompts, interfaces, thresholds, compiler
  rows, recipes, and resource maxima afterward.
- PCFL-13 is a feasibility kill fixture only. It supplies no confirmation,
  scale, compression, or population evidence.

### K9 — prospective statistics and power lock

- From disjoint pilot/blinded nuisance information, freeze `N`, `pi_min`, SESOIs,
  score functions, fixed-sequence tests, intersection rules, uncertainty,
  multiplicity, missing-cell handling, technical-seed averaging, and the
  nuisance-only blinded extension.
- Preseal all confirmation PCFL-Stream pair-root identities and forbid
  performance-conditioned replacement or early efficacy stopping.
- If powered confirmation is infeasible inside the resource ceiling, narrow or
  stop before any confirmation dispatch.

### K10 — independent review and exact human authorization

- Freeze code, manifests, schemas, prompts, candidate/index builders, compiler,
  estimators, environments, model revisions, and hashes.
- Obtain fresh independent rejection-capable review plus a separate author-side
  advocate, dispose every concern, and obtain exact-byte human ratification for
  the next node. Green CPU or model consensus alone is not GPU authority.

### K11 — ordered scientific release

1. Release connectedness and B traversal only. If `C` or `T` fails, stop.
2. Release Phase C from the sealed end-of-A states. If either experiment-choice
   or relevant-IG component of `Q` fails its joint gate, stop before D adapter
   work.
3. Release common-outcome D write branches. Require `W0` and `W1`, then
   `Fbind` and `Freacq`, then the complete-chain-rate gate in that order.
4. Evaluate explicit text and LoRA separately. Failure of adapter cut/swap or
   same-semantics transport removes the parametric clause but cannot erase a
   valid explicit-memory relay. A later rung never rescues an earlier failure.

## Claim ceiling after repair

If all semantic and relay gates pass but carrier gates fail:

> Conditional on one fixed parent-deleted child checkpoint and the registered
> PCFL-Stream environment distribution, authentic experiential records caused
> goal-conditioned constructive traversal, changed which discriminating
> experiment the child selected, and the resulting public relation improved a
> later old-plus-new goal after a prospective write.

Add “connected carried structure” only if matched link derangement passes. Add
“recognition-assisted per-life LoRA transport” only if same-corpus text,
candidate-only, adapter-off, wrong-root/twin, and generative-read carrier gates
pass. Add no compression, parenting-population, classroom, repeated-flywheel,
autonomous-theory, general-intelligence, or baseline-superiority language.

This relay cannot rescue a failed parenting result. If run from a writer-
qualified checkpoint after parenting failure, it is a separately framed
single-child mechanism experiment.
