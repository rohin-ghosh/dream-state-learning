# PCFL-Compose orbit sampling and statistical audit

**Date:** 2026-09-02  
**Status:** read-only mathematical/statistical advisory. This is not an
architecture consensus, human ratification, implementation authorization,
model/GPU authorization, or scientific evidence.

## Verdict

The corrected design is mathematically valid **if three different claims stay
separate**:

1. exhaustive CPU certification of a free, target-byte-invariant, uniformly
   weighted `2^4` orbit proves a **construct-level target-only Bayes theorem**
   of `1/16` for full D4 success;
2. sampling one uniform primary member per independent root and evaluating it
   (or the predeclared primary/antipode mean) gives an unbiased empirical
   estimate over that orbit prior; and
3. materializing the antipode supports a **whole-memory binding intervention**,
   not an empirical 16-way orbit test or four separate stage effects.

Therefore all 16 members need CPU instantiation/certification, but they do not
need model calls, dream corpora, or adapters. Two model-realized lives per root
are sufficient for the proposed population sampling and antipodal memory-swap
panel. They are not 2 independent replicates: the orbit root remains the
experimental unit.

Two adjudication phrases need repair before a frozen protocol:

- `goal-twin byte equality` is impossible as written. A goal twin deliberately
  changes the goal. Require equality of every **non-goal** target byte, while
  requiring each goal-specific packet separately to be invariant over all 16
  world-orbit members.
- a `paired randomization test` is not automatically design-exact here. The
  primary orbit draw randomizes `z`; it does not randomize the authentic versus
  crossed-memory contrast. Use root-wise paired contrasts and root-blocked
  intervals. Call a sign-flip or label-swap test a randomization test only if
  an actual exchangeable assignment is predeclared and recorded; otherwise
  disclose its symmetry assumption and call it a paired permutation test.

## 1. Why the `1/16` theorem is valid

Fix an accepted orbit root `b`. Let `X_b` be all target-only visible bytes and
let `S_b(z)` be the unique successful four-action sequence in member `H_b,z`.
The required CPU certificate establishes

```text
X_b(z) = X_b                    for every z in {0,1}^4
S_b : {0,1}^4 -> {u/v}^4        is a bijection.
```

Under the sealed conditional prior `P(z | b)=1/16`, any target-only policy
chooses a distribution `pi(s | X_b)` that cannot depend on `z`. Hence

```text
P(success | b)
  = sum_z (1/16) sum_s pi(s | X_b) 1{s=S_b(z)}
  = 1/16.
```

This remains true for a sequential policy only if target interaction cannot be
used as a probe: each bit swaps a disjoint stem pair, an action at stage `l`
reveals no unacted future bit, there are exactly four mandatory stage actions,
and any wrong prefix is unrecoverable. D4 first-action value and D1 remain
`1/2`.

The theorem is conditional on every accepted root, so it survives arbitrary
variation in goals and factors across roots. It is an exact property of the
registered generator prior, not an empirical accuracy claim about the finite
20-root panel and not a natural-world population claim.

## 2. Exact conditions the generator must enforce

The theorem and sampling design fail unless all of the following hold:

1. **Uniform free action.** The four orbit bits are independent fair bits; the
   16 correct sequences are distinct; no stabilizer or duplicated action
   sequence collapses the orbit.
2. **Orbit-level acceptance.** Generate and accept/reject the root as a whole,
   then draw `z`, or prove the rejection predicate is orbit-invariant. Never
   reject or regenerate a selected member based on its label sequence, model
   output, target result, or runtime behavior.
3. **Independent sealed sampling.** `z_b` is sampled independently for every
   root from a presealed seed mapping that is independent of factors, goals,
   schedules, arm order, model seeds, and acceptance. Always choosing
   `0000/1111` is not a population sample.
4. **Complete target invariance.** Start, goal, menu strings and order, object
   handles, budgets, prompt bytes, token lengths, files, errors, timing-visible
   fields, RNG continuation, cache state, and evaluation ordering reveal no
   orbit bit.
5. **Complete row swaps.** Bit `l` swaps the full hidden assignments of
   `u_l,v_l` across source, validation, and target suffixes. Merely swapping
   target labels or correct-answer metadata does not create a coherent world.
6. **Unique irreversible execution.** Exactly one length-four sequence reaches
   the goal; no early lock, wrong-prefix recovery, extra action, reset, retry,
   or target-time probe can rescue a guess.
7. **Stage locality.** Future-stage action dynamics do not depend on earlier or
   later orbit bits except through the public tray generated by already issued
   actions. In particular, no shared hidden target factor or renderer field
   leaks a future bit.
8. **Evaluation isolation.** A target-only call cannot inherit source events,
   another orbit member, a goal twin's execution, another arm's cache, private
   root seed, or prior target outcomes.

For auditability, persist for every `z`: the target-packet hash, correct
sequence, source/chord equivariance map, uniqueness/no-recovery result, and a
deterministic pointer that rerenders the private world. A symbolic proof alone
is insufficient for a generator implementation; model corpora/adapters for
all 16 are unnecessary.

## 3. What differs across the two realized world sides

For sampled `z` and antipode `z*=z xor 1111`:

| Object | Same or different? | Required meaning |
|---|---|---|
| Target start, goal, menus, budgets | byte-identical | Target input alone cannot select the life. |
| Hidden factors / target dynamics | different | Every decisive stage's label-to-operator binding flips. |
| Source action labels and schedule | same/equivariant | No schedule side channel. |
| Source and validation outcomes | different, row-swapped equivariantly | These are the intended evidence identifying the life. |
| Dream commitments and compiled text | independently produced and potentially different | Differences must arise from public life evidence, not scorer relabeling. |
| LoRA memory | separately trained from each life's frozen corpus | Same recipe/seeds where paired, with clean resets. |

The causal panel must actually evaluate all four cells

```text
H_z/M_z, H_z/M_z*, H_z*/M_z, H_z*/M_z*.
```

Authentic memories should select their own world's sequence; crossed memories
should redirect toward the opposite-world sequence. Cross-evaluation reuses
the two trained memories and therefore adds evaluation cost, not adapter
training cost. Reset base weights, KV/cache state, reader indexes, and RNG
state between cells.

The antipode flips all four stages together. It identifies aggregate
life-binding and detects a target-only/cached policy, but cannot estimate which
stage was memory-mediated or any stage interaction. Those questions require
single-bit counterparts or a model-evaluated full orbit.

## 4. Goal twins are not world-orbit twins

These two controls must not be conflated:

- A **world-orbit twin** changes the source life and action semantics while
  holding the complete target packet fixed. It tests whether life-specific
  evidence/memory controls behavior.
- A **goal twin** stays in the same world with the same source and same memory,
  holds start/menu/budget fixed, and deliberately changes only the goal. It
  tests whether the wake resolver conditions on the desired outcome instead
  of replaying a cached action policy.

For every goal variant, CPU-certify uniqueness, no recovery, and a different
first action. Across `H_z`, each variant's complete target packet must be
orbit-invariant and its correct-sequence map must be a 16-way bijection. Run
goal variants in isolated evaluation states; a prior goal twin's actions or
answer may not enter the next call. Goal twins are nested outcomes, never new
roots.

Thus C.1 item 4 should read approximately: `exact world-orbit byte equality;
for goal twins, equality of all fields except the deliberately changed goal;
and orbit invariance of each goal-specific packet`.

## 5. Sampling and inference

If `z_b` is uniform, both `H_z` and `H_z*` have uniform marginal orbit
distributions. For any method score `f_b(z)`, the root summary

```text
F_b = [f_b(z_b) + f_b(z_b xor 1111)] / 2
```

satisfies `E(F_b | b) = (1/16) sum_z f_b(z)`. The two-side design is therefore
unbiased for the orbit average, although a finite panel need not contain all
16 sequences evenly.

Predeclare whether the primary method estimand uses only the primary side or
the equal-weight two-side mean. For either choice:

- resample independent roots, retaining both sides, all targets, goal twins,
  checkpoints, model samples, and intervention cells inside each block;
- compute method and intervention contrasts within root before aggregation;
- keep a factorized root and its matched independent-table companion in the
  same resampling block;
- never count the 40 realized sides, targets, stages, checkpoints, or adapter
  seeds as `n=40+`; confirmation `n` is the number of roots (`20` proposed);
  and
- obtain simultaneous bounds for longitudinal claims with a root-level max-T
  or otherwise predeclared multiplicity procedure. Twenty roots is a minimum
  roster, not a power guarantee.

C.2's open root, untouched root, and single independent-table root are DEV
falsification/plumbing evidence only. A `chance+0.05` result on one root is too
discrete and correlated to diagnose population leakage statistically; it may
be a conservative stop rule, but not evidence for or against a population
claim.

Root-blocked bootstrap inference is appropriate for C.4. A design-exact
paired randomization test is not supplied merely by sampling `z`: replacing
`z` by its antipode leaves the authentic-minus-crossed factorial contrast's
sign unchanged. Use a root-wise bootstrap as the primary procedure, or add and
record an actual randomized assignment whose sharp-null permutation is being
tested.

## 6. Independent-table companion

The matched null is valid if it preserves the complete observable envelope
while deleting only cross-edge factor structure:

- identical label, renderer, source tree/chord roles, chronology, source
  count/order, reset trays, target menus, target depths, orbit prior, prompt,
  parser, sleeper, reader, and failure semantics;
- source tree edges jointly matched, not just marginally. This is feasible:
  on a tree, factorized edge operators are jointly uniform modulo gauge, so
  independently uniform `S_6` edge operators have the same public tree law;
- validation and target operators independently sampled from eligible source
  evidence, with the validation marginal matched but its tree-predictive
  dependence intentionally removed;
- the same complete-row `2^4` swaps, target-packet invariance, 16 distinct
  sequences, and sampled-primary/antipode protocol; and
- orbit-level uniqueness/nondegeneracy rejection that does not introduce a
  source--target correlation. If rejection examines both source and target
  values, conditional independence must be recomputed rather than asserted.

The visible goal is a function of the hidden canonical target sequence, so an
individual target transformation need not be independent of all target bytes.
The necessary null is narrower and exact: conditional on the visible target
packet and eligible source/validation history, the correct label sequence
retains the registered uniform 16-way orbit uncertainty, and source memory
cannot reduce it. The independent exact program must therefore abstain or
return that prior; it must never inspect the private target table.

## 7. Compute disposition

The **pair-scale principle remains valid**: analytic `1/16` certification does
not require 16 dream runs or 16 adapters, and the authentic/antipodal memory
panel requires only two trained life memories per root. The earlier numerical
confirmation budget does not automatically remain valid.

At four checkpoints, each LoRA corpus condition costs

```text
2 realized lives * 4 checkpoints = 8 adapters per root.
```

Direct-QA and self-revised compiled-LoRA as separate full-lifetime conditions
already imply 16 adapters/root, or 320 adapters for 20 roots, before the
wrong-order/factor/sham adapter panel on the preselected 10 roots, batch-SFT
references, failures/retries, dream/think evaluation, and independent-table
text companions. Crossed-world evaluation itself reuses adapters. Therefore
`168--522 GPU-hours` may remain a historical lower-bound envelope for an older
pair-shaped core, exactly as C.4 says, but it is not a costed C.4 campaign.
Freeze an explicit adapter/call manifest and rerun power/cost analysis before
ratification.

## Final disposition

Keep the 16-state CPU orbit plus uniform-primary/antipode materialization. It
is the right cost-saving design and preserves the exact target-only theorem,
unbiased orbit-average estimation, and whole-memory causality. Repair the goal-
twin byte wording, specify the empirical root summary and inference procedure,
and do not call a permutation test design-randomized without an actual
assignment. Make every manuscript table label the three evidentiary objects
separately: **CPU orbit theorem**, **root-sampled model performance**, and
**antipodal memory intervention**.

No science code, models, GPU/CPU experiments, network resources, or
authorization state were changed for this audit.
