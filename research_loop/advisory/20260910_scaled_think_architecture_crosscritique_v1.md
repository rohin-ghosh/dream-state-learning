# Architecture cross-critique of the scaled-THINK experiment

Date: 2026-09-10

Status: fresh cross-critique only; no execution or implementation authority.

Verdict: repairable, not yet binding.

Required repairs:

1. Define the topology contrast as one depth chain whose later states see
   earlier reasoning versus context-isolated sibling routes from one immutable
   state, with the same child-authored synthesis. “Serial independent routes”
   and batched branches would differ only in wall-clock scheduling.
2. Every transition needs goal, optional parent goal, state, parent state,
   status, terminal review, and an explicit successor. External truncation is
   a forced boundary, not successful completion.
3. One action means one committed next world action per JOIN transition.
   Branch execution is proposal/simulation unless it owns an isolated
   counterfactual world.
4. Quiet reflection and self-goals may eventually learn, but raw proposals stay
   ledger-only. Adopted goal + enactment + outcome + review needs an explicit
   later eligibility path.
5. THINK/JOIN/DREAM author epistemic status; SLEEP only selects, deduplicates,
   organizes, writes, and gates. “Sleep converges” means it writes the child's
   survived synthesis.
6. Use one grounded state-transition eligibility unit for branched and
   unbranched states; JOIN is a subtype.
7. DREAM must remain recent tail + typed checkpoint + lossless recall, rather
   than copying whole branch transcripts into context.
8. Bootstrap is inherited schooling for making/revising rules, not personal
   experience. Judge selective new-rule formation and later action change, not
   PLAN/REVIEW frequency.
9. Runtime mechanism changes fork immutable sibling lineages; roots and
   branch routes never merge.
10. H0 must show delayed adapter-dependent changes in state allocation or
    rule revision after reset and on a fresh surface, without ritual or harm.
