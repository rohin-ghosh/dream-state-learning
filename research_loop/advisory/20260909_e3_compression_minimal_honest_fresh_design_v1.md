Date: 2026-09-09

Status: **fresh independent source-only scientific design attack; unbound and
non-executable.** This note changes no architecture, benchmark, schema,
compiler, model, tokenizer, child, adapter, corpus, root, statistic, resource
plan, claim, or release state. It authorizes no implementation, generation,

## Verdict

**REJECT a current-scale positive whole-adapter E3. ADMIT only a staged
semantic-code experiment with a separately named LoRA-transport assay.**

The smallest honest current-scale E3 is not “the fixed-rank LoRA compressed a
life.” It is a four-load, explicit-text rate--utility experiment over one
prospectively fixed, parent-deleted child and PCFL-Stream/PCFL-Schema roots:

1. compare a minimal observation-expanded carrier with a compact connected
   semantic carrier under exact round-trip equality and complete
   actor-accessible byte accounting;
2. require authentic connected structure and, for scientific relevance, one
   prospectively committed schema-plus-residual code to preserve or improve
   fresh-goal utility relative to matched corruptions and ordinary symbolic
   baselines; and
3. only after explicit text passes, test at one largest load whether the same
   compact semantics are behaviorally accessible through LoRA.

The LoRA result is **transport**, not compression. The current rank-8
serialized adapter file is conditionally reported as `80,792,096` bytes and
alone needs at least `161,584,193` expanded bytes for a strict ratio below
`.50`; the known adapter-plus-config subtotal is `80,793,355` bytes and the
complete life-specific numerator can only be larger. No generated PCFL load,
actual expanded denominator, raw denominator, complete auxiliary census, or
actual rate presently exists. The final v4 audit passed only this partial,
author-reported serialized-adapter intercept. It did not pass E3.

There are therefore three different outcomes, not three phrasings of one
outcome:

| assay | maximum positive claim | claim it cannot support |
|---|---|---|
| exact normalized semantic code | a fixed compiler converted the child's admitted public experience into a shorter, exact, connected actor-facing textual code | learned abstraction, LoRA compression, full-life/archive compression, or method novelty |
| prospective schema-plus-residual code | on the registered structured PCFL distribution, a prospectively committed schema and residual code represented authentic connected experience more compactly than observation expansion and ordinary normalization while preserving registered utility | an emergent universal representation, compression inside LoRA, or generalization beyond the registered schema family |
| LoRA transport | the same compact semantics were behaviorally accessible through the assigned per-life LoRA under recognition-assisted reads and causal carrier controls | that the LoRA is shorter than text, that weights contain a readable graph, or any physical compression clause |
| complete-state rate--distortion | only after a real crossover, the complete life-specific actor-accessible carrier was physically shorter than the expanded carrier at bounded distortion in every registered resource coordinate | compression of the common base model, retained audit archive, whole process, or unbounded lifetime |

If the user-facing objective means “compressed knowledge inside the current
all-layer LoRA,” there is no feasible positive current-scale experiment in the
reviewed packet. If it permits a system-level actor-facing semantic code, the
textual assay below is honest but must be presented as the narrower object.

## 1. Why PCFL-13 and the existing relay are not an E3 scale experiment

PCFL-13 contains only thirteen reusable mappings and about `16.66` bits of
hidden permutation backbone. After those mappings are supported, more events
are repetition, delay, or distractors rather than more knowledge. It can test
connection, traversal, and a one-step expansion relay, but it cannot identify
a rate curve over increasing semantic load.

Use the relay's causal objects and finite read law, not its confirmation
sample size or joint E2--E5 claim. The E3 family must use fresh PCFL-Stream
cohorts so that every cut adds new mappings. Roots remain isolated environment
trials of byte-identical clones of one fixed child; they are not children,
lineages, or additional lifetimes. E3 is separate from the parenting and E6
experiments and may not pool their denominators or outcomes.

The smallest scientifically relevant variant adds one PCFL-Schema condition:
a public cohort descriptor is generated from a small, frozen regime family;
after source cohorts, the child/DREAM path must commit a schema and its
predictions before a sparse confirmation cohort is observed. A matched
independent-cohort condition has the same marginal mappings, labels, lengths,
and opportunities but no reusable descriptor-to-permutation law. This control
is necessary because ordinary PCFL-Stream cohorts are independent and contain
no higher-order regularity to discover.

## 2. Exact experiential denotation

For root `r` and predeclared cohort cut `l`, let `H[r,l]` contain only public
actions actually dispatched by the child and their ordinary public outcomes.
A frozen, target-blind compiler runs before evaluation goals and produces
`D[r,l]` from the following objects:

```text
ATOM_DEF = (schema, endpoint_1, endpoint_2, value, scope, live_status)

ATOM_WITNESS = (atom_content_hash, event_id, action_id,
                outcome_sha256, commit_ordinal)

LINK_DEF = (min(atom_1_hash,atom_2_hash),
            max(atom_1_hash,atom_2_hash), relation=CO_USE,
            scope, live_status)

LINK_WITNESS = (link_content_hash, support_event_id,
                support_action_id, outcome_sha256, commit_ordinal)

SCHEMA_DEF = (schema_family_id, parameter_code, applicability_predicate,
              prediction_commitment_sha256, support_atom_hashes,
              residual_exception_policy, status)
```

`ATOM_DEF` and `LINK_DEF` follow the public chronology and authentic co-use
requirements in relay v2/v3. A link is admitted only when both atoms were
already admitted, the child's pre-action proposal named them, and the later
public successful action syntactically consumed both. It contains no goal,
answer, target, path order, terminal action, success magnitude, or policy
continuation. Content-derived hashes, never arbitrary answer-bearing names,
identify rows.

The primary denotation contains exactly the earliest valid public witness for
each atom and link. Additional repetitions remain in the full audit ledger but
do not enlarge the positive rate denominator. This prevents repeated evidence,
verbose outcomes, or replay from manufacturing compression. Scope/status
changes that alter reads are represented explicitly; otherwise PCFL's fixed
root scope and live status belong to the single charged manifest.

A `SCHEMA_DEF` is claim-eligible only when its source supports and exact
prediction bytes seal before the confirmation cohort's decisive outcomes. A
later-confirmed proposal remains attributable to the earlier commitment. A
post-outcome proposal is a leakage-positive sentinel and never enters the
candidate code. Contradictions become charged residual exceptions and task
errors; no failed root, mapping, or schema is removed.

Canonical encoding is the strict v3-style UTF-8 JSON/JSONL discipline:
Unicode NFKC, sorted keys, compact separators, integers only, duplicate and
unknown fields rejected, sorted content-derived IDs, and one U+000A after
each JSONL object. The eventual ratified schema must fix field widths,
enumerations, ordering, and complete test vectors before roots. This note does
not silently choose implementation bytes.

Unique supported `ATOM_DEF`, authentic `LINK_DEF`, and prospectively committed
`SCHEMA_DEF` units are the semantic-load axis. Events, tokens, exposures,
proposals, and provenance repetitions are not.

## 3. The carrier panel

### 3.1 `EXPANDED_OBSERVATION`

This is the primary expanded carrier `E[r,l]`. It is a minimal, standalone
observation normal form, not verbose prose:

- one self-contained row per `ATOM_WITNESS`, repeating the complete
  `ATOM_DEF` and that witness;
- one self-contained row per `LINK_WITNESS`, repeating both complete endpoint
  atom definitions, their primary witnesses, the complete `LINK_DEF`, and the
  link witness;
- one self-contained schema-support row per `SCHEMA_DEF`, repeating its
  complete source atom definitions/witnesses, committed predictions, status,
  and residuals; and
- exactly one minimal schema/version manifest.

It uses the same primitive encodings as the compact carrier, with no prose,
padding, aliases, gratuitous whitespace, long labels, duplicate evidence, or
general-purpose compression. Its exact-key offset index is stored separately
and charged.

### 3.2 `NORMALIZED_CONNECTED`

`N[r,l]` is the strongest ordinary symbolic baseline. It contains one unique
atom table, one primary-witness table keyed by atom hash, one authentic link
table referencing atom hashes, one link-witness table, one schema table, one
residual table, and a charged exact-key index. It is what routine database
normalization should produce. It must reconstruct `D[r,l]` exactly.

This baseline is essential. Beating only `EXPANDED_OBSERVATION` mainly proves
that references and deduplication are shorter than repeated self-contained
records.

### 3.3 `SCHEMA_RESIDUAL_CONNECTED`

`C[r,l]` is the only candidate that can support a scientifically relevant
semantic-compression clause. It stores:

```text
charged manifest and label dictionary
+ prospectively committed schema family/parameter code
+ exact residual exceptions needed to reconstruct every observed atom
+ normalized authentic link table and primary link witnesses
+ exact-key index and any schema-specific decoder state
```

Predictable observed atoms are reconstructed from the schema; exceptions are
never discarded. Links remain authentic child co-use objects. If the candidate
has no prospectively committed schema, `C=N` and only the low-novelty
normalization claim is available.

Two independently implemented total functions must satisfy on exhaustive
small worlds and every experimental artifact:

```text
REDUCE_EXPANDED(E[r,l]) == CANON(D[r,l])
DECODE_NORMALIZED(N[r,l]) == CANON(D[r,l])
DECODE_SCHEMA(C[r,l]) == CANON(D[r,l])
EXPAND(DECODE_SCHEMA(C[r,l])) == E[r,l]
```

All equalities are byte-for-byte. Ambiguity, collision, uncharged dictionary,
or failure on any assigned root/load is a zero/failure, not a schema repair.

### 3.4 Noncandidate references

Report, but never select after seeing roots:

- one frozen ordinary lossless byte codec applied to `E`, including its
  decoder, dictionary, index, decompression scratch, and any simultaneously
  materialized bytes;
- a packed task-specific exact reference consisting of the public label
  dictionary, enumerative permutation index (the independent PCFL cohort
  backbone is only about `16.66` bits), authentic-link code, witnesses, and
  decoder;
- `ATOMS_ONLY`, which removes links and is explicitly resource-lower;
- the complete immutable raw audit ledger, which is not actor-accessible and
  cannot serve as a hidden retrieval store; and
- a post-outcome schema as a leakage-positive ceiling, never a legitimate
  carrier.

The packed reference need not be an actor architecture. It exposes how far
the proposed semantic code remains from the known task sufficient statistic.

### 3.5 LoRA transport carrier

At the largest text-passing load only, build `L_AUTH` from exactly the ordered
rows of `C` and build `L_DERANGED` from the same atoms, schemas, row counts,
byte/token classes, slot order, exposures, optimizer schedule, and build seed,
with only the presealed link/schema binding permutation changed. Each is a
clean-base build of the currently selected fixed LoRA layout. A cyclic
other-root assignment reuses `L_AUTH` as `WRONG_LIFE`; it is not a third build.

LoRA is mounted only for the recognition-assisted `READ`. The clean fixed
resolver and action policy see the same returned canonical rows used by text.
The candidate catalog contains only opaque type/slot metadata and no payload,
answer, binding, hit bit, target, or action. Any label table, verbalizer,
calibration vector, candidate order, prompt, or cache that is life-specific is
part of the LoRA carrier even though no positive LoRA rate claim is attempted.

## 4. One read and task protocol

Every carrier exposes the relay's finite operation:

```text
READ(query_type, anchor_id, selected_candidate_id)
```

The complete candidate-ID list is fixed before goals. The runtime performs one
exact lookup and returns one canonical row or `MISS`. It cannot rank semantic
relevance, shortlist, follow a second edge, repair a trace, inject a path, or
scan the raw ledger. Candidate scans, bytes touched, calls, retries, and
working memory are charged. Call and return caps are constant in semantic
load; linear hidden scans block scalable-read language.

`E`, `N`, and `C` must produce byte-identical returned rows, result classes,
charges, and actor-visible timing classes for the same legal read. They use the
same goals, public starts, resolver bytes, action menu, decoding, and RNG
addresses. A persisted normalized cache derived while reading `E` is an
additional `E` carrier and is charged; a transient expanded copy derived while
reading `C` is charged in its simultaneous acting coordinate.

At each claim load the smallest noncompensatory utility vector is:

```text
A = exact atomic read/action fidelity, including unsupported rejection
P = authentic multi-row connected-path completion and public action value
O = old-cohort retention/action value
Nnew = new-cohort acquisition/action value
S = fresh sparse-cohort value from the prospectively committed schema
X = cross-era path/action value using at least one old and one recent row
F = unsupported, conflicting-twin, or false-memory action rate
```

Targets, twin bindings, sparse confirmation cohorts, decisive cuts, legal
actions, and minimal proofs seal before child actions and admissions. Every
root/load stays in the denominator. Missing acquisition, schema contradiction,
parse/read failure, fit/mount failure, or action failure receives the adverse
registered value.

For explicit carriers, require at every positive-rate load:

```text
A(E), A(N), A(C) >= .95
U(E), U(N), U(C) >= .80 for U in {P,O,Nnew,X}, separately
F(E), F(N), F(C) <= .01

upper95[U(E)-U(C)] < .05 for U in {A,P,O,Nnew,X}, separately
upper95[F(C)-F(E)] < .01
```

`S` answers a different question: schema relevance. Require its candidate
minus atoms-only lower 95% endpoint above zero and its point estimate at least
`.05`, while the matched independent-cohort condition and schema-binding
shuffle remain below their frozen leakage ceilings. Exact carrier transcript
equality is stronger than statistical non-inferiority and should be required
where deterministic common reads make it possible.

At the largest load, connection additionally requires authentic `C` to beat a
degree/type/length/slot-matched link derangement by a point estimate at least
`.05` with lower 95% endpoint above zero. Masking every proof-necessary bridge
must reduce the registered action, and the truthful twin substitution must
redirect to the twin-valid action rather than merely produce `MISS`.
`ATOMS_ONLY` is supporting only because it is resource-lower.

## 5. Complete byte boundary

Do not use tokens, abstract rank, nonzero singular values, gzip size of an
adapter, or a tensor payload alone as the primary rate. For carrier `c`, root
`r`, and load `l`, preserve three noninterchangeable life-specific coordinates:

```text
B_store(c) = every persisted life-specific byte required for a cold start:
             payload/checkpoint + manifests + schema/codebook/dictionary
             + decoder/renderer unique to c + index/catalog/order/verbalizer
             + prompt/template/config unique to c + calibration/router state

B_resident_peak(c) = peak distinct life-specific bytes resident while serving
                     the registered read/action, including decoded copies,
                     indices, caches, KV/workspace, and scratch

B_simul(c) = union of distinct persisted and resident life-specific copies
             simultaneously required at the action boundary
```

Memory-mapped bytes may be counted once in `B_simul` only with a receipt that
they are the same physical representation. Serialized and decompressed copies
are both charged when both are required. Allocator overhead is reported; any
exclusion needs a prospective rule applied to every carrier.

Also print:

```text
B_common       byte-identical base child/tokenizer/resolver/runtime
B_actor_total  B_common + B_simul(c)
B_raw_min      minimal canonical public event bytes for the one primary
               support witness of every denoted atom/link/schema support
B_audit_full   complete retained immutable public ledger and audit objects
```

Only byte-identical code may enter `B_common`. Candidate-specific code is not
amortized over roots, users, queries, or imagined reuse. `B_audit_full` is
capability-inaccessible during acting and reported separately; because it is
retained, neither the whole stored life nor archive is compressed.

For `q in {store,simul}`, compute per root/load:

```text
R_exp_C^q   = B_q(C) / B_q(E)
R_norm_C^q  = B_q(C) / B_q(N)
R_raw_C     = B_store(C) / B_raw_min

R_exp_L^q   = B_q(L_AUTH) / B_q(E)
R_raw_L     = B_store(L_AUTH) / B_raw_min
R_actor     = (B_common+B_simul(candidate))
              / (B_common+B_simul(E))
```

`R_actor` is descriptive. The huge shared base cannot be dropped from a
whole-actor sentence or added only to a favorable denominator.

The basic semantic-code rate gate is the one-sided root-level 95% upper bound
below `.50` for both `R_exp_C^store` and `R_exp_C^simul`, and below `.35` for
`R_raw_C`, at each of the three registered positive-rate loads. The stronger
method-relevance gate additionally requires the corresponding `C/N` upper
bound below `.80` at the last two loads and `C` no larger than the frozen
general-purpose codec in `B_simul`. The `.80` margin is deliberately a
prospective practical threshold: a smaller improvement may still be reported
descriptively, but should not be sold as a novel semantic compressor.

Exact pinned-tokenizer counts are secondary diagnostics under a separately
authorized model-free tokenizer receipt. They never replace UTF-8/file bytes.
The complete compute vector—compiler, renderer, index, training, mount, query
encoding, candidates/bytes touched, reader/resolver FLOPs, calls, wall time,
accelerator time, peak memory, and energy if available—is reported without
conversion into a favorable synthetic scalar.

## 6. Load curve and crossover selection

Use a frozen PCFL cohort-count grid, not native-context multiples. Native
context is relevant to long-context baselines but says nothing about the
semantic or adapter byte crossover.

Before scientific identities or child outputs, a CPU-only full-support fixture
evaluates the exact serializer on a presealed power-of-two cohort grid with
fixed label byte classes, one primary witness per unit, fixed authentic-link
density, and strictly increasing unique mappings. Let `m*` be the first grid
point at which the fixture meets all three basic semantic byte thresholds in
both required coordinates. Freeze these four cohort cuts:

```text
m_prev = immediately preceding grid point
m_1    = m*
m_2    = 2*m*
m_3    = 4*m*
```

`m_prev` is a pre-crossover calibration and `m_1/m_2/m_3` are the three
prospectively fixed claim loads. Actual rates use actual admitted semantics;
no root or cut is moved when acquisition is sparse. All three claim loads must
add new supported atoms and authentic links. A rate pass caused only by extra
witnesses, verbose labels, raw prose, padding, repeated exposure, or a stalled
unique-mapping count is invalid.

If no `m*` occurs inside the CPU/resource ceiling, stop. Do not generate a
model task, choose a more redundant expanded format, relax `.50/.35`, or use
LoRA. If `C` crosses `E` but never beats `N` or the frozen ordinary codec,
retain at most the low-novelty normalization result.

The physical-LoRA crossover is a separate function. Before any positive
physical rate experiment, the actual SHA-bound complete numerator and actual
`E`/`B_raw_min` denominators must yield a crossover, followed by at least
three strictly later useful loads within the resource lease. For the currently
reported rank-8 adapter file alone:

```text
B_store(L_AUTH) >= 80,792,096 bytes
R_exp_L^store < .50 requires B_store(E) >= 161,584,193 bytes
R_raw_L < .35 requires B_raw_min >= 230,834,561 bytes
```

Complete auxiliaries raise these minima. The hypothetical bf16 tensor floor
`40,370,176` bytes receives no credit for the current fp32 serialization. A
new smaller rank/layer/precision/sparse/dedicated carrier is a material Route-C
architecture and must be bound and requalified as a new carrier, not inserted
after observing this experiment.

## 7. Minimum controls

The semantic-text assay needs all of the following; dropping one changes the
claim:

1. `EXPANDED_OBSERVATION`, `NORMALIZED_CONNECTED`, and
   `SCHEMA_RESIDUAL_CONNECTED` under one read protocol;
2. exact round trip and byte-identical returned-row receipts;
3. fixed ordinary codec and packed task-specific exact references;
4. authentic versus matched link derangement;
5. complete necessary-bridge cut and truthful twin redirect;
6. authentic schema versus schema-binding shuffle and atoms-only;
7. matched structured versus independent-cohort regime;
8. prospectively committed versus post-outcome schema sentinel;
9. unsupported/conflicting-twin false-memory probes; and
10. raw-ledger capability denial plus candidate/passive/identifier/source-
    string leakage closure.

At the one LoRA load, the minimum is two new builds per attempted root:
`L_AUTH` and matched `L_DERANGED`. `BRIDGE_CUT`, truthful twin/schema-binding
swap, and adapter-off are read-time clones; `WRONG_LIFE` reuses the presealed
cyclic other-root authentic adapter. Also require candidate-only base, unaided
generative read, exact atomic retention, and `TEXT_SAME_SEMANTICS`. A control
failure is adverse-filled and cannot create a favorable contrast.

LoRA transport passes only if:

```text
A(L_AUTH) >= .90
upper95[U(C_TEXT)-U(L_AUTH)] < .05
  for U in {A,P,O,Nnew,S,X}, separately
upper95[F(L_AUTH)-F(C_TEXT)] < .01
upper95[F(L_AUTH)] < .02

AUTH - DERANGED, AUTH - BRIDGE_CUT,
AUTH - ADAPTER_OFF, and AUTH - WRONG_LIFE
each have lower95 > 0 and point estimate >= .05,
with truthful twin/schema swaps redirecting to their valid alternatives.
```

Passing says the compact connected/schema semantics were transported through
the adapter. `R_exp_L` and `R_raw_L` are still printed as descriptive negative
rate diagnostics; they are not gates for the transport sentence and cannot be
omitted because they are unfavorable.

Bind the one fixed child-selection rule, parent/nursery deletion law, PCFL

- prove the three decoders and exact expansion identities;
- enumerate side channels and finite target-blind readers;

### Stage 2 — explicit-text feasibility only

After separate authority, run four no-claim DEV roots, then the remaining four

### Stage 3 — prospective schema falsifier

Before any LoRA build, require the text carrier's schema prediction to improve
the sparse fresh-cohort target over atoms-only, fail under the binding shuffle,
and not manufacture the same gain in the independent-cohort control. A
post-outcome schema must work as a leakage ceiling. If the prospective schema
does not add value, stop at the ordinary-normalization result.

### Stage 4 — minimum LoRA transport

First run one disjoint low-load install/read canary. Stop if the writer cannot
return exact training-semantic rows, if adapter-off is indistinguishable, or

chain is already fixed, build `L_AUTH` and `L_DERANGED` at `m_3`; text-failed
roots remain adverse zeros. Run attribution controls only after authentic
read/utility survives. No LoRA build is launched merely to measure the already
foreclosed physical rate.

### Stage 5 — physical compression remains closed

Open a future physical rate panel only after Stage 1 prints at least three
prospectively selectable useful loads strictly beyond the larger actual
expanded/raw crossover for the complete carrier. Then require the full
distortion vector, authenticity controls, fixed root-level power, fresh
independent review, and exact GPU authorization. No success in semantic text or
LoRA transport waives this gate.

## 9. Cheaper decisive falsifiers

Run these in order and stop at the first applicable failure:

1. **Entropy/reference attack.** If the code is orders of magnitude above the
   packed `~16.66`-bit-per-independent-cohort backbone after fair label/link
   accounting, it may be shorter than verbose events but has no strong coding
   efficiency story.
2. **Normalization attack.** If `C` is byte-identical to, larger than, or less
   than 20% smaller than ordinary `N` at the last two loads, do not call it a
   novel semantic compressor.
3. **Ordinary-codec attack.** If a frozen lossless codec plus decoder/index and
   acting scratch is no larger, the special semantic-code efficiency claim is
   unnecessary.
4. **Round-trip attack.** Any non-bijection means the numerator and comparator
   do not denote the same observed experience.
5. **Repetition attack.** If the favorable rate depends on multiple witnesses,
   long skins, padding, replay, or raw prose rather than unique mappings, the
   compression result is engineered.
6. **No-schema attack.** If ordinary independent PCFL-Stream passes the schema
   target, the benchmark leaks; if the structured condition does not beat
   atoms-only prospectively, there is no abstraction result.
7. **Connection attack.** If derangement or bridge cuts preserve value, the
   shorter code is not evidence of useful connected knowledge.
8. **Interface attack.** If expanded and compact carriers do not yield the same
   rows under the same read plan, the apparent rate advantage is a protocol
   change.
9. **Static LoRA intercept.** If actual `E` is at or below `161,584,192` bytes,
   the rank-8 adapter file alone mathematically cannot pass `.50`; do not build
   for a positive rate cell.
10. **Text-before-LoRA attack.** If exact text cannot complete the registered
    path/schema tasks while the leaked oracle can, the benchmark/interface is
    invalid and LoRA is uninterpretable.
11. **Install attack.** If one low-load LoRA cannot reliably return its exact
    compact rows or fails adapter-off/wrong-life, stop before the high-load
    transport panel.

These falsifiers are more informative per GPU-hour than a four-load all-layer
adapter sweep whose numerator already dominates the proposed denominator.

## 10. Novelty and relevance attack

The basic semantic-code claim is **not novel by itself**. In the current
sources, a deterministic, human-specified compiler maps events into typed atoms
and co-use rows; a normalized carrier removes duplicated provenance and uses
references. That is conventional database normalization/sufficient-statistic
engineering. It does not show that DREAM learned a representation, discovered
a schema, compressed within weights, or retained information sublinearly.

The current independent-cohort PCFL-Stream makes this limitation sharper. It
adds thirteen unrelated mappings per cohort. A compact table may have a good
constant-factor byte ratio while still growing linearly with every new
mapping. Fixed grammar plus a favorable ratio is not learned abstraction. A
co-use link also comes from a prescribed public syntactic admission rule; its
causal usefulness can be novel evidence about the complete system, but its
existence is not evidence that an internal graph emerged.

Consequently:

- `N/E < .50` is a useful accounting calibration and actor-interface result,
  not a headline compression method;
- a system-level experiential-code result becomes scientifically relevant only
  when the code is prospective, authentic, behaviorally necessary, beats
  ordinary normalization by a practical margin, and survives the structured
  versus independent/schema-binding controls;
- even that result remains conditional on a deliberately compressible PCFL
  regime family and should be described as **prospective schema-plus-residual
  coding**, not autonomous concept discovery; and
- the strongest future evidence would require regime families, renderers, and
  schema forms not effectively enumerated by the writer's supplied codebook.
  That is a larger learned-representation experiment, not this minimal E3.

Semantic compression is therefore relevant here as a necessary bridge and a
strong baseline for the full Dream--LoRA--Think objective. It should not carry
the paper's novelty alone. LoRA transport adds substrate evidence but does not
repair the coding novelty or rate failure. Only a later complete-state
post-crossover experiment can add the physical compression clause.

## 11. Claim ladder

The release sequence is strict and noncompensatory:

```text
valid public provenance and exact compiler
-> E/N/C round-trip equality
-> complete byte manifests and semantic crossover
-> explicit-text transcript/utility non-loss
-> authentic connection, bridge, twin, and leakage controls
-> prospective schema value and independent-regime falsifier
-> ordinary-normalization/codec relevance gates
-> optional one-load LoRA transport and attribution controls
-> future complete-state physical crossover and three post-crossover loads
```

Allowed language at the highest current-scale semantic rung is:

> Conditional on one fixed parent-deleted child and the registered structured
> PCFL distribution, the system converted its own supported public
> action--outcome experience into an exact, shorter connected
> schema-plus-residual actor-facing code. The prospectively committed schema
> preserved the registered old/new connected utility and improved a sparse
> fresh-cohort task relative to matched atoms-only and binding-shuffled
> controls.

Add this only after the separate transport rung passes:

> The same compact semantics were behaviorally accessible through the assigned
> per-life LoRA under recognition-assisted reads; adapter-off, wrong-life,
> matched derangement, and necessary-cut controls removed or redirected the
> relevant effect.

Do not combine the sentences into “LoRA compressed experience.” Report the
actual LoRA byte ratios immediately; at present they are expected to be
unfavorable.

A future complete-state sentence is available only if the exact full-state
gate passes:

> At three registered loads strictly beyond the measured crossover, the
> complete life-specific actor-accessible carrier was below the registered
> expanded/raw rate thresholds while preserving every registered distortion
> and authenticity component.

Even then, state that the common pretrained child was shared and the raw audit
archive was retained outside actor capability. No result here supports
whole-agent, whole-archive, lossless-autobiography, cross-child, universal,
asymptotic, compute-efficiency, or general-intelligence language.

## 12. Disposition

1. Preserve the positive physical E3 gate as closed at current scale.
2. If resources permit only one new E3 activity, run Stage 1 CPU semantic
   accounting and falsification. It can kill an uninteresting design without a
   model or GPU.
3. If Stage 1 passes, run the eight-root explicit-text DEV only. Its output is
   feasibility evidence, not a population claim.
4. Promote a prospective schema-plus-residual confirmation only after a new
   exact power receipt and ratification. If only normalization passes, report
   it as a narrow code-length baseline.
5. Treat one-load LoRA transport as optional and downstream. It neither needs
   nor receives a positive byte-rate gate.
6. Revisit physical carrier compression only at a genuinely larger semantic
   scale or under a newly deliberated smaller carrier architecture.

This design keeps the full E3 objective alive without converting an
80.79-MB adapter intercept into a fictional success.
