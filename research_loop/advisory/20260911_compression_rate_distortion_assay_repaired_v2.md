## 1. Adjudication

**Accept every scientific repair in the adversarial critique.** The original
three-way distinction and physical no-go survive, but its denotation, primary
comparator, reader, and state-accounting contracts were not claim-safe.

| critique | repaired disposition |
|---|---|
| numerator and raw denominator represented different objects | coding rate now compares only exact encodings of one frozen `D_pub`; raw-life reduction is separately named lossy projection |
| child could shrink its own judged denotation | `Omega` fixes every opportunity before action; absent/malformed/late child output remains explicitly encoded and adverse-scored |
| admission could leak hidden truth | compiler is a total public-syntax transducer; `D_star` is evaluator-only and never changes actor-visible state |
| supplied schema/decoder was hidden side information | schema inventory, decoder, carrier-static code, and selected schema bytes are charged; conditional and two-part lengths are both reported |
| expanded/JSON baseline was weak | packed normalized same-denotation code and its frozen ordinary-codec form are mandatory primary comparators |
| common READ could hide semantic work | exact coding/fidelity is a CPU assay with evaluator-supplied keys; native reader/action utility is a separate downstream assay with every native scaffold charged |
| `B_common` could absorb candidate code | generic, task-shared, carrier-static, and life-specific state are separately censused; unused code does not become common by installation |
| storage and residency were conflated | exact persisted package bytes are the coding rate; CPU/GPU residency, scratch, coexistence, bytes touched, and latency form a separate deployment vector |
| resume state was hypothetical | a claimed resumable package must actually cold-resume the frozen updater through one new cohort; the cumulative corpus is charged when the updater needs it |
| CPU/GPU plan lacked a lease | each stage below has a proposed hard planning ceiling and stops before execution unless an exact bound packet fits it |

## 2. One frozen opportunity object

For root `r` and predeclared cohort cut `l`, freeze before the child acts:

```text
Omega[r,l]  every public semantic emission/acquisition opportunity at the cut
D_star[r,l] evaluator-only correct content/status for every Omega slot
E_emit[r,l] the exact child bytes (or absence) emitted in each public slot
D_pub[r,l]  the total public-syntax parse of every Omega slot
```

`Omega` is fixed by cohort count and public opportunity schedule, never by
what the child successfully learned or emitted. `D_pub` contains one row per
slot with exactly one of:

```text
PARSED | ABSENT | MALFORMED | LATE | PUBLIC_SUPPORT_MISSING
```

Every encoded slot uses a content-free public opportunity ID fixed before
root truth. The ID roster, order, and visible bytes are identical across
binding twins and contain no relation value, success bit, future target, or
answer-bearing absence pattern. `Omega` may contain evaluator-only fields,
but only this public ID projection can enter `D_pub`.

The compiler may validate field grammar, ordinals, hashes, chronology, and
whether a cited public event exists. It may not inspect `D_star`, hidden world
truth, future goals, a theorem/proof oracle, target utility, or later outcomes
to admit, reject, relabel, repair, or set status. Semantic falsity and
proof-necessity are evaluator labels only and generate no feedback unless a
separately designed public verifier event is supplied identically to all
carriers.

All rate carriers losslessly encode the same complete `D_pub`, including
adverse slot states. Every opportunity remains in coverage, false-memory,
utility, and root denominators. An empty child can have a short code, but it
fails distortion and cannot pass useful compression.

Keep two source comparisons separate:

1. **Same-denotation coding:** exact package length for `D_pub` versus another
   exact package for `D_pub`.
2. **Task-lossy life reduction:** package length versus the minimal public
   action--outcome event tape `H_min` or actual visible tape `H_visible`, with
   every discarded field named and distortion scored against `D_star`.

No raw-life ratio may be called lossless, same-denotation, or complete-
experience compression. DREAM paraphrases, replay renderings, repeated
witnesses, and training steps are derived data and never enlarge `Omega` or a
source denominator.

## 3. Exact candidate and primary comparators

### 3.1 Mandatory packed normal form

`PACKED_NORMALIZED(D_pub)` is the primary comparator. It uses dense local
ordinals, packed enums/statuses, the same fixed label alphabet and integer
widths as the candidate, one canonical public-witness table, normalized
atom/link/schema tables, and a succinct exact-key index. Long hashes and
provenance fields appear only when the registered actor must use them; any
audit-only mapping remains reported outside the acting package.

Apply one frozen ordinary lossless codec independently to both the packed
package and the candidate. Compare plain to plain and codec to codec;
`PACKED_NORMALIZED` and `CODEC(PACKED_NORMALIZED)` are both mandatory.
Expanded semantic rows, normalized JSON, `H_min`, and `H_visible` remain
descriptive diagnostics; none is the primary coding win.

### 3.2 Schema plus residual candidate

Before confirmation outcomes exist, expose exactly one schema-commit slot per
root/cut. Use the first exact parse after the frozen source boundary. Store and
charge its exact child bytes, family ID, parameters, scope, ordinal, and
selection metadata. Later amendments never replace it; they become residuals
or failures. Ambiguity, an out-of-language proposal, or no parse is adverse.

After outcomes, a deterministic residual encoder records every disagreement
between the sealed schema and `D_pub`; it cannot revise the schema, select a
shorter family, or omit an exception. The resulting
`CHILD_SCHEMA_RESIDUAL(D_pub)` must decode byte-exactly to `D_pub`.

Run `FIXED_SCHEMA_RESIDUAL` only as a supplied-schema compressibility ceiling.
If fixed succeeds and child-authored fails, the benchmark is compressible but
DREAM did not compress it.

### 3.3 Side-information accounting

For every carrier `c`, census:

```text
B_generic
  distribution-independent runtime/serialization used identically by all

B_task_shared
  PCFL grammar and task laws genuinely required and used by all carriers

B_carrier_static(c)
  carrier-specific schema inventory, family table, decoder, codec, reader code

B_life(c)
  root payload, schema selection, residuals, dictionaries, index, catalog,
  prompts, calibration, ordering, and all other life-specific state
```

Carrier-specific unused code cannot become common merely because it is copied
into every image. Report:

```text
L_conditional(c) = packaged B_life given all sealed side information
L_two_part(c)    = packaged B_task_shared + B_carrier_static(c) + B_life(c)
```

The two-part length is primary. Conditional length may support only “within
the supplied schema language.” No task-specific bytes are amortized across
imagined roots, users, or deployments.

## 4. Rate, footprint, and resumability are different coordinates

### 4.1 Coding rate

Primary rate is exact packaged persisted bytes under one identical packaging
law:

```text
R_packed_plain = L_two_part(CHILD_SCHEMA_RESIDUAL)
                 / L_two_part(PACKED_NORMALIZED)

R_packed_codec = L_two_part(CODEC(CHILD_SCHEMA_RESIDUAL))
                 / L_two_part(CODEC(PACKED_NORMALIZED))
```

Also report both conditional ratios and descriptive ratios to expanded,
`H_min`, and `H_visible`. The descriptive raw ratios are task-lossy projection
rates.

### 4.2 Deployment footprint and work

Do not sum disk and residency into another “code rate.” Against an identical
warm common process, report separately:

- persisted package bytes and whether it remains open;
- incremental logical resident payload;
- incremental physical CPU-RAM and GPU-RAM peaks;
- peak scratch and decoded-copy bytes;
- whether disk/resident/decoded copies coexist;
- bytes touched and candidates scored per query;
- stored, input, returned-memory, generated-thought, and action tokens;
- compiler/index/train/mount time; and
- cold/read/action/update p50 and p95 latency, calls, FLOPs, and accelerator
  time.

Build/training work is unamortized. A secondary amortized number may divide
only by the predeclared realized query count. A linear hidden scan blocks
scalable-reader and compute-efficiency language.

### 4.3 Resumable learning state

Define `L_resume(c)` from the minimum actual package that can cold-start the
frozen updater and admit one further presealed cohort. The test must reproduce
the complete next-update input manifest and expected public output/receipt.
Charge the cumulative compiled corpus or raw ledger if the real clean-base
rewrite requires it; do not charge optimizer state if the real updater resets
it. Audit-only state is separately inaccessible and cannot secretly feed the
update.

Actor-facing compression uses `L_two_part`. A resumable-organism statement
requires `L_resume` to cross independently. Retaining a complete audit archive
for science forbids whole-archive or lossless-autobiography language.

## 5. Fidelity and utility gates

### 5.1 CPU coding/fidelity assay

An evaluator supplies the same frozen public query key to each decoder. Score
exact row/status, `NOT_FOUND`, bytes touched, and work. Require independent
decoders to satisfy:

```text
DECODE(PACKED_NORMALIZED)       == CANON(D_pub)
DECODE(CODEC(PACKED_NORMALIZED))== CANON(D_pub)
DECODE(FIXED_SCHEMA_RESIDUAL)   == CANON(D_pub)
DECODE(CHILD_SCHEMA_RESIDUAL)   == CANON(D_pub)
```

This isolates coding. It says nothing about whether a model chooses the right
query or traverses memory.

### 5.2 Opportunity-level distortion

Compare the public parse to evaluator-only `D_star` over all `Omega` slots.
Keep these root-level outcomes separate:

- atom and authentic-link opportunity coverage;
- schema-slot coverage and chronological validity;
- omission, malformed, late, or public-support-missing output;
- semantically false content;
- unsupported read;
- wrong binding, wrong owner/root, revoked-status read; and
- action relying on absent, false, out-of-scope, or twin-conflicting memory.

Use one-sided root-level bounds for absolute floors/ceilings and paired
differences. At minimum, atom and authentic-link coverage lower95 must be
`.95`; prospective valid-schema coverage lower95 must be `.80` in structured
roots. Predeclare equal numbers of opportunities for every false-memory
family. Targets and technical repeats reduce within root; root is the only
independent unit. Missing roots and technical failures receive adverse values.

### 5.3 Native end-to-end preservation

Only after the learned PCFL M1--M3 relay independently qualifies an endpoint,
use a common actor to choose queries from identical public state and goals.
Each carrier uses its own frozen native reader under an exhaustive symmetric
candidate universe, identical call/action/generated-token ceilings, and
charged catalogs, key-to-payload maps, indices, prompts, candidate tokens,
and scans.

Compression may test preservation of already established atomic, connected,
goal-swap traversal, old/new/cross-era, prospective schema, or one-cycle
expansion utility. It cannot originate M1--M3 claims. If an upstream endpoint
has not passed, omit it from the compression clause.

For each included utility `U`, require the explicit packed reference to have
predeclared headroom and:

```text
upper95[U(PACKED_NORMALIZED)-U(CHILD_SCHEMA_RESIDUAL)] < .05
```

False-action excess over packed must have upper95 below `.01`. Schema value
also requires a point gain of at least `.05` with lower95 above zero over
atoms-only, loss under schema-binding shuffle, and no gain in an
equal-marginal independent-regime control. Use an intersection--union release:
no average, later load, or one favorable failure family rescues another.

LoRA is a downstream transport test. It must use the same compact semantic
rows, full symmetric candidate universe, and charged scaffolds, and pass
adapter-off, cyclic wrong-root, matched derangement, bridge-cut, truthful
twin, native-interface, and non-harm controls. Passing remains transport, not
compression.

## 6. Staged experiment and hard planning ceilings

### A. Zero-model same-denotation falsifier

No child, tokenizer, LoRA, C11 execution, or GPU.

1. Freeze `Omega`, `D_star`, public-only compiler, single-schema selection,
   schema inventory/decoder, primitive encodings, and fixed cohort grid.
2. Validate independent packed, fixed-schema/residual, and ordinary-codec
   round trips exhaustively on tiny worlds.
3. On eight presealed synthetic calibration roots, use exact integer length
   recurrences on `m in {1,2,4,...}` cohorts. Stream/hash only boundary
   artifacts; do not retain giant encodings.
4. Stop unless fixed schema/residual is at least 20% smaller than packed
   normalized in both matched comparisons (`plain/plain` and `codec/codec`)
   at two consecutive growing loads and has a smaller incremental byte slope.

Proposed maximum lease before ratification: `16` CPU-core-hours, `16 GiB` peak
RAM, `8 GiB` temporary disk, and `2,048` retained receipt/test objects. Exceeding
any limit is `NO_GO` for this version, not permission to materialize more.

Maximum implication: the registered distribution admits a shorter supplied-
schema code.

### B. Artifact-only child-authorship audit

Apply the public-only compiler to already-existing prospective learned-relay
child bytes. Never repair or translate them. Score every `Omega` slot and the
single chronological schema selection. If no qualifying artifacts exist,
record `NO_DATA`; do not substitute C11, supplied memory, or a post-outcome
schema.

Proposed maximum lease: `4` CPU-core-hours, `8 GiB` RAM, `2 GiB` temporary
disk. Maximum implication: an existing artifact is or is not eligible for a
later prospective test—no compression claim.

### C. Four-root prospective explicit-text DEV

Only after A passes and a learned-relay DEV path exists. Use four disjoint
roots, all retained, at the pre-crossover diagnostic plus three fixed growing
cohort loads. Compare child schema/residual, packed same-denotation text,
atoms-only, schema-binding shuffle, equal-marginal independent regime, and a
post-outcome leakage ceiling. The compiler never filters truth.

Before any call, emit exact counts for roots, opportunities, calls, input/
output tokens, bytes, expected wall time, and p95 headroom. Proposed ceiling:
`8 A40-hours` and `24` wall-hours total for this DEV. If the projection does
not fit, stop or narrow through a new design; never drop a root/control.

Maximum implication: child-authored prospective semantic-code feasibility on
four DEV roots.

### D. Powered semantic-code confirmation

Stage C supplies the complete root-level outcome vector and technical-failure
rate. Before confirmation identities exist, a frozen simulation chooses the
smallest allowed `N` with `.80` joint power for the full intersection and
`.90` for the primary largest-load packed-rate and cross-era utility gates.
No default `N=24` is assumed. Publish the exact CPU/GPU/wall/storage lease
before identities. If no allowed `N` fits, narrow the claim by a new
deliberation; do not weaken thresholds.

Maximum implication:

> Within the sealed supplied schema language, the child prospectively selected
> a schema instance whose exact two-part schema-plus-residual code was at least
> 20% shorter than packed same-denotation and ordinary-codec baselines while
> preserving the specifically registered upstream-qualified utilities.

It cannot say the child discovered the schema family or learned a universal
representation.

### E. Optional one-load LoRA transport DEV

Only after W1 conditional writing, W2 repeated-write/authentic-source gates,
the relevant M1--M3 endpoint, and C all pass. First run one disjoint two-build
`AUTH/DERANGED` canary. If it passes, run four fresh DEV roots with two builds
each: ten fits maximum. Adapter-off, wrong-root, cuts, and twins are read-time
controls only where they introduce no hidden answer.

After actual C corpora exist, emit exact training tokens, sequences, steps,
sequence lengths, measured same-recipe throughput, GPU memory, p95 fit time,
and failure accounting. Proposed ceiling: `12 A40-hours` and `24` wall-hours.
If ten adverse-fill-safe fits do not fit, do not run.

Maximum implication: already-qualified compact semantics were behaviorally
transported through the per-life LoRA. Print unfavorable LoRA rates.

### F. Physical LoRA rate remains closed

The current known rank-8 adapter-plus-config subtotal is `80,793,355` bytes,
before life-specific scaffolds. It alone requires expanded bytes above
`161,586,710` for rate below `.50` and minimal raw bytes above `230,838,157`
for task-lossy rate below `.35`. Do not spend GPU time at current scale.

Reopen only when the exact complete persisted actor package—and separately the
actual cold-resume package—crosses packed same-denotation and task-lossy raw
comparators at three useful later loads. A quantized, sparse, targeted-layer,
or dedicated carrier is a new architecture and needs its own writer/read
qualification and authority.

## 7. Claim ceiling and C11 boundary

The release order is strict:

```text
fixed opportunities and public-only compiler
-> same-denotation exact coding
-> two-part packed/codec rate
-> opportunity distortion and false-memory bounds
-> preservation of only upstream-qualified utility
-> prospective child schema attribution
-> optional LoRA transport
-> future physical actor/resume crossover
```

Possible language by stopping point:

| pass | maximum wording |
|---|---|
| A only | supplied-schema compressibility of the registered distribution |
| D | child selected and prospectively committed a useful shorter instance within the supplied schema language |
| E | the same compact semantics were transported through LoRA |
| future actor crossover | complete actor-facing life package was physically smaller at the registered distortion |
| future resume crossover | complete resumable learning-state package was physically smaller at the registered distortion |

None licenses whole-archive compression, a literal graph in weights, learned
schema-family discovery, universal abstraction, compute efficiency, parenting,
continual improvement, sentience, or general intelligence. C11 remains a
separate fixed-policy, fixed-topology, supplied-memory ceiling. It is not
finished, enforced, executed, counted as a root, or used as learning/
authorship/retention/LoRA/compression evidence here.
