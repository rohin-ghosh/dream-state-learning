# PCFL-Compose semantic-representation adjudication

**Date:** 2026-09-02  
**Status:** fresh read-only scientific adjudication. This memo chooses a
recommended proposal direction. It does not ratify architecture, authorize
proposal/code edits, authorize CPU/model/GPU/network/training/LoRA work,
promote DEV evidence, or license a scientific claim.

The current
`chg_20260902_pcfl_compose_self_revision_text_dev_v1/experiment_spec.md` was
read as working evidence. It may be under active repair: its prose describes
free-text primary memory, while adjacent working schema/contract bytes already
contain both opaque-note and operator-AST objects and currently make the AST
causal. This memo does not adjudicate that mixed snapshot as if it were frozen,
and no digest below includes any file in that transient change directory.

## Dispositive decision

Select a **behavior-first two-lane factorial**, not an AST-primary organism and
not a corpus that mixes prose and AST records:

1. **`OPAQUE_NOTE_SELF` is the primary organism lane.** The model writes
   byte-preserved natural-language notes inside a mechanically checkable
   provenance envelope, commits exact prospective A/B tray predictions, and
   later reads the notes through a frozen surface-only lexical reader. No
   system component interprets note meaning after emission. Its exact endpoints
   are predictions, actions, `LOCK`, provenance, bytes, and whole-object
   interventions.
2. **`OPERATOR_AST_SELF` is a required, separately labeled
   structure-assisted diagnostic in the ICLR-directed precontext panel.** It
   uses fresh model sessions over the same public lives, chronology, controller
   kernel, and resource envelope. It permits exact denotation, structural
   retrieval, and law/binding cuts, but its operator algebra is explicitly a
   treatment. It cannot rescue an opaque-lane failure or explain opaque notes.
3. **The typed recurrent resolver is primary; the full-context one-shot call
   is a mandatory paired control.** A one-shot match removes the recurrent-
   Dream claim but need not erase a prospective abstraction result.
4. **A public-prefix-identical validation-A continuation fork is mandatory for
   the phrase “self-revision.”** Without it, the exact description is only “a
   second post-A Dream pass.”

This is called two-lane only at the experimental-design level. There is no
per-candidate fallback, joint index, cross-lane record selection, prose-to-AST
translation, or mixed causal memory. If resources force a single lane, run the
opaque lane and accept its narrower behavioral claim. An AST-only positive
does not establish the project's natural experiential-memory path.

The semantic-memory audit is right that opaque prose cannot support exact
record truth, semantic deduplication, factor coverage, operand-order edits, or
semantics-preserving LoRA views. Its error is making the cure the primary
organism. The countercritique is right that the proposed closed grammar makes
`S_6` operators, part-built actions, inverses, ordered composition, universal
rules, and privileged rule retrieval readily available. Its error would be to
discard that grammar entirely: as a parallel diagnostic it is the cleanest way
to distinguish natural-language memory failure from structure-assisted program
synthesis and to make narrow mechanism claims exact.

## Why this is the strongest minimal precontext design

| Criterion | Opaque-only | Closed-AST primary | Selected two-lane design |
|---|---|---|---|
| Oracle ambiguity | Avoids a semantic oracle only by giving up semantic record claims. Exact behavior remains scoreable. | Makes denotation decidable, but the grammar itself supplies a large fraction of the useful solution basis. | Keeps exact behavioral scoring in the primary lane and confines exact semantic scoring to a visibly scaffolded diagnostic. |
| Solution-class amortization | Lowest of the viable interfaces, though morphology, requested chords, process verbs, curriculum, and reader remain supplied. | High: permutation/operator/inverse/composition/rule affordances privilege the factorized solution over an independent table. | Measures this assistance directly with opaque-versus-AST and factorized-versus-independent comparisons. |
| Natural experiential-memory validity | Best available precontext proxy: the frozen model chooses its own language from lived public outcomes. Still synthetic and prompted, not naturalistic evidence. | Weak: tests serialization and use of a supplied symbolic calculus. | Makes natural text behavior the survival gate while retaining a precise symbolic diagnostic. |
| Causal identifiability | Whole-corpus and prefix-continuation effects identify life-specific memory use and evidence-conditioned behavioral change, not record meaning. | Supports exact program truth and node-level cuts if the model emits the registered shape. | Separates object-level causality from lane-specific semantic mechanism instead of conflating them. |
| Later LoRA transport | Can test byte-identical exposure to self-authored notes and downstream behavior, but not exact semantic transport. | Can test lossless structural views and node recovery, but only for symbolic-operator memory. | Preserves both future questions as separate experiments; neither is claimed by this text-only cycle. |
| Resource cost | Cheapest scientifically meaningful primary. | Comparable generation cost but risks spending the only result on a scaffolded task. | Roughly doubles recurrent Dream work, but turns both positive and negative opaque outcomes into interpretable bottleneck evidence. LoRA and post-context scaling remain excluded. |
| Positive/negative information | A positive is natural-path behavioral evidence; a null can mix inference, expression, retrieval, and control failure. | A positive is exact but scaffold-confounded; a null can be an interface burden. | The 2x2 representation-by-family result localizes both scaffold dependence and family specificity. |

No more neutral closed representation is presently superior. A universal
programming language merely hides the prior in a harder interface and creates
execution/safety ambiguity. A finite prediction table is useful as an exact
behavioral commitment, but cannot by itself represent reusable memory or
support record-level mechanism. The smallest honest primary object is therefore
an opaque note plus exact predictions, not a purported semantic string.

## Exact primary memory contract

The active primary unit should be equivalent to:

```text
NOTE(record_id, text_utf8, public_event_ids, premise_node_ids, uncertainty)
```

- `text_utf8` is authored by the model and preserved byte-for-byte. It has no
  registered denotation. Admission, indexing, selection, scoring, cuts, and
  future view generation may not depend on an interpretation of it.
- Use one record form, `NOTE`. Remove
  `GENERAL_RULE/LOCAL_RELATION/EXCEPTION/UNRESOLVED` from this lane. Those tags
  prime a solution ontology and falsely suggest machine-checkable semantics.
- Prospective A/B predictions remain separate, typed tray fields. They are
  behavior, not memory-record truth.
- Public-event and prior-node references are structural provenance only. The
  parser checks existence, eligibility, operation-specific premise counts,
  acyclicity, and a public-event ancestry path. It never checks whether the
  cited evidence supports the prose.
- Retain `R=13`, 256 canonical UTF-8 bytes per note, and a 4,096-byte active
  package for the precontext cycle unless a later deliberation changes all
  three and redoes resource tests. Enforce encoded byte counts in the runtime,
  not JSON Schema code-point `maxLength`.
- Do not enforce “one local binding,” “no universal law,” “no target pair,” or
  “no table enumeration” by interpreting prose. The prompt can prohibit
  target-specific answers; the hard firewall is that targets are unrendered
  and the sleeper receives only a public-reference allowlist. Any post-freeze
  human content coding is descriptive and non-gating.
- Sleep may validate, copy, canonically envelope, and exact-byte index selected
  notes. It may not paraphrase, summarize, infer, normalize meanings, generate
  negatives, complete compounds, or choose among candidates. If exact byte
  deduplication remains, its identity key and provenance-union behavior must be
  declared and every original must remain in the audit ledger.

The opaque reader must be total and surface-only. A suitable frozen contract
is: valid UTF-8 -> named Unicode normalization -> named case rule -> maximal
alphanumeric tokens, while preserving each literal public
`stem::suffix` token and also its two disclosed literal parts. Apply the same
tokenizer to the model query; rank by descending exact token intersection and
then SHA-256 of unchanged canonical record bytes; use a fixed cursor; return
one unchanged note or `NOT_FOUND`. Count query bytes, postings examined,
cursor, result bytes, calls, and tokens. No synonym list, relation ontology,
stemming, embedding, learned ranker, hidden scan, target-aware prefetch, or
completed solution may enter this lane.

Opaque-primary causal interventions are limited to selectors that do not
interpret text: `EMPTY`, `NO_REVISION`, authentic/counterpart or wrong-life
whole-corpus crossing, a predeclared presentation-order permutation, and a
target-independent footprint-matched sham. The sham is only a nuisance control
because changing fluent text can change many latent properties. These cuts can
show that life-specific memory bytes affected behavior; they cannot identify a
particular law or sentence as mediator.

## Exact AST diagnostic contract

`OPERATOR_AST_SELF` may use the closed typed equational operator grammar
proposed in the semantic-memory audit, including explicit public tokens,
actions, six-slot permutations, model-declared symbols, inverse, ordered
composition, apply, equality, definitions, universal rules, exceptions, and
explicit alternatives. But every report must call this an **operator-
scaffolded representation**. “Family-neutral” is not enough: it omits the
literal PCFL equations while still strongly favoring their algebraic basis.

The AST lane must satisfy all of the following:

- fresh model contexts, candidates, Dream-2 decisions, corpus, index, reader,
  and actor branch; never parse, translate, seed, or select it from opaque
  output;
- identical public source bytes, A/B requests and outcomes, family assignment,
  candidate/record capacity, cumulative output-token entitlement, and shared
  recurrent kernel, with representation-specific serialized bytes and actual
  input/call costs reported;
- both factorized and matched independent-table roots, so AST assistance is
  measured rather than declared neutral;
- a frozen total interpreter that type-checks and evaluates only what the
  model wrote, never solves missing bindings, chooses a gauge, completes a
  table, repairs a term, or feeds a truth result back into cognition;
- gauge-invariant joint-program/operator scoring, not standalone truth labels
  for gauge-dependent factor definitions;
- false-shape symmetry in Sleep, the index, and any future view generator; and
- preregistered structural selectors for orientation deletion, composition
  reversal, and decisive-binding substitution. Zero or multiple matches yield
  `CUT_UNAVAILABLE`; a prompt must not require the matching shape merely to
  make a primary gate pass.

Oracle-schema AST, exact public program, class-informed formulas, and the
perfect public-prediction gate remain distinct ceilings. In particular, the
perfect gate may compare only already committed A tray predictions with public
A outcomes. When several candidates have the same A behavior, report that
ambiguity; do not describe the selected candidate as uniquely true.

## Public-prefix-identical validation-A continuation fork

Adopt this fork as a required primary causal instrument.

At seal time, construct two valid factorized continuations `V0,V1` with:

1. byte-identical tree events, public labels, announced A requests, A
   before-trays, Dream-1 prompt, seed, trace, candidates, predictions, and
   commitment;
2. different ordinary A after-trays, with each continuation remaining a valid
   completion of the common tree prefix and selecting a different prospective
   continuation; and
3. byte-identical Dream-2 instruction, budgets, eligible-handle shape,
   seed-by-role, B request shape, and, where action is scored, target-visible
   packets whose correct prediction/action differs across continuations.

Run Dream-1 once and fork its immutable artifact. Run fresh Dream-2 sessions
whose only causal input difference is the raw public A outcome bytes. No match
bit, correctness label, orientation name, repaired candidate, or scorer field
is visible. Preseal disjoint B events and targets, then require B predictions
and downstream actions to follow `V0` in one branch and `V1` in the other.

The tree mathematics permits this: the same labeled tree admits both
orientations under different latent factorizations, while certified
noncommuting chords distinguish the continuations. Stage 0 must certify both
complete continuations, A disagreement, B/target disagreement, target absence,
and all byte-equality conditions before any model call.

The existing primary-versus-antipode comparison does not substitute for this
test when its pre-A source outcomes or Dream-1 traces differ. It tests life
binding; it does not isolate the effect of raw A on Dream-2. A successful
continuation fork supports evidence-conditioned revision of predictions and
memory-selected behavior. It still does not show that a particular opaque note
changed meaning. Failure removes “self-revision” from the claim even if the
ordinary post-A branch succeeds.

## One-system shared-loop ruling

The one-system requirement is substantive, not a shared-weight slogan. Within
each lane, Dream and Think must use one versioned `RESOLVER_STEP` parser, state
tuple, state reducer, budget accounting implementation, and failure semantics.
`READ`, `NOTICE`, `CONNECT`, `REVISE`, and `PASS` must have byte-identical
transition semantics. A generic `READ(locator)` may admit mode-specific
eligible stores or locator subtypes, but must return exactly one immutable
object or `NOT_FOUND` and update state identically.

Mode may change only:

- initial objective and public input source;
- which already-defined locator types are eligible; and
- terminal/output permissions: Dream may predict and durably commit;
  Think may `USE`, `LOCK`, or defer but cannot rewrite frozen memory.

An `x-runtime-*` comment in a JSON Schema is not evidence that this contract is
implemented. Hash-bind the reducer specification and add cross-mode trace
fixtures showing equal operations produce equal state deltas. If Dream and
Think retain different operation grammars, workspace semantics, retrieval
updates, or parsers, use only: “the same frozen backbone under role-specific
recurrent interfaces.”

Keep recurrent B as primary because it instantiates the claimed bounded local
controller. Keep one-shot A as the clean control: it receives the same public
information, objective wording, representation envelope, candidate and byte
caps, terminal semantics, and cumulative output-token entitlement, but all
eligible events at once and no intermediate external state transition. Do not
give it extra `COMPARE/HYPOTHESIZE/COMPRESS` hints. If A is within the
preregistered margin of B on prospective correctness and D4 action, describe
the successful mechanism as a batch compiler, not recurrent dreaming. If A
succeeds while B fails, the one-system recurrent organism fails on this assay.
If B wins, the licensed statement is only that this recurrent protocol helped
at its disclosed call/input-token/FLOP point; the loop was not learned.

## Resource-minimal roster

The precontext study remains one 13-tree-event, two-A-event, Dream/Sleep,
disjoint-B/target cycle. It contains no LoRA, native-context crossing,
checkpoint growth, or confirmation claim.

The smallest paper-directed representation panel is:

- opaque recurrent SELF on open factorized, untouched factorized, and matched
  independent roots, with the presealed life-binding and continuation forks;
- opaque one-shot on the same confirmatory factorized/independent sentinel
  information;
- AST recurrent SELF over the same factorized/independent public bytes in
  fresh sessions;
- neutral-prompt opaque cells on a presealed untouched factorized/independent
  pair, not only an inspected open root;
- exact program, oracle-schema, class-informed, observed-table, raw-RAG, and a
  faithful native linked-memory arm or honest `NOT_RUN`; and
- the representation-appropriate gates and cuts above.

Under the currently proposed caps, recurrent Dream has a hard maximum of 48
calls per realized life and one-shot has two. Adding a recurrent AST diagnostic
to opaque recurrent plus its opaque one-shot control raises the Dream envelope
from 50 to 98 calls per realized life before neutral/class-informed branches,
Think calls, or an extra continuation. A second recurrent Dream-2 continuation
adds up to 16 calls while reusing Dream-1. These costs must be budgeted and
reported; representation and recurrence are not compute-matched by equal
output-token caps. The AST expense is justified because it converts an opaque
null into a representation-bottleneck result and an opaque positive into a
bounded mechanism comparison. If that cost is unavailable, omit AST and every
semantic-mechanism claim rather than making AST the cheaper primary.

## What results license

| Frozen result pattern | Maximum licensed interpretation |
|---|---|
| Construct/exact-program or oracle-reader ceiling fails | Invalid assay; no neural positive or negative is interpretable. |
| Opaque factorized succeeds prospectively, matched independent remains at its certified frontier, whole-corpus crossing redirects action, sham does not, and the prefix-identical continuation follows both A outcomes | Under a frozen prompted recurrent interface, self-authored life text from public experience was causally useful for unseen compound behavior and changed with later raw evidence. No factor-program, record-truth, or naturalistic-generalization claim. |
| Opaque succeeds but the continuation fork fails | Prospective/post-A behavioral memory utility only; no causal self-revision wording. |
| Opaque succeeds and AST also succeeds with valid structural cuts | Two separate findings: a natural-language memory path is behaviorally useful, and an operator-scaffolded model-authored program mediates behavior in the AST lane. It does not prove the opaque notes contain that program. |
| Opaque fails while AST succeeds | Structure-assisted symbolic program synthesis; the natural opaque Dream/Sleep/Think path failed for this frozen model/interface. AST may localize an expression/retrieval bottleneck but cannot rescue the organism headline. |
| Opaque succeeds while AST fails | Behavioral primary survives; the AST may be an interface burden. No record-level mechanism claim. |
| Both learned lanes fail while construct and ceilings pass | A clean model/controller negative at this precontext task, not a refutation of experiential memory or lifelong learning generally. |
| Either SELF lane gains on independent tables beyond the certified frontier | Family-specific abstraction interpretation is invalid; investigate leakage, target decoding, or unmatched interfaces. |
| AST selector is unavailable or its cut does not redirect relative to sham | No claim that the registered law/binding node mediated behavior, even if AST action is correct. |
| One-shot matches recurrent | Prospective compiler result at most; no recurrent-Dream advantage or one-system necessity. |

All three DEV roots remain descriptive. Even the strongest positive above does
not license post-context scaling, autonomous hypothesis discovery, semantic or
asymptotic compression, on-policy evidence acquisition, improved future data,
a learned scheduler/critic/LOOP policy, naturalistic validity, LoRA transport,
or an ICLR confirmation claim.

## Later LoRA boundary

Do not choose the primary representation now for the convenience of a later
trainer. A separately ratified opaque-corpus LoRA may consume exactly the
selected note bytes and frozen mechanical ID/token/verbatim-reconstruction
views. Its positive would support parametric exposure/transport of life text
under the measured reader and action protocol, not exact semantic transport.
Model-generated paraphrases are new authored data, not a mechanical view.

A separate AST LoRA may consume canonical AST bytes and lossless structural
views and may support exact node recovery and symbolic-program cut claims. It
must be called operator-AST transport. Cross-representation performance is not
an identical-corpus comparison. Training a reusable traversal/search/stop
policy over public operation trajectories is a third, outer-loop experiment
and must not be conflated with either per-life memory substrate.

## Exact must-fix proposal deltas

1. **Declare the hierarchy.** Make `OPAQUE_NOTE_SELF` the sole primary causal
   memory lane; add `OPERATOR_AST_SELF` as a fresh-session, structure-assisted
   diagnostic. Prohibit mixed candidates, fallback, shared candidate pools,
   and prose-to-AST translation. Move the paper adjudication's primary
   predictive-operator-DSL requirement to this diagnostic and narrow the
   primary claim accordingly.
2. **Reconcile the working bytes.** Rewrite `experiment_spec.md`,
   `semantic_contract.md`, schema, prompts, fixtures, visibility contract,
   arm roster, tests, and gates to one consistent two-lane design. The current
   free-text-primary prose and AST-primary adjacent contract cannot coexist as
   ratifiable bytes.
3. **Replace the opaque pseudo-DSL.** Use one `NOTE` envelope with exact UTF-8
   text and structural provenance. Remove semantic kind tags and every
   prose-content admission rule requiring a hidden parser, including one-
   binding, universal-law, target-pair, and table-enumeration checks. Replace
   private denylisting with public-reference closure.
4. **Freeze the opaque reader.** Specify normalization, case handling,
   tokenization, literal compound/part handling, overlap score, hash tie-break,
   cursor, `NOT_FOUND`, and full byte/posting/call accounting. Delete “literal
   relation words” and every semantic ranking implication.
5. **Make runtime semantics enforceable.** Encode or hash-bind all phase/op/
   terminal cardinalities, exact terminal bytes, ID uniqueness, exact A1/A2
   and B1/B2 sets, RETAIN byte identity, REVISE ancestry, malformed behavior,
   provenance acyclicity, and canonical UTF-8 byte accounting. Schema comments
   alone do not satisfy this requirement.
6. **Bind a real shared kernel.** Use the same parser, state reducer, workspace
   representation, `READ/NOTICE/CONNECT/REVISE/PASS` transitions, accounting,
   and failure behavior in Dream and Think; allow only input/store and terminal
   permissions to vary by mode. Otherwise delete “one resolver/one system” and
   use the role-specific-interface wording.
7. **Repair the one-shot and neutral controls.** Give one-shot the same
   objective, representation, capacity, terminal contract, and public
   information without one-shot-only cognitive hints. Run a neutral-prompt
   sentinel on a presealed untouched factorized/independent pair, not only the
   open root.
8. **Add the public-prefix-identical A continuation fork.** Generate and CPU-
   certify two full valid continuations of one byte-identical tree/Dream-1
   prefix; fork only at raw A after-trays; hold Dream-2 interface and seeds by
   role fixed; require branch-correct B predictions and action where certified.
   Distinguish this revision test from the non-identical antipode life-binding
   intervention.
9. **Partition metrics and cuts.** Gate opaque SELF only on exact A/B
   predictions, executed actions, bytes/provenance, lexical reads, prefix-fork
   sensitivity, and whole-object cuts. Restrict program truth, factor/law
   coverage, the 4/13 semantic-item certificate, orientation deletion,
   composition reversal, decisive-binding cuts, and semantic conservation to
   AST/oracle/class-informed lanes. Treat `CUT_UNAVAILABLE` as data, not a
   malformed primary memory.
10. **Rewrite S1A/S1B.** Opaque natural-path survival must not require a
    universal-law record, final-law truth, false-content score, semantic atom
    count, or record-level cut. Require factorized prospective/action utility,
    independent-table null, whole-corpus first-action redirection, sham
    non-redirection, comparator mutation invariance, and the prefix fork for
    self-revision. Give AST its own non-rescuing diagnostic gate.
11. **State the result matrix and claim ceiling verbatim.** Include the
    opaque/AST success-failure cases above; say explicitly that AST success
    cannot explain opaque notes, opaque success cannot license factor-program
    discovery, and a one-shot match eliminates recurrence language.
12. **Keep later stages separate.** Preserve the text-only, minimal-precontext
    boundary. Any opaque LoRA, AST LoRA, learned-loop training, native-context
    crossing, multi-checkpoint growth, or confirmation roster requires a new
    deliberation, exact corpus/view contract, resource manifest, human
    ratification, and scientific/GPU gate.
