# Model-owned Dream revision protocol for PCFL-Compose

**Date:** 2026-09-02  
**Status:** read-only scientific advisory. This document does not ratify an
architecture, authorize implementation, approve a model/provider/network/GPU
run, promote DEV evidence, or license a scientific claim.

## Executive ruling

The strongest feasible headline condition is not:

```text
model proposes -> exact public comparator labels truth -> sleeper admits labels
```

That condition is a useful ceiling, but the comparator owns the decisive
selection operation. The strongest honest organism condition is:

```text
public tree experience
  -> Dream-1 commits bounded predictive candidates
  -> later raw public validation actions/outcomes
  -> fresh Dream-2 reads the raw events and emits RETAIN / REVISE / ABSTAIN
  -> sleeper compiles exactly the model-selected semantic bytes
  -> text or per-life LoRA
  -> bounded Think reads, plans, acts, and LOCKs
  -> exact comparison only in a sterile offline scorer
```

This is the minimum protocol in which the model, rather than an external
verifier, owns both hypothesis generation and durable memory selection. It
cleanly tests one fixed, prompted pass through Rohin's intended
Think/Dream/Sleep/per-life-memory architecture. It does not test a learned
dream policy, learned sleep schedule, on-policy evidence acquisition, or the
full self-improving flywheel.

The exact public-outcome gate should remain as a matched labeled ceiling. A
no-gate condition should preserve every proposed memory. Neither may replace
the model-owned condition in the headline.

## 1. Exact ownership boundary

### 1.1 Dream owns semantic content and selection

Dream-1 and Dream-2 are invocations of the same frozen resolver used by the
thinker, with a different public state and output permission. The resolver
owns:

- which predictive relations or programs it proposes;
- the explicit predictions made before later evidence;
- whether a prior proposal is retained, revised, or abandoned;
- the complete semantic abstract syntax tree of every durable memory;
- uncertainty and negative/exception records it elects to preserve; and
- the supporting public event IDs it cites.

No durable semantic atom may appear unless an exact model-emitted decision ID
selects it. In particular, the sleeper may not automatically install observed
edge atoms, factor values, an orientation, a gauge, a completed operator, or a
truth label. If witnessed events remain available, they live in the immutable
episodic store and are treated as a separately measured memory channel.

### 1.2 Sleep owns representation, never truth

The deterministic sleeper may only:

- parse a preregistered family-neutral memory DSL;
- reject malformed, over-budget, cyclic-provenance, target-tainted, or
  otherwise ineligible records using rules that do not depend on correctness;
- canonicalize field order without changing noncommutative operand order;
- deduplicate identical semantic ASTs;
- merge the cited provenance lists of identical ASTs;
- serialize the same AST for text memory;
- generate one-to-one, semantics-preserving training views for LoRA; and
- record bytes, views, failures, and source decision IDs.

It may not compare a claim with an outcome, choose between candidates, infer a
factor, solve a gauge, invert or compose an operator, derive a missing edge,
add a reciprocal or transitive consequence, turn uncertainty into certainty,
or drop a syntactically valid selected memory because it is false. A false but
well-formed model-selected memory must compile exactly as a true one would.

`ABSTAIN` produces an empty semantic-law corpus. Malformed or over-budget
selection produces a failed corpus. Neither is repaired by an oracle or
replaced by an oracle schema.

### 1.3 The exact comparator owns scoring only

The exact comparator may use hidden generator truth and later realized public
outcomes only after the relevant prediction, decision, corpus, and action are
immutable. It may compute diagnostic labels and scores. It may not emit a
field consumed by Dream-2, the sleeper, trainer, reader, thinker, actor, cache,
or later checkpoint.

The core rule is:

> A model can learn from a later public event. It cannot learn from an
> experiment harness telling it what that event implies.

## 2. Frozen chronology

Use the sparse connected bipartite PCFL-Compose repair and the corrected D4
hypercube twin construction from the mathematical audit. For each checkpoint
and world-life, seal the entire chronology before source realization.

### Phase 0 -- seal and certify

Seal:

- factorized versus matched independent-table regime;
- the sparse pre-validation spanning-tree edges and their fixed order;
- public validation set `A` and delayed confirmation set `B`;
- all never-executed D1/D4 targets and goal twins;
- the full `2^4` D4 stage-twin orbit, not only one global twin;
- checkpoint, era, action, read, operation, proposal, and memory budgets;
- all branch assignments, model/training seeds, and failure denominators; and
- the complete visibility/taint/reset manifest.

The hidden certifier checks connectivity, noncommutation, identifiability,
target absence, target uniqueness, reader headroom, and twin equality. None of
its products enters a model-facing bundle.

### Phase 1 -- public tree experience

Execute the presealed connected tree edges as ordinary public
`RESET/OBSERVE/USE/ARRIVED` events on fresh handles. Mechanically extracting
the witnessed before/after permutation is allowed as disclosed common
preprocessing. This means Paper 1 does not claim that Dream learned to parse a
tray; its claimed operation begins at connecting witnessed operators into a
predictive per-life model.

### Phase 2 -- blind Dream-1 commitment

Invoke the frozen generic DREAM resolver. It receives only:

- eligible public tree events or the common disclosed extracted operators;
- the visible two-part tool names;
- a fixed family-neutral process prompt and output DSL;
- a presealed list of `A` action pairs for which a prediction is requested;
- the proposal and token budgets; and
- public provenance handles.

It does not receive the PCFL equations, two-orientation hypothesis family,
tree path solution, regime label, hidden factors, chosen gauge, target pairs,
targets, validation outcomes, exact solver output, or scorer fields.

It emits zero to `k` candidate predictive programs. `k=2` is the current
smallest useful primary proposal cap. Every candidate must include:

- a candidate ID and exact semantic AST;
- all semantic records it would need to retain if selected;
- explicit predictions for every `A` item;
- declared confidence or uncertainty;
- cited public roots; and
- an optional `ABSTAIN` record.

Every emitted byte, malformed attempt, duplicate, omission, and abstention is
charged. The complete Dream-1 trace is hashed before any `A` outcome exists.

### Phase 3 -- raw public validation

Execute `A` as ordinary public actions and append their raw before/after
outcomes to the immutable episode stream. Do not append `SUPPORTED`,
`CONTRADICTED`, a match bit, a score, a corrected prediction, or an exact
factor explanation. No program outside the model interprets the outcome for
the headline branch.

### Phase 4 -- model-owned Dream-2 revision

Invoke the same frozen model weights in a fresh context. Dream-2 sees only the
eligible tree events, exact Dream-1 public outputs, and the raw `A` events. It
does not see Dream-1 private chain-of-thought, an external verdict, hidden
truth, or target information.

Dream-2 must emit exactly one terminal write decision:

```text
RETAIN(candidate_id, selected_semantic_AST, predictions_B, evidence_A)
REVISE(parent_candidate_ids, revised_semantic_AST, predictions_B, evidence_A)
ABSTAIN(evidence_A, reason)
```

`RETAIN` must preserve the selected Dream-1 semantic AST byte-for-byte except
for model-emitted epistemic metadata. `REVISE` creates a new model-authored AST
and cites its parents. Both must make prospective predictions for the
presealed disjoint set `B`. `ABSTAIN` selects no active program. At most one
program is active in the primary condition so downstream ambiguity cannot be
silently resolved by a parser or memory backend.

The parser follows the terminal decision literally. It does not infer what the
model meant. A wrong retention, bad revision, false abstention, or malformed
decision is the organism's outcome and remains in the denominator.

### Phase 5 -- representational sleep and memory fork

The sleeper compiles exactly the model-selected AST under the restrictions in
Section 1.2, then freezes and hashes the semantic snapshot. The identical
canonical selected content is realized as:

1. explicit text memory; and, only after its separate gate,
2. a freshly scoped per-life LoRA using the registered view generator.

The corpus freezes before any evaluation goal is rendered. Every failed write
or training run remains assigned and scores zero in unconditional analysis.

### Phase 6 -- sterile Think/action evaluation

Render the sealed goals only after the corpus hash. The frozen wake resolver
receives the goal, current public tray, menus, budgets, and its assigned memory
interface. It retrieves local records, updates a cited workspace, issues real
`USE` actions, and ends with `LOCK`. It never receives a path verdict or
counterfactual outcome. Evaluation events do not update the episodic store,
semantic corpus, adapter, reader index, cache, or later checkpoint.

Use the itemwise minimum-read certificate rather than an arbitrary cap. The
sparse-graph audit gives 13 compiled local semantic items for the gauge-fixed
D4 factor representation and up to 25 raw observed-edge reads if each of eight
candidate tools requires a three-edge derivation plus one orientation record.
These are different legitimate interfaces; report actual work and do not call
the smaller compiled requirement equivalent to raw-history access.

### Phase 7 -- delayed prospective confirmation and offline scoring

After target action is immutable, execute `B` in a sterile delayed-confirmation
fork and record its ordinary public outcome. It cannot re-enter cognition in
that target evaluation or a later primary checkpoint. The offline comparator
then scores:

- Dream-1 predictions against `A`;
- Dream-2 predictions against `B`;
- final program truth and factor/law identity against hidden truth;
- text/LoRA reads and action traces; and
- every causal twin, law, binding, lag, and sham intervention.

Delayed `B` is preferable to attaching a precomputed label before sleep: it
measures whether the final self-selected memory predicts genuinely unseen
evidence without helping select that memory.

## 3. Required matched arms

All arms fork from the same immutable Dream-1 and Dream-2 candidate traces.
The branch label is never model-visible.

### 3.1 Headline: SELF-REVISION

Compile exactly Dream-2's terminal `RETAIN`, `REVISE`, or `ABSTAIN` decision.
False self-approved memories stay active and their downstream cost is measured.
This is the only condition that can support model-owned memory-selection
language.

### 3.2 PERFECT-PUBLIC-GATE ceiling/reference

Give an exact program the same candidate pool and the same raw public `A`
outcomes. It may score only each candidate's preregistered predictions against
`A`, select the maximum-consistency candidate, and use a frozen public tie rule
(declared model priority, then canonical hash). It may not consult `B`, hidden
truth, targets, or repair/generate a candidate.

This is a ceiling on error-free use of the available public validation signal
at fixed candidate recall. It is not an oracle-truth ceiling when several
candidates are observationally equivalent under `A`; report the ambiguity
rate and never describe it as the upper bound on all possible reasoning.

The class-informed compiler, oracle-schema text, and exact public program are
separate, stronger ceilings and must not be conflated with this arm.

### 3.3 NO-GATE ablation

Compile every syntactically valid Dream-1 and Dream-2 candidate, including
conflicts, with an `UNVETTED` model-origin tag. Do not apply public or hidden
truth filtering. This measures the cost of preserving proposal noise.

Because NO-GATE has a larger corpus, add a preregistered footprint-matched
diagnostic that selects one candidate by a target-, evidence-, and
truth-independent hash. Report both; do not hide the natural all-candidate
condition merely because it performs poorly.

### 3.4 NO-REVISION diagnostic

Compile Dream-1's predeclared top-priority candidate without showing `A` to a
second model call. This measures whether public-evidence-conditioned model
revision, rather than candidate generation alone, adds value.

### 3.5 Prompt and downstream ceilings

Retain:

- generic SELF-REVISION on factorized and independent-table lives;
- a minimal neutral prompt ablation without explicit
  `COMPARE/HYPOTHESIZE/PREDICT/REVISE` process hints;
- the class-informed formula prompt ceiling;
- oracle-schema text;
- exact public program;
- raw iterative RAG and faithful native A-MEM/linked memory;
- observed-edge table and orientation/law-deleted memory;
- direct raw-transition/QA LoRA; and
- candidate-only, unaided, wrong/twin, and full substrate-by-reader controls.

The same SELF, GATE, and NO-GATE branches should be realizable in text first.
LoRA is a later matched transport experiment, not a prerequisite for testing
who selected the semantic memory.

## 4. Ownership and oracle-firewall acceptance tests

These tests must pass before a model-owned selection result is interpretable.

1. **Common-trace fork.** SELF, GATE, and NO-GATE consume byte-identical
   Dream-1/Dream-2 proposal pools, public `A` bytes, prompt hashes, seeds, and
   budgets. Forking occurs only after the common candidate trace freezes.
2. **Comparator-mutation invariance.** Replace every offline truth/comparator
   output with arbitrary legal values after the common trace freezes. SELF's
   decision, sleeper corpus hash, text/LoRA training corpus, and action bytes
   must remain identical.
3. **Raw-outcome-only Dream-2 bundle.** An exhaustive consumer/field audit
   proves that Dream-2 receives before/after public events but no match bit,
   status, rank, repaired operator, scorer text, hidden factor, or descendant.
4. **Semantic conservation.** Every compiled semantic AST has exactly one
   model selection decision and round-trips to it. The sleeper adds zero new
   semantic nodes or logical consequences.
5. **Falsity symmetry.** Substitute a well-formed false AST of identical shape
   and provenance eligibility. The sleeper must parse, deduplicate, render,
   and admit it exactly as it admits a true AST. Only the offline scorer's
   diagnostic changes.
6. **ABSTAIN/invalid preservation.** `ABSTAIN`, malformed decisions, missing
   candidates, failed compilation, failed LoRA training, and timeouts never
   trigger fallback schemas, retries with more information, or target removal.
7. **Chronology hash.** Dream-1 precedes `A`; Dream-2 and its `B` predictions
   precede sleep, targets, and `B`; the corpus precedes target rendering. Every
   deadline and hash is machine-certified.
8. **Target-descendant taint.** Target identities, reserved roles, goals,
   unique paths, twin side, cuts, scorer values, and all filenames/caches/
   exceptions/timing derived from them are unreachable by Dream, sleep,
   training, reader, and Think.
9. **Family-blind primary prompt.** Factorized and independent-table lives use
   identical prompts, DSL, parsers, proposal caps, view generation, and stop
   rules. A model-facing regime bit or family-specific error is a failure.
10. **No solver-derived data.** Gauge choices, inverses, factor completions,
    validation match labels, target compounds, exact paths, and counterfactuals
    never enter candidates, negatives, access views, indexes, or optimizer
    state in SELF.
11. **Branch and life reset.** Context, KV cache, RNG, reader/index, adapter,
    optimizer, filesystem namespace, error state, and workspace are fresh and
    indistinguishable across branches and lives.
12. **Failure-inclusive assignment.** Every presealed world-life/twin orbit,
    target, proposal, model call, and training assignment appears exactly once
    as success, zero-valued failure, or preregistered environment-wide
    `NOT_RUN`; nothing is dropped after seeing quality.
13. **D4 orbit correction.** A claimed `1/16` target-only D4 value requires all
    16 equally likely, target-byte-identical stage-swap worlds with distinct
    correct sequences. A single global twin supports only a `1/2` ceiling.
14. **Independent-table specificity.** SELF must not manufacture supported
    global structure or above-chance never-executed action value in the
    matched independent regime. GATE must use the same public-evidence rule.
15. **Evaluation sterility.** Post-target and delayed-`B` events cannot change
    any future primary state. Pre/post corpus, adapter, reader, and cache hashes
    must match.

## 5. Exact measurements

All primary summaries are failure-inclusive at the independent
world-life/twin-orbit level. Targets, calls, samples, stages, and training seeds
are nested diagnostics, not independent replicates.

### 5.1 Dream-1 proposal measurements

For each life report:

- attempted, parsed, unique, duplicate, malformed, and abstained candidates;
- tokens, calls, latency, and proposal budget utilization;
- exact prospective `A` prediction accuracy, with missing predictions wrong;
- fraction of lives with any `A`-consistent candidate;
- fraction with any hidden-truth-correct or target-usable program, scored only
  offline;
- candidate precision, candidate-pool recall, confidence calibration, and
  semantic/program diversity; and
- the same quantities in factorized and independent-table regimes.

The distinction between `any correct candidate exists` and `the model selected
it` is the proposal-versus-selection decomposition.

### 5.2 Dream-2 self-revision measurements

Report terminal `RETAIN/REVISE/ABSTAIN/malformed` rates and:

- **false retention:** selected program disagrees with eligible public `A`;
- **false abstention:** a uniquely `A`-consistent candidate existed but the
  model selected nothing;
- **selection loss:** a correct candidate was in the pool but the selected
  final program was wrong or absent;
- **repair:** no correct Dream-1 program existed but a correct revised program
  was emitted and selected;
- **preservation:** a correct Dream-1 program remained correct after Dream-2;
- **corruption:** a correct Dream-1 program became a wrong revision or
  abstention;
- exact prospective `B` accuracy of the final selected program;
- hidden-truth law/factor correctness and target-operator coverage, offline;
- evidence-citation validity and raw-`A` use; and
- decision sensitivity under a public-outcome twin with Dream-1 held fixed.

Measure conditional precision among non-abstaining writes and unconditional
world-life coverage. Never report purity without the abstention/coverage cost.

### 5.3 Selection-arm decomposition

On the same candidate trace and target set report paired differences:

```text
selection_regret = Y(PERFECT_PUBLIC_GATE) - Y(SELF_REVISION)
selection_value  = Y(SELF_REVISION) - Y(NO_GATE_ALL)
revision_value   = Y(SELF_REVISION) - Y(NO_REVISION)
proposal_gap     = Y(ORACLE_SCHEMA_TEXT) - Y(PERFECT_PUBLIC_GATE)
```

These are diagnostic decompositions, not automatically causal if the arm
changes corpus size or ambiguity. Report the footprint-matched no-gate result,
candidate ambiguity rate, bytes, and actual read/think work beside them.

The primary specificity contrast is:

```text
[Y(SELF,F) - Y(NO_GATE,F)] - [Y(SELF,I) - Y(NO_GATE,I)]
```

alongside absolute independent-table chance and false-structure rates. A
positive factorized gain plus an independent null is more informative than
high factorized accuracy alone.

### 5.4 Sleeper measurements

Report:

- selected semantic AST bytes and count;
- canonical text bytes;
- number and bytes of each LoRA training view;
- exact semantic round-trip and provenance coverage;
- deduplication ratio without truth-conditioned deletion;
- compiler rejection/failure reasons;
- number of semantic atoms introduced by the sleeper, required to be zero;
- cross-branch corpus hashes; and
- every external index, candidate set, parser table, and retained cache byte.

### 5.5 Memory/Think/action measurements

For text and LoRA report atomic, reverse, paraphrase, partial-cue, conflict,
and `NOT_FOUND` read fidelity; candidate-only and unaided-reader results;
query usefulness; working-path validity; first-action goal-twin redirection;
D1/D4 realized trajectory and `LOCK` value; and authentic/twin, wrong-order,
decisive-factor, lagged-snapshot, and sham-cut effects.

Across checkpoints, retain the adjudicated new acquisition, earliest-factor
retention, cross-era composition, exact factor entropy, native-context, and
full resource measurements. The corrected twin-orbit Bayes values are:

```text
D1 action             = 1/2
D4 full trajectory    = 1/16 only under the 2^4 free orbit
D4 first action       = 1/2
```

## 6. Prompt amortization: what remains supplied

The repaired protocol removes external truth selection, but it is still a
strongly amortized reference organism. The following intelligence is supplied:

- the fixed connected action curriculum and sleep checkpoints;
- the visible two-part morphology;
- the choice of which absent `A` pairs should be predicted;
- deterministic extraction of complete witnessed permutations;
- the generic cognitive verbs compare, hypothesize, predict, revise, and
  abstain;
- the memory DSL, bounded candidate count, one-revision schedule, and terminal
  decision grammar;
- target-independent syntactic/taint/provenance enforcement;
- deterministic multi-view rendering and LoRA exposure recipe;
- the typed Think loop, memory query grammar, action grammar, and stop budget;
- any recognition candidate universe and external index; and
- the synthetic world prior that one compact predictive program may exist.

This is acceptable for Paper 1 only if the claim says **a frozen prompted
controller under this registered scaffold**, not a learned or spontaneously
emergent dreamer. Three prompt rungs should make the dependence visible:

1. neutral compression/reflection prompt;
2. primary generic process prompt; and
3. class-informed PCFL equations/hypothesis-family ceiling.

The primary prompt may name the operations but must not name the answer class.
If only rung 3 succeeds, the result is known-family fitting. If rung 2 succeeds
but rung 1 fails, the result is process-scaffolded prospective abstraction,
which is still meaningful but narrower.

## 7. Remaining leakage and confounds

Even after removing the comparator from the loop, five risks remain.

1. **Curriculum leakage.** A connected tree followed by designated absent
   chord questions strongly suggests factor completion. The protocol tests
   solving a supplied scientific question, not autonomous choice of what to
   investigate.
2. **DSL leakage.** A factor-specific AST would hand the model the latent
   ontology. The primary DSL must be family-neutral; a factor-specific grammar
   is a ceiling.
3. **Representation leakage.** Computing gauge-fixed factors, inverse edges,
   closure, or reciprocal statements in the sleeper moves reasoning out of
   Dream. Only literal model-authored semantics may be rendered.
4. **Reader leakage.** Completed compounds, target-assembled paths, a hidden
   linear candidate scan, or a target-aware index moves cognition out of
   memory/Think. Return local records or `NOT_FOUND` and count all external
   state/work.
5. **Evaluator feedback leakage.** Even an offline scorer leaks if its labels,
   filenames, exceptions, timing, caches, or adaptive retries affect later
   states. Comparator-mutation invariance and sterile forks are mandatory.

There is also a scientific confound rather than leakage: exact public `A`
outcomes may make equality checking easy while generating the factor law
remains hard. That is precisely why candidate-pool recall, self-selection, and
action use must be measured separately.

## 8. Does this test the intended thesis?

### What it cleanly tests

If the ownership/firewall tests pass, this protocol cleanly tests whether:

1. a frozen generic resolver can form a prospective predictive connection from
   public action experience;
2. the same resolver can use later raw experience to select or revise its own
   durable belief without a truth-labeling module;
3. a restricted sleep compiler can preserve that self-selected content in an
   inspectable text representation and then in a matched per-life LoRA;
4. a bounded goal-conditioned thinker can reconstruct the relevant local
   content and execute never-observed compound actions; and
5. self-selection, perfect public filtering, proposal noise, representation,
   substrate, reader, and action failures can be causally separated.

That is a credible one-cycle Think/Dream/Sleep/LoRA organism assay and is
closer to Rohin's thesis than the comparator-gated architecture.

### What it does not test

It does not establish:

- a learned dream, think, write, replay, or sleep policy;
- unprompted research-question or hypothesis-class discovery;
- wake traversal causing later graph growth or shortcut materialization;
- recurrent multi-sleep accumulation beyond the registered checkpoints;
- memory-directed exploration or better actions producing better future data;
- learned value/critic signals, sleep pressure, or a LOOP adapter;
- semantic/asymptotic compression of independent information;
- naturalistic, human-like, open-ended, or unbounded continual learning; or
- generic superiority over unnamed agent-memory systems.

The exact paper sentence should therefore be no broader than:

> In a controlled fixed-source PCFL-Compose life, a frozen generic resolver
> prospectively proposed and self-revised a per-life predictive action model
> from raw public outcomes; a representation-only sleeper transported exactly
> the selected content through text and, conditionally, LoRA; and a bounded
> goal-conditioned resolver used it for never-executed compound actions after
> context overflow.

Every clause remains conditional on its corresponding result. If the
perfect-public gate succeeds but SELF fails, the result is a quantified
self-verification/selection gap. If SELF text succeeds and LoRA fails, the
prospective abstraction result survives but the parametric organ does not. If
raw RAG or native A-MEM matches SELF at legitimate resources, the architecture
has no demonstrated sleep-compilation advantage. If the independent-table arm
also gains, the assay is invalid rather than merely negative.

## 9. Recommended disposition

Adopt this model-owned revision protocol in the next hash-bound PCFL-Compose
architecture proposal, but only after it is independently interpreted and
critiqued under `AGENTS.md`. Replace every headline phrase equivalent to
"mechanical comparator attaches support and sleeper admits supported claims"
with the literal Dream-2 decision path above. Keep the mechanical public gate
as a labeled ceiling and the exact comparator as a sterile offline scorer.

The selected protocol is materially different from the current
`20260902_pcfl_paper_adjudication.md` chronology because it changes who owns
memory admission. It therefore requires a new exact deliberation and human
ratification; it cannot be treated as a non-material repair.
