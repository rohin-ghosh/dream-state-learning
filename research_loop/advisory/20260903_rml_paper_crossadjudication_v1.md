# RML paper cross-adjudication v1

**Date:** 2026-09-03  
**Role:** fresh senior area-chair adjudication  
**Status:** scientific design advisory only. This document does not ratify
architecture bytes, authorize implementation, authorize a model call, or
authorize GPU use. Every material next step remains subject to `AGENTS.md`,
including exact human ratification, independent review, and a separate GPU
gate.

## Executive verdict

The project is worth pursuing, but only as a staged causal memory paper, not as
an all-at-once claim about learned experiential intelligence or open-ended
self-improvement.

The selected paper-bearing generator is the **Randomized Typed Causal Workshop
(RTCW)**. `rml_d0` remains an immutable deterministic regression fixture and
supplied-gold controller assay. It contributes no independent paper sample.

The lean Paper-1 spine is:

```text
executed public action/outcome history
  -> target-blind prospective proposals
  -> later public support/contradiction
  -> deterministic connected semantic compilation
  -> recurrent goal-conditioned traversal
  -> better held-out action after native context
  -> optional same-corpus LoRA transport
```

This is already a credible paper object if it passes an adequately powered
three-pack confirmation with strong native external-memory baselines and
binding interventions. The final link,

```text
better action/memory -> better evidence acquisition -> better later memory
                    -> better later action
```

is a separate randomized one-cycle trial. It strengthens Paper 1 if powered
and passed, but it must not be inferred from the common deck. Repeated adaptive
development, a learned LOOP/controller adapter, rank cascades, cross-life
policy learning, and open-ended improvement remain roadmap work.

The prior proposal's `24` independent confirmation pairs and `.02` plateau
criterion are rejected. The common-deck confirmation starts at **48 independent
counterfactual pair roots, 16 per pack**, with a preregistered nuisance-only
increase to 72 or 96 if needed. Saturation is omitted from the core paper; it
requires its own equivalence extension.

## 1. Selected generator construct

### 1.1 RTCW is the right compromise

RTCW should be a finite discrete workshop, not a reskinned lookup table. Each
independent pair root samples causal topology, shallow local programs, schema
law, scoped exception, source opportunities, target skeletons, public skin,
handles, and assignment tapes from domain-separated randomness. H and twin
share all pre-action target-visible bytes and nuisance allocation, while a
registered involution changes at least two decisive bindings and the first
irreversible J/P choice.

The common action API and finite state should support transformers, routers or
guards, terminal regulators, consumed resources, public qualitative state,
and irreversible evaluation choices. J must be one state-bearing old-to-new
path, not two subtasks placed side by side. P must contain exactly one decisive
locally unwitnessed edge predicted by a target-independent schema committed
before its confirming public outcomes.

This construct preserves exact replay, exact adaptive no-life bounds, exact
necessity cuts, prospective support, byte-identical twins, and later on-policy
collection. The algebraic generator remains useful as a mutation family and
explicit program baseline. The continuous simulator is deferred until the
causal instrument has worked.

### 1.2 Minimal build and full build

`RTCW-MR1`, opened only after D0/G1 passes, contains:

- one fluid/thermal pack;
- two independent DEV pair roots;
- modular causal cohorts reaching one measured `2 L_native` cut;
- two J and two P targets per side;
- common-deck public action/outcome history;
- gold, witnessed-atom, graph, and generator-aware program references;
- proposal/admission chronology and learned-text inputs;
- whole twin, binding-shuffle, cited-equivalence cut, and sham-cut support;
- applicable independent CPU certificates and a non-author gold-note usability
  check;
- an on-policy opportunity manifest only, with no powered collection claim;
- no LoRA, scaling curve, or confirmation claim.

Before locked calibration, expand the same API to three genuinely
non-isomorphic packs, add N/O/X targets, and reach the `0.5x, 2x, 4x, 8x`
cohort schedule. Pack validity is about transition mechanics, not nouns.

The generator's primary validity thresholds remain legal-history value
`>= .85`, adaptive no-life/target-only/shortcut values `<= .35`, exact twin
bytes with different plans, J deletion necessity, P atoms-only `<= .35`, no
direct closure, no target-side reacquisition, and run/skip/cross-life
isolation. These are deterministic panel-validity gates, not statistical
outcomes.

The proposed depth-three grammar, `>=128` compatible complete programs, and
`>=20` pre-source bits are sensible starting constants. They must be tested for
CPU tractability and frozen before roots are opened; they should not be tuned
against model behavior. A smaller exact posterior is not automatically fatal
if adaptive no-life remains low and legal-history value remains high, but a
collapse to a tiny source-complete lookup is fatal to the intended construct.

## 2. G2 DEV minimum and decision rule

Two pair roots are the correct lean minimum because G2 is a severe
construct/branch falsifier, not inference. One root cannot reveal root-specific
template dependence. Four roots would reduce the chance of killing a noisy but
real mechanism, but that belongs in the subsequent locked calibration rather
than in the smallest generator build.

At the single honest `2 L_native` cut, each root supplies H/twin sides and two J
plus two P targets per side. Targets and sides are averaged inside the pair.
The minimum G2 panel is:

- `NONE` and honest `CONTEXT` floors;
- `WITNESS-TEXT`, `RAW-DREAM-TEXT`, `SELFCHECK-TEXT`, `PUBLIC-ADMIT-TEXT`, and
  full recurrent `E-TEXT`, using a cached shared proposal pool where applicable;
- matched `REFLECT`, native `RAW-RAG`, and native linked/A-MEM-like memory;
- exact witnessed `GRAPH` and generator-aware `PROGRAM`;
- target-independent `GOLD-TEXT`;
- cited cut, matched sham cut, binding shuffle, and whole-twin substitution.

G2 licenses a one-seed G3 transport micro only if all of the following hold:

1. recurrent gold succeeds at `>=.85`, valid cited paths are `>=.80`, and
   no-memory/open/P-atoms controls remain `<=.35`;
2. E-TEXT recovers at least 70% of the GOLD-TEXT gain over NONE on the
   pair-level aggregate;
3. public-outcome admission improves the prospective precision/coverage/action
   frontier over witnessed-only, raw proposals, and blind self-check;
4. E-TEXT is no worse than the strongest fair native external-memory arm on
   the two-pair aggregate, and neither pair has an E-TEXT deficit worse than
   `.10`;
5. E-TEXT directionally exceeds RAW-RAG and REFLECT on both pair roots; and
6. complete cuts or twin/binding substitutions remove or redirect at least 80%
   of credited successes, while sham cuts do not.

These thresholds are engineering decisions and receive no confidence interval
or population wording. `PROGRAM` is reported but is not part of item 4. If it
wins, the learned-memory moat narrows; the generator survives. X is omitted
from MR1 because it adds exception and on-policy complexity without being
needed to decide whether prospective connected text works. X becomes mandatory
before calibration and confirmation.

## 3. Confirmation unit and sample plan

### 3.1 Hierarchy

The independent scientific unit is one counterfactual causal-program pair
root. Within a pair, first average the registered target values across H/twin,
then across targets with frozen weights; average technical seeds before the
pair enters inference. Lifetime cuts are repeated measures, packs are three
fixed construct strata, and skins are renderer audits.

Each confirmation pair has at least two presealed targets per N/O/J/P/X
stratum, per side, per scored cut. R is diagnostic. `0.5 L_native` is a
descriptive pre-native anchor; `2x`, `4x`, and `8x` are the confirmatory
post-native cuts. More targets improve measurement precision but never `n`.

Use three adapter seeds in locked calibration. Confirmation may use two seeds
only if calibration excludes a multimodal failure mode and the upper confidence
bound on seed-induced SD is below `.05`; otherwise use three. Seeds are still
nested.

### 3.2 Sample size

Run six fresh locked-calibration pair roots, two per pack, after the complete
protocol is frozen. They validate execution and seed stability and provide
rough nuisance information, but do not enter confirmation or justify a final
effect.

The common-deck confirmation then follows this registered design:

- minimum `n=48` fresh pair roots, 16 per pack;
- smallest important A1 post-native AUC gain `.10`;
- one-sided familywise level `.025` and target power at least 90%;
- a nuisance-only internal sample-size check after the first 24 roots, with
  method labels and effect direction masked;
- a pre-coded simulation choosing only `n=48`, `72`, or `96`, preserving equal
  pack allocation and changing no arm, endpoint, margin, exclusion, or
  threshold;
- hard maximum `n=96`; if the frozen simulation says 96 cannot provide 90%
  power, stop or narrow the estimand rather than promote nested samples.

As a planning check, 48 pairs is plausible when the pair-level A1 SD is about
`.20` or lower for a `.10` effect. The actual increase rule must use the frozen
bounded-outcome hierarchy, not this normal approximation.

Primary analysis uses one reduced observation per pair x arm x cut, pack fixed
effects, within-pair cut covariance, unconditional failures, and studentized
paired confidence intervals. A sign-flip test is sensitivity analysis unless
symmetry is justified. G5 alone supports exact blocked randomization inference.

## 4. Arms: claim-bearing, native contextual, and diagnostic

The arm set is deliberately separated by purpose.

### 4.1 Claim-bearing confirmatory arms

| Arm/contrast | Interface | Role |
|---|---|---|
| `E-TEXT` | Its frozen recurrent native reader | Proposed connected experiential memory |
| `NATIVE-LINKED` | Validated A-MEM-like linked-note construction and native query-conditioned traversal | Frozen primary A1 external-memory comparator |
| `E-LORA-R` | Common one-row recognition channel shared with E-TEXT | Primary same-corpus transport arm |
| `TMEM-QA-LORA` | Matched LoRA/update/read budget | Primary T2 parametric alternative |

The A1 headline is E-TEXT minus NATIVE-LINKED on equal-weight N/O/J/P/X
post-native AUC. NATIVE-LINKED is chosen now, not after observing confirmation.
The decision rule is a one-sided 97.5% lower confidence bound above zero and a
point estimate at least `.10`.

T1 is E-LORA-R minus identical-corpus E-TEXT through the common channel, with a
`.05` noninferiority margin. T2 is E-LORA-R minus TMEM-QA-LORA superiority,
with a one-sided multiplicity allocation frozen with A1/T1. The LoRA claim is
not that weights beat text.

### 4.2 Mandatory native contextual panel

Run `NONE`, honest truncated `CONTEXT`, strong iterative `RAW-RAG`, matched
hierarchical `REFLECT`, exact witnessed `GRAPH`, generator-aware `PROGRAM`, and
an explicit `VOYAGER-SKILL`-like procedural library through their uncrippled
native interfaces under common action, resolver-operation, and reader-token
caps. These make the result interpretable and address long-context, episodic,
reflection, structural, program-induction, and procedural-imitation accounts.

Their contrasts are prespecified secondary simultaneous intervals, not an
all-baseline conjunctive headline. `PROGRAM` is labeled a generator-aware
adversarial reference/ceiling if its structural knowledge or compute makes it
resource-incomparable. It is never weakened to make E-TEXT win.

### 4.3 Diagnostic and mechanism arms

`WITNESS-TEXT`, raw proposals, self-check, PUBLIC-ADMIT, GOLD, `R`, the common
one-row factorial, candidate-only clean base, `RAW-LORA`, `E-LORA-G`,
wrong-life reads/adapters, source/binding shuffles, cited/sham cuts, and
target/renderer/identifier probes are diagnostics or validity controls.

`PEAM-PROC` and `BATCH-SFT` are useful additional diagnostics, but they are not
mandatory headline arms in the lean confirmation once a strong procedural
library and TMEM-QA-LORA are present. If the manuscript later claims
superiority to per-life procedural fine-tuning or ordinary trajectory SFT,
they must be run on the full confirmation panel; otherwise do not make those
claims. This avoids a large weak-reproduction grid masquerading as rigor.

Native system comparisons and the common-reader mechanism factorial must not
be mixed. Recognition candidate construction, graph traversal, index scans,
clean-base composition, writer calls, adapter fits, and all persistent/read
resources are charged to the systems that use them.

## 5. Exact claim ladder

The manuscript should use the following ladder and stop at the highest passed
rung.

### V0 — instrument validity

RTCW roots pass independent generation/oracle replay, no-life and shortcut
bounds, target solvability, twin bytes/opposite binding, J necessity, P
chronology/atoms ceiling, direct-closure, usability, and isolation. This permits
model experiments, not a memory claim.

### V1 — recurrent use of supplied knowledge

On D0/G1 and then RTCW gold, a frozen resolver can traverse supplied local
knowledge to execute J/P actions, and cuts/twins redirect it. This is a
controller/construct gate, not learning evidence.

### W1 — learned connected content on DEV

Target-blind proposals plus later public-outcome admission yield connected text
that improves the two-root J/P DEV action frontier over witnessed atoms, raw
proposals, self-check, RAG, and reflection. This is a DEV mechanism result only.

### A1/B1 — confirmatory experiential memory/action effect

Across fresh pair roots, E-TEXT improves post-native action over the frozen
native linked-memory comparator, and authentic binding matters: whole-twin and
binding substitutions redirect action while sham cuts do not. This permits:

> In the prespecified RTCW population, a frozen language-model controller
> converted its executed public action--outcome history into target-blind,
> prospectively outcome-admitted connected semantic memory whose recurrent use
> improved held-out post-native multi-step action.

Do not call this learned agency, a flywheel, or general experiential
intelligence.

### T1/T2 — same-corpus parametric transport

E-LORA-R is noninferior to identical-corpus text at margin `.05`, exceeds the
matched direct-QA LoRA alternative, passes fixed-query fidelity and
whole-adapter binding/twin swaps, and uses no hidden whole-life scan. This adds:

> The identical admitted semantics retained action value when transported into
> isolated per-life LoRA weights through a recognition-assisted read channel.

It does not establish retrieval-free memory, LoRA reasoning, compression, or
superiority to text.

### D1 — finite post-native acquisition, retention, and composition

E-TEXT has a practically positive `8x-2x` change, a positive lower bound for
`8x-4x`, no adjacent drop worse than the frozen tolerance, positive new/old/J/P
guardrails at `8x`, and growth in unique supported causal information. Reader
and memory work are disclosed. This adds:

> Across the tested `2x-8x` native-context range, the system continued to
> acquire new structure, retain old structure, and combine old and new
> structure for action.

This is finite development over a tested range, not open-ended continual
learning and not baseline saturation.

### C1 — optional compaction claim

The thesis's “compressed memory” wording needs a separate rate--distortion
test. Count semantic rows, snapshot/index bytes, writer/train cost, and reader
work against the raw public ledger and exact causal-statistic reference. Claim
only **task-sufficient compaction** if retained representation growth is
prospectively smaller than raw-ledger growth while A1 action stays within a
frozen noninferiority margin and coverage/false-memory guardrails pass. A
smaller file, duplicated training views, or hidden linear scan does not pass.

Until C1 is registered and passed, use “consolidated” or “compiled,” not
“compressed,” in the Paper-1 claim. The full thesis is preserved as the design
target without overstating its present evidence.

### F1/F2/F3 — optional one-cycle on-policy loop

A separate randomized trial shows that authentic rather than null,
binding-shuffled, or twin memory changes information-seeking behavior,
increases information gain, improves the one subsequent supported snapshot,
and improves a presealed later action. This adds:

> In a separate blocked randomized experiment, authentic lifetime memory
> caused better evidence acquisition, subsequent supported memory, and later
> sealed action over one reconsolidation cycle.

It is evidence for one positive feedback cycle, not natural mediation,
repeated self-improvement, or a learned exploration policy.

### S1/S2 — optional resource-qualified crossover

Only a separate equivalence extension can add that one specifically named
baseline flattened under a named capacity/read/compute envelope while E-TEXT
continued improving. No broader word “saturation” is permitted.

## 6. Saturation strategy

The core paper should **not target or claim saturation**. The `.02` band is far
too narrow for 24 or 48 heterogeneous pair roots, and failure to reject a
slope is not equivalence. Report the complete response surface, last-interval
effect, oracle headroom, and resource frontier.

If a crossover sentence is considered essential after A1/D1 passes, open a
separate preregistered extension with these properties:

- name only the primary NATIVE-LINKED baseline and its exact fixed capacity,
  read, writer, and compute envelope;
- justify `delta=.05` before extension outcomes are opened;
- require simultaneous two-sided equivalence for its `2x->4x` and `4x->8x`
  changes on every outcome named in the sentence, plus oracle headroom
  `>=.10` and continued unique-causal-information growth;
- require E-TEXT's `4x->8x` lower bound and the E-TEXT-minus-baseline
  last-interval difference-in-differences lower bound to exceed zero;
- begin only if a blinded audit supports at least 90% power at 96 total pairs
  (32/pack), and allow a nuisance-only increase to 144 or 192;
- if the maximum cannot achieve equivalence precision, omit the claim.

If `.02` remains non-negotiable, plan roughly 192--256 or more pairs depending
on blinded interval-change variance. That is not part of the lean Paper 1.

## 7. On-policy trial scope

The first powered on-policy trial uses **new pair roots** and exactly one frozen
`8 L_native` boundary. It does not reuse common-deck confirmation roots for its
causal estimate and does not repeat the factorial at 2x and 4x. A one-pair 2x
relay after G2 may validate branch cloning and treatment-induced action
variation, but supplies no effect estimate.

For each world side at 8x:

1. preseal the opportunity roster, collection budget, clone state, and later
   target deck;
2. create isolated branches and randomize `AUTH`, `NULL`, `BIND`, and `TWIN`
   memory labels within the world-side block;
3. let the same frozen collector choose real, costly public information
   actions under the same objective and cap;
4. append only chosen public actions/outcomes;
5. run exactly one frozen DREAM/SLEEP cycle;
6. evaluate the presealed target in a fresh process;
7. retain every assigned branch in intention-to-treat analysis.

Start with `n=72` independent pair roots, 24 per pack, and allow a
preregistered nuisance-only increase to `n=96`. Do not start the powered trial
unless blinded planning supports adequate power for both target-relevant
information gain per action and later action. If 96 is inadequate, defer the
flywheel clause.

The primary conjunction is AUTH superiority to **each** of NULL, BIND, and
TWIN, not a pooled corrupt-memory control, on information gain and later
action with simultaneous one-sided bounds above zero. Also require an omnibus
randomization effect on information-action choice, positive pairwise effects
on a predeclared target-relevant information-action rate, and positive
supported-memory quality effects against each control without conditioning on
compilation success. Require no pack-level harm worse than the frozen
tolerance. Cluster uncertainty at the parent pair root and permute labels only
within sealed world-side blocks.

Post-treatment evidence, memory, and resource state are outcomes, not
mediators to condition on. Collector-by-compiler replay and a post-sleep
snapshot swap are useful controlled component experiments, but natural
mediation is not identified.

## 8. Compute escalation and stop path

No stage below authorizes GPU use. Exact call counts, checkpoint revision,
token envelope, rank, wall-time ceiling, and GPU-hour cap require later bound
approval.

1. **D0/G1:** retain D0 as regression and finish the supplied-gold recurrent
   fast falsifier. Typed gold failure stops the construct; generic recurrence
   failure after typed success permits controller repair only.
2. **RTCW-MR1 CPU:** only after G1, ratify and implement two fluid/thermal DEV
   roots; run independent applicable certificates and the human gold-note
   usability check. No LoRA and no powered collection.
3. **G2 text DEV:** cache each proposal/reflection pool once per life, run cheap
   deterministic and native text baselines first, then learned text and
   interventions. A failed G2 cancels all weight work.
4. **G3 transport micro:** at the one 2x cut, fit one seed of E-LORA-R,
   TMEM-QA-LORA, and RAW-LORA from frozen snapshots. Fidelity, text
   noninferiority, and whole-adapter binding failure stop the weights branch.
5. **Three-pack locked calibration:** add N/O/X and 4x/8x only after G2/G3 are
   real. Use six fresh pairs and three seeds to validate the frozen pipeline,
   estimate nuisance/seed behavior, and finalize the preregistered sample-size
   simulation. Calibration never enters confirmation.
6. **Common-deck confirmation:** generate 48 fresh roots first. Run validity,
   deterministic references, text/native arms, and headroom before expensive
   adapters. Fit adapters only for sealed eligible snapshots; expand to 72/96
   only through the frozen nuisance rule.
7. **Optional extensions:** run the saturation equivalence extension or the
   separate G5 randomized trial only after the fixed-deck claim passes and only
   if their distinct claims justify their cost.

At every stage, infrastructure failures may be rerun only under a predeclared
receipt rule. Model, writer, fit, parse, and action failures remain in the
denominator. Batch independent calls across roots, never operations within a
trajectory. Reuse sealed worlds, proposal pools, semantic snapshots, and
adapters across eligible target evaluations without allowing target feedback.

## 9. Paper-worthiness

**Conditional answer: yes.** If A1/B1 passes on at least 48 independent pair
roots across three non-isomorphic packs; the native linked, RAG, reflection,
graph, program, procedural, context, and no-memory comparisons are credible;
the causal swaps/cuts redirect behavior; and D1 shows real last-interval
post-native development, the work is plausibly a main-conference paper even
without saturation or G5. The core contribution would be unusually clean
causal evidence that prospectively admitted experiential semantic memory
changes later action, not the novelty of dream/sleep vocabulary.

T1/T2 passing makes the paper materially stronger by supporting a controlled
parametric-transport clause. The separate G5 trial passing would turn the full
action-to-better-experience loop into evidence rather than roadmap. Neither is
allowed to rescue a failed A1/B1 result.

The main risks remain external validity and method novelty. Three designer-
specified synthetic packs bound the claim to the RTCW distribution. A small
clean external action slice would improve the submission but is not allowed to
replace RTCW's causal confirmation. If PROGRAM or native graph/link memory
matches or wins, the benchmark and negative phase diagram may still be useful,
but the proposed-method paper becomes borderline and must be framed as an
instrument/comparative finding. G1--G3 alone is workshop or appendix evidence,
not the paper.

## Single recommended path

Finish D0/G1; if and only if it passes, build RTCW-MR1 with two DEV pair roots;
run the J/P learned-text gate; run a one-cut one-seed same-corpus transport
micro; expand to three packs and N/O/J/P/X for six-pair locked calibration;
freeze one primary E-TEXT-versus-NATIVE-LINKED estimand and the bounded sample
rule; confirm on 48--96 new pair roots; publish the causal consolidation,
binding, finite-development, and conditional LoRA-transport result. Add the
one-cycle randomized G5 clause only through a separate 72--96-pair trial. Omit
saturation unless a separate equivalence extension is actually powered and
passes.

This path preserves the complete project thesis while assigning each link to
the evidence capable of supporting it:

```text
Paper 1 core: action -> public experience -> connected consolidation
              -> traversal -> better held-out action

conditional Paper 1: same semantics -> per-life weight transport

separate causal extension: better memory/action -> better evidence
                           -> better memory -> better later action

roadmap: learned shared agency, repeated open-ended loops, rank cascades,
         cross-life controller improvement, natural-world generality
```
