# Paper-1 benchmark architecture: RML

**Status:** read-only design advisory; no implementation or scientific-claim authority.

## Decision

Replace the headline benchmark with **Rendered Maintenance Lifetimes (RML)**: a persistent action-first world with connected causal modules over a life, late targets requiring old-to-new dependencies, and a randomized memory-assignment collection block followed by reconsolidation and a sealed later action.

This is the smallest feasible test of the actual claim:

> A frozen agent's target-blind Dream--LoRA--Think memory learned from public action--outcome history improves later action, continues to acquire/retain/combine causal knowledge across post-context lifetimes, and eventually improves evidence acquisition where named strong baselines have empirically plateaued.

A common scripted life can establish only experience-conditioned representation and use. The self-improvement/flywheel clause requires randomizing memory before new information-gathering actions. This distinction is explicit in research_notes/42_system_thesis_and_experiment_map.md (First-principles objective) and research_notes/46_pcfl_constructive_assay_v1.md (§§2,14–15).

## RML environment and experience

Each life is a persistent maintenance habitat. Meaningful words aid parsing but every decisive role binding is sampled after pretraining. Use three non-isomorphic packs, not skins:

1. Fluid/thermal.
2. Power/control.
3. Material/biological.

The generic stateful API is OBSERVE, MEASURE, MOVE, ACQUIRE, CONFIGURE, APPLY, RUN, COMMIT and STOP. Each operation costs time/material and returns only its ordinary public effect; failures may be recoverable, consumptive or terminal. The environment exposes no rule, proof, candidate plan, family identity or evaluator label. Targets score executed action return, not an answer string. Source: research_loop/plans/rendered_lifetime_candidate_B_adversarial.md (§§3.1–3.2).

Each era adds connected causal structure: fresh transformations, compatibilities/routes and scoped exceptions, with at least one new relation whose applicability depends on an earlier-era output. No independent tables/namespaces. Each pack contains two latent higher-order laws. DREAM may commit a law only before a later ordinary action outcome can support or contradict its prediction. A sparse target has one locally unwitnessed edge predictable from a valid prospective law; an explicit program-induction baseline is allowed to solve it.

The treatment holds controller phi frozen and resets MEMORY LoRA psi per life:

    public action/outcome events
      -> target-blind DREAM proposes one atom or scoped schema with roots,
         prediction, and deadline
      -> later public outcomes append support or contradiction
      -> deterministic SLEEP canonicalizes supported content and rebuilds psi
      -> bounded recurrent THINK reads cited local memory, backtracks, acts

No hidden solver, target deck, support receipt, acceptance condition or evaluation outcome is model-visible. Provisional/contradicted claims remain auditable but are excluded from positive LoRA training; no record may contain a complete plan or goal-specific fact. This imports PCFL's chronological support boundary without losing stateful actions. Source: research_notes/47_pcfl_execution_bundle_v1.md (§§5–9).

## Lifetime, targets, and splits

Mechanically compute L_native for exact model, tokenizer, chat template, system prompt, current goal/state, workspace, operation history, reader return and output reserve. Do not replace it with a convenient cap. Use nested prefixes:

    0.5 L_native, 2 L_native, 4 L_native, 8 L_native.

Every post-native interval must add public causal roots, identifiable relations, an old-new interaction and a prospective prediction. Report all four and shortest certified causal dependency. Token growth alone is not development. Source: research_loop/plans/rendered_lifetime_candidate_B_adversarial.md (§3.3).

Preseal fresh-handle targets before model calls:

| Stratum | Requirement | Status |
|---|---|---|
| R | one witnessed effect | installation diagnostic only |
| N | relation introduced since previous cut | new acquisition |
| O | early relation, last direct support outside L_native | old retention |
| J | 6–12 action plan where early relation is necessary for recent mechanism | connected old-new action |
| P | decisive unwitnessed edge from precommitted, later-supported law | prospective transfer |
| X | discriminate exception, backtrack, improve on sealed analogue | revision |

For J, early-bridge deletion must make every legal plan fail/exceed budget; early-only and recent-only information are insufficient. For P, a complete witnessed-edge graph without the law remains below headroom. Seal the X analogue before observing the exception.

Hold out complete causal-program productions, not seeds/skins. Development: at most four twin pairs per pack. Locked calibration: six new pairs, descriptive only. Confirmation: at least eight new pairs per pack, hence 24 paired world-lives. Targets, cuts, twin sides, samples and adapter seeds are nested observations; world-life/twin pair is the sole randomization and inference unit.

## Two experiments

### I. Common-experience attribution

A target-blind, nonexhaustive, outcome-blind-within-bundle source policy produces one immutable action/outcome stream. All arms receive byte-identical events. At each cut, build read-only memory; targets run in a clean process with cleared prompt/KV/reader/workspace/cache state. Target outcomes are sterile and run-versus-skip source hashes must agree.

This identifies representation/use only.

### II. Randomized on-policy flywheel

At each post-native cut clone identical public state and assign, before new observation: authentic, null, within-life binding-shuffled, or counterfactual-twin memory.

Each clone gets equal action/query/resolver/wall-clock budget and chooses observations, interventions, objectives and stopping. Its ordinary outcomes are reconsolidated once. A later J/P/X target deck is generated and sealed before collection. Cross every collected trace through compiled, raw-RAG, native-graph and direct-QA representations to separate better evidence acquisition from better representation.

The flywheel claim requires four prespecified links: authentic memory changes information-seeking action; information gain or target-relevant coverage per action rises; new supported memory improves; sealed later action improves. Analyze assignment intention-to-treat; mediation is descriptive absent separate intervention. Source: research_loop/plans/rendered_lifetime_candidate_B_adversarial.md (§4.2).

## Anti-shortcut gates

Before model/GPU work, all preselected targets must pass:

1. Legal-history/hidden-oracle action value at least .85 per primary stratum, replayable shortest plan, and J/P/X necessity certificate.
2. Exact accepted-measure Bayes no-life, target-only, state-only, ID/order-only, renderer-only, passive-signature, action-frequency and source-string predictors at most .35 per target.
3. Twin target pre-action bytes collide exactly while correct plans differ; authentic history identifies twin side.
4. No source state-goal, complete plan, terminal sequence, single record or reader return closes N/O/J/P/X. Gold atoms plus precommitted nonadaptive queries stay at most .35; gold atoms plus recurrent THINK reaches at least .85 with valid trace at least .80.
5. P schemas are target-independent and committed before confirmation; graph/atoms without schema fail P. Later schemas are leaked ceilings.
6. Field-level taint closure covers candidates, indexes, retries/errors, filenames, caches, timing, provider state and support/provenance. Injecting answer into each allowed projection must trigger a value-one audit.
7. Causal-use audit removes the minimal cited early/recent/schema cut and every redundant path; matched twin replacement shifts decisive action. Whole-memory authentic/twin assignment is primary LoRA causality evidence.

Sources: research_loop/plans/rendered_lifetime_candidate_B_adversarial.md (§§3.4–3.5,7–8); research_loop/advisory/20260902_pcfl_stream_area_chair_review.md (Fatal claim risks).

## Metrics and statistical plan

Let V[w,m,l,s] be normalized executed action value for pair w, arm m, cut l and stratum s. Illegal/malformed/defer/timeout/scientific failure scores zero at action cap. Primary outcome is equal-weight mean of N/O/J/P/X; report strata independently.

Secondary measures: first-attempt success, return, restricted mean actions-to-success, regret, information gain/action, target-relevant coverage, prospective calibration, false-memory use, old/new precision-recall, certified depth, correction half-life, reader fidelity, candidate/query work, active/retained bytes, FLOPs, latency, energy and GPU-hours.

Use paired sign-flip/randomization inference and paired world-cluster bootstrap. Average two adapter seeds within pair before inference. Prespecify max-T/Holm hierarchy: validity, fixed-deck primary baseline, lifetime development, flywheel. Missing scientific cells are zero; pre-dispatch infrastructure failure can resume only the same sealed identity.

“Saturation” is not failure to reject improvement. For every named baseline at 2x/4x/8x, preregister simultaneous equivalence bounds for slope/new-J-P growth and old-retention change. Call it plateaued only when both bounds lie in the practical plateau band while treatment's simultaneous lower growth bound is positive. Otherwise report no detectable growth and the response surface. Source: research_notes/48_pcfl_stream_and_schema_design_v0.md (§§5–6).

## Smallest informative pilot

1. CPU: make one fluid/thermal RML pack pass exact target/twin/Bayes/leakage/J-P-X/run-skip gates. Existing rml_d0 is a CPU base, not learned-memory evidence.
2. Two DEV twin pairs at 2 L_native, one adapter seed: gold atoms/schema, nonadaptive/recurrent THINK, no memory, native context/truncation, native graph/program, raw RAG, learned compiled text, direct-QA LoRA, identical-corpus compiled LoRA. Candidate-only clean base, twin adapter and generative read only on sentinel pair.
3. One authentic-versus-null/twin assigned-memory collection block per side, one reconsolidation, one presealed later J/P target. It checks relay wiring, not an effect size.

Stop if V0/V1 fails, learned text does not beat raw RAG/graph in either pair, LoRA is more than .10 below text, or assignment changes no information action. A pass licenses only a frozen confirmation proposal.

This targets GPU-hours only at branch-changing decisions. Existing anchors are about 0.5 GPU-hour for a 32B compiler pass and 0.1–0.883 for a rank-64 7B adapter; the two-pair/four-checkpoint/two-LoRA DEV estimate is 14–44 GPU-hours. One-cut pilot is therefore roughly 4–12 GPU-hours after CPU gates, subject to first actual RML timings. Source: research_loop/advisory/20260902_pcfl_compute_feasibility.md (Runtime anchors; Development pair budget).

## Honest interpretations

- Graph/program wins: controlled lifetime benchmark plus negative phase diagram; no LoRA moat.
- Compiled text wins and LoRA loses: external-memory/compiler result only.
- LoRA matches text and beats direct QA: registered parametric transport, not retrieval-free recall, compression or learned dreaming.
- C1/C2 pass and C3 fails: selected-cut representation/use, not continued development or saturation.
- C3 passes and F1 fails: fixed-stream developmental memory, not action-experience flywheel.
- One pack reverses: pack-bounded result only; do not pool it into a general phase diagram.

The negative space is essential. Weakening graph/program access or renaming budget-induced flattening as saturation would remove the benchmark's scientific value.
