# v1e scientific-value decision and next gate

**Status:** read-only advisory; not authority, ratification, or evidence.

## Decision

Run v1e at most once as a staged integration kill gate, never as Paper-1
evidence. Do not spend LoRA compute unless the complete text-stage causal
conjunction passes. Do not enter another open-ended v03r hardening cycle after
the result: green advances to action/lifetime testing; red triggers a mechanism
decision.

## What v1e can establish

A green text stage would show only that this exact, strongly scaffolded,
one-pair system can:

1. turn public experience into model-supported typed relations;
2. use a target-absent THINK0 request to create useful post-prefix memory;
3. causally depend on that memory in a later registered decision; and
4. survive the specified path, twin, distractor, and sham interventions.

A green LoRA stage would add only immediate, candidate-constrained recognition
of selected training cues and the registered own/donor paths through two
isolated adapters. It would not establish open recall, preservation, capacity,
durability, generalization, action improvement, saturation, or superiority.

## GPU decision

The only defensible sequence is:

1. close the frozen v1e bytes and obtain fresh deliberation plus exact human
   ratification;
2. run CPU validation;
3. run DEV only under its declared compute envelope;
4. run held-out text only if DEV has known-good thinker headroom, no-memory
   failure, and no shortcut/leakage failure;
5. run the two LoRA fits only if the full text-stage conjunction passes.

The run is justified only because either outcome changes the next experiment.

## Smallest paper-bearing successor

Use a text-first, six-paired-world developmental Action pilot with fixed common
action/outcome lives and evaluations at 1C and 2C:

- dream-connected text memory;
- no memory;
- raw episodic RAG;
- an independent organized/reflection-memory baseline;
- shuffled action-outcome bindings;
- matched final-batch dreaming.

Hold action, thinker, retrieval, context, and reflection budgets fixed. Score
held-out A2/A3 behavior using normalized value, return/regret, recovery, and
plan success. The primary signal is paired A2/A3 advantage plus a better
1C-to-2C slope, not QA accuracy. Only after text memory adds action value
should the identical corpora be transported to LoRA and compared with a
direct-QA LoRA.

This successor adds what v1e cannot: replication, lifetime direction, strong
memory baselines, and actual multi-step behavior. More lifetime checkpoints
will still be required before making a saturation claim.
