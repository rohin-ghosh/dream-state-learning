# Countercritique: do not make a closed operator AST the PCFL-Compose organism

**Date:** 2026-09-02  
**Status:** fresh read-only scientific countercritique. This advisory does not
ratify the proposed change, authorize proposal or code edits, authorize CPU,
model, GPU, training, LoRA, network, publication, or scientific claims.

## Decisive ruling

**Do not replace the primary model-authored text memory with the closed
operator AST proposed in the semantic-memory audit.** That AST would make
record truth and surgical edits decidable, but it would also disclose almost
the complete algebraic language of the PCFL solution: actions built from
parts, event operators, permutations, inverse, ordered composition,
universal equations, definitions, and a privileged `RULE` retrieval class.
The resulting primary condition would test constrained symbolic program
synthesis and execution, not whether a frozen language model naturally turns
lived action/outcome experience into useful dream memory.

The opposite extreme is also wrong. Opaque prose cannot support exact claims
about which law, factor, operand order, or gauge the model stored. It cannot
support record-level truth, exact semantic deduplication, a 13-semantic-item
lower bound, orientation deletion, decisive-factor substitution, or
semantics-preserving LoRA views.

The recommended contract is therefore **behavior-first hybrid**, with a hard
separation between two lanes:

1. **`OPAQUE_TEXT_SELF` is the primary minimal-cycle organism lane.** Dream
   writes byte-preserved cited natural-language notes; Sleep performs only
   syntax, provenance, byte, and lexical-index operations; Think retrieves
   those notes and acts. Its gates use only exact prospective tray predictions,
   executed actions, and whole-corpus interventions. No component interprets
   note meaning after emission.
2. **`OPERATOR_AST_SELF` is a separately labeled structure-assisted diagnostic
   lane**, alongside the existing oracle-schema and class-informed ceilings.
   It is required only before making a factor/law mechanism claim, applying
   record-semantic cuts to model-authored memory, or claiming exact semantic
   transport into LoRA. It uses fresh model sessions and cannot be generated by
   parsing or translating the opaque lane.

If resources permit only one lane at the current one-cycle DEV, run the opaque
behavioral lane and accept the narrower result. It is sufficient to decide
whether the natural Dream/Sleep/Think path is alive. It is not sufficient to
promote a semantic-mechanism or LoRA claim. An AST-only success would not pass
that survival gate.

The present proposal should still **not be ratified as written**. Its current
schema is neither an exact semantic AST nor a sufficiently specified opaque
text-memory interface, and several gates still use semantic language that its
free strings cannot justify. The repair should narrow those gates rather than
turn the primary organism into a symbolic scaffold.

## 1. What the semantic-memory audit gets right—and where it overreaches

The audit correctly identifies five real defects:

- `memory_record.claim` has no registered denotation. Its four-way `kind` tag
  does not make it a semantic AST.
- “One local binding per record,” semantic equality, operand order, and truth
  cannot be checked inside prose without an unregistered semantic interpreter.
- the JSON Schema does not encode the full phase/op/terminal state machine;
- provenance is too flat to prove that a connection or revision depends on
  earlier model nodes; and
- “literal relation words” and free query strings do not specify a total,
  reproducible reader.

Those defects forbid semantic claims. They do **not** imply that the only
scientifically coherent repair is to formalize the primary memory as an
equational operator program. The current `experiment_spec.md` already adopts
the correct narrower observation in Section 8: exact semantic endpoints are
prospective A/B trays and physically executed target actions, while free-string
truth/precision/coverage is non-exact and non-gating. It also already limits
orientation and decisive-factor record cuts to structured oracle/class-informed
corpora. Those two boundaries should be made consistent throughout the change,
not reversed.

The audit also contains a stale numerical criticism relative to the bytes
reviewed here. The current proposal says `R=13`, 256 UTF-8 bytes per claim, and
4,096 UTF-8 bytes per package—not 15, 512, and 12,288. A real mismatch remains:
JSON Schema `maxLength` counts Unicode code points, not UTF-8 bytes, and the
runtime constraints are not themselves fully hash-bound in the schema. The
audit should be rebased before its numeric list is used as a blocking receipt.

## 2. Why the proposed closed AST is a scientific treatment, not neutral plumbing

The proposed grammar is type-safe and mechanically scoreable. It is not
hypothesis-neutral for this benchmark.

| Proposed affordance | Intelligence supplied by the interface | Resulting confound |
|---|---|---|
| `OPERATOR`, six-slot `PERMUTATION`, and `EVENT_OPERATOR` | Every event should be reduced to a reusable positional operator. | Removes the representational choice Dream is supposed to make. |
| `ACTION_FROM_PARTS` and `OPERATOR_OF` | The two public name parts are candidate causal arguments to the action law. | Privileges the factorized family over the matched independent-table family. |
| `INVERSE` and ordered `COMPOSE_APPLY_FIRST` | Missing compounds should be solved by noncommutative group algebra. | Supplies the exact operation family needed by the tree-path completion proof. |
| `DEFINE`, `RULE`, `FORALL`, and model symbols | The desired memory is a ground factor table plus a universal combination equation. | Collapses broad experiential connection into filling slots in a program template. |
| `statement_form=RULE` retrieval | Think should first locate a global law and then its keyed definitions. | Makes the reader protocol itself point at the decisive solution component. |

The AST does not literally name `stem factor`, `suffix factor`, `orientation`,
or the two PCFL equations. That is weaker than a class-informed prompt, but it
still narrows an open language-model search to the exact algebraic basis in
which the benchmark has a tiny solution. In the noiseless `S_6` construction,
the math audit already shows that a tree is a deterministic propagator and one
noncommuting chord is a one-bit selector. Adding the operator calculus and a
universal-rule slot risks testing whether the model can serialize that
preselected algorithm.

This risk is not cured by calling the grammar “family-neutral.” Syntactic
availability is not scientific neutrality. An independent table naturally
fits whole-action definitions, while the factorized family is uniquely
rewarded for using the provided part/function/compose primitives. A positive
factor-versus-independent contrast would then combine experiential discovery
with an interface prior chosen specifically to make factor discovery easy.

There is also an unavoidable fork in the proposed AST cuts. If generic SELF
may emit any well-typed program, it may express the useful relation without
the registered universal composition node, in which case the order and
orientation selectors return no match. If the prompt or gate requires the
registered node pattern, the experiment has required the solution
decomposition. An unavailable cut is an honest diagnostic outcome; making AST
shape availability a primary gate is over-amortization.

Finally, the AST is poorly aligned with the project's stated long-horizon
thesis. The thesis concerns traversal, connection, revision, lossy
consolidation, multiple memory views, shortcut formation, and eventually a
learned reasoning/search disposition. Canonical equations are useful
instruments, but they test symbolic sufficient-statistic storage. They do not
test whether natural thought traces become reusable experiential memory, and
they especially do not test the newer “LoRA as learned reasoning/search
control” thesis.

## 3. What opaque text plus exact behavior can establish

Opaque text is scientifically usable when the claim follows the observables.
No semantic parser is needed for the following facts:

1. Dream-1 committed exact A tray predictions before A outcomes existed.
2. Dream-2, after receiving only raw A events, committed exact B tray
   predictions before B outcomes existed.
3. A corpus frozen before targets caused a resolver to execute a registered
   D1 or D4 action sequence and `LOCK` on never-executed compounds.
4. Replacing the whole corpus with an empty, wrong-life, or antipodal corpus
   changed exact action bytes while a target-independent sham did not.
5. The same pipeline stayed at the certified target-only value in the matched
   independent-table family.

Together these can support a narrow statement such as:

> Under a frozen recurrent prompt and deterministic lexical memory interface,
> a resolver wrote cited text from public action outcomes, revised its
> behavior after later raw public events, and the resulting life-specific text
> causally improved exact prospective predictions and executed actions on
> never-executed compounds.

That is weaker than “the model learned the correct factor program,” but closer
to the natural experiential system the project says it wants to test. It also
has a clear falsifier: if the AST lane succeeds while opaque text fails, the
result is structure-assisted program synthesis, not a surviving natural
Dream/Sleep/Think pathway.

Behavior-only evidence does **not** establish that any particular prose note
is true, that the model represented orientation, that 13 natural-language
notes are information-minimal, or that Sleep preserved denotation. It proves
only byte provenance plus causal utility of the assigned memory object. The
paper must keep that boundary explicit.

### Stronger exact revision test

The present chronology shows temporal ordering but does not by itself isolate
what raw A changed: Dream-2 is also a fresh call with a different request.
Before calling the path “self-revision,” add a presealed **public-prefix-
identical orientation fork**:

- construct two valid continuations with byte-identical tree events,
  announced A requests, Dream-1 prompt, seed, trace, and commitment;
- reveal different ordinary A trays, each selecting a different valid
  continuation, without a match bit or label;
- keep Dream-2 prompt, budget, eligible handles, seed-by-role, and B request
  shape fixed; and
- require Dream-2 B predictions and subsequent actions to follow the observed
  continuation in both branches.

The sparse-tree mathematics makes this possible in principle: a tree admits
both orientations, while a noncommuting chord distinguishes them. This is a
clean behavior-level test of evidence-conditioned revision. If the construct
does not implement this fork, use “a post-A second Dream pass” rather than a
causal self-revision claim.

## 4. Exact recommended primary contract

### 4.1 Opaque model-authored record

The active primary record should be a structured envelope around opaque text:

```text
NOTE(record_id, text_utf8, public_event_ids, premise_node_ids, uncertainty)
```

- `text_utf8` is model-authored and byte-preserved. No admission, indexing,
  scoring, cut, or training decision may depend on its interpreted meaning.
- Use one primary record type, `NOTE`. The present
  `GENERAL_RULE/LOCAL_RELATION/EXCEPTION/UNRESOLVED` menu is not as severe as
  the operator AST, but it still primes a solution ontology and falsely
  suggests machine-checkable semantics. Questions or unresolved alternatives
  can remain text plus uncertainty.
- Public-event IDs and premise-node IDs are structural provenance. The parser
  checks reference existence, phase eligibility, acyclicity, and required
  premise counts; it does not check whether the cited evidence supports the
  text.
- Retain `R=13`, 256 UTF-8 bytes per note, and 4,096 UTF-8 bytes per candidate
  unless one new contract changes all limits together. Count bytes after one
  specified canonical JSON encoding; do not rely on JSON Schema `maxLength`.
- Deduplicate only exact duplicate active note bytes under a named byte
  identity rule. Call this byte deduplication, not semantic or AST
  deduplication. Provenance unions remain separate compiled metadata and all
  originals stay in the audit ledger.

The DREAM state machine still needs conditional schemas or an equally exact,
hash-bound parser/state-transition specification. `READ`, `NOTICE`,
`CONNECT`, `REVISE`, `PREDICT`, `COMMIT`, `ABSTAIN`, and `PASS` must have
phase-specific field cardinalities, premise requirements, mutation rules, and
terminal bytes. This is interface determinism, not semantic interpretation,
and should be fixed regardless of which memory lane is chosen.

### 4.2 Prompt contract

For `OPAQUE_TEXT_SELF`:

- retain the generic objective—read public episodes, write reusable
  target-independent notes, predict announced trays, revise or abstain—but do
  not provide operator, permutation, inverse, composition, equation, rule,
  factor, gauge, orientation, or target-path constructors;
- do not ask for a “program,” “operator AST,” or a privileged global-law
  record;
- keep public two-part action spelling and exact trays because those are
  declared benchmark observables;
- preserve exact predictions as separate non-memory fields so they remain
  scoreable without reading note meaning; and
- keep explanations/reasons in the trace only, outside active memory and
  retrieval.

The neutral prompt must run on the untouched factorized and independent roots,
not only the open root. Otherwise the primary result cannot distinguish
natural reflection from dependence on the supplied `NOTICE/CONNECT/REVISE`
process vocabulary. The one-shot control must use the same objective words,
record envelope, capacity, and terminal semantics as the recurrent prompt;
the current one-shot-only `COMPARE/HYPOTHESIZE/PREDICT/COMPRESS` wording is an
additional treatment, not a clean granularity control.

The proposal should also stop claiming that Dream and Think instantiate the
same resolver state machine merely because they use the same weights. Current
Dream operations and Think operations have different grammars and transition
semantics. Either bind a genuinely shared operation kernel or use the narrower
phrase “the same frozen backbone under role-specific recurrent interfaces.”

### 4.3 Exact lexical reader

Opaque memory requires no semantic parser, but it does require a total reader.
Freeze this or an equivalently explicit target-independent lexical contract:

1. Decode valid UTF-8, apply one named Unicode normalization and case rule,
   and split into maximal alphanumeric tokens. Preserve each literal public
   `stem::suffix` compound and, because the public morphology is already
   disclosed, its two literal parts. Add no stems, synonyms, embeddings,
   relation lexicon, or ontology aliases.
2. Index tokens found by that procedure in immutable record bytes. The index
   is frozen before target rendering.
3. Apply the identical tokenizer to the model-authored query. For query-token
   set `Q`, rank records by descending `|Q intersect tokens(record)|`, then by
   SHA-256 of canonical unchanged record bytes. A zero-overlap query returns
   `NOT_FOUND`; a cursor returns the next item in that fixed order.
4. Return one unchanged record plus provenance, never a paraphrase, summary,
   completed compound, path, or plan. Count query bytes, posting entries
   examined, cursor, return bytes, and calls.

The exact scoring formula is not privileged; what matters is freezing one
surface-only algorithm. “Literal relation words” is not acceptable because it
quietly requires a semantic lexicon. A structured query for
`statement_form=RULE` belongs only in the AST lane.

## 5. Exact metrics and gates

For the primary opaque lane, register only denotation-free exact endpoints:

```text
P_A        = exact Dream-1 A tray accuracy, missing = wrong
P_B        = exact Dream-2 B tray accuracy, missing = wrong
Y_D1/Y_D4  = registered executed trajectory plus LOCK, every failure = 0

memory_value   = Y(OPAQUE_TEXT_SELF) - Y(EMPTY_MEMORY)
life_binding   = Y(AUTHENTIC_CORPUS) - Y(WRONG_OR_ANTIPODAL_CORPUS)
revision_value = Y(DREAM2_CORPUS) - Y(NO_REVISION_DREAM1_CORPUS)
loop_value     = Y(RECURRENT_OPAQUE_SELF) - Y(ONE_SHOT_OPAQUE_SELF)
specificity    = [Y(OPAQUE_SELF,F)-Y(EMPTY,F)]
               -[Y(OPAQUE_SELF,I)-Y(EMPTY,I)]
```

Report the existing no-gate and perfect-public-gate contrasts separately;
they localize selection, but corpus-size differences prevent them from
replacing the clean empty-memory contrast. Calls, input/output tokens, bytes,
latency, read count, failures, and abstention remain co-primary diagnostics.
All values at three DEV roots are descriptive and nested under orbit root.

Rewrite the S1 gates as follows:

- **S1A natural-path survival:** exact construct/firewall/program/oracle
  ceilings pass; opaque Dream-1 has a prospective A prediction; opaque
  Dream-2 has a prospective B prediction; SELF completes a D4 target and goal
  twins redirect first actions; authentic text beats or directionally exceeds
  empty and wrong-life whole-corpus controls while a registered sham does not.
  No record-level semantic cut is required.
- **S1B specificity sentinel:** the factorized opaque arm remains above its
  observed-table/empty controls under the registered descriptive margin; the
  independent opaque arm remains at its exact target-only frontier; B
  predictions, abstentions, and failures are retained; comparator mutation
  leaves all opaque outputs fixed. Do not gate on whether prose contains a
  “universal law” or on “false-retained content,” because those are undefined
  without interpreting prose.
- **AST diagnostic gate:** if run, require well-typed prospective programs,
  exact denotation, and registered cuts in `OPERATOR_AST_SELF`, but do not let
  AST failure erase an opaque behavioral success or let AST success rescue an
  opaque failure.

For opaque records, replace semantic measurements with mechanically defined
ones: record/byte counts, exact duplicate rate, citation closure, premise-graph
depth, lexical retrieval overlap, reads used before each action, and corpus
intervention effects. Premise depth is provenance depth, not reasoning depth
or truth.

The following current phrases are unsupported in the opaque lane and must be
removed or moved to the AST/ceiling lane:

- final “law” truth or universal-law abstention;
- hidden factor or orientation correctness;
- semantic precision, recall, coverage, or atom count;
- one-binding-per-record enforcement;
- generic orientation deletion, wrong-order edits, and decisive-factor edits;
- the 4/13 semantic-item minimum-read certificate for SELF; and
- “semantic conservation” beyond exact source-byte conservation.

The 13-item certificate, exact program truth, and order/factor cuts remain
valid and useful for oracle-schema, class-informed, and structurally compliant
AST arms. They certify target and reader machinery; they do not establish what
opaque SELF represented.

## 6. Cut contract

### Opaque primary cuts

Only object-level interventions whose selectors do not depend on text meaning
are admissible:

1. `EMPTY`: no active notes, same reader and budgets.
2. `NO_REVISION`: the predeclared Dream-1 package, with A unavailable to a
   second cognitive pass.
3. `WRONG_LIFE` / `ANTIPODE`: replace the complete corpus and index with the
   predeclared other-life object.
4. `SHAM_TEXT`: replace text bytes by a predeclared target-independent,
   provenance- and footprint-matched control while retaining the intervention
   receipt. Because fluency may differ, this is a weak nuisance control, not a
   semantic placebo.
5. `ORDER_ONLY`: permute record presentation under a predeclared hash order to
   diagnose order sensitivity; do not call it a law-order cut.

Every receipt binds authentic input hash, selector independent of target and
truth, output corpus/index hash, byte delta, and branch reset. These cuts can
show that an authentic life-specific corpus was used. They cannot identify
which sentence or latent rule mediated the action.

### Structured diagnostic cuts

Orientation deletion, ordered-composition reversal, and decisive-binding
substitution require a closed AST and belong only to `OPERATOR_AST_SELF`,
oracle-schema, or class-informed corpora. Structural selectors freeze before
model output. Zero or multiple matches produce `CUT_UNAVAILABLE`, not a
manually repaired edit. Cut success supports dependence on that emitted
symbolic program; it does not retroactively explain the opaque lane.

## 7. LoRA implications

No LoRA is authorized or scientifically earned by this one-cycle proposal.
The representation choice should not silently predetermine a later training
claim.

Three future questions must remain distinct:

1. **Opaque-corpus substrate transport.** A separately ratified LoRA may train
   on exactly the selected opaque note bytes using only frozen mechanical
   record-ID, public-token, citation, and verbatim reconstruction views. It can
   be compared with the identical opaque text corpus using exact read and
   action endpoints plus wrong-life/no-adapter controls. Success supports
   parametric exposure to self-authored life text, not exact semantic or factor
   transport. Model-generated paraphrases are new authored data, not a
   representation-only Sleep transform.
2. **AST transport diagnostic.** A separate LoRA over canonical AST bytes can
   support exact node recovery, structural views, and law/factor adapter cuts.
   Its result must be labeled symbolic-operator transport. It cannot substitute
   for the opaque-corpus result.
3. **Learned reasoning/LOOP policy.** If LoRA is meant to amortize BFS/DFS,
   retrieval choice, shortcut use, or stopping—as the newer thesis notes
   propose—train public operation trajectories across development lives and
   evaluate on disjoint lives. That is controller learning, not per-life AST
   storage, and requires a separate outer-loop design and ratification.

Therefore the semantic audit's AST-to-view machinery is optional for question
2, useful but not mandatory for question 1, and irrelevant to proving question
3. Do not block the natural text survival test on an artifact optimized for a
different LoRA hypothesis.

## 8. Must-fix disposition

### Must fix before ratifying the current text DEV

1. Name the primary object honestly as an opaque text-note envelope, not a
   semantic DSL/AST, or explicitly add the two-lane hybrid with distinct arm
   labels, prompts, sessions, parsers, readers, claims, and gates.
2. Encode/hash-bind all DREAM phase/op/terminal transitions, field
   cardinalities, terminal bytes, premise references, acyclicity, malformed
   behavior, and UTF-8 byte accounting.
3. Freeze a total surface-only lexical reader, including normalization,
   tokenization, ranking, collision, cursor, and accounting. Remove undefined
   “relation word” recognition.
4. Make the primary prompt, neutral prompt, and one-shot comparison honest
   rungs. Run neutral on untouched factorized and independent roots; remove
   one-shot-only cognitive hints or label them as another scaffold treatment.
5. Rewrite T06/T09/T11/T18/T19 and the S1A/S1B prose so opaque SELF is judged
   by bytes, provenance, predictions, actions, and whole-corpus cuts only.
   Keep semantic-item and record-level cuts restricted to structured arms.
6. Remove exact gating on generic SELF “law,” “false content,” factor
   coverage, orientation records, and AST semantic conservation. A blinded
   human rubric may remain descriptive after freeze but can never gate,
   select, repair, or explain an exact endpoint.
7. Add the public-prefix-identical A-continuation fork before making a causal
   raw-evidence self-revision claim; otherwise narrow the wording to a second
   post-A Dream pass.
8. Freeze `EMPTY`, `NO_REVISION`, wrong-life/antipode, sham, and order-only
   intervention builders and receipts without semantic selectors.
9. State the maximum positive opaque-lane claim verbatim and explicitly forbid
   factor-program discovery, semantic compression, exact record truth,
   record-level mechanism, naturalistic generality, post-context scaling,
   learned-loop, and LoRA claims.
10. Rebase the semantic-memory audit against the current 13/256/4,096 bytes;
    preserve its valid schema/state/provenance objections but do not use stale
    capacity assertions as a ratification blocker.

### Must fix before any semantic-mechanism or LoRA promotion

1. Add `OPERATOR_AST_SELF` only as a fresh, structure-assisted diagnostic with
   a prompt-amortization label and an opaque-versus-AST factorial comparison.
2. Freeze the AST denotation, structural reader, selector failure behavior,
   and false-shape symmetry. Never translate opaque outputs into AST with a
   model, human, or hidden-family parser.
3. Require an opaque success for a natural Dream/Sleep/Think claim. Require an
   AST success only for factor/law representation and record-cut claims.
4. Choose which of opaque-corpus transport, symbolic AST transport, or learned
   LOOP policy is being tested. Each needs its own corpus, controls,
   visibility contract, claim sentence, new deliberation, SHA-bound human
   ratification, and GPU gate.

## Bottom line

The semantic-memory audit correctly refuses to pretend that prose has an exact
denotation. Its proposed cure, however, would put PCFL's operator algebra into
the organism's language and turn a test of experiential connection into a
test of symbolic completion under a supplied calculus.

Exact prospective predictions, executed target actions, independent-table
specificity, and whole-corpus interventions are enough for a narrower and more
honest minimal gate with opaque model-authored text. They establish behavioral
utility and life binding, not the contents of the model's theory. A parallel
closed AST is required only if the paper wants exact semantic mechanism,
record-level cuts, or symbolic LoRA transport. The scientifically decisive
ordering is therefore: **natural opaque behavior first; structured mechanism
second; LoRA question explicitly chosen last.**

training, LoRA, network call, or external action was performed.
