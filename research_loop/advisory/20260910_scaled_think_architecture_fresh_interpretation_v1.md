# Scaled THINK architecture: fresh interpretation v1

Date: 2026-09-10

Status: fresh-context interpretation only. No protocol, implementation, model
execution, resource use, or claim is authorized.

## Core interpretation

Continual THINK is a semantically continuous life across bounded model calls,
observations, context resets, DREAM, and SLEEP. A state/task can stop; the
organismal stream stops only when the harness stops it.

- **State:** bounded semantic work unit: prior checkpoint + active goal + new
  information -> plan -> think/execute -> review.
- **Goal:** persistent intention that may span states and contain subgoals.
- **Branch:** isolated speculative continuation from one shared state. It is
  not another child, classroom, or adapter lineage.
- **Join:** child-authored waking state that compares branch reviews, retains
  unresolved disagreement, and chooses one shared next plan/action.
- **Ledger:** append-only tree/provenance record; recording a branch does not
  endorse it as belief.
- **DREAM:** THINK used for working-context reconciliation and goal/checkpoint
  maintenance; no deletion from the ledger and no weight write.
- **SLEEP:** externally triggered organization plus conservative LoRA write.
  It may inspect the tree, but raw speculation is not automatically a target.

The smallest branch mechanism is shallow and bounded: one shared checkpoint,
several isolated candidate routes, compact route reviews, child-authored JOIN,
then one real-world action. Existing task/subtask orchestration should be
reused. The added intelligence target is the learned policy for allocating
breadth, depth, reflection, and action.

The base already has token-level CoT, planning, alternative generation,
self-critique, social/affective representations, and in-context revision. The
developmental target is state-to-state regulation: meaningful boundaries,
goal persistence, evidence-seeking, outcome-grounded review, outside-view
self-evaluation, synthesis, prospective recall, and learned stopping within a
hard external envelope.

Bootstrap should install meta-habits that help the child form and revise its
own rules. It should not install final-task skill, unlived autobiography, or a
literal age schedule.

## Main failure modes

- unbounded generation mistaken for continual life;
- repetitive state/review ritual amplified by SLEEP;
- branches that differ only in wording;
- speculative branches mutating the shared world;
- unsupported or first-branch-biased JOIN;
- training contradicted/abandoned drafts as truth;
- recursive self-description with no changed action;
- goal drift or trivial self-goal churn in quiet reflection;
- topology gains confounded with extra tokens; and
- final-task or outcome leakage into bootstrap/parenting.
