# Fable collaboration v3 -- corrected state boundaries and bootstrap purpose

This is a direct Codex--Fable design conversation requested by Rohin. It is
analysis only: not a protocol, architecture proposal, implementation request,
or execution request.

Read the complete v2 collaboration prompt bound with this request and answer
all twelve questions there. The current `IDEAS.md` is authoritative and adds
two corrections that must override any literal reading of the older prompt:

1. **Stopping ends a state, not the stream.** A child may decide that the
   current task or subtask is complete. It then receives the next external
   situation or enters a quiet interval in which it can reflect, choose a
   subgoal, or create a viable goal. The organismal stream ends only when the
   harness stops it. Distinguish task completion, route suspension, goal
   completion, quiet reflection, and external process termination.
2. **The bootstrap gives rules for making rules.** It is not mainly synthetic
   autobiography or reproduction of unlived episodes. Its candidate purpose
   is to install target-blind metacognitive habits--plan, judge, review,
   question uncertainty, allocate more thought, and connect one state to the
   next--that make later parenting and personal experience easier to absorb.
   The scientific test must still distinguish installed behavior from improved
   later learnability.

Treat age metaphors such as “zero to six months” as intuition, not numeric
plasticity or calendar rules. Reuse existing agent task/subtask machinery where
possible; identify the narrow added mechanism as learned state-level
metacognitive control plus persistent experiential writing.
