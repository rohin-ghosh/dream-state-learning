hash-bound architecture proposal and project context, but do not read any other
interpreter's output. Output only JSON matching
`architecture_interpretation.schema.json`, with `perspective` set to
`benchmark`.

measurements force that organism to be useful. Focus on:

disagreements. Preserve hashes and the human boundary. Do not edit code, see the
