```json
Key implementation details:

**`OLoRATrainer`**
- Loads the base model in `bfloat16` via `AutoModelForCausalLM.from_pretrained` with `device_map`; no adapters attached at init time.
- `fine_tune`: builds a `ReplayDataset`, wraps the base model with a fresh PEFT `LoraConfig` targeting `["q_proj","v_proj","k_proj","o_proj"]`, optionally loads prior adapters to extract B matrices, then runs AdamW + cosine LR schedule. Loss = `cross_entropy + lambda_orth * orthogonal_penalty`, where `lambda_orth` is linearly annealed from `orthogonal_lambda_start` to `orthogonal_lambda_end` over all training steps. Saves to `output_dir/task_{task_id}/` and caches B matrices in `self.prior_bases` for future tasks.
- `_get_lora_b_matrices`: iterates `named_modules()`, finds any module with a `lora_B` attribute (PEFT convention), returns a list of `lora_B.weight` tensors (one per adapted layer).
- `_orthogonal_penalty`: for each (prior task, layer) pair computes `||prior_b @ cur_b.T||_F^2` — fully differentiable w.r.t. current adapter parameters.

**`ReplayDataset`**
- Tokenizes `trajectory_text`, splits into context (everything before the last action) and target (last action). Context tokens are masked with `-100`; only target tokens contribute to the LM loss.
- Truncates from the left at 1024 tokens, always preserving the full target.

**`generate_synthetic_augmentations`**
- Samples each trajectory independently with probability `ratio`, calls `llm_fn` with a paraphrase prompt, returns new `EpisodeResult` objects with the same `success` flag.
```
