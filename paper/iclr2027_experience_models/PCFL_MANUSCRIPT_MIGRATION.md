## Abstract decision tree

### Full result

Use connected/traversable/expandable and lifetime-superiority language only if
E0, M, and all ordered L gates pass. Parenting and compression appear only if
their separate gates also pass.

### Mechanism result

If E0 and M pass but L does not, headline the causal experiential relay:
connected personal evidence changes goal-conditioned traversal and
information-seeking, and the grounded new write supports delayed old-plus-new
use. State that long-lifetime superiority remains open.

### Writer result

If only E0 passes, headline the repeat-write stability problem and the
transactional writer that preserves routing while making grounded child
continuations extractable. Do not call this an experience-model flywheel.

### Failure result

If the replacement writer fails, publish only a rigorously replicated failure
characterization if its independent roots and controls are strong enough:
personal low-rank writes can preserve useful proposal content while destroying
the motor/action interface, and ordinary loss/storage metrics miss the
failure. Parenting, connected knowledge, and lifetime claims are removed.
